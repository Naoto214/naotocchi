# 統合ホームのフレーム間隔とタップ応答

## 共有Linux環境での確認

WPE WebKit 26.5で森・昼・秋・晴れ・28体の正式ホームを読み込み、幅320／390 CSS px、高さ792px、DPR 2で計測した。本番は `9539e462`、V11足元のみは `3eaea1e7`、統合版は `dc29a33c`。各試行は新規コンテキストで同じ正常セーブを読み、音声開始用のタップ後に8秒予熱し、30秒の通常再生を計測。各幅で正順と逆順を実施した。フレーム計測の後に、画面上に露出した住民を12回タッチした。入力時間は信頼済み pointerup のイベント時刻から次の requestAnimationFrame コールバックまで。端末のタッチセンサー、画面表示完了までの時間、発熱・電池は実機で確認する。

全144タップの選択が一致した。統合版は全4組で本番・V11よりフレーム間隔のp95・p99が短かった。共有CPUの負荷により同じ390px本番のp95が150msから479msに変動した。統合版でも長い停止があり、絶対値をiPhoneの性能には換算できない。12入力のp95は最も遅い1件に相当する。
