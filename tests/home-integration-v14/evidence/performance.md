# 統合ホームのフレーム間隔とタップ応答

## 接触補正後の最終候補

森・昼・秋・晴れ・28体の正式ホームで、`8a45a2ad`（接触補正 `d3d3a3c3` を含む）と本番、V11足元のみを比較した。Linux WPE WebKit 26.5、320／390×792 CSS px、DPR 2。各幅・順番を別々のGitHubランナーに割り当て、同じランナー内で3版を順番に計測した。正常なゲームセーブから全28体が表示されるまで待ち、音声の初回タップ、8秒の予熱、90秒の通常再生、実際のタッチ12回を行った。自然な会話と一時停止を含み、描画負荷は試行の間でも変動する。

最終候補は各試行の中央値が16ms、p95が52〜93ms、p99が62〜106ms。4試行の合計360秒で13,231間隔を観測し、250ms超が3回（500ms超1回、1秒超0回）。本番は32／3／2回、V11足元のみは38／3／1回だった。390px正順では本番より候補のp95が35ms長く、逆順では116ms短かった。4試行とも候補のp99と入力p95は本番より短く、この比較で一貫した性能悪化は観測されなかった。
