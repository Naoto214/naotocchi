# メインテーマ VERSION 3 制作設計・実行記録

依頼仕様に基づき、現行homeとClaude Dを固定参照として、新規6旋律を制作する。2026-11-08 JST制作。main基点 e0120c58、参照PR #524の9c36c38、#522のb557e03。新規 comparisons/main-theme-v3/ のみ追加し、参照PR・本体・CIを編集しない。

Web Audioの共通合成ピアノ音色を採用。外部録音音源を使う方式より配布と再現が簡単で、旋律比較を妨げない。録音ピアノではないことを表示する。旋律単独／伴奏付き、原速／四分音符96 BPM、ループ、1曲ずつの再生を用意。各新曲は1周45〜90秒。既存2曲は比較用に周回する。

1. 参照を固定保存しhomeの音高・発音位置・和声を原本と照合する。
2. Aは明るい応答句、Bは3拍子の浮遊感、Cは休符を含む親しみやすさ、Dは短調からの希望、Eは5音中心の短い動機、Fは6/8の旅と帰還をそれぞれ手作業で作曲する。
3. songs.jsを唯一の譜面データにし、MIDIとMusicXML、読める音名譜を生成。再生成スクリプトを保存する。
4. 共通のイベント列を再生・音声レンダリングに使う。停止・連打・モード変更・バックグラウンド移行を点検する。
5. 拍数、尺、MIDI読み戻し、音量・ピーク、ソース一致を検証。聴感評価とは区別する。
6. 非公開試聴ページを公開し、GitHubに独立ブランチとDraft PRを作成。mainにはマージしない。

レビュー対象：iPhone縦画面、再生の連打、音色/速度変更中の二重再生、最終小節と先頭の接続、MIDIとブラウザ音声の一致。実機聴感はユーザーが判断する。
