### 主題と構成（聴感評価ではなく作曲意図）

- A：G4–C5–E5–D5–C5。短い跳躍のあとに戻る呼びかけ。1〜8小節で提示と応答、9〜12で上方へ、13〜16で帰還。現行の分散和音列そのものは用いない。
- B：G5（付点）–E5–F♯5 → A5。長短の呼吸で小さく揺れる動機。1〜8提示、9〜16変形、17〜24下降と帰還。18小節Cm6で色を変える。Claude DのE–F♯–B動機を引用せず、3拍子・リディア的な浮遊感という特徴を発展させた。
- C：A4–C5–D5・休符・C5–A4。休符を含む問いと返事。F上のB naturalで幻想性を足す。9〜12の高音域から原点へ戻る。Fの調号は譜面上の便宜で、B♭を用いる通常のF majorではない。
- D：長いF♯5からE–D–C♯へ。1〜8はB minor中心、9以降D majorへ重心を移す。終わりのDから、次周のBm上のF♯へ共通音関係でつながる。
- E：G4–E5–D5という三音の合図。全曲で使う音高はG4/C5/D5/E5/G5の5つ、音級は4つ。反復の途中で9小節だけ上のGへ移し、伴奏のAm・Fが明るさ一辺倒にならないよう支える。
- F：A4–D5–F♯5–E5–D5。6/8の二つの波に、8分＋4分の重心移動を置く。1〜8出発、9〜16遠出（14小節Gm借用）、17〜24帰還。Bのワルツ型と異なる周期感。

全曲は明示的な音符データを手作業で作曲。音色・移調・速度だけを変えた候補ではない。最後の休符は呼吸として残し、人工的に埋めない。ループの音楽的な自然さ・長時間の飽きにくさ・記憶への残り方は実際の試聴で判断してほしい。理論上の意図を満足度の点数に置き換えていない。

## 比較の仕様

- 全8曲で同一の合成ピアノ風音色。生演奏やサンプルピアノではない。
- 旋律単独／軽い伴奏付き。伴奏はベースと控えめな分散和音。曲別の豪華な音作りは行っていない。
- 原速／共通96 BPM、ループ、停止、音量、設定どおりのWAV保存。
- 全条件でRMSを原則−20 dBFSに揃え、ピーク上限0.85。知覚音量が完全に等しいという保証ではない。
- 音の出始めに6 ms、終わりに75 msのエンベロープ。ループ終端を超える残響成分は先頭へ折り返してバッファを周期化。AudioBufferSourceNodeのloopによる再生。
- 現行は8小節×3、Claude Dは16小節×2、新曲は一周。長さ合わせのため新曲を機械的に水増ししていない。
- バックグラウンド・ページ離脱時は停止。復帰後は再生ボタンで再開。自動再生しない。
- 現行曲の音高・発音位置（微小swingを含む）・コードは固定。発音長は比較用に次の発音までの90%へ統一し、本番の短いゲート・ドラム・三角波は再現しない。現行の音源そのものの置換ではない。

## 保存内容・再生成

- `songs.js`：6案の正本譜面。四分音符=1、r=休符、音名は科学的音高表記。
- `reference-songs.js`：PR #524のsongs.js原本を無改変保存。表示・演奏に採用するのはcurrentとDのみ。他の4候補は参考ソース内に残るが試聴曲には含めない。
- `catalog.json`：全8曲と伴奏を含む時間軸。
- `scores/*.musicxml`：主旋律＋コード記号、各曲一周分。汎用楽譜ソフトで編集可能。
- `scores/*.svg` / `scores/index.html`：Verovioで組版した五線譜。
- `midi/*.mid`：原速の旋律と伴奏。channel 0旋律、channel 1伴奏。発音・休符・テンポ・拍子を保存。合成音色や音量正規化はMIDIには含まれない。
- `engine.js`：全条件共通の音符列・合成・WAV出力。
- `VALIDATION.json`：32レンダリングの数値結果。
- `PLAN.md`：制作設計。`SHA256SUMS`：保存ファイルの整合性確認。

```sh
node tools/catalog.cjs
python tools/export.py  # mido, verovio が必要
node tools/check.cjs ../../../audio.js
```

テストはこのディレクトリから実行。参照検証を省く場合だけ引数なしで実行できる。ブラウザ再生には外部依存・ネットワーク音源不要。VerovioはSVGの内部IDが変わることがあるため、再組版後はSHA256SUMSを更新する。
