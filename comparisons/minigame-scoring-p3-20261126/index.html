なおとっち・ミニゲーム採点監査 Phase 3(2026-11-26)

連打や押しっぱなしでは高得点にならない。上手な人の点はそのまま

13種(18本)の操作と採点を見直しました。本物の games.js を2つ(変更前 = Phase 2 まで、変更後 = このブランチ)読みこんで、遊んで比べられます。点数とコインの帯は本体と同じ計算で表示します(記録・コインは実際には増えません)。

変更のきまり

  • ゲーム本来の目的(ねらう・タイミング・考える)を果たさない連打・押しっぱなし・放置に近い操作では、高得点にならないようにする。
  • 連打そのものが遊びのゲーム(りくじょう・ピンボールのフリッパー)は変えない。運の要素もそのまま。
  • 上手な人の点は下げない(ボットで変更前と同じか確認)。初心者でも30点以上がとれるようにする。
  • 直したゲームには参加度メーターも入れる(放置・1回だけ・意味のない操作は記録しない)。
  • コインの帯・げんき・育成(C案)・クイックゲームは変えていません。過去の自己ベスト・実績もそのまま。

13種の一覧(目安)

ゲーム連打・放置に近い操作ふつうに遊ぶ上手に遊ぶコインへの影響

「変更前 → 変更後」。自動プレイ(ハーネス)6〜8回の平均。70点以上=大成功(60コイン)、30〜69点=ふつう(30コイン)、29点以下=しっぱい(0コイン)。

7つのプレイヤー像と 1分あたりの報酬

プレイヤー点(平均)記録へんしん/分コイン/分きげん/分そだち/分

1回の時間 = プレイ時間 + 画面の行き来 8秒 で計算。記録される回: へんしん +25・きげん +5+点/5・コインとそだちは点の帯。記録されない回: きげん +2 だけ。ボットの操作なので、人のプレイとは違います。
