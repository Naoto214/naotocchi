# 落下モーションの描画負荷と操作検証

## 正式ホームの実行中に測った値

比較ページが読み込むゲームを各条件で新規に起動した。390×844 CSS px、DPR 2、単独表示、通常速度、演出強度100%、落下設定は4項目とも標準。両案は同じ背景・初期フィクスチャと住民数を使う。テスト実行時のレスポンスで更新の採用回数と処理時間を記録した。配布ビルドに計時コードは含まれない。

**rAF Hz** はブラウザーのアニメーションコールバックの到着頻度。p95と最長はその間隔で、端末パネルへの提示フレーム数は未計測。**住民更新/秒** はコントローラーが更新を採用した回数。追いつきのための複数の model.step をひとまとめに数える。**環境描画/秒** は背景を更新した際に実際に環境描画関数へ入った回数。住民4体以上では既存の描画間引きが働く。

### 28体で3分間

同じ森・秋の昼・28体、各案を180秒ずつ実際に再生した。下表の秒数は実時間。長時間E3を先に測定し、続いて最終E3+で測定した。E3のみ先行ビルドで起動しており、最終基準側は別途#567と52枚の画素照合を行った。環境描画と住民描画の各最大値は試験内の独立した値で、同一フレームとは限らない。住民モデル列は更新ブロック全体の同期所要時間を示す。

| 案 | 実時間 秒 | rAF Hz | p95 ms | 最長 ms | 250ms以上の回数 | 住民更新/秒 | 環境描画 最大 ms | 住民モデル 最大 ms |
|---|---|---|---|---|---|---|---|---|
| E3 | 181.2 | 38.8 | 50.1 | 3333.2 | 53 | 21.2 | 41.8 | 3247.3 |
| E3+ | 180.4 | 48.1 | 33.3 | 1349.9 | 12 | 25.2 | 105.5 | 1326.0 |

E3は計測開始59.3秒後に最長間隔が始まり、この区間で住民モデル更新に3247.3msかかった。

E3+は計測開始119.7秒後に最長間隔が始まり、この区間で住民モデル更新に1326.0msかかった。

新しいブラウザーコンテキストで#567自体のE3を同じ森・28体・180秒で予備測定すると、rAF 48.6Hz、住民更新25.2回/秒、最長1,666.5msだった。最長間隔内の住民モデルは1,661.8ms、試行内の環境描画単発最大は16.2ms。基準側自体でも試行差がある。[#567の予備試験](evidence/forest-28-source-567.json)

共有Linux環境の各案1走。基準側の序盤は同じCPUで独立した#567の予備測定が一部重なり、他のCPUでも検証を実行していた。住民が選ぶ行動やホストの負荷は回ごとに変わる。短時間表には安定した60Hzから外れる区間もある。これらの標本から28体での増悪の有無や極値の上限を保証することはできない。同期計時の外で起きるGPU・ブラウザーの待ち時間は切り分け対象外。

雨の海4体を測定順を反転して18秒ずつ再測定すると、rAFは13.1 → 9.9Hz、p95は199 → 300ms、最長は1,050 → 2,607ms。各案で最長間隔内の住民モデル処理に999 → 2,430msを要した。この試験での環境描画の単発最大は10 → 6msだった。同じWPEで住民を外し、Canvasの描画と全画素取得までを分離して再測定した。各案48フレームの中央値は雨の海で10.0 → 9.5ms、夜の雪国で4.0 → 4.0ms。E3+全体の低い値はこの単独比較では再現しなかった。WPEで生じた入力の長い待ちと住民モデル処理には追加確認の余地がある。

[海の逆順再測定](evidence/webkit-sea-repeat.json) ／ [WPE環境Canvas単独](evidence/webkit-compositor.json)

同じWPEで320・375・390・430 CSS pxを試した。「動きを減らす」を有効にして両案の切替、粒子のON/OFF、4本のスライダーの上下限・標準値、比較境界のキーボード操作を確認した。全幅でホームの描画矩形の誤差は0.02 CSS px未満、環境時計と4体の配置は静止し、本編セーブに置いた確認値も保たれた。

iPhone Safari実機の表示フレーム、タッチ遅延、温度、電力、長時間のメモリ挙動は未計測。WPEの描画ドライバーと端末のGPU・OSは異なる。採用判断には実機での比較が残る。

## 再現

比較ビルドをローカルHTTPで起動し、PlaywrightのPythonパッケージ、Chromium、WebKitを用意する。

```sh
python verify_v6.py touch --scenes forest-leaves --counts 1 4 28 --seconds 10 --out short.json
python verify_v6.py load --scenes forest-leaves --counts 28 --seconds 180 --out long.json
python verify_compositor.py --out compositor.json
python verify_v6.py touch --engine webkit --scenes snow-night sea-rain --counts 4 --seconds 6 --out webkit.json
python verify_controls.py --engine webkit --out controls.json
python verify_compositor.py --engine webkit --scenes sea-rain snow-night --out compositor-webkit.json
```

各コマンドの既定URLは http://127.0.0.1:8196 。別のポートは `--url` で指定できる。
