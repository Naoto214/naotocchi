## 比較方法

各地域で1・4・10・20・28体、320・375・390・430 CSS pxの全20通りを比較する。V6・V7・V8をそれぞれ独立して起動し、住民ID、初期の足元座標、表示サイズ、乱数、画面、最初の指操作の座標を照合する。以前のV6・V7と同じ入力を再生するため、前回のドラッグ・タップの生データと前回300秒後に選んだ住民IDを使用する。各条件の初期モデルに対して歴代の短距離操作、斜め、占有地、空き地、障害物、タップを試す。該当する地形・相手のない予定操作は理由付きで保存し、実行した操作の分母から除く。タップ・ドラッグはいずれもChromiumのCDP経由でブラウザーに送信し、実際のtouch型のtrusted pointerdown／pointerupを確認する。

別の同一初期状態から、住民に追加の指示を出さず、モデルを0.05秒ずつ300秒進める。全住民の実際の一歩、経路、フットプリント間の連続接触、会話を含む反応を観測する。60モデル秒ごとの6枚で、足元・影・装備のアンカーを照合する。300秒後のドラッグ対象は3版とも前回と同一人物。住民が自ら歩いた結果、最終座標と指で押す開始点は版間で異なり得る。各地域の390px・28体ではゲーム自身に装備付きの世帯を保存・再読込させ、所持金、地域、成長、恋人、仲間、装備、更新番号、復帰後の操作を確認する。

「到着」は本人に発行した移動指示の経路終点への到着イベント、または実歩行の後、計測期限にはその終点（誤差0.01 CSS px以内）で歩行が完了していた場合。「指先4px以内」はこのうち実際の指の終点から4 CSS px以内。「自律・ドラッグ双方が失敗」は、300秒間に自律計画失敗が発生し、自律歩行開始0回だった対象が、その後に本人へ届いたドラッグでも一歩も動かなかった場合。誤タップ・無指示は別集計。「復帰」は失敗エピソード発生後、実際に足元が動いたことを確認した件数。実際に歩いた住民と通常の自律歩行を開始せず脱出経路でのみ動いた住民を別記する。

モデル進行中の検査には観測コードを挿入する。処理時間の計測には別の通常速度の長時間試験を用いる。この試験の時計はモデル秒で、iPhone Safari実機でのフレーム間隔・発熱・指の操作感は未検証。
