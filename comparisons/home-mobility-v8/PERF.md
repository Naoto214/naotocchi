## V7で長い間隔が増えた場面

PR #576 の通常順・逆順の全生フレームから、500msを超えた区間を抽出した。Linux WebKitのプロセス・スレッド別CPUを、各区間の前後に最も近いサンプルで比較した。

## 前景遮蔽で省けた処理

V7は住民一人の位置を書き込むたびに、同じフレーム内でスプライトと装備の矩形を読み、前景マスクを描き直していた。今回の予備観測では、森28体・98回の描画で前景から2,842回の矩形読み取りが発生した。V8は全住民の位置を書いた後に各画像の矩形を読み、一括でマスクを適用する。静止中のまばたき・呼吸でも矩形を読み直し、既存の多角形、SVGマスク、装備の変換を利用する。

同じV7モデル、同じseed、同じ森の28体に72回のモデル更新・描画を与え、描画関数だけを切り替えた。Chromiumのスタイル再計算はV7→V8で150→124回、逆順のV8→V7で116→156回だった。実レイアウト回数はそれぞれ28→28回・25→28回。全4試行で移動開始は3回、28体の最終座標が完全に一致した。これは描画ステップ単独の実験であり、自律歩行中の画面フレーム間隔は別に測定した。[ブラウザーのスタイル再計算と最終座標](evidence/render-style-work.json)

森（昼）と、とかい（夕）では、同じロード済みのゲーム内でV7→V8→V7と描画関数だけを入れ替え、毎回28体分を描き直して比較した。森の780×860画素、とかいの692×1,052画素ともに、RGB値が異なる画素は0だった。動く時計やゲームタイマーを固定したのは、この画素検証の間だけである。[描画領域・RGBハッシュ・戻し比較](evidence/render-pixels.json)

Linux WPE WebKitでも同じ森・とかいのRGBが各3回完全に一致した。さらに森・みずべ・おうち・とかいで、実際の画面上の各画像について、V7の読み取り順とV8の読み取り順の矩形・マスクを同じ描画中に記録した。起動時・自律再生時を含む7,076件で、生成したSVGのURLとマスクの有無はすべて一致した。CSSの動作中は、読み取りの間に矩形が最大0.3754 CSS px変化した。[WebKitの画素比較](evidence/render-pixels-webkit.json) · [4地域の観測](evidence/render-geometry.json)

おうちでテスト用に主人公を既存の家具の遮蔽面へ移した1件では、矩形が0.0824 CSS px変化する間にSVG文字列も変わった。マスクの有無は一致した。同じ320px幅で再現すると、テストが選んだ原画上の多角形中心は画面のy=527.1で、ステージの可視範囲y=147〜287の外にあった。同条件の再試行では、自然表示1,508件・強制配置を含む609件すべてで文字列も一致した。[再試行](evidence/render-home-repeat.json) · [家具の投影位置](evidence/render-home-projection.json)

みずべの横画面では実際に画面内にある岸の輪郭上へ主人公を置き、前景マスクが適用された状態でV7→V8→V7を撮影した。Linux WebKit上の518×410画素すべてが3回とも一致した。[表示中の岸と主人公の遮蔽](evidence/render-river-edge.json)

## 指を離してから足が動くまで

共有Linux環境のChromiumで、すべての版に森28体・同じ6回のタッチドラッグを入力した。各版とも6回すべてで指示した本人を選び、3回で本人が実際に歩いて経路終点に到着した。pointerupを捕捉した時点でネイティブrAFの監視を開始し、指示時の足元から1地形単位以上動いた最初のフレームと、経路終点から0.25単位未満で歩行を終えた最初のフレームを記録した。

| 版 | 到着 / 指示 | 歩き始めを観測した実時間の中央値 | 経路終点到着を観測した実時間の中央値 |
|---|---:|---:|---:|
| V6 | 3 / 6 | 712 ms | 712 ms |
| V7 | 3 / 6 | 1,565 ms | 1,565 ms |
| V8 | 3 / 6 | 348 ms | 411 ms |

対象になった3体のIDは `bat`、`punyu`、`rabbit_friend`。V8の最初の移動観測は144〜2,904msと幅があり、フレーム間隔が広いと歩き始めと到着を同じフレームで初めて観測する。これは混雑ホスト上の少数例で、本人端末での応答時間を保証する測定ではない。[信頼済み入力・座標・実経過の個票](evidence/touch-onset.json)

```sh
base=http://127.0.0.1:8377/game
python ../home-mobility-v7/performance-clock.py --base "$base" --arms v6,v7,v8 --seconds 180 --quiet --out forward.json
python ../home-mobility-v7/performance-clock.py --base "$base" --arms v8,v7,v6 --seconds 180 --quiet --out reverse.json
python performance-trace.py --base "$base" --arms v6,v7,v8 --seconds 25 --trace --out trace.json
python performance-touch.py --base "$base" --out touch.json
python performance-report.py . --out summary.json
python performance-render.py --base "$base" --mode work --out style.json
python performance-render.py --base "$base" --mode parity --out geometry.json
python render-pixels.py --base "$base" --engine webkit --out pixels.json
python render-pixels.py --base "$base" --engine webkit --occluded-region river_lake --out bank.json
python touch-onset.py --base "$base" --out onset.json
```
