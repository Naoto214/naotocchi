# 混雑時の移動をどう検証したか

## 短い退避

V7の森・390px・28体の連続再生が終わったときの足座標を保存し、同じ地形・身体寸法・接触楕円・前景マスクで復元した。カワウソと石像に同じ自律歩行を指示すると、V7では両方とも却下された。V8では元の8・12・18・24 CSS pxの退避に失敗した場合だけ、6・4.5・3 CSS pxも調べる。この2例で描画上3〜6pxの実歩行と到着を確認した。

複数の足に接している場合、各接触楕円から離れる方向が作る角度区間の境界を求め、その間の方向も試す。近隣への食い込みの総量が下がり、すべての足に対して区間全体が従来の接触判定を満たす候補に限定する。前の退避起点への逆戻りを45モデル秒間抑え、同じ自律退避を始める従来の15秒間隔を維持する。移動量は各モデルステップの実座標から測った。

## 周囲が本当に動いたときの再試行

16体以上の部屋で自律歩行に失敗した住民は、近隣住民の足座標を最長12モデル秒覚える。近隣の構成が変わるか、足が3 CSS px以上動いた場合に、元の意図を一度だけ再評価する。再評価の開始は全体で1モデル秒に1件まで。次の通常行動に移った住民、手動指示中の住民、期限を過ぎた意図は対象外となる。70モデル秒以上歩けていない場合には、近くの補助者の手動操作や会話が終わり、道を譲れるようになったときも再評価する。早期再評価は本人の近隣に限る。通路試験では、80 CSS px離れた2人目の補助者が同じ足位置で会話を終えたとき、先の指示の12秒間は待機した。次の通常の指示では協力者全員の状態を再確認し、2体が順に道を譲って本人が12px進んだ。遠くの足だけを動かした通路実験では本人は静止し、通路に接していた隣人を動かした場合だけ本人が12px歩いて到着した。

## 最大2体の道譲り

V7の2体用探索には、探索中に遠方の無関係な住民が1人でも動くと保留中の計画を破棄する分岐があった。保存された森の初期足位置に遠方の移動役を加えた切り分け試験では、V7では道譲りを始められず、V8では2人が順番に歩いた後で本人が指先8px以内へ到着した。

V8では分割中の幾何探索を続行しながら、足が動いて指先まで直接通れるようになった場合は直行を優先する。補助者が歩き出す直前に、本人・補助者・第三者の現在の足、残る全区間、地形、前景、補助者の参加可否を検査し直す。本人までの安全な計画を用意できた場合だけ、1体ずつ通常速度で歩く。

自律歩行では従来の混雑時70モデル秒の長期待機を超え、本人の意図・通常経路・単独退避が失敗した場合に、同じ道譲り機構を1件だけ起動できる。元の意図へ最大12 CSS px進む候補から、1体の補助を先に、次いで2体の順次補助を探す。地形・参加者・接触の再検査を通った各段階を、1フレーム2バッチ以内で準備する。探索を最後まで行って安全な経路がなかった場合だけ、その結果を8方位・2距離帯で覚える。開始時と終了時で本人、補助者候補、補助者の行く手を塞ぎ得る住民の足や参加状態が一致することが条件となる。次の自然な指示が別の方向であれば探索でき、同じ条件で却下された案を繰り返さない。開始から12モデル秒で失効し、新しいタッチ・画面停止・動きを減らす設定で補助を中止する。住民の歩き出し、手助けだけの歩行、本人の到着は別の観測値として扱う。最大2体で解決することは保証していない。

## 再現

生成した本人限定比較版の game/ を指定して以下を実行する。

```sh
MOBILITY_GAME=/path/to/bundle/game node --test comparisons/home-mobility-v8/movement.test.mjs
```

全20件で、実景からの短い退避、遠くの移動と近隣の移動の違い、補助者1体・2体の歩く順序、手動操作や停止による中断、同一配置の描画同期、退去を確認した。手動操作から12モデル秒たって補助者が再参加できるケースでは、本人が再度指示を受けた場合と、先の指示がまだ有効な場合の両方で到着した。左側が塞がった通路で、次の意図が右に変わった場合の到着も確認した。道譲りの人数・中断に関する試験には、原因を分離するため通路形状を制御したケースを含む。森の長時間試験や全地域の入力試験とは集計を分ける。

V7の300モデル秒の保存状態で、自律とドラッグが同時に失敗した3件については、[復元座標](dual-drag-feet.json)と[ブラウザー上での幾何検証結果](evidence/dual-drag.json)に記録した。いずれもタッチは本人に届いていた。2〜24 CSS pxを3度刻みで検査した範囲では、指示に近づける安全な初動や、最大2体の短い直線退避に続く有意な移動は見つからなかった。
