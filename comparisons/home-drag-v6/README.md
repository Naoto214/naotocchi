# ドラッグ操作の仕上げ VERSION 6

比較基準は独立Draft #572の `a0df9061c26dde237158ba3423dd4732ca8bec42`。本人限定ページのV5とV6で地域、背景、人数、時間帯をそろえ、同じ住民の初期位置から指を動かせる。ゲームの入力から、本人が歩き始めて足が着くまでを検査する。

- 指の目標が空いていればそこへ歩き、通路があれば迂回する。近い代替点では指示方向、経路の長さと周囲の住民との距離を考慮する。
- 密集時は、地形と接触の両方で安全な歩行を確認できるときに道譲りを使う。進める距離が短すぎるときや、譲れる通路がないときは既存の表情と姿勢で応答する。
- ホーム上の短いリアクション、メニュー、病気や成長の演出、手動の一時停止について、同じ指の入力がどの段階まで届くかを調べる。
- サイズB、足元の表現、背景、移動V5、装備、会話、セーブの元ファイルはV5配布物に残す。通常のホームは元の入口を使用する。
