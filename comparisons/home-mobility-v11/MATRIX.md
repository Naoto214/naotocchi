# 13地域の通常歩行と実タッチ

320・375・390・430 CSS px、住民1・4・10・20・28体の各組合せで、V10・足元同期だけを変えたV11・最終候補を開く。対象は通常の初期配置、乱数214、昼、サイズB。各ホームで同じ名簿・体格・足位置・画面上の指の座標から始める。

## 起動直後の乱数と最初の行動時刻

おうち・4体・320pxでは、同じ乱数214と同じ4体の初期足位置でも、初期化を終えた時点のモデル用乱数が異なる場合があった。ある再生のV10は8回の乱数消費後（2,992,601,918）、足元修正版は4回後（2,531,321,450）だった。同じV10を別に開くと4回後だった。通常歩行の前に生じるこの差を、候補の経路選択の効果に含めない。[初期化の比較と復元記録](evidence/matrix-startup-pilot.json) ／ [同期と乱数の呼び出し観察](evidence/foot-startup.json)

独立して起動した実際のホームの入力と5分後の結果を記録した上で、正式な比較ではV10の開始状態を受け取ったゲームからも測定した。全員の足・原画サイズ・初期活動・次の行動時刻、モデル時計、乱数、選択、既存の手動指示などが一致することを確認してから同じ指を動かした。自然な開始状態がすでに同じときは、その実測を共通の比較結果として使った。原画と地形を読む描画処理は各版本来のものを使う。

## 独立した最初の260条件

最初に13地域すべてを独立起動で測定した。初期の足と操作座標を揃えたこの回では、V10・足元修正のみ・散歩先変更を加えたV11の通常歩行は3,215・3,215・3,209住民条件。5分後のドラッグ到着は233・235・236件だった。次の測定では、開幕の活動・次の判断時刻・乱数も追加で照合した。両方の実行の元ZIPと判定を分けて保管した。[最初の13地域の全数](evidence/matrix-first-cells.csv) ／ [原本とSHA-256](evidence/matrix-first-receipt.json) ／ [集計の再実行](matrix_original_v11.py)

## 測定方法

- **開始直後の入力**　タッチ対応Chromiumにブラウザーのタッチ開始・移動・終了を送り、ゲームが受け取った信頼済みpointerイベントを検査する。障害物・占有・空いている地点、通常距離・斜めのドラッグとタップを、過去の測定と同じ条件で再生する。各操作の前に同じ配置と乱数へ戻す。
- **5分間の生活**　別に開いたホームで本物のモデルの歩行・道譲り・接触・会話の処理を300モデル秒まで進め、各住民の要求、開始、足の変位、完了を追う。通常歩行は、自分の目的地へ0.75 CSS pxを超えて近づき、実際に8 CSS px以上変位して到着した歩行。退避は別に数える。表示要素の同期時に足が変化した回数と、その前後の座標も別に記録する。5分後は事前に決めた住民を実際にドラッグし、実際の足が採用終点に届いたかを調べる。
- **同じ位置を復元した操作**　V10で5分暮らした全員の足・体格・活動・経路、モデル時計、乱数、手動指示を3版それぞれのゲームへ移す。表示を更新し、足・投影・指先・地形の一致を確かめてから同じブラウザー入力を送る。待ち行列と道譲り用の一時探索は同じ空の状態から始める。自然に経過した結果で選択・指示・歩行・到着が変わった場合は、足元版または最終候補の配置からも同じ3版を動かす。受理と終点到着は別に数える。
- **測定時間**　地域別の5分はゲーム内時計。実時間の通知が入る10分以上の連続再生は、別の森試験で測定する。地域別の値からiPhone Safari実機の性能は推定しない。

## 変わった住民と入力の内訳

- **通常歩行**　散歩先を変えたのは10地域の28体・320pxだった。10世帯すべてで、最初の変更までに成立した歩行計画は足元版と開始時刻・始点・目的地が一致し、5分の途中の同期で住民の足が飛んだ例はなかった。ジャングルでは119.6秒のアザラシの目的地変更が1回。それまでの75計画は同一で、5分後にはフクロウなど6体が通常歩行0回、石像は0回から1回となった。さばくの恋人は0回から5回、みずべの恋人は1回から0回。後者は候補では散歩を要求しなかった。[変更のあった全世帯・個体](evidence/matrix-goal-effects.csv)
- **開幕の入力**　公表V10から同時測定V10の終点到着が2件少ないのは、いなか20体・28体の各320pxで、同じ指が主人公の代わりにサルを選択したため。足元版では20体の1件、V11最終候補では0件。元の主人公への移動指示の有無まで分けて数えた。[全差分](evidence/matrix-opening-differences.csv)
- **自然に経過した後の入力**　V10と散歩先変更候補の到着は6件で入れ替わった。28体・320pxのみずべの主人公とジャングルのフクロウは、変化後の配置で歩いて到着。おうち28体の柴犬は別の住民が選ばれ、星空・記憶の湖の10体の恋人は指示を受けても経路が成立しなかった。これら5件では5分後の全員の足位置が異なった。変化した終点を含めて同じ配置へ移した入力を再生すると、3版の結果は一致した。[実タッチと経路分類](evidence/matrix-aged-failures.csv)
- **経路成立後の中断**　森10体・320pxのカワウソだけは足位置や保存できる行動状態も完全に一致し、3版とも本人が選ばれ、同じ補正点と経路を作った。V10と足元版は2歩で到着。候補の自然再生はリリース直後に手動目標がなく、歩き出せなかった。このケースを同じ状態に戻した6操作はすべて到着した。元の操作でどの非同期処理が目標を取り消したかは未特定。追加した10回のローカル自然再生はすべて到着し、元の5分後とは異なる配置だった。[過去の森の入力と照合](../home-mobility-v10/MATRIX.md)

この条件では、足元修正のみの版では、3,276住民条件のうち公表V10と同じ3,215条件で通常歩行が成立した。散歩先を事前に変える候補は、特定の住民を救う一方で通常歩行する個体が6条件減り、5分後のドラッグ到着も公表値より2件少なかった。全地域の標準にする判断は保留する。
