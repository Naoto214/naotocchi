## V9からV10へ引き継いだ犬の目的地

V10の普通の散歩では、住民の足元が収まる矩形から横・縦を独立に抽選する。横差が35地形px未満なら、今いる側から遠い矩形の端に寄せる。この矩形には木や歩けない地面も入る。地形、原画の遮蔽、住民との接触、出発点からの経路を調べるのは、その後の移動処理である。交流相手に近づく行動や描かれた自然物の観察には別の目的地生成処理がある。[V10の実装と記録](../home-mobility-v10/MOVEMENT.md)

犬の384.85秒の閉塞では、40件の異なる目的地を選び、周囲が動いた時に同じ目的地を37回再試行した。77件中66件が生の目的地の時点で地形外だった。内訳は散歩の32件とその再試行32件、観察先1件とその再試行1件。左端のx=86.90に寄せた11件とその再試行11件もここに含まれる。地形上だった11件はすべて別の住民が占めていた。77の足配置にはいずれも、犬が単独で8 CSS px進める方向が48方位の検査で見つからなかった。[目的地別の内訳と同一状態の比較](evidence/goal-sampler.json)

## 経路探索の前に目的地を選び直すV11比較案

V11は普通の散歩・一人で過ごすために自由な行き先を選んだ時だけ、元の抽選に続いて候補を比較する。人数16体以上で、抽選した地点の地形・遮蔽・他の住民の足を調べる。元の地点がこれらを通れば既存の経路探索に渡す。会話、恋人への接近、本人が選んだ休息、手動ドラッグの処理は従来どおり。[目的地の実装](goals.cjs)

- 既に2回以上の通常要求が成立せず、最初の拒否から自分で歩き出せないまま20ゲーム内秒が過ぎた時は、次に選ぶ自由な散歩先を検査する。詰まる前に検査する条件には、全員の体幅を合計してホームの横幅で割った数値を使った。今回の比較境界は2.55で、320・375・390・430pxの森28体ではそれぞれ2.662・2.410・2.447・2.493だった。同じ幅でも人数や体格で値が変わる。これは比較試作の境界で、歩行領域の面積そのものを表すものではない。
- 元の距離から、4分の3、半分、4分の1などを試し、方向は左右最大67.5度まで調べる。新しい散歩先まで16 CSS px以上あり、元の目標へ0.75 CSS pxより大きく近づき、終点の足が誰とも重ならず、全区間の地形・遮蔽・接触を既存の関数で通ることを条件にする。最大5距離×7方向。足りなければ元の要求をV10の探索に渡す。乱数を追加で消費せず、住民の行動選択回数と最大同時歩行数を引き継ぐ。
- 本人限定の診断は、選択した住民の抽選点、採用点、方角、距離、経路の終点、歩いた距離、実際の到着を区別する。観測はゲームの判断と分離している。過去の犬の77件を再現しても、この選び方で16px以上の安全な別の散歩先が生じた例は0件だった。[個体の診断](goal-observer.js) ／ [実際の足運びを含む回帰試験](goals.test.mjs)

元の地点が歩けなくてもV10が別の終点まで歩けることがある。森の実際の同一配置に比較用の目標を与えた「ぷにゅ」では、V10で39.31px、V11で34.89pxの変位があり、元の目標への接近は19.94→9.32pxだった。リスでも22.71→16.43pxだった。単独で安全と確認できる候補を選んだことは、従来より遠くへ行けたという意味にはならない。[元の座標・採用座標・両方の経路と到着](evidence/goal-sampler.json)

## 地形上で誰にも占有されていない目的地の調査
