## 演出仕様

- 現行は正式な原画、既存粒子、7点のアクセント、元の住民照明と影。A・B・Cは共通の領域・光源を使用し、変化する光の量と振幅を比較する。
- Aは基本5要素・強度0.6倍、Bは11要素・1倍、Cは13要素・1.08倍。これは描画密度の基準で、実際の筆数・粒子数は地域・天気で異なる。Cは37秒周期の約7.4秒間、対象の光が強まる。
- もりの春秋は花びらと葉、夏の夕夜は蛍、晴れの日中は芝と樹冠に局所光。雨雪は季節粒子より優先する。常に雪景色のゆきぐにでは天気で降雪と雪面の輝きを切り替える。
- うみと湖の動きは原画上の多角形内にクリップする。きらめきは朝昼夕夜で光軸と色を変える。うみの雨では一部を短い波紋にする。湖は地上の降水を外す。
- 夕夜のとかい・ゆきぐには原画の暖色灯に光を置く。とかいは雨天に舗装上の反射を少し長くする。
- 正式ホームの4秒フェードを再利用し、切替中は旧・新画像それぞれの時刻に合わせた光を背景と同じ比率で混ぜる。動きを減らす設定では装飾の時間を止めて降下粒子を省く。
- 接地・接水、光・照明、水面、環境粒子は別々に比較できる。地形、経路、衝突、足元座標、住民サイズは正式ホームに任せる。

## 採用候補と保留

第一候補はBの水域限定反射、窓明かり、夏の蛍、湖面の波紋。Cの短い輝きは湖か雪面の一場面から選ぶ。まぶしさや顔の読みやすさは本人の判断を待つ。画面全面の発光、原画を変形させる大波、広域ぼかし、進路を動かす雨宿り追加は見送る。方向影と接地影を強くする案は小さい住民と夜の表情を実機で再確認してから判断する。

## 再現方法

基準コミットのチェックアウトにこのディレクトリを置く。配信許可リスト `tools/pages/allowlist.json` の `files` を外部の一時ディレクトリ `dist/game/` に同じ相対パスでコピーする。プロジェクトルートから以下を実行する。

```sh
node comparisons/home-beauty-v3/build.cjs /absolute/path/to/dist
cp comparisons/home-beauty-v3/{index.html,controls.mjs,style.css} /absolute/path/to/dist/
node --test comparisons/home-beauty-v3/*.test.*
python -m http.server 8193 --bind 127.0.0.1 --directory /absolute/path/to/dist
```

比較用の変更は配信コピーのみに生成する。独立した試作の入口は本編の配信許可リストに含めていない。実際の描画、地形ナビゲーション、住民モデルと入力処理を使用する。一時セーブ、乱数の初期値、環境指定は比較用。個人の育成データは参照しない。
