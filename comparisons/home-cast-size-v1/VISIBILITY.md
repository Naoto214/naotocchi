## 足元、遠近感、装備

- **みずべ**　主人公は石の岸に立ち、恋人は岸から離れた浅瀬に見えます。390幅では主人公の足元（215.91, 419.19）、恋人は（109.60, 251.60）で現行・A・Bとも一致しました。原画上の水と歩行範囲との既存の関係がここにも残ります。みずべのこの描画には海の接水線がなく、水深や濡れ方は倍率で変化しません。
- **もり**　主人公の奥行き係数0.910に対して、奥の木々のそばにいる恋人は0.746。手動案でも、木々に囲まれた位置では見つけづらさが残ります。28体の足元には森の接地補助と影が追従します。
- **とかい**　建物を背景にした奥の恋人と、手前の仲間の遠近差を維持しています。390幅では恋人の高さが現行20→B22px、仲間の中央値は21→23.5pxでした。
- **おうち**　最も短い画面でBの重なり面積23.35%が4地域の最大です。

主人公のリボンと恋人の指輪はそれぞれの足元を基準に拡縮し、4地域×4幅×3案で予測位置との差は最大0.01 CSS pxでした。28個の影の足元座標と住民の歩行座標、向き、モデル本来の体寸法は案を切り替えても一致しました。全48条件で、画面端から1 CSS px以上外れる原画の本体輪郭、または描画が0画素になる住民は見つかりませんでした。装備・表情・自律移動の全時刻についての測定は含みません。

## タッチ、自律移動、会話、道譲り

森の28体で、実際のタッチ入力をChromiumに送りました。現行・A・Bごとに、恋人、柴犬、パンダ、主人公の見えている本体を順番にタップし、12回すべてで対象の住民が選ばれました。主人公のドラッグでは現行・Aで目標マーカーが現れ、移動元の記録は「drag」、0.6秒後にそれぞれ11.45・5.24モデル座標分移動しました。Bの同走では指定点へ移動せず、みずべでの別走でもマーカーだけが出た指定点がありました。地形と密集した他住民の状態によって、ドラッグした全経路が通るわけではありません。[タップ・ドラッグ・会話の計測](evidence/geometry-interactions.json) ／ [みずべでの指定点の再試験](evidence/geometry-drag-repeat.json)

B案のみずべで、歩いているカタツムリを、本人の経路上ですでに歩けると判定されている目標へ指でドラッグしました。マーカーが現れ、モデルから実際に「move / drag」のイベントが出て、観察中に46.55モデル座標分移動しました。[到達可能な地点でのB案のドラッグ](evidence/geometry-walk-drag.json)

森の同じ試行では、放置移動15回、到着13回、住民間の交流イベント1回と、画面の吹き出しの更新を確認しました。例えば、ハムスターの「ほっぺの中で迷子になった」が表示されました。歩行中に他住民との距離を保つため、予定ステップを取り消したケースも2回ありました。試験側がゲームの通常の判定分岐で記録し、ペアを強制生成したり接触半径を調整したりする操作は加えていません。

## WebKitと実機での確認範囲

Linux WPE WebKit 26.5、390 × 844 CSS px・DPR 2でも、みずべ・もりで全28体の同一配置を確認しました。みずべの主人公の実測は現行31、A37、B39、手動37px、恋人は20、22、23、25px。もりの主人公は30、37、38、37px、恋人は19、21、22、23pxでした。初回読込では、28体が先に仮配置され、ホーム原画・縦画面の投影・正式歩行座標が順に準備されます。もりはゲーム自身が原画の準備完了と投影更新を通知した後に測定しました。この試遊の確認範囲には実機iPhone Safariの見た目、発熱、実際の指での選びやすさは含まれません。[WebKitでの同一配置と各住民の高さ](evidence/geometry-webkit.json)

読み込み完了の判定を改めた最終版も、別のブラウザー起動で再測定しました。比較ページが原画・投影・住民の準備完了を表示するまで待つと、もりの全28体で現行→A→B→手動を切り替えても同じ向き・足元が保たれました。恋人は19→21→22→23px、主人公は31→37→38→37pxでした。[最終版のWebKit起動から切替まで](evidence/geometry-ready-webkit.json)

## 測定法

通常の比較ページをモバイル設定（タッチ・DPR 2）で開き、各案のボタンを使いました。各地域で28体のDOMと歩行座標・向き・体寸法が一致することを検査して撮影しています。本体に一時的に白、地に黒を割り当て、実際の投影・拡縮・奥行き・クリップ・地形によるマスクを適用したブラウザー画面から輝度96/255以上を数えました。互いに接しない画像枠を組にして撮影し、原画の透明余白を除いています。1〜2pxの差と同じ背丈の順位は、表情・輪郭のラスタライズにも左右されます。足元と装備の矩形は丸め前のCSS座標で測りました。

本人限定ページの evidence/size-pairs.png に同じ足元の原寸切り出し、evidence/size-scenes.webp に4地域と320幅のおうちの原寸比較があります。[実画面測定](verify_geometry.py) ／ [比較画像の生成](verify_geometry_sheets.py)
