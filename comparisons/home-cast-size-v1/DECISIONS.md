# 落ち葉B案の採用記録

2026年11月19日、本人がホームの秋の落ち葉に **#569のB案** を指定した。対象はもりといなかで、手前ほど大きく、遠くほど小さい葉を使う。描画上の長さの目安は現行E3+の約2倍。葉の面・縁・裏の回転、左右の揺れ、風に伴う横流れと舞い上がり、朱色・橙・えんじを含む色を採用する。標準の枚数はもり20枠、いなかの秋の夕6枠。花びら・雪・雨はE3+を引き継ぐ。[採用した試作の保存コミット](https://github.com/Naoto214/naotocchi/commit/28628cf336a8ed92efe4e9e197ca03298b798a1e)

今回の「現行」「A案」「B案」は**住民サイズ**の違いを指す。環境は全案で同じ採用済みの落ち葉Bを使う。落ち葉の本番統合は別工程。住民サイズは比較試作の段階で、採用は本人が試遊した後に決める。
