**曲がる道譲りは、本人の希望が保留中の住民を候補から外す。V11から引き継いだ直線道譲りでは、希望が保留中でも助け手になる場合がある。** 森320pxのコウモリとネコの記録でこの違いを調べた。直線の協力も止めると、この場面ではネコが得た8pxの歩行が消え、コウモリ自身の歩行は増えなかった。[曲がる計画と実行前の検査](curve.cjs) / [入力と実測値](evidence/straight-helper-review.json)

## 実際の10分再生で起きたこと

V12途中版の森320px・固定席・乱数214では、32.0987ゲーム秒にネコが目標を要求し、32.1988秒にコウモリの別の要求が失敗した。コウモリは32.2987秒から5歩で8.00 CSS pxをネコに譲り、ネコも元の希望の方向へ8.00 CSS px歩いた。コウモリが35.4819秒に次に求めたのは別の地点だった。ここでの「8px」は本人が実際に進んだ距離である。このネコの元の目標はもっと遠くにある。[実行44994011396、要求50・52・53・60](https://github.com/Naoto214/naotocchi/actions/runs/44994011396) / [抜粋](evidence/straight-helper-review.json)

## 同じ入力を最終モデルに渡した結果

記録の28体の足・体格・カメラを復元し、ネコとコウモリの元の目標を0.1001秒の間隔で通常の自律 `move()` へ渡した。他の住民は待機状態から始め、ゲーム内45.0488秒まで観測した。コウモリの直前の退避時刻・退避前の足も実測から復元した。保留希望は通常の移動処理が生成した。対照では、一時的に「有効な保留希望がある住民」を直線の自律協力からも外し、それ以外は最終モデルと同じ条件にした。対照のコードは試遊に含まれない。[元のカメラ](../home-mobility-v10/evidence/native-scene-320.json) / [足・要求座標・復元条件・各モデルのハッシュ](evidence/straight-helper-review.json)

この場面は「未達希望がある住民にも直線の協力を依頼する」既存の挙動を示す。最終V12とV11の結果は一致し、直線の協力を止めてもコウモリは元の希望へ歩けなかった。長期の回復率への影響は、この1場面からは判定できない。
