# ハムスターに残る狭い退路を比べる

本人ページは、時計にハリネズミが道を譲る場面を195～201ゲーム秒の実測記録から再生する。375px幅の森、旧調整配置、乱数937の家庭。2案は同じ28体の全状態・足位置・移動乱数1553397701から開始した。再生時刻を保ったまま案を替え、森全体と3体の拡大、¼倍速、1コマ送り、道譲り直前・時計到着への移動を選べる。[本人限定の比較](https://naotocchi-cast-size.kerzion214.chatgpt.site/v12/narrow.html)

| 観察項目 | 現行の3・8px保護 | 狭い退路の角度も確認 |
| --- | --- | --- |
| ハリネズミが道を譲り始める時刻 | 197.93秒 | 197.97秒 |
| 時計が8.00pxの中継点に到着 | 198.27秒 | 198.30秒 |
| ハムスターの単独3px退路、道譲り前 | 17/384方向 | 17/384方向 |
| 同じ退路、時計の到着時 | 1/384方向（146.25°） | 4/384方向（143.4375～146.25°） |
| ハムスターの通常歩行（前半150秒／後半150秒） | 2／0回 | 2／2回 |
| 時計の通常歩行（同） | 2／3回 | 2／3回 |
| ハリネズミの通常歩行（同） | 1／3回 | 1／2回 |

この1家庭で増えた退路と、助け手自身の通常歩行が減った結果を合わせて表示する。方位数は全周を0.9375°間隔で調べた結果で、全ての角度や地域に対する保証には使わない。過去のV10の178.24秒時点の足位置に、同一の開幕決定状態を与えた300秒の制御比較である。表示する6秒間は実測値の読み取り専用再生で、フレーム間の足位置を補間しない。[全フレームの数値](evidence/narrow-recording.json)

Chromium 156のDPR2で、録画の1/30秒ごとの全181コマ・28体・2案を正式ホームの表示と照合した。全10,136件の足の両座標、左右の向き、活動、移動元、歩行中かどうかが原本と一致し、描画した住民DOMの向きと活動も確認できた。320・375・390・430pxで、拡大と全景、タッチでの一時停止・再開、同時刻での切り替え、コマ送りを確認した。iPhone Safari実機は未検証。[画面・操作の検査結果](evidence/narrow-browser.json)
