同じ28体の森・320px・乱数214・V9調整席では、接触楕円が歩行地形38,962 CSS px²の77.01%を覆う。住民を除けば、タヌキと箱はそれぞれ96方位すべてに8px歩ける。周囲の27体を置いた開幕に単独で進める方向は両者とも0。タヌキはリス・カワウソ・ハリネズミ・箱と、箱はネコ・タヌキ・「みているなにか」・リスと接触していた。森の地形は主領域と小さな副領域に分かれる。320pxの副領域は約137 CSS px²で、そこへ飛び越えて道を空けることはできない。[4幅での占有率・地形連結・通路幅・住民別停滞](../home-mobility-v11/SPACE.md)
