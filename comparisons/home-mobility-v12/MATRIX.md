# V12の全13地域・住民の歩行と実タッチ

13地域それぞれで、住民1・4・10・20・28体、画面幅320・375・390・430 CSS pxの組み合わせを開く。比較元はPR #581のV11足元修正のみ。両版で昼の標準ホーム、サイズB、通常の初期配置、乱数214を使う。

## 同じ条件を保つ方法

- **開幕**　住民の足・体格・次の活動予定、モデル時計、乱数、選択・手動指示を照合する。独立起動で差があった場合は、そのままの測定も保管し、モデル時間0の一時停止中にV11側と同じ状態を復元する。過去の測定と同じ画面上の始点・終点でChromiumにタッチを送り、ゲームが受け取った信頼済みイベントを検査する。
- **5分の生活**　各ホームで実際のモデルを300モデル秒進める。散歩、接触、道譲り、会話、休息はゲーム自身が決める。通常歩行は家庭内の退避を除き、自分の目的地へ0.75 CSS pxを超えて近づき、8 CSS px以上の変位を伴う到着。各住民の要求・実際の足の変位・道譲り・失敗中の時間を同じ個体で照合する。5分後にはあらかじめ決めた住民をドラッグする。実時間10分の公平性・描画性能は別試験で扱う。
- **同じ足・同じ入力**　5分後のV11の住民全員の状態・乱数・経路・足を両版へ渡し、同じ住民・指・終点を再現してから再操作する。選択・指示・受理・実歩・到着・指先4px以内のいずれかが自然経過後に異なれば、V12の配置からも両版で再操作する。復元できない計算途中の道譲りと一時キャッシュは両版とも空で始める。
- **曲がる道譲り**　探索を始めた時、計画の成否、協力者が歩き出す時、本人の経路再確認を分けて記録する。計画上の経由点と実際の足を分離するため、参加者の歩行区間と到着をネイティブの歩行処理で観測する。実際に道を譲った人、助けられた人、そのほかの人について通常歩行の成立・消失も追跡する。
- **足元・保存**　各歩行区間で地形・遮蔽・速度・住民間接触を検査し、同期中に足が変わった場合は歩行と別に記録する。13地域で390px・28体の実保存を読み直し、住民、装備、育成、復帰後のタッチを確認する。
