# V12の全13地域・住民の歩行と実タッチ

13地域それぞれで、住民1・4・10・20・28体、画面幅320・375・390・430 CSS pxの組み合わせを開く。比較元はPR #581のV11足元修正のみ。両版で昼の標準ホーム、サイズB、通常の初期配置、乱数214を使う。

## 同じ条件を保つ方法

- **開幕**　住民の足・体格・次の活動予定、モデル時計、乱数、選択・手動指示を照合する。独立起動で差があった場合は、そのままの測定も保管し、モデル時間0の一時停止中にV11側と同じ状態を復元する。過去の測定と同じ画面上の始点・終点でChromiumにタッチを送り、ゲームが受け取った信頼済みイベントを検査する。
- **5分の生活**　各ホームで実際のモデルを300モデル秒進める。散歩、接触、道譲り、会話、休息はゲーム自身が決める。通常歩行は家庭内の退避を除き、自分の目的地へ0.75 CSS pxを超えて近づき、8 CSS px以上の変位を伴う到着。各住民の要求・実際の足の変位・道譲り・失敗中の時間を同じ個体で照合する。5分後にはあらかじめ決めた住民をドラッグする。実時間10分の公平性・描画性能は別試験で扱う。
- **同じ足・同じ入力**　5分後のV11の住民全員の状態・乱数・経路・足を両版へ渡し、同じ住民・指・終点を再現してから再操作する。選択・指示・受理・実歩・到着・指先4px以内のいずれかが自然経過後に異なれば、V12の配置からも両版で再操作する。復元できない計算途中の道譲りと一時キャッシュは両版とも空で始める。
- **曲がる道譲り**　探索を始めた時、計画の成否、協力者が歩き出す時、本人の経路再確認を分けて記録する。計画上の経由点と実際の足を分離するため、参加者の歩行区間と到着をネイティブの歩行処理で観測する。実際に道を譲った人、助けられた人、そのほかの人について通常歩行の成立・消失も追跡する。
- **足元・保存**　各歩行区間で地形・遮蔽・速度・住民間接触を検査し、同期中に足が変わった場合は歩行と別に記録する。13地域で390px・28体の実保存を読み直し、住民、装備、育成、復帰後のタッチを確認する。

## 自然に発動したみずべの道譲り

375px・28体のみずべで、第1候補に自然な二段の道譲りが生じた。74.65秒にたぬきが折れ曲がった経路を歩き、75.10秒に鶏が続いた。協力者は合計10歩・19.00 CSS pxで両方の退避先に到着し、石像は75.50秒に8.00 CSS pxの通常歩行を完了した。元の目的地には4.64 CSS px近づいた。同じ世帯の再測定V11と第1候補の双方で、28体全員がこの道譲り以降の5分試験終了までに自分の通常歩行を1回以上完了した。石像は4→6回、たぬきは6→5回、鶏は3→7回だった。石像の、その後の連続経路不成立の最長時間は2.40→46.85秒。[石像とほか27体の5分記録](evidence/matrix-first-river.json)

同じ出来事が各モデルでどう変わるかを、実際の71.00秒の途中状態に戻して調べた。計算中の仕事がなく、28体の歩行先、待機、直前の譲り、選択、次の行動時刻、乱数をすべて引き継いだ。第1候補は計画、2体の歩き始め、本人受理など元の時刻・経路を再現した。低優先度で探索する8px版と3+8px版では、75.90秒にこの曲線探索が不成立だった。両版はその後の120.00秒時点でも乱数・住民28体の歩行履歴が同じだった。全版で、71～120秒に新たに始めて完了した通常歩行があったのは、第1候補20体、後の2版18体。石像が74秒に考えていた実候補23個を直接調べると、8px版と3+8px版とも同じ二段経路を見つけた。通常再生の差は、3pxの退路保護条件だけでは説明できない。[実際の途中状態](evidence/matrix-river-state.json) ／ [各住民の再生記録](evidence/matrix-river-replay.json)

全28体について96方向を調べ、3・8・16 CSS px先まで地形・接触・足の進行条件を通る方向を数えた。たぬきの経由点、たぬき・鶏の終点、石像の終点だけを元配置に順に適用すると、どの距離でも、ほかの住民が最後の退路を失った局面は0件だった。全員が実際に動いた原記録では、74.00秒の探索開始から最初の人が道を譲り始めるまでに、アザラシの8・16pxの最後の退路が消えた。74.70～75.70秒にはカメレオンの8px、たぬきの16pxが消え、3pxの最後の退路を失った住民は0体だった。カメレオンの8pxはこの道譲りが発動しない後の2版でも同じ期間に消えた。96方向での結果には各方向の間に残る細い通路を含まない。[元の各時刻と参加者だけを動かした各段階](evidence/matrix-river-exits.json)
