# みずべ・おうち・いなか　E3の比較メモ

3地域の朝昼夕夜12枚を同じ縮尺で確認し、すべての位置を原画全体の1000×1500座標に記録した。原画を一度読み込むと、川面と草木の切り出しは画像ごとに再利用する。

|地域|E3の注目点|制限と狙い|
|---|---|---|
|みずべ|翡翠色の川面の6か所で原画の反射を少し屈折させ、奥の流れに短い泡、手前に細い流線を重ねる。春は速め、冬は遅め。雨は水面に輪を作り、夕と夜ではそれぞれの反射軸を光らせる。|砂利の岸は右下がりに広がり、対岸には岩がある。これらを避けた内側の多角形に反射・泡・波紋をすべてクリップする。雨天の手がかりは水面の輪と反射の弱まり。|
|おうち|中央の窓を伝う雨粒と窓外の雪。春秋の晴曇には窓の左側の木の前を花びら・葉が通る。晴れは木床に窓からの明かり、夜は右の灯具に合わせた暖色を置く。|雨雪の発生域は中央の窓枠の内側。屋内の晴天時の埃は窓の手前に少数だけ置く。床光はソファ、棚、テーブル、敷居を外した領域で弱く動く。|
|いなか|水田の両側と道端の草木11か所を原画から切り出し、畦に沿って風が届く時刻を変える。夏の夕夜は水田や道の端に蛍、春秋は花びら・葉。雨雪は季節粒子より優先する。|道路の中央と家屋は変形しない。蛍は大小・速度・明滅をずらし、画面全体への発光は行わない。|

風には約4分の周期で左右から強さの違う5回の変化があり、小さな揺れは別周期で続く。水のうねりと昼の床光もこの緩い変化を使う。旧版には正式ホームの既存装飾が表示される。

## 確認した範囲

- `node --test river-home-country.test.mjs` が川岸・岩場・窓・家具の代表点、風の時間差、強度0・対象外の早期終了を検査する。
- `verify-river-home-country.mjs` は比較ページと同一オリジンで、採用WebPを実際にデコードする。320×480の原画上で各時刻の11秒と17秒の差、強度100%と200%の差、動きを減らす設定で8秒と188秒が同じであることを調べる。RGBいずれかの差4以上を集計する。
- Linux ChromiumとLinux WebKitそれぞれ12条件で動作と強度差を検出し、動きを減らした場合は全条件で差0。水域と窓雨は透明Canvasでも4時点を調べ、アルファ6以上の筆跡で多角形を外れた画素は0。境界のアンチエイリアスは画素の四隅と中央で判定する。実機Safariの性能測定は別項目。
- 実画面例は `evidence/river-home-country.jpg`。390×844、犬1体、強度100%、演出時刻15.9秒、一部UIを除いて縮小した。動作検査値は同じフォルダーの `river-home-country-chromium.json` と `river-home-country-webkit.json` に記録した。
