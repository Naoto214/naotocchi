# 13地域の3分間観察

各地域の見どころ条件、住民1体、強度100%、375×730 CSS pxで正式ホームを起動。演出時計を0に戻したあと、30・60・180秒を通過するまで実時間で再生した。途中で出たお誘いは通常UIの「またこんど」で閉じた。効果時計を進める操作はしていない。複数のページで並行観察したため、この試行は性能評価から除いた。

各チェックポイント直前の約0.5秒で背景Canvasを208px幅に縮小して比較した。いずれかのRGBチャンネルが4階調以上変化した画素の割合。影・住民・操作UIはこの背景指標に含まない。空や窓だけを動かす地域の数値は小さくなる。比率は美しさの指標ではない。
