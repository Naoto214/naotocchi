## 数値の読み方

- **内部更新Hz**は本編コントローラーが更新を採用した回数を4秒の実測時間で割った値。テスト時だけ `frameGaps.push` の直前でカウンターを1増やした。本編が通常表示する直近最大300更新の移動平均は生データの `internalHz`、同じ窓で直接数えた値は `stepHz`。
- **背景転送 /秒**は背景用Canvasに同サイズのキャッシュ済みCanvasを転送した回数。CSSアニメーションやDOM住民、GPUへの表示完了はカウントに含まない。4体以上や低負荷設定では背景の更新間隔を広げるため、1体より多い方でrAFが高い条件もある。
- **rAF Hz**はブラウザーのコールバック到着間隔の平均から計算した。モニターに提示された物理フレーム数は未計測。多くは短い窓の1回測定。CPU affinityは試験プロセスの割当で、共有ホストの他ジョブを排除するものではない。各負荷測定ではほかの地域を同時に表示していない。住民の行動とホスト全体の負荷の影響が残る。ChromiumとWPEの絶対値をiPhoneへ換算できない。

Chromium主行列の初回計測後、山・ジャングル・砂漠・深海・星空のE3の1体と、湖のE3の1・4・28体を、更新された描画器で取り直して該当の行へ反映した。湖だけに適用した最終の光の描画変更はWPEの1体・28体でも確認。取得バッチの描画器ハッシュを負荷のJSONに記録した。

## 再現方法

ビルドの起動後、Playwright、Chromium（/usr/bin/chromium）またはPlaywright WebKitを用意して以下を実行する。地域の条件は検証コードの `SCENES` と各JSONの `environment` に記録した。

```sh
python verify_v5.py matrix --out /tmp/qa-load-chromium.json
python verify_v5.py matrix --engine webkit --regions jungle,sea,city --out /tmp/qa-load-webkit.json
python verify_v5.py interactions --engine webkit --out /tmp/qa-input-webkit.json
python verify_v5.py widths --engine chromium --out /tmp/qa-widths-chromium.json
```
