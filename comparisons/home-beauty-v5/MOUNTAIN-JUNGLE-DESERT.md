# やま・ジャングル・さばくの動作比較

原画12枚（3地域×朝昼夕夜）を確認し、配置は元絵の幅1000・高さ1500に換算した座標で指定した。移動する住民と前景は本編が描く。

| 地域 | 見比べる条件 | E3で見る場所 |
|---|---|---|
| やま | 朝・曇り → 夕・晴れ → 夜 | 上部の雲の一部がゆっくり動き、右の谷間を細い霧が通る。山頂の3つの斜面には原画に沿って光の濃淡が移る。霧は右の稜線と手前の道を避けた多角形内で描画。夜は雲の原画を動かさず、谷と山肌の光を残す。雨と雪は奥行きによって速度と大きさが異なる。 |
| ジャングル | 夏・昼・雨 → 夏・夜・晴れ | 上部のシダ、奥のヤシ、手前の草花など10か所が風の到達順に揺れる。雨は奥の明るい空間を先に通り、近くの葉先では別周期で水滴が落ちる。夕方は右上から浅い角度の暖色光。池の上に薄い湿気、夏の晴れた夜には水際に少数の蛍。 |
| さばく | 夏・昼・晴れ → 夕 → 夜 | 海が見える地平線より下の砂丘3本で、風下へ砂が跳ねる。昼の陽炎は遠い砂丘の4か所のゆがみ。冬・曇り・雨には陽炎を止める。夕は暖色の砂煙、晴れた夜は既存の星13個を足場に明滅する。雨は遠景の短い雨脚、雪指定は冷色の霞に切り替える。 |

## 描画と操作

- 風はゆっくり強まる成分と2種類の小さな揺れを組み合わせ、枝の奥行きと位置で位相をずらす。砂は尾根に沿い、粒ごとに飛距離・高さ・位相が異なる。
- 雲・葉・陽炎には原画の局所切り出しを使い、切り出しと光のブラシは再利用する。初期化時の小さな切り出しを除き、新しい画像の生成や全画面の変形は行わない。
- 「自然物の動き」「水面・反射」「季節の粒子」「環境光・照明」「幻想の光」が該当する層を制御する。動きを減らす設定では時間を固定し、葉の変形・砂粒・雨雪などを止める。強度0またはフェードの不透明度0では描画処理に入らない。
- ジャングルの実画面では犬の足が池に重なる位置と、手前の地面に乗る位置の両方を確認した。水面の動き、葉や照明の作用域は環境表現で、既存の住民座標・歩行領域・キャラクター素材を変更していない。

## 検証資料

- 実画面は `evidence/mountain-jungle-desert-live.jpg`。ローカル配信用ゲームで390×844、犬1体、演出時刻8秒を撮影した。左から、やま・朝曇り、ジャングル・昼雨、さばく・夕晴れ。
- `node --test mountain-jungle-desert.test.mjs` は強度ゼロ、雨・雪、水滴、風の時間差、砂粒の描画範囲を検査する。
- `verify_terrain_pixels.js` は実際の採用WebPを336×504で描画し、各時間帯で4秒と12秒の画素差、強度100%と200%の差、動きを減らした場合の時間差ゼロ、強度ゼロと原画の一致を調べる。RGBのいずれかが2以上変わった画素を集計する。この検査の対象は描画出力で、実機iPhoneの性能は別項目。
- Linux ChromiumとWPE WebKitの各12条件で時刻差と強度差を検出した。4秒→12秒の差はchromium 909〜18943画素、webkit 923〜18945画素。強度ゼロと原画の差、動きを減らした場合の時刻差は24条件すべて0。実測値は `evidence/terrain-pixels.json`。
