## 森で何が変わったか

V8では道を譲った一歩が本人の歩行待ちを解消したように扱われる場合があった。V9では、本人が長く歩けていない順に、元の目標に対する近隣の安全な経路を再検討する。補助者は最大2体で順に歩く。新しい移動指示、会話相手になったときの4秒の待機、入力中の住民を保護した。補助者が動けるようになった際の再判定は、実際に調べる24 CSS pxの範囲と一致させた。[元の失敗を再生したテスト](MOVEMENT.md)

「歩けた」は、本人の通常歩行が終わり、足の始点と終点が8 CSS px以上離れ、元の目的地までの距離が0.75 CSS pxより多く縮んだことを表す。道譲りや微小退避も全歩行距離には残す。本人に指示が成立しなかった期間を計り、会話や選択肢でホームの時計そのものが止まった実時間は別に計上した。各試行とも全28体の表示を維持した。[全住民の観察記録](FAIRNESS.md)

## 配置比較で注意したいこと

小さな調整案は本人限定の新しい世帯を開くときに選べる。元の配置で使えた3・8・16 CSS pxの退避距離が失われる提案は取り消す。検証した390×792の基準配置では、コウモリの足元を12px、柴犬を4px動かした。個体の体格、元の原画、接触判定、地形判定、主人公の初期位置と通路を維持した。[初期配置と別の名簿順での検査](SEATS.md)

10分比較の2つの乱数で、小さな配置調整案はともに28/28体が通常歩行を完了した。乱数214でタヌキ11回・パンダ3回・箱4回、937で5回・2回・1回だった。937のパンダの2回はどちらも8 CSS px、箱の1回は18px。主人公の犬には、27.47・26.20・10.96pxの通常歩行を終えたあと、次の歩行が成立しない期間が384.85モデル秒続いた。全員が一度歩けたあとにも、長い行き詰まりは起きる。

別に12体の足元を動かす配置も試した。実際のブラウザーでは2乱数とも26/28体で、短いドラッグの終点到着は従来配置の17/28から12/28に下がった。元から使えた退避方向を失う住民もいたため、本人限定ページには小さな配置調整案を残した。

## 描画と操作

Linux WebKitの森28体をV7→V8→V9、逆順の両方で各180秒再生した。V8からV9へのp95は通常順97→64ms、逆順99→95ms。p99は114→107ms、119→115ms。6試行全体で250msを超えたフレームは0回だった。両順序を合わせた移動距離は約22%増えた。28体の軌跡とCSSアニメーション位相を固定した試験のp95は59→63ms、60→59msで、描画単独の改善は再現しなかった。[中央値・最大値・入力遅延・描画内訳](PERF.md)

初期配置で28体を各1回、同じ12 CSS pxドラッグすると経路終点到着は両版17件、指先4px以内は8件。V8で604.21モデル秒経過した共通の世帯では両版21件、7件だった。実機のiPhone Safariにおける発熱、長時間のフレーム時間、指による狙いやすさは未検証。[個体別の指操作](TOUCH.md)

## 全13地域の歩行と指操作

従来配置の260条件で各世帯を300モデル秒観察した。通常歩行を完了した住民はV7が3,082、V8が3,088、V9が3,217／延べ3,276人分だった。V9では59人分が未完了で、経路不成立から次の自律ステップまでの待ちは最長297.85秒だった。[地域別の比較と住民別記録](MATRIX.md)

同じ座標で試した初期ドラッグ1,058回のうち、V9は経路終点に911回、指先4 CSS px以内に522回到着した。同時に測ったV8は910回・521回、V8の公表値は909回・520回。V9の本人タップ選択は246/260、自律・ドラッグ双方の失敗は2/260だった。自律生活後のドラッグ到着はV8の240/260からV9の236/260に下がった。V9の自律歩行1,114,483ステップで、他の住民との連続接触、地形・境界・遮蔽・速度の違反は各0件だった。[実測値と安全検査](evidence/matrix-result.json) · [本人限定の全地域・全住民データ](https://naotocchi-mobility-v8-evidence.kerzion214.chatgpt.site/evidence/mobility-v9/matrix/44903860732/matrix-residents.csv.gz)

## 採用判断

V9の移動と新規世帯の初期配置案は、本人限定で比較を続ける段階とした。森の10分再生後に全住民へ個別に指示した168回は、すべて狙った本人に届いた。経路終点への到着は乱数214／937の順に、V8が20／19人、V9従来配置が22／17人、V9初期配置案が23／21人だった（各28人）。それぞれ10分間暮らした足元で測っている。長く経路を得られなかった主人公の位置と、320・375pxの森で閉じる通路を次の再現対象とする。実機iPhone Safariで初期配置案の操作感とフレーム時間を測り、同じ軌跡を描いたときの改善を確認してから標準採用を再検討する。
