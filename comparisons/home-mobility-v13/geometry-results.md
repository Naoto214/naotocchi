# 森の原画と初期席

## 実際の足と原画の位置

森の昼・28体・320×792で旧来の歩行領域と表示原画を重ねると、タヌキは原画の左から46.80%、上から40.88%、箱は50.45%、35.85%に立つ。昼の絵ではどちらも奥の樹林に重なる。パンダは38.27%、65.38%で手前の草地にいる。旧版は舞台に合わせた地形と、画面全体にカバー表示する絵の地面を合成している。旧地形の足をそのまま原画座標として描くと、この食い違いを見落とす。タヌキや箱のすぐ横をさらに地面として認める根拠は見つからなかった。[元のカメラと28体の実寸](../home-mobility-v10/evidence/native-scene-320.json)

Bは既存の道の右側に小さな路肩を、Cはその路肩の先に退避できるふくらみを加える。朝・昼・夕・夜の原画では短い草の広場、読込時の滝の原画では土と苔の路面に当たる。両方とも木の根、斜面の茂み、水際の手前で終わる。新しい足場の最近縁は、1024×1536の原画上で除外区域から198.48px以上、前景の輪郭から117.76px以上離れている。斜度や高さを測るデータは2D原画には含まれない。[5枚の元画と比較線](evidence/geometry-art-review.jpg) · [ファイルハッシュと余白](evidence/geometry-art.json)

縦向きの実ゲームで最終表示される原画の横幅・高さ・クロップと、住民の足の拡大率を使って位置を照合した。B/Cの新規部分は従来の最小奥行き、前景、禁止区域を守る。新規線分は旧地形・原画地形・追加部分の多角形との交点で分割し、各区間の中点と端を検査する。歩く本人の足の境界、九点の表示判定、全区間の接触判定は従来通り。A・B・Cは全員同じ開幕座標から始める。

320のタヌキと箱は、3・8・16pxの各96方位がいずれも地形・前景を通過する。そこに他の27体を戻すと、3距離とも通れる方位は0である。パンダの地形・前景通過は53・27・21方位。接触を加えると11・5・0方位。B・Cの追加場所はこの3体の初期結果を変えなかった。

## 1席だけを動かすD

V9のコウモリ12pxと柴犬4pxは固定390で3体に8px経路を開いた。その後の細かい方位照合で以前通れた方位を失った住民がいた。V10は375の微調整を本採用せず、V11は他人と席を動かす本人の退路を保護した。V12の320では2席を微小移動する固定・参考席の延べ151,732,224組に保護条件を満たす改善はなかった。V13の探索対象は新しく追加した草地の2 CSS px格子と、その縁から28 CSS px以内の住民の小さな1席変更。後者は1・2・3・4・6・8・12 CSS px、32方位。追加地形上の席は元の席から180 CSS px以内で探した。[V9](../home-mobility-v9/SEATS.md) · [V10](../home-mobility-v10/SEATS.md) · [V11](../home-mobility-v11/SPACE.md) · [V12](../home-mobility-v12/SPACE.md)

探索した1席候補32,416件中、旧3・8・16pxの全方位を残し、8px歩ける住民を増やしたのは375の時計の18点。最も近い点は開幕位置から25.77 CSS pxで、記録済みの375の足並びではハムスターに8pxが開いた。3・8・16pxを歩ける人数はCの25・17・10体から26・18・10体に増え、接触組数は20から18に減った。320の10,314件、390の7,802件、430の5,663件に採用可能な点はなかった。

Dは森28体の375pxで時計の1席だけを表示前に提案する。草地の縁・前景、現行の接触楕円、既存接触の深さ、主人公の予約通路、距離30 CSS px以内を検査する。続いて新旧の時計が影響し得る住民について96方位で全長を検査し、以前通れた方位を1つでも失う場合や、新たに8px歩ける住民がいない場合は元の位置を使う。対象外の画面・世帯はCの地形をそのまま使う。初期検査は本人専用のメモリ内世帯でのみ発生する。既に表示した住民の再同期中に席を与え直す処理はない。

375×792の実ブラウザでは時計を25.77 CSS px移し、固定席でハムスターとリス、V9参考席でハムスターに8px方向が開いた。375×760では当日の足・画面・予約通路を用いた条件を通過せず、時計は元の席に残った。個々の距離・方位、初回の計算時間、同じモデルの再同期時の足・セーブ・ストレージ隔離を比較用ゲームで検査した。[ブラウザでの採否・足・負荷](evidence/geometry-browser.json) · [別の実行で独立に取り直した全方位](evidence/geometry-direction-audit.json)

別の固定席ブラウザで全28体の3距離・96方位を独立に取り直すと、375×792でCは24・14・9体、Dは26・16・9体、接触は22組から20組になった。全旧方位の損失は0。先の記録済みカメラではコウモリ、ユニコーン、リス、アザラシの初期座標が一部異なる。新しい席の実時間費用は、負荷のあるLinux Chromium環境で固定席216.0ms、独立再試行509.4ms、参考席268.9msだった。初期席検査自体に500ms超の観測があり、継続フレームとは別の採用課題となる。320・375・390・430pxを含む7回の再同期はいずれも追加席検査0回、最大足変位0px、世帯の保存文字列が一致し、ブラウザの元の保存領域に入れた確認値は隔離されたままだった。

## 320で新しい退避場所を使う2席の補足

Cの草地を実際に使う2席だけを、オフラインで追加調査した。少なくとも一方の席は新しい草地上の格子点で、元の足から180 CSS px以内。もう一方は同じ草地か、現在の足から1・2・4・8・12・16 CSS pxの32方位。いずれかの席がタヌキ、箱、またはその8px方向を塞ぐ仲間である場合を調べた。本人と周囲が元から持つ3・8・16pxの全96方位を保護し、相互・第三者接触の悪化を排除した。

| 4 CSS px | 5,276,770 | 779,554 | 23 | 21 | 0 |
| 2 CSS px | 30,546,510 | 12,523,086 | 618 | 600 | 2 |
