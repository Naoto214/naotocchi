# V2の保存とV3の保護検証

## 比較の基準

基準はDraft PR #570の `7e0a8cd6a506142fbe65b9ca6fd4ff4f855d4e9a`。#569の固定コミットからビルドを再現し、V1、V2の順に生成した3,900ファイルを基準にした。V2の入力として使う際は、全ファイルの相対パスと個々のSHA-256から求める集合ハッシュ `41e3c1643927fda017d6dd16688129221bb80714a3bd89b86237a176e195b79c` も検査する。[V2の保存コミット](https://github.com/Naoto214/naotocchi/commit/7e0a8cd6a506142fbe65b9ca6fd4ff4f855d4e9a)

最終の配置表（SHA-256 `afecec73e5e0bdb377c42bcccdec0c2ff74efbc2f34c6d7f154dba6776e1954a`）と、初期配置を保ったまま倍率を比べる操作を含む比較ページを固定してNode.js 22.23.5で再生成し、試遊に使う3,909ファイルが再生成物とバイト単位で一致した。集合ハッシュは `c98b1de105f27b97fe5c2fd0e9f83b5ce1621d248e0c315c45c59c299c9ecc2c`。V2の3,900ファイルも全件一致した。従来のルートと `/v1/` は同じURLで引き続き開ける。追加は比較ページ `/v3/` の4ファイルと、ゲームディレクトリ内の5ファイル。52背景、キャラクター原画、装備、32曲のBGM、落ち葉Bを含む環境描画、CARD GAME、育成と保存の処理はすべて基準に含まれる。[パッケージの照合](evidence/guard-package.json) ／ [V2で照合した原画・音源・移動モデルの内訳](../home-cast-size-v2/evidence/guard-package.json)

## ゲームの描画範囲と操作

最終版のゲームHTMLに対する変更は、比較用スクリプトを読み込むタグだけ。住民コントローラーの差は読み込む地形モジュール名だけで、元の全処理と照合した。キャラクターの奥行き、画面の投影、ドラッグの座標変換、タップ選択、接触回避、会話、セーブのロジックが同じであることを確認できる。表示が大きくなると、同じ基準で拡大されたタップ範囲が隣の住民と重なる場面はあり得る。画面の拡大操作に関するviewport設定は、外側の比較ページと内側のゲームの双方でV2と一致する。V3の操作用コードにはピンチ操作の追加がなく、ゲーム本来のタッチ処理を使う。実機でのピンチ操作は未検証。[ゲーム入口とコントローラーの照合](evidence/guard-package.json)

初期配置だけを変更できるよう、V2の地形オブジェクトに候補座標を渡す。固定配置と追加0%ではV2のオブジェクト自体を返す。最適化では歩行可能地、投影や逆投影、到達判定、経路探索、遠近倍率について各関数の同一性を検査する。旧84%表示のボタンと切替処理はV2で廃止済みで、V3でも要素は存在しない。モデルは元の当たり判定を使う。13地域×4画面幅×5段階×2配置で、固定または追加0%の初期座標19,656件がV2と一致した。追加ありの最適化13,104件も再現可能で、V2から変更された初期候補は元の歩行可能判定にすべて合格した。この検査は候補座標の比較で、接触処理後の実画面を測る検査とは別に行った。[地形・初期配置の照合](evidence/guard-navigation.json)

Linux Chromiumで390×844・DPR 2、森・昼・28体を固定し、V2とV3の0・5・10・15・20%を実表示で照合した。主人公と恋人は120→126→132→138→144%、仲間は105→110.25→115.5→120.75→126%。カメラと奥行きで補正した実CSS倍率の最大絶対誤差は0.0000012だった。最後に0%へ戻しても、28体のモデル寸法・足元・奥行き、ゲームの実幅390px、ステージ矩形、カメラ、背景Canvasの画素がV2基準とすべて一致した。空のブラウザープロファイルで親側に置いた4つの保存領域とタブ識別値に、試遊側の書き込みは届かなかった。[固定画面とセーブの実ブラウザー照合](evidence/guard-browser.json)

320px幅のとかい・28体・追加10%では、同じ初期候補でも84点のタップ試験が59点と64点になった。再起動条件を変えた追試では、倍率の適用順が原因だとは確認できなかった。同じ立ち位置で倍率を判断する際は、試遊ページの再生を「固定」にし、「この候補配置のまま倍率を比べる」を選ぶと、同じ立ち位置と背景のまま比較できる。[タップ試験の2回の記録](evidence/input-same-seats-repeat.json) ／ [起動順序と再現試験](evidence/input-startup-order.json) ／ [配置を保つ操作の検証](evidence/shell-held.json)
