# 足元が使える範囲と、画面上の余白

森・28体では、320px幅の画面で最も奥と最も手前の足元は約53 CSS pxしか離れていなかった。390px幅では約323 CSS px離れている。短い画面ほど、背景に広い草地が見えていても、同じ縦位置に顔や体が重なりやすい。[測定値](evidence/footprint.json)

## 背景に草地が余って見える理由

原画は試遊画面の背景まで広がる。住民の足元はゲーム内の地表に置かれ、画面上では会話欄や操作部に挟まれた表示枠に収まるようカメラが縦横を別々に射影する。森の320幅では縦の1モデル単位が約0.21 CSS pxに縮む。このため足元だけを下へ移すと、画像では草地でも住民表示枠の外に出ることがある。[背景の描画](../home-cast-size-v2/PROTECTION.md) ／ [カメラの縦横倍率](https://github.com/Naoto214/naotocchi/blob/7e0a8cd6a506142fbe65b9ca6fd4ff4f855d4e9a/home-production-touch.js#L260)

画面の中に収まることも、そこに立てる十分条件ではない。V5は住民の寸法と地形に応じて足元を制限し、手前の物に隠れる候補や近くの住民との接触を避ける。倍率を上げた今回の固定比較ではモデル座標を維持するため、顔が大きくなっても使える地面は増えない。[モデルの境界と接触判定](https://github.com/Naoto214/naotocchi/blob/7e0a8cd6a506142fbe65b9ca6fd4ff4f855d4e9a/home-production-model.js#L6) ／ [固定した28体の全座標比較](evidence/shell-chromium.json)

## 移動V5を保つ改善候補

- **初期配置で使える奥行きを活かす。** 足元を地形上に置けると確認した候補の中から、主人公・恋人の顔が手前の仲間に隠れにくい場所を先に選ぶ。仲間は左右と奥行きの両方に分け、原画の樹木・室内の家具・水面に合う場所を使う。「サイズ別の配置」で候補を選び、「この候補配置のまま倍率を比べる」をオンにして「現行」に戻すと、同じ大きさで配置の効果を確認できる。
- **余白も絵の一部として残す。** 主人公の表情を見分けやすくするには、表示枠が短い場面で追加倍率を一段下げる方法もある。近景にある草花や岸を残したまま、タップしやすさ、ペアの顔、他の住民の輪郭を比較できる。
- **カメラを変える案は別の比較にする。** 同じモデル上の足元を少し広い範囲に描く方法には、原画と足元、影、装備、タップ座標の射影を一緒に検証する必要がある。短い表示枠では上下の顔・装備や会話欄との干渉も再測定する。今回の試遊と計測はV2のカメラを使用した。

## 再現方法

13地域×4幅×5人数の固定配置から、全260ケースの足元を検証した。縦長画面でサイズ別配置と対応させた一部の対照は、候補と同じ追加倍率のURLから起動した。すべての対照で描画倍率を現行に設定してから最初の足元と画像枠を取得した。JSONの `positiveGainFixedEntryLinks` に該当する入口の条件を記録している。初期・モデル8秒後と、記録のある条件では30秒後の足元範囲もJSONに収録した。位置の最小値と最大値が変わらなくても、内側の住民は動いている場合がある。自律移動の距離や到達回数は移動テストで確認できる。[全ケースの足元・面積](evidence/footprint.json) ／ [自律移動の記録](evidence/geometry-motion.json)

```sh
python comparisons/home-cast-size-v3/verify_footprint.py \
  --fixed /tmp/cv3-paired/fixed --game /tmp/cast-v3/game \
  --out /tmp/footprint.json --table
```
