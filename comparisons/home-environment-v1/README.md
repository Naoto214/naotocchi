本番のホーム描画と、環境演出だけを差し替えた2つの案を見比べるための比較です。

- **A**：現在の本番
- **B**：雨・雪・花びら・落ち葉の改善版
- **C**：Bに、草木の揺れ・水面・光・灯りなどを重ねた総合演出版
- **D**：Cの動きを限界まで強めた最大演出版（上限を確かめるための版。ここから引き算する前提）
- **E**：Cの強さを基本に、不自然な変形と規則的な動きを直し、Dの良い部分を控えめに取り入れた**最終候補**

配置・移動・歩行領域・恋人位置・キャラサイズ・接触判定・タップ／ドラッグ・UI・ステータスバー・背景原画・BGM・セーブ形式には触れていません。**本番ファイルは1バイトも変更していません。**

### B2・B3：Bの動きのまま継ぎ目をなくす

- 揺れ幅はBの式と同じ（手前の葉先で最大約4.7、突風時はその約1.45倍）、速さもBと同じです。
- Bはタイルごとに無関係な位相で動かしていました。B2・B3は、同じ速さの波が木の中を風下へ流れる形にして、隣り合う場所がほぼ一緒に動くようにしています。これが四角い継ぎ目と隙間をなくす条件です。
- そのため「1枚1枚がバラバラに震える」感じはBより少し減り、「細かな波が葉を渡る」感じになります。

### B4：枝をしならせず、形を保って回す

- **小枝の分離**：葉に加えて、細い小枝だけを葉のレイヤーに入れます。樹皮の色の画素のうち、太さが約6画素以下のものだけを小枝と判定し、幹と太い枝は必ず原画側に残します。
- **回し方**：小枝と葉を、付け根を軸に1つの角度で回します。場所の中では厳密な回転なので、枝の長さ・太さ・曲がりは変わりません（C2は先端ほど角度が大きくなる「しなり」でした）。
- **角度**：手前で最大約1.6度、奥で約0.5度。木ごとに周期と向きが違います。
- **葉先**：その上にBの細かな揺れを重ねます。
- **無理に動かさない所**：夜は小枝を空と見分けにくいため小枝を分離せず、葉だけが回ります。場所の縁では動きがゼロになるので、縁をまたぐ枝は縁の近くでわずかに曲がります。

### Claudeの推奨

**B4を推奨します。** 「葉の動きが分かりやすい（Bの長所）」「継ぎ目がない（C2の対策）」「枝がぐにゃぐにゃしない（形を保った回転）」の3つを満たす仕組みだからです。B4で枝の付け根に切れ目やずれが見える場合は、枝を一切動かさない **B3** が安全な選択です。

動きそのものは開発側では目視できていません（強い風＋3倍拡大の静止画で、B2・B3・B4に四角い線や枝の切断がないことは確認）。最終判断は比較ページの実際の動きでお願いします。

## 木の揺れの最終比較（VERSION 6：B・C・C2・C3）

### B案がC案より広く動いて見えた理由

実際に動かしている範囲は同じでした。違いは動き方です。

| 項目 | B 葉先だけ | C 枝葉を分離 |
| --- | --- | --- |
| 動かす場所（森） | 16か所・原画の14.1% | 同じ16か所・14.1% |
| 葉の分離方法 | 同じ（色で葉を判定し、葉レイヤーと下地に分ける） | 同じ |
| 平均の移動量 | 0.62 | 0.59（ほぼ同じ） |
| 最大の移動量 | 5.4 | 8.1（突風時の枝先） |
| 動きの種類 | 速い細かな揺れ（毎秒約0.4〜0.6往復）が常に全体で起きる | ゆっくりしたしなりが中心で、突風のとき大きく動く |
| 付け根からの変化 | 付け根0→先端で最大 | 付け根0→先端で最大（回転なので距離に比例） |
| 隣り合うタイルのずれ | 平均0.77・最大8.3 | 平均0.52・最大5.4 |

- **広く見える理由**：Bは風が弱いときも全体が速く細かく動き続けるためです。Cは動きの大半が突風のときに集中し、凪のあいだは静かです。
- **四角い境界・隙間の原因**：B・Cとも、葉のレイヤーを4×4の四角いタイルに切り、タイルごとに別々の位相でずらしていました。隣のタイルと最大8.3ずれると、その分だけ四角い継ぎ目や隙間（下地）が見えます。Bは揺れが大きいぶん目立ちます。

（移動量の単位は原画の横幅を1000としたもの。スマホの画面では約0.4〜0.55倍のピクセルになります。）

**継ぎ目の出ない方式（C2・C3）**

- 葉のレイヤーを、重み合計がちょうど1になる「重なり合うやわらかいタイル」に分けます。少しずつ違う位置に置いても四角い縁や隙間ができず、なめらかな伸び縮みになります。
- ずらす量は、場所の縁でゼロになります。動かない原画と必ず継ぎ目なくつながります。
- 下地は、葉が実際に動く範囲にだけ敷きます。動かない所にぼかしが出ません。
- 葉先の揺れは、木の中を風下へ流れる長い波にしました（タイルごとのバラバラな位相をやめました）。
- 葉と下地の分離は数フレームに分けて行い、時間帯の切り替えで止まらないようにしました。準備のできた茂みから順に揺れはじめます。
- 幹や苔のついた樹皮にかかる場所は、追加候補から外しました。

**確認できたことと限界**

- 強い風＋3倍拡大で、Bには四角い線が見え、C2・C3には見えません（静止画で確認）。
- C2・C3でも、強い風のときに3倍まで拡大すると、葉がわずかにやわらかく見える箇所があります。
- 夕方は西日の当たった葉を樹皮と見分けられず、動く葉が少なめです。

### Claudeの推奨

**C2を推奨します。** Cの自然な揺れ方のまま、動く範囲がほぼ2倍になり、四角い境界の原因そのものを取り除いています。C3は風がはっきり分かりますが、強い風のときの葉のやわらかさがC2より出やすいので、「もっと動きがほしい」と感じた場合の次点です。

## 木の揺れ方の比較（VERSION 5）

最終候補Eのうち、木と草の揺れ方だけを4方式で切り替えられます。ほかの演出（ほたる・星・水面・雨・雪・花びら・落ち葉・自動調整）はどれも同じです。

| 方式 | 動かし方 | 幹・空・地面 |
| --- | --- | --- |
| **A 現在のE** | 原画そのものを、縁でゼロになるずらしで動かす | 葉と一緒に引っぱられる（歪みの原因） |
| **B 葉先だけ** | 葉を原画から分離し、枝は動かさず葉先だけを細かく揺らす | 一切動かない |
| **C 枝葉を分離** | 葉を原画から分離し、枝の付け根を軸にしならせる。葉は追従し、葉先は細かく揺れる | 一切動かない |

### B・C・D に共通する新しい仕組み：葉と背景の分離

原画は描き直していません。読み込んだ原画から、葉の茂みごとに次の2枚をその場で作ります。

- **葉のレイヤー**：色で葉と判定した画素だけ（時間帯ごとに判定を変えています。空・雲・樹皮・岩・青い遠景は葉に入りません）
- **下地**：葉を抜いた跡を、まわりの空・遠景・幹・枝の色で埋めてぼかしたもの

下地の上で葉のレイヤーだけを動かすので、葉の後ろの空や幹は1画素も動きません。葉が動いて見える隙間には、ピントの外れた奥行きのような下地が見えます。

- **付け根**：森の16か所は、過去のE3で調べてあった枝の付け根を軸に使っています。ほかの地域は、草や植え込みは根元、張り出した枝は幹側、柳は上端を軸にしました。
- **根元から先へ**：付け根では動きゼロ、遠い葉ほど大きく動きます。Cのしなりは手前で最大約3度、奥で約1度です。
- **木ごとの違い**：木ごとに揺れの周期が違い、突風は風上の木から順に届きます（となり同士が同じ動きにならないことをテストで確認）。
- **夕方**：西日の当たった葉は樹皮と色が近く、葉と判定できない所は動かしません。

### Claudeの推奨

**C（枝葉を分離）を推奨します。** 幹と空が動かないまま枝がしなり、葉が追従するので、ご要望の「根元は固定・先端ほど大きく・木ごとに違う」に最も近い方式です。動きはAよりはっきりしています。

Cでもまだ不自然に見える場合は、**D（木は静止）** が次点です。形が一切変わらないので歪みは原理的に起きず、葉のきらめきと木漏れ日・草・落ち葉で風を感じさせます。

動きそのものは開発側では目視できていません（静止画の拡大確認と数値チェックのみ）。最終判断は比較ページの実際の動きでお願いします。

## 最終候補（E）

演出の量ではなく動きの質を直した版です。強さはC案と同程度です。

### 直したこと

| 気になっていた点 | 原因 | E案 |
| --- | --- | --- |
| 森の奥の光が一列に並び、弧を描いて動く | E3の「光の行列」（11個が1本の曲線上を順に進む演出）と、同じ式で動くほたる | 両方を外し、D案の独立したほたるに置き換え。1匹ずつ居場所・軌道・速さ・明滅の間合いが別で、ときどき別の場所へ移ります |
| 木が途中から揺れる／背景画像が歪んで見える | 原画を楕円に切り抜いて回転させ、縁をぼかして重ねる方式。縁で元の絵と二重になり、幹も一緒に回る | 切り抜き方式をすべて停止。葉の茂み・枝先・草むらだけを、**縁でゼロになる滑らかなずらし**で動かします。境目も二重写りもできず、幹・岩・建物は動きません |
| 木の一部が伸び縮みする | 回転とせん断の合成 | 中心の移動量を、場所の半径の3分の1未満に制限（テストで確認） |
| 雲やかげろうで背景が波打つ | やまの雲・さばくのかげろうも同じ切り抜き方式 | 停止。霧の流れ、砂の上の風は残します |
| 人工的な線・規則的な模様 | D案の風の筋、地面を渡る帯、海のうねりの線 | E案には入れていません |

### D案から取り入れたもの（強さを落として）

- 水面のきらめき（強さ5.5割・大きさ7割）。太陽・月の道の上がやや強く光ります
- 川の流れの筋（本数を半分、濃さを半分、細く）

### D案から取り入れなかったもの

目に見える風の筋、地面を渡る風の帯、海のうねりの線、E3の最大強度（2倍）駆動、雨の波紋の二重化。
