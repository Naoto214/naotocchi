# ホーム環境演出 VERSION 2（季節・天気・時間帯・生きた世界）

本番のホーム描画と、環境演出だけを差し替えた2つの案を見比べるための比較です。

- **A**：現在の本番
- **B**：雨・雪・花びら・落ち葉の改善版
- **C**：Bに、草木の揺れ・水面・光・灯りなどを重ねた総合演出版
- **D**：Cの動きを限界まで強めた最大演出版（上限を確かめるための版。ここから引き算する前提）
- **E**：Cの強さを基本に、不自然な変形と規則的な動きを直し、Dの良い部分を控えめに取り入れた**最終候補**

配置・移動・歩行領域・恋人位置・キャラサイズ・接触判定・タップ／ドラッグ・UI・ステータスバー・背景原画・BGM・セーブ形式には触れていません。**本番ファイルは1バイトも変更していません。**

## 最終候補（E）

演出の量ではなく動きの質を直した版です。強さはC案と同程度です。

### 直したこと

| 気になっていた点 | 原因 | E案 |

## 最大演出版（D）

「見てすぐ動きが伝わる」ことを優先し、背景そのものの動きを最大にした版です。雨・雪・花びら・落ち葉の**量はCと同じ**です。

| 対象 | Dで強めたこと |
| --- | --- |
| 木・枝葉・草 | E3の揺れを最大強度（2倍）で駆動。手前ほど大きく、奥ほど小さく揺れます |
| 風 | 目に見える風の筋。約11秒ごとに突風が立ち上がって弱まり、向きも毎回変わります。合間もそよ風が残ります |
| 草地・田畑・砂・雪原 | 突風に合わせて、明るい波と影の谷が地面を渡ります（もり・いなか・やま・かわの岸・さばく・ゆきぐに） |
| 木漏れ日・光 | E3の光の筋と地面の光を最大強度に |
| 川 | 川面の72点すべてから、下流へ走る流れの筋。長さ・速さ・間合いは1本ずつ別 |
| 海 | 沖から浜へ寄せるうねり11本（遠くは細かく、手前は大きく）、波打ち際を最大強度に |
| 水面のきらめき | 海・川・池の全域で、点ごとに別の拍で光ります。太陽・夕日・月の道の上は特に強く |

| 夜空 | 原画の星の位置に合わせたまたたき（8地域）、ときどき流れ星 |

**強すぎるかもしれない点**（引き算の候補）：もりの光の筋、風の筋の濃さ、川の流れの筋の本数、海のうねりの線の濃さ。

## 新たに改善したもの

- **雨**：ほぼ真下（傾き1.4〜3度、全滴同方向）、遠・中・近の3層。雨雲の色かぶせ。
- **雨の波紋**：うみ72点・かわ72点・ジャングルの池13点。原画の水面だけを色で判定して自動配置し、岩・砂浜・岸・空には出ません。各点が別々の周期で休みを挟み、落ちる位置も毎回少しずれます。遠くは小さく淡く、手前は大きくはっきり。朝・昼・夕・夜で色と濃さが変わります。
- **雪**：3層、落下と別周期の左右のゆれ、ゆるい横流れ。夜は青白く。
- **花びら**：ゆれ・傾き・裏返りが1枚ずつ別の周期。時間帯で色が変わる。
- **落ち葉**：夜は月明かりの色。毎秒30コマ。
- **描画方式**：落下物はすべて背景Canvasに描きます（DOM要素を粒ごとに動かす方式は28体で大きくコマ落ちしたため不採用）。
- **二層構成**：背景＋生きた層は別のCanvasに保持して低い頻度で更新し、落下物だけを毎秒30コマで重ねます。
- **自動調整**：ホーム全体のコマ落ちを検知すると、生きた層の更新を 30 → 15 → 10 → 6fps → 停止 と段階的に落とし、余裕が戻れば上げます。落下物は止めません。

Linux・ヘッドレスChromium（ソフトウェア描画、画面390×844・DPR3）で、実ホームに住民を表示して計測しました。値はブラウザの毎秒コマ数、C案の括弧は生きた層の更新頻度です。

| --- | --- | ---: | ---: | ---: |
| もり・あき・晴れ・昼・28体 | 通常 | 60 | 60 | 60（層30fps） |
| うみ・なつ・雨・夕・28体 | 通常 | 60 | 60 | 60（層30fps） |
| ゆきぐに・ふゆ・雪・夜・28体 | 通常 | 60 | 60 | 59（層30fps） |
| とかい・なつ・晴れ・夜・28体 | 通常 | 60 | — | 59（層30fps） |

| もり・あき・晴れ・昼・28体 | 4倍低速 | 40 | 40 | 40（層6fps） |
| うみ・なつ・雨・夕・28体 | 4倍低速 | 44 | 36 | 30（層は停止） |

- 通常速度では、A・B・Cとも28体で毎秒約60コマ。C案の生きた層は毎秒30コマで動きます。
- CPUを4倍遅くした条件（低性能端末の目安）では、C案は生きた層を自動で間引くか止めます。もり・ゆきぐに・とかいは現行と同じコマ数でした。
- **うみの雨は4倍低速で現行より重くなります**（A 44、B 36、C 30）。雨筋96本と波紋72点を毎秒30コマで描く負荷で、粒子の量を「ふつう」「少ない」に落とす端末負荷段階が効く場面です。
- 落ち葉の毎秒30コマ化（B案・もり・秋・28体）は、通常速度・4倍低速とも現行と同じコマ数でした（60／40）。
- この計測のあとで手前の雨筋を少し短く細くしました（描画量は減る方向）。表の値はその前のものです。
- **iPhone Safari 実機では未計測です。** ソフトウェア描画での結果なので、GPUのある実機での傾向は異なる可能性があります。
