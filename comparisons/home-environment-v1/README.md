# ホーム環境演出 総点検 VERSION 1（季節・天気・時間帯）

本番のホーム描画（現行）と、演出だけを差し替えた提案版を、同じ原画の上で見比べるための比較です。
配置・移動・歩行領域・恋人位置・操作・ズーム・UI・BGMには触れていません。**本番ファイルは1バイトも変更していません。**

## 現状（全13地域 × 季節4 × 天気4 × 時間帯4 = 832条件）

| 演出 | 条件数 | 本番の実装 | 状態 |
| --- | ---: | --- | --- |
| 雨 | 160 | 旧CSS粒子：1px線16本、斜め約7度、実質の不透明度0.36 | 古いまま。明るい背景ではほぼ見えない |
| 雪 | 128 | 旧CSS粒子：点16個が斜めに直進 | 古いまま。ゆれ・奥行きなし |
| 春の花びら | 32 | 旧CSS粒子：花の画像16枚が斜めに直進・一定回転 | 古いまま |
| 秋の落ち葉 | 32 | うち14条件は承認済みB案（#569 → #587） | **18条件に旧い落ち葉が残存** |
| ただよう光 | 192 | しんかい・ほしぞら・きおくのみずうみ | 現状維持を推奨 |
| 粒子なし | 288 | 原画の光と影のみ（曇りは薄いベール） | 現状維持を推奨 |

旧い落ち葉が残っている18条件：かわ（朝・昼・夕・夜）、やま（朝・昼・夕・夜）、いなかの夜。いずれも晴れ・曇り。

そのほかの確認結果：

- #568 の雨・雪・花びらの改善（E3+）は比較Draftのままで、本番には入っていません。#587 で入ったのは落ち葉B案だけです。
- 本番の落ち葉B案は、背景Canvasの再描画間隔（120ms）に合わせて毎秒約8コマで動いています。
- 朝・昼・夕・夜の光と影は、52枚の原画に描き込み済みです。演出側で光を足す必要はありません。
- 草木の揺れ・水面の動きは本番にありません（#567 のE3は未統合）。今回は対象外とし、雨の日の水面の輪だけ提案に含めました。
- 粒子はすべて住民・UIより奥のレイヤーにあり、住民に重なりません。

## 提案

| 演出 | 提案 | 現行との違い |
| --- | --- | --- |
| 雨 | ほぼ真下（傾き1.4〜3度で全滴同方向）、遠・中・近の3層、96本 | 斜めをやめ、長さ・太さ・濃さに奥行き。雨雲の色かぶせ、うみ・かわ・ジャングルの水面に雨の輪 |
| 雪 | 遠・中・近の3層、80片。落下とは別の周期で左右にゆれ、ゆるく横へ流れる | 直進をやめ、大きさ2.4〜10px・速度に幅。夜は青白く |
| 花びら | 18枚。ゆれ・傾き・裏返りが個別の周期。3色、時間帯で色が変わる | 画像の一定回転をやめ、形・色・動きを作り直し |
| 落ち葉 | 承認済みB案を残り18条件へ。夜は月明かりの色。毎秒30コマ | 葉の絵・表裏・風はB案のまま。かわは岸の木から、やまは谷風に乗る5枚だけ |
| おうち | 雨・雪は窓の中だけ（現行の切り抜きを維持）、小さく控えめに | — |

粒子数は端末の負荷段階で 96/54/28（雨）、80/44/22（雪）、18/11/6（花びら）に減ります。「動きを減らす」設定では表示しません。
雨・雪・花びらはCSSのtransformとopacityだけで動かし、JavaScriptの毎フレーム処理はありません。

## 比較ページ

```sh
node comparisons/home-environment-v1/build.cjs /tmp/naotocchi-environment
python -m http.server 8196 --bind 127.0.0.1 --directory /tmp/naotocchi-environment
```

地域・季節・天気・時間帯・粒子の量を切り替えられます。現行は本番の `home-production-world.mjs` をそのまま、提案は `proposal/` の4ファイルを重ねて同じページで動かしています。

```sh
node --test comparisons/home-environment-v1/fx.test.mjs
```
