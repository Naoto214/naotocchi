# アストラさんへの引き継ぎ：四季の背景画と雲の素材

ホームの環境演出（季節・天気・時間帯）のうち、プログラムの加工だけでは届かなかった美術面を
お願いするための資料です。原画はそのまま残し、追加の画像を「差し込む」形で使います。

## 1. いまの原画

- 場所：`comparisons/dayparts-20261103/{v2,v4,v6,images}/<地域>-<時間帯>.webp`
  （どの版を使うかは `home-dayparts.mjs` の `DAYPARTS` が決めています。合計52枚・約23MB）
- 形式：WebP、**1024×1536（縦2:3）**
- 地域13：`home` `forest` `river_lake` `jungle` `countryside` `mountain` `snow` `sea` `deepsea`
  `desert` `city` `star_stop` `memory_lake`
- 時間帯4：`morning` `day` `evening` `night`

## 2. 季節専用の背景画の条件

| 項目 | 条件 |
|---|---|
| サイズ・形式 | 1024×1536、WebP（1枚 300〜600KB 目安） |
| 構図 | 同じ地域・同じ時間帯の原画と**輪郭が重なること**（地平線、道、川岸、建物、幹の位置） |
| 歩行領域 | 住民が歩く地面（下側およそ6割）の形・傾き・明るさを大きく変えない。地面に大きな物を足さない |
| 住民が隠れる物 | 手前の木・岩・柱・家具の位置と形を変えない（遮蔽の判定が原画に合わせてあります） |
| 水面 | 川・海・湖・田んぼの位置と輪郭を変えない（波紋・きらめきの位置が決まっています） |
| 空 | 空の範囲（上端からの高さ）を変えない。**雲は描き込まず、晴れた空だけ**が理想（雲は別に重ねます） |
| 窓（home） | 窓枠の位置を変えない。季節が変わるのは窓の外の景色だけ |
| 光 | 時間帯の光の向き・色は原画と同じ |
| 降るもの | 雨・雪・花びら・落ち葉は描き込まない（動く粒として重ねます） |

揺れる葉は、原画の色から葉を見分けて切り出しています。季節画でも葉の位置がほぼ同じなら
そのまま動きます（紅葉・枯れ色に合わせた見分け方は入れてあります）。

## 3. 色の加工でできたこと・できないこと

できたこと：葉・草の色替え（春の若葉、夏の濃い緑、秋の赤と黄、冬の枯れ色）、空と重ならない
範囲での遠くの山・林への色替え、花や霜の散らし、動く雲。

できないこと（＝描いていただきたい理由）：

- 葉を落とした**冬の枝ぶり**、積もった雪、霜の降りた地面
- **桜や梅が咲いた木**の形（色の点を散らすだけでは花房になりません）
- 黄金色の**稲穂・すすき**、刈り取り後の田
- 空の色に近い**最も遠い青い山**の季節感（紅葉の山肌、冠雪）
- 春霞・冬の澄んだ空気など、画面全体の空気感

## 4. お願いしたい画像（優先順）

1. **forest-day** の 春・秋・冬（まずこの3枚で差し込みの確認をします）
2. countryside-day、river_lake-day、mountain-day の 春・秋・冬
3. city-day、memory_lake-day、home-day（窓の外）の 春・秋・冬
4. 上記の morning / evening / night
5. jungle・star_stop は控えめな差（任意）。snow・desert・sea・deepsea は原画のままで構いません

夏は原画をそのまま使います。全部そろえると最大208枚ですが、**1枚ずつ足せます**。
無い組み合わせは、今の色加工で自動的に補います。

## 5. 透明な雲の素材（任意）

今の雲はプログラムで形を作っています。絵柄により合う雲が欲しい場合：

- 透過PNGまたはWebP、横長（例 1024×384）、**左右がつながる**（横に流すため）
- 奥用（小さく淡い）と手前用（大きく厚い）の2種
- 種類：晴れの綿雲／薄雲／曇りの層雲／雨雲／雪雲。白〜灰の濃淡だけで描き、
  朝夕・夜の色はこちらで付けます
- 上が明るく下が陰になるように（光は上から）

## 6. 組み込み方

- 置き場所：`comparisons/seasons-v1/<season>/<地域>-<時間帯>.webp`
  （例 `comparisons/seasons-v1/autumn/forest-day.webp`。season は `spring` `autumn` `winter`）
- 登録：`comparisons/home-environment-v1/proposal/home-season-art.mjs` の `SEASON_ART` に1行足す
- 読み込むのは**表示中の1枚だけ**。読み込みが終わるまでは色加工版を表示します
- 空・水面・窓の範囲は `proposal/living/skyline.mjs`（空）と `proposal/living/maximum.mjs`（水面・星）に
  地域ごとの数値があります。構図を守っていただければ調整は不要です
