# ホーム住民サイズの採用記録

2026年11月19日、本人が #570 の手動案 **主人公120%・恋人120%・仲間105%** を採用した。倍率の100%は正式ホームでその同じ住民・立ち位置・人数を描いた大きさ。主人公の既存110%も、その基準に含む。主人公と恋人がどちらも120%でも、原画・役割・立ち位置に由来する大小差を保つ。遠くの恋人が手前の仲間より小さく見えることを許容する。[採用元の比較コミット](https://github.com/Naoto214/naotocchi/commit/e7d881b825622efddac61857075c2c1658da706f)

落ち葉は #569 のB案を引き継ぐ。今回の最終確認は本人限定のホームで行う。正式ゲームへの統合・配信は別工程。
