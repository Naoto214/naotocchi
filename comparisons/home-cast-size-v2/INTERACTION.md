## 背景の確認方法

幅320・375・390・430 CSS px、高さ568・812・844・932 CSS px、DPR 2の縦画面を使用。地域ごとに人数と画面幅を割り当て、設定欄の朝・昼・夕・夜を実際に切り替えた。通常のブラウザーのCanvas描画を観測し、元画像が中間Canvasに描かれてから、画面の背景Canvasに合成された時点のファイル名を取得する。選択値に加え、地域名・時間帯と画像名、画面中央に絵があること、住民・影・読込済みのキャラクター画像の個数を照合する。各時刻の全画素の画質評価はこの計測に含まない。

Chromium 156.0.8078.79 では13地域の全52切替が一致した。人数は1・4・10・20・28体が一巡するように割り付けた。全場面で主人公のリボンがあり、恋人を含む場面では指輪も表示された。最終版のホーム内に旧切替ボタンとその文言は0件だった。「動きを減らす」有効時の結果を地域・人数・画面幅別に記録した。[全52場面の実測](evidence/interaction-scenes.json)

## 再現

V2の試遊版をローカルで公開し、Python・Playwright・Chromiumを用意して比較フォルダーで実行する。WebKitではPlaywright用のLinux WebKitを使用する。

```sh
python verify_interaction_scenes.py http://127.0.0.1:8202 --out scenes.json
python verify_interactions.py http://127.0.0.1:8202 --ordinary-targets --out inputs.json
python verify_interactions.py http://127.0.0.1:8202 --widths 320 --observe 2 --out forest-exit.json
python verify_interactions.py http://127.0.0.1:8202 --engine webkit --widths 390 --out webkit.json
python verify_interaction_social.py http://127.0.0.1:8202 --out social.json
python verify_interaction_restore.py http://127.0.0.1:8202 --out restore.json
```
