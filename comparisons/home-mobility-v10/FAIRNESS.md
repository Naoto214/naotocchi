## 成立率、復帰、意図された待機

通常歩行は、本人の最初の目標に0.75 CSS pxを超えて近づき、正味8 CSS px以上進んで自律経路の終点に到着した脚。道を譲る歩行や退避のタグを持つ歩行は除外した。1回・2回・前後半の両方の3指標は別々に判定した。

経路成立率の分母は住民が実際に発行した自律要求。拒否区間の開始はネイティブ探索の不成立。次の本人の一歩、次の本人の成立経路、または次の通常歩行の終点を別々に数えた。いずれも座る・休む・見回す・向きを変える活動へ移った時点で、その連続拒否区間を閉じる。歩行枠が埋まって4活動を選んだ場合も含む。会話、病気、睡眠などでモデル時計が停止した実時間は経路拒否に加えていない。ネイティブ時計が30実秒以上動かず、応答が必要な質問・延期ボタンが画面に出た場合のみ同一の手順で実タップした。発症時の薬や通常の清掃・給餌もV9とV10で同条件。各ゲートの時間と行った世話の回数、個体別の休息・社会活動の時間も収録した。ルートを要求しない活動だけでは拒否区間は始まらない。会話相手として聞き手になった瞬間は全件の生ログに専用イベントがない。拒否から次の本人歩行までの経過秒数全体を、物理的に閉じ込められていた時間とは判定できない。

各個体のCSVには失敗区間が本人の一歩で終わった件数、自発・枠待ちの活動で終わった件数、観測末に未解決の件数を併記した。step_recovery_fraction は本人の一歩で終了した件数 / 全開始区間。strict_normal_recoveries は通常移動で終了した件数。peer_change_retries は、近傍の足やヘルパーの利用可能性が変化したためネイティブモデルが実際に再試行した回数。道譲り後の継続経路の再開は別欄に記録した。

## 保存・復帰と安全性

各再生の終了時にゲームが試験用の保存領域へ書き込んだデータを、新しいホームのネイティブローダーに渡した。住民の並び・恋人・地域を照合し、比較用再配置をせずにホームを動かした。この検証とは別に、経路の途中の足・元の目標・乱数を保存した試験用チェックポイントから個体ごとの指操作を実行した。

全30セルで実際にセーブを読み戻した後に、すべてのホームで自律歩行が始まった（合計161回）。コミットされた歩行脚の速度上限超過は0件。脚の間などで観測した原因未分類の足位置差は58件、累計313.538 CSS px、最大22.742 CSS px。320px・乱数214のパンダで従来配置のV9が22.595 CSS px、V10が22.742 CSS px。これらの座標差は移動距離から除外した。 [位置差の発生区間と対象住民](evidence/forest-all/forest-foot-shifts.csv)

各セルは同一乱数につき1回の実時間再生。ホストのフレーム間隔や世話・会話のタイミングで後続経路は分岐する。既往例の厳密な再現を比較するには、同じ状態の個別再生とこの自然再生を併用する。
