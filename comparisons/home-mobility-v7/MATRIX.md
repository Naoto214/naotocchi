## 描画足とセーブ再読込

同じ経年後対象260体のうち、自律指示を受けながら300秒間一度も歩き始めず、本人に届いたドラッグでも歩けなかった件数はV5 / V6 / V7で 21 / 17 / 3。自律移動が同条件で、タッチ時に別の住民が選ばれた件数は 5 / 5 / 1。[対象ID・妨げた住民・待機・指示受理の一覧](evidence/matrix-aged-targets.csv)
モデル0・60・120・180・240・300秒の実DOMで、各版 19,656 組の住民の足アンカーとモデル座標を照合した。最大差はV5 / V6 / V7の順に 0.0134 / 0.0134 / 0.0136 CSS px。
各地域28体・390pxの3版で、経年後のネイティブ保存と再読込を 39 回実施した。隔離した試遊メモリでは通常の画面再読込時に保存が破棄されるため、測定時は実際の保存関数が生成したバイト列を、再読込した画面の通常のロード関数に渡した。所持金・保存版・装備・恋人・仲間の照合成功 39 回、再読込後タッチ配信 39 回、本人への指示 39 回、本人到着 39 回。

## 測定条件と数値

13地域×1・4・10・20・28体×320・375・390・430 CSS px。実タッチはPlaywrightのChromiumモバイル入力。3版とも世帯・初期足・表示サイズ・乱数を一致させ、過去の実座標を再使用した。5分の経年は自律移動を有効にしたネイティブモデルを0.05秒刻みで進め、各60秒で本物のホームを再描画した。経年試験はモデル時間の観察。実時計での連続映像の停止とWebKitの負荷は別の長時間試験で扱う。iPhone Safari実機のV7操作結果は未検証。
