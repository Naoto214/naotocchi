# なおとっち 2.5Dホーム最終仕上げ

採用サイズで実際に住民を動かし、元の足元と新しい足元を画面上で切り替えられる。 [本人限定試遊](https://naotocchi-cast-size.kerzion214.chatgpt.site/v5/) ／ [到達率・停止時間・全地域の結果](RESULTS.md)

## サイズBの採用仕様

PR #570 VERSION 4で比較したB案を採用した。以前の正式ホームの実表示を基準に、主人公と恋人を120%、仲間を105%とする。主人公の元の110%はこの基準に含まれる。追加分は全員に同じ係数を一度だけ掛ける。

| 条件 | 追加倍率 |
|---|---|
| 1〜18体、または幅320 CSS px以下 | 0% |
| 19〜28体かつ幅375 CSS px以上 | 19体で+1.5%、以後1体ごとに+1.5%、28体で+15% |
| 幅321〜374 CSS px | 上記の人数別追加分に、幅320〜375pxを0〜1とした `t²(3−2t)` を掛ける |

28体・375px以上の最終倍率は主人公138%、恋人138%、仲間120.75%。28体・348pxでは全員への追加が約7.70%、360pxでは約12.26%になる。[採用した比較の測定結果](https://github.com/Naoto214/naotocchi/blob/e07d2cc53eca36ff23e02142ab385d6001e0521b/comparisons/home-cast-size-v4/RESULTS.md)
