譜面

ピアノロールは メロディ 1周ぶん。上の 文字は コード。階名と 曲紹介の 音名は 移動ド（長調は 主音を ド、短調は 主音を ラ）。「ー」は 付点4分以上の のばす音、「・」は 休符。

① 音楽理論上の 評価（Claude・10点満点）

Claude は 音を 聴けません。この表は 楽譜の 分析（音域・音の 動き・和音との 関係・反復・和声の 色）から つけた 予想です。聴いた 感想では ありません。また、自分で 作った 曲は 高く 見積もりがちな ことも 割り引いて ください。

② 聴感評価（あなたの 耳で）

ここは 空欄の まま お渡しします。聴いた 印象を 星と メモで 残せます（この ブラウザだけに 保存され、ほかの 人や Claude には 送られません）。

iPhone Safari で 聴くとき

  • 最初の 1回は「▶ 再生」を タップして ください（ブラウザの 決まりで、タップ前は 音を 出せません）。
  • 消音スイッチが オンでも 鳴る ように「メディア再生」として 鳴らしています。それでも 鳴らない ときは 消音を 切って ください。
  • 画面を 消すと 止まります。もどった ときは もう一度 ▶ を。

この 音源の 制約

  • ブラウザの Web Audio で その場で 合成した 音です。録音した ピアノでは ありません。
  • 音色は V1 の 試聴室と 同一で、7曲 共通です。ちがいは メロディ・和声・テンポ・調・拍子だけです。
