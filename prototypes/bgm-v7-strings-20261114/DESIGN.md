# V7 B案 — 弦の音源・接続改善

基準: PR #547 / 25c69a0a78e7f72351ffad1836ec4932760f0552。採用済み音声出力修正を引き継ぐ。独立ブランチcodex/bgm-v7-strings。旧版は読み取りのみ。

利用者指定の比較を実行する。Aは現行Bの原盤を参照（旧V7-Aを意味しない）。B1は同じ音符・発音位置・楽器配置・V6表情曲線で、VSCO録音の選別・安定区間・フレーズの接続・離音を改善。B2は明確な別録音候補が品質検査に合格した楽器を交換し、どの楽器を交換したか明記する。別録音が必ず優れているとは前提にしない。

ピアノは既存の検証済みV6ピアノ成分を固定して使う。主旋律3158音、全32曲ID/曲名、配置50行、B案の弦104音（実数はスコアから照合）の音高・発音順・発音位置を保持。楽譜の音価は保存し、演奏上の接続・離音だけを別の演奏表へ記録。ホーム夜の前半はピアノのみ、後半の弦も元の配置・控えめなバランス。

方法: まず持続録音のノイズ、音域差、先頭と持続部、ピッチ揺れ、フレーズ間の実際の低音量区間を測定。連続する音だけを短く受け渡し、明示的なフレーズ休符を埋めない。同音の連続は必要なら同一録音の連続部分を使用。新しい人工サンプルループ・時間引伸ばし・合成ビブラートは使わない。和声変化を越える長い重なり、残響増量で隠す方法は避ける。

候補: VSCO CE CC0、Karoryfer x bigcat cello CC0（実演者Kamila Borowiakの独奏録音）。混在した出典を一括でライセンス確認できないSSO/VPOや、単周期/ループ合成を主眼とするString Cyborgsは今回の優先候補にしない。

比較は全曲平均LUFSをそろえ、盛り上がり区間にもジャンプできる。必要なら乾いた弦だけの短い比較も用意し、ピアノや残響に隠れていないことを確認できるようにする。A/B1/B2の違い・使用録音・限界を記載。iPhone本体スピーカーで動作確認済みの音声出力コードを基準にブラウザー回帰検証。今回の新版の実機聴感は利用者の試聴確認と区別する。
