## Architecture and reuse
New files only in prototypes/growth-clear. Import old board/validation/gravity, movement/kicks/BFS placements, item enumeration, seeded RNG and evaluator. Adapt the existing transactional session to structured pair cells {k,s}; use its same item semantics (egg ranks hatch 01..04, costs unit / 3 units). Original resolver remains the old-rule comparator. New resolver uses maximal equal-stage components, with mixed-species clearing taking precedence over all same-species subsets. One board snapshot per wave; all groups resolve simultaneously; gravity then repeat. Upper stages clamp to 08 (no overflow clear); only a pure-species 08 group clears successfully. Evolution destination 04..07 grants one matching egg; mixed clears grant neither eggs nor gauge. Gauge uses actual stage increase.

## Bag
20 pairs, exact categories 7/5/5/3 and exact 8 individuals per species. Construct same-species degrees [3,3,2,2,2] randomly assigned to species, then a loopless residual multigraph with degrees [2,2,4,4,4]. Shuffle category assignments within same/different species and shuffle all pairs. Stage-equal pairs draw one stage from .4/.3/.2/.1. Stage-different pairs draw unordered 12/13/14/23/24/34 with probabilities .44/.26/.10/.10/.06/.04 and random orientation. Both endpoint marginals are exactly .4/.3/.2/.1, unlike rejection sampling two independent stages. This is a constructive sampler, not uniform sampling over every feasible bag. Bag counts vary for stages only.

## Anchor semantics
A: lowest, then leftmost. B: most recently landed cell; lock-to-settle fall distance orders split landing (largest distance latest), exact ties use higher id. In subsequent waves freshly falling survivors get priority; if no group member newly fell, prior priority survives then A fallback. Egg prioritizes the inserted id; transform prioritizes the changed id; bulk prioritizes changed cells bottom-to-top, left-to-right. C: choose a member id for EACH evolving group before applying that entire wave; no choice for clears. Transactional resolver can request a missing choice; replay carries choices keyed by wave and sorted component ids. Invalid choice throws without mutation. AI uses deterministic positional choice and records it. UI asks for each choice, including later chains. Extra decisions are counted, not assumed equivalent to simple controls.
