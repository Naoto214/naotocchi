# なおとっち BGM VERSION 4（2026-11-14）

採用32曲（PR #534）の 第4版。VERSION 3（PR #542）の ポップで 賑やかな 印象を、**音を 減らして** 透明感・美しい 旋律・自然な 余韻へ 改めた。
楽器は 増やして いない。新しい 曲や 旋律も 作って いない。

## 守った もの

- 採用32曲・曲ID・曲名・テンポ・拍子・小節数・反復・長さ・ループ指定（V1 と 同じ）
- 主旋律の 音高・開始時刻・譜面上の 長さ・本数（V1 と 完全一致。3,158音）。ペダルで 響かせる 長さは 別の 値（hold）として 持ち、譜面の 長さ（dur）は 変えない
- 配置表 50行と 場面ごとの 曲、変奏の テンポ・小節の 範囲・用途
- V1（#536）・V2（#539）・V3（#542）の 音源・楽譜（`verify_v4.py` が ハッシュで 確認）

### ホーム4曲

採用アレンジA の ピアノ（旋律と 左手の 和音）を 中心に 作り直した（V3 の ギター・ウッドベースは 使わない）。

| 曲 | V4 |
|---|---|
| そよかぜの まど（朝） | ピアノ ひとりの 旋律と 和音。2周目は フルートが そっと 寄りそう |
| いつもの にわ（昼） | ピアノの 旋律と 和音。2周目 クラリネット・3周目 フルートが そっと 寄りそう |
| ほしふる みずうみ（夕） | ピアノの 旋律と 和音、チェロが 低音を 長く 支える。2周目は クラリネット |
| ほしぞらの やくそく（夜） | ピアノ だけ。ペダルで 一音一音を 長く 響かせる。残響を 少し 長く（2.8 秒） |

### ホーム夜が「ぶつ切り」に 聞こえた 原因

旋律の 譜面上の 長さは ほぼ 音価 いっぱいで、音符の あいだの 無音では なかった。原因は 次の 3つ。

1. 録音の アップライトピアノは 打鍵後 0.5 秒で −15〜−20 dB と 急に 減衰する（一音ずつ 叩く 響き）
2. V3 は ペダルを 使わず、各音を 譜面の 長さ ＋ 0.3 秒で 止めて いた（次の 音が 前の 音の 消えた あとに 始まる）
3. 2拍ごとの 左手の 和音も 同じ ように 切れて いた

V4 は ペダル・ゆっくりした 離鍵・打鍵の 山の やわらげ・少し 長い 残響で つないだ。旋律の 音と 音の あいだの 音量の 落ちこみ（中央値）は
夜 16.7 → 12.2 dB、朝 11.8 → 7.9 dB、昼 8.3 → 5.1 dB、夕 12.2 → 10.1 dB（`tools/legato_metric.py`）。

## ファイル

- `audio/<id>.flac`（24-bit/44.1 kHz）・`audio/<id>.m4a`（AAC 192 kbps）・`midi/<id>.mid`（譜面の 長さ）・`receipts/<id>.json`（ハッシュと 検証値）
- `scores-v4.json`（V4 の 楽譜。hold＝ペダルの 長さ、removed＝削除した 音と 理由）
- `tools/arrange_v4.py`（編曲）・`tools/render_v4.py`（描画。V2 の 描画部品と V3 の 音づくりを 使い 設定だけ 変える）・`tools/verify_v4.py`（点検）
- `tools/legato_metric.py`（音の つながりの 目安）・`tools/report_v4.py`（VALIDATION.md を 作る）
- `PROGRESS.md`（進み具合。途中で 止まっても receipts の ハッシュで 完成済みを 判定し 続きから 作れる）

## 作り方

```
python prototypes/bgm-v4-20261114/tools/arrange_v4.py
python prototypes/bgm-v4-20261114/tools/render_v4.py --stage 1      # ホーム4曲
python prototypes/bgm-v4-20261114/tools/render_v4.py --group 2      # 2〜5（7曲ずつ）
python prototypes/bgm-v4-20261114/tools/verify_v4.py --audio
(cd prototypes && python bgm-v4-20261114/tools/report_v4.py)
```
