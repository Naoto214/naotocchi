# VERSION 7 — ホーム4曲 A/B 試聴設計

基準: V6 / PR #546 / 146383829818fc986926c05700986705d7241858。今回はホーム4曲だけ。残り28曲・ゲームBGMの差替えは選択後まで行わない。

## 音質上の診断

V6の音色はV5から継承され、V6自体は新しい楽器音符を追加していない。既存声部が前へ出たことで品質上の問題が目立った可能性がある。ホームの持続音277音を追跡すると、クラリネット25音・フルート16音・ビオラ3音が、短い要求長で作ったキャッシュを再利用したため、原録音が十分長いにもかかわらず人工ループで延長されていた。チェロはこの4曲では0音。これは確認できた機構であり、ユーザーの聴感上の雑音の全原因と断定しない。

## アプローチ

単に木管を小さくする案では人工反復は残る。全体音源交換はV6のピアノと夜の余韻を損なう可能性がある。ユーザー指定のA/Bを、ピアノ保護＋独立した弦の描画・再構成で制作する。

- A: ピアノ中心。木管・ビオラの重ねを外し、柔らかい弦を後半の要所だけに置く。夜はV6独奏原盤をそのまま使用。
- B: ピアノ＋新規採用の独奏バイオリン＋低中域チェロの明示的な短い応答。音を増やし続けず、頂点の前後は休む。夜は原盤のピアノを基礎に、後半だけ極めて静かな弦。

VSCO CE固定コミットのCC0生録音を使用。バイオリンは旧版未使用のSolo Violin/Arco Vibのp（弱奏）。チェロは同ライブラリのCello Sectionのv1を選別・再構成し、独奏チェロの録音とは称さない。木管・ビオラは今回不採用。録音全長のキャッシュ、自然な弓のアタック、フレーズ単位の連続強弱、短い重なりで接続。人工ループ延長・周期的合成ビブラートは使用しない。

## 保護と出力

全32曲のメタデータ・主旋律3158音をV6と照合。ピアノのvel/expressionDb/dur/hold/layerは完全保持。配置50行不変。V6強弱曲線を弦にも継承。夜AはV6 FLAC/AACの同一バイト。夜BはV6原盤を加工せず加算後の共通ゲインのみ。

独立ブランチ/Draft PR、A/B×4のFLAC・AAC・MIDI、音源ライセンスと品質測定、比較ページ（V6/A/B、同一位置・共通音量、ホームのみ）。試遊版へ追加するのは /bgm-v7/ と /audio/v7/ のみ。既存ゲームとV6比較は不変。実機iPhoneを使えない場合、WebKit検証を実機確認と表現しない。
