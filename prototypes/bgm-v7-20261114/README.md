## 4曲の方向性

| 曲 | A：ピアノ中心 | B：小さな室内楽 |
| --- | --- | --- |
| そよかぜの まど | 2周目の要所だけ4音のバイオリン | 中盤のチェロから、後半のバイオリンへ受け渡す |
| いつもの にわ | 短いチェロ2音と、3周目のバイオリン4音 | 2周目から応答し、3周目の音域と響きを少し広げる |
| ほしふる みずうみ | 既存のチェロ低音を再構成、終盤にバイオリン3音 | 静かな入りから歌い、2周目14小節で頂点、柔らかい帰着 |
| ほしぞらの やくそく | **V6ピアノ独奏の原盤をそのまま使用** | 同じピアノ原盤に後半のごく小さな弦。前半は実波形も一致 |

木管・ビオラの声部を外し、弦を必要なフレーズへ明示的に記譜。旋律やピアノの音符は変えていない。夕のチェロ低音は既存の音高・開始位置・長さを引き継ぐ。夜は華やかさより独奏の余韻を優先する。曲ごとにA/Bを混在して選べる。

## 音質の診断と修正

V6は新しい音符を追加しておらず、V5の楽器を表情付けで前へ出していた。旧サンプラーをホーム4曲の順番で追跡した結果、持続音277音中44音で、短い要求長のキャッシュを後から再利用し、原録音が十分長いのに人工反復で延長する挙動を確認した（クラリネット25、フルート16、ビオラ3、チェロ0）。これは確認できた仕組みであり、ユーザーが感じた雑音の全原因とは断定しない。

新しい弦の描画系は録音全長をキャッシュし、人工的な反復延長をしない。弱奏の独奏バイオリン録音を新規採用し、チェロ・セクションの弱奏を低中域で再構成。音域ごとの持続部音量差を補正し、緩やかな弓の入りと離音、V6のフレーズ曲線に沿った連続強弱を加える。楽器の数や音量を増やすだけの方法は取らない。

ライセンス、録音の役割、品質測定の限界は [RIGHTS.md](RIGHTS.md)。16録音の出典・ハッシュは `samples-v7.json`。CC0 / VSCO 2 Community Edition。チェロは独奏の録音ではない。専用レガート遷移サンプルを使った演奏でもない。美しさ・心地よさ・感動の程度は、最終的にA/B試聴で選んでいただく。

## 保護・検証

- 全32曲のID・曲名、主旋律3,158音の全イベント（音高・順序・時刻・長さ・強さ・表情）、ピアノの全イベントをV6と照合。残り28曲の楽譜は完全一致、配置50行は変更なし。
- V6のピアノ成分を当時と同じ順序で再構成。元の全体原盤との誤差は−117.48〜−117.73 dB。そこからピアノだけを取り出し、余韻・表情を保持。仕上げは曲全体への一定ゲインだけで、コンプレッサー・リミッターは使わない。
- 夜AはV6 FLAC/AACとSHA-256が一致。夜Bも前半は元のFLACとサンプル単位で一致。弦は後半のみ。
- 新しい弦147音はすべて録音長内、移調は最大2半音、人工ループ0。16原録音と全8音源のクリップ0。
- 不要な鈴・シェイカー・ギターの刻みは追加なし。昼36秒の高音クラリネットも存在しない。

各音源の詳細は `receipts/a/`・`receipts/b/`、集計は `verification/audio-summary.json`。ループは原曲と同じフレーム数。AACのパディングを含むファイル長ではなく、比較プレーヤーのloopEndを楽譜の周期に設定する。

独立した読み取り専用レビューで、保護対象、音域・和声、音源キャッシュ、夜の一致、比較操作を確認し、阻害事項なし。レビュー担当は録音の聴感と実機iPhoneを確認していない。

## 再現と再開

Python 3.12、numpy/scipy/soundfile/mido、FFmpeg 7.1.5。`VSCO_DIR` にV2の429ファイルと `samples-v7.json` の録音を各相対パスに置く。`V7_WORK_DIR` はピアノ抽出WAVの作業ディレクトリ。保護されたV6原盤も必要。

```bash
export VSCO_DIR=/path/to/vsco
export V7_WORK_DIR=/path/to/work
export OPENBLAS_NUM_THREADS=1
python prototypes/bgm-v7-20261114/tools/arrange_v7.py
python prototypes/bgm-v7-20261114/tools/run_v7.py --prepare-piano
python prototypes/bgm-v7-20261114/tools/test_v7.py
python prototypes/bgm-v7-20261114/tools/quality_v7.py
python prototypes/bgm-v7-20261114/tools/verify_v7.py
```

以後は `run_v7.py`（`--prepare-piano`なし）。実サンプルとピアノ中間ファイルを検証してから、楽譜・音響コード・出典・完成音源が一致する曲をスキップする。夜Aは原盤をコピーし、再エンコードしない。各案の `scores-*.json` は保護照合のため32曲を含むが、今回書き出すのはホーム4曲だけ。

ブラウザーテストは `tools/test_compare.cjs`。`COMPARE_URL` でローカルまたは公開URLを指定できる。ローカルでは `bgm-v7/` に `compare/`、`audio/v6/` と `audio/v7/` に各音源ディレクトリを配信する。
