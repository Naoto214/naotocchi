# なおとっち — 採用32曲 BGM 音質改善 VERSION 2

PR #536（VERSION 1 原盤）の 32曲を、同じ 楽譜の まま 描き直した 音源集です。曲・曲ID・曲名・旋律・主要な リズム・テンポ・小節・反復・配置表50行は 変えて いません。
変えたのは 音色・楽器の 割り当て・強弱・定位・残響・帯域・マスタリングです。

- 比較試聴ページ（Claude Artifact・本人限定）: https://claude.ai/artifact/PnXWhCx4YVUfXAGFh7rhn3
- 比較ページの ソース: `compare/index.html`（リポジトリ内では V1 を `../../bgm-master32-v1/audio/`、V2 を `../audio/` から 読む）
- 曲目表（ゲーム統合の 正本）: `catalog-v2.json`（曲ID・用途・配置行は PR #536 の catalog.json と 同じ）
- 検証記録: [VALIDATION.md](VALIDATION.md)、権利: [RIGHTS.md](RIGHTS.md)、作業進捗: [PROGRESS.md](PROGRESS.md)

## V1 が こもって 聞こえた 理由（測定）

| 原因 | V1 | V2 |
|---|---|---|
| 楽器ごとに 2次ローパス（7.8 kHz、ベル 4.3 kHz、フルート 6.5 kHz） | すべての 音に かかって いた | かけない。録音の 倍音を そのまま 使う |
| 3〜6 kHz（輪郭・明瞭さ）の 割合 | −20〜−53 dB（ホーム4曲は −46〜−51 dB） | −17〜−28 dB |
| サンプルの 左右 | 平均して モノラル化 | ステレオの まま。左右の 広がり −21〜−34 dB → −5〜−11 dB |
| 強弱 | ピアノは 弱い 1層だけ | 3層（弱・中・強）＋同音の 連打は ラウンドロビン |
| 残響 | 9本の 反射を 左右反転で 足す 簡易な もの | 帯域ごとに 減衰が 違う ステレオの 残響（高い 音ほど 早く 消える）。ループ曲は 残響の 尾を 曲頭へ 折りかえし、つなぎ目が 切れない |

## 用途ごとの 音づくり

| 用途 | V2 の 楽器 |

| ホーム朝昼夕夜 | 採用アレンジA の 楽譜・楽器（ピアノ＋ハープ／マリンバ）・強さを そのまま。ピアノの 旋律は 強いレイヤー、伴奏は 中間レイヤー。音源の 質・ステレオ・残響・帯域だけ 改善 |
| なおぽよ。 | やわらかい マリンバと ハープ。2周目は フルートが 小さく 寄りそう |
| なおころ。 | ピアノ、自作ナイロンギターの 分散和音、ウッドベース（コントラバスの ピチカート）。2周目は クラリネット |
| CARD GAME | ピアノ・マリンバ・弦の ピチカートの きざみ。2周目は 木琴。終盤は テンポ 156 版（変奏の テンポは V1 の まま） |
| ミニゲーム（汎用・スポーツ・クイック） | マリンバ（2周目に 木琴）、ギター、ウッドベース、やわらかい 打楽器 |
| レース | ピアノと 木琴、マリンバ、ギターの きざみ、ウッドベース、打楽器 |
| パズル | クラリネットの あたたかい 旋律と ハープ |
| ボード・釣り | ピアノと ナイロンギター（釣りは チェロ） |
| 3D 探検 | フルート、ハープ、弦の 持続音。2周目は クラリネットが 1オクターブ下で 支える |
| 3D 飛行・海 | フルートに 1オクターブ上の グロッケン、ハープの きらめき、広い 空間（本人メモ「煌びやかに」） |
| 睡眠・デート・お別れ・思い出 | ピアノと ハープ、チェロと 弦の やわらかい 持続音（睡眠は ハープの 旋律） |
| ジングル | 祝い: ピアノ＋フルート＋ハープ＋ギター＋グロッケン。孵化: トランペット・グロッケン・ティンパニ・シンバル。最後の 余韻と 効果音の すき間は V1 と 同じ 長さ |

旋律の「重ね」は、同じ 音高・同じ リズムで 別の 楽器を 小さく 重ねる だけです（1オクターブ上・下を 含む）。旋律の 音は 足しも 引きも して いません。

## 音源仕様

| 項目 | 値 |
|---|---|
| 原盤 | FLAC 24bit / 44.1 kHz / ステレオ（ホーム4曲も 44.1 kHz で 描き直し。V1 の ホームは 32 kHz） |
| 配信 | AAC-LC / M4A / 44.1 kHz / 192 kbps（V1 は 160 kbps）、movie timescale 44100 |
| 長さ | V1 と 同じ 音楽周期。ループ曲は 0 〜 duration を そのまま 繰りかえす（AAC の 末尾の 詰め物は 再生側で 切る） |
| 音量 | V1 と 同じ 用途別 目標 LUFS（ホーム −23、静かな 用途は 低め、孵化 −19）。true peak −1 dBTP 以下。音圧を 稼ぐ ための 圧縮は しない（先読みリミッターは ピーク保護の 予備で、実際に 働いた 曲は ない） |
| MIDI | V2 の 楽器割り当てで 書き出し（主旋律は 1トラック目）。V1 の MIDI は 変更なし |

## 再制作

```sh
pip install numpy scipy soundfile
GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 --filter=blob:none --no-checkout https://github.com/sgossner/vsco-2-ce   # samples-manifest.json の ファイルだけ 取りだす
python prototypes/bgm-v2-20261112/tools/arrange_v2.py        # V1 楽譜 → scores-v2.json
python prototypes/bgm-v2-20261112/tools/render_v2.py --group 1   # 1〜4。receipt と ハッシュが 一致する 曲は とばす
python prototypes/bgm-v2-20261112/tools/verify.py --audio     # 旋律・ID・配置・V1保護・各曲の 検証値
python prototypes/bgm-v2-20261112/tools/compare.py           # V1/V2 の 比較測定
python prototypes/bgm-v2-20261112/tools/catalog_v2.py        # catalog-v2.json と 比較ページ用 catalog.js
```
サンプルの 置き場所は 環境変数 `VSCO_DIR`（既定 `/home/user/sgossner/vsco-2-ce`）。描画は 乱数の 種も 固定で、同じ 入力から 同じ 音が 出ます。
