## 気づいた こと・残る 確認

- **お別れ（bgm-farewell）は V2 でも 暗め:** 3〜6 kHz が −27.5 dB で、32曲の 中では いちばん 暗いです。低い 音域の ピアノと チェロだけの 静かな 曲なので、補正は 上限（+6 dB）で 止めました。
- **ミニゲーム系は 明るめ:** マリンバ・木琴・ギターを 使う 曲は 3〜6 kHz が −19 dB 前後で、明るめです。疲れない よう、目標を 超えた 分だけ 最大 −6 dB 抑えて います。
- **ピアノの 録音:** VSCO の アップライトピアノは 録音そのものが 暗い ため、ピアノだけ 明瞭さを 補う EQ（3.4 kHz +4 dB、9 kHz 以上 +3 dB）を かけて います。
- **耳での 確認が 必要:** iPhone スピーカーでの 聴こえ方、長時間の 聴き疲れ、ギター（自作合成）の 自然さ。
