# VERSION 3 実装方針

本人指定のA＋Bを今後の基準とし、A配置とB配置の選択は保留。元A〜D・AB画像とVERSION 2資料は無変更で保持する。

1. 共通の装飾原画をABから編集生成。銀の葉と双葉を保ち、9・3・6時の同径小文字盤を追加。
2. 原画へ正確なSVGの数字・60分割目盛り・同径3マーカー・6針を重ねる。A/Bは同じ背景・枠・目盛り・座標を使用し、役割と角度だけ変更。個別再生成による装飾のずれを防ぐ。
3. 60/30/12の文字表示と実際の目盛り本数を区別。標準比較は左60分割、右30分割、下24分割。提案は右を半分刻み60分割にして外観を保ったまま全指定値を表示。
4. そだちの旧換算3°/点と、一周100の3.6°/点を比較。数値と角度・目盛り番号・中間判定を同時表示。端点0と100/12は数値表示で区別する。
5. 新しいv3/ページを既存Siteの入口とし、v2のindex/app/clockを保存して往復できる構成。通常時計は6針のクロノグラフ表示例を別モードで提示。
6. 全有効値の換算・6針・共通背景・旧成果保護・変更範囲を検証。本人限定Siteと既存Draft PR #497へ保存。

計算・座標・目盛りはコードを正本とし、装飾だけ生成画像を利用する。機構・印刷・重なりの実物評価は未実施と明記。サイズは240〜280mmの卓上/壁掛け検討、腕時計用機構の単純拡大はしない。
