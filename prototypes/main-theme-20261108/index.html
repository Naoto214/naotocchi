なおとっち テーマ試聴室

いまの メインテーマと、新しく 作曲した 5つの メロディを 聴きくらべる ページです。6曲とも おなじ 音色・おなじ 音量・おなじ 伴奏型で 鳴らしているので、ちがいは メロディと 和声だけです。

音色 テンポ

譜面

ピアノロールは メロディ 1周ぶん。上の 文字は コード。階名と 曲紹介の 音名は 移動ド（その曲の 主音を ド）で、「ー」は 付点4分以上の のばす音、「・」は 休符。

比較（10点満点・机上評価）

Claude は 音を 聴けないので、旋律の 形・反復・音域・和声の 分析から つけた 予想点です。現行曲には「すでに なじんでいる」強みが あり、この表には ふくめていません。最終判断は 実際に 聴いた 印象を 優先してください。

Claude の 見立て

この 音源の 制約

  • 音は ブラウザの Web Audio で その場で 合成しています。録音した ピアノでは ないので、本物の ピアノより 素朴に 聴こえます。
  • 音色は 6曲 共通です。ちがいが 出るのは メロディ・和声・テンポ・調だけです。
  • 「ゲームの 音で」は 現行曲だけの 参考再生で、audio.js と おなじ 鳴らしかた（三角波・ドラム・2周目の アルペジオ）を なぞっています。
  • iPhone は マナーモードだと 音が 出ません。

MIDI と 譜面データ

  • MIDI: prototypes/main-theme-20261108/midi/（メロディ・コード・ベースの 3トラック）
  • 楽曲データ: songs.js、点検: tools/check.cjs
  • 点検では 現行曲の データが audio.js の TRACKS.home と 一致することも 確かめています。

権利と 制作履歴

  • A〜E案は 2026-11-08 に この リポジトリの ために 新しく 書いた オリジナル曲です。既存曲の メロディは 参照・引用していません。
  • コード進行（下降ベース、IV–V–iii–vi など）は 一般的な 和声の 型で、特定の 曲に 依拠していません。
