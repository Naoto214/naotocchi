# なおとっち BGM VERSION 5（2026-11-15）

採用32曲（PR #534）の 第5版。VERSION 4（PR #543）を もとに、**旋律の 1音ずつの 音量ムラを 整え**、2周目 以降に さりげない 変化を 加え、
「いつもの にわ」36秒付近の「ファー」と 浮く 音を 直した。V4 で 除いた ギターの 刻み・シェイカー・単発の 高音は 戻して いない。

## 守った もの

- 採用32曲・曲ID・曲名・テンポ・拍子・小節数・反復・長さ・ループ指定（V1 と 同じ）
- 主旋律の 音高・開始時刻・譜面上の 長さ・本数（V1 と 完全一致。3,158音）。変えたのは 強さ（vel）だけ
- 配置表 50行と 場面ごとの 曲、変奏の 仕様、V4 の 不要音の 除去・ペダル・離鍵・残響（ホーム夜を 含む）
- V1〜V4 の 音源・楽譜（`verify_v5.py` が ハッシュで 確認）

## 1. 旋律の 音量ムラ

**原因**: 旋律の 1音ずつの 大きさは、VSCO の 録音ごとの 差（同じ 強さでも 音によって 大きさが 違う）、音域の 差、強弱レイヤー、
V3・V4 で つけた 小さな ゆらぎが 重なって、ホーム4曲で 最大と 最小が 16〜18 dB も 開いて いた（標準偏差 約 4 dB）。

**直し方**（`tools/note_level.py`・`tools/arrange_v5.py`）:
1. 旋律と 旋律の 重ねの 1音ずつを 音源ライブラリで 単独に 描き、耳の 感度に 近い 重み（K 特性 相当）で 大きさを 測る
2. フレーズとして 意図の ある 抑揚を 目標に する: 4小節の 山なり（±1.5 dB）、高い 音は 少し 豊かに（1半音 0.12 dB、最大 ±1.5 dB）、小節の 頭 +0.6 dB、
   裏拍の 短い 音 −0.6 dB、フレーズの 終わり −1 dB
3. 目標と 測った 値の 差を 1音ずつ 強さで 補正（最大 ±12 dB）。強い コンプレッサーは 使わない

結果: ホーム4曲で 標準偏差 約 4.3 → 0.7 dB、幅 16〜18 → 3〜4 dB（残った 3〜4 dB は 意図した 抑揚）。全32曲の 値は VALIDATION.md。

## 2. 「いつもの にわ」36秒付近

| 調べた こと | 結果 |
|---|---|
| 34〜39秒に 鳴る 全音 | ピアノの 旋律（F5→E5→F5→A5→**C6**→A5→F5→G5）、ピアノの 和音と 低音、3周目の クラリネットの 旋律の 重ね |
| 浮いた 音 | 36.30 秒、旋律の 最高音 C6 を 重ねる **クラリネット**（旋律の 重ね。主旋律では ない） |
| 原因 | VSCO の クラリネットの 最高音（C6）の 録音が、ほかの クラリネットの 音より 約 20 dB 大きい。持続音なので 打鍵の あとも ふくらみ「ファー」と のびた |
| 修正 | クラリネットの 重ねは A5（81）より 上を 鳴らさない（旋律は ピアノが 弾く）。全体の 音量は 下げて いない |
| 測定 | C6 付近（1,000〜1,100 Hz）の のびて いる 部分 36.55〜36.90 秒: V4 +34.1 dB → V5 +21.8 dB（34.0〜36.2 秒の 平均 比）。V4 は 打鍵（+31.1 dB）より ふくらみ、V5 は 自然に 消える |

同じ 理由で、ほかの 曲でも クラリネットの 重ねの A5 より 上を 外した（koro-1 17音・kisetsu 10音・home-evening 9音・home-day 2音）。

## 3. 単調さ（一定の 刻みは 使わない）

2周目 以降の 静かな ループ曲に、その 時に 鳴って いる 和音の 音だけで 作った 声部を 加えた。旋律と 2度・長7度で 重なる 音は 入れない。

- **内声の 対旋律**（counter）: 和音が 変わる たびに、いちばん 近い 和音の 音へ ゆっくり 動く 長い 音。4小節の 4小節目は 休む（息つぎ・対比）
- **木管の 応答**（response）: 旋律が 2拍 以上 のばす 音の あいだに、のばして いる 音の 3度〜1オクターブ 下の 和音の 音で 2〜3音。2回に 1回だけ、向きを 交互に
- **低音の 動き**（ホームの 朝・昼）: 小節の 低音の 3拍目に 5度を そっと

| 曲 | 加えた もの |
|---|---|
| そよかぜの まど（朝） | 2周目: クラリネットの 内声・フルートの 応答・低音の 5度 |
| いつもの にわ（昼） | 2周目: チェロの 内声、3周目: クラリネットの 内声・低音の 5度 |
| ほしふる みずうみ（夕） | 2周目: ビオラの 内声 |
| ほしぞらの やくそく（夜） | なし（V4 の ピアノ ひとりの まま） |

ほかの 静かな ループ曲（なおぽよ。・なおころ。・デート・きせつ・探検・パズル・ボード・お別れ）にも 内声と 応答を 加えた。
活発な ゲーム曲・ジングル・ファンファーレは 音量ムラの 補正 だけ（場面の 個性を 保つ）。
