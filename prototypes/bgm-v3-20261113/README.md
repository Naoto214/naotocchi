# なおとっち BGM VERSION 3（2026-11-13）

採用32曲（PR #534）の 音質改善 第3版。PR #539（VERSION 2）を もとに、**旋律と 関係なく「チン」「キン」と 鳴る 単発の 高音を 取りのぞき**、
音数を 整理して 生楽器が 自然に 掛け合う 響きに した。新しい 曲や 旋律は 作って いない。

## 守った もの

- 採用32曲・曲ID・曲名・テンポ・拍子・小節数・反復・長さ・ループ指定（V1 と 同じ）
- 主旋律の 音高・開始時刻・長さ・本数（V1 と 完全一致。3,158音）
- 伴奏・打楽器の 音高と リズム（楽器は 替えた。ギターの 和音は 低い 音から 最大 28 ms ずらして 指で はじく 感じに）
- 配置表 50行と 場面ごとの 曲、変奏の テンポ・小節の 範囲・用途
- V1（#536）・V2（#539）の 音源・楽譜（`verify_v3.py` が ハッシュで 確認）

## 原因の 調査

`tools/ping_scan.py`（原盤の 高域の 突出を 時刻で 探し、楽譜の 音と 対応づける）と `tools/stem_probe.py`（楽器・役割ごとに 分けて 描いて 測る）で 調べた。

| 曲 | 原因 | 発生 |
|---|---|---|
| ホーム4曲 | 伴奏に 時々 入る 高音域の ハープ（昼は マリンバ）の 単発音（音高 73〜81、右寄り） | 朝 24音・昼 24音・夕 30音・夜 11音。高域エネルギーの 13〜58% を 占め、鳴った 瞬間 まわりより 最大 約 35 dB 突出 |
| ホーム4曲 | V2 の 高域の 持ち上げ（ピアノ用 3.4 kHz +4 dB・9 kHz 以上 +3 dB、仕上げで 3.8 kHz +4 dB・8 kHz 以上 +5 dB） | 暗い ピアノを 明るく する ための 補正が、ハープの 立ち上がりと 弱い 打鍵の 録音の サー音を 強めた |
| 28曲中 27曲 | V1 の ベルを 引きついだ 単発の グロッケン（role=sparkle） | 1曲 2〜30音 |
| 活発な 6曲 | 2周目に 重なる 木琴 | CARD GAME・アクション・クイック・スポーツ・レース |

調べた 結果、ピアノの 録音（VSCO 2 CE アップライト）は 強い 打鍵（レイヤー3）が いちばん 澄んで いて、3〜6 kHz の 明瞭さを 自然に 持ち、
6〜12 kHz は 少ない。弱い 打鍵の 高い 音には 録音の サー音が ある。V3 は 旋律を レイヤー3 の まま、高域を 持ち上げない。

## 変更

- 単発の 装飾音 500音を 削除（ホーム 89音・28曲 411音）。どの 音を なぜ 消したかは `scores-v3.json` の 各曲 `removed` に 記録。
  たまごが かえる ファンファーレの グロッケンは ファンファーレの 一部なので 残した。
- 高域を 持ち上げない 仕上げ: 3〜6 kHz は 足りない ときに 最大 +2.5 dB、8 kHz 以上は 多すぎる ときに 下げる だけ。
- ピアノの 補正を やわらかく（2.6 kHz +1.5 dB のみ）。ハープ・マリンバ・グロッケン・シェイカー・シンバルの 6〜7 kHz 以上を 少し 丸める。
- 木琴の 重ね → マリンバ。静かな 曲は 同じ 楽器の 中で 強さの 外れ値を おさえる（突然 大きな 音を 出さない）。
- 旋律に 人が 弾く ような 強弱（4小節の 山なり ±7%・拍の 強弱・ごく 小さい ゆらぎ）。
- ホーム4曲（伴奏の 音は そのまま、楽器だけ 替えた）:

| 曲 | V3 の 楽器 |
|---|---|
| そよかぜの まど（朝） | ピアノの 旋律、ナイロンギターの 和音、ウッドベース。2周目は フルートが そっと 寄りそう |
| いつもの にわ（昼） | ピアノの 旋律。和音は ピアノ → ギター → 両方と 受けわたし、ウッドベース。2周目 クラリネット・3周目 フルート |
| ほしふる みずうみ（夕） | ピアノの 旋律。和音は ピアノ → ギター、チェロの やわらかい 低音。2周目は クラリネット |
| ほしぞらの やくそく（夜） | ピアノ だけ（伴奏は 弱い タッチ） |

## ファイル

- `audio/<id>.flac`（24-bit/44.1 kHz）・`audio/<id>.m4a`（AAC 192 kbps）・`midi/<id>.mid`・`receipts/<id>.json`（ハッシュと 検証値）
- `scores-v3.json`（V3 の 楽譜。削除した 音の 記録つき）、`ping-metrics.json`（V2/V3 の 高域の 目安）
- `tools/arrange_v3.py`（編曲）・`tools/render_v3.py`（描画。V2 の 描画部品を 使い 設定だけ 変える）・`tools/verify_v3.py`（点検）
- `tools/ping_attrib.py`（目立つ 高音の 立ち上がりを 楽譜の 音に 結びつけて 数える）

## 作り方

```
python prototypes/bgm-v3-20261113/tools/arrange_v3.py
python prototypes/bgm-v3-20261113/tools/render_v3.py --stage 1      # ホーム4曲
python prototypes/bgm-v3-20261113/tools/render_v3.py --group 2      # 2〜5（7曲ずつ）
python prototypes/bgm-v3-20261113/tools/verify_v3.py --audio
```

サンプルは V2 と 同じ VSCO 2 CE（CC0-1.0、固定コミット）。ギターは 自作の 物理モデル。権利は `../bgm-v2-20261112/RIGHTS.md` と 同じ。
自動の 測定は 目安で あり、実際の 聞こえ方は 本人の 試聴で 確かめる。
