# PR #418 — 魔法門からトゲを避ける斜め移動

対象: `6d4a2dc63a53c143d191181cd2bbb5bbaf0d4672` の続き。開始時remote mainは `2ed423e81ac83631048df028e9aafe5dce5b2958`。main・本番Pagesは変更しない。

## 根本原因

座標はエンジンと同じ0始まり。ステージ07で犬を合体して `(3,2)` の門へ移動すると、犬2になる。トゲは `(4,2)`。

- 門 `(3,2)` → 右上 `(4,1)` は、隣の壁 `(3,1)` を `engine.mjs` の `solid()` が検出して拒否。
- 門 `(3,2)` → 右下 `(4,3)` も壁 `(3,3)` により拒否。
- 逆方向も同じ壁で拒否。トゲは `solid()` に含まれていない。
- 前回テストはトゲに一度入って再合体した `(4,3)` から始まり、門そのものからの退出を検証していなかった。
- 今回は実配置で合体→門通過→斜め退出→帰還を再現し、変更前の4テストの失敗を確認した。

## 修正

エンジンの角抜け・通行条件・入力補間は変更しない。実際の壁配置を最小限ずらす。

| 面 | 壁の変更 | 通れる往復 |
|---|---|---|
| 07 | `(3,1)→(2,1)`、`(3,3)→(2,3)` | 門 `(3,2)` ↔ `(4,1)` / `(4,3)` |
| 10 | `(3,1)→(2,1)` | 門 `(3,2)` ↔ `(4,1)` |
| 12 | `(3,1)→(4,1)`、`(3,3)→(4,3)` | 門 `(3,2)` ↔ `(2,1)` / `(2,3)` |

10の右下 `(4,3)` は壁そのものなので禁止のまま。12では条件を満たすかえる1が対象。かえる2は門へ入れない。

閉鎖門での全探索は07/10/11/12とも exhausted・救出0。壁や不一致門の角抜け禁止、8方向、門の個別条件、トゲ実進入時の分裂は維持。

`store.mjs` は変更前の正確な地形を追加で受理するだけ。version1・保存キー・データ構造を変更せず、旧状態・Undo・キャラ配置を保持。新しい壁の位置に旧キャラがいても消さない。旧途中データは旧地形で続行し、既存の案内どおり「はじめから」で新通路になる。
