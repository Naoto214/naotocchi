# 03. 実装不一致候補（C）

## 結論
**確定した、または強く疑われる実装不一致は 0 件です（C = 0）。**

## 調べた範囲と方法
- 静的照合: 全452枚について、カタログ本文 ↔ 宣言的プログラム（RULES 438 + 旧実装 cards.mjs 14〜15）。回数制限（H1）、数値の対応（H2/H3）、「能力なし」にプログラムが付いていないか（H4）、参照カード名（H7）、用語（H5）、体裁（H11）。
- 全452枚: 実装あり 452（RULES 438、LEGACY 14）。実装なし 0。画像 904枚中、対応ファイル欠落 0。
- 既存テスト: 選定した node:test **217/217 PASS**（`evidence/existing-tests-217.log`）。
- 静的フラグ 100 件超は、全件を目視で確認し**誤検知**と判断しました（理由は `cards-452.csv` の note 列）。代表例:
  - 「1ラウンドに1回」の防止・置換カード7枚（C-hedgehog ほか）は、プログラム側に `once` が無い。これは防止の共通機構が1ラウンド1回を保証するため。C-hedgehog は `tests/replacements.test.mjs` が「1回目は防止、2回目は防止されず15」を直接確認している。他6枚は同じ共通機構に依存（証拠M）。
  - 本文の数値がプログラムに直接現れないもの（34枚）は、閾値が条件（op/n）や段階・枚数の別表現で保持されている。

## 証拠が弱い範囲（正直な限界）
- 直接テスト参照が無いカードは223枚（メイン125、あそび50、できごと14、あいてむ14、なかま10、こいびと5、セカイ5）。これらは種類別の共通テストと宣言的プログラムの静的一致で担保され、**カード個別の挙動テストはありません**。「不一致がある」という意味ではありません。
- 静的調査では、同時誘発・連鎖順序・複数効果の相互作用など**実行時にしか分からない問題は検出できません**。疑わしいカードがなかったため、今回は再現テストを新設していません。
- 提案: 無い直接テストを埋める軽量な表駆動テスト（IMP-07、テストのみ）。
