# 06. 優先順位付き改善案

**すべて提案のみです。採用・実装は本人判断を待ちます。** 優先順位は指定順（1 重大不一致 → 2 保存・結果に影響 → 3 初心者が誤解 → 4 ルールブック/本文の不整合 → 5 UI → 6 軽微表記）。
区分: 【本文のみ】= カード本文（と版管理）だけで済む／【資料のみ】= docs だけ／【テストのみ】／【処理変更】= ゲーム処理の変更。**【処理変更】は今回ゼロ**です。

優先順位1・2（重大な実装不一致、保存・対戦結果に影響する不具合）: **該当なし**（C=0）。

---
## IMP-01（優先4）旧設計資料の旧新関係が不明【資料のみ】 / D
- 現行: `docs/card-game-design-current.md`（2026-09-13）が「最新仕様の正本」と自称。内容に「ときとばし」「本編で解禁」等の旧仕様が残る。`docs/card-game/01-core-rules.md` 冒頭にも「解禁」の記述。
- 問題: 読んだ人が旧仕様を現行と誤解する。ルールブックは「全452枚を最初から使用」「ときおくり」。
- 裁定の根拠: 118（ときおくりへの用語移行）、現行ルールブック第1・3章。`docs/card-game/README.md` は同ディレクトリを SSOT と明記。
- 改善案: 冒頭に「設計初期の資料。現行はルールブック（rulebook-content.mjs）と docs/card-game/README.md」と1段落の注記。本文は書き換えない。
- 実装影響: なし。保存互換: なし。CPU判断: なし。
- 必要なテスト: なし（docs内に tools/pages の allowlist 影響が無いことだけ確認）。
- 推奨: 中。

## IMP-02（優先4）出典対応表の本文2件が旧版【資料のみ】 / D
- 現行: `docs/content-provenance-20261021/cards.csv` の G-doodle-jump（#452 で改訂）、P-rock_octopus（#449 で改訂）が旧本文。実装・カタログは新本文で一致。
- 問題: 出典表を根拠に監査する人が旧本文を現行と誤認する。
- 根拠: 477（G-doodle-jump 新本文）、#449。
- 改善案: CSVの2行だけを現行本文に同期、またはCSVに「作成時点の本文」と明記。
- 実装/保存/CPU影響: なし。必要なテスト: 出典表を参照するテスト（あれば）の再実行。推奨: 低〜中。

## IMP-03（優先4）「発動コスト」の定義語がルールブックに無い【資料のみ。または本文のみ】 / B
- 現行: 7枚（G-bubble-shooter, G-darts-board, G-jenga-tower, G-shanghai-tiles, G-stack-leaves, G-street-fight, M-phoenix-06）が「発動コスト」。第8章は「時コスト」までで、手札・準備枠を払う追加コストの語を定義していない。
- 問題: 初心者が「時コスト」との違いを推測しにくい。
- 根拠: 該当カード自身の本文（意味は明確）。新裁定は作らない。
- 改善案: (a) ルールブック第8章に「発動のために手札や準備枠のカードを払うものも『発動コスト』と呼ぶ」の一文（**ルールブック変更は本人判断**）、(b) 本文は現行維持。カード本文の変更は不要。
- 実装/保存/CPU: なし。テスト: rulebook 構造テスト（章・出典）。推奨: 中。

## IMP-04（優先3）曖昧さのある本文7枚の明確化【本文のみ】 / B
- 対象: G-lunar-lander, G-submarine-3d, M-venus_flytrap-03, M-venus_flytrap-08, M-sakura-06, M-star-03, M-man-04（理由は `04-…md`）。他に G-area-claim ほか表記ゆれ系はIMP-05。
- 改善案: 条件・コスト・回数制限・数値を残したまま、文の区切りと語順だけ整える。具体文案は採否判断のあとに作成（今回は不採用前提のため作らない）。
- 実装影響: 本文のみ。カタログの完全一致・sha256テストの更新が必要。
- 保存互換性: doc 477 の方式に従い**新版（例 hotseat-5）＋旧保存は旧本文のまま再生**。旧版名をテストに残す。
- CPU判断: 変わらない（プログラム不変）。
- 必要なテスト: catalog.test の期待更新、該当カード回帰、旧版保存の再生、本文長140字境界の表示確認（M-sakura-06）。
- 推奨: 中。**まとめて1回の版更新にする**（版を何度も上げない）。
