https://claude.ai/artifact/NCuzyP2R6yr1s2npApvqEn

- claude.ai の本人アカウントだけが開ける非公開ページです。
- 正式版とは保存領域が別です（`naotocchi-detail-stage-trial:` で始まる鍵）。正式版の対戦・戦績・マイデッキには触れません。
- ゲーム本体は、このブランチの正式ファイルそのものです。切り替えで変わるのは、詳細画面を描く1か所だけです。

### 使い方

1. 開始画面の一番上「カード詳細 比較試遊版」で **新UI／現行** を選びます。既定は新UIです。
2. 「比較用の場面から始める」で場面を選びます（「ひとり（CPU）」と「ふたり」があります）。
   - たまごの手札交換（必須選択）
   - 通常手番
   - 応答中
   - 3択の対象指定
   - 4つの装備先
   - 宣言
   - 連鎖中の応答
3. 手札のカードを押すと詳細が開きます。右上のボタンで、同じカードのまま新UIと現行を切り替えられます。
4. 新UIでは、カードをダブルタップすると拡大・縮小します（縦画面はツールバーの「＋ 拡大／－ 縮小」でも同じです。ピンチも使えます）。
5. 「新しい対戦を開始」から、ふつうの対戦もできます。

試遊版では、保存ファイルの書き出し（ダウンロード）は動きません。公開先の制限によるものです。

## 新UIの構成

| 領域 | 内容 |
|---|---|
| 上部 | 現在の状況（例「Aのターン・選択待ち」「Bのターン・Aの応答待ち」）、拡大・縮小（拡大で大きさが変わる時だけ表示）、「盤面へ ×」 |
| 中央 | 正式カード。画面の空きに合わせて大きく表示し、名前・コスト・イラスト・能力本文はカードの上で読む |
| 横画面 | 左にカード全体、右に状況・「盤面へ ×」と操作ボタン。カードは押した時だけ拡大し、もう一度押すと戻る（拡大・縮小のボタンは出さない） |
| 下部 | 必要な操作ボタンだけ。主文は大きく、結果が分かりにくい時だけボタンの中に「※」の小さな補足 |

カードの外に出していた次の表示はなくしました。

- カード名・分類・通常時コスト・レアリティの再掲
- 能力本文の全文再掲
- 「関連ルールを読む」
- 「必須選択：このカードを選ぶ」
- 「たまご：手札から選び、山札の下へ戻す」などの説明欄

ルールブックは、開始画面と対戦メニュー（☰）から開けます。

### ボタン内の補足の決め方

補足は、正式の表示処理がすでに持っている情報だけから作っています。新しいルール判断はしていません。

| 操作 | 主文 | 補足 |
|---|---|---|
| たまごの手札交換など、山札の下へ戻す選択 | 「きまぐれなねこを選ぶ」 | ※ 山札の一番下へ戻します |
| 支払いで捨て札へ送る選択 | 「〜を支払いに選ぶ」 | ※ 支払いとして捨て札に置きます |
| 発動の対象・支払いを選ぶ | 「〜を選ぶ」 | ※ （効果名）の対象にします ／ ※ 支払いに使います |
| 空いている場所に出す・配置する（装備を含む） | 正式の文言（例「まねっこサルをなかまへ」） | ※ 配置先：なかま① |
| 場のカードと入れ替えて出す | 正式の文言（例「〜を出す／きまぐれなねこと交代」） | ※ なかま②のきまぐれなねこと入れ替えます |
| パス・ちょうせん・宣言など | 正式の文言 | なし |
