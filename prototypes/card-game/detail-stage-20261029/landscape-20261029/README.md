# 横画面：基本盤面とカード詳細をスクロールなしで全部表示（2026-10-29）

本人の評価「縦画面は非常に良い」を受け、**縦画面はそのまま**、横画面だけを直しました。

方針: 横画面では、基本盤面もカード詳細も、小さくなってよいのでスクロールなしで全体が収まるようにする。カードは必要なときだけ拡大して読む。

- 比較画像（左: 修正前、右: 修正後）: [COMPARISON.md](COMPARISON.md)
- 操作QA（横画面5サイズ）: [stage-ops-landscape.json](stage-ops-landscape.json)（62/62 PASS）
- 測定: [before.json](before.json)・[after.json](after.json)（`capture.mjs`）、追加確認 [checks.json](checks.json)（`checks.mjs`、179/179 PASS）
- 測定はすべて Chromium（Playwright、タッチ・モバイル表示、2倍密度）。実機 iPhone Safari では未確認です。

## 変更内容

| 画面 | 修正前 | 修正後 |
|---|---|---|
| 基本盤面 | 盤面の欄の高さが足りず、844・852・932・667 で盤面の中に縦スクロールが出ていた | 盤面の各マス（3段）を画面の残りの高さで等分し、マスの中のカードはマスに収まる大きさで表示。山札・発動領域・捨て札の欄も同じ高さに収め、低い時は山札の小さな絵を省いて枚数を必ず見せる |
| カード詳細 | カードは本文が読める大きさ（304×456）で、下側はスクロールした先 | 左にカード全体（縦横比そのまま、枠・下端まで）、右上に状況・拡大・「盤面へ ×」、右に操作ボタン。カードは画面の高さに収まる大きさ |
| 拡大 | 同じ | カード（または「＋ 拡大」）を押すと幅いっぱいに拡大し、カードの部分だけスクロールして読む。「－ 縮小」かカードをもう一度押すと全体表示に戻る。拡大は表示だけで、対戦状態・保存は変わらない |

変更したのは `style.css`（横向きの盤面と詳細の配置）と `ui-viewport.mjs`（横向きの詳細は常にカード全体が入る大きさ）だけです。縦向きの規則には触れていません。
