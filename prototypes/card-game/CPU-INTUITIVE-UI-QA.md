## 変更

1. 相手のたまご置き場を3×3の下、反転済みメイン列の自分寄りへ移動。管理列の余白も合わせる。自分側・slot ID・カード方向は不変。
2. 自分または相手のメインをタップすると、その時点で合法な「ちから／ちえでちょうせん」が詳細に出る。既存エンジンは両者のメインを参加者として選ぶため、なかま等への新しい対象ルールは追加しない。
3. 自分のこいびと枠のカードから合法な「交際を進める」を直接表示。通常は時1。軽減・増加があればエンジンの合法候補・ラベル・確認画面の見積もりをそのまま使う。UI側でコストを固定・再計算しない。
4. 時コストの丸を19→22cqw、数字を16→18cqw、太さ900・判別しやすいサンセリフ数字へ。金縁とアイボリーを保ち、背景を不透明化して濃い数字を載せる。分類14色と数値0〜8は変更なし。見出し右側の既存23%の余白に収める。

cardActionsは安全な投影のv.actionsから既存オブジェクトを選ぶだけ。行動IDの生成・状態変更・コスト判定は行わない。
既存のprepare/commit/engine.actを通し、支払い確認・最新revision・二重実行拒否を維持する。
新しい操作があるメイン／こいびとは盤面から直接操作詳細へ。他の閲覧・効果本文・管理領域の読み取り専用詳細は維持。
光るカードの表示にも同じ対応付けを使用。CPU判断モジュールは無変更。
