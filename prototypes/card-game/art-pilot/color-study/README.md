## 方法と客観比較

sRGBを線形化しOklabへ変換、全91組を比較。値は便宜上 ΔEOK×100。CIEDE2000とは異なり、値を識別合否の閾値には使わない。色覚特性はMachadoのseverity 1.0行列を線形RGBへ適用、色域外をclip。protan/deutan/tritanの模式的比較で、全ての個人差・重症度・ディスプレイを代表しない。Tritanモデルには原資料記載の近似制約がある。

|---|---|---|---|---|

|candidate|7.81 / 23.15|0.56|1.83|3.03|
|improved|7.81 / 22.45|1.66|1.83|3.03|

### 重点6組：通常視の元色 / 実描画の枠色

枠色は600pxカード左端ROI x14–17,y400–499の中央値。白い重ね色を含む一地点の参考測定であり、全画素を代表しない。実描画では元色の差が概ね半分程度に圧縮される。

|組み合わせ|現行 元色→枠色|新案 元色→枠色|所見|
|---|---|---|---|
|むし × なかま|10.57 → 4.86|19.97 → 9.68|黄色と黄土色に分離し明確に改善|
|ひと × こいびと|11.29 → 5.47|15.84 → 7.80|淡いピンクと深いローズへ分離|
|みずべ × セカイ|9.34 → 3.96|20.01 → 8.95|明るいターコイズと落ち着いた青灰に分離|
|けもの × あいてむ|8.67 → 4.19|19.62 → 8.98|濃茶と明るいベージュに分離|
|あそび × なかま|6.21 → 3.19|9.05 → 4.30|改善するが、暖色同士の近さは残る|
|うみ × ふしぎ|17.13 → 7.25|25.62 → 10.20|明るい青と暗い藍紫へ分離|

新案の通常視で最も近いのは「あいてむ×できごと」（7.81、枠色3.35）。なかま×あそびも注意（9.05、枠色4.30）。ただし、できごとを暗くするとセカイへ近づくため、その変更は見送った。改善案でもprotanではひと×できごと、deutanではひと×あいてむ、tritanではくさ×セカイが近い。色だけで14分類を保証できない。

新案のうみ×げんそうはprotanで0.56。げんそうを #B58BE3 とすると9.80へ改善し、通常視でも18.38。紫らしさを保ちつつ柔らかいラベンダーにする。明るさの上昇により白線アイコンの見やすさは下がるため、次項の線色提案を併記する。

## 10観点の評価

|観点|評価|
|---|---|
|14色相互|新案・改善案は現行より役割が明確。全組み合わせの完全分離は不可。|
|色相・明度・彩度|改善案は明るい黄、濃い藍紫、低彩度の道具・できごと、高彩度の属性を配分。L/C/hはmetrics.json。|
|80/110px|110pxでは黄/緑、茶/ベージュ、青/藍紫の差を視認。80pxは細い枠だけでの判断が弱く、マークと分類名の併用が必須。本文は拡大表示で読む。|
|色覚特性|紫1色の修正は青との特定の混同を緩和。残る近似色には形状・分類名が必要。|
|金縁・植物|黄色は金に近いが、金縁は装飾、甲虫マークは意味情報として分離。紙調で高彩度が和らぐ。|
|絵本アート|実カード8枚の専用アートで調和確認。紫の彩度を少し下げる改善案が柔らかい。美的評価は制作判断。|
|深緑盤面|元色だけでなく淡い紙調のカード面が境界を確保。濃い藍紫の元色を直接盤面へ置くと弱いため、現行の紙調と金縁を保つ。|
|青銀裏面|裏面は無変更。青・ターコイズ・藍紫がつながり、暖色側は金縁・紙色で統一。|
|属性とカテゴリー|属性はメインだけの紋章、その他はカテゴリー名で区別。14色を14属性として扱わない。カテゴリーの未承認マークは追加しない。|
|452枚へ展開|8属性＋6カテゴリーのトークン対応を維持。今回の14代表は配色判断用で、452枚の全背景相性を検証したとはしない。|
