## 今後の8段階制作ルール

1. まず正本8姿の不変要素と変化を一覧化する。体型・色・模様・個体数を情景より優先する。
2. 各段階に生態と整合する一つの行動を割り当てる。休息・移動・遊び・摂食・保護などを種族に応じて選び、全種族を同じ8場面にしない。
3. 隣接2枚では、行動・視点・画面内の位置・距離・環境構造のうち原則2項目以上を変える。ただし変態そのものが十分に明確な場合、同じ場所を成長の連続性として残してよい。
4. 色や時間帯だけの変更、毎回中央・同方向・同じ比率の全身像、毎回同じ花/イソギンチャクの囲い込みを避ける。
5. 小さな生活圏から外へ、活動から休息へなど、種族固有のつながりを作る。成熟を必ず巨大化・英雄化で表現しない。
6. 8枚を名前なしで並べ、80px/110pxでも主役のシルエットと場面の大区分が分かるか確認する。細部だけの差なら構図から見直す。
7. 正本との照合、身体欠損・余剰部位・画面端の切れを確認し、問題のある画像だけ修正。旧版と理由を残す。
8. 画風・テンプレート・14色・マーク・裏面は共通資産を再利用し、イラストに文字や記号を焼き込まない。

この基準は残りメイン216枚へ、行動・視点の考え方は他カテゴリー190枚へ適用予定。ただし今回残り406枚は制作せず、再開は次回の指示を待つ。
