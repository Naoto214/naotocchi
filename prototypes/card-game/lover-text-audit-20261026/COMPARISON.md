## 3. 重点確認A〜E

### A. 交際段階の誘発（交際0→1→2→3→結婚）

| 出来事 | 正式ルールでの名前 | 実装の出来事 | 参照するこいびと |
|---|---|---|---|
| 出して交際0を始める | 交際を始めた時 | `place` | ねこ社長 |
| 0→1 | 交際段階が進んだ時 | `progress` | クモ |
| 1→2、2→3 | 交際段階が進んだ時 | `progress` | クモ、シカ |
| 3→結婚 | 結婚した時 | `marriage` | にんぎょ（**実装ではクモも**） |
| 進行も結婚もしないターン | — | 履歴に両方が無い | うし |

- 【事実】本文の上では、18種類すべてが「交際段階が進んだ時」と「結婚した時」を区別している。
- 【事実】混同はクモの実装だけにある（`remaining-rules.mjs:109`）。
- 【事実】うし・ロボットは、本文で「交際段階」と「結婚」を別々に書いている。良い例として、ほかのカードの書き方を変える必要はない。
- 【事実】ヤギと世界樹②の「交際を進める」は誘発ではなく、交際進行という行動を指す。3→結婚の行動も含む（01:180）。

### B. 結婚後の効果

| カード | 結婚後 |
|---|---|
| ワシ | 次の自分のターン開始時から、毎ターン1枚引く。結婚した瞬間には引かない |
| ロボット | 交際3と同じちから+1が続く |
| にんぎょ | 結婚した時の1回だけ |
| うし | 結婚済みでも、そのターンに結婚していなければ使える |
| ヤギ・シカ・クモ | 進む先がないので、交際関係の効果は使えない |
| その他10種類 | 交際段階と関係なく、結婚前と同じ |

- 【事実】交際3と結婚を同じ状態として書いた本文はない。ロボットは「交際段階が3、または…結婚している間」と、2つを別の状態として並べている。

### C. 別れ・離婚と、除去・防御・回収

| 場面 | 関わるカード | 結果 |
|---|---|---|
| 相手の「すれちがい」で手札へ | サボテン（装備が無ければ防げる）、らぶれたー（捨てれば防げる）、ゆきだるま（手札で発動） | 防げば関係が続き、−10もない。防がなければ別れ／離婚で−10 |
| 相手の効果でこいびとが捨て札へ | ゆきだるま（捨て札で発動） | −10は残る。【事実】現行カタログに、相手のこいびとを捨て札へ送る本文は無い（「相手の…捨て札に置く／手札に戻す」を全件検索。75 §3、94〜96） |
| 相手の効果でメインが捨て札へ | クマ | メインだけの離脱では関係は続く（01:183） |
| 回収 | にんぎょ（セカイ）、ゆきのせいれい（メイン）、りゅう⑧（捨て札のこいびと） | 回収は手札まで。直接置き直さない |

- 【事実】本文の上で、別れ・離婚の−10を消すと書いたカードはない。
- 【事実】サボテンとらぶれたーは、どちらも「相手の効果で手札に戻る」時だけ働く。らぶれたーをサボテンにみにつけると、サボテンの防止は使えなくなる（装備があるため）。らぶれたーをメインにみにつければ両方を持てる。

### D. 対象と確認の時点

- 「自分／相手」「この恋人（このカード・このこいびと）」「メイン」「なかま」は、18種類とも読み分けられる。
- 表記ゆれ: ねこ社長・ヤギ・にんぎょは「このこいびと」、シカ・ワシ・ロボット・ゆきだるまは「このカード」。意味は同じなので、今回は直さない。統一するかは判断事項（README）。
- 条件の確認時点（発動時か解決時か）は、カード本文には書かず、共通ルール（06、93）に従う。にんぎょ・ゆきのせいれい・タコの対象は発動時に固定し、消えても選び直さない（75 X06・X07）。本文に「選び直す」処理を加える必要はない。

### E. 文字数と小さい画面

| 文字数 | カード |
|---|---|
| 44〜65字 | ワシ、ワニ、ねこ社長、にんぎょ、サボテン、ひまわり |
| 66〜90字 | ロボット、ヤギ、シカ、アンコウ、サソリ、クモ、クマ |
| 91〜124字 | ゆきのせいれい（98）、ゴリラ（107）、うし（109）、ゆきだるま（117）、タコ（124） |

- 【事実】カード表面は、本文が140字を超えると `long-copy` という縮小表示になる（`ui-presentation.mjs:114`）。18種類とも140字以下。タコの改善案（132字・追加案138字）も140字以下。
- 【推論】長い5種類は、条件を省くと意味が変わる。カード本文は変えず、ルールブックと用語説明で補う方がよい。
