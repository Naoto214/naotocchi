## 表示仕様

| 場面 | 本文 | その他 |
|---|---|---|
| コレクション・デッキ一覧・手札・通常盤面 | 表示なし。短縮・冒頭もなし | B3-A/V8の顔を保持。名前1行、補助名、分類、コスト、ちから/ちえ、菱形、NAOTOCCHI |
| 選択・詳細 | 正式全文 | 横長原画全体、能力名、条件、結婚時の効果、独立したクリーム本文欄。必要な高さだけ伸び、画面全体をスクロール |
| たまご通常 | 表示なし | 正式画像・淡い青。コスト・能力値・レア・投入上限なし |
| たまご詳細 | 正式説明全文 | 状態表示・デッキ外であることを表示 |

通常面はV8レンダラーを再利用。14色・二重金枠・植物・補助名位置・数字の光学補正を変更しません。本文なしの通常面と本文ありの詳細カードを同じカードで並べます。詳細画面は本体と本文欄を連続した読書領域にし、2:3比率に文章を押し込めません。

手・脳素材はV8に保護され、能力値比較・対戦UIの選択肢に残しています。通常は文字ラベルと数値のみ。画像は新規生成・加工せず、通常面でcover/containを比較。詳細は原画全体を優先します。

## レアと投入上限

`policy.mjs` は、現在のレア76枚に対応する**ID別上限1**と既定上限3を固定した独立メタデータです。実行時に `rare` から再計算しません。全459枚で現行上限と一致。レアフラグを反転してもこの上限表は変化しないことを検証しました。試作デッキ編集と詳細表示はこの表を読み、レアリティと「同じカードIDで○枚」を別欄に表示します。1/2/3の検証値は正式ルール・実デッキ・試作デッキへ適用しません。

**正式ゲームの `rare` は見た目専用ではありません。** 現行engineの投入制限、レアを参照するカード効果、CPU評価でも使用されます。正式エンジン・CPUは変更していません。将来の統合時は、投入制限の参照だけを共通の `deckLimit(cardId)` へ移し、レアに依存する能力やCPU判断を維持する必要があります。既存の保存ID配列を変える必要はありません。詳細はV8の `RARITY-DESIGN.md` を参照。
