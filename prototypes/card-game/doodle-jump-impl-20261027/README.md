動作：使うと予約 → 次の合法なときおくりで1枚 → 段階がちょうど1つ上がった時だけ+5 → 予約はその1回で消える。2段階以上はドローのみ。ときおくりしなければターン終了で失効。たんじょう・へんしんでは発動せず予約は残る。応答・連鎖・他カードのプレイ・保存復帰では消費されない。しばいぬ等、他のときおくり関連カードの処理は変えていない。

## 3. CPU判断の最小修正（`cpu-observation.mjs`・`cpu-policy.mjs`、`POLICY_VERSION` は据え置き）

- 観測：ときおくりを待つ予約カードの候補に、**カードを払った後も払えるときおくり**の段階差の一覧（`timeSkipAfter`）を付ける。ときおくり候補には、自分の予約が足すそだち（`timeSkipBonus`、1段階なら+5）を付ける。自分の盤面・手札・時だけを使う。
- 評価：`timeSkipAfter` が空（相手ターン・応答中・時不足・ときおくり先なし）なら −20（使わない）。ある時は「ドロー＋（1段階が可能なら+5）」を評価し、そのときおくりより先に使うよう、払えるときおくりの最高評価を加える。ときおくり候補は `timeSkipBonus` を加点。
- 時の機会費用：同じときおくりが軽減後の安い候補で残る場合（カブトムシ④）は、その高い候補を「失う選択肢」に数えない。
- 評価係数全体・探索方式は変えていない。初級は従来どおり上限12の評価なので、使える場面でも中級より使わないことがある（難易度差を維持）。
