## B1 の効果（既存の比較結果を再利用。新たな大量対戦はなし）
正式実装は実験版と試合単位で同一なので、PR #491 の E1 の結果がそのまま当てはまります。
- 中級の能力値一致率：50% → 100%
- 単独効果（相手が初級の組）：そだち +0.36 [+0.10, +0.61]、勝点 +0.016 [+0.005, +0.026]
- 初級に対する中級の勝点：0.552 → 0.568
- デッキ間の勝点の変化：±3.1 ポイント以内
- 能力値を選ぶカードがないデッキ（メイン成長・なかま・こいびと・そだち獲得）は、試合が一切変わらない
- 判断時間の増加はない
