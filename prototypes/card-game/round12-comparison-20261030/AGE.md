# 「10ラウンド＝100歳」との整合性（年齢設定は変更しません）

現行の正式設定：「全試合10ラウンド固定。R10終了＝100歳。メイン8段階とは別概念」（`docs/card-game/01-core-rules.md` §「10ラウンド＝100歳」、ルールブック「10ラウンド＝100年」）。
ここで比べるのは、**12ラウンドを採るとした場合に年齢をどう語るか**です。今回は年齢設定を正式に変更しません。

## 年齢が出てくる箇所
- ルール本文・ルールブック・チュートリアル：「10ラウンド＝100年／100歳」「R10の最後に…」
- カード：**50さいのお祝い**（R5で発動）＝「1ラウンド＝10年」を前提にした本文。**なおとのおまもり**（第7ラウンド以降）・**さいごのじかん**（R10）も、「70代以降」「人生の最後」と読める。
- 「100」はもう1か所、**そだち100（100維持の早期勝利）**にも出てきます。年齢の100とそだちの100は別物ですが、どちらも「100」です。

## 3案の比較
| 観点 | A：10R＝100歳（現行） | B：12R＝120歳 | C：12R＝100歳（1R≒8.3年） |
|---|---|---|---|
| 1ラウンドの年数 | 10年（きりがよい） | 10年（きりがよい） | 8.33…年（端数） |
| ラウンド末の年齢 | 10, 20, …, 100 | 10, 20, …, 120 | 8, 17, **25**, 33, 42, **50**, 58, 67, **75**, 83, 92, 100 |
| 50さいのお祝い（R5） | R5＝50歳で一致 | R5＝50歳で一致 | 50歳はR6。**本文の変更が必要**（カード変更） |
| なおとのおまもり（R7以降） | 70歳以降＝人生の後半 | 70歳以降。ただし終盤6ラウンド分に効く | R7＝58歳以降となり「晩年」の印象とずれる |
| さいごのじかん（R10） | 最後のラウンド＝100歳で一致 | R10＝100歳は「最後」ではない。**裁定か本文の変更が必要** | R10＝83歳。同上 |
| 「100歳まで生きる」到達感 | 最終比較の瞬間が100歳 | 100歳の後に2ラウンド続く。「100歳」の節目が試合の途中に埋もれる | 最終比較の瞬間が100歳のまま |
| 世界観の説明しやすさ | 「1ラウンド＝10年、10ラウンドで100歳」と一言で言える | 「120歳まで」は長寿の物語として不自然さが残る（ただし、なおとっち世界は架空なので、「長生きモード」と名乗れば成り立つ） | 「1ラウンド約8年」は覚えにくく、年齢を数えにくい |
| 時計との相性 | 弱い（10は時計の目盛りと合わない） | 中（12ラウンド＝時計の12目盛り） | 強い（12時間で一周＝一生、を100歳に重ねられる） |
| メイン8段階との関係 | 別概念のまま（8段階は年齢と対応しない） | 同左 | 同左 |
| テンポ（実験結果は REPORT.md） | 基準 | 試合が長くなる | Bと同じ（年齢の呼び方だけの違い） |

## 所見
- **整合性が最も高いのは A（現行）。** 「1ラウンド＝10年・最後が100歳」、カード3枚の本文、ルールブック・チュートリアルがすべて一致しています。
- **B は年齢の刻みと既存カード（50さいのお祝い）を保てますが、「100歳で人生を終える」という最終比較の物語が崩れます**（100歳の後にR11・R12がある）。採るなら「長生きモード（120歳）」のような**別モードとしての名前**が要り、さいごのじかんの裁定（R10のままか、最終ラウンドか）が必須です。
- **C は「最後が100歳」を保てますが、1ラウンドが端数の年数になり、50さいのお祝いの本文変更が避けられません**（カード変更は今回禁止）。時計の12目盛りとの相性は最も良いものの、年齢を数える体験としては A・B より分かりにくくなります。
- いずれの案でも、メイン8段階は年齢と別概念のままで、12R化の影響は受けません。

年齢の設定・カード本文は変更していません。12Rを採用・追加する場合は、B・C のどちらで語るか、さいごのじかんをどう裁定するかを決める必要があります。
