## 0. 結論（先に）
- **第一推奨は「10ラウンド維持」。** 12ラウンドは、試合が約2割長くなります。一方で、終盤の緊張感（最後の2ラウンドで勝敗が動く割合）は**上がらず、わずかに下がり**ます。さらに、**デッキ間の有利不利が有意に広がり**、**そだち100の早期勝利が3%→16%に増える**（100上限への張り付き）ため、「長く遊べる分だけ面白くなる」とは言えません。
- 追加の2ラウンド（R11・R12）には行動が残っていて、全くの空白ではありません。ただし、その中身は**R9・R10と同じ種類の行動の繰り返し**です（なかまの能力・ちょうせん・そだちの上積み）。たんじょう・新しい恋人・へんしんのような「新しい展開」は、ほとんど起きません。
- 12ラウンドを将来「別モード」として足す余地はあります。ただし採るなら、早期勝利の張り付き・デッキ差・3枚のカード裁定・年齢の語り方を先に決める必要があり、**今の正式版に足すほどの利点は見つかりませんでした**。

## 12. 推奨
1. **第一推奨：10ラウンド維持（正式ルールは変更しない）。**
2. 12ラウンドを「別モード」として足すのは、現時点では推奨しません。将来検討する場合の前提条件：
   - 100上限への張り付き（早期勝利16%）への対策の要否
   - 12R向けのデッキ調整（そだち獲得デッキの弱体化、アイテム・じゅんびの強化への対応）
   - さいごのじかん（R10）・50さいのお祝い（R5）・なおとのおまもり（R7以降）の裁定
   - 年齢の語り方（[AGE.md](AGE.md)：B「120歳」かC「100歳＝1R約8.3年」か）
   - 対戦状態にラウンド数を持たせる保存設計（版名で分岐させない）と、戦績の検証（round≤10）の扱い
3. 物理版の時カウンターは、ラウンド数とは別に判断できます（[COUNTER.md](COUNTER.md)）。推奨は **0〜10 ダイヤル＋二重リング（外周＝ラウンド／年齢、ストッパー付き）**。12R・別モードを採る場合だけ、同じ構造のまま0〜12へ広げます。

## 13. 限界
- CPU 同士（中級対中級）の対戦で、人の遊び方とは異なります。特に、「時が余る」「パスだけのターン」は CPU の手の選び方の影響を受けます（ただし、感度分析では CPU のラウンド定数の影響は小さかった）。
- 正式CPU 7デッキに ⑧ のメインと「すれちがい」が無いため、⑧到達・別れ・離婚へのラウンド数の影響は測れていません。測るには専用デッキが必要です（今回はデッキ変更をしない方針）。
- 推定プレイ時間は、1手あたりの秒数を仮定した概算です。
- 12Rは「ラウンド数と時の設定値だけ」を変えた案で、カード本文・CPU・デッキは10R用のままです。
