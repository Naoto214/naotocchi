# 追加の限定比較 — ⑧到達・すれちがい（別れ・離婚）（2026-10-31）

本人の判断（2026-10-31）：正式ルールは **10ラウンド＝100歳を維持**。12ラウンド＝120歳への変更と12ラウンドの別モード追加は保留。
そのうえで、MAIN（4,088戦）では測れなかった **⑧到達** と **別れ・離婚** を、追加対戦だけで比べました。計画は実行前に固定しています（[PLAN-EXTRA.md](PLAN-EXTRA.md)）。
数値は `results/followup.json`（`analyze_followup.py`）。**既存の4,088戦は再実行していません。** 正式ルール・カード452枚・CPU・保存形式は変更していません。

## 0. 結論
- **最終推奨：10ラウンド維持（正式ルール変更なし）。12ラウンドの採用・別モード追加は、引き続き推奨しません。**
- ⑧ と恋愛では、12Rにも小さな利点が見つかりました。⑧到達率が+7pt、⑧到達後の手番が+1、別れた後に再び結婚して終われる割合が+8pt です。
- ただし、どれも**10Rで足りない部分を補う大きさではありません**。10Rでも、⑧デッキの73%がR10までに⑧へ届き（多くはR5〜R8）、到達後もほぼ毎ターン行動しています。
- 一方で、MAIN と同じ代価がそのまま現れました。**早期勝利（100維持）が約6倍**、**試合が約6.5分（約2割）長くなる**、**最後の2ラウンドで結果が動く割合は上がらない**。さらに、**離婚が増えます**（席あたり+0.058、増えた分の多くはR11・R12）。

- なかなおりは、両形式とも使われませんでした（CPUが使う局面＝交際段階0の恋人がいる局面がほぼ無い）。

## 5. 最終推奨
**10ラウンド維持（正式ルール変更なし）を最終推奨とします。** 12ラウンド＝120歳への変更と12ラウンドの別モード追加は、どちらも推奨しません。

| 観点 | 結果 | 12Rへの評価 |
|---|---|---|
| ⑧到達 | 10Rでも73%（多くはR5〜R8）。12Rで+7pt | 小さな利点 |
| ⑧到達後の活動 | どちらも活発（パスだけ2〜3%）。12Rで手番+1 | 小さな利点 |
| 結婚・立て直し | 12Rで結婚+5pt、退場後に再び結婚して終われる割合+8pt | 利点 |
| 離婚 | 12Rで+0.058／席（R11・R12のすれちがい） | 中立〜代価 |
| デッキ差 | ⑧の強いデッキがさらに有利（MAINと同じ方向） | 代価 |
| 早期勝利（100維持） | 約3% → 約18% | 大きな代価 |
| 終盤の緊張感 | 最後の2ラウンドの変化は上がらない | 利点なし |
| 試合時間 | +6.3〜6.6分（約2割） | 代価 |
| 世界観 | 10R＝100歳が最も整合（AGE.md） | 代価 |

12Rの利点（⑧の遅い到達、別れからの立て直し）は、「10Rでは時間切れになって体験できないもの」ではありません。むしろ、「10Rでもかなりの割合で起きていることが、少し増える」程度です。追加の2ラウンドの代価（時間・早期勝利・デッキ差・裁定と保存設計の負担）を上回るとは言えません。

将来12Rを再検討するなら、「別れ−10」の重さが12Rでは相対的に軽くなる点、早期勝利の張り付き、⑧デッキの有利化を先に扱う必要があります。

## 6. 限界
- CPU 同士（中級対中級、`heuristic-1`）です。正式CPUは現在 `heuristic-2` ですが、能力値を選ぶカードでの選択だけが異なる変更で、#493 の比較ではデッキ間の変化は±3.1pt以内でした。10Rと12Rの差の向きが変わるとは考えにくいものの、検証はしていません。
- 実験用デッキは各3枚（⑧）・2枚（すれちがい）の入れ替えだけで、最適化したデッキではありません。
- ⑧到達後の「行動」には、相手の手番での反応も含みます。推定プレイ時間は MAIN と同じ仮定の概算です。
