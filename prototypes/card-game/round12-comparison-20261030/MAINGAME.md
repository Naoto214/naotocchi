# 本編（メイン育成ゲーム）を120にする場合の影響調査（設計案のみ・本編は変更しない）

**本編は変更していません。** 調査は main `7c1f18c7` の読み取りだけです。

## 0. 前提の訂正：本編は「100日」ではなく「100さい（約100分）」
- 本編の時間の単位は「日」ではなく**年齢（さい）**です。リポジトリの本編側に「100日」という記述はありません（`script.js`・`README.md`・`NAOTOCCHI_MASTER_SPEC.md` で0件）。
- 定義：`script.js:98` `AGE_TICKS_PER_YEAR = 20`（コメント「人生の長さを きめる ゆいいつの 定数（1さい=60秒 / 100さい=100分）」）、`script.js:99` `GOAL_AGE = 100`、`script.js:65` `TICK_MS = 3000`（1tick＝3秒）。
- つまり本編は **「0さい→100さいの一生を、遊んでいる時間で約100分」・8段階** です。実カレンダーの「日」は、日次報酬（`dailyKey`）にしか使われていません。
- したがって、ご依頼の「本編120日」は、次のどちらかの意味になります（どちらかを先に決める必要があります）：
  - **(甲) 120さいにする**（ゴール年齢を変える）
  - **(乙) 100さいのまま、一生を120分に延ばす**（`AGE_TICKS_PER_YEAR` 20→24）

## 2. 3案の比較
| 観点 | A：本編100さい・CARD GAME 100歳（現行） | B：本編100さい・CARD GAME 120歳 | C：本編120さい・CARD GAME 120歳 |

| 世界観の統一 | ◎ 一生＝100さいで、両方とも一致 | × 本編は100さいでお別れなのに、カードでは120歳まで生きる。「さいごのじかん」（本編のお別れを引き継ぐカード）とも食い違う | ○ 一致する。ただし「120さいまで生きる」ことの説明が要る |

## 3. 所見と推奨
- **推奨：A（本編100さい・CARD GAME 100歳）を維持。**
  - 本編とカードの「一生＝100さい」がそろっています。カード「さいごのじかん」も本編のお別れを引き継いでいて、世界観が一貫しています。
- **B は避けるべきです。** 本編とカードで寿命が食い違い、本編由来のカードの意味が崩れます。
- **CARD GAME を120歳にするなら、統一のためには C（本編も120さい）が必要**になります。ただしその場合、本編の年齢の節目・8段階の境目・実績・保存の移行まで、大規模な変更が伴います。カードゲームの比較結果（REPORT-G120.md）で D が明確に優れている場合に限って検討する価値がある、という位置づけです。
- 本編は今回変更していません。
