## 変更
- **開始画面：** ヘッダー右上（タイトルの右）に「なおとっちへもどる」リンク（`href="../../"`）。対戦中はヘッダー自体が隠れるので、盤面・手札の操作の邪魔をしません。
- **対戦中：** ☰ 対戦メニューのいちばん下（区切り線の下）に「なおとっちへもどる」。
  - 対戦が進行中なら、その場でこの端末に保存し直し、保存できたことを読み戻して確かめてから確認を出します。
    「この対戦は端末に保存しました。あとで CARD GAME の『ひとりであそぶ／ふたりであそぶ』→『保存した対戦に戻る』で続きから遊べます。」
    ［なおとっちへもどる］［対戦をつづける］（既定のフォーカスは「対戦をつづける」）。
  - 保存できなかった端末では「保存できませんでした」と警告し、既定を「対戦をつづける」、移動ボタンは「保存せずにもどる」にします。
  - 対戦がない・対戦終了後は確認なしで移動します（終了した対戦と戦績は既に保存済み）。
  - 確認中は対戦メニューが開いたままなので、CPU は動きません。
- 文言は「ゲームにもどる」だと CARD GAME の対戦へ戻る意味と紛れるため、「なおとっちへもどる」にしました（なおぽよ。の「なおとっちへ」に合わせた表記）。
- マイデッキの未保存編集がある場合は、既存の `beforeunload` 確認がそのまま働きます。
- ルール・カード（452枚）・CPU判断・保存形式・戦績には触れていません。

## 追加改善（2026-10-31 第2段）：画面の階層に応じたもどる操作

### 実際の画面構造
CARD GAME のトップ（メインメニュー）、「対戦の準備」（あそびかた・席・CPU・デッキ選択と「保存した対戦に戻る」）、マイデッキは、
同じ開始ページ `#welcome` の上下に並んだ区画です。「ひとりであそぶ／ふたりであそぶ」は、ページ内の「対戦の準備」までスクロールするだけです。
そのため、新しい画面は作らず、このページの該当位置へ戻す形にしました。

なおとっち本編 → CARD GAME トップ（ページ上部）→ 対戦の準備（同じページの下）→ 対戦画面

### 各画面の戻り先
| 画面 | 操作 | 戻り先 |
|---|---|---|
| CARD GAME トップ | ヘッダー右上「なおとっちへもどる」 | なおとっち本編 |
| 対戦の準備 | 見出し左「← もどる」 | CARD GAME トップ（同じページの上部。「ひとりであそぶ」にフォーカス） |
| 対戦中 ☰ 対戦メニュー「もどる」 | 対戦をつづける | メニューを閉じて対戦のまま |
| 〃 | ← 対戦の準備へ | 対戦の準備。あそびかたを今の対戦に合わせ、「保存した対戦に戻る」にフォーカスし、すぐ下に再開の案内を出す |
| 〃 | ← CARD GAMEトップへ | CARD GAME トップ（再開の案内は対戦の準備に出る） |
| 〃 | なおとっちへもどる | なおとっち本編（ページ移動） |
| 対戦終了後の結果 | 「対戦の準備へ」（旧「開始画面へ」） | 対戦の準備（もう一度遊ぶ準備） |
| 対戦終了後 ☰ | ← 対戦の準備へ／← CARD GAMEトップへ／なおとっちへもどる | 確認なしで移動（終了した対戦は保存済み）。「対戦をつづける」は出さない |
| カードコレクション・ルールブック・戦績・マイデッキ | 既存の「閉じる」 | 変更なし |

- 「←」が付いた操作は CARD GAME の中で戻ります。「なおとっちへもどる」だけが本編へ移動します。☰ メニューでは枠の色も分けています。
- 対戦中の3つの移動は、どれも移動前に保存し直し、読み戻して確かめてから確認を出します（既定のフォーカスは「対戦をつづける」）。保存できない端末では警告を出し、移動ボタンを「保存せずにもどる」にします。
- 開始ページから開いた ☰（「保存ファイルを読み込む」）では、もどる操作を出しません。ヘッダーに「なおとっちへもどる」があるためです。
- 学習（チュートリアル）の結果画面も「対戦の準備へ」と表示されます。もともと CPU 対戦の準備へ移る動作なので、表示が実際の動きに合いました。
