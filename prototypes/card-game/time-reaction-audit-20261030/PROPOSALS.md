# CPU判断の改善案（比較のみ・正式CPUは変更しない）

前提：ルール（本人方針0-1〜0-7）・カード・時の管理・発動／連鎖処理・保存形式は変えない。変えるとすれば `cpu-policy.mjs`（必要なら `cpu-observation.mjs` の公開情報の追加）だけ。`POLICY_VERSION` を上げ、旧保存は旧方針で再生する前提。

## A：現行維持（修正不要）

| 項目 | 根拠 |
|---|---|
| A1 相手ターンの見送りの大半 | 中級が見送った局面の評価値はすべて0以下。上位は効果0のカード（交際0以外のはじめてのデート・上位のないとしをとったじぶん・場7枚未満のじんとり等）。（R5） |
| A2 R1〜R4で自分ターンに時を使い切る | 失効は1ターン0.3〜1.0。相手ターンで時不足になったターンの88%（中級。初級84%）は、自分ターンを時0で終えた直後。ただし固定局面で、時が残っていれば結果が変わったのは30件中2件（R8）。序盤は自分の展開を優先する方が合理的 |

| A5 R5以降の時の失効の大部分 | 中級の失効時間（R1〜R9）23,729のうち63%は「使い道がない」（合法の有償行動なし）または「評価0以下の行動のみ」、37%は「相手ターンに使えるカードがあったが評価0以下で見送った」もの。デッキに後半の時を使うカードが少ないという構造の問題で、CPUの誤りではない。カード・デッキ側の論点（本人判断） |

## B：軽微な改善（局所的な評価の調整）

### B1 能力値を選ぶ反応で、勝負の種目に合う方を選ぶ　【第一推奨】
- 対象：スキージャンプ（しかける）・かくとうバトル（すぐつかう）など、`variant` で ちから／ちえ を選ぶ `chosenStat`／`stat` の効果。
- 変更案：`stepValue` で `o.challenge` があるとき、変更する能力値が `o.challenge.parameter` と違う候補の値を0にする（`chosenStat` は `a.variant`、`if`＋`variant` 条件は条件に合う型だけを数える）。
- 効果：自然対戦で、中級のスキージャンプ発動の49%、かくとうバトルの約50%が種目と不一致。中級のスキージャンプ不一致133回のうち59回は、正しく選べば負け・引き分け→勝ち（そだち+5）に変わり得た。`challengeKit`（自分からのちょうせんを宣言するかの判断）は「正しく選ぶ」前提で+3を見込んでいるため、宣言の判断と発動の判断の食い違いも解消する。
- リスク：小。合法手・エンジンは変わらない。勝負の外で使う「このターン+」型（勝負前の準備）には影響しない設計にする。
- 必要なテスト：固定局面R1・R2の単体テスト（種目＝ちえで ちえ を選ぶ）、`tests/cpu*.test.mjs` 全件、ちょうせん／アイテム／バランスデッキを含む小規模対戦で不一致率0%の確認。
- 既存デッキへの影響：ちょうせんデッキ（スキージャンプ3・かくとうバトル2）・アイテムデッキ（スキージャンプ2）・バランスデッキ（スキージャンプ2）の中級／初級が強くなる。デッキ間バランス（#404〜#407）の再確認が必要。

### B2 最終ターンは手札と時の保持価値を0にする
- 変更案：自分の最後の自分ターン（R10）と、その後の相手の最終ターンでは、`play` の `-3`（手札1枚分）と時の減点（初級の `legacySpend`、中級の機会費用）をかけない。効果の見積もりが正なら使う。
- 効果：固定局面60件中7件で最終そだち+5〜+25、3件で勝敗が変わる（R3）。
- リスク：小〜中。効果の見積もりが粗いカード（例：ミニゴルフの「このターンにプレイしたのが1枚だけ」条件を0.45倍で一律評価）では、無駄打ちが起きる（ただし最終ターンなので損失は効果0の範囲）。
- 必要なテスト：R10終了時の固定局面、R10の先攻・後攻両方、`tests/cpu*.test.mjs`。
- 既存デッキへの影響：そだち獲得（ミニゴルフ）・ちょうせん（かくとうバトル）で最終そだちが少し上がる。初級を対象に含めるかは本人判断（初級の「単純さ」をどこまで残すか）。

### B3 しかけの価値に発動見込みを入れる
- 変更案：しかけの配置評価 `7-spend+2`（種類によらず一律）に、公開情報から見た発動見込みを掛ける。例：ミサイルコマンドは相手の捨て札・公開済みカードに「時2以下で自分の場を対象にするアクション」がなければ低く評価。スキージャンプは自分が今後ちょうせんを宣言する見込み（初級は「勝っている時だけ宣言」なので低め）を掛ける。
- 効果：ミサイルコマンドは150回しかけて発動0回（R4）。初級のスキージャンプは175/300（58%）しか発動せず36%が終局まで残る。準備枠（アイテムデッキでは満杯が1試合0.8ターン）を装備・別のしかけに回せる。
- リスク：中。相手の手札は見られないため見込みは推定になる。過小評価すると、しかける方式そのものを使わなくなる。カード別に係数を持つと保守の負担が増える。
- 必要なテスト：しかけ可能な固定局面（P4）、アイテムデッキの対戦、しかけ発動率・残存率の比較。
- 既存デッキへの影響：主にアイテム・じゅんびデッキ。ミサイルコマンドのカード自体の強さ・デッキ採用の是非はバランス側の論点（本人判断）。

### B4（参考・優先度低）相手ターンの「このターン」型の価値
- `stat`（`duration:'turn'`）を相手ターンに使う評価は0.2倍、勝負中は2.4倍で、勝負の結果が変わるかは見ていない。B1を入れれば、種目違いの無駄打ちはなくなる。差を見て使うかの判断（勝てる／引き分けにできる時だけ使う）はB1の延長で可能。ただし固定局面30件では結果が変わる例が少ない（R8）ため、優先度は低い。

## C：大きな改善（判断方式の変更）

### C1 ターン全体の計画（相手ターン用の時の予約）
- 内容：自分ターンの行動を1手ずつ評価する現行方式ではなく、「このターンに使う時」と「相手ターンへ残す時」をまとめて計画する。相手のちょうせん・妨害の見込み（公開情報）と、手札の反応カードから残す時を決める。
- 効果：序盤の時不足（相手ターンの時不足窓は中級で1試合1.83ターン）を、必要な時だけ減らせる可能性。ただし現行7デッキには相手ターン専用の反応カード（`reaction` 型）がなく、固定局面でも効果は小さい（R8）。
- リスク：大。評価の再設計、計算量の増加、難易度差の作り直し、既存の大量対戦・デッキバランス検証のやり直し。
- 必要なテスト：全デッキの総当たり、初級・中級差、iPhone上の思考時間、保存・再生の互換。

### C2 浅い探索（1手先の相手応答を含む評価）
- 内容：候補ごとに複製を作り、相手の応答と勝負の比較まで公式エンジンで進めて評価（今回の固定局面の rollout と同じ考え方）。
- 効果：B1・B2・B4をまとめて置き換えられる。条件付きカード（ミニゴルフ等）の評価の粗さも解消。
- リスク：大。思考時間の増加（今回の rollout は1局面あたり数百ms〜数秒）、決定性・再生互換の確認、初級との差の設計。
