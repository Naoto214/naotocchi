## 0. 結論（要約）

- 現行ルールの駆け引き（相手ターンのすぐつかう、残り時の保持、しかけの前払い）は、エンジン・ルールブック・正式ルールで一致して実装されている。
- **CPUはその駆け引きをほとんど使っていない。** ただし主な理由は、CPUの判断の誤りよりも **現行7デッキに相手ターン向けのカードが少ない** ことにある。中級が相手ターンに見送った局面は、すべてCPU自身の評価で0以下（効果0のカードが大半）。
- 明確な判断の誤りは3つ：**(1) 能力値を選ぶ反応で、勝負の種目と違う方を約半分の確率で選ぶ**（スキージャンプ・かくとうバトル）、**(2) 最終ターンでも手札と時の保持価値を差し引く**、**(3) 発動条件がほぼ成立しないしかけ（ミサイルコマンド）を一律の価値で置く**。
- 第一推奨は B1（種目に合う能力値を選ぶ）。正式CPUは変更していません。

## 4. 未使用のまま失われた時

- 1ターンあたりの失効（R1〜R9、次の自分ターン開始時点の残り）：初級3.16、中級2.96。失効が出たターンの割合：初級72%、中級66%。
- 中級の失効の内訳（合計23,729）：使い道なし（有償の合法手なし）4,690（20%）、評価0以下の行動だけ10,194（43%）、相手ターンに使えるカードがあったが評価0以下で見送り8,681（37%）、相手ターンで一部使用164。
- **判断**：後半の失効は、時がラウンド値まで増えるのに、使えるカードがないという構造によるもの。中級の見送りはすべてCPU自身の評価で0以下で、「使い切る方が得だった」と言える局面は最終ターン（第7節 R3）に限られる。「相手ターンへの備え」として残したのではなく、使い道がないから残っている。

## 5. すぐつかう／しかけるの使用頻度と有効性

| | すぐつかう | しかける |
|---|---|---|
| 使用頻度（1試合、中級） | 自分ターン 4.34、相手ターン 0.16 | 0.60（ちょうせん・アイテム・バランスデッキのみ） |
| 発動成功率 | 使用＝発動 | スキージャンプ 85%、たこやきやさん 87%、ミサイルコマンド **0%** |
| しかけたまま終局 | — | 中級19%（ミサイルコマンド51・スキージャンプ38・たこやき14） |
| 準備枠不足による機会損失 | 該当なし（満杯でも使用：初級168・中級128回） | アイテムデッキで満杯のためしかけ不可 0.8ターン／試合 |
| 相手ターンでの発動 | 0.16回／試合（中級） | ミサイルコマンドだけが相手ターン型で、発動0 |
| 時コストに対する効果 | 条件なしのそだち系は確実に効く。条件付き（ミニゴルフ等）は評価が粗い | 前払い2で「自分の宣言時に+3」。正しい能力値なら勝負1回分（そだち+5）を左右する。実際は49%が種目違いで無効 |

方式そのものの価値：しかけるは「条件が確実に来る」カード（たこやきやさん＝自分のターン終了時、スキージャンプ＝自分の宣言時）では高い発動率で機能している。一方、相手の行動に依存するミサイルコマンドは、現行デッキの組み合わせでは条件がほぼ来ない。これはカード固有の条件の問題で、しかける方式の価値の問題ではない。すぐつかうの「相手ターンにも使える」利点は、現行デッキでは相手ターンに意味のある反応カード（防御・妨害）が少ないため、ほとんど発揮されていない。

## 12. 本人判断が必要な事項

1. **B1 を正式CPUへ入れるか**（入れる場合は `POLICY_VERSION` の更新、旧保存の扱い、デッキ間バランスの再確認）。
2. **B2 を初級にも適用するか**（初級の「単純さ」をどこまで残すか）。
3. **初級の「相手ターンに反応しない」仕様を維持するか**（現状は意図された差。初級が相手ターンに使えば、自身の評価でも正の機会が標本4,314件中539件ある）。
4. **後半の時の失効**（R7〜R9で開始時の約8割が失効）は、CPUではなくカード・デッキ構成の論点。相手ターンに意味のあるすぐつかう（防御・妨害）をCPUデッキへ入れるか、現状を「後半は時が余る」設計として受け入れるか。
5. **ミサイルコマンド**を現行のアイテムデッキに残すか（カードの強さ・採用はバランス側の論点で、B3とは切り分ける）。

## 調査の限界

- 「機会」は応答ウィンドウ単位で、同じ連鎖で何度も来る分を含む（ターン単位の値も併記）。
- 時不足と条件不成立の区別は「時を99にした複製で合法になるか」による。コスト軽減の見積もりの細部は含まない。
- 固定局面の rollout は両席とも中級CPUで続きを進めた結果で、最善手の保証ではない。最終ターンの差には、その後の展開の分岐による間接的な差も含まれ得る（R3で直接効果のある候補だけを数えた）。
- 能力値の不一致が結果を変え得たかは、発動時点の差での判定（その後の応答は含まない）。
