# 代表局面（2026-10-30）

すべて `runs/T-manifest.json` の自然対戦から取り出した実在の局面です。`match` と席・ラウンドで再生できます（`tools/audit-run.mjs` の `play()` に `onDecision` フックを渡す。`tools/probe*.mjs` が実例）。
「自然」は実際の対戦で起きたこと、「固定」は同じ局面の複製で条件（難易度・時）だけを変えた検証です。両者を混ぜていません。

## R1 スキージャンプ（しかける）が勝負と違う能力値に+3する　【問題・B】

| 項目 | 内容 |
|---|---|
| 局面（自然） | `T:main~challenge:3:BI:X-first` 席B（中級、ちょうせんデッキ）R8、自分から **ちえ** でちょうせんを宣言、差 0（同値） |
| 使用可能な行動 | しかけ済みスキージャンプの誘発：`ちから+3` / `ちえ+3` |
| CPUの選択 | `ちから+3`（勝負はちえなので効果なし） |
| より合理的な候補 | `ちえ+3` → 差 +3 で勝利（そだち+5） |
| 原因 | `cpu-policy.mjs` `stepValue` の `chosenStat` は `n*(o.challenge?2:1)` で、選ぶ能力値と勝負の種目を照合しない。2つの候補が同点（6）になり、席・手順ごとの同点処理（`tie`）でほぼ半々に決まる |
| 自然対戦の規模 | 中級 269回中133回、初級 175回中90回が種目と不一致（`results/variant-check.json`）。中級の不一致133回のうち59回は、正しく選べば発動時点の差で負け／引き分け→勝ちに変わり得た |

同種：`T:main~challenge:4:BI:Y-first` 席A R7 ちえ勝負・差-1 で `ちから+3`、`T:partner~challenge:4:II:X-first` 席B R9 ちえ勝負・差0 で `ちから+3`。

## R3 最終ターンに効果のあるすぐつかうを残して終わる　【問題・B】

| 局面（固定：自然対戦の局面を複製して最後まで進めた） | CPUの選択 | 候補 | 最後まで進めた結果 |
|---|---|---|---|
| `T:main~growth:2:BB:X-first` 席B（初級）R10 終了申し出、時9、そだち75 | 終了（パス） | ミニゴルフ（評価 -3.62） | パス：最終80・引き分け／ミニゴルフ：最終85・**席Bの勝ち** |
| `T:main~challenge:4:BB:X-first` 席B（初級）R10、時10、そだち35 | 終了 | かくとうバトル キック／ガード（評価 -1.28） | パス：最終35／使用：最終60（勝敗は変わらず） |
| `T:main~challenge:2:II:Y-first` 席A（中級）R10、時8、そだち50 | 終了 | かくとうバトル キック／ガード（評価 -0.03） | パス：50／使用：55 |

- R10の自分ターン終了時に、有償のすぐつかうを持っていた60局面（固定）のうち、カード自身の効果が見込める候補で最終そだちが上がったのは **7局面（初級5・中級2）**、勝敗が変わったのは **3局面**。残る局面は「使っても変わらない」（効果0のカードが大半）。
- 原因：中級は「手札1枚＝3」の減点（`['play','programPlay']` の `-3`）を最終ターンにもかける。初級はさらに一律の時減点（`legacySpend`）を加える。R10の自分ターンが終わると、手札と時はどちらも価値がなくなる。
- 注意：差の中には、使ったカード自身ではなく、その後の展開の分岐による間接的なものもある（例：`T:main~growth:4:II:Y-first` のじんとりは、場3枚で効果0なのに最終+5）。上の7局面は、カード自身の効果の見積もりが正の候補だけを数えた。

## R4 ミサイルコマンド（しかける）が一度も発動しないまま準備枠を占める　【問題・B】

| 項目 | 内容 |
|---|---|
| 局面（自然） | `T:main~item:1:II:X-first` 席B（中級、アイテムデッキ）R8、準備枠 = ミサイルコマンド・なおとのランタン・おべんとうばこ（満杯） |
| 状況 | ミサイルコマンドの発動条件「相手が時2以下のアクションで自分の場のカードを対象にした時」は、現行7デッキ同士ではほぼ成立しない |
| 自然対戦の規模 | 896戦で150回しかけ、**発動0回**。終局時に111枚が準備枠に残存。残り39枚は途中で準備枠を離れた（おちばタワーの支払いなど。離れた理由は個別に集計していない） |
| CPUの選択 | しかけの価値は種類によらず一律（`place`/`prepared` = `7-spend+2`）。発動見込みを見ていない |
| より合理的な候補 | 相手に「自分の場を対象にする安いアクション」がない間は、装備・別のしかけ・時の温存を優先する |

アイテムデッキは準備枠の満杯で1試合あたり約0.8ターン、しかけを置けない（初級0.81／中級0.82）。

## R5 相手ターンの見送り — 合理的な例　【A】

| 局面（自然） | 見送ったカード | 判断 |
|---|---|---|
| `T:main~main:1:BB:Y-first` 席A（初級）R4、時2、相手の連鎖中 | うんめいのへんしん（評価 -5） | 相手ターンに使っても「次のへんしんの時-2」は自分ターンまで残らない。見送りが正しい（中級でも見送る） |
| 中級の相手ターン見送りの上位 | はじめてのデート（交際0以外は効果なし）、としをとったじぶん（山札に上位がない）、なかなおり（交際0以外は1枚見るだけ）、じんとり（場7枚未満は効果なし） | 効果0または小さいカード。見送りは合理的 |

中級が相手ターンに見送った局面の評価値は、すべて0以下です（標本2,610件：-1以下が1,751件、-1〜0が859件）。ぎりぎりで見送った上位は、山札を見る系（あたらしいであい -0.01、おともだちチケット -0.2、としをとったじぶん -0.23）で、「手札1枚で1枚を探す」ため価値はほぼ0になります。

## R8 相手のちょうせんへの防御反応は、時不足でも結果への影響が小さい　【A（観察）】

固定局面30件（`results/positions-defense.json`、相手ちょうせん中にかくとうバトル／ビーチバレーを保持）：
- 実際の時で、選択によって勝負の結果が変わる局面は0件。
- 時が足りなかった9件を「カードのコスト分だけ時があった」場合に置き換えると、結果が改善するのは2件（R2〜R3、差-1）。
- ビーチバレーは「このターンになかまの能力の効果が適用されていること」が条件で、相手ターンにはほぼ使えない（条件不成立）。
