# 通常たまごカード — デザイン・物理版

正本参照: assets/characters/egg/intact.png と ui-assets/card-back-approved.png。
本編たまごのクリーム色・青灰色の斑点・ドット絵の形を参照して制作。顔や手足を追加しない。青銀の地・銀色植物・外枠は承認済み裏面を参照し、中央だけ温かな淡金色の光を加えた。

- original.png: built-in imagegen原画、1024×1536、2:3。
- initial-draft.png: 制作初稿を保存。
- egg-card-print.png: 原画画素数を維持、300dpiメタデータ付きPNG。
- ui-assets/egg-card-small.webp: 320×480。
- ui-assets/egg-card-large.webp: 1024×1536。
- 時コスト・ちから・ちえ・通常カードIDなし。詳しい処理はタップ詳細に掲載。
- 裏面は通常カードと共通。各プレイヤー1枚、計2枚。メイン枠最下層に置き、メインで完全に覆う。
- フィールドにはメイン枠だけ設け、たまごの絵は印字しない。
- ネオたまごは構想のみ。効果/画像/入手/消失/保存状態は今回追加しない。

63×94.5mm出力なら約413ppi。通常カードの実際の判型に合わせ比率固定で出力する。塗り足し・印刷所CMYK・用紙・角丸は未指定で、発注前に入稿仕様へ調整が必要。製造や印刷発注はしていない。

## 制作

参照画像2枚からbuilt-in imagegenで生成し、2:3へ再構成。元生成物を無変更保存し、build.cjsで印刷PNG/配信WebPへ変換。hashと寸法はassets.json。

主プロンプト: 承認済み裏面の青銀と植物装飾、本編のたまごの形・斑点・色を保持。中央に金色の光、上に「たまご」、下に「メインがいない状態。自分のターン開始時、通常ドロー後にさらに1枚引き、手札1枚を山札の下へ戻す。」、脚注「状態表示用・デッキには含めない」。数値やコストなし。2:3の単一外枠。卵や文字は歪ませない。

comparison.htmlは同じ公開状態を旧/新の実際のレンダラーで作った静的比較。スクリーンショットや実機QA成功の証拠ではない。
