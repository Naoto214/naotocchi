## 1. 本人の判断

PR #481 の比較結果（2,960戦）を確認したうえで、本人が次のとおり決定しました。

| 項目 | 判断 |
|---|---|
| **A 案（現行維持）** | **正式採用**。結婚前の別れ そだち−10、結婚後の離婚 そだち−10、恋人の自由交代は引き続き不可 |
| B 案（結婚前の別れ−5） | 不採用 |
| C 案・C2 案（新カード「円満な別れ」） | 現時点では正式カードに追加しない |

## 2. 判断の根拠になった結果（`REPORT.md` の要約）

| 項目 | 結果 |
|---|---|
| 別れ・離婚の発生 | 自然対戦（中級・A案）の恋人側160席で、結婚前の別れ70回・離婚32回（交際0／1／2／3：26／18／14／12）。PR #440 の0回と違い、実際に計測できた |
| 別れ1回の重さ（F2：強制的に1回起こした試合と起こさない試合の対、200対） | そだち−7.3（95%CI −8.7〜−5.9）、得点率−2.8ポイント（−7.1〜+1.7） |
| 別れの後の回復 | 結婚前に別れた席の69%が、終局までに出し直して結婚。結婚率（配置した席のうち）は3案とも約95% |
| B−A（恋人側の得点率） | 中級 +4.1ポイント（+0.8〜+7.3）、初級 +6.2ポイント（+2.7〜+9.8）。すれちがいを使う側は同じだけ下がる（中級 −4.1） |
| C のカード効果だけ（同じデッキの対照 Cx との差） | +1.9ポイント（+0.2〜+3.6）。すれちがいを受けた時に手札にあれば使える場合に限られる |
| 出し直しの悪用（C：ねこ社長の出し直しを機械的に繰り返す） | 得にならなかった（−2.5ポイント、有意差なし） |
| 結婚の時期・恋人の滞在・2枚目以降の配置・余る恋人 | 3案でほぼ同じ。B・C は別れた時の損失だけを変えた |

判断の要点：
- −10は重いものの取り返せる大きさで、恋人を育てて結婚する戦略は成り立っている（A）。
- B は恋人側を助ける分、唯一の妨害札すれちがいの価値を同じだけ下げ、ルールの数字が二つになり、旧保存の版分けも必要になる。
- C は効果が小さく、453枚目のカード・画像・カタログ・CPU判断の新設に見合わない。

- A の写しは、同じ試合を正式エンジンで再実行して40試合中40試合で保存hashと結果が一致（うち20試合は別れを含む。`results/equivalence-N1.json`、main `953b9c34` の正式エンジンで実施）。

## 4. 限界

- CPUは案によって判断を変えない。B で別れを気にせず恋人を出す、C で円満な別れを温存するといった適応はない。
- CPUはすれちがいを、相手の交際段階を見ずに序盤から使う（相手が受ける−10を評価しない）。F2 で使う段階を固定して補ったが、F2 は相手の手札1枚をすれちがいに置き換える方式で、保存の再生の対象外。
- 円満な別れの使い方は実験用の規則（すれちがいへの応答だけ）と、悪用検証の機械的な規則だけで調べた。
- 恋人デッキは公式CPUの2種類だけ。ねこ社長以外の配置時カード（ペンギン②・おばけ⑦・とかい・パイプつなぎ・クラゲ⑥など）との組み合わせは、対戦では調べていない。
- 小規模（合計2,960戦）。交際段階ごとの差の信頼区間は広い。人のプレイヤーでの試遊はしていない。

## 5. 残す将来候補（今回は着手しない）

- 「浮気」：すれちがいと同じ効果なら追加不要。差別化するなら「交際段階を1下げる（別れは起こさない）」。名前の印象も要検討（`UWAKI.md`）。
- C2（相手のターンにだけ使える円満な別れ）：将来、交際0の別れへの不満が実機試遊で出た場合の比較候補。採用時の影響範囲は `COMPATIBILITY.md`。
- CPUのすれちがいの使い方（相手の交際段階を考えない）の改善。
- 終局時に恋人カードが手札に余る問題（81%の席）は、どの案でも残った。別の課題として扱う。
