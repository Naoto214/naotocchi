## 改善点

- 補助名はBを第一候補。背景・枠・段階数字を付けず、名前の行高に追従して直下に置く。V6のA／非表示Cと比較可能。主名の色は維持し補助名だけ淡く小さくした。
- イラスト→能力値→本文の順序を保ち、能力値を等幅2領域にする。各領域の中心に数字を置き、Canvasの実字形境界で上下左右を補正。右上コストのV6安定化座標はそのまま。
- V6は固定高さの本文領域に `overflow:auto` があり、最終行の一部がスクロール端で見切れていた。V7は文字サイズを保ち、全文の実測高さを確認する。収まらない場合は原文の冒頭を明示し、拡大の全文欄へ案内する。中身によりイラストやカード比率は動かさない。
- クリーム色を第一候補、淡い分類色も維持。正式14色・金枠・植物装飾・裏面はそのまま。漢字・必要なルビは表示比較のみ。
- レア菱形の表示／非表示は比較ページだけの切替。内部rareと投入制限を変更しない。
- 対戦サイズのカード幅は手札領域の実幅に合わせて縮め、320pxでも横にはみ出さないようにした。

## レア仕様と分離案

現在は `rare: boolean` が菱形表示と `rare ? 1 : 3` の上限を結び付ける。正式452枚のうちレア76枚、追加7枚を含めても76枚。UI合成マークであり画像へ焼き込まれていない。CPUデッキも共通検証を使用し、CPU評価やレア対象効果にもrareを使う。

将来はレアリティと、ルール版ごとのカードID別投入上限（既定3・個別1/2/3）を分け、共通上限取得処理をデッキ検証・編集・CPU検証で共有する案。[RARITY-DESIGN.md](RARITY-DESIGN.md) に所在と移行方針を記載。今回の正式実装には導入しない。
