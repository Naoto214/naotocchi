## 再現

リポジトリrootで実行。PR #498の上記コミットがローカルに存在すること。

```sh
node prototypes/card-game/design-comparison-v3-20261114/build.mjs /absolute/output/v3
node prototypes/card-game/design-comparison-v3-20261114/verify.mjs /absolute/output/v3
node --test prototypes/card-game/design-comparison-v3-20261114/title.test.mjs
```

出力先は独立フォルダを指定。UIの依存は同じV3出力内に含まれます。公開済みV1/V2へのリンクは親Siteを前提とします。viewport-fixture.html / contrast-fixture.html は検証用で、公開ビルドには含めません。browser-verification.json、contrast-results.json、画像に観測結果を保存。
