## 3. すれちがい

エンジン（`rules.mjs` の `opponentPartner`、`engine.mjs` の `breakupPenalty`）で、交際 0〜3 と結婚後の両方が対象になり、結婚前 −5・結婚後 −10、結婚後は「♥ 結婚したら」も失うことをテストで確認。
ルールブック第 9 章に説明、第 15 章によくある質問を追加。すれちがいの「関連ルールを読む」は第 9 章（交際・結婚）へ案内する。正式本文は変更なし。

## 4. 旧保存（hotseat-7 以前）

対戦画面の投影で、旧版の対戦に見えるカードへ `legacyRules` を付け、こいびとカードの「♥ 結婚したら」を出さない。カード閲覧の詳細には「前のルールで続いている」注記を出す。
保存・再生・処理は変えていない（hotseat-7 実データ 20 件の保存文字列一致をテスト）。コレクション（図鑑）は常に正式な最新カードを表示する。
