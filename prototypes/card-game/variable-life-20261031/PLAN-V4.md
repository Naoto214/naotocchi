**変更の理由：**
- **まちぶせどけい：** VERSION 3 は「相手が時のカードを出した時に発動し、カウンターを安くする」案でした。しかし既存の処理では、連鎖は解決を始めると最後まで続き、途中に応答の機会がありません。そのため、発動して解決した軽減は、カウンターの機会の後になってしまいます。伏せたままカウンターの支払いに使う形にして、「伏せたカードがあると返されるかもしれない」という読み合いは残しました。
- **ちょっとまった：** 既存の処理には「そだちが100に届いた時」の出来事がありません。100維持は、相手が届いた後、こちらのターンの終わりに判定されます。そこで、相手のターン終了時（届いた直後）に発動する形にしました。100維持を止める働きは同じです。
- **相手のそだちを減らす処理：** 既存の「そだちの減少を防ぐ」カード（びっくりハリネズミなど）が働く、既存の減少の処理を使います。

**U12（本人の指示）：**
- カウンターされた時のカードは、通常の移動（行き先：捨て札）で場を離れます。持ち主の既存の置換効果が働きます。
  - タンポポ④：手札のセカイを捨てて場に残す（任意）。
  - ヒトデ⑦：山札の一番下へ。
  - サンゴ⑦：3種類そろっていれば、捨て札に置かない。
- **効果の不成立は、移動の前に決まります**（移動先に関係なく不成立）。終了ラウンドは、最後に成立した時のカードが決めます。
- 置換カードがない場合は、VERSION 1 と同じ結果です。
- 確認済み：smoke-v4 の U12 の10項目に合格（2026-11-04 訂正：当初11項目と書いたのは誤り）。

## 2. CPU smart3（実験用。正式CPUは変更しない）
- **基準：** smart2 と同じです。新カードがない対戦では、smart2 と完全に同じ判断をします（V2C と同じ seed で112戦、保存ハッシュ 112/112 一致、`runs/v4eq-*`）。
- **新カードの判断：**

  | カード | 判断 |
  |---|---|
  | はやじまい・ながいきのひけつ・おもいでのしゃしん | 得られるそだち×終盤の重みで評価 |
  | ながいきのひけつ | 負けていて XI・XII を持ち、終了ラウンドが10以下の間は温存（延長後に +15 で使う） |
  | いなかのおみやげ | 自分のセカイが時のカードか空の時に使う |
  | まちぶせどけい | 手札に時のカードがある時に伏せる |
  | ちょっとまった | 相手が85以上で、終了ラウンドがまだ先の時に伏せる |

- **時のカードの判断（勝率見込み）：**
  - 自分の手札の新カードを、その終了ラウンドで得られる追加のそだちとして足す。対象ははやじまい（残り1ラウンドになるなら）と、ながいきのひけつ（11以上なら +10）。
  - 両者の場のおいわいのつる（公開情報）は、R10以降の回数×5 として足し引きする。
  - 相手の手札・山札の中身は使わない。

## 4. 有望カードの選び方（V4F_N_* の後、V4F_MULTI の前に記録）
次の両方を満たすカードを有望とします。
- **逆転の改善：** 負けている側が終了ラウンドを動かした試合での勝率（延長した側の逆転率、または短縮した側の逆転率）が、比較基準より上がる。
- **公平性の維持：** デッキ幅・先攻得点率・接戦が、比較基準より有意に悪化しない（95%CI）。

MULTI は、有望カード各1と、IX・XII を各1追加した構成です（同名3枚まで）。

## 5. 分岐（同じ局面からの比較）
- **分岐する局面：** 次の条件を満たす最初の局面で分岐し、両方を最後まで smart3 同士で進めて勝敗を比べます。
  - 自分の番の通常の行動機会。
  - 負けている側。
  - R7〜R10。
  - 終了ラウンドを延ばす時のカード（XI・XII で、現在の終了ラウンドより後）を出せる。
- **延長（E）：** その時のカードを出す（XII を優先）。
- **延長しない（N）：** その席は、その後の試合で終了ラウンドを延ばす時のカードを出さない。ほかの判断は CPU のまま。
- **短縮の分岐：**
  - 分岐する局面：負けている側が、R7〜R9 に IX（または現在の終了ラウンドより前の時のカード）を出せる、最初の局面。
  - 短縮（S）と、短縮しない（N）を同じように比べます。
- **比べる条件：** 比較基準（B4）、ながいき＋XI・XII（C_naga）、はやじまい＋IX（C_haya）、MULTI。
- **指標：** E と N の、負けている側の得点率の差＝延長（短縮）による逆転力。95%CI は局面単位のブートストラップで出します。

## 6. 評価（`analyze_v4.py`）
**指標：**
- R9 短縮による逆転率：負けている側が短縮して、その試合に勝った割合。
- R11・R12 延長による逆転率。
- 延長前後の勝率改善（分岐）。
- デッキ別の得点率・デッキ幅、接戦、先攻・後攻。
- アイテム型・そだち獲得型。
- 100維持勝利。
- 特殊カウンターの発生率、新カードの使用率と使用ラウンド。
- 保存→復元、異常終了・無限連鎖。

**差：** 各条件 − 比較基準（V2C、同じ seed で対応づけ）。ブートストラップ 95%CI。
