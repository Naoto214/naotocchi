## 仕様（実験 T-2s と同じ規則。詳しくは [../TIME.md](../TIME.md)）
| 項目 | 内容 |
|---|---|
| カード | せかい IX・X・XI・XII。時2で、レアではありません（同名3枚まで）。新しい絵はまだありません（「画像を表示できません」と表示されます） |
| 自分の番 | ふつうのセカイと同じように出します（前のセカイは捨て札へ）。出した時に、終了ラウンドを N にします（両者共通）。N が現在のラウンドより前なら出せません |
| 特殊カウンター | 相手の時のカードの能力が連鎖で待っている間は、応答として手札の時のカードを「〇でカウンター（時2）」で出せます。カウンターは何回でも続けられます。最後のカードだけが成立し、それまでの時のカードは捨て札へ置かれます。終了ラウンドは、すべての応答が終わってから一度だけ変わります |
| 終了 | 終了ラウンドの後攻の番の後に最終比較をします。100維持の判定は、終了ラウンドより前のラウンドだけで行います |
| デッキ | 対戦開始時に、両者のデッキへ時のカードを入れます。枚数は赤い枠で選べ、「各1枚（計4枚）」が既定、「各2枚（計8枚）」も選べます。入れ替えたカードは画面下に表示されます |
| 人生の時計 | 描画（文字盤・針の色・形・寸法・配置）は採用版のままです。下中央の小針が、成立した終了ラウンドを指します（IX＝270度、X＝300度、XI＝330度、XII＝0度）。カウンターの途中では動きません。IX を受け付けるために、試遊版の写しだけ入力確認の範囲を9まで広げています（未確定事項 U8） |
| 表示 | 延長すると「延長」、短縮すると「短縮」（R9 は赤）のバッジが出ます。結果画面に「R10終了時点」のそだちも出ます |
| 保存 | 鍵はすべて `naotocchi-time-trial:` 付きで、正式版・ほかの試遊版とは別です。終了ラウンドは保存せず、再開時に操作の再生で作り直します。戦績は R12 まで記録します |
| CPU | 実験用の補助（smart：終盤の勝敗見込みで延長・短縮・カウンターを判断）を使います。正式CPU（heuristic-2）そのものは変更していません |
| 制限 | 「保存ファイルを書き出す」は公開先の制約で働きません |

## 確認していただきたい操作
1. 「ふたりであそぶ」または「CPUとあそぶ」→ 赤い枠で時のカードの枚数を選ぶ → 「新しい対戦を開始」。
2. 時のカードを引いたら、カードを押して「IXを配置（時2）」などを選びます。出した時の能力は「効果を使う」で処理されます（強制）。
3. 相手は応答の時に「XIIでカウンター（時2）」などを選べます。さらに元の側もカウンターできます。全員パスすると、最後のカードだけが成立します。
4. ターン表示「ROUND n/終了ラウンド」と時計の小針が、成立後に変わることを確認してください。途中で保存・再読み込みしても同じ状態に戻ります。
5. 見てほしい点：
   - いつ出すか（序盤にセカイ枠を埋めるか、終盤まで取っておくか）。
   - カウンターのために時2を残すかどうか。
   - 自分のセカイを置き換える損。
   - カウンターされた側のセカイ枠が空になる扱い（U1）。
   - 本文の長さ（U9）。
