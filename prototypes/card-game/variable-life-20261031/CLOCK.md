# 時計型カウンター（10赤・11緑・12青）の設計検討（机上評価）

**時計の形を理由に、正式ルールは変更しません。** ここでは、本人の構想（12目盛り・3色マーカー・共有の時計1個に独立した3本の針）が、可変ラウンド制とどう合うかを整理します。
前提資料：PR #495 の COUNTER.md §6・§7、DECISION.md（12目盛り＋10の位置に赤いゴールマーカー、長針＝ラウンド・短針＝そだち）。

## 1. 構想の整理
| 部品 | 意味 | 動く頻度（1試合） |
|---|---|---|
| 文字盤 | 12目盛り。10＝赤（100歳・通常のゴール）、11＝緑（110歳・延長）、12＝青（120歳・最大延長） | — |
| 長針（共通） | ラウンド R1〜R12 | 10〜12回（ラウンドごとに1目盛り） |
| 短針A・短針B | 各プレイヤーのそだち（1目盛り＝10、5は半目盛り） | 何度も（ちょうせん+5、カード±5〜10、結婚+10、別れ−10。1ターンに0〜数回） |
| 補助カウンター（各自） | 残りの時（0〜12） | 1ターン平均約2回（設定1回＋支払い約1.3回。PR #495 COUNTER.md §2） |

## 2. 可変ラウンド制との整合（よく合う点）
- **ラウンドの長針：** 通常は赤（10）で止まる。延長カードを使うと、針が赤を越えて緑（11）・青（12）へ進む。**「人生がのびた」ことが目で分かる**。R1〜R12 がそのまま1時〜12時の位置にそろう。
- **そだちの短針：** 1目盛り＝10なので、**100＝赤、110＝緑、120＝青**。そだちの上限とラウンドの終わりが、**同じ色の同じ位置**に来る（10ラウンド＝100歳＝そだち100、の一貫性がそのまま延長にも続く）。
- **今どこまで延びているか（最終ラウンド・上限）を示す「ゴールピン」** を外周に付けると分かりやすい。最初は赤（10）に置き、延長・上限解放でピンを緑・青へ動かす。
  - 延長と上限解放が**1枚で同時に起きる方式（A4）なら、ピンは1本**で済む（最終ラウンドと上限が常に同じ色）。
  - **独立した2種類のカード（A3）なら、ピンが2本**必要（「最終ラウンドのピン」と「そだち上限のピン」）。表示と説明の手間が増える。
  - 延長だけ（A1）なら、ピンは「最終ラウンド」の1本だけ。そだちの上限は常に赤（100）のまま。
- **デジタル版：** 12目盛りのリングを表示し、11・12（緑・青）は**延長されるまで薄く**しておく。延長したら色が付く。そだちのバーも、上限の位置に色の区切りを出す。時計がなくても「赤がゴール、延長で緑・青」と同じ説明で通じる。

## 3. 問題点と対策
| 問題 | 内容 | 対策案 |
|---|---|---|
| **0と12（120）の重なり** | そだちの短針は 0 と 120 が同じ真上の位置。ラウンドの長針も、試合前（0）と R12 が同じ位置 | ラウンドは R1 から始めるので、長針は真上＝R12（青）だけに使う（試合前は1時の位置に置く）。そだちの0は、ゴールピンが青（12）に無いときは「0」、青にあるときだけ「120」と読む規則にする。または、真上のすぐ左に小さな「0」の窪み（やすみ）を作る |
| **3本の針の独立操作** | 普通の時計は歯車で針が連動する。このゲームでは3本が無関係に動く | 同軸の3重パイプ＋針ごとのクリック（デテント）。1本を回しても他の針が摩擦で動かないこと。**短針A・Bを長さか先端の形で区別**（例：Aは丸、Bは三角） |
| **短針A・Bの取り違え** | 2人の短針が同じ長さ・同じ形だと、どちらが自分か分かりにくい。同じ値なら重なる | 色を席の色に合わせる。**赤・緑・青のマーカーとは別系統の色**にする（マーカーと針の色が同じだと読み違える）。重なったときは「同点」と読めるので、むしろ分かりやすい |
| **ラウンドとそだちの針の識別** | 長針＝ラウンドだが、時計の読み方では長針＝分 | 長針を細く長く、先端に「R」や砂時計の印。短針は太く短く、先端に席のマーク |
| **そだちの細かな増減** | 5刻みの増減が多い。2人分の短針を、相手の針に触れずに回す必要 | 半目盛りのクリック（0〜120で24か所）。針のつまみを外周側に出し、自分の側から回せる配置（Aは左下、Bは右下など） |
| **相手の操作で自分の針が動く** | 共有の時計1個だと、相手が回すときに触れる | 3本それぞれに独立したつまみ（外周リング型）。**各自のそだちは手元のダイヤル、共有はラウンドだけ**にする別案も残す（§4） |
| **残りの時** | 3本の針とは別の数値 | 各自の補助カウンター（0〜12）。時はラウンドの値までなので、**長針の位置を見て合わせる**手順で足りる |
| **通常の時計としての商品化** | 3本の独立した手動の針と、時刻を示す時計の機構は両立しない | 文字盤のデザイン（12目盛り＋10赤・11緑・12青）を共通にし、**ゲーム用（手動3本針）と飾り時計用（ムーブメント入り）を別の製品**にする。飾り時計では、赤・緑・青は「10時・11時・12時の色」として意味を持たないデザインの飾り |

## 4. 案の比較
| 観点 | 案1：共有の時計1個・3本針（本人の構想） | 案2：共有の時計1個（長針＝ラウンド）＋各自のそだちダイヤル | 案3：各自の時計（長針＝ラウンド・短針＝そだち）×2 |
|---|---|---|---|
| 時計らしさ・商品性 | ◎ 1個で全部が見える | ○ | ○ |
| 3色マーカーの意味（ラウンドとそだちの一致） | ◎ 1つの文字盤で一致が見える | ○ | ○ |
| 相手の針に触れる誤操作 | △ 対策（独立つまみ）が必須 | ◎ | ◎ |
| ラウンドの二重管理 | ◎ 1か所 | ◎ 1か所 | △ 2台のずれ |
| 部品の複雑さ | △ 同軸3本 | ○ 同軸1本＋ダイヤル2個 | ○ 同軸2本×2 |
| 延長・解放のピン | ○ 1台に1〜2本 | ○ | △ 2台とも動かす |
| 可変ラウンド制との整合 | ◎ | ◎ | ○ |

所見：
- **可変ラウンド制と最もよく合うのは、本人の構想（案1）です。** 延長で長針が緑・青へ進むこと、そだちの上限が同じ色の位置に来ることが、1つの文字盤で一目で分かります。
- 弱点は**操作の干渉**です。試作では、まず案2（共有の長針＋各自のダイヤル）で遊び心地を確かめ、そのうえで同軸3本の機構を作るのが安全です。
- **ゲームのルールの面では、ピンの本数が少ない方式ほど時計と相性が良い**（延長だけ：1本、1枚で両方：1本、独立2種：2本）。ただし、どの方式を採るかはゲームの面白さで決めます（REPORT.md）。

## 5. 10ラウンド制（現行）とのかね合い
- 現行（延長なし）でも、文字盤は「10赤がゴール、11・12は飾り」として使えます（PR #495 の第一候補と同じ）。可変制を採らない場合も、文字盤のデザインを変える必要はありません。
- 可変制を採る場合だけ、11緑・12青が「延長」の意味を持ちます。**文字盤を先に作っても、ルールの決定を後に回せる**（デザインがルールを縛らない）のが、3色マーカー案の利点です。

## 6. 実験結果との対応（REPORT.md）
- 最有望案 A1t（人生延長のみ）なら、外周のピンは**「最終ラウンド」の1本**。そだちの上限は赤（100）のまま動かない。延長は約4〜5割の試合で起き、緑（11）までがほとんど、青（12）は約5%（1枚採用ならほぼ0）。**「赤がゴール、たまに緑まで延びる、青はまれ」**という見え方になります。
- そだち上限解放を別のカードとして加える場合は、2本目のピン（そだち上限）が必要。上限が110・120になる試合は約15%、そだちが110に届く席は1〜2%です。短針が緑・青の位置まで行くことは、ほとんどありません。
- 固定12R（A5）とは違い、ほとんどの試合は赤（10）で終わるので、**「10ラウンド・100歳が基本」という文字盤の読み方は崩れません。**
