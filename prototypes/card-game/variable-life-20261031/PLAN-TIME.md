# 追加計画（本実行の前に固定、2026-11-02）— 時のカード IX・X・XI・XII と特殊カウンター

本人の正式決定（今回の試作の前提）：IX・X・XI・XII は通常のセカイ（しかけない）。使えるラウンドの特別な制限なし（ただし現在のラウンドより前への変更は不可）。自分の番は通常のセカイとして出す。相手が時のカードを出したら、時のカードで特殊カウンターできる（何回でも続けられる）。カウンターされたカードは捨て札。最後に成立したカードの効果だけを適用。終了ラウンドは両者共通。時2（暫定）。同名3枚まで（通常のセカイと同じ）。
**main・本番Pages・正式カード452枚・正式ルール・正式CPU・正式デッキ・保存データは変更しない。既存の時計デザインは変更しない。**

## 1. 実装（実験の隔離ビルド・試遊版の中だけ。`lib/life-patches.mjs` の time 部分）
| 項目 | 実装 |
|---|---|
| カード | `X-T-IX`・`X-T-X`・`X-T-XI`・`X-T-XII`。種類セカイ・時2（条件により3）・レアではない |
| 自分の番 | 通常のセカイ配置（自分の行動機会・時を払う・前のセカイは捨て札）。出した時の強制の能力「終了ラウンドを N にする」が連鎖に乗る |
| 出せない時 | N が現在のラウンドより小さいとき（配置の操作自体が出ない。既存の配置条件の仕組み） |
| 特殊カウンター | 連鎖上で待っている最も新しい時のカードの能力が相手のものなら、応答の機会に手札の時のカードを「カウンター」として出せる（既存の応答の手札カードの仕組み）。セカイ枠へ通常のセカイと同じく配置し、時を払う。その能力も連鎖に乗る |
| 解決 | 連鎖は後から乗ったものから解決（既存）。無効になっていない最後の時のカードが N を適用し、同じ連鎖の前の時のカードをすべて無効にして、場にあれば捨て札へ置く。前のカードは無効として解決される（既存）。**終了ラウンドは連鎖の解決時に一度だけ変わる**（途中では変わらない） |
| 終了判定 | 既存どおり、終了ラウンドの後攻の終了処理の後に最終比較。終了ラウンドより前のラウンドだけ100維持を判定。後攻が現在のラウンドを終了ラウンドにした場合、先攻には番を足さず、応答の機会（カウンター）だけ |
| 場を離れた後 | 終了ラウンドは戻らない |
| 動作確認 | `lib/smoke-time.mjs`（`evidence/smoke-time.txt`、30項目合格。IX→XII→X→XI で XI だけ成立・11、途中は10のまま、先攻 IX で後攻の R9 の番あり、後攻 X で R10 終了、後攻 X に先攻 XII でカウンターして R11 へ、時不足でカウンター不可 など） |

## 2. 条件（MAIN の seed・同じ枠。各デッキの枠は「メイン以外で残り枚数が最も多いカードから1枚ずつ」）
| 条件 | 枠 | 規則 | CPU | seed | 試合数 |
|---|---|---|---|---|---|
| T-X4 対照 | 対照札×4 | 現行 | 正式どおり | 001〜020 | 1,120 |
| **T-2s** | IX・X・XI・XII 各1 | 時2・カウンターあり | 終盤の勝敗見込み | 001〜020 | 1,120 |
| T-2f | 同 | 時2・カウンターあり | 時のカードも普通のセカイとして出す（PR #498 W-* と同じ） | 001〜020 | 1,120 |
| T-3s | 同 | **時3**・カウンターあり | 終盤 | 001〜020 | 1,120 |
| T-2n | 同 | 時2・**カウンターなし**（比較用） | 終盤 | 001〜020 | 1,120 |
| T-X8 対照 | 対照札×8 | 現行 | — | 001〜010 | 560 |
| T-8s | 各2（8枚） | 時2・カウンターあり | 終盤 | 001〜010 | 560 |
計 **6,720戦**。比較対象：既存の A0（現行・PR #495 G-A）・X0・A5（固定12R）。試験運転 392戦（`runs/tpilot-*`、異常0・保存→復元一致）。
- **CPU「終盤の勝敗見込み」（実験専用）：** 時のカードの価値＝（N−その時点で成立しそうな終了ラウンド）×（終盤ほど重い重み：残り1ラウンド以内1・3ラウンド以内0.5・それ以前0.15）×（負けていれば延ばす・勝っていれば縮める方向に、点差に応じて）。相手が100維持中なら延長を避け短縮を好む。変化のないカードは出さない。普通のセカイとしての価値は数えない（置き換えるセカイの損だけ引く）。判断方法そのものは heuristic-2、正式CPUは変更しない。
- 試験運転で、価値0の時のカードが「パスと同点」になり乱数で出される不具合を見つけ、価値0は出さないように修正してから計画を固定した。
