## 2. 原画の仕様（既存452枚と同じ）
| 項目 | 仕様 |
|---|---|
| 大きさ・比率 | **1536×1024 px、3:2 横長** |
| 形式 | **PNG、RGB 8bit、透過なし**（既存452枚はすべて不透過の RGB） |
| 含めないもの | **文字・数値・マーク・カード枠・能力本文**。分類の色も焼き込まない（枠の色は UI が `approved-colors.mjs` から付けます） |
| 画風 | やわらかく、かわいく、繊細な絵本風。自然光・暮らしで個性を出し、主役と顔の周りは読みやすく（`art-pilot/README.md` 美術・素材契約） |
| 構図 | 全景を `object-fit: contain` で表示します。主役を画面の端で切らないでください。上下左右とも、端から約5%には大事なものを置かない |
| 小さい表示 | 一覧では横 80〜110 px のカードになります。主役がその大きさでも分かること（既存の 80／110 px 見本：`art-pilot/previews/iphone-width-80.png`・`-110.png`） |
| 既存との統一 | 同じ種類の既存カードと並べて違和感がないこと。参考：`art-pilot/rollout/final-452-20261019/contact/world-01.png`（せかい13枚）、`event-01.png`（できごと21枚） |
| 登場するキャラクター | 既存の正本（2D本編の種族・顔・体型・色）に合わせる。新しい種族は作らない |

## 3. 受け渡し
1. 原画7枚：`prototypes/card-game/art-pilot/illustrations/<ID>.png`（例：`W-time-ix.png`）。
2. 各画像の SHA-256 と、生成の意図・参照した画像を `art-pilot/provenance.json` と同じ形で記録する。
3. **本人の美術承認**：原画と、600×900 の完成プレビュー（既存の `cardMarkup` で描画したもの）を確認していただきます。
