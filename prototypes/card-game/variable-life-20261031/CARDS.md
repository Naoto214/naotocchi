## 2. 比較の結果（詳細は REPORT.md）
| 項目 | 比べたもの | 結果 |
|---|---|---|
| 時コスト | 延長 時2（A1）・時4（A1c4） | 時4にしても悪い影響はほとんど減らない。最終ラウンドは時が余っている（失効65%以上）ので、コストは抑止にならない。**時2で十分** |
| すぐつかう／しかける | A1・A1t | **しかける（A1t）が良い。** 延長直後に相手の維持勝利の判定が来る形が減り（維持勝利 +3.5pt → +0.4pt）、12Rも 15.9%→4.8%。伏せ札を読む駆け引きが加わる |
| 使えるタイミング | 最終ラウンドのみ（A1）・いつでも（A1a）・いつでも＋1試合1回（A1aL） | **最終ラウンドのみ。** いつでも使えると、R8から負けている側がとりあえず延ばす（12R 20.5%） |
| 採用枚数 | 2枚（A1）・1枚（A1n1） | **1枚の方が良い。** 延長29.6%・12R 0.4%、悪い影響（接戦）も −3.9 → −2.9pt |
| 1試合の使用回数 | 制限なし・各1回（A1aL） | 12Rは減る（22.0%→6.8%）が、延長の頻度は減らない |
| 延長の成功率 | 延長した側（ほぼ全員が負けていた側）の得点率 | 0.11〜0.20。**逆転の手段としては弱い** |
| 上限解放の成功率 | 相手の維持を途切れさせた件数 | 共通（A2）：維持の開始の21.7%を阻止。自分だけ（A2s）：1.2% |
| 引けない場合の不利 | 片方だけ引いた試合の得点率（X0比） | +0.7〜+2.5pt、いずれも有意差なし |
| 先攻・後攻 | 先攻得点率・延長した席 | 0.504〜0.509。延長した席の先攻比率43〜47% |
| 既存カードとの相互作用 | アイテム・じゅんびデッキ、さいごのじかん | 延長ルールはアイテム・じゅんび（準備枠をそろえてから得点）を +5〜+7pt 強くする。「さいごのじかん」はR11・R12で使えない |

## 3. 抜いた2枠（全条件共通。`lib/decks-life.mjs`）
規則：メイン以外で枚数が最も多い2種類（同数ならデッキ記載順）の、それぞれ最後の1枚を同じ位置で置き換える。
| デッキ | 抜いたカード |
|---|---|
| メイン成長 | としをとったじぶん・うんめいのへんしん |
| なかま | ものしりふくろう・はやおきニワトリ |
| こいびと・交際 | こだちのシカ・たかねのワシ |
| ちょうせん | すばしっこいうさぎ・やさしいゴリラ |
| そだち獲得 | いなか・ぐうたらパンダ |
| アイテム・じゅんび | おべんとうばこ・つみかさねタワー |
| バランス | ものしりふくろう・はやおきニワトリ |
| （⑧調査）main+8 | としをとったじぶん・うんめいのへんしん |
- 2枚を対照札にしただけ（X0）で、アイテム・じゅんびは −6.5pt、接戦は +4.6pt、デッキ幅は 0.236→0.156 になりました。正式にカードを加える場合も、**何を抜くか**がバランスに大きく効きます。

## 4. CPU の判断（実験専用の補助、`lifeValue`）
- 延長：負けている（または同点）とき、最終ラウンドに近いほど価値が高い。勝っているときは使わない。相手が維持中なら使わない（相手に判定ラウンドを渡すため）。
- 上限解放：相手が維持中なら大きな価値（共通方式のみ）。自分が維持中なら使わない。自分が上限の近くにいれば少し価値。
- 判断方法そのものは heuristic-2 のまま。新カードの無い対戦では正式CPUと同一（保存sha 168/168一致）。
