## 2. 実装したルール（実験・試遊版。`lib/life-patches.mjs` の time 部分）
| 項目 | 実装 |
|---|---|
| カード | IX・X・XI・XII（セカイ・時2・通常・同名3枚まで）。ID `X-T-IX` など |
| 自分の番 | 通常のセカイとして出す。出した時の**強制の能力**「終了ラウンドを N にする」が連鎖に乗る（こねこのしゃちょう・みずべ・XI/XII と同じ仕組み） |
| 出せない時 | **N が現在のラウンドより小さい時**（配置の操作自体が出ない。既存の「配置条件」）。R11 に X は出せない。R10 に X は出せる（10＝現在） |
| 特殊カウンター | 連鎖で待っている**最も新しい時のカードの能力が相手のもの**なら、応答の機会に手札の時のカードを「〇でカウンター（時2）」として出せる（既存の「応答で手札から出す」仕組み）。自分の時のカードにはカウンターできない。何回でも続けられる（手札と時がある限り） |
| カウンターしたカード | 通常のセカイと同じく**自分のセカイ枠へ配置**（前のセカイは捨て札）。その能力も連鎖に乗る |
| 解決 | 連鎖は後から乗ったものから解決（既存）。**最後の（無効になっていない）時のカード**が N を適用し、同じ連鎖の前の時のカードをすべて無効にして、場にあれば捨て札へ。前のカードは無効のまま解決される（既存）。**終了ラウンドはすべての応答が終わってから一度だけ変わる** |
| 例 | IX → XII → X → XI：XI だけ成立して終了ラウンド11。IX（A が X で置き換え）・X（カウンターされた）・XII（B が XI で置き換え）は捨て札。A のセカイ枠は空、B は XI（動作確認・ブラウザ確認で確認） |
| 終了判定 | 終了ラウンドの**後攻の終了処理の後**に最終比較（既存）。**後攻が現在のラウンドを終了ラウンドにした場合**、先攻には通常の番を足さず、応答（カウンター）の機会だけ。そのまま判定。**先攻が出した場合**、後攻の通常の番はそのまま |
| 場を離れた後 | 終了ラウンドは戻らない（上書きは次の時のカードだけ） |
| 終了ラウンドの範囲 | 9〜12。既存の上限12・1つの値 `life.final`（試遊版の時計・表示もこの値を読む） |

### 処理順の整理（通常のカウンター・コスト・移動）
1. 時のカードを出す（自分の番）：時を払う → 前のセカイを捨て札 → 出したカードをセカイ枠へ → 出た時の能力（強制）を連鎖へ。
2. 応答：相手は、手札の時のカードでカウンターできる（時を払う → 自分の前のセカイを捨て札 → セカイ枠へ → 能力を連鎖へ）。続けて元の側も、相手の新しいカードにカウンターできる。どちらもパスで連鎖の解決へ。
3. 解決：最後の時のカードが N を適用し、前の時のカードを無効・捨て札にする。
4. **通常のカウンター（無効化）との優先順位（将来の規則案）：** 通常の無効化は連鎖の上に乗り、先に解決される。最後の時のカードが無効にされたら、その時のカードは何もしない。次に解決される「無効になっていない最後の時のカード」が適用される。**現行452枚にはセカイの能力を無効にできるカードがないため、この順序は今は起こらない**（未確定事項）。

## 4. CPU の判断（実験専用の補助）
- **smart（終盤の勝敗見込み）：** 価値＝（N−その時点で成立しそうな終了ラウンド）×重み×方向。
  - 重み：残り1ラウンド以内は1、3ラウンド以内は0.5、それ以前は0.15。
  - 方向：負けていれば延ばす、勝っていれば縮める（点差に応じて）。
  - 相手が100維持中なら、延長を避けて短縮を好む。
  - 変化のないカードは出さない。普通のセカイとしての価値は数えず、置き換えるセカイの損を引く。
  - カウンターも同じ式で、連鎖で待っている時のカードの数字と比べて評価する。
- **filler（比較用）：** 普通のセカイの価値（セカイ枠が空なら9）＋上の変化の価値（PR #498 W-* と同じ考え方）。

## 5. CPU シミュレーションの結果（要約。詳しくは REPORT.md §13）
- 6,720戦すべてが最後まで進み、保存→復元はすべて一致しました。カウンターの最長は各1枚で4枚、各2枚で6枚で、無限に続くカウンターは起きませんでした。
- T-2s（時2・カウンターあり・各1枚）：
  - 平均終了ラウンドは 10.50（R9 12.9%・R10 40.0%・R11 31.2%・R12 15.8%）。
  - カウンターは40%の試合で起き、成立したラウンドは R7 が最多でした。
  - 先攻の有利・デッキ幅・接戦は対照と差がありません。維持勝利は +1.4pt、アイテム型は +8.5pt でした。
  - 延ばした側の得点率は 0.20、縮めた側は 0.78 でした。
- カウンターなし（T-2n）でも数字はほぼ同じでした（後から出した側が上書きするため）。
- 時3（T-3s）も、時2との差はありませんでした。
- 各2枚（T-8s）では、カウンターが79%の試合で起き、接戦は −5.9pt、そだち獲得は −7.5pt に悪化しました。
