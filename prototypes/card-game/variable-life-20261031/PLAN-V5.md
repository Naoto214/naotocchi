## 2. CPU smart4（実験用。正式CPUは変更しない）
smart3（VERSION 4）に、次の変更を加えました。新カードがない対戦では、smart2 と完全に同じ判断をします（V2C と同じ seed で112戦、保存ハッシュ 112/112 一致、`runs/v5eq-*`）。

1. **ながいきのひけつ：** 「今使う価値」と「温存する価値」を比べます。
   - 温存する価値＝（5＋10×終了ラウンドが11以上になる見込み×その時に負けている見込み）×終盤の重み×0.95。
   - 延長の見込みは、自分の手札の XI・XII とラウンドから見積もります。相手の手札は使いません。
   - **今使う場合：** 終了ラウンドがすでに11以上で負けている（+15）、最後のラウンド、+5 で100に届く（100維持の開始）。
   - 序盤の使用を一律に禁止はしません（価値の比較の結果として温存します）。
2. **おもいでのしゃしん：** 手札にある時、自分の時のカード以外のセカイを時のカードで置き換える損に、しゃしんの +5 を足します。
3. **おいわいのつる：** D1〜D3 のすべてを、時のカードの勝率見込みに足します（R10以降の回数×5）。
4. **はやじまい＋IX、特殊カウンターによる上書きの見込み：** smart3 のままです。

確認：smart4 の判断の5項目に合格しました（smoke-v5）。

## 4. 判定の規則（結果を見る前に固定）
- **おいわいのつるの公平性：**
  - 先攻得点率が、比較基準と有意に違わない（95%CI が0をまたぐ）こと。
  - かつ、R8 に負けていた側の得点率が上がること。
  - D2・D3 のうち、両方を満たし、先攻得点率の差の絶対値が小さいほうを推奨します。どちらも満たさなければ「見送り」です。
- **カードの組み合わせ：** 次の3点で比べます。
  - R8 に負けていた側の得点率の差。
  - 公平性の3指標（先攻得点率・デッキ幅・接戦）に、有意な悪化がない。
  - アイテム型が有意に強くならない。
- **最終推奨の候補：** 上の条件を満たす中で、逆転の改善が大きく、使うカードの種類が少ない構成を優先します（カードを増やすと、既存の強いカードが抜ける損があるため）。
