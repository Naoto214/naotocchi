## 試遊版の仕様（実験の A1t1 と同じ規則）
| 項目 | 内容 |
|---|---|
| カード | 人生延長（仮）：できごと・時2・**しかける**。「自分のターン終了時、現在のラウンドが最終ラウンドの場合に発動できる。最終ラウンドを1つ後ろへのばす（両プレイヤー共通・最大R12）」 |
| デッキ | 対戦開始時、両者のデッキの1枚を人生延長に入れ替える（メイン以外で枚数が最も多いカードの最後の1枚。実験と同じ規則）。何を入れ替えたかは開始時に画面下へ表示。マイデッキに自分で入れてある場合は入れ替えない（2枚以上入れて試すこともできる） |
| 延長 | 1ラウンドに1回まで（両者合計）。R10→R11→R12。時は R11＝11、R12＝12 |
| 維持勝利 | 100維持のまま（上限100固定）。延長すると R10（R11）も維持勝利を判定するラウンドになる |
| 表示 | ターン表示が「ROUND n/最終ラウンド」。延長後は緑（R11）・青（R12）の「延長」バッジ。結果画面に「R10終了時点のそだち」を追加（延長後の逆転を確かめるため） |
| 保存 | 端末内の保存の鍵はすべて `naotocchi-life-trial:` 付き。正式版の対戦・戦績・マイデッキには触れない。保存の形（seed・デッキ・コマンド）は正式と同じで、最終ラウンドは再生で作り直す |
| 戦績 | R11・R12 で終わった対戦も記録できる（試遊版の中だけ、ラウンド12まで許可） |
| ひとりであそぶ | CPU 対戦でも同じ規則（CPU の使い方は実験の評価式。負けていると延長しやすい） |
| 制限 | 「保存ファイルを書き出す」は、公開先がダウンロードを許可しないため働きません（これまでの試遊版と同じ）。端末内の保存と「保存した対戦に戻る」は使えます |

## iPhone で確認していただきたい操作
1. ページを開き、「ふたりであそぶ」を押す。赤い枠の「試遊版：人生延長（仮）」の説明を読む。
2. A・B のデッキを選んで「新しい対戦を開始」。画面下に「試遊版：A：○○ → 人生延長（仮）／B：…」と、入れ替えたカードが出る。
3. 交代のたびに「手札を隠して渡す」画面が出る。受け取った人が表示してから操作する。
4. 人生延長（仮）を引いたら、カードを押して「人生延長（仮）をしかける（時2）」。いつしかけてもよい（時2は、しかけたときに払う）。
5. 相手側の準備枠には「しかけたカード」（裏向き）とだけ表示され、中身は分からない。
6. **R10（最終ラウンド）の自分の番で「ターン終了を申し出る」**と、終了時に「人生延長（仮）の能力を発動」か「見送る」を選ぶ画面が出る。
7. 発動すると、最終ラウンドが R11 になり、ターン表示に緑の「延長」バッジが付く（先攻が延ばしたときは後攻の番が「ROUND 10/11」、後攻が延ばしたときは次の番が「ROUND 11/11」）。R11 も同じ手順で R12 へ延ばせる（青のバッジ）。
8. 対戦が終わると、結果に「R11最終比較」（または R12）と「R10終了時点 · A ○ / B ○」が出る。R10の時点で負けていた側が勝ったかどうかを確かめられる。
9. 途中で ☰ →「カードゲームトップへもどる」→「ふたりであそぶ」→「保存した対戦に戻る」で再開しても、延長した最終ラウンドはそのまま。

### 重点的に見てほしい点（本人の指示）
- **伏せた延長カードによる読み合い：** 準備枠の伏せ札が「延長かもしれない」と思わせるか。延長を警戒して相手の動きが変わるか。
- **延長のタイミング：** いつしかけるか（早く伏せると準備枠を1つふさぐ・時2を先に払う）。R10で負けているときだけ使うか、同点でも使うか。先攻が延ばした場合、後攻は R10 の自分の番をそのまま遊べる。
- **延長後の逆転の可能性：** 結果画面の「R10終了時点」と最終結果を見比べる。実験（CPU同士）では、延長した側（ほぼ負けていた側）の得点率は約0.12でした。
- 気づいたこと：先に延長されると、勝っている側の100維持勝利の判定ラウンドが増えることがあります（延長した直後の判定）。

## 公開前の確認（`qa-trial.cjs`、Chromium・タッチ、390×844 と 844×390）
- 新しい2人対戦で、両者のデッキに人生延長が1枚ずつ入り、戦績用のデッキと一致する。保存の鍵はすべて試遊版専用。
- R10・後攻B（B 65・A 80、両者が人生延長を手札に持つ）の保存（`fixtures/r10-both-hold.json`、`make-save.mjs` が試遊版と同じモジュールで作成）から再開し、画面のボタンだけで：
  B がしかける → R10 の自分の終了時に発動 → ROUND 11/11・延長バッジ → A が R11 にしかける（**Bから見ると「しかけたカード」で中身は非公開**）→ 再読み込み・再開しても ROUND 11/11 → A が R11 の終了時に発動 → ROUND 12/12 → R12 後攻の終了で「R12最終比較」・「R10終了時点 · A 80 / B 65（人生延長でR12まで）」→ 戦績に R12 の対戦が記録。
- 両方の向きで成功、ページエラー0件、横スクロールなし。公開用（large 画像のみ）の組み立てでも同じ確認が成功。記録：`evidence/qa-log.txt`・スクリーンショット。
- 確認中に分かったこと：「たこやきやさん」（しかけ）は、自分の準備枠の人生延長を対象にできる（既存カードとの相互作用。不具合ではない）。
- WebKit（Safari の描画エンジン）はこの作業環境に無いため未実行です。iPhone の実機で確認してください。
