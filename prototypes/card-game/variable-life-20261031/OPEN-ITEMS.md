## 4. 短い効果文の案（U9）
**共通ルール：** ルールブックの「時のカード」の項にまとめ、カードには書きません。
- 両者共通。
- 現在のラウンドより前にはできない。
- 相手の時のカードにカウンターとして出せる（何回でも）。
- カウンターされた時のカードは効果なし・捨て札。
- 最後の1枚だけが成立する。

| カード | 短い本文の案 |
|---|---|
| IX | 【時のカード】終了ラウンドを9にする。 |
| X・XI・XII | 同じ形（10・11・12） |
| はやじまい | 負けていて、終了ラウンドが次のラウンドの時に使える。そだち+5（終了ラウンドが10なら+10、9なら+15）。1ターンに1回。 |
| ながいきのひけつ | そだち+5。終了ラウンドが11以上で負けているなら、さらに+10。 |
| おもいでのしゃしん | 終了ラウンドのラウンドに使える。自分のなかま・こいびと・セカイ（時のカードを除く）1枚につきそだち+5（最大+15）。1ターンに1回。 |
