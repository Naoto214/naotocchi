## 仕様（実験 W-A／W-B／W-C と同じ規則）
| 項目 | 内容 |
|---|---|
| カード | せかい「XI」「XII」（時2・レアではない）。ふつうのセカイと同じく、自分の番に手札から出す（前のセカイは捨て札へ）。出した時、終了ラウンドが変わる（両者共通・最大12）。そだち上限は100のまま |
| 方式 | 対戦の準備の赤い枠で選ぶ（既定は A）。**A**：XI→11。XII は終了ラウンド11以上のときだけ出せて→12。**B**：XI→11、XII→12 を独立に（短くはならない）。**C**：XI・XII とも1つのばす（最大12） |
| デッキ | 対戦開始時、両者のデッキの2枚を XI・XII に入れ替える（実験と同じ枠）。何を入れ替えたかは画面下に出る。方式はカードに入るので、保存した対戦はその方式のまま再開される |
| 延長後 | 出したセカイが後で場を離れても、終了ラウンドは戻らない。延長すると R10（R11）も100維持の判定ラウンドになる |
| 表示 | ターン表示が「ROUND n/終了ラウンド」、延長後は緑（11）・青（12）の「延長」バッジ。結果に「R10終了時点のそだち」 |
| 保存 | 鍵はすべて `naotocchi-world-trial:` 付き（正式版・A1t1 試遊版と別）。戦績は R12 まで記録 |
| 制限 | 「保存ファイルを書き出す」は公開先の制約で働きません |

## 確認していただきたい操作
1. 「ふたりであそぶ」→ 赤い枠の「XI・XII の方式」で A／B／C を選ぶ → デッキを選んで「新しい対戦を開始」。
2. XI・XII を引いたら、カードを押して「XIを配置（時2）」。出した時の効果は「効果を使う」操作で処理される（強制）。
3. ターン表示が「ROUND n/11」「ROUND n/12」に変わる。A では、終了ラウンドが10の間は XII の配置が出てこない。
4. 結果画面で「R10終了時点」と最終結果を見比べる。
- 見てほしい点：いつ出すか（序盤にセカイ枠を埋めるために出すか、終盤まで取っておくか）、自分のセカイ（もり・いなか・おうち等）を XI・XII で置き換える損、方式ごとの分かりやすさ。CPU 同士では序盤に出されることが多く、延長が大半の試合で起きました（REPORT §12）。
