# 04. 表示見切れ候補の実画面QA

対象: PR #459 で「概算で見切れの疑い」とされた19枚（E 18＋M-stagbeetle-06）。参考として M-sakura-06（144字、最長）を加えた**20枚**。基準 main `85a59bb3`。**UIコードは変更していません。**

## 結論
- **カード面で本文が実際に見切れたカード: 0枚**（20枚×全画面幅×2画面、84セルすべて）。前回の概算（E）は、カード面の自動縮小（`fitMainCardCopy`：はみ出す時に本文を3.1cqwまで縮める）を考慮しておらず、実際には当たっていませんでした。
- **全文は必ず読める**: コレクションの詳細パネル、対戦中の詳細パネルとも、本文は欠けず、全20枚×全画面幅で正式本文と一致。
- ただし実画面で**別の、より一般的な問題**が見つかりました（D）: 対戦中のカード詳細で「能力全文」が**小さな内側スクロール枠**に入り、狭い・短い画面では初期表示で一部しか見えません。20枚固有ではなく、複数行の本文を持つ全カードに共通です（コントロールの51字カードでも320幅で同じ）。

## 方法（再現可能・読み取り専用）
- スクリプト: [display-qa/run-display-qa.mjs](display-qa/run-display-qa.mjs)（本番画面を操作するだけ）、集計 [summarize-display-qa.mjs](display-qa/summarize-display-qa.mjs)。結果 [results.json](display-qa/results.json)、分類表 [display-qa-matrix.csv](display-qa/display-qa-matrix.csv)、スクリーンショット [screenshots/](display-qa/screenshots/)（336枚）。
- 画面幅: 320×568・375×667・390×844・430×932（縦）。横向き 844×390 は最長の4枚（M-coral-06, M-stagbeetle-06, M-woman-02, M-sakura-06）。
- 画面（5種のうち実際に本文が出る面）:
  1. カード通常表示＝コレクションの棚（9ポケット）。通常表示のカードには本文を出さない設計（`compact`）。題名の見切れだけ確認（見切れなし）。
  2. カード拡大表示＝コレクション詳細の表カード。本文の見切れ・実効フォントを測定。
  3. カード詳細パネル＝コレクション詳細の本文欄。正式本文との一致・画面内表示。
  4. コレクション＝上記の棚→詳細の遷移（検索でカードを開く）。
  5. 対戦中の表示＝本番の「保存した対戦に戻る」から、手札のそのカードを開く詳細（カード面＋能力全文）。
- 前回(#459)の推定との差を測るため、文字数の違うコントロール7枚（M-jellyfish-03 51字〜M-dog-06 106字、既存の2.9cqw例 M-cat-07・M-antlion-06）も同じ手順で測定（[baseline-results.json](display-qa/baseline-results.json)）。

## 分類
- A: 全文が読める／B: 軽微（全文は読めるが面の本文が既存の許容水準 2.9cqw より小さい）／C: 実際の見切れ（面・詳細とも全文を読めない）／D: 画面幅・向き・状態に依存（初期表示で一部のみ。操作で全文は読める）。

- **カード別の最終判定は20枚とも D**（390・430では A、320・375・横向きで D）。C は0。
- D の中身: 対戦中の詳細の能力全文枠が、320幅で約42px（約2行）、375幅で約102px（約4.6行）、横向きで約52px（約2.4行）。全文は約6〜10行相当なので、初期表示で見えるのは全体の約20〜25％（320幅）、約53〜69％（375幅）、約41％（横向き）です（下表）。390幅以上では枠が十分大きく全文が見えます。
- カード面の本文の実効フォント: コレクション詳細で 6.5px（320）／7.6px（375）／8.0px（390）／8.2px（430）、対戦中の詳細で約9.1px（全幅）。100字前後より長いカードは自動縮小（3.1cqw）に入り、これは既存の許容例（M-cat-07・M-antlion-06/07 の 2.9cqw）より大きいため B には当たりません。面の本文は縮小ミニチュアで、読みやすい全文は詳細パネルが担っています。

## 限界（正直に）
- 使用したのは Chromium（Playwright）で、**実機の iPhone Safari（WebKit）ではありません**。日本語フォントの寸法が実機と異なる可能性があり、実機での最終確認は本人QAです。
- 対戦中の画面は「保存した対戦」の開始直後（手札のカードを開く詳細）で測っています。この状態では必須選択の操作ボタンが詳細内に出るため、能力全文枠の高さは**この状態の値**です。通常手番の詳細では行動ボタンの数が変わり、枠の高さも変わります。通常手番の再現は途中で打ち切りました（実装済みの操作手順では再現できず、未確認）。
- 「効果が発動・解決される瞬間の連鎖表示」は、カードごとに必要な盤面が異なるため再現していません。同じ本文が出る詳細パネルで代替しています。
