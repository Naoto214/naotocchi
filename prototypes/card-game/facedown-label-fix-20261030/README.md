# 伏せ札の表示：持ち主には自分の伏せ札の名前を出す（2026-10-30、Draft・本人の別承認までマージしない）

表示だけの修正です。カードの効果・伏せ札ルール・保存形式・対戦の版は変えていません。基準は main `e33ec25a`。**mainマージ・本番Pages更新はしていません。**

## 1. 原因

- 盤面の伏せ札は、もともと持ち主には名前、相手には「しかけたカード」と出ていました（`engine.mjs` の `view`）。
- 問題は**行動ボタン・対象選択・連鎖の対象**の文言です。相手の伏せ札を隠すために、文言の中の「相手が伏せている札の名前」を**文字列で一括置換**していました（`privateLabel`）。
- そのため、**相手が同じ名前の札を伏せていると、持ち主自身の札の名前まで「しかけたカード」になっていました**（例：両者がボンバーを伏せている時、持ち主の画面で「しかけたカードの能力を発動」「対象 1：しかけたカード」）。同じデッキどうし・同じカードを使う対戦ほど起きやすい。

## 2. 修正（`engine.mjs` だけ）

| 箇所 | 修正前 | 修正後 |
|---|---|---|
| 対象選択の文言（`selectionPrompt`） | 名前の文字列置換 | カードごとに判定：閲覧者に見えない伏せ札だけ「しかけたカード」 |
| 連鎖の対象（`view` の chain） | 名前の文字列置換 | カードごとに判定（従来の hiddenTargets の扱いはそのまま） |
| 行動ボタン（`view` の actions） | 相手の伏せ札の名前を全部置換 | 行動が指すカード（発動元・対象・支払い・選択肢）を見て、**閲覧者に見える札と同じ名前は、出てくる回数がその札の数と一致する時だけ残す**。それ以外は従来どおり置換（迷ったら隠す側） |

- 相手の伏せ札を指す行動では、その名前は必ず置換します（相手から見える情報は増えません）。
- CPU の観測（`cpu-observation.mjs`）は文言を使わないので変わりません。CPU に非公開情報は渡りません。
- 文言は保存に入らず（保存は操作列だけ）、復帰後も同じ表示になります。
