# 早期たんじょう・段階成長の戦略的価値と、既存カード効果の改善候補（2026-10-27）

PR #447の正式決定（たまごの共通ルールは現行維持）を前提に、既存カードの効果で「早く生まれて育つ」選択の価値を高められるかを調べました。
**正式カード本文・効果・数値・ゲーム処理・CPU判断・正式ルールは変更していません。新しい対戦も行っていません**（既存記録の読み取りだけ）。

- 対象カード一覧：[results/target-cards.md](results/target-cards.md)（142枚、本文は正式カタログのまま）
- 使用状況：[results/card-usage.json](results/card-usage.json)、メイン移動の集計：[results/main-moves.json](results/main-moves.json)
- 将来の比較実験の計画：[EXPERIMENT-PLAN.md](EXPERIMENT-PLAN.md)

## 0. 結論（先に）

1. **早期たんじょうには、既存カードによる価値がすでにあります。**
   - たんじょう時に発動する①の能力（22枚）は、早く低段階で出した時だけ得られます。
   - ②・③の毎ターン能力は、場にいるターンが多いほど使えます。
   - その結果、早期たんじょうはメイン能力の発動回数が多くなっています（1試合平均 A 1.49 → B 0.88 → C 0.31）。
   - ただし、1回ごとの利益は「山札上1枚を見る」「このターン能力値+1」程度が中心で、勝率差になるほどではありません。
2. **「段階を1つずつ育てる」ことに直接報いるカードは少なく、そのうち2枚は条件が厳しすぎてほぼ機能していません。**
   - ぴょんぴょんジャンプ（G-doodle-jump）のそだち+5と、ジャンプクエスト（G-jump-quest）は、どちらも「1ターンにときおくり2回」が条件です。
   - 既存2,240戦で、そのターンが来たのはときおくりをしたターン939回のうち17回（1.8%）、席単位で3%でした。
   - 一方、ときおくりの53%は「1段階だけ」上がる成長でした。
3. **改善候補は2枚だけに絞りました。最初に試すのは1枚（ぴょんぴょんジャンプ）を推奨します。** その他のカードは現行維持を推奨します（§4）。
4. 早期たんじょうを必ず有利にすることは目標にしていません。改善案は「育てる経路を選んだ時の手応え」を増やすだけです。
   長期待機・高段階への直接たんじょうでも得られる「この段階になった時」系のカード（10枚）には手を付けず、待機も選択肢として残します。

## 3. 既存データから分かったこと（再実行なし）

使ったデータ：PR #447 の2,240戦（現行ルール1,120戦）と、CPU 7デッキ6,600戦（第4段階・恋人デッキ・7デッキ横断の保存記録）、旧試験デッキ1,680戦。

### 3.1 早期たんじょうで得られるカード能力の価値

| 指標（現行ルール、PR #447） | A 早期 | B R4から | C R7で高段階 |
|---|---|---|---|
| メイン能力の発動（1試合） | 1.49 | 0.88 | 0.31 |
| ときおくり（1試合） | 1.77 | 1.13 | 0.19 |
| へんしん（1試合） | 0.21 | 0.17 | 0.04 |
| 最初の段階 | 1.62 | 2.94 | 4.66 |
| 試合終了時の段階 | **4.94** | **4.93** | **4.90** |
| 得点率（Aとの差） | — | +0.037 | −0.005 |

- **早く生まれても、最終的に到達する段階は同じ（約⑤）です。** 違いは「途中の能力を何回使えたか」と「その間ちょうせんに参加したか」だけです。
- 早期たんじょうの能力の利益は小さく（下表）、相手のちょうせん機会も増やすため、勝率では相殺されています（PR #447）。

### 3.2 低段階メインの使用頻度

CPU 7デッキでの「引いた枚数あたりの使用（play/draw）」と「試合終了時も手札に残った割合（stuck）」：

| 段階 | play/draw | stuck | 例 |
|---|---|---|---|
| ① | 0.32〜0.50 | 0.38〜0.67 | ねこ① 0.33／0.67、いぬ① 0.35／0.66、かめ① 0.37／0.56 |
| ② | 0.37〜0.48 | 0.41〜0.63 | ねこ② 0.38／0.63、サクラ② 0.38／0.58 |
| ③ | 0.34〜0.52 | 0.42〜0.66 | カブト③ 0.34／0.66、キノコ③ 0.52／0.48 |
| ⑤〜⑥ | 多くは0.78〜1.00（いぬ⑤ 0.64、カブト⑥ 0.47を除く） | 0.00〜0.25（カブト⑥ 0.49を除く） | ねこ⑤ 0.99、サケ⑤ 0.99、サクラ⑥ 0.97 |

- 低段階は1試合に最初の1枚しか出番がなく、残りは手札で使えないまま終わることが多いです（同種族の過去段階へは戻れない）。カード効果の弱さというより、**構造上の性質**です。
- 既存カードには、余った低段階を価値に変えるもの（カクレクマノミ②、ほし②、昔のアルバム、ソリティア、？？？⑧）がありますが、CPU 7デッキには入っていません。カード変更よりデッキ構築の問題です。

### 3.3 ときおくり・へんしんの使用状況と、段階を飛ばす利点

- ときおくりの上がり幅（A、496回）：1段階 53%、2段階 30%、3段階 14%、4段階以上 3%。平均1.68。
- 1ターンに2回以上ときおくりしたのは、ときおくりをしたターン939回中17回（**1.8%**）、席の3%。
- 段階を飛ばす利点：時が毎ターン「そのラウンドの値」に戻るため、1回で大きく上げる方が時の効率は同じで手札の消費が少なく済みます。ただし飛ばした段階の能力（skip_arrival・leave_by_move）は得られません。現状では、その差を埋める「1段階ずつ育てた報酬」はほとんどありません。
- へんしんはメイン成長デッキ（1試合1.1回）とちょうせんデッキ（0.45回）だけで使われています。

### 3.4 早期たんじょう／長期待機が有利になるデッキ（PR #447、各n=40で目安程度）

| デッキ | A 早期 | B R4から | C R7で高段階 | メイン能力（A） |
|---|---|---|---|---|
| ちょうせん | **0.725** | 0.588 | 0.588 | 2.29 |
| メイン成長 | 0.562 | 0.600 | 0.487 | 2.14 |
| こいびと | 0.412 | **0.575** | 0.450 | 1.96 |
| そだち獲得 | 0.450 | 0.463 | 0.512 | 2.35 |
| なかま | 0.425 | 0.450 | 0.550 | 0.53 |
| アイテム | 0.375 | 0.438 | **0.225** | 0.24 |
| バランス | 0.438 | 0.537 | 0.537 | 0.59 |

- 早期たんじょうが報われるのは、メイン能力とちょうせんの補正に依存するデッキ（ちょうせん）。
- 長期待機（C）で落ちるのは、メインに装備を重ねるアイテムデッキ。
- なかま・バランス・そだち獲得は、メインに依存しない得点源が多く、待機しても大きく損をしません。

### 3.5 序盤のメイン能力が使われない原因（カード効果とCPU判断の区別）

| 原因 | 例 | 区分 |
|---|---|---|
| 1回の利益が小さい | 「山札上1枚を見て上か下」（かめ③、ペンギン②、サンゴ②など） | カード効果（意図的な小ささ。初心者向けの安定） |
| デッキの条件に合わない | いぬ③（自分のちょうせんで負けた時）、サケ③（セカイを変更した時）、サクラ③（捨て札に装備） | デッキ構築 |
| 発動条件がほぼ成立しない | ぴょんぴょんジャンプ・ジャンプクエスト（1ターンにときおくり2回、成立1.8%）、ゆきのせいれい（ときおくりで⑦か⑧、発動 0.03〜0.05） | **カード効果** |
| CPUの評価が弱い | 予約型の効果（`reserve`）、`setFromHand`、手札を山札下に置くコスト（キノコ②）、ピクロス | **CPU判断**（PR #406・#407の報告書で既に記録済み） |

ぴょんぴょんジャンプは、引いた369枚が一度も使われていません。これには「+5の条件がほぼ成立しない」というカード側の理由と、「CPUが予約効果を小さく評価する」というCPU側の理由が重なっています。改善案の検証では、CPU判断と分けて測ります（[EXPERIMENT-PLAN.md](EXPERIMENT-PLAN.md)）。

### 4.2 改善候補（優先順位つき、最小限）

| 優先 | カード | 問題 | 方向 |
|---|---|---|---|
| **1** | ぴょんぴょんジャンプ G-doodle-jump（あそび・時1） | そだち+5の条件「同じターンに2回目のときおくり」がほぼ成立しない（1.8%）。成長の手応えを表すカードなのに機能していない | 1回のときおくりで、**1段階だけ上がった時**に+5 |
| 2 | ジャンプクエスト G-jump-quest（あそび・時1） | 発動条件「このターンにときおくり2回以上」がほぼ成立しない。使用率0.01 | 条件を「このターンにときおくりを行っている」へ緩和（1と同時採用はしない） |

### 4.3 候補にしなかったもの

- **ゆきのせいれい P-snow_spirit**（ときおくりで⑦か⑧になった時）：到達段階が平均⑤のため、ほぼ発動しません（0.03〜0.05）。ただしこいびとカードはPR #446（恋人18種類の監査）の範囲なので、ここでは改善候補にせず、参考として記録します。
- **低段階が手札に残る問題**：構造上の性質で、既存の再利用カードがあります。全低段階の能力強化は大量変更になり、初心者向けの単純さも損なうため推奨しません。
- **ピクロス・ときのチケット・あと**：使用0の主因はCPU評価（探索の当たり確率・`setFromHand`）で、カード効果を変える根拠になりません。
- **共通ルールでの「段階を経た報酬」**：PR #447の決定と正本02の方針（まずカード側）に反するため扱いません。

## 5. 改善案の比較

### 5.1 候補1：ぴょんぴょんジャンプ G-doodle-jump（推奨）

| 項目 | 内容 |
|---|---|
| 現行本文 | このターン、自分が次にときおくりを行った時に1枚引き、その次にときおくりを行った時に自分のそだち+5。 |
| 改善案の本文 | このターン、自分が次にときおくりを行った時、1枚引く。そのときおくりで段階が1つだけ上がった場合、さらに自分のそだち+5。 |
| 変更点 | +5の条件を「2回目のときおくり」から「1回目のときおくりで段階が1つだけ上がった」へ。時コスト1・ドロー1・+5の数値は変えない |
| 期待される効果 | ①→②→③と1段階ずつ育てる経路に、そだちという手応えが付く。大きく飛ばす（①→④）か、1段階ずつ育てるかの選択が生まれる。長期待機・直接高段階の価値は下げない |
| 強くなりすぎるリスク | 時2（カード1＋ときおくり1）で「1枚引く＋そだち+5」。同じ時1のあそびの相場（ルナランダー：残り時ちょうど2で1枚＋5、ミニゴルフ：プレイ1枚だけなら＋5と1枚、リズムハイウェイ：条件付き＋5と1枚）と同程度。3枚入れても最大+15で、ときおくりは1試合平均1.8回なので、実際は1〜2回が上限 |
| 他カードへの影響 | カブトムシ④（ときおくり−1）、ハンググライダー3D（−2）と組むと時1で+5になり得る。それでも「1段階だけ」の条件で上限は同じ。しばいぬ・とかい・セミ③とは同じターンに重なっても+5は1回 |
| CPU判断への影響 | 現行CPUは予約効果を小さく評価するため、改善しても使用が少ないままの可能性があります。CPU判断の変更は今回の範囲外で、検証ではCPUとカードを分けて測ります |
| 保存互換性 | 保存は操作列の再生方式なので、本文を変えるとこのカードを使った旧保存の再生結果が変わり得ます。カード版の区別（旧本文で復帰）か保存形式の版上げが必要です |
| 必要な検証 | EXPERIMENT-PLAN.md の実験1・2（効果の強さ、待機の選択肢が残るか、上限） |
| 現行維持との比較 | 現行は事実上「時1で1枚引く」予約カードで、名前・イラストが表す「ぴょんぴょん育つ」楽しさがゲームに出ていません。変更は1枚・条件1つだけで、初心者にも「1つだけ上がったら+5」と読みやすい |

## 6. 変更した場合の影響範囲（今回は何も変更していません）

| 範囲 | 影響 |
|---|---|
| 正式カード本文 | `full-catalog.mjs` の該当1枚の本文と出典ハッシュ、設計正本（ぴょんぴょんジャンプは `85-play-batch-4-card-text-draft.md`、ジャンプクエストは `81-play-batch-2-card-text-draft.md`） |
| 効果の実装 | ぴょんぴょんジャンプ：`remaining-rules.mjs` の予約（`reserve('time_skip', …)`）に、直前の段階との差の条件を追加。ときおくりの出来事は直前のメイン（`previousMain`）を既に持っているため、エンジンの共通処理の変更は不要の見込み。ジャンプクエスト：`rules.mjs` の条件 `twoTimeSkips` を「このターンにときおくりあり」に変更 |
| 他カード | §5の組み合わせ（カブトムシ④・ハンググライダー3D・しばいぬ・とかい・セミ③・ほし②・ソリティア・昔のアルバム） |
| CPU判断 | 変更不要。ただし予約効果の評価が弱いため、使用頻度は上がりにくい（CPU改善は別承認） |
| ルールブック・コレクション | カード本文の表示のみ。共通ルール・チュートリアルは変更なし |
| 保存互換性 | 旧保存の再生互換のため、カード版の区別か保存形式の版上げが必要 |
| 固定400戦の証拠 | 固定400戦のデッキにはどちらのカードも入っていない（デッキA／Bの全41種を確認）。証拠には影響しない |
| CPUデッキ | 現行のCPU 7デッキにはどちらも入っていない。デッキに入れるかは別判断 |

## 7. 限界・未確認事項

- 使用状況はCPU同士の記録で、CPUが評価しにくい効果（予約・探索・手札コスト）は過小に出ます。
- CPU 7デッキは31種族中8種族しか使っていません。残り23種族の低段階は使用データがなく、本文からの評価だけです。
- デッキ別の早期／待機の差は、1条件40戦で目安程度です。
- 改善案の強さは計算と相場比較だけで、対戦では確かめていません（実験は計画のみ）。
- 人間が遊んだ時の「育てる楽しさ」は、実機試遊でしか確かめられません（PR #447 の課題①〜③）。
