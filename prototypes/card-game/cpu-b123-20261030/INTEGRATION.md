## 3. B-1 と B-2 の関係（コードからの確認）
| 局面 | B-1 だけ | B-2 だけ | 組み合わせで起き得ること |
|---|---|---|---|
| 自分の勝負のスキージャンプ（しかけ・時0） | 正しい能力値を選ぶ | 変化なし（時0なので相殺されない） | 独立 |
| 自分の勝負中の応答（自分ターン） | 正しい型を選ぶ | 変化なし（自分ターンの応答は機会費用ではなく `legacySpend`） | 独立 |
| 相手の勝負中、かくとうバトル**1枚** | 正しい型を選ぶ（同じカードの型どうしは相殺の対象外） | 変化なし | 独立 |
| 相手の勝負中、かくとうバトル**2枚**（または同価値の補正カード2枚）、時が1枚分だけ | 2枚の「正しい型」どうしが相殺し合い、0点でパスと同点のまま残り得る | 相殺は消えるが、型は乱数で選ぶ | **相乗効果**：両方で初めて「正しい型を確実に使う」になる |
| 自分ターンの通常行動（たんじょう・ときおくり・配置） | 変化なし | 相殺が消える | 独立 |
| 最終ターン（#491 B2） | 変化なし | 同名2枚の相殺は B2 でも残る | B2 と B-2 にも同じ相乗の可能性 |

結論：B-1 と B-2 は**別の箇所**（B-1 は候補の価値、B-2 は時の機会費用の差し引き）を変えます。ほとんどの局面では独立です。ただし「相手ターン・同価値の補正カード2枚・時が足りない」局面だけは相乗効果があり得るため、組み合わせの比較が必要です。
