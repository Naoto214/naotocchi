# CPUデッキの検討（比較候補の資料のみ・正式7デッキは変更しない）

方針：時を使い切るためだけにデッキを変えない。各デッキの戦略・個性・勝率を保護する。以下は、本人が判断するための材料です。

## 1. 相手ターン向けカードの現状
PR #489の集計では、7デッキのすぐつかうのうち、相手ターンに意味のある使い道があるのは次のカードだけでした。

- ちょうせんデッキのかくとうバトル×2（相手のちょうせん中の能力値補正）
- 負けた後のあやまりにきただいおういか×1
- 条件のないそだち系（すごろく・花など）。これらは自分ターンに使っても同じ効果です。

相手ターン専用の反応カード（`reaction` 型）は7デッキに0枚です。後半に時が余る主因はここにあり、CPUの判断の誤りではありません。

## 2. ミサイルコマンド — CPU判断とデッキ相性の分離
| 観点 | 結果 |
|---|---|
| 発動条件 | 相手が時2以下のアクションカードを発動し、自分の場のカードを対象にした時 |
| 452枚で条件を満たすカード | 6枚：すれちがい（時2）・エアホッケー（時1）・ブロックくずし（時2）・フリーキック（時2）・マインスイーパー（時1）・タンクバトル（時1） |
| 正式7デッキに入っている枚数 | **全デッキ0枚** |
| CPU同士の対戦 | 原理的に発動しない（PR #489：150回しかけて0回発動） |
| 人間との対戦 | 人間が上の6枚を入れていれば発動し得る。カード自体が無意味なわけではない |
| CPU判断（B3） | 相手の公開カードに条件に合うカードが見えないまま試合が進むと、しかける評価が下がる（`results/tables.md` の E3） |

つまり、問題は「CPUが発動しないカードを置き続ける判断（B3で改善できる）」と、「CPUデッキ同士では発動できる相手がいない（デッキ相性）」の2つに分かれます。

## 3. 比較候補（未実施・本人判断）
| 案 | 内容 | 利点 | 懸念 |
|---|---|---|---|
| D0 現状維持 | アイテムデッキのミサイルコマンド×2を残す | 人間相手には妨害の読み合いが残る | CPU同士では準備枠を2枠分ふさぐ。B3を入れれば置く回数は減る |
| D1 同じ「しかける」へ入れ替え | ミサイルコマンド×2 → ドミノたおし（時1、自分があいてむを表向きでプレイした時）など、アイテムデッキの動きで条件が来るしかけ | デッキの主題（装備・しかけを並べる）を保つ。準備枠の札が働く | デッキバランス（#404〜#407、#432の7デッキ表）の再測定が必要 |
| D2 相手ターン向けカードの追加 | 例：ちょうせんデッキにかくとうバトルを追加、相手のちょうせんへの防御を厚くする | 相手ターンの駆け引きがCPUにも出る | 時を使い切るための変更にならないよう、勝率と個性の比較が前提 |

D1・D2は、正式デッキの変更になるため今回は行っていません。行う場合は、B1を正式採用するかを先に決め、その方針で7デッキの総当たりを測り直すのが安全です（B1はちょうせん・アイテム・バランスデッキの強さを変えるため）。
