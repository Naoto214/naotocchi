# 総合報告 — CPU判断 B1／B2／B3 の独立比較（2026-10-30）

基準 main `851cf09a`。PR #489（調査HEAD `0ac54ccd`）を読み取り専用で引き継ぎ、正式CPU・エンジン・ルール・カード・正式7デッキ・保存形式・戦績・画像・固定400戦の証拠は変更していません。実験CPUは `lib/` に隔離しています。数値表の全体は [results/tables.md](results/tables.md)、計画は [PLAN.md](PLAN.md)、保存互換性は [COMPATIBILITY.md](COMPATIBILITY.md)、デッキの検討は [DECKS.md](DECKS.md) にあります。

## 0. 結論
- **B1（中級の能力値選択）は採用候補として良好です。** 能力値の一致率は 50% → 100% になりました。中級のそだちは単独効果で +0.36、勝点は +0.016 です。能力値を選ぶカードがないデッキには影響しません。デッキ間の勝点の変化は最大3.1ポイント、判断時間の増加は 0.013ms でした。
- **B2（最終ターン）は小さく効きますが、初級でより効きます。** 中級は単独効果でそだち +0.19、初級は +0.47 でした。効果0のカードを使い出すことはありません。
- **B3（しかけの発動見込み）は今の形では不十分です。** R10の無駄なスキージャンプは減りましたが、ミサイルコマンドの設置はほぼ減りませんでした（70 → 66）。発動見込みを掛けても評価が正のまま残るためで、準備枠と手札のコストを入れる追加案（B3'）が必要です。
- 第一推奨は **B1 を中級だけに正式採用すること**（別承認が必要）。

## 1. B1の修正内容と直接テスト
**修正（実験コピーのみ）**
- `lib/policy-exp.mjs` の `stepValue` に、勝負中の分岐を追加しました。
  - `chosenStat` の ちから／ちえ の候補は、勝負の種目なら `n×2`、種目でない場合は「このターン」型だけ `n×0.2`（同じターンの後のちょうせんに残る価値）、勝負中だけの型は0。
  - `if {variant}` に守られた `stat`（かくとうバトルのパンチ・キック・ガード）は、選んだ型の枝だけを数え、勝負の種目の能力値で評価します。
  - 勝負の外では、差の大きい能力値へ +0.3 の小さな優先を付けます（ペンギン⑥型など）。
- `lib/observe-exp.mjs` は、`if` の `{variant}` 条件をヒントに足します。正式観測は文字列条件しか渡しておらず、CPUからは型の違いが見えていませんでした。
- **途中で見つかった回帰と修正：** 最初の版（`results/E1-v0/`）は、選択肢のない固定の能力値カード（ビーチバレー）の評価まで変えていました。その結果、ちえの勝負で「あそびずきカワウソ」を誘発するために使う合理的な一手をやめてしまいました（なかまデッキ -0.31）。B1 は「能力値の選択」だけを直す案なので、`a.variant` がある候補に限定し、E1 を再実行しました（PLAN.md の変更記録）。

**評価方法（ミサイルコマンドだけを特別扱いしない共通方式）**
- 開始時・終了時の誘発：その時点が残っていれば1。
- 自分の行動で起きる誘発：「前のターンにしかけた」条件なら、自分の次ターンが残っていれば1。ほかの条件付きは0.5。
- 相手の行動で起きる誘発：相手の公開カードに条件に合うカードが出た率（事前 0.25/2.5）を、残りの相手ターン数に当てはめる。

**結果と原因**
- R10のスキージャンプ（次の宣言機会がない）は置かなくなりました。
- ミサイルコマンドの発動見込みは R1 で約0.65、R5 で0.21、R9 で0.04と下がります。それでも評価（9×見込み − 時）は R9 まで正のまま残ります。
- 正式の配置評価には「手札1枚を手放すコスト」（すぐつかうの -3 に相当）も「準備枠を終局まで占めるコスト」もありません。そのため、後半の使い道のない時でしかけてしまいます。
- **追加案 B3'（未実施）：** 配置評価から手札1枚分と準備枠の機会費用を引く。計画外のため今回は対戦していません。

## 10. 第一推奨
