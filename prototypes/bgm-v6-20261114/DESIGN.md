# VERSION 6 — 制作方針

基準: PR #544 / 0cf8100d3ad85888f5e32f670a56631ecb4e82ce。依頼された32曲・50配置・主旋律3,158音を保護する。

V5の録音差補正の上に、曲別の小節位置で指定する長い強弱曲線を加える。音高やランダムな揺れから頂点を自動生成しない。既存対旋律・重ね・内声は必要なフレーズだけ前へ出し、導入と終止では控える。新しい音の自動生成は行わない。和声の基本形を保持し、声部の出入りと音量で響きの奥行きを作る。

ホーム朝は13小節後半、昼は7小節半、夕は8小節と14小節後半、夜は9・13小節の既存旋律を音楽的な目印とする。昼は3周目を頂点とし、夕は2周目後半の頂点の後に静かに戻る。夜はピアノのみ、hold・release・残響を変更しない。

比較した方法: 全体音量のみの加工では楽器の受け渡しを改善できない。全曲の再作曲では旋律保護に反する。そのためV5楽譜から演奏表情と既存声部の配置を編集する。これは制作者判断であり、聴感上の最終評価は試聴で行う。

成果物: 独立ディレクトリの楽譜・MIDI・FLAC・AAC・再現コード・32曲9項目の分析・検証記録。ホーム4曲、残り7曲×4回で保存。試遊版だけBGMを更新し、V5を固定保存してV5/V6比較ページを公開。本番mainへはマージしない。
