# なおぽよシリーズ 最終UI実装計画

ユーザー指定17項を承認済み仕様とする。既存エンジン、証明、開発UIを維持し、プレイヤー層を追加する。

1. 共通設定 `prototypes/naopoyo/settings.mjs`: 解放済み5種族×3セット、選択セット、スライド3種族。ドロップの既存保存は変更しない。
2. スライド `player-model.mjs`: 有効操作のみ履歴更新、1手Undo、練習フラグ、経過時間、復帰検証。`player-store.mjs`: 独立キー、revision、重複記録防止。
3. `player.html/css/mjs`: 証明検証後開始、画像選択、外周卵、即時へんしん、排他演出、結果・中断。
4. 共通入口・記録 `prototypes/naopoyo/` と本編リンク。ドロップに共通設定の読み込みと直接開始設定への遷移のみ追加。
5. 新機能テスト、証明全再生、mutation、4画面ブラウザ、既存ドロップ回帰、全体回帰、CIを確認。合格時のみ#383マージ。

重点: 壊れた保存は上書きしない。未解放種族を表示しない。Undo後再読込でも通常記録へ戻らない。非同期読み込み・演出・別タブ競合を防ぐ。途中盤面の未証明を行き詰まりと扱わない。
