## 結論（採用提案ではなく試遊対象）

重点比較はB、C16-20、D0。Bは位置の予測可能性と終盤スライド、Cは低密度への直接対策、Dは手動卵負担を減らす対照案。Aも全設定で選択可能。Eが必ず基準。

8seed×2方策の解法確認はE5/16、A8/16、B9/16、C16-20 10/16、D0 6/16。解決列の終盤slide比率はE64.7%、A66.6%、B77.4%、C72.0%、D84.1%。解決列の卵使用平均E11.8→B6.667、C3.4、D1.833。ただし全体へんしん平均はE2→B3.333、C4、D4.333で、へんしん依存の解決とはいえません。成功したseed/方策の構成も違うため因果的な改善率ではありません。

種族集中を狙う方策はE5/8、B8/8、C8/8、D6/8、多様性報酬方策はE0/8、B1/8、C2/8、D0/8。これは探索ヒューリスティック同士の比較であり、全ての多種族戦略の否定ではありません。補充で最大種族比率は下がる一方、多種族が戦略上有利になった証拠は弱い。異種消滅・種族能力は導入していません。

4/12単独ではEの確認数5/16のまま、解決列で単体へんしん平均0.4→7、卵11.8→16、手数19–39→37–87。単純な高コスト化は操作負担を移す恐れがあります。スライド報酬のみとの組合せではB8/16・終盤85.3%、C11/16・終盤64.4%。採用前に快適さを比較します。

スライド限定の40探索では寿命消滅0。未証明であり不可能ではありません。大量の低段階補充は長期化/詰まりも起こし得ます。短い解法（Cの6手など）は初期の高段階配置によるため人間の平均プレイ時間を意味しません。

## ルール契約

全方式、有効なslide処理と既存連鎖が終わってから補充。無効slide/道具操作直後には供給しない。勝利時は供給停止。補充後の自動進化/連鎖は行わず、次のプレイヤー操作で解決する。従来の08寿命消滅条件を変更しない。卵獲得・へんしんは既存エンジンを呼び、比較差分だけwrapperで扱う。

|方式|数/段階/種族|位置|空き不足|
|---|---|---|---|
|E|0、既存手動卵/へんしんのみ|既存|既存|
|A|1、01が90%/02が10%、3種族等確率|空きからseed乱数|追加なし|
|B|Aと同じ|移動反対辺の空きから選択|反対辺に空きがなければ追加なし|
|C|8/12/16以下で各閾値または閾値+4まで。段階/種族はAと同じ|空きから選択|空き数に制限|
|D0|新規獲得卵を待機、最大2体/slide、普通01/銀02/金03/白金04、種族等確率|空きから選択、低ランク優先|待機を繰り越す|
|D1|D0に加え、各ランク手動在庫1個まで新規卵を留保|同上|同上|

Dは初期卵を自動消費しない。BはThreesの「変化した行だけ」などを完全再現するものではなく、反対辺からの供給を参考にした独自条件。NEXTは種族/段階、Dは待機数を表示する。位置乱数はseedと補充通番から固定。空き盤面が異なると同じ通番でも実位置は異なる。無効入力は通番不変。Undoで状態と通番も戻す。

対戦設計：seed・初期条件・方式・費用・版・補充乱数列を両者で一致させ、表示種族は同能力のindexとして扱う。操作により供給時点/空き位置が分岐するため、常に同じ座標に出現するとの保証ではない。オンライン実装/ネットワーク検証は対象外。

ゲージ候補は現行2/6、4/12、報酬floor(半分)、slide進化だけ報酬、slide進化だけ＋1、全体へんしん後3有効slide待機。上限24/初期4を維持。補充比較176・ゲージ単独80・有望組合せ80・slide限定40の376列。主探索幅16・最大160手・120,000ノード、slide限定幅32・240手・60,000ノード。時間上限1e9msは実質ノード制限を優先する設定。未解決prefixを不可能証明と扱わない。
