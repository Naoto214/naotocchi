# 8編曲の内容

| 曲 | A：自然な改良 | B：豊かな楽器構成 |
|---|---|---|
| そよかぜのまど | 弱音アップライトピアノ。原曲の左手を維持し、和声末尾に小さなハープ | フルートの主旋律、ハープ分散和音、柔らかなピアノ和声 |
| いつものにわ | 弱音ピアノ、原曲の左手、少量のマリンバ | ピアノ、マリンバの分散和音、チェロ・ピッツィカートの低音 |
| ほしふるみずうみ | ピアノを中心に、句末のハープと小さな部屋の余韻 | ピアノ、ハープ、控えめな弦。旋律の休みに和声音の応答 |
| ほしぞらのやくそく | 柔らかいピアノと間を残したハープ | ピアノ、まばらなベル、薄い弦、四分音符の静かなハープ |

元の主旋律の全イベント（MIDI音高・開始時刻・音価）を比較するテストを実施。テンポ・拍子・曲の長さは共通です。音色の自然な立上がりと離鍵後の余韻は楽器ごとに異なります。Aは左手を維持し、Bは既存和声を基に伴奏を再構成しています。

音源は元のサンプルの左右をモノ化して控えめに定位を付け直し、高域の硬さを弱め、小さな初期反射を加えています。広大なホールや強いドラムは使いません。最終ゲインのみで−23 LUFSを目標にそろえ、コンプレッサーで編曲を押し潰しません。ブラウザーでも同じK-weighted gated loudness方式で再測定し、原曲を含めてゲインを調整します。

ループは音楽上の周期を維持し、末尾の残響を先頭へ循環加算します。原曲の比較用バッファにも末尾の余韻を循環加算し、元エンジンの生データは保存用に保持します。A/B切替は60msのクロスフェードで同じ位相から再生。再生中に別の時間帯を選ぶ場合はその曲の先頭から開始します。

長時間の心地よさ、iPhoneスピーカーとイヤホンの聴感、8編曲の採否は本人の試聴で決定します。主観評価を自動テストで代用したとは主張しません。
