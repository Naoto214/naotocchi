## 制作の判断
既存アレンジAのVSCO 2 CE音色群と統一する。残る28曲は用途別にピアノ、木管、マレット、ハープ、弦、必要な金管・打楽器を組む。主旋律の音高・開始・音価、テンポ、小節、反復を固定し、強弱と伴奏で展開する。原曲32件には配置表で直接使わないohayo / explore-2も含む。用途が変奏へ移った事実を明示し、勝手に配置しない。

## 作業順
1. source.json / placement.json / source-lock.jsonを生成し、32曲・50行・元MIDI・旋律を照合する。
2. scores.jsonと再現可能な編曲スクリプトを作成。主旋律は原データから生成し、保護検査を実施。
3. CC0サンプルを固定URL・SHA-256で取得。28曲を44.1kHzでレンダリング、AACとFLAC原盤と編曲MIDIを出力。ホーム4曲の32kHz仕様は保存。
4. 曲種別の音量目標、ピーク、モノ互換性、連結境界、全ファイル復号と長さを検証。ループは余韻を循環加算、ジングルは末尾だけ自然減衰。
5. 単一完成版の試聴ページ。個別・連続・ループ・音量・用途・ID。タップでAudioContextを解除、読込競合・停止・バックグラウンド停止に対応し、同時保持は少数曲に限定。
6. ブラウザー再生と縦横レイアウト、保護ファイル差分を確認。実機iPhoneでない検証は明示。
7. README / RIGHTS / VALIDATIONと対応表を保存、独立Draft PRを作成、本人用試聴ページを公開。

## 検証上の注意
数値解析は音楽の好みや実機スピーカー聴感の代替ではない。新規録音や生演奏とは称さない。短いジングルと静かな睡眠曲は一律の音圧にしない。ホーム原盤は加工せず再生時の場面音量をメタデータで示す。
