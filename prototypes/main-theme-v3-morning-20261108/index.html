譜面

ピアノロールは メロディ 1周ぶん。上の 文字は コード。階名と 曲紹介の 音名は 移動ド（長調は 主音を ド、短調は 主音を ラ）。「ー」は 付点4分以上の のばす音、「・」は 休符。

① 音楽理論上の 評価（Claude・10点満点）

Claude は 音を 聴けません。この表は 楽譜の 分析（音域・テンポ・音の 動き・和音との 関係・調の つながり）から つけた 予想で、聴いた 感想では ありません。自分で 作った 曲を 高く 見積もりがちな ことも 割り引いて ください。

② 聴感評価（あなたの 耳で）

空欄の まま お渡しします。星と メモは この ブラウザだけに 保存され、ほかの 人や Claude には 送られません。

iPhone Safari で 聴くとき

  • 最初は「▶」を タップして ください（タップ前は 音を 出せません）。
  • 消音スイッチが オンでも 鳴る ように「メディア再生」として 鳴らしています。鳴らない ときは 消音を 切って ください。
  • 画面を 消すと 止まります。通し再生も そこで 止まるので、もどったら もう一度 ▶ を。
