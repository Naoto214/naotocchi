# PR #426 — 地形上で暮らすホーム / version 7

本人のversion 6 iPhone Safari実機QAを起点にした追加改善。Draftを継続し、最終採用は本人の実機判断とする。mainマージ、本番GitHub Pages公開、育成ルール・保存形式の変更は行わない。

## 実装

### 楕円地面の撤去と共通地形

Homeに追加されていた `home-front` (r=650) / `home-back` (r=550) のplaza spotを構成データから削除。透明化ではなく、地面メッシュを作る入力そのものから専用広場を取り除いた。体調注意時の旧 `cast-stage::after` 楕円ハローもHomeでは表示しない。体調表示・メーターは維持。

めぐるの `buildWorld`、`worldObjects3d`、正式な樹木・岩・建物、`terrainGrid.walkY`、`streams3d`、pond、`buildCollisionGrid / collidesAt`、`alignHomeGround` とカメラ投影を再利用。拡大した樹木・建物と衝突寸法を一致させ、Home配置から衝突グリッドを再構築した。旧世界の衝突グリッドを使い回さない。

`home-terrain-navigation.mjs` はこの共通地形の画面投影アダプタ。画面点を地形の高さへ逆投影し、安全点を選び、12pxグリッドのA*で経路を探索する。斜め辺と経路短縮も全区間を3px以下の間隔で検査。水際48world-unit、pond24、solid28の余裕を持たせ、都会の車道も除外する。めぐる既存の地域間ルート/corridorは自由探索の移動用なので、固定カメラのHome内ポイント経路に転用していない。地形・衝突の正本を共有し、画面内の経路探索だけを分離した。

固定カメラと地面の基準を調整し、主役も従来の手前plazaの半径650を越えた安全な地形へ移動できる。森は草地と折れた小道・倒木の周囲、水辺は川岸と岩の周囲、都会は歩道・手前の広場。UIと画像の実寸から画面内の限界を算出するため、円形の活動範囲は持たない。川や道路を渡る探索ゲームにはしていない。

接地はレンダラーと同じ地形サンプルに一致。遮蔽は実際の3D形状の投影三角形を、足元より前にある部分だけDOMイラストのマスクに使う。装備・ハートの枠外部分を切らない `no-clip`、カメラ変更・復帰時の投影revisionによる再生成を追加。通知による高さ変化では、可能な限り元のワールド位置を再投影して維持する。

### サイズと複数キャラ

最終地形・390px・同一の静止比較条件で **100/90/80/70% × 主役のみ／仲間同席／恋人同席／3体／6体 = 20通り** を保存。`screenshots/size-comparison.jpg` と各原画像を参照。

| 比率 | 主役画像枠 | 判断 |
|---|---:|---|
| 100% | 220px | 単体は見やすいが、6体では周辺の空きが少なく、恋人・仲間との重なりが増える |
| 90% | 198px | 表情は明瞭。複数体時の余白は80%より小さい |
| **80%** | **176px** | **今回の採用候補。表情・タップ対象を保ち、6体の分散と移動の余白を確保** |
| 70% | 154px | 余白は増えるが、仲間・恋人の顔が小さくなる |

これは「version 6の人数依存solverの結果を一律80%にする」変更ではない。新しい幅基準の固定枠 `min(220, stageWidth*.62)*.8` を採用。旧版は同じ幅でも来訪人数で主役が縮んでいたが、新版では人数・通知の有無で枠を変更しない。画面幅の変更には追従する。画像の縦横比、種族・成長段階のPNG内の相対寸法、主役/恋人/仲間の比率を保持。正式画像を書き換えていない。

初期配置と来訪時に実画像サイズから分離距離を取り、先にいたキャラを優先して新来訪者を空いた安全点に置く。移動中にも近づきすぎを抑制。狭い画面での一時的な接近はあり得るが、全員を中央へ戻す処理は持たない。地形高さ変化・前後の描画順・自然な接近を使用する。

### 表情・自律行動・操作

正式2D画像、状態別表情、Relationship Expression、Motion v2、Conversation v2の既存resolver/ownerを維持。自律移動は位置・向き・軽い姿勢のみを扱い、表情画像を笑顔へ置換しない。空腹・病気の実画面でも正式表情が残ることを確認した。性格と関係性は読み取りだけで、育成・性格・関係値へ書き込まない。

散歩、方向転換、見回し、観察、休憩、座る、単独行動、接近、同席、環境反応を維持。新しい移動処理はwaypointを順に追い、育成/画面離脱/選択変更で経路を取り消す。タップ選択、地面タップ、ドラッグ指定、別キャラ選択、放置後の自律再開を維持し、じゃれる・求愛・掃除は既存ボタンのみ。

### 上部UIと通知

タイトル・データ・つうしんの下に `homeInformation` を置き、その中に年齢/そだち/お金 → 時間/天気/季節/旅先 → 名前/成長段階（既存の体調表示も維持）→ 操作案内。直下の `homeEventSlot` に通知をnormal flowで配置する。背景を隠す大型パネルは作らない。

ストーリー/実績・誕生日・ミニゲーム結果の表示を直列化。結果カードの既存表示時間を維持し、重要な作者/初遭遇表示を通常・環境・誕生日より優先。同優先度はFIFO。割り込みで消える通知は待ち行列へ戻す。隠れたタブでは進めず、表示途中の通知も復帰後に再表示する。内容・発生条件・報酬は元の処理が所有し、待ち行列には表示用payloadしか保存しない。

通知がなければslotの高さは0。長文は最大84px内でスクロールできる。通常会話は既存の下側speech slotを維持。イベントと会話が同時でも別領域となる。通知本文と操作案内のコントラストも修正した。既存safe-area/visualViewport対応を継承。

## 検証

最終テスト結果は `VALIDATION.md` と `logs/` に記録する。途中のRED/失敗ログも残し、修正後と区別する。

- 3地域×4幅で、共有地形の往復投影、旧手前plaza外の安全点、到達できる倒木/岩、川/車道/solid進入防止を検証。
- 経路の障害物回避、斜めの角抜け防止、waypoint追従、育成による全経路解除、UI reflow時のworld位置維持を検証。
- 人数増減時のサイズ一定、通知FIFO、非表示中の通知保持、HTMLの情報順を検証。
- fresh reviewerが衝突サンプル/小画面接地/経路解除を確認。重要指摘3件（hidden通知失効、装備mask clipping、古い投影cache）を修正。未対応のCritical/Important指摘なし。

ブラウザはクラウドChromeのCanvas 3D互換描画。320/375/390/430px（高さ844）で確認。例：375pxで情報bottom174.375、通知top179.375/bottom206.172、会話top468.172/bottom503.172、操作ボタンtop667/bottom831。通知がない390pxではslot高さ0、stage高さ339.75。イベント文字の例はQAボタンによる配置fixture、会話は既存speech slot。イベント発生条件や報酬の検証ではなく、同時配置の確認として扱う。

実際の試遊gameで水辺のキャラ選択・左へのドラッグ移動、続く「ごはん」（おなか+25/ごきげん+3の既存動作）を確認。6体fixtureで自律再開後に移動・向き直り・観察・単独・接近・同席・座る・休憩を記録。fixtureは保存せず、本編の来訪を強制しない。3地域の環境アニメーションは既存world lifeを維持。

**iPhone実機合格とは扱わない。** このブラウザは約1fps制限があり、Safari/WebGLの性能や指の感触は評価できない。実機では3地域の接地/前後関係、川岸・障害物へのドラッグ、1/2/3/6体の見やすさ、safe-areaとアドレスバー伸縮、長文通知と会話、スリープ復帰、30分程度の発熱/滑らかさを確認する。最終サイズ採用も本人の判断とする。
