# ホームの9語を、どこでどう使うか

ボタンは「ずかん」「あいてむ」、毎日見るメーターは「せいちょう」、育成値は「そだち」の呼び名を残す案です。説明では「年齢順」「時間帯」「使い切りのアイテム」のように、操作や条件を区別できる言葉を使います。セリフは話者ごとの声を優先します。以下は採用前の候補です。

### 先に区別したいもの

- **年齢・姿・せいちょう・そだち**　年齢は ageTicks から算出します。通常の姿は年齢と種族に応じて変化します。「せいちょう」は、たまご時はふ化に向かう進み具合、ふ化後は「そだち」が次に1上がるまでの進み具合です。「そだち」は20から始まり、上限は100。人生カードでは最後と最高の値を別々に表示します。参照元は script.js:10557、12334、12838、10759、132、11216 です。
- **時間帯・制限時間・一緒に過ごした時間**　「せかい」の設定値は朝昼夕夜または自動、「ゲームのながさ」は秒数に影響します。話し言葉の「なんでもないじかん」は日常の時間を指します。参照元は script.js:14736、index.html:512、script.js:7079 です。
- **仲間・恋人・結婚相手**　仲間の現在人数、過去の加入履歴、恋人候補、現在の相手はそれぞれ別です。結婚後も固定の「こいびとの詳しいデータ」が読み上げられるボタンには、実際の関係に応じた読み上げ名を提案します。参照元は script.js:11222、14575、12905 と index.html:157 です。
- **気持ちとごきげん**　「きもちいい」は感覚、関係ログの「気持ちが重なった」は出来事です。0～100の状態を示す既存メーターには「ごきげん」の名前があります。参照元は script.js:7448、7749、12328 と index.html:192 です。
- **図鑑の合計と図鑑完成の条件**　図鑑画面の進捗は育成姿・仲間・恋人を合算します。完成実績は育成姿の登録数で判定するため、条件説明を「図鑑のすべての育成姿を登録した」とする案です。参照元は script.js:14569、2411、2327 です。

### 用例

識別子は照合用です。中括弧は実行時に入る名前や値、同じ欄の「／」は画面にある区切りです。静的に実装を照合しました。読み上げの実音や端末別レイアウトは未確認です。
