## 保護の根拠と範囲

- 本編メニューの「ものがたり」から開く読書ページは prototypes/madoromi-white-reader-20261027/dist/index.html。保護範囲は main#book section.chapter > p.source[data-source-index]。段落ごとに章、順序、原稿ID、現行HTMLの行、正本JSONの行、原文、段落HTML、SHA-256を記録した。
- Chromium で本文を開き、全段落の textContent と正本 source/manuscript-lines.json、段落要素の outerHTML と実装ファイルを照合した。段落内の改行30箇所は pdf-wrap で保持され、CSSにより画面では隠れる。text と proposal には改行を保持し、実際に画面で読める文字列は displayText に収録した。語、句読点、三点リーダー、対話の括弧も一致した。
- 作品名・章題を含む395個の読書用ノードの並びを source/reader-source-ids.json と照合した。正本の396レコードに含まれる原稿ID 1「第三十八稿｜全六章完成版」は読書用ページでは非表示。第五章では追加段落の原稿ID 395 が 210 と 211 の間に入る。原稿ノードを画面順に段落区切りでつないだ全文は dist/madoromi-v19-full.txt と末尾の改行まで一致した。
- source/provenance.json と source/approved-edits-v19.json に記録された過去の承認済み修正は現在の正本に織り込まれている。明確な誤字・脱字として提示できる箇所は見つからず、別枠の参考候補は0件。
- 調査基準は 622dcf34cd08f2341897360d17fd2f8d0473085b。独立した一時ブラウザー環境で本文、読書メニュー、作品情報を照合した。

## 正式名称と読書UI

作品タイトルの「微睡み」は著者の表記を保つ。六つの章名は章番号と題名の間の空白も含め、目次と見出しで一致する。著者欄は全角空白のある「著者　豊田直人」を維持する。書名は本編入口、タブ、書名リンク、表紙、作品情報の5箇所。六つの章題は各2箇所にある。

| 用途 | 表記 | 判断 |
|---|---|---|
| 本編メニュー | ものがたり | 短い操作名のかなを維持 |
| ゲームから入ったときの復帰 | ホームにもどる | 本編に帰る操作名を維持 |
| 読書の開始・再開 | 読みはじめる／続きから読む／はじめから読む | 開始、しおりからの再開、巻末からの再読を区別 |
| 本文への近道 | 本文へ | キーボードで読む位置を選べる |
| 目次と文字設定の開閉 | 目次・文字 | メニューの二つの用途を短く示す |
| 目次の読み上げと復帰 | 章の目次／目次にもどる | ナビゲーション名と操作を区別 |
| 表紙への移動 | 表紙／表紙へ戻る | 目次では移動先、巻末では戻る操作を示す |
| 文字サイズ | 文字の大きさ／小／標準／大／特大 | 四段階の選択肢を読み分けられる |
| 作品情報 | 作品情報／著者　豊田直人 | ボタンと領域の読み上げ名をそろえ、著者名を維持 |
| ページメタ説明 | 微睡みの箱庭。全六章の物語。 | タイトルと章構成を簡潔に示す |

全388段落と各表示箇所の対応を story.json に収録した。passages は本文、chapters は各章の見出し、ui は正式名称・メタ情報・操作表示、issues は誤字脱字の参考候補。
