# 日本語表記の判断基準案　VERSION 2

短い操作名は、子どもが押す場所を探しやすく、説明から同じボタンを見つけられる書き方を残す。説明文では、条件・対象・結果が先に読み取れるよう、やさしい漢字と句読点を使う。正式採用は本人の判断を待つ。

## 優先度と集計単位

Aは対象・条件を誤解する文、現行仕様と食い違う説明、同じ正式名の明確な揺れ。Bは読みやすさ・案内の改善。Cは好み、演出上の別名、作品・話者の表現。優先度は確認する順番で、採用や変更の指示ではない。
