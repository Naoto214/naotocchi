# 確定文の実装と検証

全519件に、変更・維持する表示箇所、関連テストと確認すべき挙動、旧記録の扱いを付けた。変更364件、維持155件。V4の出典・コードの参照・検証結果を使った実装指示で、ゲームへの適用や適用後のテストは今回の作業に含まれない。

- **本編の生活ログ**　J030・J031は新規ログの書き込みと、記念日・挨拶など旧表記を読む処理を同時に扱う。旧表記、新表記、該当する履歴なしの3条件で回想と返答を比べる。過去の本文、個体名、相手名をそのまま再表示する。
- **能力名・正式カード名**　能力名179件はIDを基準に、詳細面・コレクション詳細・効果の発動元で照合する。J245「宝を暮らしに変える」と、タンポポ⑤のJ283「つぼみを守る」も表示名として適用する。J283の原稿照合は当時の「つぼみをまもつ」で行う。変更する正式カード名11件では、新旧名でコレクション・デッキ・戦績から同じIDに到達すること、旧対戦からログを再生できることを確認する。
- **カードルール**　J番号12件は9つのRの表示フィールドを参照する。J010・J027・J028・J466 は同じR04を参照するため、実装箇所は1か所。Rの全文、現在の仕様、過去の固定局面・旧原典を別々に照合する。J026・J040・J503は生成する引用名をJ001にそろえ、効果の対象と数値を保持する。
- **ゲームの説明**　J038は初回と再表示で「✨あそびかた」が出る経路を確認する。J082は「選んだ1本を最大10回。」に合わせて3回失敗・10回成功で終了する経路を比べる。J438はヘルプ表示中の進行と閉じた後の操作を確認する。J464は現行と旧対局で見出しを「人生の長さ（ラウンド数）」にし、既存の選択肢・内部値・保存済みラウンドとの対応を確かめる。
- **条件を含む説明**　J440は姿・仲間・恋人・通常ゲームの付与経路、ゲスト、所持上限、日次達成時の抽選除外を照合する。J461は通常成功と同じ育成効果・30コイン、クイック除外、プレイ回数・点数への非加算を使い捨ての記録で確かめる。シール課題・実績・アイテムも表示文と保存IDを個別に照合する。
- **固定文字列・旧保存**　旧文字列を含む検査では、表示の期待値、当時のテスト入力、過去のスナップショットを区別する。復旧・消去・上書きの動作確認にはテスト用の記録を使う。読み上げ名、動的な値、スマートフォン幅の長文は実装後に表示先で確認する。
