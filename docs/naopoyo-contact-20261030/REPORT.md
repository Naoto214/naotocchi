## 現行処理順と方向比較

`move` → 上昇足場判定 → `enter` の壁・ゲート上面・角抜け・地形判定 → 接触相手の分類 → 入場段階と合体後段階のゲート判定 → 余剰の戻り先判定 → 合体／交換 → 到着時の出口・トゲ処理 → `settle` による全員の重力。

- 同種族4+8、8+4、6+6：合体優先。重力なしの8方向すべてで接触先8・出発点余剰を確認。
- 同種族8+8、異種族：8方向のswapイベントとID保持を確認。実際の許可には双方の地形・上昇・ゲート・角の合法性が必要。
- 左右反転：画像盤面と周辺条件の各ケースで同じ結果を確認。
- 重力ありの水平・足場付き斜め：合体規則と左右対称性を確認。
- 垂直は水平と同条件ではない。上の4／下の8は重力で安定するが、下から真上への操作は自分を目的地の足場にできず拒否される。
- 上の8／下の4は、入力前の重力だけで下8／上4になる。監査ログの `initialSettlement` と入力後 `events` を分けて記録した。このケースを「同じ初期位置からの手動接触」とは数えない。
- 床・岩・魔法ゲート上面・トゲ隣・出口隣・他キャラ隣を両操作で確認。ゲート上面はVERSION 11の `magic-gate-v2` 規則で足場となる。過去版の支持規則へ戻していない。
- 余剰の足場がない別ケースでは余剰4が3マス落下し、移動先8は岩上に残った。
- 入場段階・合体結果・余剰の各ゲート検証、実際のトゲ接触・出口救出・交換後重力は既存 `contact-rules` 等の回帰でも確認。
- 全地形×全方向の直積を網羅したという主張はしない。
