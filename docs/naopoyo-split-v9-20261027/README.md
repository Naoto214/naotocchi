## 一手予告の正準仕様
`simulateSplit`は盤面cloneに実エンジンmoveを一度だけ実行する。合法でsplitイベントのある操作だけを表示対象にし、全重力・合体・余剰分離・救出を含む最終結果を使う。別の配置ルールや解答探索はない。

一筆書きBの現在pointer cell内で端へ近づいた時に計算し、落下後は実キャラ位置へrebaseする。セル境界を越える本来の操作は即確定し、待機・タイマー・確認入力を加えない。高速ドラッグは予告を飛ばせる。動作中は予告を抑え、動作終了時に保持中の入力から再計算する。

最終位置は正式画像の半透明シルエット・点線枠・数字、出現点は小さな輪、救出は出口の星と数字。変更前の影響キャラを薄くする。キャンセル、別キャラ、Undo、retry、apply/restore、終了で予告を消す。履歴・state・serialize・storageを変えない。832の分裂予告を実結果と比較し全件一致。
