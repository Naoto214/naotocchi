ここから 朝の 曲の 目安を こう 決めた:

### 各曲の 設計

**朝A あさひの さんぽ** — 「ソ ラ ドー シ ラ」。2度・3度と のぼって 主音で 一息つく、日の 出の 動機。2・6小節の Cadd9 で 9度の 音が 透明に 鳴る。9〜10小節は 和音を 1段ずつ のぼり（C → D）、13小節で 動機が D の 和音の 上に 戻って 最高音 D6。ト長調は 昼の ハ長調の 属調で、朝 → 昼の 切りかわりが 自然。

**朝B おはようの ひかり** — 「ミ ミ ソー｜ファ ミ レー」。同じ 音を そっと 2回（まばたき）。低い 音域（F4〜）で 始めて、動機が 3・5・13小節と だんだん 高く なり、最後は 1オクターブ 上で 目が さめる。1〜3小節は ベースが E♭ に とどまり（Fm7/E♭）、まだ 布団の なか。12小節 F7（ファ#）が 窓から さす ひとすじの 光。5曲で いちばん ゆっくり（♩=80）。

**朝C そよかぜの まど** — 「ソ レ ドー レ ミ」。5度 上へ ひらいて 主音へ おりる、窓を あける 動機。1・3小節の Dadd9 は 3度より 先に 9度が 鳴って 空気が 澄む。9〜11小節は 8分音符の「ミ ソ ラー ソ ミ」を 和音ごとに 写す そよ風の 句。13小節で 動機が Bm7 の 上に 高く 戻る。

**朝D きょうの はじまり** — 「ドー.レ ミ ソ｜ラー.ソ ファ ド」。付点4分で ゆっくり 踏みだし、2小節で 6度まで のぼる 素朴な 動機。9〜11小節は 8分 2つで 弾みを つけて 長い 音へ とびこむ 句を 1音ずつ 上げ、12小節の A♭（♭VII）→ F で 地平線が ひらく。最高音を B♭5 に おさえて、期待感は あるが 落ち着いた 明るさに した。

**朝E あさつゆ** — 8分休符の あと「ソ ミー レ ド」。6度 上へ ふわりと 跳んで 段々に おりる、葉の 上の 露が 光る ような 動機。気に入った 4曲の 共通点を あわせた: maj7 の 透明感（ほしふる）、和音を なぞる 明るさ（現行）、少ない 音数（ほしぞら）、五音音階より の 懐かしさ（きせつ）。9〜11小節は「ミー.ファ ラ ミ」の 形を 1音ずつ 下げる 句。12小節 ♭VI（D♭maj7）→ C7 で 一瞬 光の 色が かわる（ほしふるの ♭VI が 好きだった ことから）。ヘ長調は 昼の ハ長調の 下属調。

### 既存曲との 似かた（点検）

`tools/check-v3.cjs` は「音程 + 長さ」の 並びで、各曲と 既存 11曲（V1 の 6曲・V2 の 5曲）・ほかの 朝の 曲との 最長一致を 数える（移調しても 同じ 形なら 一致）。8音 以上で 不合格。

- 制作中、朝E 9〜11小節が V2 新A 9〜11小節と **9音** 一致した（2分 + 4分 + 4分で 下りる 同じ 写し方）ので、書き直した。朝D 3小節も V2 新C と 7音 一致したので 書き直した。

## 7. 権利関係

- 朝A〜E の 旋律・和声づけは、2026-11-08 に Claude（Anthropic の AI）が この リポジトリの ために 新しく 作成した もの。依頼者 Naoto214 の 指示のもとで 制作した。

- 音源は 合成で、外部の 音素材・サンプルは 使っていない（フォントは Google Fonts を 表示に だけ 使う）。
- AI が 作った 楽曲の 著作権の 扱いは 国・地域で 異なる。商用利用や 登録の 前に、必要なら 専門家に 確認する こと。
