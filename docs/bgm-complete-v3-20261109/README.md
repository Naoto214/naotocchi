## 2. 設計の 基準

各場面を、次の 順で 判断した。

1. **専用メロディーが 必要か** — 長く 遊ぶ・その ゲームの 顔に なる 場面（パズル・ボード・レース・お別れ・睡眠 など）は 専用曲。
2. **採用曲の 変奏で よいか** — 同じ ゲームの 中の 結果・終盤・章の おわりは、採用曲の 旋律を そのまま 使った 変奏で、ゲームごとの 個性を 保つ。
3. **他ゲームと 共通曲で よいか** — アクションと ストラテジー、本編と なおころ。の 埋めこみゲーム、ホームと メニュー など。
4. **短い ジングルが 適切か** — 1〜5秒の 演出（たまごが かえる・誕生日・達成・勝敗）は ループ曲を 流さず、ホーム曲を 一瞬 下げて ジングル。
5. **無音が 適切か** — ものがたり・起動直後・BGM オフ設定。なおぽよ。の 失敗（画面が ない）や 特殊ギミックは 曲を 変えない。
6. **長時間でも 疲れないか** — 1秒あたりの 音数を 用途で 変えた（睡眠 0.7・釣り 1.0・お別れ 0.8〜0.9・パズル 1.4〜1.9・レース 2.7）。最高音は どの 新曲も D6 まで。
7. **ループが 自然か** — どの 曲も 16小節で 主和音（または ループ先へ 向かう 和音）に 帰る。ジングルは ループしない。
8. **操作や 効果音を じゃましないか** — 効果音の 多い ミニゲームは 旋律を 中音域に、パズル・ボード・釣りは 音量を −4 dB、睡眠は −8 dB を 目安に した。

**独立ゲームの 個性**: なおぽよ。＝はずむ 2音と 休符（ぽよぽよこもれび）、なおころ。＝3連符で ころがる サイコロ（ころころじんせい）、CARD GAME＝連打と 8分休符の 勝負（デュエル・スタート）。結果・終盤・章の おわりは それぞれの 採用曲の 変奏で つくり、ほかの ゲームの 曲を 借りない。
