# なおとっちの文章ルール

会話、通知、説明、プロフィール、図鑑、ムービー字幕に共通する方針です。キャラクターは `character-world-master.v1.js` と現在の実装を確認してから書きます。

## 読みやすさ

- 日本語の文中を全角・半角スペースで区切らない。「動き出す理由を探してる」のようにつなげる。
- ためらいや余韻が必要なときだけ「…」「……」を使う。空白を機械的に三点リーダーへ置き換えない。
- 話題の切り替わりには読点や句点を使う。短く、声に出して自然に読める文にする。
- 吹き出しは一つの反応を中心にする。ムービーでも、一枚の字幕に事情を詰め込まない。
- 少し変な観察、小さな勘違い、日常のずれを大切にする。良い既存のセリフは残す。
- 同義文や語尾の変更だけで本数を増やさない。同じ候補内の完全一致も避ける。

英語の単語間、数値・アイコン・操作キーの区切り、コードの字下げ、HTML属性の空白は別です。独立した成績表示には「／」などの区切りを使えます。飾りの記号列は文章ではありません。

## 話す人

| 話者 | 基本の役割 |
| --- | --- |
| pet | 本人の感情、独り言、変な気づき。お世話への当事者の反応 |
| partner | となりにいる距離感、気づかい、軽いツッコミ。各キャラの言い方 |
| companion | 仲間として参加する反応、応援、第三者からの発見。各キャラの興味 |

一人称や関西弁を全員に一律で付けない。既存の方言あいさつは、本人がたまに話すバリエーションとして扱う。恋愛では大きな誓いを重ねるより、照れや小さなやりとりを優先する。

## 現在のカタツムリと時計

- `snail`：せっかちなカタツムリ。気持ちは先へ進むが、からだはゆっくり。雨、葉っぱ、背中の家、遊びへの好奇心、仲間への気づかいも使う。すべてを速さの話にしない。
  - 「忘れ物!…家、背中だった」
  - 「この葉っぱ、座り心地もいいね」
  - 「ここにいるよ。殻のとなり、座る?」
- `clock`：じかんにルーズなとけい。時刻は大まかで、小さな出来事の音を覚えている。時間、記憶、待ち合わせを少し感じさせる。胞子、菌糸、きのこの成長設定を持ち込まない。
  - 「今?だいたいこのへん」
  - 「きのうの音が、ひとつ残ってる」
  - 「今の一秒、覚えておこう」

## 保存と表示

旧セーブの `koala`、`kinoko` は、その持ち主が出会った別の仲間です。新規出現のカタツムリや時計に置換しません。旧キャラの互換データ、画像、過去の記録は残します。主人公の `mushroom` も現在の有効な種族です。

保存済みの名前・思い出・対戦の質問は、表示時に余分な日本語スペースを整えます。保存内容や質問IDを文章修正のために書き換えません。思い出の認識・重複判定では旧表記と新表記の両方を扱います。HTMLに入れる保存済み文章はエスケープします。

## 確認

文を変更したら、その文を参照する比較・思い出判定・イベント経路も確認します。`npm test` で会話、ムービー、旧セーブ、ミニゲーム入力・保存を検証します。

表示は別途ブラウザで確認します。吹き出し、長い説明、ムービー、古いセーブのプロフィールを狭い画面でも読むこと。本文に字間を加えず、必要な余白は要素のレイアウトで作ります。`letter-spacing` を使うゲームの記号・飾りまで一括で変更しません。
