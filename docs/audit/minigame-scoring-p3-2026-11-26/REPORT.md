# ミニゲーム採点 Phase 3: 連打・押しっぱなし・放置に近い操作で高得点にならないようにする(2026-11-26)

- 起点: main `24c64450`(Phase 2・C案の公開後)。監査は #591(`docs/audit/minigame-scoring-audit-2026-11-24/`)、方針は `followup-2026-11-24.md` の「Phase 3」。
- **13種(18本)**を変更しました。参加度の判定を全100本にそろえる作業は、共通処理の変更が大きいため **別の Draft PR** にしています(へんしんメーターの問題はそちらが本体です)。
- 試遊ページ: `comparisons/minigame-scoring-p3-20261126/`(`node tools/minigame-audit/build-p3-trial.cjs` で変更前・変更後の games.js を用意)。

## 1. 方針(2026-11-26 のご指示)

- ゲーム本来の目的(ねらう・タイミングをあわせる・考える)を果たさない連打・押しっぱなし・放置に近い操作では、高得点にしない。
- 連打そのものが遊びのゲーム(りくじょう・ピンボールのフリッパー)は制限しない。運の要素もそのまま。
- 上手な人の点は下げない。初心者でも30点以上をとれるようにする。ゲームの個性・操作感・達成感を残す。
- 過去の自己ベスト・実績・コインの帯・げんき・育成(C案)・クイックゲームは変えない。

- 連打・押しっぱなしで **コインが速くたまる状態は、対象の全ゲームでなくなりました**(上級者を上回るものはない)。
- へんしんメーターは「記録される回」なら点に関係なく +25 なので、連打でも記録される(=参加している)ゲームでは、まじめに遊ぶ人と同じくらいたまります。ハンググライダーの「ゆらす」は早く着地するぶん 75/分 と上級者より速い。**へんしんメーターの問題は、参加度を全100本にそろえる別PRで扱います**(このPRの範囲では、すぐ終わる・意味のない操作の回を記録しないところまで)。

**初心者への影響**: 初心者ボットの点が下がったのは、つみあげタワー(82→61)、ダーツ(74→53)、ハーフパイプ(100→44。ポンプ押しっぱなし+1回転は以前の「連打」と同じ操作)、ドミノ(100→86、完成なので60コインのまま)。どれも30点以上(30コイン以上)で、画面の表示(ゆれ・おちつきゲージ・転倒・コンボ)を見れば上達できます。
