### G-AC-07 / breakout-classic, pingpong-3d / 仕様不整合（開始猶予）
- **現象**: 開始猶予の間も制限時間のタイマーが減る。
  - breakout は startTime=now（games.js 666）。ボールはサーブで 0.9 秒止まるが、タイマーは最初から減る（727）。

- **影響**: 体感で 0.6 秒長くなるだけ。記録には影響しない。
- **回帰テスト案**: harness で開始直後に `advance(500)` しても、残り時間の内部値が DURATION と一致することを確かめる。

- **現象**: 復帰する高さ `p.y=(ROWS-3)*T`（games.js 4354）が、階段チャンクの1段目（ROWS-3 行は必ずブロック、4325）と重なりうる。
- **追跡**:
  - 縦方向の衝突処理（4370）は `p.vy>0` のときに、足元のセルが solid なら上に押し出す。復帰後 vy=0 から重力で vy>0 になるので、毎フレーム1段ずつ上に押し出され、最大4フレームで階段の上に立つ。動けなくなる状態にはならない。
  - 横方向の判定は vx≠0 のときだけ働く。
- **判定**: **誤検出**（めり込みは自然に解ける。一瞬ずり上がる見た目は改善工程の範囲）。
- 付記: とげの上に復帰すると、無敵 1.5 秒の後に、動かなければ再び被弾する。これも改善工程に送る。

### G-AC-36 / push-puzzle / bug（クリアの多重加算、新規）
- **現象**: 面をクリアすると、1.2 秒後の setTimeout で次の面へ進む（games.js 4483）。その間も入力をロックしていない。
  - ↩もどす（4485、anim のチェックも無い）→ 同じ手、を繰り返すと、`solvedAll()` が何度も成立する。
  - そのたびに `solved++` され、setTimeout も増える。
  - その結果、lvIdx が一気に進み、面が飛ばされ、solved が過大になる。
- **再現**: repro-push-AC.cjs で、実際の runtime-harness と canvas スタブを使った。
  - 1問目を9手で解き、続けて「もどす→同じ手」を2回行い、3 秒進めた。
  - **1問しか解いていないのに onComplete(100)**。正しくは 1問クリアなら 15+25+15=55 点で、時間切れまで続く。
- **正本**:
  - HUD「n/3問目」
  - 結果文言「🏆 3問クリア!」（4510）
  - score 式 `15 + solved*25`（4509）は「解いた問題数」を数える。
  - INFO 15002 / CONTROLS「↩で1手もどせる」
- **判定**: **確定不具合（一意）**。1問を1回だけ数え、遷移中の入力を受け付けないことが、正しい挙動として一意に決まる。
- **修正単位**: **「遷移中の入力ロック」**（G-AC-24 と共通）。
  - `levelDone` フラグで move、undo、reset、スワイプを止める。
  - solved++ は `if (!levelDone)` のときだけ行う。
  - load() でフラグを戻す。
- **影響**: 過去の自己ベストに不正な 100 点が含まれている可能性がある。記録の巻き戻しは行わないことを推奨する（判別できないため）。
- **回帰テスト案**: repro スクリプトをテスト化し、`scores` が空のままで、ヘッダーが「2/3問目」であることを確かめる。

## 4. 気づき（5行）
1. 付録の「バグ疑い」のうち、正本（README 67 の点検記録、randomThemeGame のコメント、同じ箇所のコメント）が意図を明記している誤検出が5件あった（road の判定、archery の照準、basketball の輪、ライバルが同性能、REGION コメント）。
2. 新規で見つかった本物の得点バグは2件で、どちらも「クリア後の待ち時間に入力をロックしていない」が原因。push-puzzle（1問で100点、実際に再現）と mini-golf（ホール飛ばし、6打上限の抜け）。共通の入力ロックで両方直せる。
3. 「みじかめ」は mgDuration の時間だけを縮め、周回・ボスの出現・ウェーブ間隔・目標点は縮めない。そのため grand-prix は完走できる確率が 0%、sky-shooter はボス戦が 3.9 秒になる。固定量の比例化をまとめて設計すべき。
4. 正本同士の矛盾が3件ある。downhill-mountain（CONTROLS・MASTER_SPEC は12段、テスト・HUD は10段）、cake・bento の即時完了（UX ルール対テスト）、README の 71 と 153（みじかめの定義）。直す前にどれを正とするかを決める必要がある。
5. 残り時間を表示しないゲームが11本、初期の秒数を直書きしているゲームが4本あり、HUD の共通化で一括解消できる。リズムは「空打ちで 82 点」になり、点数の妥当性が崩れているので、優先度が高い。
