# 02. 仕様判断待ち・Human QA 待ち一覧（Phase 0）

- 基準: main `249a954f`。
- ここに載せたものは、**既存の正本だけでは正しい挙動が一意に決まらない**もの（正本が何も言っていない、または正本同士が食い違っている）。もう1種類は、**実機での測定や目視でしか確定できない**もの。
- どれも実装していない。各項目の選択肢・影響・根拠は `evidence/`（ID で検索）にある。
- 判断の負担を減らすため、**同じ論点の項目は1つの「判断テーマ」にまとめた**。テーマ1つにつき1回決めれば、まとめて実装できる。

## A. 人間の判断が必要なテーマ（優先度順）

### T0. 性格（traitCounts）の扱い【最優先・ここで停止】
- 03-unreachable-content.md を参照。実績3つ・ゴール⑤・レインボーのテーマ・♾️のせかい・⑤のあいさつ・れんくんの恋愛ルートに、新規セーブでは到達できない。
- 選択肢は A（旧クイズを復元）／ B（既存イベントで加算）／ C（3実績を外す、または退役させる）／ D（文言だけ直す）。**新しい性格の獲得方法はこちらでは決めない。**

### T1. 対戦・終局の点数尺度（引き分け・時間切れ・負け・脱出）
| ID | 対象 | 論点 |
|---|---|---|
| G-DE-11/12/13 | animal-shogi / connect-four / gomoku | 時間切れの引き分け（50〜55点）が、負けの上限（45点）より高い。引き分けを負けより高く評価するのは設計として成立しうるが、時間切れまで粘る誘因になる |
| G-AC-30 | street-fight / pingpong | 引き分けの扱い |
| G-AC-13 | fp-dungeon | 宝箱0個で脱出しても52点以上。時間切れで宝箱3個だと45点 |
| G-AC-31 | tower-defense | 時間切れでも「守りきった」として勝ち扱いになる |
| G-FG-16 | sugoroku | 運だけで S ランクに届くかどうか |
| G-FG-18 | line-trace | 時間切れで手をつけていない問題を、平均に入れるかどうか |
| G-FG-19 | solitaire / hit-blow / slide-puzzle | 考えるゲームなのに制限時間が短い。時間切れのときの点数 |
| G-FG-21 | 横断 | 全体の尺度（失敗しても70〜92点が出るゲームがある、など） |
- **決めること**: 「勝ち／引き分け／時間切れ／負け」の点数帯の表を1つ決める。決まれば、01 の U5 `mgVersusOutcome` で一括して適用できる。

### T2. 100点・S ランクに届かないゲーム
| ID | 対象 | 最高点 |
|---|---|---|
| G-DE-14 | minesweeper | 96 |
| G-DE-15 | 2048 | 1024 の段（100点）は計算上届かない。512 も厳しい |
| G-DE-27 | tennis / air-hockey / tank | 94 / 98 / 99 |

- **決めること**: 「どのゲームも100点・S ランクに届くべきか」という原則。届くべきなら、点数式の上限をそろえる。

### T3. 「みじかめ」設定とゲームの構造（周回・ボス・投数・ターン）
| ID | 対象 | 数値で確定したこと |
|---|---|---|
| G-AC-33 | grand-prix | みじかめ（21秒）では、ブーストなしの2周完走が0% |
| G-AC-34 | sky-shooter | みじかめではボス戦が3.9秒しかない |
| G-AC-39 | bowling / archery / free-kick / crane | 表に見えない打ち切り時間がある |
| G-FG-10 | curling-winter | みじかめ（31.5秒）では8投が必ず打ち切られる（最短でも32.0秒かかる） |
| G-FG-14 | sugoroku | みじかめでは84%が時間切れになる |
| G-FG-22 | missile-command | 制限時間がなく、長い |
| G-DE-20 | track-field / ski-jump | 制限時間がなく、入力しないと終わらない |
- **決めること**: 「みじかめ」の原則。周回・ボスの出現などの固定量も長さに比例して縮める（`mgScale`）のか、ターン制のゲームは「みじかめ」の対象から外すのか、手番の区切りで判定するのか。

### T4. 残り時間の表示
- G-AC-28 / G-FG-11: 時間制なのに残り時間を表示しないゲームが11本ある（TD、そうこばん、オセロ、卓球、ローグ、GP、カーリング、ジェンガ、checkers、mancala、sudoku など）。
- **決めること**: すべての時間制ゲームに表示するか（01 の U3 `mgTimerHud` で一括対応できる）。

### T5. 難易度の配線
- G-AC-12 / G-DE-23 / G-DE-24 / G-FG-17: 難易度の値を取得しているのに使っていない（bowling、memory、halfpipe、voxel、mini-golf）。難易度設定に反応しないゲームもある（blackjack、yacht、picross、2048）。
- G-DE-26: voxel-mine のコメント「うえに にげる」と、実装（足もとのマグマを消す）が合っていない。
- **決めること**: 「全ゲームが難易度設定に最低1つは反応する」という原則を採るかどうか。
