## 担当範囲全体の気づき
- **重複群**: 引っぱり物理エイム（billiards・catapult、外部では archery/bowling）、盤上の対AI（animal-shogi・connect-four、外部で reversi/gomoku/checkers）、3D位置合わせ（ring-flight 2版、外部で submarine/hangGlider）。connect-four と gomoku、ring-flight-summer と ring-flight-3d は判断が実質同じ。
- **スコア式の歪み（共通の弱点）**: ①対AI 2作は「時間切れ（50/55点）＞負けの上限（45点）」で引き延ばしが得。②minesweeper（上限96）と 2048（1024 は手数的に到達不能）は 100点に届かない。③ski-jump と ring-flight は満点ラインが低く飽和しやすい上、無操作でも中位点が出る。
- **難易度軸**: 13作すべて minigameEase 不使用で ageDifficulty のみ。2048 は難易度変化ゼロ。AI深さの最上段は hard 設定でしか出ない（normal 最大 0.55）。
- **反復性**: catapult（2ステージ固定）と billiards（ラック固定）は乱数が無く、解法を覚えると枯れる。minesweeper・bubble・snake・frogger は乱数か学習要素で長持ちしやすい。
- **キャラ接続**: currentSprite を使うのは baseball（打者）・ring-flight（操縦士）・catapult（弾）・frogger（かえる役）・ski-jump（選手）の5作。frogger は「おうちへかえる」がテーマ的にも最も自然。残り8作はキャラ不在で、台詞は全作とも実況・状況説明のみ（キャラらしい反応は無い）。
- **良い実装パターン**: billiards の的球進行方向ガイド、animal-shogi の駒の動き方向ドット、bubble の壁反射予測線、minesweeper の初手安全＋chord、2048/snake/frogger の mgPad＋スワイプ併用、開始猶予 MG_ACTION_START_GRACE_MS の一貫使用。
- **バグ・ズレ候補**: bubble-shooter の段降下で泡が消える/ずれる（5356行）、baseball の早押し即からぶりとキャンバス誤スイング（5092, 5126行）、ring-flight の held 死にコード（5221行）、季節ゲームのコメントと実装の不一致（10185行 vs script.js 15876行）。
- **説明文**: ski-jump（73字）・frogger（70字）が長く、操作段階も多い。他は 47〜62字。
