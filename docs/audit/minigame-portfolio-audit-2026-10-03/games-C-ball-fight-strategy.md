# chunk-C 監査: games.js 3139〜4608行（12ゲーム）

前提メモ（担当範囲共通）
- 12ゲームとも MINIGAMES 配列（games.js 9971-9982）に1バリエーションずつ登録。担当範囲の生成関数は REGION_MINIGAMES / SEASONAL_MINIGAMES から参照されていない（grep で make*Game の他の呼び出しなし）→ **地域・季節版なし**。
- category は script.js 14843-14857 の対応表から（basketball/pingPong/freeKick=sports, chainPuzzle/pushPuzzle=puzzle, streetFight/skyShooter/jumpQuest=action, towerDefense/roguelike=strategy, grandPrix=drive3d, reversi=board）。
- 範囲内で `minigameEase()` は一度も使われていない。難易度はすべて `ageDifficulty()` と `mgDuration()` 経由のみ。
- `currentSprite()` を使うのは street-fight / roguelike / sky-shooter / jump-quest / push-puzzle の5本。partner・食べ物・季節の参照は範囲内に無し。
- mgDuration（script.js 2943-2949）: easy ×1.2、「みじかめ」設定は20秒以上を ×0.7。**ゲーム内の固定定数（ボス出現時刻・周回数など）は短縮されない**ので、いくつかのゲームで「みじかめ」と噛み合わない（後述）。

## 担当範囲全体の気づき
- **重複群**: 「上へはらって疑似3D射出」= basketball-3d / free-kick-3d（＋範囲外の swipe-throw 等）。「対AI盤ゲーム」= reversi-6 と board 枠の connect-four・animal-shogi。「ステップ移動の格子ゲーム」= roguelike / push-puzzle（同じ mgPad steps 設定 3980, 4461）。「落ち物」= chain-puzzle と falling-block。
- **時間表示の欠落が多い**: pingpong / tower-defense / roguelike / grand-prix / push-puzzle / reversi は制限時間があるのに残り時間を表示しない。逆に street-fight(50秒) / sky-shooter(62秒) / jump-quest(70秒) は初期表示の秒数が実際と違う（1フレームで上書き）。
- **mgDuration と固定定数の不整合**: sky-shooter の BOSS_AT=15秒、grand-prix の2周は時間短縮に追従せず、「みじかめ」設定で達成不能/極端に不利になる。
- **コメントと実装のずれ**: TD「6ウェーブ」→4、ローグ「3かい」→2、GP「3しゅう」→2。仕様の意図確認が必要。
- **キャラ接続は「絵を置く」止まり**: currentSprite を使う5本（格闘の頭・ローグの駒・機体の上・ジャンプ主人公・倉庫番）でも、台詞は全て実況/説明調で、キャラ固有の反応・回数で変わる反応はゼロ。minigameEase も範囲内で未使用。
- **記録・回数による変化がどのゲームにも無い**: 再訪性は「乱数生成」（roguelike, jump-quest, grand-prix, chain-puzzle）に依存。固定面の push-puzzle と固定マップの tower-defense は早く枯れる。
- **良い実装パターン**: 格闘の「連打で威力低下」「3連続ヒット以降スタンなし」（3556-3578）のような単純連打対策、basketball の落下予想表示（ただし強すぎ）、grand-prix の「canvas 長押し＝アクセル＋押した位置でハンドル」という片手経路、jump-quest のコヨーテタイムと長押しジャンプ。
- **判定のずれ**: pingpong のアウト判定（最後に打った側が得点 3316, 3336）は実際の卓球と逆で直感に反する。TD の時間切れ=勝利（3945）、格闘の同HP=勝利（3671）も意図確認したい。
- **得点の天井**: basketball（7本前後で100）、free-kick（4本全部で100）は満点到達が容易。勝敗型（pingpong/格闘/TD/ローグ/リバーシ/ジャンプ）は「勝てば60以上・負ければ58以下」で段差がはっきりしている。
