### falling-block-puzzle（ブロックパズル）
1. **id/名前/分類**: falling-block-puzzle / 「ブロックパズル」🟦 / category `fallingBlock`（10045） / makeFallingBlockPuzzleGame / 1600〜1642 / 地域・季節版なし
2. **基本ルール**: 8×14盤（1602）にテトリス風ピースが落ちてくる。横一列そろうと消える。28秒以内にできるだけ多くライン消し。ピースは5種のみ（I・O・T・L・S。J・Zなし、1603〜1609）。
3. **入力**: 下部パッドの左右なぞり=移動、下なぞり=ソフトドロップ、パッドのタップ=回転（1617）。ボタン「↻かいてん」「⏬いっきに」（1617, 1629〜1630）。盤面上でもスワイプ左右=移動、下スワイプ=ハードドロップ、タップ=回転（1632〜1634）。懸念: 盤面の下スワイプがソフトでなくハードドロップで、パッドの下なぞり（ソフト）と意味が違う。stepPx 24 ごとに1マス移動なので、素早く長くなぞると行き過ぎる可能性。
4. **長さ**: mgDuration(28000)（1611）＝normal 28秒、easy 33.6秒、みじかめ 19.6秒。積み上がりで早期終了あり（spawn時の衝突 1621）。ヘッダーの初期表示が「残り：32秒」と固定文字列（1613）で実時間とずれている（最初のフレームで更新される）。
5. **終了とスコア**: 時間切れ or 出現位置で衝突（窒息）で終了。`clamp(35 + lines*11 + min(25, score/70), 30, 100)`（1638）。内部scoreは1/2/3/4列消しで100/260/480/800、ソフトドロップ+1/マス、ハードドロップ+2/マス。0ラインでも35点保証。窒息にペナルティはない（同じ式）。約6ライン＋内部点で100に到達。
6. **難易度**: ageDifficulty/minigameEase の参照なし。落下間隔は `max(240, 620 - lines*18)` ms（1637）で消したライン数に応じて速くなるのみ。
7. **ランダム性**: ピース種のみ（1621、7-bag なし）。運の比重: 低〜中（5種・8列盤でピース偏りの影響はあるが、短時間なので配置技量が主）。
8. **技量**: 回転・配置判断、穴を作らない積み方、ハードドロップでのテンポ稼ぎ。
9. **繰り返し**: 盤・ルール固定、乱数はピース順だけ。2〜5回目は上達余地あり、28秒・最大でも数ライン規模なので10回目以降は「何ライン消せたか」のみ。記録・段階なし。
10. **タグ**: パズル / 空間認識 / 短期戦略 / 精密操作。毎手: 「次のピースをどこにどの向きで置くか決め、パッドで移動・回転して落とす」。
11. **類似**: 担当外の chain-puzzle / match-3 / puzzle-2048 と同じ「盤面整理パズル」枠だが、落下＋回転の空間判断は本作のみ。stack-* は「落とすタイミング」中心で判断が違う。
12. **固有要素**: 回転と穴埋めの空間判断。まとめ消しのボーナス（1〜4列で点が増える）。
13. **キャラ接続**: 無し（currentSprite・台詞なし。メッセージは「✨まとめ消し!」「ラインを消した!」「ここでは回せない!」のみ）。
14. **懸念**: 28秒ではテトリス系の醍醐味（積んで一気に消す）に届きにくく、テンポが短い。0ラインでも35点保証。盤面スワイプ下とパッド下で操作の意味が違う。初期表示「32秒」の固定文字列。次ピース表示（NEXT）なし。CONTROLS 46文字（ゲーム時間に対して妥当）。
15. **分類**: 「小改善でかなり良くなる」— 骨格は正しいが、ピース5種・NEXTなし・28秒という制約で浅め。NEXT表示とスワイプ操作の統一だけで遊び味が上がる。
16. **なおとっち余地**: ①4列消し時にキャラが一瞬盤の横で踊る/驚く ②窒息で終わった時に「ぎゅうぎゅう…」とキャラが押しつぶされる反応 ③同じピース（例: Iが来ない）が続いた時にキャラがぼやく。

### crane-game-3d（クレーンゲーム）
1. **id/名前/分類**: crane-game-3d / 「クレーンゲーム」🕹️ / `craneGame`（10046） / makeCraneGame / 1648〜1783 / 地域・季節版なし
2. **基本ルール**: コイン3回。ボタン長押しでアームが右へ→離すと停止→もう一度長押しで奥へ→離すと降下・つかむ。左手前の落とし口へ自動で運び、途中で落とすこともある。落ちた景品はその位置に残る。
3. **入力**: 長押しボタン1つ（bindHeldButton 1677）またはキャンバスの押下（1678）。hold＆release の2段。懸念: アームは右・奥への一方向のみ（1709〜1710）で、行き過ぎたら戻せない。ボタンラベルが段階で変わる（1671〜1674）ので見れば分かる。
4. **長さ**: 3回の試行（1652）。mgDuration(45000) の時間制限は「idle段階」でのみ判定（1766）。1回あたり降下・運搬・帰還アニメで数秒かかるため、実質3回分の待ち時間が長め。
5. **終了とスコア**: 3回使い切る or 全景品ゲット or 45秒経過（idle時）。ゲットあり: `clamp(40 + 景品value合計*0.7 + 残りコイン*5, 40, 100)`。0個: `clamp(14 + 使ったコイン*2, 10, 25)`＝通常20（1773）。景品value: くま30/プレゼント45/おうかん70/あめ20（1656〜1659）。くま1個で61点、おうかん1個で89点。
6. **難易度**: gripPower に `lerp(1.05, 0.9, difficulty)` を掛けるだけ（1697）。景品配置・アーム速度は不変。
7. **ランダム性**: 運搬中0.35秒ごとに `Math.random() > gripPower + 0.12` で滑り落ち（1719）。景品配置は**固定**（1656〜1659）。運の比重: 中（中心をつかめばgripPower≈0.9以上で滑落はほぼ起きないが、端つかみは運任せ）。
8. **技量**: 2軸の停止タイミング（奥行きの見極め）。小さい・高価値のおうかんは grip 0.6 で中心精度が要求される。落下位置が落とし口方向に寄るので「ずらし」戦略が成立。
9. **繰り返し**: 景品位置・価値が毎回同じなので、2〜3回目で「どこで離せばいいか」を覚えられ、10回目以降は作業化しやすい。乱数は滑落だけ。
10. **タグ**: タイミング / 空間認識（奥行き） / リスク選択。毎手: 「どの景品を狙うか決め、横→奥の2回、指を離す瞬間を合わせる」。
11. **類似**: 長押し→離して止める点は stack-* や pinball の発射、archery-3d 系の「ため」に近いが、2軸を順に止める点は本作のみ。
12. **固有要素**: 失敗しても景品が動いて「次の手が良くなる」持ち越し要素。2段停止の奥行き判断。
13. **キャラ接続**: 無し（currentSprite なし）。台詞は「💪がっちりつかんだ!」「はしをつかんだ…落ちそう!」「景品0こ。アームだけ帰ってきた…」（1698, 1772付近）など機械的な実況のみ。
14. **懸念**: 景品配置が固定で繰り返しに弱い。アームが戻せない一方向。運搬・帰還アニメの待ち時間（1回あたり数秒×3）。0個でも20点。CONTROLS 51文字（やや長めだが内容は必要）。
15. **分類**: 「小改善でかなり良くなる」— 落ちた景品が残る仕組みは良い。景品配置の乱択と、景品にキャラの好物/おもちゃを混ぜるだけで繰り返し性と世界観が両方上がる。
16. **なおとっち余地**: ①景品に「なおとっちのぬいぐるみ」を混ぜ、取れたらキャラが照れる ②3連続で取れない時、キャラがガラスに張り付いて見ている ③滑り落ちた瞬間にキャラの「あっ」という短い声。

### pinball-physics（ピンボール）
1. **id/名前/分類**: pinball-physics / 「ピンボール」🎯 / `pinball`（10047） / makePinballGame / 1789〜1943 / 地域・季節版なし
2. **基本ルール**: プランジャーを長押しでためて発射。左右フリッパーで玉を打ち返し、バンパー（100/100/150）・スリングショット（+30）・★ターゲット（+50、両方点灯で+200）で得点。ボール3個以内・制限時間内に目標点に到達すればクリア。
3. **入力**: ◀ひだり／はっしゃ／みぎ▶ の3ボタン（hold）、またはキャンバスの左右半分タッチでフリッパー（1824〜1829）。マルチタッチ対応（touches Map）。懸念: 発射ボタンが中央にあり、フリッパー2ボタンと並ぶので親指2本操作は可能。弱すぎ（charge<0.18）は発射されない（1833）。
4. **長さ**: `mgDuration(lerp(25000, 21000, difficulty))`（1792）＝normal 約22.8秒（年齢依存）。タイマーは最初の発射から開始（1835）。3球落とすか目標点到達で早期終了。
5. **終了とスコア**: 目標点到達で即クリア: `clamp(74 + 残り球*8 + min(10,(score-GOAL)/50), 74, 100)`。未達: `clamp(20 + score/GOAL*52, 20, 70)`（1936）。到達即終了なので超過ボーナスはほぼ働かない。
6. **難易度**: 目標点 `lerp(1150,1600,difficulty)` を50刻み（1793）、制限時間短縮（1792）。物理・台の形状は不変。
7. **ランダム性**: 発射時の横速度 ±2（1834）、以降は決定論的物理。運の比重: 中（ピンボール本来の混沌さ。ドレインに吸われるかはフリッパー操作次第だが、短時間ゆえ数発のバンパー当たり次第で点がぶれる）。
8. **技量**: フリッパーのタイミング、発射の強さ。ただし20秒強ではショット狙いまでは難しい。
9. **繰り返し**: 台は1種固定。2〜5回目は感覚がつかめて点が伸びるが、10回目以降は同じ台の繰り返しで変化なし。
10. **タグ**: 反射 / タイミング / 物理エイム。毎秒: 「落ちてくる玉を見て、左右どちらのフリッパーをいつ上げるか判断し押す」。
11. **類似**: breakout-classic（下で受けて打ち返す反射）と判断構造が近いが、本作は重力とフリッパー角度の物理。air-hockey とも「受け返す」点で共通。
12. **固有要素**: ためる発射＋重力物理＋バンパー連鎖の「当たると派手」な爽快感。
13. **キャラ接続**: 無し。台詞は「フルパワー!」「バンパー!+100」「ボールを落とした…残りN」（1838, 1891, 1898付近）。
14. **懸念**: 目標点（1150〜1600）を約21〜25秒で取れるかはコードから不明（実プレイ確認要）。未達でも最大70点。CONTROLS 36文字。
15. **分類**: 「仕様確認が必要」— 目標点と時間のバランスがコードだけでは判断できない。実測でクリア率を見るべき。
16. **なおとっち余地**: ①ドレイン（下の穴）にキャラが立っていて、落ちる玉を見送って振り向く ②★ダブルボーナス時にキャラが台の上に一瞬顔を出す ③発射フルパワー時にキャラが一緒に飛ばされそうになる。

### haunted-house-3d（おばけやしき3D）
1. **id/名前/分類**: haunted-house-3d / 「おばけやしき3D」👻 / `hauntedHouse`（10048） / makeHauntedHouseGame / 1945〜2085 / 地域・季節版なし
2. **基本ルール**: 一人称レイキャスト迷路（11×9、ループ5、1950）。鍵を拾い、出口から脱出。鍵を取るとゆうれいが追跡モードになる。
3. **入力**: 下部パッド（vector, sticky）で左右=旋回、上=前進（1990〜1993）、bindFirstPersonControls でキャンバスドラッグ旋回も可。懸念: 一人称の旋回＋前進をスマホのパッドで行うのは慣れが要る（酔い・迷い）。
4. **長さ**: `mgDuration(lerp(30000, 26000, difficulty))`（1952）。
5. **終了とスコア**: 脱出: `clamp(100 - max(0, 経過秒-25)*1.4, 70, 100)`。捕まる: 鍵あり34/なし22。時間切れ: 鍵あり40/なし25（2074〜2077付近）。制限時間が26〜30秒なので脱出すればほぼ93〜100点。
6. **難易度**: 時間短縮、追跡速度 `lerp(1.45, 1.85, difficulty)`（1953、プレイヤー2.4）。徘徊速度0.8固定。
7. **ランダム性**: 迷路生成・鍵/出口位置（BFSで遠い所）・装飾・徘徊目標（1956〜1958, 2000〜2006）。運の比重: 低〜中（迷路の当たり外れはあるが、コンパスが常に鍵/出口方向を示す 2059〜2060 ため探索の運は小さい）。
8. **技量**: 迷路の移動精度、ゆうれい回避ルート選択。
9. **繰り返し**: 迷路が毎回生成されるので5回目以降もレイアウトは新鮮。ただしコンパス＋ミニマップで「矢印に向かって歩く」作業になりやすく、数十回では単調。
10. **タグ**: 探索 / 空間認識 / 回避。毎秒: 「コンパス方向と分岐を見て曲がる方向を決め、ゆうれいとの距離を見て進路を変える」。
11. **類似**: fp-dungeon / roguelike-dungeon / bomber-maze と「迷路を歩く」で重なる。fp-dungeon とは一人称迷路で判断・操作がほぼ同じで、違いは追跡者の有無。
12. **固有要素**: 鍵を取った瞬間に立場が「探索→逃走」に反転する緊張。危険時の赤いビネット脈動（2049〜2052）。
13. **キャラ接続**: 無し（currentSprite なし）。台詞「🔑かぎを取った!ゆうれいが気づいた…出口へにげろ!」「👻近い!にげろ!」「時間切れ…屋敷に閉じこめられた」。
14. **懸念**: ゆうれいの初期位置が**出口セル**（1960）で、徘徊開始前に出口付近にいる＝序盤は出口側が危険という仕様（意図か要確認）。脱出点がほぼ固定で高く、捕まる/時間切れとの差が大きい（成功/失敗の二値化）。一人称操作はスマホで分かりにくい。CONTROLS 49文字。
15. **分類**: 「他ゲームとの役割整理が必要」— fp-dungeon と一人称迷路として重なる。本作は「鍵後の逃走」に役割を絞るとよい。
16. **なおとっち余地**: ①ゆうれいが実はキャラの仲間（コンパニオン）の変装だった、が稀に起きる ②捕まった時にキャラが白目で気絶する一枚絵 ③何度も遊ぶと屋敷のゆうれいが「またきたの?」と覚えている。

### race-3d（カーレース3D、RACE_THEMES乱択）

10. **タグ**: 回避 / 追跡（ライン取り） / 精密操作。毎秒: 「カーブの向きと前の車を見て、左右どちらにどれだけ寄せるか決めアクセルを維持」。

12. **固有要素**: 遠心力に逆らうステア。順位なしのタイムアタック。
13. **キャラ接続**: 無し（プレイヤー車は drawRearCar の色付き車。キャラ絵なし）。台詞「💥ぶつかった!」「🏁ゴール!ノーミス!」。

## 担当範囲全体の気づき
- **重複群**: (1) 釣り4種（real-fishing / fishing-sea / fishing-deepsea / fishing-river）は判断・操作が同一。fishing-sea は real-fishing の title 違いのみ。(2) race-3d は grand-prix-3d / p3-drive / road-* / downhill-* と疑似3Dロードエンジン共有。(3) haunted-house-3d は fp-dungeon と一人称迷路で重複。(4) space-gunner-3d は missile-command / sky-shooter / asteroids と照準撃ち枠で重複。(5) mini-golf は billiards / curling / bowling と引いて離す物理エイムで近い。
- **テーマ乱択の限界**: race/rhythm/tilt/gunner の randomThemeGame は見た目だけで、「こおりのたまころがし（すべる）」のようにタイトルが挙動差を約束しても挙動は同じ。fishing-river の「流れを読もう」も同様。
- **キャラ接続が薄い**: 10ゲーム中 currentSprite を使うのは釣りだけ（3064）。他は無機質な実況メッセージのみ。
- **難易度の効き方がまちまち**: falling-block と mini-golf は ageDifficulty を使っていない（mini-golf は宣言のみ）。rhythm-highway は LENGTH_MS 固定で mgDuration（easy延長・みじかめ）が効かない。
- **最低保証点**: 何もしなくても 20〜35点前後が返るゲームが多い（falling 35、crane 20、pinball 20、haunted 22〜25、fishing 18）。
- **操作の誤爆リスク**: mini-golf はどこをタップしても打てる、rhythm は空打ちノーペナルティ（連打で稼げる可能性）。
- **繰り返し耐性**: 迷路/コース/譜面を生成するもの（haunted, tilt, race, rhythm）は配置が毎回変わるが、構造が一定で数十回では単調。固定配置のもの（crane 景品、pinball 台、golf 6ホール）は5〜10回で覚えてしまう。
- **良い実装パターン**: crane の「落ちた景品が残って次の手が良くなる」持ち越し、haunted の「鍵で探索→逃走に反転」、fishing の段階ごとに1ボタンの意味が変わる設計、pinball/gunner の予告・派手なフィードバック（バンパー発光、赤い攻撃予告リング）。
- **成功/失敗の二値化**: haunted（脱出ほぼ93〜100 vs 22〜40）、pinball（74〜 vs 〜70）、tilt（55〜 vs 〜45）は結果が二極化し、途中の上達がスコアに出にくい。
