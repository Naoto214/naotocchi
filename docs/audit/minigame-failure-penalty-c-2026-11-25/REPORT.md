## 3. 気づいた点(この PR とは 切り分け)

**参加度メーターの ない ゲームで、形式的な 操作を くり返すと、へんしんメーターを 速く ためられます。**

- 自動プレイの データ(監査時、73本)では、44本が「1回 タップして 放置」で 記録されます。いちばん 早いのは **スネーク(1タップで 約4秒で 終わる、10点)**、ほかに ビーチバレー(約12秒)・月面着陸(約12秒)・アステロイド(約18秒)・バッティング(約19秒)。
- 記録される回は 点に 関係なく へんしんメーター +25 なので、スネークを 1タップで くり返すと、まじめに 遊ぶ(1回 約30秒)より 3〜4倍 速く へんしんが 選べます。きげんも 1回 +7(放置は +2)。
- これまでは しっぱい 1回ごとに おとろえ +8・いのち +2 が つくので、くり返すと 育成に 害が ありました。C案では げんき −12 だけ(ねれば 数秒で もどる)なので、くり返しの 歯止めが 弱く なります。
- コイン・そだちは 0 の ままなので、育成の 進み(そだち)や お金には 影響しません。影響は へんしん(ずかん集め)と きげん だけです。
- 改善案(承認後、別 PR で 検討):
  1. Phase 5 の 参加度メーター 全100本化で、早く 終わる ゲーム(スネーク・ビーチバレー・月面着陸・アステロイド・バッティング)を 先に 対応する。
  2. へんしんメーターの +25 を「参加あり」かつ「一定時間(例: 15秒)いじょう 遊んだ」回だけに する。
  3. または しっぱいの 回は +10 などに へらす。
