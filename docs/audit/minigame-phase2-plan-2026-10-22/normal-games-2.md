# Phase 2 計画: 通常ゲームの再評価・改善候補（担当: 付録 D/E/F/G の通常ゲーム）

- 基準: `origin/main` = f69310c7。行番号は **origin/main の games.js / script.js**（`git show origin/main:games.js`）。前回監査（2026-10-03）の行番号より **+16〜+88 ずれている**（PR #415 で行が増えたため）。根拠の監査ID（G-DE-xx / G-FG-xx / B・W 番号）は前回監査・Phase 0 と同じもの。
- 対象: 付録 D（4632〜5953）、E（6039〜7547）、F（7548〜8950）、G（8951〜10035）の通常ゲーム53本。**ring-flight-summer と curling-winter の差別化（B）は別担当**。この2本については、単体改善（A）を本体（ring-flight-3d / curling-ice）の行に書いた。
- PR #415 で修正済みのため、未修正として扱わないもの: B12 bubble の降下（`makeBubbleHex` 5314）、B13 lights-out の最小手数、B14 darts のゲージ、B15 shanghai の配り、B16 memory の3枚目、B17/B18 sudoku（唯一解・赤表示）、B19 checkers の文言、W06〜W13 のコメント、W11 domino の「余りボーナス」文言（CONTROLS script.js:15396 で削除済みを確認）。
- 性格への影響の読み方: `individualGameResult`（script.js:10419）は **rawScore ≥35（C）で genre の courage 経験と game の perseverance 経験を付け、≥55（B）で perseverance の次の段階を付ける**。ランクは script.js:15453（S90/A75/B55/C35）、genre は `MINIGAME_GENRE_OF_CATEGORY`（script.js:15198〜）から決まる。表の「性格」欄には C/B への到達率が **増える／減る／なし** のどれになるかを書いた。
- 台詞について: Conversation v2 / Director が担当するので、この計画ではゲームに台詞を足さない。前回監査の「なおとっち余地」（キャラの一言など）は、ここでは扱っていない。ゲーム内の say() の実況とエフェクトだけを、ゲーム側の範囲として書いた。

凡例: 規模 S＝1関数内の数十行、M＝ゲーム内の仕組みの追加、L＝ルールの再設計。「要T」は 02-pending-decisions.md の判断テーマ。

## 2. B: 判断が近いペアの差別化案

### 2-1. tank-battle ⇔ bomber-maze（11×11、敵を全滅、壁を壊す。全滅で78/80点以上、失敗の上限70点の同じ型の点数式）
- **差別化の軸**: tank は「射線と向きのリアルタイムの撃ち合い」、bomber は「置いて待つ読み合い」。
- **tank-battle**: ①**基地（🏠）を守る拠点防衛にする**（本家の鷹にあたる）。敵の一部は基地を狙うので、「前に出て撃つか、戻って守るか」の判断が生まれる。②マップのレンガの配置を、左右対称のまま乱数にする（6307 付近の固定マップ）。③弾どうしの相殺（既存）を、狙って使える見せ方にする（相殺したときに火花と効果音）。
- **bomber-maze**: ①**敵の次の進行方向を足跡の矢印で0.5秒先まで見せる**（ランダム歩行を読めるようにして、置き場所の読みを技量にする）。②爆風が連鎖して2体以上を巻き込んだら加点する。③レンガで敵を閉じ込めてから爆破する、という置き方を有効にする。
- 規模: 各 M。影響: tank は守りの分、全滅の達成率が下がり、**B 到達率が少し減る**。bomber は読めるようになって、**C/B 到達率が増える**。要T: なし（点数帯は T1/T2 に従う）。要 QA: 矢印の見やすさ。

### 2-2. submarine-3d ⇔ hang-glider-3d（同じ擬似3D・同じ delta パッド・前から来る物を取る）
- **差別化の軸**: submarine は「深さを選ぶリスクとリターン」、hang-glider は「速度と高度の交換」。
- **submarine-3d**: ①**深さを3つのレーン（浅い・中・深い）にして、上下でレーンを切り替える**。深いほど💎の価値が高い（×1/×2/×3）が、酸素の減りも速く、🫧は浅いレーンにしか出ない。「深く潜って稼ぎ、浅く戻って吸う」の往復が判断になる。②横の動きはそのまま、縦はレーンの切り替え（スナップ）にして、2軸の同時操作の負担を下げる。
- **hang-glider-3d**: ①**木と家に当たり判定を付ける**（低空ではぶつかって減速する）。②🌀上昇気流を「地面の影」で予告し、機首を下げて速度を稼いで届かせるか、上げて延命するかの判断にする。③保持するだけの最適解をなくすため、機首角を保持したときの沈下率を、目標の対気速度から外れるほど大きくする。
- 規模: 各 M。影響: submarine は運（🫧の出現）の比重が下がって技量の比重が上がり、**C/B は分布の幅が広がる（増減両方）**。hang-glider は保持だけの満了がなくなり、**C 到達率が減る**。要T: T6（G-DE-25 の機首の保持）。要 QA: レーン切り替えの手触り。

### 2-3. plane-landing ⇔ lunar-lander（降下速度と姿勢を制御して着陸）
- **差別化の軸**: plane-landing は「1本の正解の線を、どれだけ丁寧になぞるか」（連続した精密さ）、lunar-lander は「燃料とパッドの倍率に賭ける」（リスクの選択）。今の両方の長所を、それぞれの役割としてはっきりさせる。
- **plane-landing**: ①**滑走路の長さと接地帯の位置を毎回変える**（短い滑走路では早めのフレアが必要になる）。②風向きを吹き流しで見せ、横風のずれを修正する。点の内訳（中心／ふわっと／ライン、8401〜）はそのまま使う。
- **lunar-lander**: ①**パッドの並び（×1/×2/×3）を乱数にする**（今は左から右に固定。G 付録9）。②残った燃料を点に残す比重を上げ（残り燃料/10 → /5）、「×3 に賭けて燃料を使うか、×1 で燃料を残すか」の判断にする。③HUD に「この燃料で届くパッド」を色で示す。
- 規模: 各 S〜M。影響: どちらも平均点はほぼ変わらない。**C/B はなし**。要T: なし。要 QA: lunar の両手操作。

### 2-4. connect-four ⇔ gomoku-9（対 AI で並べる・塞ぐ）
- **差別化の軸**: connect-four は「重力による罠（下の段が埋まるまで置けないマスを使う）」、gomoku は「広い盤で攻め筋を2本同時に作る（四三）」。
- **connect-four**: ①**自分と相手の「3つ並んだ先の空きマス」を、置けるようになるまで点線で見せる**（重力の罠が見えるようにする）。②AI の深さを、ふつうの上限まで年齢で 2→4 に段階づける（今は d<0.3 なら2、<0.7 なら4、5は hard だけ。5590 付近）。最初の数手はノイズを大きくし、強すぎる序盤をやわらげる。
- **gomoku-9**: ①**AI を「相手の活三・四を見る2手読み」にする**（今の1手読みの scoreCell（6252）では、ダブル三の必勝パターンが固まる）。②開始時に、中央付近に定石の数手（3〜4個）をランダムに置いた局面から始める（毎回違う序盤になり、60秒で決着がつきやすい）。
- 規模: connect-four S〜M、gomoku M。影響: gomoku は必勝パターンが効かなくなり、**勝ちが減って C/B 到達率が減る**。connect-four は序盤がやわらいで、**勝ちが増える**。要T: **T1/T3**（時間切れの扱いは両方に共通）。要 QA: なし。

## 4. 最優先にしたい5件

1. **盤上の対 AI 群＋カーリングのターン制の時計と mgVersusOutcome**（animal-shogi, connect-four, gomoku-9, checkers-6, mancala-kalah, curling-ice/winter）: 7本（reversi を含めれば8本）に一括で効く。マンカラは1手1.5秒でも36%が時間切れ、カーリングの冬版はみじかめで必ず打ち切られる、と数字で確定している。時間切れ50〜55点が「粘り得」になって C を配る歪みも、同時に消える。T1/T3/T4 の判断が1回で済む。
2. **無操作・運で C/B に届くゲームの是正**（ring-flight-3d, ski-jump, blackjack-21, sugoroku-race）: 新しい性格の仕組み（PR #417）では、C で courage と perseverance、B でその次の段階が付く。何もしなくても46〜50点（C）が出る、運だけで1位72点（B）が出る、という状態は、**性格の成長を操作と無関係に配ってしまう**。性格のルールは変えずに、点の分布の側で直すのが筋。
3. **sugoroku-race の「ねらって」と実装の不一致（T8）**: 説明・タイトル・CONTROLS の3か所が「狙える」と約束しているのに、コード上狙えない（85msごとのランダムな目）。子どもが「自分が下手だから」と誤解する、最も納得感を損なう不一致。狙える巡回にする場合も、道の選択を足す場合も、L 規模なので早めに判断が要る。
4. **判定の納得感を S 規模で直せる3本**（baseball-batting の区間通過、fruit-slice の combo の窓、darts-board の照準オフセット）: どれも数十行で直り、iPhone での「合っていたのに外れた」「指で見えない」という不満に直結する。baseball と darts は C/B 到達率が上がる側、fruit-slice は満点の取りすぎが減る側で、バランスも取れる。
5. **決定論的に満点が取れる3本の判断の追加**（jenga-tower, halfpipe-skate, domino-run）: 3本とも「ほぼ全員が100点」の状態で、上達が点にも性格にも出ない（全員が B の段階を自動で得る）。L 規模なので、Phase 2 の後半で1本ずつ。最初は手触りの改善幅が最も大きい halfpipe の位相判定から始めるとよい。

1. PR #417 によって、**点数の分布はそのまま性格の成長の分布になった**。「無操作で C」「運で B」「全員100点」は、遊びの問題から育成の問題へ格上げされた。満点到達テストと並んで、「無操作ベースラインが C 未満」のテストも共通化したい。
2. 不満の大半は、ルールではなく**時間と手番の扱い**（ターン制に秒数の制限を掛ける構造、みじかめの0.7倍）から生まれている。盤上・カード・推理の11本は、時計のポリシーを1つ決めるだけで体験が大きく変わる。
3. 前回 G 分類の catapult は、ルールを変えずにステージ生成だけで直せるので A（M）に下げた。逆に blackjack と sugoroku は、判断そのものが無いので C に据え置いた。分類の基準は「判断の有無」が妥当。
4. 近いペア（tank/bomber、submarine/glider、plane/lunar、connect-four/gomoku）は、どれも**片方に「読める予告」、もう片方に「賭けの選択」を足す**という同じ型で差別化できる。統合しなくても役割を言葉にできる。
5. 前回監査の「なおとっち余地」は、ほとんどがキャラの台詞で、Conversation v2 の範囲に移った。ゲーム側に残る接続は「見た目に currentSprite を使う」程度（dot-eater の自機、plane のキャラの大きさ）で、規模も小さい。
