## 2. 設問ごとのまとめ

### 2-1. 地域・季節の差は「それだけで十分な魅力か」
- **十分（手を入れない）**: road-themed、stack-themed、stack-acorn、stack-leaves、stack-harvest、road-city、road-jungle、road-desert。地域・季節版は、その場所・季節で出やすくなる「出会い」が役割で、見た目はその地域の印象として成り立っている。一般プールでは常に低い重みで、いる地域でだけ ×1.45 に券1枚と到着時の引き寄せが付く（s:16262-16268, 16303-16313, 16380-16391）。そのため、同じ中身の「またこれ」感は一般プールの派生ほど強くない。ルールを無理に変えないほうがよい。
- **不十分**: (1) 一般プールの中で同じ中身が並ぶもの: p3-space、p3-drive、stack-snowman。(2) 複製: fishing-sea。(3) 説明が挙動を約束しているもの: fishing-river、stack-snowman。(4) 季節限定なのに体験の差がないもの: ring-flight-summer、curling-winter（しかも時間の不具合あり）。
- **すでに役割があるもの**: fishing-deepsea は、魚表だけで難度と点数の差が実際にある。深さを選ぶ案は「あると良い」程度で、優先度は中。

### 2-3. ID・記録・実績・優遇・性格への影響
- **ID と記録**: どの案も既存の `mg()` の id をそのまま使う。`minigamePlayCounts` / `minigameRecords` の互換性は保たれる（旧キーの移行表 s:1892-1894 にも影響しない）。ルールが変わるので、**過去の自己ベストは別の条件で取った値になる**。巻き戻しはしない、という Phase 0 の方針（02 の T10「記録」の行）に合わせ、そのまま残すのを推奨。
- **実績**: 種類数の実績（games-played-25/60/100、s:2225/2259/2309）は id の数で数えるので、影響はない。A/S ランクの種類数の実績（s:2260, 2310）は、派生が難しくなると**取りにくくなる**（いまは同じ中身の派生で A ランクを量産できる）。王冠の優遇（s:2682-2701）は id 単位なので影響はない。
- **地域・季節の優遇**: 重みの計算と id による補正は変わらない（雪のとき curling ×2、晴れのとき ring-flight ×1.3）。**派生を統合・削除するとこれらとテスト（region-identity-test:97-108）が壊れるので、統合は推奨しない。**
- **性格の genre**: どの案もカテゴリを変えないので、genre（action / drive3d / sports）は変わらない。C/B 到達率の増減は表の各行に書いた。全体では、増えるのが fishing-sea、fishing-deepsea、ring-flight-summer、road-city。減るのが p3-space、p3-drive、stack-sakura、fishing-river。fishing-river は、よどみの確率を調整すれば中立にできる。
- **性格の「応用」**: 派生はすでに別の id なので、変化はない。統合すると、応用の経路（同じ中身の別 id で稼げる）が減る。

### 2-4. 不具合の候補
1. **curling-winter の時間（G-FG-10）**: みじかめでは必ず打ち切られることを、コードで確定した（mgDuration は20秒以上なら ×0.7、s:2944-2949 → 31.5秒。g:7646）。ふつうの長さは Human QA 待ち。直し方は **T3** で決める。推奨は「A: 手番の区切りでだけ打ち切る」と「B: `STONES×12000` 程度で、ターン制はみじかめの対象外」の組み合わせ。ただし決めるのは人間。T4（残り時間の表示）も同時に。テストは「説明の4こ＝ヘッダーの残り4」（minigame-phase1-wording-test:49）が守られていればよい。
2. **fishing-river の「流れを読もう」（G-AC-25）**: 仕組みがないことを確認した（g:3054-3055 の wait は深さ方向に沈むだけ）。**T8** で決める。急ぐなら A（文言）で先に整合をとり、B（2-2 の flow）は差別化の PR で入れる。
3. **p3-space と road-themed(sky) のアイテム重複**: g:213 と g:1014 で、よいもの ⭐🌟、わるいもの ☄️🪨🛰️ が共通。sky テーマの絵文字を替える（S、T判断なし）。
4. **カテゴリが分かれているため3連続回避が効かない**: road と perspective3d（g:10131 / 10140）に加え、**realFishing と fishing（g:10147 / 10252-10258）も同じ問題**がある。たとえば road-themed → p3-space → road-city → p3-drive、real-fishing → fishing-sea → fishing-river のように、同じ中身が続いても止まらない（s:16410-16431 はカテゴリ文字列の一致だけを見る）。
   - **推奨する直し方**: カテゴリ（＝ genre）は**変えない**。回避判定のためだけに「生成関数の系統（family）」を持たせる。例: `minigameFamilyOf`（`road`/`perspective3d` → `laneRush`、`realFishing`/`fishing` → `fishing`）を s:16411 と s:16431 で使う。
   - カテゴリを `road` にまとめる案は、p3-* の genre が drive3d から action に変わる。そうなると性格の courage の genre キー、好みのジャンル、天気・時間帯の補正（s:14040-14051）が変わるので、**推奨しない**。

## 5. 気づき
- 判断の差がないのは20本中17本。ただし、地域・季節の「出会いの演出」としては、見た目差だけでも成り立っている。全部に手を入れる必要はない。
- 3連続回避の穴は road だけでなく、釣り（realFishing と fishing）にもある。カテゴリを統合すると性格の genre が動くので、回避用のキーを別に持たせるのが安全。
- ring-flight-summer は `theme` が、makeRoadGame は `duration` が、すでに引数として用意されていて、ほとんど使われていない。差別化の受け皿はもうある。
- 派生ごとに id が分かれているので、同じ中身の派生で A ランクの種類数や性格の「応用」を稼げている。差別化するとこれが少し取りにくくなる。この点は PR の説明に書いておく。
- カーリングに雪の摩擦を足すと、石が早く止まり、時間の問題が少し軽くなる。それでも、時間の直しは T3 の判断として別の PR で先に行う。
