## 0. 結論（先に読む部分）

1. **いちばん大きな問題は、「何もしなくても性格が育つ」こと（実測）。**
   - 通常100本のうち **19本が、何も操作しなくても C（35点）以上**になる。5〜6本は B（55点）以上になる。
   - 無操作で7回遊ぶだけで、「がんばり」が★5（ゲームだけで届く上限）になった。
   - 原因は3つで、重なりはない。
     - 対戦の時間切れ・引き分けの点が高い: 9本（T1）
     - 自動で進むゲームが勝手に点を取る: 8本（T7）
     - **不具合**: 2本（sugoroku の0マス同着で1位、mini-golf の未プレイホールの罰）
2. **類似7ゲームは、全部を差別化する必要はない。** 本当に効くのは次の3本。
   - **海の釣り**: 今の釣りは「近くに投げるほど得」で、ゲージの「遠くへ」と逆になっている。鳥の群れと巻き取りの補正で、「どこへ投げるか」という釣りの判断が生まれる。
   - **宇宙フライト**: ハイウェイと、同じ乱数なら結果まで同じ。流れ星で「行き先を読む」ゲームにする。
   - **冬のカーリング**: 「みじかめ」では4投目を一度も投げられない。先に時間の不具合を直す。
3. **大規模再設計8本に、全面作り直しが必要なものはない。** 6本は中改善、2本は小改善で足りる。
4. **最初の一手**は、本人の判断が要らない次の2つ。どちらも iPhone ですぐ体感できる。
   - 確定不具合2件（sugoroku、mini-golf）の修正
   - 海の釣り「とりやま」
5. **本人に最初に決めてほしいこと**は、T7 → T1 → T9 → T3 の順の4つ（§11）。

## 3. 各ゲームの3案比較

7本それぞれについて、次の3案を比べた。比較の軸は、面白さ・直感性（説明なしで分かるか）・難易度・実装の重さ・保守性・育成への影響の6つ。各ゲームの比較表は [01](01-similar-7-games.md) の §1〜§7 にある。

- A案: 今のルールのまま小さく直す
- B案: そのゲームだけの判断を足す
- C案: ゲームの作りを大きく変える

**C案（大きな変更）を第一推奨にしたゲームはない。** 理由は次の2つ。

- 7本とも、すでに兄弟のゲームと同じ操作に慣れた人が遊ぶ。操作を大きく変えると、地域・季節の「いつものあれの特別版」という良さが消える。
- C案は、どれも実装が L で、得点の分布も大きく動く。性格の成長への影響を、1本ずつ調整し直す必要がある。

## 6. 点数と新性格の成長の整合（要約）

- **個性への効き方**（コードの事実。03 §1）
  - ランクの閾値: S90・A75・B55・C35（script.js:15849-15856）。
  - D なら何もしない。C 以上で「ゆうき」にジャンル、「がんばり」にゲームが入る。B 以上で「がんばり」の次の段階にも入る。
  - 1カテゴリは最大6件・1件4点（individuality.js:38-42）。
- **4つの分類（実測。種の数が少ないので、割合は ±10〜20% の目安）**

| 分類 | 本数 | 代表 |
|---|---|---|
| 無操作で C 以上 | 19（ほかに、種によって C に届くもの8） | 対戦の時間切れ9、自動で進む8、不具合2 |
| 無操作で B 以上 | 5〜6 | mini-golf、connect-four、gomoku、sugoroku、hang-glider（submarine は最大66） |
| 運だけで B（ランダム操作で半分以上 B） | 4 | mini-golf、gomoku、hang-glider、sugoroku |
| ほぼ自動で100点 | 0 | ― |
| 熟練しても高得点が難しい（推定） | ランダム操作では、一度も C に届かないものが42本 | 多くは「狙って操作すれば届く」もの。T2 の6本だけは S に届かない |

- **ジャンルの偏り**: ボードは12本中7本が無操作で C。6ジャンル中5ジャンルの「ゆうき」が、放置だけで埋まる。strategy（2本）だけは、遊ばないと取れない。
- **推奨**（§5 の T7）: T1（9本）＋不具合（2本）＋T7（8本）＝19本で、無操作の C をすべて止められる。重なりはない。
- **残るもの**: 1回タップするだけで C になる3本（minesweeper、tower-defense、bubble-shooter）。運の強い sugoroku は、T8 で「狙えるゲーム」にする判断と一緒に扱う。
- **測定の限界**（03 §2.3）
  - ボットの入力は狙いのない乱数で、指は1本。
  - canvas は描画を捨てる代用品で、時計は偽物。
  - gomoku は、同じマスを2回押して確定する仕組み。ボットが石を置けていないので、実機での確認が必要。

## 7. Quick の役割と avgSkill

- **役割**: 短い時間で、説明なしに遊べる反射と判断のミニゲーム。通常のゲームと同じ複雑さや難易度は求めない。育成効果は、今回も足さない。
- **現状（実測と推定）**
  - avgSkill を使っているのは、**れんくんの候補条件の1か所だけ**（script.js:960, 989-990）。
  - Quick の点は、isQuick の分岐より前に avgSkill の合計へ足される（script.js:17143-17144）。
  - そのため、Quick の1本ずつのモードを繰り返すと、れんくんの条件（85）を超えられる（推定の計算）。
- **推奨（T9）**: Quick の点を avgSkill に入れない。
  - 変えるのは2行の場所だけ。
  - 実績の回数・記録・コイン（100）は今のまま。
  - 役割の分担が、「通常のゲームは育成、Quick は遊び」とはっきりする。
- **本人の判断**: 既存テスト3か所（quick-mode-test:196、individuality-runtime-test:59, 61）の意図を書きかえる必要がある（H13・H14）。

## 9. 改善の優先順位

判断の基準は6つ。

- 今の楽しさを壊しにくい
- 1つの変更で複数のゲームが良くなる
- iPhone で体感できる
- 育成への影響が小さい
- 既存のコードを再利用できる
- 会話とぶつからない

| 順 | 何を | なぜ先か |
|---|---|---|
| 1 | **確定不具合2件**（sugoroku の同着1位、mini-golf の未プレイホールの罰） | 不具合なので判断がほぼ要らない。放置の B 2本が消える |
