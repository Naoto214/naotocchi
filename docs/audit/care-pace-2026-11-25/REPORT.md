## 1. 結論(先に)

- **現行は「目を離せないゲーム」です。** すべて満タン・うんち0の状態から何もしないと、平均2.7分で最初のサイン、5.6分で病気、9.4分で死亡します(150回の平均)。実ブラウザでも、卵がかえってから眺めているだけで4分でうんちが4個たまり、9分で死亡しました。
- 忙しさの主因は、**うんち(ランダムで固まって出る/寝ていても出る/4個で急降下)**、**ごきげん(減り方はおなかと同じなのに、じゃれる1回+5・連続3回まで)**、**病気の連鎖(けんこう−20/分)** の3つです。おなかの減り方そのものは主因ではありません。
- **推奨は B案(ゆったりとした育成)** です。ときどきお世話する人の必要操作は10分あたり12.4回から4.4回(−65%)、サインが出ていない連続時間は平均1.9分から9.8分、病気は1生涯6回から0回になります。一方で、そだち・クリア率・寿命・ミニゲームの価値は現行並みのままです。

## 4. 忙しさの原因(個別の分析)

1. **うんち(最大の原因)**: 発生が「毎tickの抽選」なので固まって出ます。2個でおしらせ、3個で病気の抽選、4個でごきげん−40/分と、**1つの見落としが3段階で連鎖**します。寝ていても出るので、寝かせても安心できません。
2. **ごきげん**: 減り方はおなかと同じなのに、1回の回復が小さく(+5)、連続3回までしか効きません。「こまめに触らないと保てない」作りで、まとめ押しも生みます。
3. **病気の連鎖**: うんち3個 → 病気 → けんこう−20/分 → 約5分でけんこう0 → 45秒で死亡。この流れが「目を離せない」感覚の正体です。
4. **睡眠**: 自分では起きないので「起こす」操作が必要です。寝ている間もうんちと病気が進むため、寝顔を眺める時間になっていません。
5. **安定ボーナスの60秒条件**: 「1分以内に何か触る」と成長が続くので、熱心な人ほど1分ごとに触る動機があります。
6. **通知**: うんち2個でおしらせ、ゲージ50で黄色になるため、サインがほぼ常に出ています。じゃれるのおすすめの落とし穴もあります。

おなか(−7/分、約3.6分に1回)は単独では忙しさの主因ではありません。ただし、ごきげん・うんちと周期が重なって「同時に3つ」になる原因の1つです。

## 8. 推奨: B案

理由:

1. 忙しさの3つの原因(うんち・ごきげん・病気の連鎖)を、それぞれ別々に緩めています。おなかの減り方は約6割にとどめ、一律に遅くはしていません。
2. ホームの演出(自然のできごと)が「ごきげん」に効くようになり、**眺めていること自体に価値が生まれます**。寝顔も90秒は眺められます。
3. 育成の結果(そだち・クリア率・寿命・ミニゲームの価値)は現行並みです。熱心な人が報われる差も残ります。
4. 20分放っておけば危険になるので、育成ゲームとしての緊張感は残ります。
5. 必要なお世話は減っても、じゃれる(続けて喜ぶ回数は3→4)・ごはん・ミニゲームはいつでもでき、成長や会話に効きます。**任意で触れ合える機会は減らしていません。**

### 採用する場合に一緒に決めたいこと(B案の差し替えには含めていません)

- **実績・解禁条件**: B案では、1生涯のごはん回数が約12回(こまめ派)になります。実績「ごはんだいすき」(1生涯30回)にはほぼ届きません。フェニックスの解禁(1生涯で病気を5回治す)は、食べすぎによる病気でしか届かなくなります。条件の数を見直すか、回数ではなく量で数える形にするのがよさそうです。
- **自動お世話アイテム**(ちょうネクタイ・リボン・トイレットペーパー・マフラーなど): お世話の頻度が下がるぶん、ありがたみが減ります。値段や効果の見直しが必要かもしれません。
- **既存の問題(どの案でも直したい)**: けんこう0が続く経路の死亡が「おわかれのまえぶれ」(最低2分)を通りません。15tick(病歴が多いと最短6tick)で死亡します。
- **おすすめの落とし穴の修正**(じゃれるを続けすぎたら「あそぶ」をすすめる)は、どの案を採るかにかかわらず入れる価値があります。

## 9. 整合性の確認

- **並行中の PR**: #595(ミニゲーム採点 Phase 2)、#594(ピンチズーム)、#592(ホーム環境演出)は、どれも tick・お世話・care-status を変更していません(差分を確認済み)。#595 で点数の分布が変わると、ミニゲームで回復するごきげんの量が少し変わります。B案はミニゲームに頼らず保てるので影響は小さいです。
- **これまでの調整との方向**: script.js のコメントによると、満腹・機嫌は 1 → 0.6 → 0.35/tick、うんちは 8% → 3.5% と、すでに2回緩めています。B案はその延長にあります。
- **寿命・時間**: AGE_TICKS_PER_YEAR・GOAL_AGE・TICK_MS は変えていません(1生涯100分のまま)。
- **保存の互換**: B・C案はうんちの次の時刻(`poopTimer`)をセーブに加えます。ない場合はその場で決めるので、古いセーブでもそのまま動きます。
