## 3. なかま・こいびととの関係(監査と調整)

### 3.1 現行と B2 のしくみ(コードで確認)

- **きずなの減り:** 現行は 28年(28分)で100→0、B2 は40年(40分)。なかま・こいびとで同じ速さです。0で離れて、おとろえ+8が付きます。こいびとの場合はいのちにもダメージがあります。
- **回復:** じゃれる1回で、**そばにいるなかま全員**のきずなが+30されます。こいびとは、きゅうあい(+30)・デート(+45)で回復します。
- **なかまが増えたときの負担:** じゃれる1回で全員が回復するので、タップ数は増えません。負担の正体は「放っておくと時間で必ず離れる」ことです。
- **住民どうしの会話:** なかま・こいびとが家を訪れて話すのは、きずな60以上の「訪問中」だけです。会話そのものは、きずなに影響していませんでした。

### 3.3 V3 のしくみ

- **一緒に暮らしていれば離れない:** びょうきでも まえぶれでもなく けんこう40以上の間は、きずなが50より下がりません。**本当に放っておかれたとき**(びょうき・けんこう40未満が続くとき)だけ冷えて、0で離れます。
- **関係を育てる楽しさは残す:** 家を訪れて話すにはきずな60以上が必要です。じゃれる・きゅうあい・デートで上げると、訪問や会話が増えます。結婚には今までどおり、きゅうあいを重ねる必要があります(任意の触れ合いに意味が残る)。
- **住民の会話を活かす:** 家に来ているなかま・こいびとは、一緒に過ごすだけできずなが育ちます(+0.2/tick。40年かけて減る速さ0.125/tickより速い)。訪問中のにぎやかさが、そのまま関係を保ちます。
  - ※訪問(relationship-life.js)はシミュレーションの VM では動かないため、この効果は数値の比較に含めていません。数値は控えめな側に出ています。
- **なかまが多いほど楽:** なかま1人ごとにげんきの減りが5%ゆっくりになる、既存のしくみがあります。なかま12人では睡眠が5.9回→3.5回、サインなしの時間が10.2分→15.5分になります。
- **すれちがい中のこいびと**(変身で恋愛のタイプが変わったとき)は、今までどおり仲直りの物語が必要なので、下限をかけていません。

## 4. 放置時の安全性

**状態の定義**
- **健康**: おなか・ごきげん・げんき90、うんち0、けんこう100(お世話した直後)
- **普通**: 70・70・70、うんち1、けんこう100(少し間があいたところ)
- **やや悪い**: 45・45・45、うんち2、けんこう80(黄色のサインが出ているところ)

**放置したときの病気 / 死亡(300回ずつ)**

| 案 | 状態 | 5分 | 10分 | 15分 | 20分 |
|---|---|---|---|---|---|
| B2 | 健康 | 0 / 0 | 0 / 0 | 3% / 0 | 70% / 0 |
| B2 | 普通 | 0 / 0 | 0 / 0 | **61% / 0** | 92% / **52%** |
| B2 | やや悪い | 0 / 0 | 66% / 0 | 91% / **75%** | 100% / 100% |
| V3 途中案(うんちだけ緩める) | 普通 | 0 / 0 | 0 / 0 | 54% / 0 | 90% / 18% |
| V3 途中案 + おこたり2分 | 普通 | 0 / 0 | 0 / 0 | 18% / 0 | 80% / 2% |
| **V3(おこたり3分・けんこう0.6倍)** | **健康** | 0 / 0 | 0 / 0 | **0 / 0** | **6% / 0** |
| **V3** | **普通** | 0 / 0 | 0 / 0 | **1% / 0** | **74% / 0** |
| **V3** | **やや悪い** | 0 / 0 | 23% / 0 | 81% / **0** | 100% / 100% |

- 「普通から15分」で病気が多かった原因は、うんちではなく、**おなかが20を切るとすぐ病気の抽選が始まる**ことでした(15分で おなか10)。V3は、その状態が3分続くまで待ちます。
- やや悪い状態から15分で死亡していた原因は、けんこうの減りが現行のまま(−2/tick)だったことです。V3では0.6倍にしました。
- 結果、**健康・普通なら15分ながめても病気・死亡はほぼ0**です。20分放っておくと病気になり始めます。黄色のサインが出たまま20分放っておくと、まえぶれ(3分)を経て死亡します。少し目を離しただけで心配する必要はなく、放っておき続ければ緊張感があります。
- 救出(赤いおしらせから対応するまで): 30秒・1分は100%、2分は94%、3分は15%です。現行はどの遅れでも0%です。
