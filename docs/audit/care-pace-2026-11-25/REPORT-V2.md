## 3. 睡眠の監査

### 3.1 現行の仕様(コードで確認)

- げんきは起きている間 −0.32/tick(B・B2は −0.20)で減ります。ミニゲームでも1回 −12 減ります。
- 寝ると約5秒で満タンになります(100msごとに+2)。60秒以上寝てから起きると、せいちょう+3 が入ります。
- **自分では起きません**(現行)。起こすのはプレイヤーです。
- 寝ている間、おなか・ごきげんの減りは ×0.4 になります(B・B2は ×0.25)。現行ではうんちは**寝ていても同じ速さで出ます**(B・B2は ×0.3)。
- 寝ている間にできない操作(現行): ごはん・あそぶ(Quick・ゲームパスを含む)・じゃれる・きゅうあい・デート・たび・めぐる・現在地へ移動・なかまのさそいを受ける。そうじとくすりはできます。

### 3.2 現行・B・B2 の比較(50生涯の平均)

| | 現行 | B | **B2** |
|---|---|---|---|
| **ときどき派** 睡眠の回数 / 1生涯 | 8.6 | 6.2 | **6.2** |
| 1回の長さ | 135秒(プレイヤーが戻るまで) | 87秒(自分で起きる) | **87秒(夜は約3分)** |
| 起きてから次に寝るまで | 9.1分 | 13.6分 | **13.6分** |
| 寝ている時間の割合 | 19% | 9% | **9%** |
| 起こす操作 / 1生涯 | 8.4 | 0 | **0** |

| **初心者** 余分な「おきる」 / 1生涯 | 3.8 | 9.4 | **0.4** |

**読みとれること**

- 睡眠が必要になる間隔は、ときどき派で約14分、ミニゲーム中心派で約4分です。ミニゲーム中心派の間隔が短いのは、1回 −12 のげんき消費のためです。8ゲームに1回「ねる」を押す計算になります。この消費はミニゲームの側のバランスなので変えていません。
- 現行の「中断される感覚」の正体は、寝ている間に押したボタンが「起きてから」と断られ、**起こしてからもう一度押す**必要があることです(ミニゲーム中心派で1生涯22回)。B2ではこれがなくなります。
- B2では、ときどき派の睡眠はすべて「自分で起きる」で終わります。寝顔を90秒(夜は3分)眺める時間が生まれます。寝ている間は減りが¼になり、うんちもほとんど出ないので、寝かせたまま眺めていても安心です。
- B2でも寝ている間は起きない操作(デート・現在地へ移動・なかまのさそい)は、頻度が低いので今回は対象外にしました。採用時にまとめるかどうか決めてください。

## 4. 既存の問題の修正

### 4.1 おすすめに従ってじゃれ続けると悪化する問題

| おすすめのボタンを30秒後にそのまま押し続けるプレイヤー | 現行 | B | **B2** |

| 死亡率 | **100%** | 0% | **0%** |
| 嫌がられた回数 / 1生涯 | 21.2 | 0 | **0** |
| びょうき / 1生涯 | 6.9 | 0 | **0** |

| 好きでじゃれる人(20〜40秒ごとに1〜2回) | 現行 | B | **B2** |
|---|---|---|---|
| 嫌がられた回数 / 1生涯 | 119 | 167 | **0.2** |
| 死亡率 | 56% | 72% | **0%** |

- おすすめは、続けてじゃれた回数が上限に達すると「あそぶ」に切りかわります(B・B2 共通)。
