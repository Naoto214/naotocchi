## 1. 修正の内容

### 1-1. たまころがし迷路(`tilt-maze-3d`):採点バグ

| | 修正前 | 修正後 |
|---|---|---|
| 進み具合の計算 | 初期値はゴールまでの道のり(BFS)。更新はマンハッタン距離(直線) | 初期値も更新も、ゴールまでの道のり(BFS) |
| スタートにいるだけ | 進み具合が約0.5 → **30〜35点(ふつう・30コイン)** | 進み具合0 → 15点 |
| ゴール手前まで進んで時間切れ | 最大45点 | 最大45点(変わらない) |
| ゴールしたとき | 55〜100点 | 55〜100点(変わらない) |

- 失敗したときの式 `15 + 進み具合×30`(15〜45点)は変えていません。進み具合の物差しを直しただけです。
- 迷路の道のりの半分まで進めば30点(ふつう)になります。B案の「一定の成果=30点以上」と合っています。

### 1-2. 上海(`shanghai-tiles`):詰んで進めなくなる

- **原因**: 配りは「取りきれる順番がある」ように作られていますが、プレイヤーが別の順番で取ると、同じ場所に重なった2枚(下の段と上の段)だけが残ることがあります。下の牌は上の牌の下にあるので取れません。でたらめな順に取る人のシミュレーションでは、60枚の盤で約5%、68枚の盤(むずかしい)で約12%が詰みました。「まぜる」は場所を変えずに絵柄だけ配り直すので、何度まぜても取れず、時間切れまで待つしかありませんでした。
- **修正**: まぜるときに、残った牌の「置き場所」だけで取りきれるかを調べます(絵柄は見ません)。
  - 取りきれないと分かったときだけ、2段目より上の牌を、1段目の空いている場所(元の位置に近い順)へおろしてから配り直します。
  - 1段だけのならびは、いちばん左と右の牌が必ず取れるので、必ず取りきれます。
  - 画面には「🔀かさなった牌を下におろして、まぜた」と出ます。
- 調べきれなかったとき(計算の上限に達したとき)は、ならびを変えません。取りきれないと**確かめたとき**だけおろします。
- **救済の まぜ直しは 減点しません**(2026-11-25 承認)。詰みは プレイヤーの せいでは ないためです。
  - ふつうの「まぜる」(ボタン、取れるペアが なくなった ときの 自動)は、これまでどおり 1回につき −2点です。
  - 救済として 数えるのは「置き場所だけで 取りきれないと たしかめ、実際に 牌を おろせた」ときだけです。調べきれなかったとき・おろせなかったときは ふつうの まぜると 同じ(減点あり)なので、意図しない 無減点の まぜ直しは 起きません。
  - 画面の 文は「🔀かさなった牌を下におろして、まぜた(減点なし)」です。
- 点数の式・ヒントは 変えていません。

### 1-3. スライドパズル(`slide-puzzle`):まれに解けない盤

- **原因**: シャッフルは合法手を60手(4×4は140手)動かすので、必ず解けます。ただし偶然完成形にもどったとき、2枚を入れかえていました。そのため置換の偶奇が変わり、**解けない盤**になっていました(3×3で約10万回に1回)。
- **修正**: 完成形にもどったら、もう一度まぜます(最大20回)。それでも完成形のとき(乱数が極端にかたよった場合)は、空きマスを1手だけ動かします。どちらも合法手なので、必ず解けます。
- ふだんのシャッフル(完成形にもどらない場合)は、乱数の使い方も結果も以前と同じです。
