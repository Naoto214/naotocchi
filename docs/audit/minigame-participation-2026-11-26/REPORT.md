# 参加度の 判定を 全100本に そろえる(へんしんメーターの 問題・2026-11-26)

- 起点: main `24c64450`。Phase 3(#597)とは **別の Draft PR** です(共通の 判定 `script.js` を 変え、46本に メーターを 入れるため)。
- 全100本の 判定表: [TABLE.md](TABLE.md)(種類・数える 操作・最初の 目標・変更前後の 記録の 有無・即時失敗の へんしん/分)。
- #597 で 直す 16本(つみあげタワー6本・ダーツ・リズム・アステロイド・フルーツ・アーチェリー・ハーフパイプ・かくとう・グランプリ・ケーキ・ドミノ)の メーターは #597 に 入っています。**両方 マージすると 100本 すべてに メーターが そろいます。**

## 1. 問題(#596 の 報告・2026-11-25)

C案で しっぱいの 育成ペナルティが なくなり、記録される 回は 点に 関係なく へんしんメーター +25・きげん +5+点/5 に なりました。メーターの ない ゲームでは「1回 さわれば 記録」なので、すぐ 終わる ゲーム(スネーク 約4秒)を 1タップで くり返すと、まじめに 遊ぶより 3〜4倍 速く へんしんメーターが たまりました。

## 2. 方針(2026-11-26 の ご指示)

- **参加度メーターを 優先**する。プレイ時間が 短い こと・30点未満で 失敗した こと だけを 理由に へんしんメーターを 減らす 方式は とらない。
- C案は そのまま(まじめに 挑戦した 回は 失敗しても ペナルティなし、へんしん・きげんの 効果も これまでどおり)。
- 参加度を 満たす ためだけに 無意味な 操作を させない。

## 3. 変えた こと

### 3-1. 共通の 判定(`script.js` `mgParticipated`)

| 種類 | 変更前 | 変更後 |
|---|---|---|
| アクション(4秒区切り) | 操作が あり、遊んだ 時間の 2割いじょう・2区切りいじょうで 操作。**ただし 1区切り(4秒未満)で 終わった 回は 1回 さわれば 参加** | 操作が あり、2割いじょう・2区切りいじょう。**1区切りで 終わった 回は、最初の 小さな 目標を 達成した(`achieved`)ときだけ 参加**。すぐ やられて しまう ゲーム(スネーク・フロッガー・ボンバー)は 3区切り(8秒)いじょう または 達成。**この3本の「達成」には、ゲームの 目的に そった 操作も ふくめる**(スネーク: 向きを 3回 かえる、フロッガー: 前へ 3マス、ボンバー: ばくだんを 置いて 1マスいじょう 動く。3-3) |
| 考える(回数) | 意味の ある 操作が きまった 回数(1〜3)いじょう、または 目標 達成 | 同じ(考えている 時間は 放置と みなさない) |
| 盤上の 対戦 | 合法手 + 手と手の 間 30秒いない または 決着 | 同じ |
| メーター なし | ゲームの 画面で 1回でも 入力 | (このPRと #597 で 0本に なる) |

参加なしの 回は これまでどおり「途中で やめた」と 同じ(記録しない・げんき −6・きげん +2。コイン・そだち・へんしんメーター なし。しっぱいの ペナルティは もともと ない)。ことばは 2つに 分けました。

- 放置・操作の 少ない 回: 「そうさがなかったので、今回は記録しないよ」(これまでと 同じ)
- 操作は あったが 何も 達成せず すぐ 終わった 回: 「**すぐにおわったので、今回は記録しないよ。もう少しあそぶと記録されるよ**」

### 3-2. メーターを 入れた 46本(`games.js`)

ゲームの 性質ごとに、**状態が かわった 操作だけ**を 数えます(かべに ぶつかる・同じ 向きを 押す・もう 開いた カード・ボタンの 連打で 何も おきない 操作は 数えない)。長く 押しつづける 操作(アクセル・ハンドルなど)は 0.4秒に 1回だけ 数えます(`mgActEvery`)。

- **アクション 25本**(スネーク・フロッガー・ボンバー・ブロックくずし・スペースガンナー・おばけやしき・3Dダンジョン・れんさパズル・タンク・ミサイル・ドットイーター・卓球・3Dレース・ジャンプクエスト・たこやき・りくじょう・ボクセル・フルーツマッチ・じんとり・ビーチバレー・月面着陸 など): 4秒区切り + ゲームごとの「最初の 小さな 目標」(リンゴを 1こ・ブロックを 1こ・1体 たおす・1点 など)。
- **考える・1球ずつ 21本**(パズル9本・釣り4本・ボウリング・バスケット・フリーキック・ミニゴルフ・ビリヤード・カタパルト・バッティング・クレーン・ヨット・おべんとう・ロッククライム・ローグライク・せんなぞり): 回数(1〜3回)+ 目標。考える 時間・球が とまるのを まつ 時間は 放置と みなさない。

全100本の 内わけ(2本の PR が そろった とき): アクション 45・アクション(回数のみ)2・考える 47・盤上の 対戦 6。

### 3-3. ボンバー・スネーク・フロッガー(2026-11-26 ご判断で 見直し)

「8秒未満で 敵を たおせなかった」だけで まじめな 初心者が 記録されなく ならないよう、**プレイ時間だけで なく ゲームの 目的に そった 操作**で 参加に します(多少の 抜け道は 許容)。

| ゲーム | 8秒未満でも 参加に なる 操作 | まじめな 初心者(自動プレイ) | 放置・1回だけ | 連打 |
|---|---|---|---|---|
| ボンバー | 1体 たおす / ばくだんを 置いて 1マスいじょう 動く | 動いて ばくだん(にげる・にげない)16回中 **16回 記録**(見直し前は 7〜8秒で 終わると 記録されなかった) | 記録しない | 記録しない(パッドを 押す だけでは 動かない) |
| スネーク | リンゴを 1こ / 向きを 3回 かえる | ― | 記録しない | 記録しない |
| フロッガー | 1匹 帰す / 前へ 3マス 進む | でたらめ操作 4回中 4回 記録 | 記録しない | **記録する**(前へ とびこむ 連打は 3マス 進む。抜け道として 許容) |

## 4. 7つの 状況の 区別

| 状況 | 判定 | 例 |
|---|---|---|
| 完全な 放置 | 意味の ある 操作 0 → 記録しない | どの ゲームも |
| 一度だけ 操作して 放置 | アクション: 1区切りだけ → 記録しない / 考える: 回数 不足 → 記録しない | 1回だけ 操作した 回は、変更前 84本中 43本で 記録 → 変更後 **0本** |
| 意図的な 即時失敗の くりかえし | 何も 達成せず 1区切り(すぐ やられる ゲームは 2区切り)で 終わる → 記録しない | スネーク 1タップで 4秒: 記録 → 記録しない(へんしん 124/分 → 0) |
| 目的と 関係ない 操作の くりかえし | 状態が かわらない 操作は 数えない | ダーツの 的の 外・ドミノの「おす!」だけ・卓球で 自動で 当たる 球・りくじょうの 同じ 側の 連打 |
| まじめに 挑戦して 短時間で 失敗 | 最初の 目標を 達成していれば すぐ 終わっても 記録。4秒(すぐ やられる ゲームは 8秒)いじょう 遊べば 記録 | でたらめ操作(初心者の 下限の めやす)で 記録された ゲーム: 75本 → 69本 |
| 上手に 短時間で クリア | クリア = 目標 達成 → 記録 | ― |
| 考える ゲームで 長考 | 回数で 見る(時間を 見ない) | そうこばん・上海・ナンプレ・盤上の 対戦 |

## 6. のこる 課題(このPRでは 直していない)

1. **ブラックジャック(143/分)**: 運の ゲームで、ボタンを すぐ 押せば 数秒で 全部の 勝負が 終わります。「考える ゲームは 時間を 見ない」方針と ぶつかる ため、このPRでは 変えていません。案: 勝負ごとに「ヒット/スタンド を えらんだ」回数で 数える(いまは 1回)。
2. **ローグライク(123/分)**: 連打で 敵に つっこむと 4秒で たおれます。ターン制なので 時間で 区切らず、今回は 回数(3回)の まま。案: 「1体 たおす か つぎの 階」を 必須に する。
3. **フロッガー(115/分)**: 前へ とびこむ 連打は「前へ 3マス」を 満たすので 参加に なります。まじめな 初心者を 記録しない ことを さける ため、抜け道として 許容しました。
4. **10〜12秒で 終わる 短い 試合**(ブロックくずし・スペースガンナー・ビーチバレー・月面着陸・バッティング 74〜85/分): 1回 ごとに 3区切りいじょう ちゃんと 操作して いる ので 参加。ゲームの 長さの ちがいで、ふつうに 遊んでも 同じくらい たまります。
5. 盤上の 対戦の「25秒おきに 1手」(時間切れ 40点)は Phase 4。
