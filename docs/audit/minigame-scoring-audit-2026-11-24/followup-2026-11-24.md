# 追加確認と Phase 2〜5 の改善方針(2026-11-24・第2回)

- 監査 VERSION 1(本フォルダの README)に対して、2026-11-24 に B案の採用と段階的な進め方が承認されました。この文書はその後の追加確認と、Phase 2 以降の方針整理です。
- **Phase 2 以降は方針の整理だけで、実装はしていません。** Phase 1(重大3件)は別の Draft PR で実装しています。
- 承認された共通の目安:
  - 0点: 放置(実質的な参加なし)
  - 1〜29点: 挑戦したが、成果が不十分
  - 30〜69点: 一定の成果
  - 70〜99点: 優れた成果
  - 100点: 最高水準
- 承認された前提:
  - コインの帯(0/30/60)と、げんき(12)は変えない。
  - クイックゲーム50本の報酬は保留。
  - 過去の最高点・実績はリセットしない。
  - 連打は一律に禁止しない。ゲームの意図に沿っているかで判断する。

## 1. 追加確認

### 1-1. タワーディフェンスの「時間切れ=勝ち」を、なぜ重大3件に入れなかったか

**事実**(コード、`games.js` 3983〜4120行)
- 4ウェーブを全部倒すと勝ちになります。勝ちの点は `62 + 残りライフ×3.8`(60〜100点)です。
- 90秒(みじかめでは63秒)の時間切れで終わったときも `finish(lives > 0)` を呼ぶので、ライフが1でも残っていれば、**4ウェーブを倒していなくても**同じ「勝ち」の点になります。画面には「🏆守りきった!」と出ます。
- 負けの式は `12 + 到達ウェーブ×9 + 撃破×0.4`(10〜55点)です。タワーを1本も建てなくても、ウェーブが自動で2まで進むので、ちょうど30点になります。

**自動プレイの結果**(ハーネス)
- ゆみタワーを2本建てて放置: ふつう77〜92点、みじかめ96〜100点。
- でたらめ操作: 30・31・70・89点。

**重大にしなかった理由**
- 重大の定義(解答不能・進行不能・採点バグ)のうち、「採点バグ」は「コードが意図と違う点を出す」ものとして扱いました。
- タワーディフェンスは、コードが**明示的に**「時間切れでライフが残れば勝ち」を書いています。2026-10-12 の Phase 0 でも「仕様判断待ち(G-AC-31: 時間切れでも守りきった扱い)」に分類されていました。
- つまり不具合ではなく「設計の判断」の問題であり、進行も止まりません。そのため「改善推奨・高(P2)」としました。最終報告の 3-1 にも、その旨を書いています。

**現在の評価**
- 監査の時点では「改善推奨・高」でした。B案の目安(70点以上=優れた成果)に照らすと、**「タワー2本で放置して大成功」は明確な不整合**です。
- Phase 2(建設0本で30点)と Phase 3(時間切れの勝ち)の両方で扱います。
- 「守りきった」という遊び方自体は、タワーディフェンスらしい良さです。そこで次の方向を提案します。
  - 時間切れを「判定」にする。倒したウェーブの割合と残りライフで、30〜69点の帯にする。
  - 70点以上は、全ウェーブを倒したときだけにする。

### 1-2. 参加度メーターがある28本と、ない72本の違い

**仕組み**(コード、`script.js` `mgParticipated` / `finishMinigame`)

| | メーターあり(28本) | メーターなし(72本) |
|---|---|---|
| 判定に使うもの | 操作があった4秒区切りの数と割合(2区切り以上、かつ全体の2割以上)。盤上の対戦は、手と手の最長の間隔(30秒以内か、決着したか) | 「ゲーム画面で1回でも入力があったか」だけ |
| 何もしない | 記録しない(「途中でやめた」と同じ) | 記録しない |
| **最初に1回だけさわって放置** | **記録しない** | **記録される**(そのゲームの放置の点で) |
| 記録しないとき | 点・記録・コイン・そだち・個性・会話なし。げんき−6、きげん+2 だけ | ― |
| 記録されるとき(30点未満) | ― | しっぱい扱い: コイン0、**おとろえ+8・deathMeter+2**、きげん+5〜、げんき−12。自己ベスト・avgSkill・回数・実績の対象 |

メーターがあるゲーム(28本):
- road系6本(road-themed・city・jungle・desert、p3-space・p3-drive)
- ring-flight 2本、tilt-maze、hang-glider、plane-landing、sky-shooter、falling-block、downhill-snow、submarine、bubble-shooter、doodle-jump、tennis、minesweeper
- 盤上の対戦・カーリング9本(reversi・animal-shogi・connect-four・gomoku・checkers・mancala・air-hockey・curling 2本)

なお、そうこばんはメーターの代わりに、問題を解く画面での入力回数(`inputs`)を渡しています。練習の入力は数えません。

**自動プレイでの実際**(1回だけさわるボット)
- メーターあり28本: 1回だけさわって放置した回は、**28本すべて記録されませんでした。**
- メーターなし72本: **64本で記録されました。** 残り8本は、ボタンを押さないと終わらないゲームです(ピンボール・ダーツ・スキージャンプ・りくじょう・ブラックジャック・ヨット・UFOキャッチャー、そうこばんの練習)。
  - 記録された64本の点は、タワーディフェンス(30点)を除いて、**すべて30点未満**でした。

**採点・報酬への影響**
1. **点の高さへの影響は小さい。** 1回さわって放置したときの点は、ほぼすべて30点未満です。
2. **ただし扱いが逆になる。** 同じ「1回さわって放置」でも、次のように分かれます。
   - メーターありのゲーム: 「途中でやめた」扱い。罰はほぼありません(げんき−6)。
   - メーターなしのゲーム: 「しっぱい」扱い。おとろえ+8・deathMeter+2 の育成上の罰がつき、自己ベストの記録・avgSkill(れんくんの条件)・プレイ回数にも入ります。
   - 小さな子が画面に1回触れて置いたままにした、という場面で、ゲームによって結果が変わります。
3. **承認された目安との関係。**
   - 目安の「0点=放置」は、現在の「記録しない」に当たります。メーターありの28本では、すでにこれが実現しています。
   - メーターなしの72本では、「挑戦したが不十分(1〜29点)」と「放置(0点)」の区別が、入力が1回あったかどうかでしか付いていません。
   - Phase 2 以降で採点式を直すときに、同時にメーターを渡すと、この区別をそろえられます。

**提案**
- Phase 2・3 で式を直すゲームには、同時にメーターを渡します。点が変わるゲームと、放置の判定を一度にそろえるためです。
- それ以外のメーターなしのゲームは、Phase 5 でまとめて渡します。
- 盤上の対戦のメーター(turnGap)にも、別の弱点があります。25秒おきに1手だけ打つと、「参加あり」で時間切れ40点が記録されます(五目ならべ・コネクトフォーで確認)。これは 2-1 の Phase 4 で扱います。

## 2. Phase 2〜5 の方針と対象ゲーム(監査結果の再検討)

再検討で、監査の P2 の33本のうち、いくつかを**現行維持**か**要判断**に変えました。次のようなゲームは、ゲームの意図に沿った結果なので無理に直しません。
- 連打が遊びの中心になっているもの(りくじょうの100m)。
- 運を楽しむゲームとして成り立っているもの。

### Phase 4: 100点に届かない・難易度・制限時間・プレイ時間の不整合

- **100点に届かない17本**: 式の上限をそろえます。上手な完全クリアで100点に届くようにし、ふつうのクリアの点は変えません。
  - ビーチバレー88、3Dレース約85、かくとう92、着陸92、テニス94、ボウリング96、マインスイーパー96、上海約96、ソリティア約97、エアホッケー98、タンク99、カタパルト93〜99、しんけいすいじゃく約99
  - ブロックくずし、3Dダンジョン、2048、せんなぞり
- **時間と構造のずれ**
  - マンカラ: 60秒ではほぼ1局が終わらない → 時間を延ばすか、粒を減らす。
  - ふゆのカーリング: 4投なのに45秒 → 投げる数に比例させる。
  - ドットイーター: 時間内に全部食べられない → ドットを減らすか、時間を延ばす。
  - 「みじかめ」設定で満点やクリアが難しくなるもの: グランプリ・スカイシューター・おばけやしき・3Dダンジョン・卓球・ビリヤード・ミニゴルフ・フロッガー・たこやき。
- **対戦の時間切れ40点の見直し**(ご指示: 優勢・互角・劣勢・実質的な放置を区別する)
  - いまでも、オセロ・チェッカー・マンカラ・エアホッケー・テニス・卓球・カーリングは、時間切れのときに優劣で点が分かれます(判定勝ち55〜69/互角40/判定負け34以下)。
  - **五目ならべとコネクトフォーは、盤面の優劣を見ずに一律40点**です。盤面の評価(リーチの数など)で、優勢・互角・劣勢を判定するようにします。
  - **実質的な放置**(25秒おきに1手など): 「制限時間に対して手が少なすぎる回」は記録しないようにします(例: 自分の手が、互角に打てば打てる手の数の3分の1未満)。
  - **0−0のテニス・エアホッケー**: パックやボールに一度もさわっていない回は「参加なし」、ラリーがあった回は互角40のまま。
  - **互角は40点のまま**です(一律の減点はしません)。

### Phase 5: 軽微な見直し

- メーターなしの約70本に、参加度メーターを渡す(1-2 の提案)。
- 放置すると終わらない7本に、長い無操作で終わる目安を出す(ピンボール・スキージャンプ・ダーツ・ブラックジャック・りくじょう・ヨット・UFOキャッチャー)。
- ピクロスの問題「ほし」(答えが3通り)、ソリティアの配り、パイプつなぎの予備の盤、ゆきだるまタワーの色の見分け、ジェンガ・ドミノのタップの大きさ。
- 結果の一言の境目(80/50)を、報酬の帯(70/30)にそろえる(T10 G-QI-20)。

## 3. 進め方

- 各 Phase で独立した Draft PR を作ります。各 PR には、次を入れます。
  - 変更前後の比較表(自動プレイのボットで、放置・でたらめ・連打・上手な操作の点)
  - 改善の理由
  - ゲームバランスへの影響(コインの帯に入る割合の変化)
  - 回帰テスト、Chromium・WebKit での確認、試遊ページ
- Phase 2 の実装は、この方針表の承認後に始めます。特に「要判断」の4件(ブラックジャック・ヨット・ピンボール・ケーキ/ドミノ)は、ご判断をお願いします。
