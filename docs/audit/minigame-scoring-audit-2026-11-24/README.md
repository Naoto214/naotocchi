## 0. 結論(先に要点)

1. **重大は3本。** 進行不能・採点バグに当たるのは、たまころがし迷路(採点バグ)、上海(詰んで時間切れまで進めない)、スライドパズル(まれに解けない盤)。
2. **そうこばんと同じ「達成ゼロでも30点以上」は、そうこばん以外に少なくとも20本あります。** さらに、**単純な連打・放置に近い操作で「大成功(70点以上)」が安定して出るゲームが約15本**あります。この2つを合わせた33本を「改善推奨・高(P2)」にしました。
   - 自動プレイで新たに見つかった例: **つみあげタワー系6本は、ボタン連打だけで100点**(6回中5回)。実ブラウザでも100点・60コインになりました。
3. **100点(満点)に届かないゲームが17本**あります(上限88〜99点、または時間内に事実上届かない)。
4. **報酬は「1回あたり」は公平、「時間あたり」は最大で約19倍の差。** コインは点数の帯(70/30)だけで決まり、プレイ時間は8秒〜150秒です。ケーキデコレーションは約8秒で必ず100点(60コイン)。
   - ゲーム一覧から同じゲームを選び直せるので、「短くて満点が確実なゲームの周回」が最も効率的になります。げんき(1回12)で回数は抑えられています。
5. **推奨は B案(達成度と挑戦のバランス)を「5つの原則」として導入し、A案の修正から段階的に進めることです**(7章)。C案(共通式への統一)は、ゲームの個性と過去の記録の比較可能性を失うため推奨しません。

自動プレイのボット(`tools/minigame-audit/sim.cjs`):
- **放置**: 何もしない。
- **1回だけ**: 開始1秒後に1回タップして、あとは放置。
- **でたらめ**: 画面・ボタン・キーに、0.25〜0.6秒ごとにランダムな操作をする。初心者の下限の目安です。
- **連打**: 中央タップ・ボタン・スペースを、0.15秒ごとに押し続ける。

制約もあります。ハーネスの画面は300×300の代用品なので、ドラッグで置くゲーム(ケーキ・おべんとう)には、でたらめ操作が届きません。こうしたゲームの値は参考扱いにしています。

## 2. 共通の採点・報酬の仕組み(コードから確認)

| 点数 | 帯 | コイン | 育成 | その他 |
|---|---|---|---|---|
| 70〜100 | 大成功(great) | 60 | そだち+14、おとろえ−8 | きげん +5+点/5 |
| 30〜69 | **ふつう(success)** | 30 | そだち+7、おとろえ−3 | きょうのチャレンジは30点以上でクリア |
| 0〜29 | しっぱい(failure) | 0 | おとろえ+8、deathMeter+2 | |

- **ランク**: S 90以上 / A 75以上 / B 55以上 / C 35以上 / D。Sランクでは「せいちょう2ばい」が2分つき、30%でシールが出ます。
- **なかまの勧誘**: 50点以上(レアは70点以上)で成功します。
- **参加の判定(T7、2026-10-28 案B)**: 操作がほぼない回は「途中でやめた」と同じ扱いで、記録されません。
  - ゲームが操作の量(`mgPlayMeter`)を渡す場合: 操作のあった4秒区切りが2つ以上で、かつ全体の2割以上なら参加。
  - 渡さないゲーム(**100本中、約70本**): 1回でも画面に触れれば記録されます。
- **げんき**: 1回のプレイで12減り、10未満では遊べません。プレイの長さは関係ありません。
- **結果の一言**(`resultMessageForScore`)は 80/50 で分かれ、報酬の帯(70/30)とずれています(既知の G-QI-20)。

## 5. 難易度・制限時間・解答可能性

- **制限時間が構造に合わないもの**
  - マンカラ: 60秒ではほぼ1局終わらず、上限69点の判定止まりになる。
  - ふゆのカーリング: 4投なのに3投と同じ45秒。
  - ドットイーター: 全部食べるのに136マス以上必要だが、28秒で動けるのは129マスまで。
  - そのほか、上海・ソリティア・3Dダンジョンは、時間ボーナスの式と制限時間が合っていない。
- **「みじかめ」設定との相性**(手番制以外は0.7倍に短縮される)
  - グランプリ・スカイシューター・おばけやしき・3Dダンジョン・卓球・ビリヤード・ミニゴルフ・フロッガー・たこやき・ライツアウトで、クリアや満点が大きく難しくなります。
  - 一方、サブマリンは短いほうが有利になる逆転があります。
- **運の比重が高いもの**: すごろく、ブラックジャック、ヨット、しんかいフィッシング(大物1匹で100点)、マッチ3、ハンググライダー。
- **スマホ操作**(コードからの推定。実機での確認は今後の課題)
  - ジェンガのブロックは高さ16px、ドミノの置き場所の間隔は14pxで、押し間違えやすい。
  - ゆきだるまタワーは白どうしで見分けにくい。
- **簡単すぎる**: 3-4の表のとおり(ケーキ、ドミノ、ジェンガ、ボクセル、ハーフパイプ)。
- **難しすぎる**: れんさパズル(普通に遊んで30点前後)、ブロックくずしの3面、2048の高い段。

## 6. プレイ時間と報酬の公平性

- **1回あたり**: コインは点数の帯だけで決まります(0/30/60)。げんきの消費は一律12です。点数帯が同じなら、どのゲームを選んでも報酬は同じです。
- **時間あたり**: 想定プレイ時間の中央値は約28秒です。最短はケーキの約8秒、最長はそうこばんの約150秒です。
  - 必ず100点になるケーキ: 60コイン÷8秒 = **約450コイン/分**。
  - ふつうのアクション(30秒で大成功): 約120コイン/分。
  - そうこばんで3問クリア: 約24コイン/分。
  - 最大で約19倍の差です。
- **周回の有利さ**: 「ゲームきろく」から同じゲームを選べ、結果カードに「もういちど」もあります。そのため、短くて満点が確実なゲーム(ケーキ・ドミノ・ジェンガ・つみあげタワー)の周回が最も効率的です。Sランクの「せいちょう2ばい」(1回2分・最大10分)と、30%のシールも、同じように周回で集まります。
  - 歯止めは、げんき(100から約7回)と、1日に1回のきょうのチャレンジです。
  - したがって「1日あたり」の差は大きくありませんが、「短い時間で効率よく」の差は大きいです。
- **方針**: 長いゲームの報酬を増やすより、**満点が確実すぎる短いゲームの採点を直す(P2)** ほうが、ゲームの個性を残したまま公平になります。「短く遊べるゲーム」と「じっくり遊ぶゲーム」の両方は維持できます。
- **実績・プレイ回数**: 回数は開始時に数えます(G-QI-16)。参加なしの回は記録されませんが、回数(`minigamePlayCounts`)は増えます。ゲームによる差はありません。

## 7. クイックゲーム50本(補足)

- **採点**(コード): 混ぜたラン(20本)は1本クリアにつき5点、「1本ずつ」(10回)は1回につき10点です。ライフは3です。
- **報酬**
  - コインは**混ぜたランの20/20(100点)だけ100コイン**で、それ以外は0です。
  - げんきを使わず、げんき0でも遊べます。
  - 育成・勧誘・avgSkill には入りません(T9 で決定済み)。
  - 記録と回数(`minigamesPlayed`)は増えます。
- **役割の違い**: 通常ゲームは「育成とコインの主な源」で、クイックは「すきま時間の腕だめし」です。役割が分かれていて、通常100本の採点の問題はクイックには及びません。
- **気づいた点**(変更なし・要観察)
  - 19/20(95点)でも0コインです。報酬が「完全クリア」だけにあり、崖になっています。腕だめしとしては一貫していますが、やさしさの面では検討の余地があります。
  - げんきを使わないので、熟練者が連続でパーフェクトを出せる場合、時間あたりのコインは通常ゲームより高くなりえます(1回約80秒で100コイン)。パーフェクトの実際の達成率は人間の測定が必要です。
- **確認していないこと**: クイック50本それぞれの解答可能性の自動プレイ。出題が一意になることは、既存の `minigame-phase2-randomization-test` が確認しています。
- **なおぽよ。・なおころ。・CARD GAME**: 共通の報酬処理(`finishMinigame`)は通りません(確認した範囲)。今回の提案の影響範囲には入りません。

## 8. 採点基準の改善案(A・B・C の比較)

| 論点 | A案: 現行維持+明らかな不整合のみ | **B案: 達成度と挑戦のバランス(推奨)** | C案: 共通採点基準 |
|---|---|---|---|
| 0点の定義 | 現行のまま。放置は T7 で記録しない | 現行どおり「放置=記録しない」を0点の代わりにする | 全ゲームで「放置=0」を式に組みこむ |
| 挑戦だけで最低点 | ゲームごとにばらばら(5〜50) | **挑戦した失敗は10〜25点**(しっぱい帯の中)。「がんばった」の文言を出す | 一律10点 |
| 放置と挑戦失敗の区別 | T7 のまま。ただし meter を渡さない約70本は、1タップで記録される | **全ゲームに meter を渡す**(T7 の判定をそろえる) | 同左 |
| 部分達成 | ゲームの式のまま | **最初の小さな目標を1つ達成で30点**(1問・1ライン・1ゲート・1勝など)。それ未満は30点未満 | 達成率×70 で機械的に |
| ボーナス | 手数・時間・コンボがゲームごと | **ボーナスは達成の上に乗せるだけ**(達成ゼロには足さない)。点の2割まで | 一律の時間ボーナス |

| 悪い点 | 達成ゼロで30点、連打で満点、が残る(P2の33本) | 33本程度の式を見直す手間。自己ベストの一部が出にくくなる | 個性が消える。全100本の書き直し。過去の記録と比べられない |

### 推奨: B案を「採点の5つの原則」として採用し、段階的に適用する

1. **達成ゼロは30点未満**(しっぱい帯)。ただし、挑戦した失敗は10点以上にし、放置(記録なし)と区別する。
2. **単純な操作の繰り返し**(連打・押しっぱなし・放置に近い操作)で、**大成功(70点以上)が安定して出ない**。
3. **上手な完全クリアで100点に届く**(時間内に物理的に可能であること)。
4. **ボーナスは達成の上に乗せる**。達成ゼロに足さず、点の2割を超えない。
5. **負け・時間切れは、同じ局面の決着の勝ちより低い**(T1 の考え方を、対戦以外にも広げる)。

この5つは、自動プレイのツールで「放置・連打・でたらめのボットが 原則1・2 を破らない」ことを、テストとして毎回確かめられます。
