## 関係性・保存の仕様

NPC45種の正式マスターを参照し、既存46イベントが指すNPCに出会う。全NPCが毎回出る設計ではない。仲間の誘い、会話、恋愛の意思表示、別れの選択を別フェーズで扱う。固定NPCの設定は変更せず、プレイヤーのこの旅の性別・恋愛タイプを設定できる。本編個体の既存設定を読み込んだ場合は尊重する。考え中・恋愛しない設定は友情となる。fate-04「八つ目の窓」の後には「なおと」と追加報酬なしで立ち話する。恋人休止後も交際関係は残り、二重交際を防止する。

保存schema 3。V2 schema 1は自動移行し **rulesVersion 2** で旧対戦の抽選・ミニゲーム・NPCプレイヤーを継続する。黙って選択キャラを削除しない。旧対戦にはその旨を画面表示し、新しいV3関係性は新規対戦から有効。主セーブ＋検証済み直前バックアップを保持。本編キーには書き込まない。

サイコロの出目と停止待ち期限、経路、選択／結果、NPC関係・同行・履歴・ステージID・CPUスキップ結果は保存される。再読み込みでCPUの読み時間は最初から、進化の見せ方は省略可能だが確定値を再適用しない。背景タブ／休憩中はタイマーを止める。改ざんされた同行経路は保存を置換する前に拒否する。

## 意図したV2との差分

旧対戦では乱数・報酬・経路・成長を保護。V3新規対戦では以下を変更した。

1. 仲間・恋人の関係選択を追加（恒常的能力補正なし）。追加の判断手順に伴いCPUの選択系列は変わる。
2. `worldRegion` を日本編定義のイベントプールへ対応させる。森で海限定イベントを抽選しない。旧 `BOARD.region` はV2継続専用に残す。
3. 記憶・パズルのチャレンジを本編ルール由来の短縮版へ変更。チャレンジ用乱数消費が変わる。
4. イベント文面の改善。数値、ID、選択数は保護。
