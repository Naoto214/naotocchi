# V3 日本ステージ・48マス監査

2026-10-30。対象は独立プロトタイプ `prototypes/life-sugoroku/` のみ。本編の地理・画像は変更していない。

## 地理の根拠と盤面への翻訳

正本は `meguru.js` の `WORLD_GEOGRAPHY`（version 2 / canon v1 / plan D2）。キャラクターと世界のIDの参照元は `character-world-master.v1.js`。過去の `NAOTOCCHI_MASTER_SPEC.md` の件数・未実装リストは現在の地理正本として使わない。

- 北を上に置く。西の山地と東の山なみの間が細長い谷。おうちは谷の大川のすぐ西。東の山なみは背景地形であり、歩ける地域・マスを作らない。
- みなもとの湖から谷の大川（内部ID tenryu）が南へ下り、おうちの横、峡谷、外洋へ流れる。とかい・湾とは接続しない。
- いなかととかいの間に分水界を描く。みやこがわ（内部ID shonai）は分水界の町側から始まり、とかいを通って南西の湾へ注ぐ。上流同士を接続しない。
- 森はおうちからいなかへの途中、西の山地の裾。湖岸から北の小さな峠へ回る分岐は mountain → river_lake / forest の既存の関係を使う。
- 海からおうちへの盤面の帰路は南の峡谷・谷沿いを圧縮したすごろく上の表現。本編に home|sea の新しい正式接続を追加するものではない。
- 48マスの循環盤なので縮尺・距離・個々の主世界接続の完全再現ではない。主世界全13地域のうち7地域を表す。砂漠・雪国・島・深海・上空・記憶層を新しい遊べる地域として追加していない。

## 互換性と到達性

ID 0–47、元の type、next、4分岐の各4マス腕を保持。52有向辺、行き止まり0。全48始点それぞれから全48マスへ到達できる。分岐は 1→2/6、13→14/18、25→26/30、37→38/42。合流は10/22/34/46。番号は通常非表示、tileSvg の debug:true の場合のみ1始まりを表示する。監査表は0始まり。

`region` はV2保存の抽選互換用に保持する。V3新規対戦では `worldRegion` から日本編定義のイベントプールを引く（おうち・いなか→square、川・湖・やま・もり→forest、とかい→city、うみ→sea）。したがって森で海限定イベントは起こらない。地理表示は `worldRegion` と `label` を使う。表の旧プールはV2互換用の値である。
