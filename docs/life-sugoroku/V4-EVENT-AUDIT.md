## Adapter contract

`eligibleEvents(s,p)` maps the V4 board's worldRegion through JAPAN_STAGE.events.regionPools, always excludes personal seen IDs, and avoids shared recent IDs when another event exists. Recent-only exhaustion reuses an unseen candidate; total exhaustion yields a quiet zero-reward result.

`offerEvent(s,p,draw)` draws exactly once from eligible candidates. `applyEvent(s,p,pending,index)` validates the scene and integer choice before mutation, returns a result pending, records actual clamped deltas, and prevents duplicate application through seen IDs. It does not set host phase/pending or consume randomness.

An armed charm cancels negative reward components once and preserves positive components, matching V3 item behavior. Clock youth adds one growth to each of the next two applied choice events; this explicit item exception can produce non-five-unit deltas. Clamps may also yield partial deltas. No 20-round penalty, affinity, orientation, persistent scene flags, stage change, or species change is applied.
