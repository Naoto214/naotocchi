# 画面QAの実施範囲と未完了項目

Cloud Chromeの管理プレビューを使用。公開sourceと4049ファイル照合済み。iPhone実機ではない。

| 対象 | 観察 |
|---|---|
| 都会390px | 前景の芝生/細い散策路、中央道路、両側歩道、奥の店舗。旧巨大灰色台形なし |
| 正式最大2体 | 320pxで主役＋恋人、430px枠内で主役＋仲間。各キャラの姿と選択を確認 |
| サイズ | 操作見本の主役枠154/176/198pxを比較。176pxを維持 |
| 案内 | 390pxでメニューから再表示、案内あり/なしの画面を確認 |
| 通知＋会話 | 375pxの配置fixtureで上部通知・下部会話・育成操作の分離を確認。報酬の発生条件試験ではない |
| 森・水辺 | 既存の小道・樹木、川・岸・岩の構図を確認 |

成功ドラッグの習得/保存、キャンセル、人数変化、育成操作、セーブ互換は自動テストで検証。ブラウザーでのドラッグは実施したが、全種類について成功後の移動先を個別に確定できておらず、実指の操作性を合格扱いにしない。

スクリーンショットはブラウザー側に保存したが、規定の共有先への同期が失敗した。要求された7種類の比較画像はGitHub保存・添付未完了。古いv7画像をv8の証拠には使用しない。とくに修正前後の新規比較合成は未作成。

本人iPhone Safariでは、2体のタップ/ドラッグ、表情、初回案内終了と再表示、車/通行人/魚の自然さ、safe-area、通知＋会話、画面復帰と長時間の滑らかさ/発熱を確認する。
