# なおぽよ。今後の構想

将来は10章・各10面の全100ステージを目指す。第1章は1〜10、第2章は11〜20、以降は章ごとに10面ずつ増え、第10章は91〜100とする。

序盤は基本操作を学び、後半は仕掛けの組み合わせと発想の難しさを発展させる。操作数を増やすこと自体は難易度の目標としない。

現在の20面は156手の保存解答があり、第2章として難しすぎる可能性がある。将来、難易度の見直し、後半章への移設、挑戦面としての保存を検討する。今回は盤面や難易度を変更しない。

おてほんは検証済みのステージ別操作列と共通再生機構を分け、今後の章に拡張する。新しい解答も実エンジンの入力経路で検証し、全員救出できる場合にのみ表示する。
