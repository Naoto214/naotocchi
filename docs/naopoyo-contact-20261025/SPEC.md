# 共通接触ルール contact-v1

本人指定の共通ルール改訂。`movementRules: contact-v1` は章番号に依存しない共通契約。第2章のみopt-inし、第1章・旧12面・既存v2は従来のまま。将来正式移行時も各面の解答・保存移行を検証してから明示的に採用する。

## 採用方針

合体可能（同種族、8+8以外）なら既存足し算合体・余剰分離を優先する。合体条件を満たすが門条件等で拒否された操作を交換へfallbackしない。異種族または8+8の場合だけ交換を検討する。

交換はプレイヤー操作と外部移動の接触に適用し、自然落下には適用しない。A/B双方の移動先地形・門・角と上昇条件を交換前に検証する。片方の拒否は無変更。両位置を同時確定後、操作キャラ→相手の順で地形効果、最後に既存の決定的重力を実行する。IDは保つ。

両側の岩・壁（盤外含む）が塞ぐ斜め移動を禁止。片側のみなら通行可否と上昇を通常判定。分裂体の2歩配置経路も閉じた岩角を越えない。キャラは動く接触対象であり角の壁にしない。魔法門はマスの通行条件であり岩角として扱わず、実際に入るキャラ／合体結果／余剰を検証する。

出口は全段階・種族に通行可能、条件一致時だけ救出。出口だけでは支持にならない。出口上の不一致キャラは保存可能。合体結果と余剰の出口条件も確認する。救出済みキャラは重力処理しない。トゲは従来supported-v1の実進入時分裂・非支持を維持する。

重力下の上昇は両キャラに既存supported-v1を適用。出発点・到着点の下に支持が必要で、自分を支持に数えない。このため飛行なしの単純な上下交換は上がる側が支持を得られず拒否される。8方向対象とは無条件8方向許可を意味しない。交換後に支持がなくなれば同一操作内で落下。

## 比較した方式
- 全面の既存ルールを変更：正式第1章を保護できないため不採用。
- 第2章のローカル例外：共通仕様・将来100面への拡張に反するため不採用。
- 明示的共通ルール版：採用。未指定面の互換性、解答・保存移行の境界が明確。

## 表示・保存
交換の論理処理は即時で決定的。2体は約180msの小さい弧で表示し、入力をロックしない。落下があれば交換後に続ける。reduced-motionは演出だけ省略。

新保存キーへ旧pilot/supportedの進捗だけ読み取り移行し、旧盤面/Undoは持ち込まない。旧キーは無変更。QA保存は通常進行から独立。

## 検証前の留保
角抜けと出口非支持で旧解法が変化する。全10面・20の難易度を再探索して採否を評価する。重大な破綻時は配信しない。人間の超高難度体験とiPhone実機は自動検証と区別する。
