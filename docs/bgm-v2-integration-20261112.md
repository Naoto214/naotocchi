## 音量・フェード・効果音との 関係

- 音源は 用途別の 音量で 原盤に 焼いて ある（ホーム −23 LUFS 基準）ので、再生側で 二重に 下げない。
- 本体での 全体音量（`FILE_LEVEL = 0.4`）は、ホームで 以前の 合成BGM と 出力の RMS が そろう 値を Chromium で 実測して 決めた（0.5 だと +2 dB だった）。
- 曲の 切りかえは 古い 曲 0.9秒 フェードアウト・新しい 曲 1.2秒 フェードイン。ジングルの 間は ループ曲を 下げ（−10 dB、たまごは −14 dB）、終わったら 1秒で もどす。
- よみあげ（クイックモードの こえ）の 間の ダッキングは 以前と 同じ（音源BGM も bgmBus の 下に つないだ）。
- 効果音・こえの 音・音量は 変えて いない。

## iPhone Safari・画面遷移

- 最初の タップ（pointerdown・keydown）の 中で AudioContext を 再開し、無音を 1サンプル 鳴らして 解除する。
- タブが 隠れたら 止め、もどったら 続きから（既存の 動きと 同じ）。サブアプリは ページを 離れると 音も 止まる。
- 復号済みの 音は 最大 3曲だけ 持つ（1曲 約 30 MB の ため、iPhone の メモリを 守る）。
- 音源が 読めない とき（通信不良など）は 以前の 合成BGM に 自動で もどる。
