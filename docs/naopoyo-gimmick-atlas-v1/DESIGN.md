# 全体設計 VERSION 1

これは採用前の設計成果物。ゲームエンジン、正式第1章、PR #523 V2、本番UIを変更しない。100面を実装しない。比較ページは本人限定の別Site。新規ファイルのみの独立Draft PRに保存する。

## 制作方針と比較した選択肢

1. 多数の独立装置を追加：見た目は増えるがルール記憶と似た解法も増える。推奨しない。
2. 少数の共通原理に整理し、配置・順序・配分を変える：今回の推奨。装置の外見と因果を固定できる。
3. 既存スイッチ中心で100面：技術負担は小さいが本人の問題意識に反するため不採用。

これらは制作者の提案であり、本人が選択済みという意味ではない。32推奨にはコア・派生・構成法も含むため「32種の新エンジン機能」ではない。

## 表現の共通ルール

- 機能は形で表す。床スイッチは既存の丸い沈むプレートを保持。重量型は天秤台座、記憶型は留め爪、順序型は噛み合う歯車。丸・ひし形・チェックの抽象的な使い分けは廃止案。
- 色は対応関係に使用し、機能には使用しない。1組なら無印。複数組は青緑＋一本溝／琥珀＋二本溝／紫＋点の縁の最大3組。色を消しても模様が対応する。多数組を必要とする盤面自体を見直す。
- 推奨色：輪郭 #263f39、石 #a7b7ad、木 #b98c55、信号青緑 #287e77、金 #e0b34a、危険 #b64b3b、紙 #f6f1df。白い光だけで状態を伝えず、押込み・錠の位置・橋の有無を変える。
- 星は出口だけ。出口は金星アーチと統一された下札。条件がなければ札なし。「=4」は単体の段階で、4体を意味しない。門は梁、扉は格子、通路は床、ワープは環で区別。
- UI文言「重さ」は提案。内部のlevelや正式ゲームの用語を今回書き換えない。最終採用前に第1章の説明と読み合わせる。
- 木の重力看板・タップ説明は維持。重力面の全床に矢印を敷かない。
- NPCは壁のない専用表示マス。足元のアンカーを床上面に固定し、影を床に描く。吹き出しと名前は予約した上部空間、盤面外へ自動折返し。画像そのものは変更しない。
- 大岩は非対称な岩肌と重い接地影、押箱は木枠と金具。動く足場は必ずレールと停止点を持ち、崩れる床は石床と同じ素材に段階的な亀裂。
- 完了はチェック印ではなく世界の変化で示す。岩の移動、橋の完成、留め爪の固定を描く。

## 比較画像の位置づけ

SVGはゲームに組み込む前の機能デザイン原画。A「木と石」は厚み・接地影・素材を重視、B「くっきり」は影を減らし太い輪郭と平面を重視。Aを基本、36pxで輪郭が潰れる部位だけBへ寄せる案を推奨する。キャラを描き直した図案ではなく、NPC項目には能力を説明する装置図を置く。正式画像は比較ページの住民欄にそのまま載せる。

すべての推奨項目にA/B画像を用意。待機／作動の比較は状態がある装置だけに適用し、分裂等は前後の模式図である。図は操作可能なゲームではない。保留・不採用にはルール確定前の量産原画を作らない。

## 新規機能の正式化ゲート

推奨でも未実装の機能は次の順で別途検証する。合格前にその機能が必要なステージを完成扱いにしない。

1. 最小盤面で移動・出生・接触・余剰・交換・落下の全組合せを確認する。
2. 手番の順序案：有効な1マス移動→既存の分裂／接触／重力の安定化→装置条件→予約効果→外力→既存安定化→出口判定。装置連鎖が一操作で終わらない場合は循環を拒否する。これは未実装の候補順序で、正式エンジンを先に変えない。
3. 外力・転送は一操作内同装置1回。占有・閉門・能力喪失を検証。新規UIを要する待機・潜水切替・乗物操縦は保留。
4. 保存は個体、選択、装置状態、予約、位相、救出、崩壊を一つのスナップショットにする。Undoで全復元。試作保存キーは本編と分離。やりなおしで初期状態へ。
5. 飛行実験の旧BFS分裂・トゲ支持を持ち込まない。正式D・supported-v1で再実験する。主人公の種族を面ごとに指定する案は、画像・保存・能力派生の設計を別途通す。

## 作問・検証規約

各面の解法は「操作列」だけでなく、状態遷移の依存グラフを記録する。装置ごとに独立した仕事を一文で定義。たとえば18は〈足場確保→橋完成→向こう岸で分配→崩壊路から回収→出口〉。橋完成と出口成立は別の操作でなければならない。

- 各装置を無効化した探索でクリア不能か確認。取り除くことと常時開放は別々に調べ、見た目だけの装置を発見する。
- 救出フラグを偽固定、協力効果を無効化、出口の救出条件だけ除去の3検査で、地形上も協力が必要か調べる。
- 最短解法は全状態の幅優先探索で証明できた場合だけ最短と記す。予算打切り・best-firstは「検出解」。選択を手数に数えるか、ドラッグ中の1マスを1手とするか固定する。
- 1操作で複数段階が完了するかイベントログで確認。無関係な同時効果は許容できるが独立課題の代替は不可。
- 表中の発想が違っても、依存グラフが同型なら再作問候補。特に11/29/84の保持引継ぎ、26/54/85の綱、34/64/94の荷物は重複監視対象。
- 最短手数を難度指標の主役にしない。分岐の意味、可逆性、配分の選択、将来状態の予測で評価する。
- ソフトロックはUndo／やりなおしで復帰。初見で不可逆状態になる装置は発動前に形と予告で読めるようにする。
- 100面の本表は盤面・解法の証明ではない。既存面以外に最短解法やプレイ可能性を主張しない。

## ヒントと画面

通常の面上部は場所と目標だけ。具体的な進入位置、分裂数、スイッチ順を常設しない。ヒントを開くと①観察する対象②考え方③操作例の順。おてほんは最後の明示操作。第1章のチュートリアルはそのまま保存し、第2章以降だけの提案とする。

比較ページは分類を1つずつ表示。100面表は章ごとのカードに分ける。ダウンロードはCSV／Markdown／JSON。ブラウザの本編保存を一切読まず書かない。横向きは2列、縦は1列を基本にし、図内の36px・48px表示を用意する。
