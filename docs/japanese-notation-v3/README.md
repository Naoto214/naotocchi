## 用途別の基準

既存の [文章ルール](../TEXT_STYLE.md) を判断の基準にした。短い操作名・数値ラベルはひらがなを使い、説明でボタンを指すときはその表示名を引用する。長い説明はやさしい漢字と句読点で区切る。「そだち」と「せいちょう」、「きずな」と「なかよし度」のように別の値を示す語は区別する。セリフは話者の口調、書名・進化名はそれぞれの正本を尊重する。過去の記録は原文を残し、照合が必要な場所で旧名と新名を扱う。
