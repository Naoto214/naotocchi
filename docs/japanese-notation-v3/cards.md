# CARD GAME　名称を採用する場合の表示・検索・保存

5枚のできごと札は読みを変えずに正式カード名を漢字まじりにすることを推奨する。あそび札100枚と本編の選択画面をIDで結ぶと、現行の題名は90組が一致する。差がある10組のうち、迷路1組は同じ読みのため統一を推奨し、9組は別々の題を維持する。これらはVERSION 3の採用案で、採用済みのカード改訂とは区別する。

## 旧名検索を確かめた範囲

コレクションの collection.mjs:9 とマイデッキの my-decks.mjs:48 は、name・form・searchAliases・id・text を検索に使う。実装と同じ関数を読み込み、5枚のできごと札と迷路の計6枚について、メモリ内に仮の新名と旧名別名を設定した。6 ID × 新旧2名 × 2画面の24判定で、いずれも元のカードIDが返った。戦績の検索（records-ui.mjs:20）は name と id のみ。戦績でも旧かな名から探せるようにするには、この検索式に別名を加える必要がある。

**再現確認**　新規のテスト用2人対戦（hotseat-9、seed 4）で E-new-encounter を合法手として発動・解決し、4手目の保存を作成した。表示名だけをメモリで変更して保存を復元すると、「A：あたらしいであいを発動／解決」の2行がそれぞれ「A：新しい出会いを発動／解決」になった。表示する結果履歴にも新名が入り、カードIDを含む操作列、両者の状態、エンジンの行動履歴、再保存した文字列は変更前と一致した。5枚すべての発動条件や全世代の旧対戦を再現したものではない。

## 承認の扱いと表記判断

#564 は19の進化表示名、#571 は既存11枚の漢字表記と追加3枚の名称承認。追加3枚の導入は #573 の新規7枚の内数。#565 は表示デザイン、#574 は459枚と閲覧用たまごの件数・ページング。承認範囲は対象IDと欄で照合し、同じ札の能力名や本文には広げない。典拠は prototypes/card-game/evolution-names-v13-20261119.md、docs/card-game/kanji-names-v17-20261119.md、tools/card459-adoption-v18-20261120.json。今回の5枚・迷路と残り9組への推奨は、この既承認群とは別の判断である。

非Aの能力名179件は、正式カタログの各カードIDの source にある名称と、そこが指す個別の設計原稿を突き合わせた。J214（治す／直す）、J228（世界／セカイ）、J245（変える／換える）、J273・J329（火／日）は表記次第で意味が限定される。J283「まもつ」は設計原稿にも同じ読みがあり、誤記と断定せず「つぼみを守る」を比較候補にした。いずれも個別判断とし、綴りだけでカード効果の対象・数・時機を変えない。J025の「人生の時計の表面」は読み上げ用途の改善候補だが、配置名という情報も外れるため個別判断とした。
