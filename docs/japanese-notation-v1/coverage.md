## 集計と調査の境界

台帳は日本語のまとまり、出典、ゲーム内の役割を単位にしている。複数行のテンプレートはソース上の開始位置または表示要素の行を付けた。動的数値、名称、分岐は｛ ｝と省略記号で表し、条件別に定義された文言も記載した。原文中の改行、連続する空白は一覧用に調整した。記号のみの装飾や単純な数値は一般に数えず、攻略に関わる門・出口の条件記号を別に記録。単にリポジトリに残るQA、非公開の操作比較、成長落下系など許可リストにない独立試作は対象外。別章から名前付きで import する部品は実使用箇所を追った。

ソース静的照合が中心。端末・保存状態・乱数を組み合わせた全画面の実表示、実画像内の焼き込み、読み上げ実音、各ブラウザーが返すエラー文、全時点の動的連結文は未確認。共通の本編マスターが供給するキャラクター名・個性文は本編側とも照合する。ゲームの状態、セーブキー、スコア値、面の解法、音声辞書や画像は編集していない。

1. 日替わりの「1日1回。成功でラッキーコイン1個」は、対象ゲームで実点30点以上を取った日の初回が報酬対象。「今日のゲームで30点以上を取ると、ラッキーコインを1個もらえるよ（1日1回）。」とすると再挑戦の余地も伝わる（script.js:13303、17830）。
2. クイックの「穴から出てきたものをタップ。」は正解とおとりの花を区別できない。「穴から出たうんちをタップ。花は押さないでね。」なら判定どおりに遊べる（quick.js:181、735、736）。
3. 「✨はじめてのゲーム」は通常の3回目にも表示される。同じ見出しを使い続けられる「✨あそびかた」を提案（script.js:17997、18163、18595）。
4. 「画面かしたのパッド」は「画面か」と「した」の境界が読みにくい。「画面か画面下のパッド」とすれば操作先が区別できる。開始紹介と実プレイのヒントは別ソースなので両方が対象。ゲーム名の3Dを先に置くか後に置くかは、一覧名と演出見出しの扱いを決めてから変更する。
5. クイックの短い「たべろ！」「よけろ！」と読み上げ「たべろ」「よけろ」は役割が異なる。音声文字列と画面文字列は各自の用途で維持した。
