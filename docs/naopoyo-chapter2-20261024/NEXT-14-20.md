# 14〜20面の制作計画（未実装）
本人の11〜13試遊後に難易度を決定する。先に量産しない。

|面|発見候補|制作時の検証|
|---|---|---|
|14|足場役を分裂して必要な大きさを取り出す|分裂しない短絡解、下段だけで全員救出できる解を調査|
|15|トゲのマスそのものに着地して止まる|空トゲ直上との違い、進入方向不変、離脱再進入|
|16|余剰を高い位置へ残す|8超過を使わない解を調査、単なる加算問題を避ける|
|17|同じ仲間が支える役と進む役を交替|最初から固定足場にする解を調査|
|18|一度降りてから上の道を作り直す|戻る発想が必須で、移動の長さだけになっていないか|
|19|出口の数字から、残す足場を逆算する|13の単純延長を避ける。違う順序の別解を許容するか明記|
|20|森の総合問題。支える→分かれる→再会→全員帰還|全員救出、早期救出で詰む反例、初見観察・ヒント依存率|

各面は「新発見・中心発想・前面との差・必須ギミック・主解・別解・短絡・仮難易度」の8項目で採否判定。操作精度や待ち時間を難易度に使わない。飛行正式導入・ゲスト複雑操作・新ボタンは別途。
