# 本人用iPhone Safari試遊手順

試遊URLはdelivery.mdおよびDraft PRに記載。本人のChatGPTアカウントで開く。別origin＋試遊専用保存キーなので本番の進捗とは独立する。QA操作は試遊版のみに含まれる。

1. 通常の「あたためる」で誕生。データで4気質、4こころ、好み未形成を確認。
2. 左下「本人用・個性QA」→「新しい子」で試遊データを初期化できる（試遊内の実績もリセット）。確認後はQAパネルを閉じる。
3. 12年齢ボタンで各イベントを確認。これは年齢を直接設定するQA機能で、未訪問の中間イベントを自動消化しない。
4. 3択の全文・縦並び・タップ範囲・横スクロールなしを確認。選択中の年齢停止、選択後の短い反応を確認。
5. 「あとで」→データ「人生のつづきへ」。Safari再読み込みでも保留が残り、選択済みイベントは再加点されないことを確認。
6. QA「交流を試す」は通常仲間6人を配置する。これは抽選を省いた試験状態で、実際の出会いや取得の証拠ではない。見送りと受け止める選択を試し、次は異なる相手になることを確認。
7. 通常ゲームでC/Bを取り、旅・景色・仲間の交流を遊ぶ。QA「記録を確認」で得点・選択・好みの内部記録を読める。直接こころを満点にする操作はない。
8. 同じ場所往復・同じゲーム短時間反復で好みが急変しないことを確認。複数の異なる経験で形成させる。
9. 別タブで開き、古いタブの選択が二重加点されないことを確認。画面ロック、バックグラウンド、復帰も試す。
10. 100歳の人生カード・保存コード・過去の子を確認。通常100本・クイック・恋愛・へんしん・おせわの使い勝手も試す。
