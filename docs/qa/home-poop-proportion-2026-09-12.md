# ホームのうんち・指輪表示再調整（2026-09-12）

対象は #251 マージ後の main `3dc322f400da4cd711cc384fa12a5aefb09be2a4`。
通常時のうんちが小さすぎるという指摘と、追加の「横並びにする」「指輪も少し大きくする」指定を反映。

## 変更

- うんちは実際に配置された主役フレームの表示倍率 `main.w / 104` に追従。以前の `Math.min(1, fieldScale)` を廃止し、1倍を超える通常表示でも拡大する。
- サイズは `max(8, min(24, round(12 * fieldScale)))`。縮小表示の比率と8pxの認識下限を保持。仲間数・うんちの個数・話者でサイズを直接分岐させない。
- 最新指定に合わせ、最大4個を横1列・間隔2pxで配置。通常の単独表示では4個90×21px、320×568・仲間26人では38×8px。最大でも102×24px。
- 主役の右下〜吹き出しの右上に4個分の領域を常に予約する。画面端から24px以上離し、うんちの下端は足元+4px、吹き出しは足元+6pxを保持。うんちのために吹き出しを下へ動かさない。
- 右側の仲間のしっぽが横1列と接触したため、しっぽの付け根を予約領域の手前へ制限した。半幅7px＋余白2pxを確保し、先端は引き続き実話者の方向を向く。本体の中央軸は話者によらず一定。
- 横幅を増やした分、必要な条件ではキャラと会話の軸を一緒に内側へ寄せる。出現・掃除・話者変更では再配置しない。以前と共通の実描画条件では、画像未読込の最小領域2条件を除き主役の表示倍率を保持。
- 描画270×152・全画像読込失敗でも26人／32人全員を表示。通常のカーブ、既存の浅いカーブの順に試し、それでも収まらない場合だけさらに浅くする。主役32px・仲間12pxの既存下限と動作時の余白は維持。
- フィールドの結婚指輪は13px固定から `clamp(13px,.4em,20px)` へ変更。実際に配置された恋人の文字サイズを継承し、通常時は大きく、混雑時は従来の13pxを下限にする。
