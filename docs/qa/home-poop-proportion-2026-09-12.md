# ホームのうんち表示サイズ再調整（2026-09-12）

対象は #251 マージ後の main `3dc322f400da4cd711cc384fa12a5aefb09be2a4`。
通常時も12pxで頭打ちになるため小さすぎる、という表示フィードバックへの追加修正。

## 変更

- 実際に配置された主役フレームの表示倍率 `main.w / 104` をそのまま使う。以前の `Math.min(1, fieldScale)` を廃止し、1倍を超える通常表示にも追従する。
- サイズは `max(8, min(24, round(12 * fieldScale)))`。1倍以下の比率と8pxの認識下限を保持し、大きな通常表示では拡大する。仲間数・うんちの個数・話者でサイズを直接分岐させない。
- 間隔2px、最大2列×2段。小画面では4個18×18px、通常の単独表示では4個44×44px。上限サイズでも50×50px以内。
- 描画サイズと予約領域を共通の計算にする。小さいフィールドでは既存の46×36pxを保持し、大きい表示では必要な分だけ上・右へ広げる。右側の余白も予約し、画面端から24px以上離す。
- うんちの下端は主役の足元+4px、吹き出しは足元+6px。会話の中央軸と距離を保持し、出現・掃除・話者変更で位置が跳ねない。

基準を16pxへ一律に増やす案は、背の低い魚と一部の恋人・装備があると置き場が右へ離れすぎるため採用しなかった。縮小表示の比率を保持し、通常時の上限制限を解く方法にした。
