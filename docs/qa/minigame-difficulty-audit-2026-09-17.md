# ミニゲーム 難易度・遊びやすさ 総点検（2026-09-17）

100本すべてを、実装コード・現在のパラメータ・iPhone想定の画面サイズ（`.device` 340px ＝ canvas 実効幅およそ292px）・操作方法まで確認した記録。

## 0. 判定のものさし

「難しい＝面白い」とは考えず、次の5点で見た。

1. **初見で何をすれば成功なのかが画面から分かるか**（ヒント文だけに頼っていないか）
2. **入力レンジのうち、成功する範囲がどれくらいあるか**（例：スワイプの強さ0〜1のうち何%が成功か）
3. **失敗がプレイヤーのミスか、ゲーム側の設定のせいか**
4. **iPhoneの片手操作で必要な精度が出るか**（1本指、親指の可動範囲）
5. **難しさに対して、成功時の見返り（点数・演出）が釣り合っているか**

測定には次の2つを使った。

- **ランダムプレイ計測**（`scratchpad/randplay.js`）：ランダムなタップ／スワイプで45秒プレイし、最終スコアを取る。
  「まぐれで取れる点」の下限がわかる。ここが**0や下限に張りつく＝どう触っても報われない**ゲーム。
- **入力レンジの数値解析**：弾道・摩擦を実装どおりに解いて、入力のうち何%が成功範囲かを出した。
