## 実機 QA の項目

### PR 2-1 クイックの判定と入力（#425）
1. stack: 開始してすぐ押すと失敗するか。何回か遊んで、揺れ始める位置と向きがばらけるか。
2. count: 正解が3つの選択肢の左・中・右のどこにも来るか。
3. catch: 🍂🪨🧸 などのデコイを押すと失敗になるか。仲間と重なったときに、見た目と判定が合っているか。
4. flames: 火が戻るろうそくが、左端だけでないか。
5. 指を押したまま次のゲームに移っても、スワイプ系（flee・swipe・throw・sort）が勝手に判定されないか。
6. mash→wait、tickle→button、clean→throw と続いたときに、触っていないのに失敗しないか。
7. 開始から 150ms の猶予で、押したのに反応しないと感じないか（特にスワイプ系）。

### PR 2-2 クイックの結果演出（#423）
1. shutter: 撮ったあとに、画面が真っ白のまま止まらないか。
2. cliff の落下、charge のジャンプ、stack の落下、sort の飛び去りが、結果表示（0.52秒）の間に見えるか。
3. 上部の ○/✕ バッジ（56px）と、薄い全面の色で、成功か失敗かが一瞬で分かるか。
4. 9文字の指示（「くすりをのませろ！」「あめがきたらかさ！」）が、1行で出るか。
5. テンポが前と変わらないか（20本のランの長さ）。

### PR 2-3 同系統3連続の回避（#420）
1. ランダムで遊んだときに、道を走るゲーム（ロードラン／うちゅうフライト3D／ハイウェイ3D）が3回続かないか。
2. 釣り（ほんかくさかなつり／地域の釣り）も同様に、3回続かないか。
- 確率で出るものなので、実機で再現しにくい。判定は自動テストで確かめてある。
