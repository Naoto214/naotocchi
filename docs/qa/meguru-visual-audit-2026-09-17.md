# めぐる 13地域の造形・構図 横断監査（2026-09-17）

PR #279 までで「空間の構造」（一本道でない地図・地域ごとの地形・巨大な囲い・前中遠景）はできたが、実機では canvas で描く巨大地形・建物・地面・小物の**造形の質**が追いつかず、「本当にその場所を歩いている」より「疑似3D用の図形で作った世界」に見える場面があった。添付された とかい／もり／うみ の実機写真から見つかった問題を、13地域すべてへ横展開して監査した記録。

撮り方: iPhone 相当 390×844（canvas 実効 338px 幅）で、各地域 **入口(A)／代表地点(B)／奥地かランドマーク(C)** の 3地点を同じカメラ条件で撮り、キャラクターを消さずに「場所として成立しているか」を見た。評価は小物の数ではなく、①巨大図形が地形／建物に見えるか ②素材を並べただけに見えないか ③主役が分かるか ④前景／中景／遠景が成立しているか ⑤地域内でも景色が変わるか ⑥キャラクターを消しても場所として成立するか。

## 0. 13地域に共通していた原因（実機写真から）

| 症状 | 原因 | 直し方 |
|---|---|---|
| 巨大な地形が「灰色の板／壁」に見える | 遠い造形物ほど **alpha を下げて半透明**にしていたため、重なった砂丘・崖・幹がガラスの板の束に見えた。輪郭が直線的で、面が単色、裾が地面と切れていた | 半透明をやめ、**色を霧の色へ寄せる空気遠近**に変更（`sh()` が距離で `curFogRgb` へ混色、色はキャッシュ）。地形は曲線の重なり＋明暗＋層の線＋裾の溶け込みで描く |
| 木が「黒い柱」 | 幹が直線の長方形、枝も根も樹皮の情報もなかった | 板根の広がり＋わずかに曲がる幹＋影側／光側の面＋樹皮の筋＋枝と葉のかたまり（近いものだけ）＋根元の苔 |
| ビルが「灰色の長方形＋格子」 | 単色の面に窓を1枚ずつ並べただけ | 本体＋道側の暗い面（箱に見える）＋パラペット＋給水タンク／アンテナ＋窓を**帯**で＋1階の入口・ひさし・灯り。商店街は低い店構え、路地裏は配管と非常階段の壁 |
| 地面が「記号の散布」 | 草の縦線・落ち葉の楕円を大量に撒いていた | 個数を約半分にし、**面としてまとまる層**（大きな苔・落ち葉のたまり・湿った地面）を追加。地面区画は4角ではなく不規則な丸みにして「板」に見せない |
| 素材イラストが主役になる | 🌊🧊⭐🌾🏔️ などの絵文字イラストを 230〜560 の大きさで目印に置いていた | `SPOT_PROP_STRUCT` で canvas 造形に置換（🌊は置かない＝海そのものが主役、🧊→氷柱、⭐→クリスタル、🌾→畑…）。両端の大物も 3つに2つは canvas 造形。群生の絵文字は小さく |
| 主役が多すぎる | 全地区で同じ囲い・同じ群生・同じ密度 | 地区（zone）ごとに **frame（囲いの種類）／frameScale／field（群生）／hero（主役1つ）** を持たせた |
| 倒木が横一列 | 向きが固定で、置き方も一様 | 倒木・流木・岩に角度を持たせ、倒木は2本重ねることがある |

## 2. 「今直す」と「3D化まで待つ」の分類

### A. Three.js 化しても残る世界設計（今回しっかり作った）
- **意味で読める世界**: `worldLayers(world)` が terrain / water / road / building / vegetation / landmark / obstacle / light / scenery に分けて返す。`STRUCT_ROLE`（造形物 → 役割）と `AREA_ROLE`（地面区画 → 役割）を持つ。canvas は色と形で描くが、3D はこの役割でメッシュを選べばよい
- **地区ごとの構図**: zone の `frame`／`frameScale`／`field`／`hero`。どこを歩いているかで囲うもの・生えているもの・主役が変わる
- **海岸線に沿う濡れ砂の帯**（`world.shore`）、水域（海・川・海溝・池）、道と広場、ランドマークの位置、地区の光と霧（`zone.mood`）
- **目印の置き方**: 素材のイラストを大きく置かない（`SPOT_PROP_STRUCT`）。両端の大物は造形物が主
- **自然物のゆらぎ**: 倒木・岩の角度と重なり
- **近すぎる巨大物の扱い**: 種類ごとの `NEAR_CUT`（ビルは画面の半分、崖は 0.55、砂丘は 0.7…で切る）。3D でもカメラのニアクリップに相当する設計判断

### B. canvas 疑似3D版だけの見た目（違和感がなくなる最低限にとどめた）
- 幹の樹皮の筋（3本）、ビルの窓の帯（最大9段）と桟（近い時だけ）、砂丘の砂紋（近い時だけ3本）、崖の層（3本）と割れ目（2本）
- 空気遠近の混色と色キャッシュ、遠くの造形物のシルエット LOD（`px < 26` は形1つ）
- これ以上（細密な樹皮・窓枠を何十本も・砂粒）は描かない。本物3D化で捨てる可能性が高い

### C. 3D化まで待つと決めたもの
- 木・建物・岩の**個別の質感**（法線や影の落ち方）— canvas では面の明暗までにとどめる
- **キャラクターと景色の画風の完全統一** — 住民のイラストは既存の 2D 素材の立て看板のまま。3D では看板の向き・影・接地で解決する
- **カメラの高さや向きで変わる遮蔽**（本物の奥行き）— 疑似3Dは並べ順と半透明で代用している
- 水面の反射・波の立体 — 今は帯と白い線

## 3. 完成ライン（疑似3D版をどこまで作れば 3D 化へ進んでよいか）

疑似3D版の到達点は「これが完成グラフィック」ではなく、次の 7 つが成立していること。

| 条件 | 状態 |
|---|---|
| 探索して楽しい（分岐・ループ・秘密・発見） | ✅ PR #279 までで成立 |
| 地域ごとに空間が全く違う | ✅ 13地域で地面・囲い・遠景・空気・密度が全部違う（テストで固定） |
| 地形が成立している（海岸線・川・海溝・砂丘・崖・浮島） | ✅ 今回、板に見えない造形になった |
| ランドマークがある | ✅ 13種すべて canvas で描く（🌳 に落ちる landmark はゼロ） |
| 住民が暮らしている | ✅ 図鑑の全員がどこかに住む（PR #277 の分離は維持、fauna／character 監査 0） |
| どこへ行こうか迷える | ✅ 地区ごとに主役が違う（hero＋frame＋field） |
| 3D化しても世界設計をそのまま使える | ✅ `worldLayers` と役割マップ。canvas 固有の情報に依存しない |

**判断**: 地形・道・建物配置・水域・ランドマーク・探索構造に残る問題はなく、疑似3D版はここで止めてよい。残るのは B と C の「画力」の問題で、それは本物3D化へ渡す。
