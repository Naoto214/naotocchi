# Home version 17 — 表示品質・主体識別

PR #426 / 本人限定試遊版。mainへのマージ、GitHub Pages本番公開は行わない。iPhone Safari実機QAは本人確認待ち。

## 原因と修正

V16はCanvasの文字幅に固定の話者・余白幅を足して背景幅を決めていた。実際の画像、正式名、gap、border、padding、フォントの描画幅との差が残り、「1行」と判定した後のDOMで末尾だけが折り返していた。丸文字フォントの字面が古い行高を超えるため、上下の切れと不要なスクロールバーも発生した。質問用CSSは話者を隠し、交流Reactionでは既存データのcompanion IDが表示処理へ渡されていなかった。

V17は実DOMを利用可能な全幅で一度組み、Rangeとclient/scroll寸法で判定する。実際の画像・名前・余白を残した本文幅で、読みやすいサイズ候補を順に試す。1行の場合だけ背景を実幅へ縮め、必要な長文だけ自然に折り返す。短い複数行と長い名前はbalanced wrapping、長文は欄内スクロール。画像load、ResizeObserver、fonts.ready/loadingdone、画面復帰で再計算する。文字列別の補正や台詞の書換えはない。

| 領域 | 本文サイズ | 高さ・背景 |
|---|---|---|
| 通知 | 1行17→16→15px、複数行15→14→13px | 外枠42px固定。短文は内容幅、長文は最大幅と欄内スクロール |
| 会話・返答・Reaction | 1行18→17→16px、複数行17→16→15→14px | 外枠76px固定。正式画像28px＋名前と本文を分離、背景最大72px |
| 質問・選択肢 | 14px、選択ボタン44px以上 | 同じ76px。短い2択は2列、3択以上は全文幅の1列・欄内スクロール |

重点7文は375/390/430pxで全て1行。320pxでも6文は1行。「ほこりにも引っ越してもらった」は正式名の占有幅を保ち17px・自然な2行とし、極小文字にしない。末尾1文字だけの行はない。通知「あくびの途中でねた」は17px、背景171pxで全幅を占有しない。

## 正式画像と主体

`renderLaneSpeaker`が既存のspeakerオブジェクトを受け、正式キャラクターマスター、既存のExpression resolverを使用する。主役、仲間、恋人・配偶者、順次掛け合い、質問、選択後の返答、交流Reaction、作者等の特別会話を対象とする。画像の代わりに絵文字や仮画像を作らない。

- Conversation v2は既存beat.role / visitorKeyからそのbeatの話者を取得。
- 交流質問・Reactionは同じexchange.companionを正本とする。質問者を無条件に返答者へコピーしない。
- Expression開始→正式画像と名前→本文→話者種別、の順で更新する。
- 次の実発言は直前のReactionを覆い隠さず、同じ欄を引き継ぐ。
- ホームでの選択後Reactionを匿名の上部通知へ重複表示しない。ホーム外の既存通知経路は維持。
- 年齢選択等のシステム結果やプレイヤー操作に架空の話者を付けない。
- 誕生日・重要イベント等の通知は42pxを維持し、キャラクター由来の場合は正式画像・名前を付ける。
