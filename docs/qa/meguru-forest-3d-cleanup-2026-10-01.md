基準: `main` `31edb95e`(Merge PR #362、experimental forest 3D)。branch `claude/naotocchi-forest-3d-cleanup`。
目的: 3D の せかいとして **意味・見た目・あたり・きょりの 表現を そろえる**。はでに する のでは ない。
visual language は **「せかいは 3D・キャラだけ 2D」**: 2D の まま で よいのは player・なかま・住人 だけ。けしきの 物は 3D の かたち に するか、3D では 出さない(「自然な 3D」→「かんたんな 3D」→「それでも 不自然なら 非表示」の じゅん)。意味の ちがう 物への 置きかえ は しない。

2D(フラグなし)は 1 つも かえて いない(props 1233・あたり 531 の まま。`objectType3d` と 3D の おきなおし は 3D モードだけ)。

## F. fade の 直し
- 棚卸し: レンダラーに「きょりで 透明に する」みちは もともと **ない**(透明の material は 水・あわ・しぶき・ぬれた 地面・まだら・かげ・光 と、すかしの ghost だけ)。実機で 見えた「とおざかると うすく なる」は **きり(fog)が 500 から はじまって いた** ため: 500 より さきの 木が 地平の いろに まざって、消えて いく ように 見えた
- 直し: きり は **1400 から**(far 3800 + 1400 × view)。遠近感は いろ(地平の いろへ)だけ。かたい 物の 透明度は きょりで かえない
- すかし(occlusion)は `pickOccluders` に 切りだし: カメラ → player の 線分に あたりの まる(+ キャラの はば)が かかる かたい 物 だけ、8 つ まで。線分から はずれたら その frame で もどる。きょり・むき では えらばない
- テスト 3d: あいだの 物だけ すける / よこ・とおい・うしろ は すけない / player が どいたら 0 / ソースに 透明の material が ゆるした もの いがいに ない / `opacity = …dist` が ない / fog.near = 1400

## H. performance hotspot(おがわのおく)
- 実機: avg 22.3 / p95 44 / p99 135 ms・60 ms 超 17 / 600 が 1 回。ほかの 場所は avg 16〜19 / p95 19〜28
- 調べ: headless で おがわのおく の まわりを 20 秒 あるく(main と cleanup)。3D の JS は **さいしょの 2.5 秒だけ** p95 25〜109 ms、その あとは 3〜6 ms。texture は ふえない(37〜45 で 一定)。corridor の 準備(predecode)は gate の そば だけで、おがわのおく では はしらない。住人の 絵の 読みこみ も ない
- 判断: **transient**(その 場所に 固有の 重さ では ない)。Three.js は material の shader を さいしょに えがく とき 組む(lazy compile)ので、新しい しゅるいの 物(水の Phong・ひかる かさ など)が はじめて 画面に 入った frame に つまずく。おがわのおく は 池・丸太・岩・キノコ・しだ が 一度に 入る 場所
- 直し(小さく・あたり と 見た目は 弱めない): 入る とき に `renderer.compile(scene, camera)` で shader を ぜんぶ 組む(入る 時間に よせる)。実機で おなじ 場所で また 出るか は 人の確認(§N)
