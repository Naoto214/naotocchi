  • F4 / F5 しらせ: ふつうの spot と 地区は toast なし。ランドマークは 左上の 名まえの 静かな 強調。ひみつ だけ toast。きろくは かわらない

  • F10 水: 川 = 1 本の 帯(岸つき)、海 / 湖 = 岸 → 浅瀬 → 水平線 の 1 まい、池 = でこぼこ + 深さ、しんかいの 谷。池の ならび 禁止
  • F7 / F8 / F11 Kit v2: 木(ほそる 幹 + かたまり 2〜4)・たてもの(入口 / まど / 屋根)・岩 / がけ・はし(いみ ごと)・遺跡・昆布(曲がった は)

実機 確認の 重点ルート(この じゅんに あるくと v2 の 契約を みじかく 確認できる)

  1. home → forest: corridor が 3D の まま つづく(切りかえ なし・player が 消えない)
  2. forest: 木の よこを 通る(すかし → もどる)・たき・木の かたまり
  3. city: ビルの いろ / 高さ / まど・電柱・看板(日本の まち らしさ は つぎの QA の 裁定)
  4. mountain / snow: がけの かた・落石・針葉樹・雪原の 起伏
  5. river_lake: 川が 1 本の 帯・湖が 1 まい・はし(丸太 / 石)
  6. sea: すなはま → ぬれた 砂 → 浅瀬 → 沖 → 水平線・岸の あわ
  7. deepsea: 昆布の は・サンゴ・谷・きりの いろ
  8. jungle: 密度 / 重さ(perf 表示)
  9. desert: 砂丘の 起伏・岩・遺跡(砂色)・オアシス
  10. star_stop / memory_lake: 星・きり・湖の 面
