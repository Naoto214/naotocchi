`relationship-life.js`はDOM/描画/save非依存。`meguru.js`は既存actorをresident/party間で移すだけで複製しない。交流探索は毎秒1回。Homeは既存render周期で訪問を更新し、非表示・活動中・メニュー・睡眠時は訪問を終了する。非表示時間の積算や復帰時のイベント連発はしない。

## 頻度と測定

共通の自発イベント間隔180〜360秒。開始直後は180秒静かにする。挨拶は直近600秒に最大2回、恋人の自発交流（恋人訪問を含む）は最大1回。誘いの初回は1200秒以降、以後1200〜2400秒以上。訪問の初回は300秒以降、以後300〜600秒以上。いずれも共通予算が優先されるため、各間隔は発生保証ではない。明示的なプレイヤー操作・終了通知はこの自発予算と別。

再現コマンド: `node tools/relationship-free-life-measure.cjs`。数値は[measurement.json](measurement.json)。

| 10分あたり | 常時候補ありの予算測定（100 seed × 60分） |
| --- | ---: |
| 通常の出会い/reunion | 1.085 |
| なかまの挨拶 | 0.532 |
| 恋人の自発交流 | 0.412 |
| 一時同行の誘い | 0.208 |

これは種別を順に試すコントローラー測定であり、実際の接近回数ではない。誘いは平均約48分に1回で、初期目安より控えめ。共有予算・他イベントとの競合による。

実空間測定: 全図鑑、home/forest各4 seed、各10分、10Hz、衝突を通す周回入力。交流は0〜2回/10分（計11回、平均1.375）。自動partyは全8ケース0体。20 world単位以上動いた住人はhomeで29〜30/38、forestで21/37。短時間のこの経路では恋人交流・誘いは観測なし。出会いを強制するテレポートは行わない。

CPU step p95は0.31〜0.66ms、p99は0.47〜2.10ms（実行ホスト）。描画・GPU・iPhone FPSではない。80 world単位内の一般住人を含む最大密度はhome7、forest2。関係による全員集合は解消したが、既存の広場の群集は残る。

## 3D表情Workへの共通契約

`meguruMod.socialSession.subscribe(listener)`で購読し、戻り値の関数で解除する。`script.js`内の`meguruMod`初期化後が統合点。外部レンダラーにはbridge経由で渡し、別のsessionを作らない。テストの独立simulationは明示的に同じsessionを注入できる。

イベントは浅いimmutable object: `{version:1,type,actorKey,at,context,regionId?,reason?}`。`at`は有効セッション秒、永続時刻ではない。`actorKey`は既存`companion:<id>`/`partner:<id>`等。HomeではregionIdなし。

| type | 意味 |
| --- | --- |
| reunion | 通常住人との近距離の短い出会い |
| greeting | なかまの挨拶 |
| visit | Homeへの訪問開始 |
| affection_interaction | 恋人の自発的な交流 |
| accompany_start | プレイヤーが選んだ同行開始。reasonはwalk/date/adventure |
| accompany_end | 同行終了。reasonはtime_elapsed/destination/player_choice/region_change/exit/relationship_changed等 |
| return_to_free_life | 同行解散または訪問終了。accompany_endと対で届く場合は演出を重複させない |

誘いは20秒の任意UI状態で、現在は表情イベントにしない。listenerは最大32、配送開始時のsnapshot、例外はゲーム進行から隔離する。表情Workの未導入・失敗時も生活は単体動作する。表情側でactorの存在・現在のregionを確認し、遅延演出を次地域へ持ち越さない。

Character 3D、`meguru-3d.mjs`、World renderer/environment、Expression/Motion内部の差分なし。`script.js`はHomeで渡す出席者と発話候補、`meguru.js`は関係住人・同行・任意UIが競合注意箇所。protected-source fixtureは変更を許可された`meguru.js`のhashのみ更新し、Character/Expressionのasset検証を維持した。save/schemaと関係値更新ロジックは変更しない。
