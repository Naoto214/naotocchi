## hungryの根拠

**本人左目（viewer-right）**の重点範囲は `[104,58,107,62)`。外側の輪郭に近く、本人右目（viewer-left）より横幅が狭い。上・下の暗部の間に灰褐色の明点 `(105,60)` = RGB `(88,73,59)` があり、単一の塗りつぶし線ではなく、縦方向の眼部として読める。白いハイライトはないが、左右で光の当たり方が異なる表現は許容できる。外周・まぶたとの分離は弱いのでAとはしない。

**本人右目（viewer-left）**は `[94,58,99,63)` 周辺で、白に近い1画素 `(97,60)` = RGB `(227,220,213)` と角張った暗部がある。下端の肌色の明るさ `(95,62)` を眼内ハイライトと自動的に同一視しない。両眼を完全対称にする必要はない。今回のBは顔全体での自然さに基づく監査意見であり、暗い画素の存在数による合格ではない。

## wantsPlayの根拠と問題領域

**本人左目（viewer-right）**の重点範囲は `[102,61,107,65)`。その外側の連続性を見るため `[100,57,108,66)` も座標図に掲載。

- `(103,61)`／`(104,61)` からy=62の暗部へつながり、黒目と上まぶたの境界が読み取りにくい。
- **y=63、x=102〜107付近**で暗部が横に連なって顔外周へ伸びる。黒目の外周として閉じたまとまりより、顔の輪郭・突起とつながった帯に見えやすい。すべてを黒目と断定はできないため、この帯を削る修正案はまだ作らない。
- `(102,64)` 側にも暗部が続き、下まぶた・頬の陰影との境界が曖昧。下側の金色の肌を白いハイライトとは数えない。
- 白に近い眼内ハイライトは確認できない。**白い点がないこと単独は欠陥ではない**が、輪郭の接続・暗部の一体化・本人右目（viewer-left）との開眼構造差が重なるため、自然な非対称として無条件に許容するのは難しい。

**本人右目（viewer-left）**は `[93,59,98,63)` 周辺。下側の暗部はやや詰まるが、上部の白に近い1画素 `(95,60)` = RGB `(242,230,212)` と肌色との境界により、開いた目としてのまとまりが本人左目（viewer-right）より明確。

今回のCは、本人左目（viewer-right）が単純に縦・横の寸法で小さいからではなく、**眼部と周辺構造の分離が不自然に弱い**ため。意図的な細め目／ウインクの可能性を画像だけから排除はできないが、制作意図として確認されていないため、それを理由に正常扱いしない。人間確認後に必要なら眼部限定の最小修正を検討する段階。
