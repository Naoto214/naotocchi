# VERSION 5 実到達検証計画

評価はモデルの理論境界ではなく、同じ初期状態からブラウザーのpointerdown/move/upを経由して到達した足元・本体alpha端・装着物込み端を使う。旧版A、V2 C、V4 D、V5 Eは同じ入力群。カメラ倍率・描画原点・ステージ矩形・開始足元の一致を確認する。新規試験とV5再生では旧版のポインター開始点も再利用する。共通比較セーブseedを使い、各試行で同一のnative位置へ復元する。

- 390×844、とかい夜、28体の全個体×上下左右。接触を切り分ける主表は対象1体だけをモデルに残し、28体時のカメラ・画像サイズを固定する。通常の単独人数画面とは明記して区別する。外周64 CSS px刻みと現在の足元に正対する入力を測る。
- 同じ28体配置を維持する密集試験では全個体×4方向へ正対する実ドラッグ。直接掴めない個体はQA fixtureで対象個体を選択してから、既存controllerが対応する空き地ドラッグを使う。この分岐は画面上の選択ボタン操作自体の検証ではない。いずれも動作受付・実停止を記録し、空き地もない場合は未測定と明示する。
- 320/375/430pxはヤドカリ・アザラシ・ゴリラを重点検証。装着あり/なし・大きな貝の段階差・上部通知/下76pxセリフを代表条件に含める。
- 13地域×4時間帯で背景ロード・地域切替・描画枠保護・通知下端とセリフ上端への非侵入・実ポインター操作。全装備×全進化×全地域×全配置の完全総当たりではない。
- 自律移動は4体/28体で、足元境界・新規接触・既存接触悪化を毎step確認。新領域への実訪問はV4 navigator.validとの差として数える。実訪問0件の条件は自律利用成功と扱わない。
- 装着変更、画面幅変更、地域切替後の再同期を検証。比較ページの横切れも独立に確認する。

各方向の最良値は有限の候補操作群の最良値で、数学的全域限界ではない。全候補の同一操作比較を保存し、旧版成功からの受付拒否・0.8 CSS pxを超える要求方向の後退を記録する。到達後の0.25px刻み直線延長プローブは局所制約であり、実行停止理由や迂回不可能の証明とは区別する。

実機Safari・指によるタッチ・動的ツールバー・実Safe Areaの検証は環境に応じて限界を明示する。Chromiumモバイル設定を実機検証と呼ばない。

初回受付と最終位置は分けて記録する。V5の再試行によって初回falseから実際に動く場合も、実移動として測定する。未選択でポインターを送れなかった試行は実ドラッグ回数から除外する。保存済み旧版試行の掴み位置が1px違うケースは入力差として集計し、厳密な同一操作比較から区別する。
