## 開発PCなしの1・5・27体fixture

既存の `meguru-qa.cjs` と同じdog04＋nativeなかま構成から、既存NTS1形式のコードを作りました。新しいsaveキーやschema変更はありません。コード復号と既存loaderでの段階・構成確認3/3はPASSですが、実機の表示数・性能はNOT_RUNです。[構成とSHA256](iphone-fixtures.json)。

1. 個人の育成データと分けたSafariのQA用プロファイルを使います。rawcdnの別commit URL同士は同じ保存領域を共有します。
2. [1体コード](iphone-native-1.txt)／[5体コード](iphone-native-5.txt)／[27体コード](iphone-native-27.txt)のいずれかの全文をコピーします。
3. 上記sourceのMeguru3Dを開き、プロフィールの「セーブのバックアップ」内「セーブコードをここに」へ貼り付けます。「よみこんでおきかえる」は既存の確認に従って2回押します。上書き対象はQAプロファイルの試験データです。
4. 再読込後、めぐる→森へ入り、perf表示の `c3d ... actors` が1／5／27か確認します。不一致ならPASSにせず、画面と値を記録します。ゲーム進行・カメラ・距離による変化も記録します。
5. 2D比較も同じコードから開始し、同じ場所・カメラ・時間条件で順番に確認します。個人セーブへ試験コードを入れないでください。
