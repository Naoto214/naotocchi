## 2. hungry：先に通常08・左右眼を監査

通常08の本人左眼はx102〜105、y59〜61付近の暗い線が外周x105へつながる。閉じ気味の眼なので、開眼したhungryへの白点や眼球形状のテンプレートにはしない。通常08にも左右の幅・形・光の非対称があるが、これだけでhungryの暗部のまとまりを正常と確定しない。

hungry本人左眼の重点は `[104,58,107,62)`、両眼の共通比較cropはCL `[100,56,110,66)`／CR `[90,56,100,66)`。以下は画素を観察した説明で、黒目・まぶたを画像だけから完全に意味分割したものではない。

|要素|本人左眼 CL（viewer-right）|本人右眼 CR（viewer-left）|
|---|---|---|
|白／明色画素|白に近い画素はなく、(105,60)=(88,73,59)の弱い灰褐色反射がある|(97,60)=(227,220,213)の白に近い画素がある|
|黒目に見える暗部|(104,59)=(32,10,2)、(105,59)=(16,4,0)、(105,61)=(22,4,0)等が反射の上下を囲む|x95〜98の暗部の中に明点があり、内部と周囲の分離が比較的読みやすい|
|上まぶたに見える部分|(104,58)=(12,7,4)から下の暗部へ続く。まぶたと黒目の境界は弱い|x97,y58の暗部と眼内の明点に高低差がある|
|外周との接続|外側x106の暗色画素、とくに(106,60)=(19,4,1)へ暗部がつながり、外周と眼部がまとまって見えやすい|眼の周囲に肌色を挟む部分が多く、CLほど顔の端と一体化しない|
|非対称|幅が小さく暗い。自然な遠近差でもあり得るが、内部構造の読みにくさは実在する|より広く明点が強い。これへの完全対称化は要求しない|

下まぶた／肌の明色 `(104,62)=(221,164,116)` や本人右眼下側の明色を、眼内白ハイライトへ自動的に数えない。原寸と拡大で、左眼は場所自体は分かるが暗部のまとまりとして読みやすいという懸念を確認した。以前の現状維持を再確定する結論にはしない。

## 3. hungry B：1案、2画素のRGB変更

監査結果を踏まえ、白点追加・移動や他表情の眼移植は選ばず、既存反射と内側遷移の明暗を調整した。今回は設計したRGB値であり、通常08の粒子色対応とは別の眼内調整である。

|座標|A RGB|B RGB|目的|
|---|---|---|---|
|(105,60)|(88,73,59)|(163,145,125)|既存の灰褐色反射を同位置で明瞭化。純白にはせず、右眼の白点より暗くする|
|(104,60)|(56,18,0)|(108,66,34)|内側の眼部と顔色の遷移を緩め、暗部の塊を少し分ける|

上まぶたの暗部、外周x106、下まぶた、本人右眼、口、頭部外形は変更していない。元の外周接続そのものを切り離した候補ではない。小さく暗い左眼と左右の非対称性は残る。wantsPlay／WP-CL1の眼・色・形はコピーしていない。

128pxではAより眼内の反射が読め、暗部が一枚の塊に見える度合いは弱まる。一方、眼の幅や外周接続は変わらず、全構造が明確になったとは主張しない。反射が明るすぎないか、hungryらしい自然さに寄与するかを人間確認に残す。

104／80pxでは各1画素差が残り、左眼内がやや明るくなる。改善は限定的で、原寸128pxほど構造を分けて読めない。64pxでは今回の最近傍縮小後A/B全画像が同一。64pxで差がないことを不採用理由にはしない。
