# なおとっち世界 正式地理 v1（D案「弓なりの大陸と、そのふところの湾」）＋ 世界地図 Phase 1

採用: **D案**。A / B / C は比較検討の履歴として **PR #298**（`docs/qa/meguru-world-geography-options-2026-09-19.md`）に残します。
正本コード: `meguru.js` の `WORLD_GEOGRAPHY`（この文書はその読み方と、採用前の最終整合監査の記録）。
前提とした監査: `docs/qa/meguru-world-audit-2026-09-19.md`（PR #296）。

**Phase 1 では region-local の世界を 1 つも変更していません。** 13地域の x / z / entry / zone / spot / path / collision / 住民AI / `travelToRegion()` は無変更です。

## 0. いちばん大事な区別 — 「地形」と「みち」は別もの

| | 正本の場所 | 意味 |
|---|---|---|
| **feature（地形）** | `WORLD_GEOGRAPHY.features` | 世界として連続しているもの。大河・山脈・湾・海岸線 |
| **connection（みち）** | `WORLD_GEOGRAPHY.connections` | プレイヤーが地域を行き来できる道 |

**大河は いなか と とかい を地形として貫きますが、プレイヤーの主要なみちは街道です。**
この 2 つを混ぜないことが、将来ストーリーや川沿い移動を足すときの土台になります（#39 / #40）。
同じく山脈も「やま region の背景」ではなく、ゆきぐに・やま・もりの山麓・さばくの雨陰にまたがる世界の feature です（#41）。

### 2-3. 大河（`great-river`）

```
やまのふもとのみずうみ ─ みずうみのほとり ─ かわのたき ─ かわぎし
   → かわぞいのみち・みずぐるま → たなだへ水を引く
   → おうちの西を回る → とかいのかわぞいのみち → かこう（すなはま）→ 湾
```
9 点、すべて y が単調に下る（下流へ下る）。点ごとに region を持ち、**その region を見つけていない間は描かない**ので、地域を見つけるたびに川が延びます（#25）。

### 2-4. 山脈（`spine`）

```
ゆきやま ─ とうげのきた ─ ちょうじょう ─ がんかいのみち ─ いしのもり／やまのすそ
```
弓なりに、北西のゆきぐにから北のやま、北東のもりへ。**弓の内がわ（南）が風上で濡れ、外がわ（北西）が雨陰で乾く**。

## 3. 世界地図 Phase 1

### 3-1. UI の階層（#16 / #17）

```
めぐる（探索）
  └ 🗺 ちず            ← 既存の地域地図（変更なし）
       └ 🌍 せかい      ← 新規。地域地図のボタン列に追加
            └ 地域を 2 回タップ → その地域の地域地図（読むだけ。ワープしない #32）
                 └ もどる → せかい → もどる → もとの地域地図 → もどる → 探索
```

「もどる」は 1 段ずつ戻り、いちばん上まで戻ったら閉じます。**ホームの 3×3 は増やしていません。既存の「たび」も地域選択も無変更です**（#33 / #48）。

### 3-2. 世界地図に出すもの / 出さないもの

| 出す | 出さない |
|---|---|
| 発見済み region の地形と名前 | **未発見 region（輪郭も名前も「？？？」も出さない）** |
| 大陸・山脈・大河・湾・海岸線 | **469 spot・652 path・118 zone**（地域地図の役目 #24 / #31） |
| 発見済みの主要接続 | **未発見の接続**（両端の地域を見つけていても出ない） |
| 発見済み tier1 landmark（小さな星） | 未発見 tier1・tier2・tier3 |
| たてじく（発見済みのときだけ上下の印） | **未発見の特殊層**（存在すら出さない #27） |
| いまいる地域（赤い輪） | **住民の位置・経路・密度**（#35 / #58） |
| | **きおくのみずうみ**（発見後も地上に貼らない #28） |

### 3-3. 発見のしかた（#19 / #21 / #22 / #23 / #46）

**region の発見と connection の発見は完全に別です。**

| | 条件 | 旧セーブ |
|---|---|---|
| **region** | `lifetime.regionsVisited` ∪ `specialRegionsVisited`（＋つねに `home`） | ✅ そのまま移行。訪問済みの地域が未発見に戻ることはない |
| **connection** | **両側の「入口 spot」を両方とも見つけている**ときだけ | ❌ 別軸。「その地域へ行ったことがある」だけでは 1 本も開かない |

入口 spot は 32 個すべて実在の非秘密 spot です（`stonelook「いわばのみはらし」`、`windnotch「かぜのきれめ」`、`caravan「キャラバンのテント」` など）。
つまり旧セーブでも、**実際にその 2 か所に立ったことがある接続だけ**が開きます。`travelToRegion()` には 1 行も触れていません（#34）。

### 3-4. 世界探索率（#29 / #30 / #48）

```
せかい % = 0.40 × (見つけた通常 region / 11)
         + 0.25 × (見つけた主要接続 / 15)
         + 0.20 × (見つけた tier1 landmark / 17)
         + 0.15 × (訪れた通常 zone / 103)
```

| 分母 | 値 | 秘密を含むか |
|---|---|---|
| 通常 region | **11**（`NORMAL_REGIONS`。しんかい込み、ほしぞら・きおくは除く） | 含まない |
| 主要接続 | **15**（通常 11 地域を結ぶものだけ） | 含まない |
| tier1 landmark | **17**（18 − ほしぞらの 1） | 含まない |
| 通常 zone | **103** | 含まない（103 zone すべてが非秘密 spot を持つことを実測） |

**せかい 100% は、秘密 107 個を 1 つも見つけず、ほしぞらにも きおくのみずうみにも行かずに達成できます。**
4 つの分母はすべて固定の定数なので、パーセントから残りの秘密の数を逆算できません（#30）。
ほしぞら / しんかい / きおく は別枠のフラグとして持っています（#49）。

### 3-5. セーブ

追加したのは **`lifetime.meguru.world = { regions: [], links: [] }` の id の集合 2 つだけ**です。座標は 1 つも保存しません（実測 800 バイト未満）。旧セーブには自動で空の入れ物が作られ、`regionsVisited` から組みなおされます。

### 3-6. 図上サイズ（#13 / #63 / #64）

- **一辺 = √(実面積 Mu²) + 2**、生活圏は下限 5.5。13地域すべてに同じ式（地域ごとに手で直すと、大きさから「ここは特別だ」と逆算されてしまう）
- 実面積は **(maxX − minX) × len**。halfW×2×len ではない（うみ 25.64 / きおく 10.64。halfW から出すと 40.0 / 14.0 になり、広すぎる）
- 図上の楕円の**細長さは、その地域の本当の world の細長さ**から（やま 0.44 は細い尾根、うみ 0.40 は岸の帯）
- さばく : おうち は実面積 **8.67 倍** → 図上 **1.77 倍**。おうちは点にならず、さばくは一番大きいまま
- **画面に描くときの引きのばし（display transform）は正式地理と分離**。たて長の画面でよこ長の世界が小さくならないよう、描画時だけ最大 1.35 倍たてに伸ばす。`mapX` / `mapY` は 1 ミリも動かない

## 5. 実画面で確認したこと

390×844 / 375×667 / 360×640 の 3 サイズ、探索の 7 段階（A おうちだけ → G ほぼ完成）で Chromium 実機確認。
JS エラー 0 件、下端のはみ出し 0px、ボタン（− / ＋ / 🌍 せかい / もどる）はすべて 40px 以上の高さで収まりました。
せかい % は A 5% → B 18% → C 44% → D 53% → E 78% → F 87% → G 100%。

自己監査（#73）で直したもの:

1. **もようが 1 つも描かれていなかった。** `hash()` は 32 ビットの整数を返すのに 0〜1 の乱数として使っていたため、もようが画面のはるか外に飛んでいた（正しくは `hrand()`）
2. **もようが地面と同じ色系で見えなかった。** すべてのもようにインクの縁を付け、塗りを濃くした
3. **やまに湖のもようが並んでいた。** `terrain` の判定順で `lake` が `mountain` より先にあったため。順を入れ替えて峰になった
4. **13個の丸に見えた。** 地域を一回り大きくし（`GEO_UNIT` 0.20 → 0.27）、土の下敷きを先に敷いて隣どうしが溶け合うようにした
5. **長い道が他の地域をまっすぐ貫いて見えた。** `long` の接続を弧で描くようにした
6. **たて長の画面で地図が小さかった。** 描画時だけの引きのばしを入れた（正式地理は無変更）
