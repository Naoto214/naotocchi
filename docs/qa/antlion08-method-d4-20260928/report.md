## 制作方式と保護範囲

D1から直接作成。D2/D3からの累積加工ではない。画像生成・顔移植・再描画なし。既存QA用の233画素maskを継承し、RGBだけ変更した。D1の40独立粒子成分168画素と外側の細い軌跡65画素が対象。翅との接点・帰属の曖昧な近傍画素は従来どおり保護。

通常基準08の8近傍連結成分を座標と拡大目視で確認。独立粒子116画素（成分2〜26のうち17を除く）と外側軌跡73画素（成分17）を別々の色参照とした。色だけで身体から抽出していない。参照maskは特定SHAの通常基準用であり、他画像へ一般化する分類器ではない。

各群をlinear-sRGB相対輝度で順序付けし、D1の明暗順位に対して通常基準の経験分位点にあるRGB三つ組を割り当てた。形のコピーや座標の移動はない。疲労用の明度・彩度係数はゼロ工程であり、通常基準の実測色以外の色を生成しない。D4がD1より暗く見えるのは参照元の色が異なるためで、通常基準より暗くする追加補正ではない。

## 定量比較

対象233画素すべてが、対応する通常基準の群に実在するRGBと完全一致する。参照パレットへの最近傍RGB距離・ΔE76はいずれも最大0。これは同じ色を使用した検証であり、異なる座標にある画像全体のpixel一致や視覚的一致を意味しない。

|---|---|---|---|---|
| 粒子 | 187.440 / 120.802 / 60.302 | 241.452 / 185.702 / 108.107 | 207.726 / 168.315 / 113.607 | 187.423 / 120.810 / 60.363 |
| 軌跡 | 200.151 / 131.356 / 65.315 | 242.015 / 187.831 / 107.277 | 208.231 / 169.908 / 113.092 | 200.046 / 131.338 / 65.385 |

| 群 | 平均L* 通常→D4 | 平均Lab座標間距離 | 相対輝度平均 通常→D4 |
|---|---|---|---|
| 粒子 | 56.613607 → 56.613757 | 0.028329 | 0.252775 → 0.252859 |
| 軌跡 | 60.765725 → 60.750462 | 0.064323 | 0.296318 → 0.296311 |

平均RGB差の絶対最大は0.104532（8bitの0〜255尺度）。サンプル数は通常116/73、D4は168/65で異なるため、色の出現頻度まで完全一致するわけではない。平均Lab座標間距離は画素ごとの対応ΔE平均ではない。独自の許容閾値で採否を決めていない。
