## 実装

主8px格子とV2の目的地補正・互換経路を保持しました。補助探索は背景固定4px格子で、接触・遮蔽を満たす到達可能な連結領域を探します。近いが到達不能な候補を避け、開始点付近の12候補が塞がっていても安全な接続先を探します。旧格子に候補がない細い通路も対象です。

既存経路がある場合、要求方向の両成分を後退させず、元入力へ近づく点だけを採用します。接触楕円、遮蔽、既存の3px間隔の線分確認、フレームごとの安全確認は緩めていません。自律移動とドラッグは共通処理です。V18縦画面だけに適用します。

追加地面へ進んだ位置は、安全な限り通常の再描画後も保持します。装着変更等で現在の描画範囲外になった場合は既存の安全処理に従います。画像・サイズ・カメラ・深度曲線・保存形式・通知・セリフ・UIは変更していません。
