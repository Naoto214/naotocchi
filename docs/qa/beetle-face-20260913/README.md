# カブトムシ・クワガタムシの顔と8段階の見直し

基準コミット: `dac247a518059f189d1360f3766bdd834fc8afff`

## 変更

成虫の頭と前胸が一続きに見え、顔が後ろ側に付いて見える問題を修正した。頭部・前胸・上翅を分け、カブトムシは頭角の付け根の左右、クワガタムシは大あごの付け根より上・後方の頭部に目を置く。口も同じ頭部の前面にまとめた。

追加の指摘「カブトムシの顔だけが身体から大きく曲がってこちらを見ている」と「目は両方見えた方が良い」に対応し、成虫5〜8を再修正した。小さめの頭を前胸に自然につなげ、頭・前胸・胴体をまとめて正面寄りの斜め向きにすることで両目を見せる。奥の目は遠近に合わせて少し細くし、頭だけを正面へ回さない。

| 段階 | カブトムシ | クワガタムシ |
|---|---|---|
| 1 | 小さな幼虫。頭を琥珀色の硬い頭部として描き分けた | 既存の小さな幼虫を保持 |
| 2 | 丸い節と明るい頭、体を弓なりに伸ばして動く幼虫 | 濃い大きな頭と小あご、体を低く横へ伸ばして動く幼虫 |
| 3 | まるまる幼虫。厚い体と閉じ目の笑顔を保持し頭部を整理 | 既存の大きな幼虫を保持 |
| 4 | さなぎ。頭角、頭、折り畳んだ脚・翅を描き分けた | さなぎ。顔の下から伸びる一対の大あごと脚を描き分けた |
| 5 | 羽化直後の淡い殻、独立した頭、細い脚 | 羽化直後の淡い殻、独立した頭、一対の大あご |
| 6 | 赤銅色、細身の体、大きな歩幅、両触角、開いた笑顔 | 赤褐色、細長い低い体、大きな歩幅と開いた大あご、1つの笑顔 |
| 7 | 濃い茶色、充実した体格、安定した姿勢 | 濃紺の硬い殻、長い大あご、充実した体格 |
| 8 | 落ち着いた茶色、穏やかな半眼、脚をたたんだ丸い休息姿、殻の摩耗 | 穏やかな半眼、脚をたたんだ低い休息姿、閉じ気味の大あご、殻の摩耗 |

全段階を見せて区別を強める追加要望に対応し、両種の2・6・8を再修正した。1〜3は丸まる姿・伸びて動く姿・太く育った姿、6〜8は細身の歩行・成熟した体格・脚をたたむ休息姿として、輪郭と姿勢でも見分けられるようにした。クワガタ6の二重に見えた口を1つに整理し、カブト6の両触角も見やすくした。

画像14枚を置換。画像パス、種族ID、段階名、年齢設定、セーブ形式は変更していない。新しい輪郭から `cast-bounds.js` を再生成し、そのHTML参照のキャッシュトークンを更新した。輪郭データの変更も14枚分だけ。

## 検証

- 16枚すべてを原画・128px・82px・42px、および明暗背景で目視確認。レビューで指摘したカブトムシ6/7の類似を、6の色・姿勢・表情の再修正で解消。
- 全16枚のPNGチャンクCRC・実復号・128×128 RGBA・8bit・二値透過・8px以上の余白を確認。新規14枚は不透明色63色以内、接地線y=119、背景処理色の残存なし。
- 対象外のキャラクター画像283枚は変更前後のSHA-256一致。クワガタ幼虫1・3も保持。
- `npm test`: smoke・dialogue・既存QAルートの確認に加え、Nodeテスト405件成功、失敗0。結果は `tests.log`。
- 両目が見える向きに追加修正した後、更新した輪郭データとキャッシュ参照を対象に `cast-layout-test.cjs` / `asset-versions-test.cjs` を再実行し14件成功、失敗0。結果は `alignment-tests.log`。
- 段階の区別を強めた最終6枚への差し替え後、同じ関連テストを再実行し14件成功、失敗0。結果は `distinct-stages-tests.log`。幼虫1→2→3で描画面積が増えることも確認し、伸びた2が1より小さく見える縮小結果を調整した。
- 既存runtime harnessを使い、2種×8段階のホームと図鑑詳細が対応する同一PNGを参照することを確認。結果は `runtime-assets.json`。代替DOMでの検証であり、ブラウザー描画の検証ではない。
- 独立レビューで顔の位置と段階差を確認。追加の頭の向き修正も含め、最終PNGのSHA-256は `asset-validation.json` に記録。
