# bento の配置シャッフル（PR 2-4 / #424）が新性格システムの成長に与える影響（2026-10-22）

- **対象**
  - `dragDecorate-bento`（ジャンルは puzzle）。
  - 新性格システム（#417）は、通常ゲームの結果を次の2つの基準で数える。
    - ランク C: 35点以上
    - ランク B: 55点以上
  - 数え方は2つある。
    - ジャンルごとの courage
    - ゲームごとの perseverance（B で次の段階に進む）
- **変えていないもの**: 点数式、ランクの閾値、成長量。
- この文書では、**推定値**と**実測値**を分けて書く。

## 1. 点数の仕組み（コードで確認した事実）

- 点数は `Math.round(見本どおりの数 / 4 × 100)`（games.js の `finish`）。
- 4つ目の具は、最後に残った1枠に必ず入る。そのため、4つ全部を置いた場合、見本どおりが「ちょうど3つ」になることはない。
  - 全部置いたときの点数は **0・25・50・100 の4通り**。
  - 75点は、時間切れで3つだけ置いた場合にだけ出る。
- 基準との関係
  - **C（35点以上）**: 見本どおりが2つ以上（50点以上）。
  - **B（55点以上）**: 全部置いた場合は **100点のときだけ**。
- 訂正: PR #424 の最初の説明では「B＝75点（3/4）」と書いていたが、誤りだった。

## 2. 実測値（ボットによる測定。実際のプレイヤーの数字ではない）

- 方法
  - `docs/qa/minigame-phase2-bento-measure.cjs` を使う。実際の games.js の bento を、テスト用の環境（tests/helpers/runtime-harness.cjs）で動かす。
  - 乱数の種を変えながら、2種類のボットで遊ばせた。
    - **見本を見ないボット**（以前の固定配置の場所に置く。位置を覚えて解いていた人の上限のモデル）
    - **見本を読むボット**（見本どおりに置く）
- 実行方法: リポジトリのルートで `node --max-old-space-size=4096 docs/qa/minigame-phase2-bento-measure.cjs 200 memorizer`。
  - 1回の実行で、テスト用の環境を数百個作る。そのため、回数が多いとメモリが足りなくなる。

| ボット | 版 | 回数 | 点数の分布 | C 到達率 | B 到達率 |
|---|---|---|---|---|---|
| 見本を見ない（以前の固定配置で置く） | main（修正前） | 120 | 100点 ×120 | 100% | 100% |
| 見本を見ない（以前の固定配置で置く） | PR 2-4 適用後 | 480 | 0点 188・25点 144・50点 127・100点 21 | 30.8% | 4.4% |
| 見本を読む | main（修正前） | 120 | 100点 ×120 | 100% | 100% |
| 見本を読む | PR 2-4 適用後 | 200 | 100点 ×200 | 100% | 100% |

- 理論値との照合
  - 見本を見ない場合の正解数は、4つの並べ替えでずれずに残る数（不動点）になる。
  - 確率は、0個 9/24、1個 8/24、2個 6/24、4個 1/24。
  - C は 7/24＝29.2%、B は 1/24＝4.2%。測定（30.8%・4.4%）とよく合う。
- **言えること**
  - 「見本を読めば必ず満点」は変わらない。
  - 「覚えた位置で置くだけ」の解き方は、C 到達率 100%→約29%、B 到達率 100%→約4% に落ちる。

## 3. 推定値（実際のプレイヤー。測定はしていない）

- 実際のプレイヤーは、2つのボットの間にいる。2.2秒の見本で、4つの具の位置をどれだけ覚えられるかによる。
- 推定（根拠は、ボットの両端の値と、短期記憶で4項目を2.2秒見るという条件だけ。**未測定**）
  - 慣れた人の B 到達率（＝100点の率）: 以前のほぼ100%から、**6〜9割程度**に下がる。
  - 慣れた人の C 到達率: 2つ合えば届くので、**9割以上を保つ**と見ている。
  - 初めて遊ぶ人: 以前から毎回、見本を読む必要があった。そのため**影響はほぼない**。
- 性格の成長への影響
  - **courage（ジャンル puzzle）**: C で付き、ほかの puzzle ゲームでも稼げる。影響は小さいと見ている。
  - **perseverance（bento）**: B で次の段階に進むので、bento で次の段階に進むのは以前より遅くなる見込み。
- **実際のプレイヤーの実測値はない。**
  - セーブは端末の中だけにあり、プレイの統計を集める仕組みはない。
  - 本人専用の試遊版で bento を10回ほど遊び、点数を記録すれば、本人1人分の実測値になる（docs/qa/minigame-phase2-trial-2026-10-22.md の QA 項目）。

## 4. 判断が要る点

- この変化は「覚えゲーを、見本を読むゲームに戻す」ためのもので、承認済みの PR 2-4 の意図どおり。
- B 到達率の低下が大きすぎると感じた場合は、点数式を変えずに調整できる。たとえば見本の表示時間（PREVIEW_MS 2200）を延ばす。
  - ただし、これは T 系の仕様判断（T5 難易度の決め方）に関わるので、今回は変えていない。
