## A. Zzzの正式方向と変更履歴

**正式素材は「小→中→大のZが右上へ並ぶ」構図。キャラ画像の標準向きと移動方向は別である。**

| 段階 | 確認箇所／コミット | 確認結果 |
|---|---|---|
| 原型 | `04dfe418` の `pet-expression.js` | Zの中心はおよそ(71,34)、(82,25)、(93.5,13.5)。右上へ並ぶSVG。 |
| Motion v2前／後 | `ebffaad9^`／`cc4dce9e` の `pet-expression.js` | 同じ構図。輪郭と内側の組で6path。PNGの睡眠顔とSVGのZは別。 |
| PR初期 | `74c3e066` | 本体の向き判定とSVG側の扱いは独立。 |
| v12 | `7fb7fd0a` | ラッパー全体の反転にZも巻き込まれた。 |
| v13 | `e42da308` | 正式画像側だけ反転する方式へ。文字の鏡像は解消したが頭部位置の対応が不足。 |
| v14 | `b53e7bd5` | `sleepAccentShift`で頭部側の位置を補正。 |
| v15 | `1fc96db7` と後続修正 | `placeActorEffects`で共通アンカー補正。Zのpathと浮遊の符号には移動方向`direction`を使用。 |
| v16 | `home-diorama.js` | Zのpathと浮遊の符号だけを本体画像の反転状態`facing`へ変更。 |

犬・猫などの標準イラストは**左向き**。`facingScale`は「標準左向き×移動左向き」で+1（未反転）になる。v15のworld directionを使った解釈では、その未反転画像にも左上のZを与えていた。v16は未反転の正式素材で元の右上構図を維持し、反転画像には左上構図を与える。したがって犬の場合は**見た目左向き→右上、見た目右向き→左上**。これは反転フラグを見た目の右向きと取り違えないための対応であり、本体の向き判定は変更していない。標準右向きの竜などにも同じ原則、正面素材は本体を反転しない既存判定に従う。

変更していないもの:

- v15の外側translate、成長段階別head offset、transform origin。
- 小さい最初のZのpath位置。後続Zだけxを0／−22／−45へ平行移動する。
- Zのpath形状、サイズ、順序、色、透明度、3.6秒ease-in-outの浮遊ループ。
- 病気、しょんぼり、喜びのエフェクト、および仲間・恋人の本体変換。

**履歴から確認できる「右上」は素材の構図である。** 元から粒子が一つずつ発生・消失していたとは確認できなかった。v15の時間方向の動きは全Zの3px上昇／帰還とopacity .8→1→.8のループ。v16もこれを維持する。連続フレームは睡眠開始、0/900/1800/2700/3600ms、起床による消失を記録し、存在しない粒子寿命を新設しない。

## B. 通知42px・会話76px

設計原則: **領域は固定し、内容に合わせて内部の表示だけを最適化する。**

ブラウザーの実フォントをcanvasで測定する。文字数だけで日本語／英語の幅を推定しない。画面幅・フォント読込・本文変更時に再計算し、内容を削らない。

| 内容 | 候補 | 幅と配置 |
|---|---|---|
| 通知 | 18px/1行 → 16px/2行 → 14px/2行 → 最小13px | 短文は実測幅+余白、長文は領域幅。42pxの中で最大40px、必要なら内部スクロール。 |
| 通常会話 | 20px/1行 → 17px/2行 → 最小14px | 正式話者画像30pxと名前を左、本文は残り。短文中央、長文左寄せ。最大72pxを76px内に配置。 |
| 質問／選択肢 | 14px、ボタン44px以上 | 2列を基本に全文折返し。質問と選択肢を含む欄内だけスクロール。 |

重要警告、通常数値増減の抑制、警告への復帰、通知の優先順位・重複抑制はv15の処理を継続。会話なしでは背景パネルを表示しない。長文は小さくし続けるのでなく、下限でスクロールさせる。

## C. 選択肢の統合

旧実装は`#speechChoices`と`.home-choice-popup`が会話欄の上へ出る配置。移動領域はv15で通知42px／会話76pxを恒常的に除外しており、今回追加の禁止領域を設ける必要はない。

- Conversation v2: 既存の質問／選択肢DOMを`#speechSlot.is-asking`内の通常フローへ。回答時の既存イベントと返答、Reactionをそのまま使う。
- 個性・仲間イベント: 同じ`#individualityDialog`を76px欄の子として移動。選択処理をコピーしない。退出時は元の親へ復元する。
- 重要なレビュー修正: `index.html`ではdialogが同期初回renderの後に解析されるため、初回に存在しなくても後続renderで取り込めるようにした。遅延DOMテストでRED→GREENを確認。
- 複数選択肢、長い質問、延期ボタンも欄内スクロール。カメラ、移動bounds、ホームの高さは変更しない。

`script.js`、会話データ、育成・恋愛・仲間・セーブの正式ルールには変更なし。
