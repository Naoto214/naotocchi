## 選定・分類結論

マスターrare順は dragon → phoenix → god → world_tree → ghost → star → plush → unknown。直前完成godの次にある既存正規系統として世界樹を選定する根拠がある。テストfallbackは選定根拠にしていない。

全8段階とも一つの芽／苗／木に一つの顔。複数顔・一群・別個体の新規対象なし。Aの単一身体原則に従うが、複数構成員同期を行う対象はない。B/Cに該当する顔付き個体は描かれておらず、新しい分類確認は不要と判断する。

成長文の「不思議な気配」「知らない足跡」「枝の間で声がする」は世界観上の気配を記すが、画像中に別生物がいることを確定しない。段階名「精霊の木」から周辺物に新しい顔を付けたり、生体へ変更したりしない。

## 制作・合成時に守る点

- 全て既存顔のみを編集対象とし、枝・樹冠・根・土・芽・発光物・輪・星の数と構造を維持する。
- 05〜07の発光物を元の明るさのまま残しても、別個体の「元気な表情」ではない。主顔の不調意味を損なわない範囲で元意匠を保持する。
- 原画の光は状態マークと別物。睡眠・不調時も元意匠を消す必要はない。新たな状態マークや汗をPNG内へ描き込まない。
- 05〜07の吊り光付近、08の輪付近は汗・マークとの視覚衝突に注意する。既存の配置規則を緩めず、新8段階だけ調整し合成確認する。
- 全状態を病気や枯死への樹木構造変更で表現しない。表情変更であり、葉落ち・折枝・発光物消失等の成長段階改変を行わない。

判定：元画像・成長資料に基づく通常制作へ進める。分類を理由とする追加ユーザー確認は不要。これは完成80枚の受理ではなく制作前の元画像レビューである。
