## 結論

- 復元した右下極小泡は既存定義どおり **B5**。通常の45画素を同じPNG座標へ復元している。10表情すべて、テンプレート照合の唯一の最良位置は移動(0,0)。個別に異なる座標へ貼ったという証拠はない。
- B5の青い核18画素は10/10で座標・形・RGBAが同一。通常45画素のRGBAは7/10で完全一致。strained／hungry／criticalは既存輪郭を保護した1画素のみ不一致。色・透明度を変えた別の泡を10個作ったものではない。
- ただし **身体に対する位置まで完全一致ではない**。身体輪郭自体が表情ごとに異なる。顔・泡を除いた整数平行移動registrationではB5中心差はx=-1〜0、y=0〜+1px。身体component bbox左上基準ではx=-2〜0、y=0px。両方式を併記し、片方だけを「真の身体位置」と断定しない。
- **既存B1〜B4も10/10で核の形・面積、輪郭／ハイライトに差がある。** 単なるcrop差や5泡全体の同じ移動では説明できず、B5だけを動かせば全体が揃うという結論にはならない。
- 補修前commitとの実PNG照合で、前回のB5補修が既存4泡・身体を変更していないことを10/10で確認。既存差はB5補修より前に存在する。元の生成過程で差が生じた具体的機序までは断定しない。
- 許容差は未設定。「1〜2pxだから合格」とはしていない。完全元形一致を要求するならB1〜B4を含む10枚が再判断対象。B5だけの修正枚数は基準点／接触部分の扱い次第で、現時点で確定しない。

## 2. 測定法と限界

全11画像が128×128。PNG自体のcrop・bounds・offsetを変更していない。各画像の実transparent boundsと本体component bboxはJSONに記録。

全55泡に同じ**青い核の検出**（alpha>16、R<90、G>40、B>G+20）を使用。既存IDのROIを継承し、B4だけ下端切れを防ぐため監査用窓を `[100,70,124,94)` に拡大してB5基準supportを除外した。これは測定窓の変更で、PNGのcrop変更ではない。白いハイライトと濃い輪郭は核には含まれない。

**核のbboxを泡全体のbboxと読み替えないこと。** 全泡alpha成分が独立していればその正確なbbox・中心・面積も別記。B2の8表情、B4の5表情は身体／B5と連結しているため、全輪郭の帰属をalphaだけで一意に分離できない。ここは全輪郭測定をnullとし、恣意的な切断線で数字を作らない。B5の全泡bboxは元の45画素supportを使う。3接触画素は別途明示。全体の色・ハイライト・輪郭は同じ窓の拡大とRGBA差も用いて比較した。

身体registrationは通常の身体輪郭を基準とし、全5ROIと顔領域x40〜90/y50〜86を除外した共通有効域でalphaシルエットのXORを最小化。±8pxの整数平行移動を全探索し、拡縮・回転・非剛体変形なし。最良解はすべて一意だが残差があるため、身体自体が完全な平行移動ではないことも記録。相対座標の主列は通常本体原点 `(8,14)` をregistrationで移送した原点から計算。補助列は各画像の最大本体component bbox左上から計算する。前者の相対差にはregistration推定の限界があり、後者の差には身体外縁形状の差が入る。

状態マーク・汗は別レイヤーであり本監査PNGに含まれず、位置比較対象外。資料にも重ねていない。RGBA比較は無補間の原寸で行う。近傍身体を含む窓全体の差を泡だけの差とは呼ばない。
