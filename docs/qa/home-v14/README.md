## 睡眠Zzz

v12では画像とZzzを含む親 `.character-visual` 全体を反転していた。v13は画像だけの反転に分離し文字を正常化したが、Zzzの横位置は未反転時のまま残った。画像の頭は反対側へ動くため、頭とZzzが離れた。

v14は画像だけを反転するv13の構造を維持する。既存の `pet-expression.js` が出力する成長段階別SVG translateから小さいZの中心を読み、画像boundsによる反転中心に対して**位置だけ**を対称移動する。固定ピクセルや犬専用の補正ではない。表情描画コード・画像・MARK_PLACEMENTは変更していない。

- アンカー `A=(71+既存translateX)/104×100%`
- 画像の反転中心 `O=(bounds.left+bounds.right)/256×100%`
- 通常方向: 補正0。鏡像方向: `2×(O−A)%` をaccentに加える。
- 縦位置、SVG形状、元の睡眠アニメーションは維持。画像の移動・縮尺と同じ親座標系で追従する。
- 静止中のsleep→wake→sleepで描画DOMだけが置換されても、位置キャッシュの早期returnより前に補正する。起床時はaccentが消え、補正0に戻る。

例: 大人のいぬ `dog/06` はbounds `[16,8,112,120]`、SVG `translate(-34 -19.5)`。小さいZの中心は35.5769%、反転中心50%。右向きではv12が64.4231%、v13が35.5769%、v14が64.4231%。左向きは35.5769%を維持。縦アンカーは不変。

[位置比較](images/sleep-comparison.jpg) / [左右の連続フレーム](images/sleep-sequence.jpg)

**画像の性質:** v12/v13の睡眠比較は、確認した旧CSSの反転方式を現在の同一シーンへ適用した再構成。過去のiPhone実機写真・旧版全体の起動写真ではない。v14は実際の修正後表示。v12再構成には睡眠中のCSS優先順位も反映した。会話・通知の修正前画像は保存していたv13のscript/CSSを使っている。

**役割の区別:** 正式な睡眠Zzzは既存の主役の表情機能。仲間・恋人には同じ睡眠状態が元々なく、rest/sit等の既存自由生活を維持した。3役割のadapterでaccentが存在する場合の置換・補正テストは通過しているが、「仲間・恋人が新しく眠りZzzを出す機能を実装・実機確認した」とはしない。新しい睡眠ルールは追加していない。

## 会話吹き出し

`width:max-content` と画面内最大幅を併用し、幅と高さの実測値で既存の話者追従位置を決める。55pxの仮の高さ下限を廃止。上下4px・左右7pxの余白、本文14px・行高1.4を採用。大きい文字設定は15px。本文3行までを表示し、それを超える内容は従来のスクロールで全文を保持する。話者のアイコン・名前を維持するため短文の外枠は約39px高。

| 390px画面の例 | 主役の幅×高さ | 本文 |
|---|---|---|
| Hey! | 約100×39px | 1行 |
| おやすみ。あしたからほんきだす | 約282×39px | 1行。狭い幅では自然に折り返す |
| 長い日本語 | 最大340×約67px | 3行。溢れる場合はスクロール |
| 英語の中長文 | 最大340×約47px | 2行。話者名・幅によって3行 |

恋人の短文は名前幅を含め約118×39px。短いセリフを340px幅へ引き伸ばさない。

13px・13.65px（+5%）・14.3px（+10%）を同じ英語文で比較した。14.3pxでは3行、14pxでは2行となるため、約7.7%増の14pxを採用した。実機での読みやすさの最終評価は本人確認待ち。

[修正前後の文章量比較](images/bubble-comparison.jpg) / [13px・5%増・10%増・採用14px](images/font-comparison.jpg)
