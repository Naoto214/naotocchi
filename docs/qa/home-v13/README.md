## 原因と修正

| 問題 | 確認した原因 | v13 |
|---|---|---|
| 仲間が上に並ぶ | `layoutTerrainCast`が最前列中央の席を主役へ優先割当。少人数の弧も主役より上側だった | 通常の初期配置を中央自然分散へ。中央付近の席を主役、近い席を恋人へ割当。人数が増えると前・中・奥へ展開 |
| 下の地面が使えない | モデルの下端は`height-54`。scene floorも同じ予約。固定うんち行と高さ55pxのspeech slotを常時確保していた | 体・装備の実寸を引いた下端`height-12`へ。speechは話者追従overlay、うんちは安全地面へ。一律に全員を下げていない |
| 水辺の活動帯 | 水面・道路・物体で画面中央と安全地形の中央が一致しない | 共通navigationによる安全判定・経路を保持。初期syncでは安全帯中央の候補を考慮し、既に動かした主役を毎回中央へ戻さない |
| Zzz逆向き | 正式画像とaccent SVGを含む`.character-visual`全体を`--diorama-facing`で鏡像化していた。v12のsleepボタン修正とは別経路 | 鏡像化は直下の正式画像／emoji fallbackだけ。SVG、文字、ハート、指輪、選択表示へ伝播させない。Motion v2は従来のwrapperを担当 |

カメラを下へずらす修正や、半円形の移動制限は追加していない。地面・障害物・水面・車道・画面外・実寸を含めた既存の安全判定を通す。主役・仲間・恋人は同じ移動領域を使い、体や装備寸法による端の余白だけが異なる。

## 操作・会話・うんち

- 主役が下端近くへ歩いて到着。[下側の活動](lower-area.jpg)。恋人もドラッグで下側へ移動し、表示矩形bottomが451.48→533.49pxへ変化。主役の地面タップも歩行状態へ移行。[操作](drag-and-ground.jpg)
- 主役・仲間・恋人を順にタップし、それぞれ`data-diorama-selected=true`を確認。手動操作後の猶予、自由生活再開、既存の恋人approach/together重みを保持。
- 吹き出しは話者のx/yと身長から位置・尻尾を計算。画面端でclampし、選択肢の実際の高さを収める。選択肢の追加・消去時にも再配置。[短画面会話](conversation-short.jpg)
- 仲間交流の結果statusも高さを持つ表示として保持。「言葉がなくても、気持ちよさが伝わった。」を高さ32.19pxで確認。[交流結果](exchange-result.jpg)。既存台詞・回答結果・頻度・抽選を変更していない。
- うんちは主役に近い安全地面の空き候補から配置し、キャラ占有を避ける。[28体とうんち](poop-28.jpg)。同数のDOMが再生成された場合も座標を再適用。掃除後0個を確認。[320×568の掃除・5＋4ボタン](short-controls-clean.jpg)
- うんちの座標は表示用だけで保存しない。個数・掃除効果・セーブ形式は変更なし。安全な候補が全くない場合は危険地形に偽配置せず非表示になる。今回の120条件では4個すべて配置できた。
