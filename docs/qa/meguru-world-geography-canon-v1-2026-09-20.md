## 借りているもの / 借りていないもの

この世界は長野県・愛知県・鳥取県・沖縄県・日本地図の**再現ではありません**。借りるのは
**山に挟まれた谷／大河／山里／分水界／別水系／大都市と湾／高山／雪山／砂丘／南国森林／源の湖**
という**地形の記憶**だけです。ゲーム内の名まえはすべて現状維持で、実在の地名・施設名は 1 つも出しません。
完成した地図は、輪郭も距離も海岸線も外縁も**なおとっち独自の形**です。

**Phase 1 では region-local の世界を 1 つも変更していません。** 13地域の x / z / entry / zone / spot / path / collision / 住民AI / `travelToRegion()` は無変更です（469 spot・652 path・118 zone・107 秘密をテストで固定）。

## 1. 世界の中心

**二つの大きな山地に はさまれた ほそながい たに。その たにに「おうち」がある。**

- **おうち**（飯田型）= たにの まちだが、**たにぞこではなく 段丘の うえ**。`home` に水の zone が 1 つもないという既存データが、そのまま「川が町を貫かない段丘の町」を表している
- **いなか**（阿智型）= おうちの **西〜南西へ 山に入った 山里**。たなだ・かじゅえん・しゅうらく・ちんじゅのもり。奥ほど標高が上がって霧が出る
- **かわ・みずうみ**（天竜川型）= 同じ たにの 水辺。おうち・いなか と合わせて **飯田型生活圏の三角**
- **ほしぞら** = いなかの **山の上**から入る上空層（`ふるいとりい` → 山道 → `ていりゅうじょ`）
- **とかい**（名古屋型）= **分水界の峠を越えた、別の流域**の大都市。おうちの隣町ではない
- **うみ** = とかい側が 湾・港、奥へ行くほど 岬・灯台・**外洋**
- **しんかい** = うみの **外洋がわの 下**
- **きおくのみずうみ** = 世界地図のどこにもない記憶層

**2 つの水系は別もの**: 天竜川型（やま → かわ・みずうみ → たに → 峡谷 → 南 → 太平洋）は **とかい・湾へ流れない**。庄内川型（分水界の反対側 → 山間部 → とかい → 港 → 湾）は **たにを通らない**。上流でつながっていません。

**人の道は川とは別**: おうち → いなか → 山間部 → 峠／分水界 → とかい。

## 3. 源の湖（諏訪湖型）と きおくのみずうみ

天竜川型水系の**いちばん上流**に、`source-lake「みなもとのみずうみ」` という **ふつうの世界地形 feature** があります。
`kind: 'lake'`、点の region は `river_lake` なので、**かわ・みずうみ を見つけると地図に出ます**。

**この湖そのものは きおくのみずうみ ではありません。**世界観としては

> 通常時は ただの 源の湖 → 霧・夜・記憶にまつわる条件がそろう → **地図に存在しない湖岸**が現れる → きおくのみずうみ

という入口です（条件の実装は Phase 2 以降）。
`memory_lake` は **`mapX` / `mapY` が `null`** のまま、世界地図に region として描かれず、
世界探索率の分母にも入りません。どの地形 feature も `memory_lake` を指しません。
**ナオト**は `{ region: 'memory_lake', spot: 'deep', secret: true, fixed: true }` のまま
＝「地図にない記憶の場所の奥へたどり着くと、そこにいる」という解釈です。

## 8. 2 つの水系

```
【天竜川型 tenryu】                     【庄内川型 shonai】
やまの源流域                             分水界のむこうがわ（とかい側の源流域）
   ↓                                        ↓
みなもとのみずうみ → かわ・みずうみ      山間部のぼんち
   ↓ かわのたき                             ↓
かわぎし（しもながれ）                    とかいの かわぞいのみち・まちのはし
   ↓                                        ↓
たにぞこ（おうちは段丘の上）              ふなつきば
   ↓ 峡谷                                   ↓
みなみへ                                  みなと → 湾
   ↓
うみの外洋がわ → 太平洋
```

- `tenryu` の通過順は **mountain → river_lake → home → sea**。**city を通りません**
- `shonai` の通過順は **countryside → city → sea**。**river_lake も home も通りません**
- 2 本の最も近い点どうしは **3.34 めもり**離れています（テストで 1.5 以上を固定）。**1 本の川が山の上で分かれているようには描きません**
- **みやこがわは いなかから流れ出しません。**図の上の始点は **分水界のとかい側**（-2.95 / -3.00）で、
  いなかの塗り（楕円 ×1.3）の外、分水界の稜線から 0.52 めもり向こうです。点の `region` は `countryside` のまま
  ＝「いなかの峠に立つと、反対側へ落ちていく水が見える」という**見つけかた**のアンカーであって、水源ではありません。
  これはテストで固定しています（おねの同じ高さでの x を比べて、始点が向こう側・いなかが手前側）

## 11. 世界地図 Phase 1（#299 から無変更の部分）

UI の階層（めぐる → 🗺 ちず → 🌍 せかい → 地域を選ぶ → その地域地図）、Fog of War、region 発見の移行、**connection 発見（両側の入口 spot を両方見つけたときだけ）**、秘密漏洩の防止、世界探索率、地域地図との役割分担は **#299 のまま**です。

### 世界探索率（**分母は 1 つも変わっていません**）

```
せかい % = 0.40 × (通常 region / 11) + 0.25 × (主要接続 / 15) + 0.20 × (tier1 / 17) + 0.15 × (通常 zone / 103)
```
D2 は削除 1（`city|home`）・新規 1（`home|river_lake`）・置換 1（`sea|star_stop` → `countryside|star_stop`、どちらも分母外）なので、**通常 11 地域を結ぶ地上リンクは 15 本のまま**です。秘密 107 個は分母に入りません。

### 図上サイズ

一辺 = √(実面積 Mu²) + 2、生活圏は下限 5.5。実面積は (maxX − minX) × len。楕円の細長さは本当の world の細長さから。**描画時のたて方向の引きのばし（最大 1.35 倍）は正式地理と分離**しており `mapX` / `mapY` は動きません。

## 11-B. 3D 化へ残す正本 — 地理データと描画都合の分離

将来 Three.js へ移すとき、この正本をそのまま元データとして使えるよう、
**地理（正本）と描画都合（表示）を混ぜていません。**

| 正本（`WORLD_GEOGRAPHY`） | 将来の使い道 | 描画都合（`drawWorldMap` / `worldMapLayout` 側だけ） |
|---|---|---|
| `regions[].mapX / mapY / layer / height / depth` | `regionOrigin`・LOD の並び | 楕円の大きさ `worldMapShape()`、たて方向の引きのばし（最大 1.35 倍） |
| `features[kind:'range'].points` | mountain mass・遠景山地 | 岩色の帯の太さ、みねの三角の大きさ |
| `features[kind:'river'].points` | river spline | 線の太さ・上流／下流の太さの変化 |
| `features[kind:'lake'].points` | 湖面ポリゴン | 塗りと ふちの色 |
| `features[kind:'divide'].points` | watershed | 点線とひげの記号 |
| `features[kind:'coast' / 'bay'].points` | coastline | 外洋へ ひろがる おびの本数 |
| `regions[].climate / terrain / belt`、`rim` | biome transition・世界の外縁 | もようの種類 |
| `connections[].long` | – | **図の上で弧を描くかどうかだけ**。距離も意味も変えません |

`mapX / mapY` は**ゲームの world 座標ではありません**。`regionOrigin` を入れるときに混同しないよう名前を分けてあります。
