## 実装

1. **主な候補格子を背景座標に固定。** 従来の `bounds.left/top` 起点から、背景の `(0,0)` を投影した固定起点に変更。画面境界は候補の切り取り範囲としてのみ使います。候補間隔は8 native px、距離は境界で切り詰める前の入力から計算します。
2. **過去の安全な到達点を保持。** 固定格子だけでは以前の候補が必ず残るとは限らないため、従来版の目的地・経路を互換候補として評価します。VERSION 1の候補も、従来版の要求方向成分を後退させない場合に保持。新しい候補が要求方向へ後退する場合は安全な互換候補を優先します。過去の境界起点格子は互換検証用であり、新しい探索格子の起点にはしません。
3. **通れる経路を候補選択だけで失わない。** 新しい最寄り点への経路が塞がっている場合に過去の安全な経路を試し、過去の格子が狭い通路を見落とす場合には新しい格子を試します。独立レビューで見つかったL字の狭い通路を、実際のナビゲーションによる回帰テストにしました。
4. **安全判定は維持。** 接触の楕円・余裕、背景ポリゴン、遮蔽、フレームごとの安全確認は緩めません。過去の到達点が現在の描画保護範囲外の場合は互換候補にしません。補助経路も現在の範囲内かつ同じ接触・遮蔽条件で確認します。
5. **適用はV18縦画面に限定。** それ以外のナビゲーションは従来動作を維持。既定モードの経路と目的地を変更前コードと比較するテストも追加しました。

画像・表示サイズ・深度スケール・カメラのフィット・背景52枚・通知・セリフ・操作UI・保存形式は変更していません。変更したJS/moduleのキャッシュ参照と公開用ハッシュを更新しています。

## 安全上、広げなかった部分

- **接触回避:** 前回の制約解除実験では接触を消すと左・上に大きく進みましたが、これは重なりを許した結果です。今回は接触半径を減らさず、経路探索の見落としを改善しました。4体の固定配置で左側が大幅に広がる変更ではありません。
- **アザラシの背景上端:** とかいの歩行ポリゴン上端は背景座標 `z=0.53`。上側には建物・植栽があり、全時間帯で自然な歩行面として使えることを確認できませんでした。背景画像やポリゴンを拡張せず、目的地補正による後退を直しています。
- **ヤドカリ下方向:** VERSION 1の追加余地を保持。さらに広げるには足元下の描画・揺れ余裕を削る必要があります。76pxセリフ領域と既存の余裕を維持し、追加拡張は行いませんでした。
- **過去位置が安全でない場合:** 装着物変更などで描画保護範囲外になった過去の点、他個体が塞いだ経路は復元しません。これは安全上の例外で、範囲外の旧候補を戻さない単体テストを追加しています。

## 検証

- 8条件、3版で **2514候補試行**。従来版で受付成功した **819件**の同一操作を比較し、VERSION 2の方向別後退の最大値は **0.000000px**。回帰判定の許容値は0.8 CSS px（既存の到着判定が0.5 native px）です。
- 同一開始配置、同一サイズ・カメラ倍率、他個体の位置を固定。Playwrightのポインター操作で実ハンドラーを通し、その後モデルを進めて実停止位置を測定。目的地への直接 `model.move()` だけで成功扱いにはしていません。
- 幅320/375/390/430、3/4/28体、装着あり／なし、ヤドカリ2段階。主6条件は48px間隔＋8px追加探索、320px・28体は48px間隔の追加検証。全組合せの総当たりや連続領域の完全探索ではありません。
- 320×568の固定4体配置ではアザラシが他個体に隠れ、従来版から直接選択できませんでした。この条件のアザラシ上は未測定として比較ページから除外しています。
- 実シーンの自律移動を1,200秒シミュレーションし、280回の移動、従来境界外への10,355フレームの訪問と個体別境界内での移動を確認。共有モデルの目的地・経路処理はドラッグと自律移動で共通です。
- 装着変更直後、画像遅延、リサイズ・回転、模擬Safe Area、地域切替、4体ドラッグのライフサイクル検証を実施。
- 回帰・境界・保存・地域・既存描画など109件成功（新規10件を含む）。アセット整合性9件、Pages20件成功。新規のVERSION 2単体テスト10件成功。
- 広めに実行した旧テストのうち、V22当時から全ファイル不変を求める検査と、SHA-256形式だけを要求する古いV18公開トークン検査は、変更前のPR #554でも失敗することを確認。今回の修正対象にせず記録しました。現在の正式なアセット整合性検査と保護対象ファイルの検査は成功。全リポジトリ `npm test` の全件成功を主張するものではありません。
- 独立レビュー指摘を修正し、格子が狭い通路を見落とす例と、到達不能な互換候補が新しい経路を隠す例をテスト化。

**実機iPhone／Safariは未検証です。** Chromiumモバイル設定と模擬Safe Areaでの検証です。仲間が動き続ける実ゲームの全配置で同じ最端へ到達することは保証しません。
