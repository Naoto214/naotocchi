# ホームの主役・仲間の左右バランス（2026-09-12）

対象: #252 マージ後の main `46e3fef340b20006340fbad24e432462891404c1`。
開始時の tree `62bce47a99072539700ef74bd98c4fdd2717dc20` とローカル全794ファイルを照合した。

## 原因と修正

以前は右下のうんち用領域を core の幅に含め、その外側へ仲間を配置していた。
そのため、うんちが出ていないときも右翼が遠ざかり、主役も左へ寄る条件があった。

- 主役の透明余白を除いた描画範囲の中心を、フィールドの中央に固定。
- 左右の仲間は、主役の描画範囲から各画像の内側の縁までの距離を揃える。PNGの枠の中心を機械的に反転するだけにはしない。
- 対になる仲間は同じ高さ・カーブ・列を使用。異なる画像幅は対ごとの大きい側で間隔を確保する。奇数人数の最後の1人も、既存の対の配置を片側だけ変えない。
- 恋人・装備・ハートの広い側に必要な余白を、左右へ等しく確保。うんち領域を仲間の横配置計算から除外した。
- 仲間の配置後、うんちを足元・吹き出し脇の安全な場所へ横一列で置く。そこに収まらない場合は吹き出し下に必要最小限の段を取り分け、左右を同じ条件で収める。画面全体の高さやステータス位置は伸ばさない。
- うんちは実際の主役フレーム倍率 `main.w / 104` に連動する従来の8〜24px、間隔2px、最大4個を維持。常に4枠分を計算し、出現・掃除・発言者変更でキャラや行が跳ねない。
- 吹き出しは主役中央・足元から6px。しっぽは、うんちが同じ高さにある場合だけ接触を避ける。吹き出し下のうんちが本人のしっぽを横へ引っ張らない。
- 最小画面の8人前後、および透明余白の異なる画像と読込失敗画像が混在する30〜32人で、従来の列数制限では画面が伸びる条件を再現。通常のカーブで収まらない場合のみ短い列を追加し、最小サイズを保持する。2行の列も内側へ曲がる配置とした。

保存データ・ゲーム進行・仲間の種類や人数・指輪のサイズ規則は変更していない。
