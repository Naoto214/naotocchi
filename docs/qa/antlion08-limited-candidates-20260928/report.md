## 1. 制作方法と原画像保持

built-in image_genを各1回、合計2回使用。プロンプトは[prompts.md](prompts.md)。生成出力は指定外にも描画差が出たため、全体を候補として採用しなかった。2つの生成原本は`/sources/`に制作履歴として隔離し、候補一覧や本番の参照先にしない。

### strained

生成出力の大きな悲しげな目や身体・粒子の変化は不採用。**下向きの小さな口の部分だけ**を取り出し、現在のstrainedの口周辺 `[100,63,105,66)`（5×3px）に限定して適用した。元の顔領域に実在するRGBへ対応づけ、画風から浮く色を持ち込まない。顔・頭部の拡大、64px向けの顔全体の大型化はしていない。

- 変更は口周辺の**15画素のRGBだけ**。alpha変更0。
- 目・眉・まぶたは既存strainedのまま。既存の狭い目元と下向きの口の最小限の組み合わせ。
- 口領域外は透明画素のRGBも含めRGBA完全一致。
- 身体・脚・翅・触角・腹部・全粒子・軌跡・位置・個数・色は完全保持。前回の脚監査結論は維持。
- 制作履歴のcrop座標・色対応方法・全15画素の前後RGBAは[pixel-audit.json](pixel-audit.json)。

### critical

生成出力にも顔や身体の変化があり、その画素は一切使用していない。原画像の独立した小粒について、拡大で大粒の脇・軌跡の周辺・下端を確認し、重なって見える副次的小片を選んで除いた。全体を機械的に均等間引きする方法ではない。

- 選んだ**18独立成分・30画素**だけ、alphaを255→0にした。RGB値は削除画素も含め全画素不変。
- 大きい粒を残し、隙間の微小点と一部の2〜5画素の小片を減らした。大粒の周り・中央下寄り・軌跡脇など複数箇所で選び、位置の移動・追加・均等配置はない。
- 削除量や「43以下」という上限から選んだものではない。拡大で選択した結果を測定したところ35成分になった。D4の35成分との一致は目標値ではない。
- 元の身体と接続した最大成分（身体・顔・脚・翅・触角・腹部・接続軌跡）は全画素一致。削除対象以外もRGBA完全一致。
- 軌跡の色・幅・位置は不変。通常基準08を共通粒子色とする方針を維持し、減光・低彩度化・疲労補正0。
- 削除ID・全座標・前後RGBAは[pixel-audit.json](pixel-audit.json)。選択は単一候補のための目視判断であり、他表情へ自動適用する汎用間引きルールではない。

## 2. strainedのサイズ別評価

今回の分類はマークなし本体で、A＝十分読める、B＝ニュアンスは読めるがマーク併用が望ましい、C＝誤読／弱さから再検討候補。前回と同じ定義。観察者QAであり、盲検の識別率試験ではない。

| サイズ | 現strained | 新候補 | 観察 |
|---|---|---|---|
| 128px | C | B | 下向きの口が確認でき、薄い笑顔から不快・気乗りしない方向へ改善。強い怒り・涙・病気色を足していない。ただし嫌悪と不満・つらさの厳密な区別までは保証しない |
| 104px | C | B | 笑顔の読みは弱まり、口を結んだ不快感が残る。顔だけで「力が入っている」と一意に読むほどの強調はない |
| 80px | C | B（弱め） | 下向きの暗い口が小さく残る。目元は既存のままで、微妙な感情差は銀マークで補う |
| 64px | C | B（暫定・要人間確認） | 変更差は小さい。口の暗部は残るが、128pxと同程度の改善とは主張しない。実端末で薄い笑顔の読みが残るなら再検討余地あり |

**128／104pxでは薄い笑顔の読みを弱める改善を確認したが、A相当の明瞭さや他状態との完全分離を達成したとは扱わない。** sick／weak／criticalの顔色・閉眼や、sulkyの強い内向きの目元は移植していない。それでも不満顔との意味の重なりは残るため、正式銀マークを併用する。

正式マーク付き比較は既存resolverの`normal + reaction:strained`、既存`accentFor`の銀波線、通常08の既存art offsetを使用。色・形・位置を変更していない。SVGではHTML用absolute配置規則だけを適用対象から除き、正式の描画規則とtransformで表示。汗なし。実Home動作検証ではない。[state-audit.json](state-audit.json)に4サイズ×2画像の記録。
