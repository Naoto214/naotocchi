## 今回の判断候補

- **顔の再検討候補はstrained。** 128／104pxでも、狭い目と口の組み合わせが薄い笑顔に読める余地がある。小表示だけの問題ではない。Cは再生成命令ではなく、人間確認用の抽出。
- **criticalは粒子密度だけを再検討候補とする。** 共通抽出で粒子状成分数53、画素量189は全11枚の最大。他10枚の最大に対しそれぞれ1.23倍・1.27倍。通常／D4との比較だけでなく、他候補との比較でも高い。局所最大密度・外側軌跡との比率は極端な外れとは言えず、「別エフェクト」「削減必須」までは断定しない。
- happy／wantsPlay／sleepingは128／104pxで意図した大きな感情が読め、80／64pxで差が弱まる。**小顔＋正式状態マークでの補完による許容候補**。tiredは128pxで疲れのニュアンスが比較的明瞭、104pxから睡眠寄りの曖昧さが増す。正式採用済みD4は保持。
- hungry／sick／weak／criticalは128pxでも細かな状態名はマーク依存だが、要求／不調／消耗のニュアンスは残るためB。名前を顔だけで一意識別できないことだけではCにしない。sulkyは128pxで不満の目元が読め、104px以下で弱まる。

## 1. 評価条件と定義

マーク・汗なしの本体を、128／104／80／64pxそれぞれで比較。通常基準を併置し、顔ROI `[85,51,112,72)` の8倍拡大は特徴の存在確認にのみ使った。拡大で分かる差を原寸の読みやすさと同一視しない。最近傍で表示、身体・顔の形や位置の補正なし。

- A：顔だけでも意図した状態が十分読める。
- B：ニュアンスは読めるが、状態マーク併用が望ましい。
- C：別状態への誤読または表情自体の弱さがあり、顔の再検討候補。

このCは前回の「マーク込みでも弱いC」と定義が違う。前回B×10と今回のCを、画像が変わった結果とは扱わない。また、混同の可能性が少しでもあれば全てCとする評価ではない。一般的なニュアンスが残るBと、嫌悪が笑顔に読める方向性の懸念があるCを区別する。

観察者による比較QAであり、ラベルを隠した識別率試験ではない。画面密度・ブラウザー補間・端末の自動縮小で見え方は変わる。実Home／実機の識別率は測っていない。

## 3. 共通の粒子・軌跡抽出方法

全11枚に同じ規則を適用。RGB・彩度・明度は抽出条件に使わず、元のRGBAを一切変えない。

1. 128×128画像のalpha>0を8近傍で連結成分化。
2. 最大成分を身体と身体につながる軌跡として除外。残る成分のうちxまたはy方向のspanが12px以上のものを細長い軌跡候補として除外。
3. 残る独立小成分を「粒子状成分」と呼ぶ。後方共通ROI `[8,59,62,118)`（54×59＝3186px²）と交わる成分数・ROI内画素数を集計。
4. 軌跡比率は、目視で全11枚の翼本体を含まない共通外側領域 `[8,95,35,118)`（27×23＝621px²）で、上記の身体接続成分または細長い成分の画素を軌跡の代理量とする。同領域の粒子画素数／軌跡画素数を比較する。
5. 局所密度は後方ROI内の全12×12窓の最大占有率。固定3×3分割の各占有率・最大窓座標もJSONに保存。

通常基準だけで独立している長い軌跡は、この共通ルールで除外される。個別の「通常だけ成分17を除外」という指定は使用しない。span閾値10／12／16pxで全11枚の結果が変わらないことも確認。

**限界：** 意味上の全粒子を完全分離した値ではない。身体・軌跡に接触した粒子は除外側へ入り、孤立した帰属不明の小点は粒子側へ入り得る。軌跡の比率も外側の一部の代理量であり、翼と融合した全軌跡の面積比とは呼ばない。[抽出可視化](extraction.svg)で桃＝粒子状成分、灰＝除外、青緑＝外側領域の軌跡代理量を表示。

全画像alphaは0／255なので、粒子の占有面積px²と粒子画素数は同じ値。外接矩形面積で水増ししない。外接矩形は別情報としてJSONに記録。

### criticalは他表情から外れているか

- 通常比：成分数2.79倍、粒子画素1.93倍。D4比：成分数1.51倍、画素1.40倍。
- 他10枚の中央値比：成分数1.77倍、画素1.67倍。他10枚の最大比：成分数1.23倍、画素1.27倍。全体に小粒が多い傾向を支持する。
- 記述的なTukey上側目安（他10枚のQ3＋1.5×IQR）は成分数46、画素185。criticalの53／189はともに超えるが、画素は目安を4px上回るだけ。独立した無作為標本ではなく10枚なので、統計的有意差や固定の合否基準にはしない。
- 局所最大は39／144pxで他画像の最大35／144pxを上回るが、同じ記述的目安39.75px内。外側の粒子／軌跡比0.486もD4の0.462に近く、軌跡が消えて粒子だけになった状態ではない。
- 同領域の見た目でも、大きい粒だけでなく粒の間や軌跡付近に細片が多い。128で密度差が見え、64でも散在感が一部残る。一方、煙状の面や別種の太い発光へ変わったとは判断しない。

**結論：単に自然な揺らぎとして変更不要と確定するより、criticalの「全体の粒子量」だけを再検討候補にする根拠がある。** ただし、全ての密度指標で明確な外れという結果ではない。粒子を何個／何画素減らすか、どの点を除くかは未決定。「criticalだから多い」という説明は採用しない。色は通常基準08を共通基準とする確定方針のまま。
