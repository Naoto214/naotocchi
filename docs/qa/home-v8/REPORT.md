## 公開前の停止理由

GitHub pushに対し自動承認レビューが「対象GitHub remoteと送信内容へのエンドユーザーの明示的承認を確認できない」として拒否した。別経路で再試行していない。ローカルcommit、検証記録、配信パッケージを先に整え、`Naoto214/naotocchi` の `experiment/home-art-25d-20261028`（Draft PR #462）への保存と既存本人限定Siteへのv8追加を具体的に確認する。mainマージ・本番公開は対象外。

## 検証上の注意

Cloud Chromeの制御タイムアウトはアプリの地形エラーと混同しない。停止した一括検証を合格として数えず、完了した個別レポートだけを集計した。未完走の8候補一括実行は成功扱いしない。v7 CIの物理タップ失敗も、v8の回転修正で解決済みとは主張しない。

旧配信ファイル34本に継承されていた空白圧縮差分は構文木一致を検証した上で元のbyte列へ戻した。今回の圧縮対象をv8のみへ限定し、version 7を維持する。容量整理は内容一致を確認した旧checkoutの追跡作業コピーをsparse化しただけで、元画像・未追跡ファイル・Git履歴を保持した。復元手順は`RESUME.md`に記載。
