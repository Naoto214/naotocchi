# UIとキャスト同期の統合記録

基準mainは `1c389070e0f5b81ed248b6df8afaecd793639e42`。PR #183、#203、#205、#206を含む現行実装から作業した。画像やキャラクター／世界マスターを巻き戻さず、今回の差分でも変更していない。

## 実装

- お世話を同寸の9ボタンに整理し、画面下に追従。図鑑・実績・ゲーム選択・世界・アイテム・デザインはメニューに集約。データ・通信は上に配置。
- 名前と獲得済みバッジをキャストの上へ、セリフを内容に応じた吹き出しに配置。おとろえを含む9ゲージは通常のホームに表示。
- 全キャストは一つの親要素で3.2秒周期、左右4pxに移動。相対位置を変えず、横に8pxずつの余白を確保。動きを減らす端末設定では静止。お世話の反応はセリフ・効果で残し、個別の回転／拡縮による身体の衝突を避ける。
- メイン104〜112 CSS px、恋人52〜56px、装備36pxを基準に、仲間を可変サイズの左右の弧に配置。現行26人と旧セーブの28人、未知画像の代替表示を保持。26を上限として保存データを切り捨てない。
- `cast-bounds.js` は既存PNG294点の透過境界と凸包のメタデータ。元画像を切り抜かず、全体を `object-fit:contain` で表示する。画像更新後は `python tools/generate-cast-bounds.py`（Pillow使用）でメタデータを更新する。読み込みに失敗した画像は全枠を使う安全な配置へ戻る。
- デートの誘いは恋人データ内に移動。報酬の選択・消費・デート／記念日の字幕・既存通信説明を保持。
- 世界はじかん・きせつ・てんきの5択ずつ。じかん／きせつの「げんざい」は端末時計を参照。現在地の取得は利用者の操作から始め、天気の取得完了が手動選択を上書きしない。
- 現在地は市区町村の読み仮名を優先。実在住所を新しいゲーム地域IDにせず、現在地を選ぶと既存のhome地域の表示に使用する。座標・住所はセーブに残さない。取得中に別メニューへ移っても、遅い応答で旅を実行しない。
- デザインは画面を先に選び、既存40色・40柄と解放条件を保持。初期色を承認案の淡いピンク／緑へ調整し、字体3種類・文字サイズ2種類を追加。
- おわかれ前の暗さ・彩度効果はホーム内容だけに適用し、同じ画面要素の子にある固定メニューはビューポート基準を維持する。完全リセットの確認中に Escape を押すと、その確認だけを閉じ、長押しタイマーと進捗を取り消してデータ画面へ戻る。
- 位置情報の拒否・失敗後は自動で再許可を求めず、利用者が再取得を選んだときだけ再試行する。取得成功後の15分更新は維持。睡眠中など実行できない旅では、現在地の市区町村表示を解除しない。
