## レビューで修正した再発経路

- 重要発言を出した後に、古い通常雑談の予約済み台詞が上書きする。
- 前置き付き質問で、タブ切替後に選択肢だけ残り質問文が消える。
- 横向きのpointerup後、別のRAFが無期限追従を6秒へ戻す。
- メニュー中に返答タイマーが終了し、復帰後に最後の吹き出しが消えない。
- 新しい育成状態に以前の質問が残り、その後の重要発言が待ち続ける。
