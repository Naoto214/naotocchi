# VERSION 17 — V16からの限定修正

基準: `9d261bd0f86af9e618aab77a049e20aca9b6013d`。既存のPR505軽量checkoutを再利用。Draft維持、main・本番Pagesは更新しない。

## 変更

- 前景マスクの基準を、実際に画面へ描いた背景の変換に一致させた。身体の反転・Motion v2の回転/伸縮/移動を逆変換してマスクだけを追従させる。正式画像・前景ポリゴン・身体の接地座標・モーション定義は不変更。
- 横向きの既存通知42pxを左上、既存コメント76pxを左下へ移す。表示の有無によらず、全表情の描画範囲と影を常時予約する。既存モデルに表示上のboundsフックだけを追加し、既存nearest/route/歩行処理へ渡す。地域の床定義や世界座標・保存形式は変更しない。
- 横の既存旅モーダルだけをvisualViewportの高さに合わせる。見出し/閉じるボタンを残し、theme-scrollだけを内部スクロール。開いたまま縦へ戻すと元の親・inline styleへ復帰。
- V16の縦UI/コメント位置、人数倍率、背景表示、暗転撤去・数字表示除去をV17にも継承。

**縦の追加拡張は上下0px。縦の余白・床・倍率を変更する修正は加えていない。** 床の有効点とモデルのbody-height上限は別だが、V16の投影では最大表情/モーションを含む描画が既に上下約3pxの安全余白まで達している。床に有効点があっても、同じ倍率・固定コメント位置を維持したまま世界範囲だけを広げると描画領域が通知/コメント側へ侵入する。13地域の床を一括拡張する対処はしない。

## 足元の検証範囲

V16は前景をnative artTransformで計算する一方、背景は全画面cover/横の高さfitで描画していた。またmask-positionは反転/回転を含む身体変換を逆算していなかった。V17では両方を修正した。単に全住民を上へずらす変更はない。

上記world座標で足元を観察し、40歳の姿・1/6/28体の通常歩行、rest、observe、turn、sit等と画面切替を確認。数学的回帰では正向き/左右反転/回転と非一様伸縮のいずれも前景頂点の画面位置が一致することを検証した。家具の前景ポリゴンは削除せず維持した。

提供された5枚の静止画は確認したが、画像には保存座標がないため、撮影瞬間の正確な世界座標は確定できない。上記は再現用の実測座標であり、撮影時の座標と同一だとは主張しない。物理iPhone Safariでの症状消失は本人確認待ち。
