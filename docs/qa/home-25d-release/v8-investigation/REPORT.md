## 確認した原因

### 固定76px枠と実際の吹き出しは別の位置にある

`home-production-layout.css`のV7追加部分は、`#speechSlot`の76pxを残し、子の`#homeCommentDock`だけを`position:fixed`へ移す。dockは`height:auto`、`flex-direction:column`、`max-height`は画面上方まで広がる。`home-production-touch.js`の`place()`が操作ボタンの4px上へ下端を合わせるため、本文が長くなるほど上端が中央へ移動する。

元の`#speechSlot`は`.screen-frame`内でスクロールする。`#homeEventSlot`も同じスクロール領域にある。さらに元のspeechSlotと固定ボタンの間には高さ86pxの`.home-meters`がある。つまり「上通知 / 中央世界 / 固定下コメント / 固定操作」の4領域になっていない。

### Chromium実測（V7、同じ長文、おうち28体）
