Recommended sequence after the evidence checkpoint: one house-yard-road coherence unit with actual entrance anchors and focused before/after images; then a shared stall silhouette unit; then a regional composition batch based on full-frame comparisons. The entrance issue is a source-grounded lead, not proof that all garden placements are wrong. Inspect and test candidate adjustments before adoption.

No product file changed in this audit. Do not call all V1–V9 complete, production ready, or Human QA approved.
