# ボタンのいろ「とうめい」

2026-09-11。ユーザー指示「ボタンの色に『とうめい』を増やして、良いなら実装」に対応。
基準mainは `8de40f77b1872db479e854162c4ded207eec7a18`（#239統合済み）。着手時のopen PRは旧#92のみ。

## 変更

- でざいん → ボタン → ボタンのいろに「とうめい」を追加。クラシックの隣に表示し、初めから選べる。
- 昼は白、夜・深海・星空は黒の無彩色の下地を不透明度18%（82%透過）で表示。文字・アイコンに透明度はかけず、既存の文字の縁取り、ボタンの輪郭、操作サイズを維持する。
- 押下・キーボードフォーカス時は32%の下地と輪郭を表示。ミニゲームの共通操作も選択に従い、長押し表示、選択枠、使用不可、正誤・終了確認の区別を維持する。
- メーターの色、HUDの透明度、お世話の危険表示は別の設定として維持。「とうめい」はメーターの選択肢には出さない。
- ピッカーでは無彩色の市松模様で透明を示す。世界背景に市松模様は表示しない。選んだ柄は独立して保存する。
- 保存v5の既存 `deviceThemeId` に `transparent` を保存。既存の選択や解禁条件を変更しない。収集表示は全80種から81種へ増える。
- 実行時変更は `script.js`、`design.css`、`world-scene.css` と `index.html` の読込トークン。
