# ホーム中央のタッチ固定

## 対象

- ユーザー動画（23:57）では、ヘッダーと下部操作が静止したまま、年齢・キャラクター・メーターが上下する。
- 前回の #244 は main `d0991e7335f3e3d0207dde8a899c176c847a0065` にマージ済み。公開ページの読込トークンと固定用属性を確認した。端末の録画だけから、その端末で読み込まれた版までは断定できない。
- 前回の検証は CSS による固定、scrollTop、ホイール。物理iPhoneの一本指操作と弾性スクロールは未検証だった。
- 今回は #245 を含む main `4534972c99551b4cbec43cede0d46b87d42ada91` を統合。取得した差分から復元した tree `54c605fb4be5cc5cf4be9da5c221a2478c2dba56` が GitHub と一致することを確認。

## 変更

- `home-touch.js` で固定ホームの一本指のドラッグを非passiveな touchmove ハンドラーで抑える。レイアウトや文字のサイズは変更しない。
- 長いお知らせとセリフは、文章が残っている向きへスクロールできる。端まで読んだ後の引っ張りがホームへ伝わるのを抑える。
- タップ開始はキャンセルしない。複数指の操作、拡大中の移動、メニュー・ミニゲーム・人生の記録は既存の操作を維持。
- CSSに常時パンを禁止する指定を置くと、拡大後の移動も妨げる可能性があるため、既存のCSS固定と状態に応じたイベント処理を組み合わせる。
- 他の修正と共通の `script.js` は今回変更しない。キャッシュトークンは更新する。

## 検証

- 変更前の全テスト303件成功。
- 一本指の上下移動、文章端での引っ張り、ホームに戻った後の固定の3テストが、追加処理のない状態で失敗することを確認。追加後は4件すべて成功。
- #245統合前の全テスト307件成功。最新main統合後の結果はPR本文に記録する。
- Home layoutに393×852・上59px/下34pxの模擬安全領域・mobile/touchモードを追加。
- Chromiumではネイティブのタッチ入力を上下に4往復方向へ送り、指を離す前も含めて年齢・メーター・中央scrollTop・ページscrollYを計測。長文にもタッチでスクロールする。
- Chromium/WebKitの両方で、実DOMに対するキャンセル可能なTouchEventを送り、年齢・キャスト・メーター・お世話ボタン起点のドラッグ抑制と複数指の許可を確認する。
- 既存の小画面、大文字、全バッジ、横画面、設定末尾・ミニゲーム・お別れへの到達性も検査する。
- ブラウザー検証の結果・画像はPRのHome layoutチェックで確認。物理iPhoneのSafari/PWAそのものでは未検証。
