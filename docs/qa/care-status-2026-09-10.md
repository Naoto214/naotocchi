## 実装した範囲

専用画像16種を一枚へまとめ、七つのお世話ボタン、状態通知、所持金、病気／睡眠の
バッジ、ごほうび、足元のうんちへ接続した。空の皿は次段階用。
既存キャラ画像・Canvas描画を保持し、顔のない卵の「あたためる」だけ既存の卵画像を使う。
[素材とサイズ確認](../art/care-icons-v1-2026-09-10.md)。

状態の判定は読み取り専用の `care-status.js`、表示と一時通知は `script.js`。
一時通知をセーブへ追加していない。危険度に応じて既存2行ナレーション領域の通知を選び、
原因と次のお世話を示す。対象ボタンに静止した「!」と枠を付け、本文へ読み上げを接続する。
キャスト配置計算・左右の弧・既存の字幕領域・ボタン寸法の定義は保持。
バッジは空のときも高さを予約する。通知の出入りで外側の高さを変更する実装は追加しない。

| 優先度 | 判定・表示 |
| --- | --- |
| 最優先 | 通常モードでdying、deathMeter≥80、健康0、または健康<20かつ低健康継続。継続中はタイマーで消さない |
| 警告 | 健康≤25、病気、空腹≤25、起床中の元気≤25。原因が残る間は優先表示 |
| 一時表示 | お世話／ミニゲーム報酬の増減を最大2項目。元の結果本文も全文保持 |
| 通常案内 | 機嫌≤25、うんち≥2、おとろえ≥70、睡眠中・睡眠回復完了 |
| 節目 | そだちの増減、成長の25%刻み、健康25超への回復、睡眠回復完了、おとろえ50以降の25刻み |

通常の自然減少では通知を増やさない。節目は危険や増減で領域が埋まっていても収集し、
最新の要約一つ（最大2項目）にまとめてから表示する。操作の案内は現状から再判定し、
保留する睡眠完了通知は過去の回復だけを伝える。長い結果本文と増減は同じ固定領域内で
スクロールできる。最適な折返し・読み取り時間は実画面の確認を残す。

薬は病気にだけ案内し、睡眠中にも使える既存仕様を反映。睡眠中の食事やじゃれは起床を
先に案内する。連続じゃれのペナルティ・低元気での遊び・命回復の各60以上の条件も参照。
健康回復を即時に約束しない。卵・死亡・100歳の別れに死亡警告を出さず、無限では
世話不足の案内だけを出す。ゲーム・メニュー・ムービー・人生記録を覆わない。
低状態へ移ったときの仕草は既存のキャスト反応を一度利用し、軽量・会話中・非表示時は
抑制する。動きを減らす設定でも文字・形・対象ボタンの印を残す。
