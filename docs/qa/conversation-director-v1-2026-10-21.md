## 3. 重要な発見: 現在の main では、こいびと・なかまが Home で放置会話をほぼ話せない

`tools/conversation-sim.cjs` の通常シナリオ(本番どおりの訪問)では、**Director の前後どちらでも訪問者の発話は 2 時間で 0 回**だった。Director 導入前の commit(`36cf2864`)で直接確かめた:

- 2 時間で訪問 17 回、訪問者が Home にいる時間 30%
- 訪問者の放置発話の試行 161 回(greeting 118・affection_interaction 43)が**すべて `socialSession.attempt` に拒否**

原因(relationship-life.js の POLICY): 訪問そのものが こいびとでは `affection_interaction` 枠(10 分に 1 回)を使い、次の出会いまで 180〜360 秒あく。訪問は 60〜180 秒で終わるので、訪問中に話す順番がほぼ来ない。

→ PARTNER_IDLE_LINES(50)・COMPANION_IDLE_LINES(47)・専用の放置台詞(こいびと 54・なかま 88)が、Home の放置では実質到達不能になっている(#382 以降)。Relationship lane の仕様なので**変更していない**。意図どおりか確認が必要(§6-1)。Director は訪問者が話せるようになったとき用に、常在 fixture(main の `setPresentCastFixture`)で検証してある。

## 5. 確認のみの項目(変更なし)

- ヤギ「じゃれたら次のぼろ！」→ **「じゃれたら次、のぼろ！」に読点を1つ足した(本文の語は不変)。** 原文を git でたどると、2026-09-10 の `55fe1c4c` で分かち書きを外す前は「じゃれたら 次 のぼろ！」(=次、登ろ)。意図的な言葉遊びではなく、空白の機械的な削除で「次のぼろ(ボロ)」と読める曖昧さが生じていた。同じ枠の台詞(「そこよりあっちの岩で遊ぼう!」「休憩場所、ちょっと高いけど来る?」)とも「登る」で整合。TEXT_STYLE.md「話題の切り替わりには読点」に従い、元の区切りを読点で戻した。
- 友達拒否メッセージ(COURT_FRIEND_REACTIONS): `${emoji} ${label}:${reaction}` で上部欄へ出る。9 行中 4 行が地の文(「恋愛の向きはあわなかったけど…」等)。TEXT_STYLE.md「発言の前に小さいキャラ画像と名前を付け、情景説明には付けない」はムービーの規則で、上部欄の書式規則は未定義。**整合は未解決として記録のみ**。
