- 通常 zone: **103**（変わらない）

## T. Three.js 移行との整合

| D2 の要素 | `regionOrigin + local` での 3D 配置 |
|---|---|
| 二つの山地に挟まれた谷 | 谷の regions（おうち・かわ）を同じ帯に並べ、両側の山地を地形メッシュに。**region-local 座標は動かない** |
| 分水界 | 2 つの流域の origin の高さを変えるだけ。歩行には影響しない |
| 2 水系 | feature の折れ線なので 3D でも 2 本のまま。**水が 1 本に見える誤解が起きない** |
| いなか → 山上 → ほしぞら | 高さの違う層への遷移。#299 と同じ「特殊 connection」の扱い |
| うみの湾 → 岬 → 外洋 | 1 region の中の連続なので、origin 1 つで足りる |
| しんかい | うみの外洋側の下。`layer: 'below'` のまま |
| きおくのみずうみ | 座標を持たないので 3D 配置の対象外。**Phase 5 でも例外のまま扱える** |

D の「湾の口に上下が重なる」より、**D2 の「山の上」と「海の下」が離れているほうが 3D では素直**です（同じ x/z に 3 層を重ねなくてよい）。
