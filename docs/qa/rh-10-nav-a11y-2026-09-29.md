## 2. §8.9: ④ずかん / ⑤PERFECT の おいわいを 保存

- 成立した とき `lifetime.pendingGrandGoal`(`dex` / `perfect`)に のこす。
- 見る まえに ページを 閉じても、次の 起動で もういちど 出る。
- 見おわったら(とじる / ♾️ へ)消す。
- 対応する クリアの 旗(`dexCleared` / `perfectCleared`)が ない pending は 出さずに 消す。
- 人生の おわり(life)は 保存しない(いままでどおり。audit で 判断が 要る 側)。

## 3. §8.4: 戻る(Android の 戻る・iOS の スワイプ・Escape)

- **`closeTopLayer()` を Escape と `popstate` で 共有する。** 上から 順に:
  1. けす 確認
  2. めぐるの 地図(地図だけ)
  3. ミニゲーム(**やめるかの 確認を 出すだけ**)
  4. デート・うそつきしょうぶ・なかまの さそい・へんしんの えらび・おいわい(**とじられない ので とどまる**)
  5. めぐる(出る)
  6. パネル(とじる)
  7. home(何も しない)
- **history の あつかい**
  - home 以外の 層に いる あいだだけ、history に entry を **1 つだけ** もつ。層の あいだの 移動では ふやさない。
  - UI で 閉じて home に もどったら、その entry を `history.back()` で けす。その popstate は むしする。
  - とじられない 場面・ミニゲームの 確認では、entry を もどして とどまる。
- ミニゲームの Escape は いままでどおり ミニゲームの keydown が うけもつ(確認の 出し入れ)。

## 4. §8.5: 通知の 優先度 — 優先度 0(critical)だけ

- 保存の 失敗・読みこみからの 復旧・複数タブ の おしらせは、ほかの おしらせに 上書き されず 8 秒 のこる。
- その あいだに 来た ふつうの おしらせは、最後の 1 つだけ あとで 出す。
- **決めて いない もの**(既定の 分類が 判断を 要する):
  - 優先度 1〜3 の queue(103 か所の 呼び出し側の 分類)
  - 雑談の 間隔(孵って 10 分 の 倍)

## 5. §8.6: アクセシビリティ

- **ダイアログ**
  - 23 の パネルに `role="dialog"`・`aria-modal="true"`・`aria-label` を つけた(見出しの 文字。見出しが ない ものは 用途の 名前)。
- **inert**
  - パネルが ひらいて いる あいだ、その 下に かくれた ホームの 画面(`#screenNormal`)を `inert` に する(Tab で 後ろに 行かない・読み上げで 読まない)。
  - 下の ボタンの 列と ヘッダーは パネルの きりかえ(`openExclusiveMenu`)に つかう ので inert に しない。
- **読み上げ**
  - `storyFlash` / `birthdayToast` に `role="status"` と `aria-live="polite"` を つけた(`#message` は いまの まま)。
- **reduced motion**
  - ミニゲームの 画面の ゆれ(当たった ときの `ctx.translate`、10 か所)を、`prefers-reduced-motion` では うごかさない。
  - 引数は かならず 計算する ので、`Math.random` の 並び(= ゲームの 乱数)は かわらない。
  - 照準の ゆれなど 遊びの 一部は 対象外。
  - games.js / quick.js に confetti は なかった。
- **決めて いない もの**(見た目・UX の 変更に なる):
  - 44 px 未満の 当たり判定
  - 空・雪 × 透過 72% の コントラスト
  - 再挑戦の ボタンの 3.6 秒
  - iOS の `touch-action` / callout
  - 320 px の toast の `nowrap`
