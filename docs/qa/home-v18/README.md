# Home v18 — CSSによる会話・通知レイアウト

基準は PR #426 `264e0a7`。mainマージ・GitHub Pages更新なし。正式採用は本人iPhone Safari QA完了後。

## 原因と変更

v17はRange/clientWidthの計測後に `white-space:pre` を固定し、JSで背景幅・文字サイズを確定していた。通知ではclientWidthが余白を含み、さらにcare iconの疑似要素floatはRangeに含まれない。実際のmedicine通知の最後の文字が表示領域を約6px越える失敗を追加テストで再現。遅れて文字幅が変わる条件では `いまのぼく、ちょっとできる子` の末尾が約26px越えた。これは再現した構造上の欠陥であり、本人Safariでの正確な発火条件を断定するものではない。

JSの幅計測・フォント縮小・nowrap固定・Mutation/Resize/フォント監視を撤去。CSSのmax-content + max-width + min-width:0 + border-boxで実際の画像/名前/余白を差し引き、本文を自然に折り返す。短文は内容幅、長文は利用可能幅と縦スクロール。pre-wrapを基本とし対応ブラウザでbalanceを使う。line-break:strictで小書き文字の行頭を避ける。日本語フォントは既存の同梱M PLUS Rounded 1cと既存fallbackを維持。文字サイズの自動拡大補正は会話・通知欄内で100%に固定し、ブラウザ拡大は維持。

会話・返答・Reactionは16px（旧短文最大18pxから約11%縮小）、通知15px（旧最大17pxから約12%縮小）。質問・選択肢14px、画像28px、名前11pxは維持。通知42px・会話76px、28体、3D背景、Expression、Motion、会話内容/条件/頻度、保存スキーマは維持。script.jsのゲームロジックは無変更。
