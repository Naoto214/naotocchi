## 2. non-region transition（いきなりワープしない）

どちらも `gate.ends[region].land` に**6 段階**の間の地形を持たせました。行きと帰りで逆順です。

### `mountain|river_lake` — 源流 → 渓谷 → 谷底 → 湖畔

```
やま側   とざんぐちの てまえ → いわだらけの かわら → こけの いわ → たきつぼ → ながれが ゆるむ → みずうみの きし
かわ側   みずうみの きし → ながれこむ さわ → たきつぼ → こけの いわ → いわだらけの かわら → やまの ふもと
```

**山から突然湖畔へ跳びません。**間の岩場・渓流・滝つぼ・湖岸は region ではなく
non-region geography として `land` に持ちます。

### `home|river_lake` — 町はずれ → 段丘の端 → 坂 → 河川敷

```
おうち側  いえなみの はずれ → だんきゅうの ふち → した から 水おと → さかみち → かわらの いしはら → かわぎしの ひろば
かわ側    かわぎしの ひろば → かわらの いしはら → さかみち → だんきゅうの ふち → きが 見えて くる → おおきなき
```

**`home` region の中に水域は 1 つも足していません。**川は feature (`tenryu`) として
region の外を通り、段丘・坂・河原は `land` の意味データです。
「木の横から突然川へ出る」形にはなっていません。

## 3. おおきなきの分かれみち

`home.bigtree` が Phase 3B-0 の基盤のはじめての使いてです。

| | `bearing` | `priority` |
|---|---|---|
| `home\|forest`（西へ・もり） | `{ x: -1, z: 1 }` | **0** |
| `home\|river_lake`（東へ・かわ） | `{ x: 1, z: 1 }` | 1 |

- **まっすぐ歩けば、今までどおり もり**へ出ます（`priority` の低いほうが既定）
- 西へ寄れば もり、東へ寄れば かわ
- テストでは `push` を -1 / -0.9 / -0.8 / -0.6 / -0.4 と +0.4 … +1 で振って、
  **一度も取りちがえない**ことを確認しています
