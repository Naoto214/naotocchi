### 1.1 監査で わかった 制約(どう直すかを決めた もの)

- **snow の `ground` は変えられない**: 世界地図の地域のいろ・地域地図(`mapPalette`)・corridor の端の いろ が `WORLDS.snow.ground` を読む。変えると見た目以外(地図)まで動く → `path` と 地面の もよう(`detail`)だけで直す。`path` は地図に使われていない。
- **memory_lake の 🌳 は差しかえられない**: 壁の 🌳 100 本は `solid`(当たり判定あり)。別の絵にすると collider の形が変わる → 数・位置・種類は そのままで、**描くときの透明度だけ**で霧に沈める。
- **star_stop の帯は DistantFeature の land_below**: 遠景データ(37 件・方角・種類)は触らない → `drawDistantBelow()` の **ぬりかた(グラデーション)だけ**を変える。`distantShown` の形も変えない。

| 項目 | before | after | ねらい |

数・大きさ・重み(`detail` の 2〜4 番目)は変えていない。いろ 3 つ だけ。

**画面(390×844、day)**

| 地点 | 彩度 | ほぼ白 | 低彩度(灰) |
|---|---|---|---|

### 2.2 memory_lake — 木を奥ほど霧に沈める(数は変えない)

`EMOJI_MIST`(地域ごとの表)と `emojiMistFactor(regionId, emoji, dz)` を追加し、絵文字の `fade` に かけるだけ。

- 対象: memory_lake の 🌳 / 🌿 だけ。🕯️(あかり)は沈めない。ほかの 12 地域は常に 1
- `dz ≤ 260` は そのまま(足もとの木は くっきり)→ `dz 1100` で 0.42 まで うすく → その先も 0.42(ゆうれい にしない)
- props・壁 100 本・solid・位置・種類・描く命令の数 は 1 つも変わらない

| ふたつめのともしび(day) | 6.4% | 3.9% |
| くちたさんばし(day) | 9.1% | 8.7% |

奥の木が霧に溶け、ランタンの あかり が主役として前に出る。river_lake(昼・明るい緑・🌳 そのまま)と並べたとき、「霧の夜の湖」と「明るい川と湖」で はっきり分かれる。上位3種の割合そのもの(63%)は目標にしていない(指示どおり)。

### 2.3 star_stop — 地平線の さかいめ を 雲の霞 に

`drawDistantBelow()`(land_below を描く所)だけを変えた。

- 地上のグラデーション: 地平線の 1 段目を 地上のいろ → **空のいちばん下のいろ(霞)**。地上のいろは 0.4 の所から(霞の向こうに うっすら見える)
- 霞の帯: 地平線の少し上(帯の高さの 0.35)から下(0.7)まで、空の下のいろで `0 → 1(地平線)→ 0.5 → 0`
- 描く命令: 1 フレーム +2(グラデーション 1 + fillRect 1)
- 変えていない: DistantFeature の件数・方角・種類・`distantShown` の形(`id/kind/layer/slot/alpha/y`)・Phase 4D の backdrop の yaw 追従・`lower` になるのは空の層(star_stop)だけ

**地平線付近(y 110〜170)の緑〜青緑 の占有**

| 地点 | before | after |
|---|---|---|
| はたけのあぜ(day) | 12.5% | 0.0% |
| つきのみち(day) | 14.5% | 0.0% |
| くものかいろう(day) | 1.9% | 0.0% |
| まちあいのひろば(day) | 0.0% | 0.0% |
| はたけのあぜ(evening / night) | 0.2% / 0.0% | 0.0% / 0.0% |

水平な青緑の帯と緑のすじ が消え、紫の空が雲の霞を通って足もとの雲の島へ つながる。地上は霞の下に暗く うっすら残る(ゴンドラで降りる先があることは わかる)。
