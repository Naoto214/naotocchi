## 1. やったこと

| | 中身 |
|---|---|
| **`buildWorldSteps`(generator)** | `buildWorld` の なかみを generator に した。`buildWorld` は それを さいごまで まわす だけ(いままでと 同じ)。くぎり(`yield`)は 段の さかい・大きな ループの なか・障害物(120 こ ごと)・住民(12 にん ごと)。**forest 246 / home 79 くぎり**。くぎりで とめても とめなくても できる world は **13 地域 すべて 1 バイトも かわらない**(md5 で くらべた)。らんすうは つかわない |
| **preload の じょうたい** | `idle → preparing → ready → committed`、もどったら `aborted`、こけたら `failed`(`CORRIDOR_PRELOAD_STATES`)。する ことは 純関数 `corridorPreloadAction(state, frac)` で きめる |
| **組む ばしょ** | 道の **70%** で 組みはじめ(`CORRIDOR_PRELOAD.start`)、**45%** より もどったら すてる(`dispose`)。1 frame に 組む のは **4 ms まで**(`budgetMs`)、こえたら つぎの frame |
| **正本** | 組んで いる あいだ・組みおえても `state.regionId`・セーブ・はっけん・ちずは **出発 地域の まま**。組んだ world は メモリ だけ。地域を かえるのは 着いた ときの 1 回(4E-2 と 同じ) |
| **着いた とき** | ready なら 組んだ world を そのまま つかう(`buildWorld` を よばない。4E-2 の handoff)。組みかけ なら のこりを その場で 組む。つかえない(`preloadValid`: 同じ 出口・同じ むき・道の おわり・じかんや てんきが 同じ)ときは すてて、4E-2 の 着き方(その場で 組む)。**移動 そのものは しっぱいさせない** |
| **こけた とき** | 台帳 / 組む とちゅう / 絵の したく が こけても 歩ける。その 旅では もう 組まない(1 旅 1 回)。着いた ときに 4E-2 の 着き方で 組む。つぎの 旅では また ためす |
| **絵の よみこみ** | ready で 着く がわの 絵(けしき・住民・なかま)を よみこみ はじめる(`prepareIllustrations`)。絵が 1 まい よみこまれる たびに 立て看板の したく(glyph)は ぜんぶ 作りなおしに なる ので、**したく(warm)は よみこみ おわり(か 1.5 秒)を まって から**、24 回に わけて(4E-2 は 8 回)。ならべかえ と したく用 renderer の 用意は それぞれ べつの frame |
| **暗転の したの 1 まい** | 組んで 絵の したくも すんで いれば、着いた frame で 暗転の したに 1 まい えがく のを やめる(さいしょに 見える え が もう おもく ない)。1 frame はやく あけはじめる。まにあわない ときは 4E-2 と 同じく えがく。**みじかい 暗転(あけ 0.12 秒)は のこす** |
| **しらべもの** | `corridorStats.preload`(starts / readies / aborts / fails / commits / fallbacks / invalid・さいごの 1 回・ログ 60 まで)。`corridor.preload` / `held`(組んだ ものを もって いるか)。ひとには 見せない・セーブ しない |
| **テスト だけ** | `start(el, { corridorFaults: { registry, build, warm, commit, slow } })` で わざと こけさせる / おそく する |
| `script.js` | `prepareIllustrations` が よみこみ おわりの Promise を かえす(いままでの よびかたは そのまま) |

`buildWorldSteps` と `obstacleOf` いがいの 4E-3 の コードは 4E-2 の 印(`// ====== Phase 4E-2 …`)の なかに あり、4E-2 を けすと いっしょに きえる。

## 2. じょうたい と じかん の ながれ

```
 s/L   0 ─────────── 0.45 ──────── 0.70 ─── ~0.78 ──────────────── 1.0
 出発 world   [ もつ(sim.world)────────────────────────────────────] → 着いたら はなす
 corridor     [ corridor world ─────────────────────────────────────] → 着いたら すてる
 着く world                       [preparing]─[ready: 絵の よみこみ → したく 24 回]─ commit
                                   4 ms/frame   (よみこみ おわりを まつ)             (buildWorld を よばない)
 もどる        0.45 より もどる → aborted(組んだ もの・組みかけ・台帳・したく を ぜんぶ はなす)
               また 0.70 を こえる → もういちど preparing(あそびが あるので 行ったり 来たりで くりかえさない)
 reload / もどる → aborted(セーブは 出発 地域。つぎは 出発 地域から)
```

| じょうたい | どう なる |
|---|---|
| idle | 70% を こえると preparing |
| preparing | 1 frame 4 ms ずつ 組む。おわれば ready。45% より もどれば aborted。こければ failed |
| ready | 絵の よみこみ → したく。45% より もどれば aborted。終端で commit |
| aborted | 組んだ ものを もたない。また 70% を こえれば preparing |
| failed | その 旅では なにも しない。終端で 4E-2 の 着き方 |
| committed | 着いた(組んだ world が いまの 地域に なった) |

## 3. 組みはじめる ばしょ(0.6 / 0.7 / 0.8 を くらべた)

| はじめ | 初回(はやさ 1) 余裕 | 2 かいめ(1.4 倍) 余裕 | 暗転 | 組んだ ものを もつ じかん | 引き返しの むだ |

## 6. 出発 world を いつ すてるか(A〜D を くらべた)

| 案 | いつ すてる | へる メモリ | 引き返した とき |
|---|---|---|---|
| A | corridor に 入って すぐ | forest 536 KB / home 104 KB | 出発 world を 組みなおす: forest **111〜128 ms**(CPU 4 倍・1 回で)/ home 12 ms |
| B | 25% | 同じ | 同じ |
| C | 組みはじめ(70%) | 同じ | 同じ(ただし 70% から もどる ことは すくない) |
| **D(採用)** | **着いた とき** | 0 | **組みなおさない**(いまの 4E-2 と 同じ) |

- へる のは さいだい 0.5 MB。そのかわり 引き返すと forest で 100 ms 級の 組みなおし(わけて 組んでも 12〜20 frame)が 出発 地域に もどる ところで おきる
- **D に した**: メモリの さは 小さく、引き返し・reload が いちばん かんたんで 安全。4E-4 で 10 本に ひろげて もっと 大きな 地域が 出て きたら、そのとき B / C を もういちど くらべる

## 9. 判定: **A. preload 採用**

- 着く まえの 組む frame: **100 ms 級 → 21〜33 ms**(CPU 4 倍)、ふだんの はやさ で 8 ms。見える つまずきは なくなった
- 着く 暗転: 中央値 292 → **233 ms**、250 いか 4 / 18 → **12 / 18**、さいだい 400 → 300 ms。目標(≤ 250 ms・できれば 200 前後)は 中央値で みたし、半分 いじょうが 200 ms。のこりは forest の 1 frame の ながさ
- さいしょに 見える 着く がわ の frame: 33〜72 → **6〜17 ms**
- 着く まえに ready: 18 / 18(初回・2 かいめ・1 / 8 / 27 にん)。余裕 1.4 秒 いじょう
- 歩く p95 は わるく ならない。メモリは +1 MB みまん
- 引き返し・reload・しっぱい は どれも 出発 地域の 正本の まま、移動は とまらない
