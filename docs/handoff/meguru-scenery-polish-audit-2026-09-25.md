## 4. 第1段階でやったこと

### 4.1 しくみ: `deco`(見た目だけの景色)

spot に `deco: [struct...]` を足せるようにした。置きかたは #319 の `view` と同じだが、

- **`spotDiscoveryLevel()` は `deco` を見ない。** → しらせ(L0 / L2 / L3)も探索率も 1 つも変わらない。
- `solid` にしない → `colliderOf()` は `null`。当たり判定を 1 つも増やさない。
- `mid` を付けない → 地図の目じるしにならない。

`view` の 4 か所(#319)は**もとの探索のまま**で、位置は main と 1 ミリも変わっていない(照合ずみ)。

### 4.3 アーチ primitive(いわのアーチ / ほねのアーチ)

**`drawStructure` に `arch` を 1 種類だけ足し、material(`variant`)で塗り分ける。** spot 固有・connection 固有の描画関数は作っていない。画像 asset も追加していない(Canvas primitive のみ)。

- deco の書き方: `deco: ['arch:rock']` / `deco: ['arch:bone']`(「かたち:material」)
- `STRUCT_ROLE.arch = 'terrain'` / `OCCLUDER_BOX.arch = [0.52, 1.0]`(自分の前に来たときにすける箱)/ 遠景のシルエット色 `TINY_COLOR.arch`
- 地形なので主役サイズを 1 まわり大きく(`DECO_LEAD_SIZE.arch = 400`。ほかの deco の主役は 300 のまま)
- けしきはいつもカメラを向く板なので、yaw が変わってもアーチの形のまま

| | rock(いわのアーチ) | bone(ほねのアーチ) |
|---|---|---|
| 形 | 左の岩塊は太く高く、右の脚は細く低い。上の橋は薄く少し垂れる。穴は中心からずれた不ぞろいな形(`fill('evenodd')` でくり抜く) | ろっこつのような 2 本が上で合わさる。奥にうすい一組(深さ)。右の骨は少し短い |
| 色 | 海辺の砂岩(手前の灰色の searock とも、明るい砂とも違う)。根元は波にぬれて暗く、上に草 | 乾いた白 〜 黄土。外側の影は砂より濃くしてシルエットを立てる |
| 気をつけたこと | **人の建てた門に見せない**。最初はなめらかな半円で、漁村の家の前に来ると「家の門」に見えたので作り直した | **こわくしない**。太く丸く、端は小さなふくらみで終わる。頭がい骨・血などは描かない |
| 周り | 海では根元に白い波(潮風のけはい) | 根元は砂にうまる。周りに飾りは足していない |

### 4.4 deco 主役の探し方(見えることを先に見る)

いわのアーチは、最初の置き方では**画面にまったく出なかった**。原因は 2 つあった:

1. **同時に描く数の上限(`cap`)で間引かれていた。** 上限を超えると `must` でない物を遠い順に削る。密な sea(1 画面 114 個)ではアーチが真っ先に消えていた(疎な desert では出ていた)。
   → deco の主役に `keep` を付け、**上限で削らない**。`hero` は付けない(付けるとカメラが目じるしへ振り向き、見た目だけの変更でなくなる)。
2. **到着の視線が大きな frame で埋まっていた。** いわのアーチの周りは細い道の両脇を solid な searock が、左を漁村の家(みなと地区の frame)が埋めている。候補を全方向に並べて実際に `project()` すると、ふつうの大きさ(300)ではどこに置いても 7 割以上が手前の物に隠れた。
   → deco の主役だけ、**着く人の視線がどれだけ大きな物にさえぎられるか**を連続値で数え、いちばんさえぎられない候補を選ぶ。候補も少し先(〜1.57r)まで探す。障害物は 1 つも動かさない。

`view`(#319)の 4 か所と deco の補助は**もとの探し方のまま**(main と位置が 1 ミリも変わらないことを照合)。

途中で試して捨てた案: 「来る道をまたいでアーチを立てる」。道の上だけは視線がさえぎられないが、近づくときも着いたときもアーチが自分に重なり、すけて半透明になってアーチに見えなかった。

## 5. 今回やらなかったこと(と、その理由)

| # | 場所 | なぜ見送ったか |
|---|---|---|
| H4 `たきのみはらし` | 滝をさえぎっているのは **`solid` な `bigtrunk`**。視線を空けるにはその木をどけるしかなく、**当たり判定の障害物が動く**。このタブは collision に触らないので**手を出さない**(`bigtrunk` も動かしていない)。→ 「視線を空ける」を collision ごと扱うかは別途判断 |
| (H5 / H6 は §4.3 で対応ずみ) | 汎用の `arch` primitive を 1 種類足して 2 か所を仕上げた |
| M1 star_stop の地平線 | 近景と遠景の継ぎ目はレンダラー側の話で、飾りの置きかたでは直らない |
| M3 / M4 の色 | 地域ぜんたいの色は `ground` / `backdrop` / zone の `tint` の話。13 地域を一度に触らない方針なので第2段階へ |
| L3 間引き | 減らす側は「どこを減らすか」の合意が要る。第3段階 |
