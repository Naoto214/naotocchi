## 1. 監査のやりかた

13 地域すべてを、**データ側**と**実画面**の両方で見た。

- データ側: `buildWorld()` が実際に置いた `world.props` を数える(日替わりでばらつくので `day / sunny / spring` に固定)。飾りの数・語彙のばらつき・道からいちばん近い飾りまでの距離・地面の彩度。
- 実画面: Chromium 390×844 で、**道を歩いて到着した視点**を再現して撮影(`renderer.project()` で「実際に描かれた数」も数える)。
  - みはらし系 18 か所
  - 13 地域の代表地点(出口ではない中央寄りの spot)

撮影: `test-results/polish-audit/`(`before-` / `mid-` / `hub-` / `corr-` / `arrive-` / `after-`)。

### 1.1 途中で直した測りまちがい(2 件)

**① corridor の入口を「出ていく向き」で見ていた。** 最初、`さばくのいりぐち` 9 個 / `ふもと` 15 個と出て「到着地点が空っぽ」と判定したが、これは**地域から出る向き**の画だった。corridor で着いた人はその逆を向いている。向きを直すと **desert 68 個 / mountain 136 個**で、空いていない。この 2 件は**対象から外した**(いったん入れた deco を取り消した)。

**② 「自前の飾りが無い＝弱い」ではない。** みはらし 33 か所のうち 18 か所は自前の飾りを持たないが、実画面で見ると `ひがしのみね` のように**遠景 + 地域の ambient だけで十分に成立**しているものが多い。判定を「**なまえが約束したものが画面にあるか**」に絞り直した。

## 4. 第1段階でやったこと

### 4.1 しくみ: `deco`(見た目だけの景色)

spot に `deco: [struct...]` を足せるようにした。置きかたは #319 の `view` と同じだが、

- **`spotDiscoveryLevel()` は `deco` を見ない。** → しらせ(L0 / L2 / L3)も探索率も 1 つも変わらない。
- `solid` にしない → `colliderOf()` は `null`。当たり判定を 1 つも増やさない。
- `mid` を付けない → 地図の目じるしにならない。

`view` の 4 か所(#319)は**もとの探索のまま**で、位置は main と 1 ミリも変わっていない(照合ずみ)。

### 4.2 直した 3 か所

| 場所 | 主役(300) | 補助(180) | ねらい | 描かれる物 |
|---|---|---|---|---|
| `star_stop.starfall`「ほしのおちるところ」 | `crystalgarden` | `crystal` ×2 | 落ちた星のかけらが地面から生えている | **4 → 7 個** |
| `snow.slopetop`「げれんでのうえ」 | `snowfence` | `oldpost` | ゲレンデの柵とポール。白に茶色を入れる | **28 → 31 個** |
| `snow.peak`「ゆきやま」 | `firewood` | `log` | 到着地点に薪と丸太の茶色。landmark の峰は主役のまま | **13 → 15 個** |

いずれも既存の scenery vocabulary のみ。新しい画像 asset も新しい Canvas primitive も足していない。
どれもその地域の ambient(`clutter` の `frame` / `fore` / `edge`)とは別の struct を選んでいる。

**空白は埋めていない。** 3 か所とも足したのは 2〜3 個だけで、周りの空きはそのまま残している。

## 5. 今回やらなかったこと(と、その理由)

| # | 場所 | なぜ見送ったか |
|---|---|---|
| H4 `たきのみはらし` | 滝をさえぎっているのは **`solid` な `bigtrunk`**。視線を空けるにはその木をどけるしかなく、**当たり判定の障害物が動く**。このタブは collision に触らないので手を出さない。→ 次段階で「視線を空ける」を collision ごと扱うか、判断が要る |
| H5 `いわのアーチ` / H6 `ほねのアーチ` | アーチを描く struct が**存在しない**(`ruingate` / `woodbridge` / `ropebridge` / `lightbridge` のみ)。既存語彙だけでは名前を満たせない。**新しい Canvas primitive を 1 つ足すか**の判断が要る(画像 asset ではなく `drawStructure` の case 1 つ。2 か所に効く) |
| M1 star_stop の地平線 | 近景と遠景の継ぎ目はレンダラー側の話で、飾りの置きかたでは直らない |
| M3 / M4 の色 | 地域ぜんたいの色は `ground` / `backdrop` / zone の `tint` の話。13 地域を一度に触らない方針なので第2段階へ |
| L3 間引き | 減らす側は「どこを減らすか」の合意が要る。第3段階 |
