## 種族とゲスト

|種族|初期の個性|今回|将来|

正式データ正本：`character-world-master.v1.js` の companions / partners と `assets/characters/companions/`、`partners/`。ふくろうは「ものしり」、タコさんは「8本腕の世話焼き」を尊重。タコさんを凶悪な深海モンスターとして追加しない。

なかま/こいびと：数字なし・合体分裂なし・本編の獲得状況を参照しない固定ゲスト。通常は占有マスとして通行不可。今回Eの2体は案内/仕掛け主の非操作出演。救出対象・操作可能な協力ゲスト・対スイッチは設計のみ。将来の操作ゲストはmain actorsと別ID領域/goal集合を持ち、move-onlyのcommandを使う。本人の本編の恋人との恋愛関係を強制しない。

ボス：HPなし、消失なし。盤面の周辺セルを2〜4マス程度使い、仕掛けの予告と発動を示す。最終目標は通常actor全員脱出。大きなボス絵で通路や数字を覆わない。Eでは通常ゲスト大のタコさんで比較し、大型ボス絵は未実装。

## 100面へ広げる順序

1. A/B/Cの本人操作QA → 入力・視認性を修正。
2. D/Eの楽しさ評価 → 1つの発想で解ける面を各3面程度追加。
3. 章ごとに「導入2・応用3・組合せ3・試練1・余韻1」の10枠を埋める。
4. 直近3面で主解法が重複しないこと、同時に初登場する仕掛けは1種、時間あり面を3連続させないことを検査。
5. 水流・泡・風・氷・ワープは候補。既存の爽快感を実機で確認してから追加。
