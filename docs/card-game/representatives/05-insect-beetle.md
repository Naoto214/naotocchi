# むし代表テスト — カブトムシ

状態: **①〜⑧第一周＋横断監査済み。数値・具体効果は未確定。**

設計軸: **かわる**。うみの「状態・関係を流動させる」と違い、むしは **今どの段階にいるか／どこを通るか／どこを飛ばすか／どこに留まるか** 自体を戦術にする。

仮数値曲線: `2/2 → 3/2 → 5/3 → 1/4 → 5/3 → 8/4 → 10/4 → 6/6`

連作: `①ためこむ → ②育つ → ③留まるか変わるか → ④止まって変わる → ⑤生まれ変わる → ⑥飛び立つ → ⑦最強のとき → ⑧強さを手放す`

## ときとばしとの関係
- ③5/3→④1/4は明確な一時弱体化。
- 現行ルールでは③→⑤=時2、③→⑥=時3等で④を飛ばせる。この自由は残す。
- ④を通る／飛ばす／③に留まるの3ルートに、それぞれ異なる意味を作る。
- ④経由を単純な恒常+2等にすると必ず通るのが正解になるため禁止。**④を通るルートと飛ばすルートで得るものを変える**方向を優先する。
- 例として、④経由は後の安定・継続、飛ばすルートは今すぐ高段階へ到達、という時間軸の違いを候補とする（具体効果未確定）。

## 横断監査
- ④1/4と⑦10/4が同じ一生に存在する極端な曲線を個性として維持する。
- ⑤⑥⑧すべてが「捨て札に④があるなら」にならないよう、明示的な④経由参照は1〜2段階程度を目安に抑える。
- ⑦はちから10自体が大きな能力。さらに大きな数値補正を載せない。
- ⑦10/4→⑧6/6にも「留まる／進む」の判断を作る。
- 高段階直接たんじょうは共通ルールどおり可能。⑦直接たんじょうが強すぎるかは、通常時コスト設計・模擬対戦まで保留し、現時点で禁止例外を作らない。
- 低数値＝弱カードではないという共通原則を④で特に検証する。

## 近接属性との差
- みずべ=**場所**を変える。
- うみ=**状態・関係**を変える／流す。
- むし=**段階・経路**を変える。

カクレクマノミの「自分の状態が変わる」とカブトムシの「人生段階をどう通るか」は別戦術として維持する。

## 次に再開する場所
**くさ代表「サクラ＝そだてる」①〜⑧。** 既存正本には仮曲線 `1/3 → 2/3 → 4/4 → 6/4 → 7/5 → 9/5 → 5/7 → 4/9` と、能力方向 `①芽吹く→次段階準備、②根づく→セカイ、③育つ→なかま、④支える→盤面安定、⑤備える→⑥への予告、⑥咲く→瞬間成果、⑦実る→成果を次へ、⑧残す→過去／捨て札活用` がある。これを理由なく変更せず代表テストする。
