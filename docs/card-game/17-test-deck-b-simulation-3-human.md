# 17 テストデッキB — 第3回模擬（ひと①〜⑧中心）

最終更新: 2026-09-14

状態: **ひと①〜⑧横断監査・第2稿候補抽出。**

## 前提
`15-test-deck-b-main-16-draft.md` のひと①〜⑧を主役に、B40枚で「えらぶ」という属性軸が各段階で重複せず機能するかを確認した。

# 段階別監査

## ① 1/1「これからのじんせい」
未来3枚からメイン以外1枚を選ぶ能力は、①から始める理由として十分。低数値でも役割が明確。

**維持。**

## ② 2/2「どっちであそぶ？」
あそびを使った時にちから／ちえ+1を選ぶ。操作が軽く、序盤の「選ぶ」体験として分かりやすい。

**維持。**

## ③ 4/3「とくいをみつける」
片方+2／もう片方-1は、相手盤面を見て得意を決める選択が生まれる。②との差も十分。

**維持。**

## ④ 6/4「どっちでいどむ？」
ちょうせん時に手札1枚を山札下→1枚引く選択は、単なる数値補助でない点が良い。ただし「使用能力値を選んだ後」という文言は、基本ルール上ちょうせん宣言時の選択と噛み合うため維持可能。

**維持。**

## ⑤ 8/5「だれと、どこで」
現稿は「なかま・こいびと・セカイのうち2種類以上があるなら、3種類から1つ選び別効果」。テーマは良いが、物理版では1枚に3分岐を持つため処理と読解がやや重い。

また、条件成立後に毎ターン3択を確認するため、ひと属性の中でこの段階だけ文章密度が高い。

### 第2稿候補
`1ターンに1回。自分のターンに、自分になかま・こいびと・セカイのうち2種類以上がある場合、発動できる。その中から1種類を選ぶ。このターン、その選んだ種類のカードが自分の盤面にある間、このメインのちからかちえを1つ選び+1する。`

- 3種類別効果を廃止。
- 「誰と・どこで生きるかを選ぶ」テーマは残す。
- 数値+1だけなので8/5自体の強さを壊しにくい。
- 盤面のどの種類を活かすかを毎ターン選ぶ体験は維持。

**⑤は簡略化を推奨。**

## ⑥ 7/7「つかいわける」
低い方+1は、7/7の均衡を壊さず相手に応じた選択を残す。⑤より処理が軽く、成熟段階として自然。

**維持。**

## ⑦ 5/8「けいけんをいかす」
第2回でも懸念した通り、⑥7/7から進む理由がやや薄い。ちえ8自体は明確な価値だが、能力の「捨て札1枚を山札下→片方+1」が小さく、相手がちえ型でない限り⑥留まりが自然になりやすい。

ただし強化しすぎると⑦が自動選択になるため、数値ではなく**経験を使う柔軟性**を少し強める。

### 第2稿候補
`1ターンに1回。自分のターンに、自分の捨て札のメイン以外1枚を選んで発動できる。そのカードを山札の一番下に置く。このターン、このメインのちからかちえを1つ選び+1する。そのカードが「なかま」「こいびと」「セカイ」のいずれかなら、代わりに+2する。`

- 過去の人生要素を使った時だけ+2。
- アクションカードを戻すだけなら従来どおり+1。
- ⑥7/7との競合を保ちつつ、⑦へ進むテーマ上の理由を作る。

**⑦は小強化を推奨。**

## ⑧ 3/9「つぎへたくす」
能力発動は主に別種族へへんしんする時で、毎試合使えるわけではない。ただし⑧はちえ9自体が明確な到達価値であり、能力まで常時使いやすくすると直接⑧たんじょうが強くなりやすい。

発動率の低さは「老年期に次へ託す」というテーマと許容範囲。現時点では変更しない。

**維持。**

# ひと属性の段階差
- ① = 未来から選ぶ
- ② = あそび後の伸ばす方向を選ぶ
- ③ = 得意分野を選ぶ
- ④ = 挑戦時に手札更新を選ぶ
- ⑤ = 誰と／どこで生きるかを選ぶ
- ⑥ = 能力値を使い分ける
- ⑦ = 過去の経験を選んで活かす
- ⑧ = 何を次へ残すか選ぶ

「えらぶ」は一貫しているが、同じ操作の繰り返しにはなっていない。

# 条件付き+10ちょうせんとの関係
ひと②〜⑥は能力値補助や手札整形が中心で、メイン自身が直接追加そだち+5を持たない。このため、カワウソ等のサポートを引いた時だけ「大勝負」が生まれる構造を維持できている。

# 第3回結論
## 変更推奨
1. **人⑤** — 3分岐別効果を1つの統一効果へ簡略化。
2. **人⑦** — 過去のなかま／こいびと／セカイを使った場合だけ+2にして、⑥から進む理由を少し強める。

## 維持
人①②③④⑥⑧、カブト全段階、基本ルール、ちょうせん+5方針。
