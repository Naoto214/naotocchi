# 41 メイン31種族 — 8段階人生テーマ地図

最終更新: 2026-09-14

状態: **残りメイン232形態を能力化する前の種族横断設計。既存代表・31のカブト／クワガタ本文は変更しない。**

## 目的

メイン248形態を1枚ずつ先着順で能力化すると、同じ属性・近縁種・成長段階で能力が重複する。

先に31種族それぞれについて、

1. 8段階でどんな一生を語るか
2. 属性テーマの中で、その種族は何を担当するか
3. どの既存処理を主な遊び場にするか
4. 近縁・同属性と何を重ねないか

を決める。

具体的なちから／ちえ・能力本文は、この地図の後で8段階横断設計する。

## 生態の扱い

- 現行 `character-world-master.v1.js` の8段階を最優先する。
- 実在生物は現実の生態を出発点にするが、なおとっちらしい解釈・誇張を許容する。
- 現実の分類とゲーム属性は同一でなくてよい。例: **サンゴは現実には動物**だがゲームでは「うみ」、**キノコは菌類**だがゲームでは「くさ」。
- 生態からカード能力へ翻訳する際も、新専用ゲージ・大量マーカーを安易に増やさない。

今回の生態方向は現行マスターに加え、サケの川→海→川回帰、ヤドカリの殻替え、クラゲのポリプ／メデューサ型、ヒトデ類の再生、サンゴの群体・礁形成、セミの地下生活、タンポポの種子散布、ハエトリグサの刺激検知などを公開生物資料で再確認した。細かい種差が能力強度に関わる段階では個別再調査する。

# ひと — えらぶ

## M-man — おとこのひと
- 既存代表。設計軸: **えらぶ**。
- 一生: 可能性 → 遊ぶ → 得意を見つける → 挑む → 誰と／どこで生きる → 使い分ける → 経験を活かす → 次へ残す。
- 主な遊び場: 選択、ちから／ちえ切替、人生カード種類横断、過去と未来。
- 状態: 代表テスト＋B第2稿を優先。再設計しない。

## M-woman — おんなのひと
- 暫定種族軸: **くみあわせる**。
- 一生案: 可能性 → 遊び方が増える → 得意を組み合わせる → 複数の道を見る → 人・場所・行動をつなぐ → バランスを取る → 経験同士を結ぶ → 次の選択肢を残す。
- 主な遊び場: 異なるカード種類を組み合わせる、2つの小さい選択を1つの結果へつなぐ。
- 差別化: おとこのひとが「その場で1つ選ぶ」基準なら、おんなのひとは「複数の人生要素を組み合わせる」。
- **重要:** これは性別による能力差・性格差を主張する設定ではない。ひと属性内で2つの標準プレイ体験を作るための暫定ゲーム軸で、力・知性・恋愛・職業等を性別固定しない。必要なら男女間で入れ替えても世界観が壊れない設計にする。

## M-ren — れんくん
- 暫定種族軸: **つづける**。
- 本編デザイン: 同じ一人が幼少→高齢まで明確に年齢を重ね、サッカー好き要素は主に子ども期。
- 一生案: 好きなことを見つける → 夢中になる → 上達する → 人と関わる → 続け方が変わる → 経験になる → 見守る側になる → 好きだったことが人生に残る。
- 主な遊び場: 同じ種類の行動を人生の別段階で違う意味へ変える／過去の「あそび」を後で価値化。
- 差別化: シークレットだから数値で上位互換にしない。本人についてマスターにない性格・経歴を想像して能力化しない。

- 差別化: ぬいぐるみは不利状態に別価値、ほしは尺度を変える、？？？は「そもそも分類できるのか」を小さく揺らす。

## 42以降へ進む前の原則

- 同じ属性テーマを31種族すべてへ機械的に貼らない。
- 種族テーマは「全8枚に同じ効果をつける」という意味ではない。8段階で一生として展開する。
- 代表8種・カブト／クワガタの既存仮数値・能力方向は理由なく再設計しない。
- 残り種族は、生態の個別監査→①〜⑧の数値曲線→能力方向→近縁監査の順で作る。
- 最終アートはまだ作らない。
