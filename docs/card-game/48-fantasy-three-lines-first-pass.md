## 属性テーマ

げんそう = **こえる**。

通常なら届きにくい限界・不利・終わりを、条件・代償・長い準備などと引き換えに越える。

- りゅう: **ためて、解き放つ**
- フェニックス: **燃えて、代償ごと限界を越える**
- かみさま: **重い条件に応じて、願いへ大きく応える**
- おばけ: **場を去った後にも、気配を残して終わりを越える**

「レア＝無条件高性能」にはせず、能力の使い方まで含めて通常種と違う体験を作る。

## フェニックスとの差

- りゅう: **先にためる → 後で使う**。
- フェニックス: **今限界を越える → 後で代償を引き受ける**。

どちらも高数値だが、時間軸を逆にする。

# 3. かみさま — ねがいにこたえる

仮数値曲線:

合計: ちから30 / ちえ64 = 94。

象徴的に高いちえを持つが、能力は「何でもできる」ではなく、**明確な条件を満たした時に1つ選んで応える**方向へ限定する。

なおとっち世界の幻想キャラクターであり、現実の宗教・信仰・神学を表現する設定ではない。

## フェニックス／りゅうとの差

- りゅう: 自分の資源をためて大技。
- フェニックス: 自分を燃やして限界突破。
- かみさま: **盤面の条件を満たした結果、選択型の奇跡**。

高数値だけでなく、誰が何を払う／準備するかを分ける。

# 4. おばけ — いなくなってものこる

仮数値曲線:

レアだが基礎総量はりゅう／フェニックス／かみさまより低い。代わりに、**盤面を離れた後まで意味が続く**という独自性を持たせる。

## 他属性の「過去」との差

- おとこのひと: 過去を**選んで活用**。
- サクラ: 過去を**次の準備へ循環**。
- キノコ: 過去領域を**見えないつながりとして広げる**。
- ぬいぐるみ: 過去が**過去のままでも価値**。
- おばけ: 自分が去った後に**既に生じた気配／効果だけが残る**。

無条件復活・何度でも戻るカードにはしない。
