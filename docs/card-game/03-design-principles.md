# 03 設計原則・未確定事項・次の作業

## カード設計で避けること
- 高段階を低段階の完全上位互換にする。
- レアを通常の単純上位互換にする。
- 細かな数値計算や新ゲージを大量に増やす。
- 9マス全部を埋めることだけを正解にする。
- 相手を長時間何もできなくする。
- 完全無効・簡単なメイン除去を大量に作る。
- 相手盤面を見なくても最適行動が決まる。
- デジタル自動処理前提の複雑な基本ルール。
- カードゲーム専用概念を増やしすぎ、本編との関係を薄くする。
- ちょうせん関連カードばかりにして「ちょうせん専用TCG」にする。
- しかけを±1/±2だけの足し算合戦にする。

## ちょうせん関連能力の方向
数値補正以外にも、ちから／ちえの入替、特定補正の弱体化、引き分け利用、敗北時の別利益、属性／段階条件、ちょうせん後へんしん、相手の選択を読んだ時の発動、参照方法変更等を混ぜる。ただし例外過多にしない。

## 盤面に責任を持つ
準備3枠、なかま3枠等が埋まっても、手詰まりを恐れて基本ルールへ自由廃棄・自由交換を大量追加しない。「つかう」は盤面満杯でも使える。必要ならカード能力で片付け・手札交換・捨て札利用等を作る。実際の手詰まり頻度は模擬対戦で判断。

## 物理版
基本ルールは物理カードで処理可能にする。3×3＋1×3、時カウンター、そだち0〜100（5刻み）トラック、装備対象マーカー、発動領域へのカード重ねで連鎖処理。ちから／ちえはカード記載1〜10、補正も人間が追える範囲。デジタルでしか扱えない隠し計算や大量の常時変動値を避ける。

## 本編との一体感
本編で育てる→8段階を見る→なかま／恋人と出会う→結婚→セカイを旅する→ゲームで遊ぶ→アイテムを使う→出来事を経験する、がカード解禁へつながる。シールは「集める・ダブる・貼る・飾る」、カードは「解禁する・デッキを組む・戦う」。

## 既存TCGの参考方針
遊戯王、デュエマ、ポケカ、Magic、Shadowverse等を比較材料にしてよいが、「有名TCGがそうだから」では決めない。なぜそのルールが必要かを抽象化し、なおとっちの10ラウンド・時・そだち・3×3・人生テーマに理由が当てはまる場合だけ採用。

遊戯王から特に参考: 伏せの緊張、割込み、「それに対して」、チェーン、逆順解決、コンボ、切り札、逆転、盤面／捨て札から読む楽しさ。参考にしない方向: 過剰な無効合戦、長大な1ターン、相手がほぼ動けない盤面、複雑な速度分類。

## メイン8段階の作り方
各段階を先に「この時期は何が得意／不得意か、前段階から何を得て何を失ったか」で言語化し、その後ちから／ちえへ変換する。種族ごとに人生曲線を変える。

試作例（**数値未確定**）:
- おとこのひと: ①1/1, ②2/2, ③4/3, ④6/4, ⑤8/5, ⑥7/7, ⑦5/8, ⑧3/9
- サクラ: ①1/3, ②2/3, ③4/4, ④6/4, ⑤7/5, ⑥9/5, ⑦5/7, ⑧4/9
- カブトムシ: ①2/2, ②3/2, ③5/3, ④1/4, ⑤5/3, ⑥8/4, ⑦10/4, ⑧6/6
- フェニックス: ①3/2, ②5/3, ③7/3, ④9/4, ⑤10/5, ⑥8/7, ⑦4/9, ⑧9/8
- ぬいぐるみ: ①6/2, ②7/3, ③7/5, ④5/5, ⑤3/6, ⑥4/7, ⑦1/8, ⑧2/10

これらは方向性確認用で正式数値ではない。

サクラ能力方向の試作（**能力未確定**）: ①芽吹く→次段階準備、②根づく→セカイ、③育つ→なかま、④支える→盤面安定、⑤備える→⑥への予告、⑥咲く→瞬間成果、⑦実る→成果を次へ、⑧残す→過去／捨て札活用。

## 8属性代表テスト — 作業チェックポイント

### ひと代表: おとこのひと
**状態: ①〜⑧の第一周と横断監査まで完了。能力・数値は代表テスト中の仮案。次はけもの代表「いぬ」①〜⑧へ進む。**

代表としての設計軸: 「男性だからちから型」ではなく、ひと属性の標準的な人生として **えらぶ** を最も純粋に表す。①〜③は「自分の未来を選ぶ」、④〜⑥は「今どう生きるかを選ぶ」、⑦〜⑧は「これまでの人生をどう活かすかを選ぶ」。

ちから／ちえの仮曲線は既存試作 `①1/1 → ②2/2 → ③4/3 → ④6/4 → ⑤8/5 → ⑥7/7 → ⑦5/8 → ⑧3/9` を維持して代表テストする。数値は未確定。⑤以降も完全上位互換にならず、⑤8/5→⑥7/7、⑥7/7→⑦5/8、⑦5/8→⑧3/9で「進む／留まる」の選択が成立することを重視する。

#### ① 赤ちゃん — 可能性／「これから」
- 仮値: ちから1／ちえ1。
- 人生上の意味: まだできることは少ないが、これからの可能性が最も広い。
- 能力方向（未確定）: たんじょう時などにデッキ上の複数枚を見て、**メイン以外の人生に関わるカード**を1枚選ぶ。なかま／こいびと／セカイ／あそび／あいてむ／できごと等から、その試合でこれから関わるものを選ぶイメージ。
- 狙い: 高段階から直接たんじょうできる中でも①から始める価値を作る。ただの汎用ドローではなく「未来をえらぶ」に寄せる。
- 枚数（上3枚／上4枚等）や失敗時処理は現時点では固定しない。

#### ② 幼児 — あそぶ／「好きなこと」
- 仮値: ちから2／ちえ2。
- 人生上の意味: 遊びながら身体も頭も育ち、好きなことを選び始める。
- 能力方向（未確定）: 自分が「あそび」を使ったことを条件に、ちから／ちえのどちらを伸ばすか選ぶ。第一案はそのターン中、選んだ方を+1。
- 永久強化の積み上げにはせず、管理負荷や②への居座り最適化を避ける。
- けものも「あそび」を使える。ひとが能力を独占せず、けもの側は後でより能動的・即効的な「あそび」活用として差別化する。

#### ③ 子ども — 得意を見つける
- 仮値: ちから4／ちえ3。
- 人生上の意味: 経験から、自分が何を得意とするかを選び始める。
- 能力方向（未確定）: この段階になった時などに、ちから／ちえのどちらかを選び、そのターン選んだ方を大きめに補正する。第一案は+2（4/3から6/3または4/5）。
- 「たんじょうした時」だけか、「ときとばし／へんしん等を含めこの段階になった時」かは全メインに関わる共通能力語彙として代表テスト後に整理する。

#### ④ 青年 — 挑戦／「どう挑むか」
- 仮値: ちから6／ちえ4。
- 人生上の意味: ③で見つけた得意を世界へぶつけ、挑戦する時期。
- **基本ルールを維持する:** ちょうせんで「ちから」を選べば必ず自分のちから対相手のちから、「ちえ」を選べば必ずちえ対ちえ。相手側の比較パラメータを選んだり、基本比較方法を④だけで自由に変えたりしない。
- ちから／ちえは公開値なので、補正前の勝敗は多くの場合予測できる。選択を「どちらなら勝てるか」という答え合わせだけにしない。
- しかけ・条件付き能力による勝敗確定前の反応／連鎖があるため、公開値で優勢でも最終勝敗は確定ではない。この既存の読み合いを活かす。
- 能力方向（未確定）: 単純な数値強化より、「ちから／ちえのどちらを選んで挑むか」に別の意味や小さな利益を持たせる方向。ただし④一枚で「えらぶ」を背負わせず、具体効果は①〜⑧と他属性を見て決める。

#### ⑤ 成人・壮年 — 人生を広げる／「誰と・どこで生きるか」
- 仮値: ちから8／ちえ5。ちからの人生ピーク候補。
- 人生上の意味: 自分一人の挑戦から、周囲との人生へ広がる時期。
- 能力方向（未確定）: **なかま／こいびと／セカイ**など、誰と・どこで生きるかという既存の人生要素に関わる選択。3択の長文能力にせず簡潔にする。
- ④のちょうせん強化の単純上位互換にはしない。8/5の高いちからで挑み続けること自体も選択肢として残す。

#### ⑥ 中年・成熟 — 使い分ける
- 仮値: ちから7／ちえ7。
- 人生上の意味: 行動力のピークを少し手放し、経験とのバランスを得る。
- 7/7という印刷値そのものが「相手・状況を見てちから／ちえを選ぶ」性格を持つため、能力でさらに数値選択を盛りすぎない。
- ⑤8/5に留まるか、時を使って⑥7/7へ進むかが自然な判断になることを重視する。
- 能力方向（未確定）: 選択した結果に小さな意味を持たせる程度を候補とし、具体化は後回し。

#### ⑦ 高齢期 — 経験を活かす
- 仮値: ちから5／ちえ8。
- 人生上の意味: 今の能力だけでなく、これまで何をしてきたかが価値になる時期。
- 能力方向（未確定）: 完全公開の**捨て札＝これまでの人生**を参照し、その中の経験から何を今に活かすか選ぶ。
- 「捨て札1枚につき+1」のような後半自動巨大化・細かな枚数計算は避ける。
- ①がデッキ＝未来から選ぶのに対し、⑦は捨て札＝過去から選ぶ対称性を持たせる。ただし最終能力では①と⑦の操作感を別物にする。

#### ⑧ 老年期 — 残す
- 仮値: ちから3／ちえ9。
- 人生上の意味: 一番強い段階ではなく、人生で得たものを次へ残す時期。
- 能力方向（未確定）: これまでの経験から1つを選び、次のメインやその後の人生へ残す。特に⑧からの自発的な**へんしん**と組み合わせる方向を重点候補とする。
- 新しい永続ゲージ／複雑な記憶マーカーは避け、既存のカード・捨て札・手札・そだち等で物理処理可能にする。
- メイン除去まで強く罰する能力にするかは未確定。自分のへんしん時だけに限定する案も比較する。

#### ①〜⑧の連作
`① 何と出会うか → ② どう遊ぶか → ③ 何を得意にするか → ④ どう挑むか → ⑤ 誰と・どこで生きるか → ⑥ 状況に応じて使い分ける → ⑦ 過去のどの経験を活かすか → ⑧ 何を次へ残すか`

全体を通して **ひと＝えらぶ** を表す。ただし各カードに無理に二択・三択文章を付けるのではなく、数値曲線や既存ルール上の判断自体も「えらぶ」の一部とする。

#### 横断監査結果
- **数値曲線:** 現状維持。高段階が完全上位互換になっておらず、ときとばしで進む／留まる判断を作れる。
- **公開値問題:** ちから／ちえは見えているため、通常ちょうせんの補正前勝敗は予測しやすい。属性設計では「高い方を選ぶだけ」にしない。しかけ・能力・選択による別目的を使い、読み合いを残す。
- **①と⑦の類似:** 未来（デッキ）／過去（捨て札）の対称性は残すが、どちらも「複数枚から1枚取る」だけにはしない。最終能力の操作感を分ける。
