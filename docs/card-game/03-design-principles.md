# 03 設計原則・未確定事項・次の作業

この文書の進捗・未確定事項・末尾の作業順は代表テスト当時の記録。現在地は[README](README.md)、全体監査は[61](61-full-rules-and-card-text-audit.md)を参照する。設計原則と試行の履歴は保持する。

## カード設計で避けること
- 高段階を低段階の完全上位互換にする。
- レアを通常の単純上位互換にする。
- 細かな数値計算や新ゲージを大量に増やす。
- 9マス全部を埋めることだけを正解にする。
- 相手を長時間何もできなくする。
- 完全無効・簡単なメイン除去を大量に作る。
- 相手盤面を見なくても最適行動が決まる。
- デジタル自動処理前提の複雑な基本ルール。
- カードゲーム専用概念を増やしすぎ、本編との関係を薄くする。
- ちょうせん関連カードばかりにして「ちょうせん専用TCG」にする。
- しかけを±1/±2だけの足し算合戦にする。

## ちょうせん関連能力の方向
数値補正以外にも、ちから／ちえの入替、特定補正の弱体化、引き分け利用、敗北時の別利益、属性／段階条件、ちょうせん後へんしん、相手の選択を読んだ時の発動、参照方法変更等を混ぜる。ただし例外過多にしない。

## 盤面に責任を持つ
準備3枠、なかま3枠等が埋まっても基本ルールへ自由廃棄・自由交換を大量追加しない。「つかう」は盤面満杯でも使用可。必要ならカード能力で片付け・手札交換・捨て札利用等を作り、実際の手詰まり頻度は模擬対戦で判断する。

## 物理版
基本ルールは物理カードで処理可能にする。3×3＋1×3、時カウンター、そだち0〜100（5刻み）トラック、装備対象マーカー、発動領域へのカード重ねで連鎖処理。デジタルでしか扱えない隠し計算や大量の常時変動値を避ける。

## 本編との一体感
本編で育てる→8段階を見る→なかま／恋人と出会う→結婚→セカイを旅する→ゲームで遊ぶ→アイテムを使う→出来事を経験する、がカード解禁へつながる。シールは「集める・ダブる・貼る・飾る」、カードは「解禁する・デッキを組む・戦う」。

## 既存TCGの参考方針
遊戯王、デュエマ、ポケカ、Magic、Shadowverse等は比較材料にしてよいが、「有名TCGがそうだから」では決めない。なおとっちの10ラウンド・時・そだち・3×3・人生テーマに必要な理由がある場合だけ採用する。

遊戯王から特に参考: 伏せの緊張、割込み、「それに対して」、チェーン、逆順解決、コンボ、切り札、逆転、盤面／捨て札から読む楽しさ。参考にしない: 過剰な無効合戦、長大な1ターン、相手がほぼ動けない盤面、複雑な速度分類。

## メイン8段階の作り方
各段階を先に「この時期は何が得意／不得意か、前段階から何を得て何を失ったか」で言語化し、その後ちから／ちえへ変換する。種族ごとに人生曲線を変える。

- フェニックス: ①3/2, ②5/3, ③7/3, ④9/4, ⑤10/5, ⑥8/7, ⑦4/9, ⑧9/8

サクラ能力方向の試作（**未確定**）: ①芽吹く→次段階準備、②根づく→セカイ、③育つ→なかま、④支える→盤面安定、⑤備える→⑥への予告、⑥咲く→瞬間成果、⑦実る→成果を次へ、⑧残す→過去／捨て札活用。

設計軸: 男性だからちから型ではなく、ひと属性の標準的人生として **えらぶ** を最も純粋に表す。仮曲線は `1/1 → 2/2 → 4/3 → 6/4 → 8/5 → 7/7 → 5/8 → 3/9`。数値・具体効果量は未確定。

| 段階 | 人生テーマ | 仮値 | 能力方向（未確定） |
|---|---|---:|---|
| ① | 赤ちゃん／可能性 | 1/1 | デッキ＝未来から、メイン以外の人生に関わるカードを選ぶ。①から始める価値を作る。 |
| ② | 幼児／あそぶ | 2/2 | あそびを使った時などに、ちから／ちえのどちらを伸ばすか選ぶ。永久累積は避ける。 |
| ③ | 子ども／得意を見つける | 4/3 | ちから／ちえのどちらを得意にするか選ぶ。第一案はそのターン片方+2。発動語彙は後で共通整理。 |

連作: `①何と出会うか → ②どう遊ぶか → ③何を得意にするか → ④どう挑むか → ⑤誰と・どこで生きるか → ⑥状況に応じて使い分ける → ⑦どの経験を活かすか → ⑧何を次へ残すか`。

#### おとこのひと横断監査
- 数値曲線は現状維持。高段階が完全上位互換ではなく「進む／留まる」を選べる。
- ちょうせん基本ルールは曲げない。「ちから」なら必ずちから同士、「ちえ」なら必ずちえ同士。
- 公開値なので補正前勝敗は予測しやすい。「高い方を選ぶだけ」にせず、しかけ・条件付き能力・別目的で読み合いを作る。
- ①未来／⑦過去の対称性は残すが、最終能力を両方「複数枚から1枚取る」だけにはしない。
- 高段階へ直接たんじょう可能なので、⑧を「直接⑧→即へんしん」が常に最適になる能力にはしない。必要なら別段階のおとこのひとが捨て札にある場合等で経由価値を作るが、全段階経由は要求しない。
- ひとは「人生で何を選んできたか」。むしは後で「どの段階を通る／飛ばす／留まるか」自体を中心にする。

### けもの代表: いぬ
**状態: ①〜⑧の第一周＋横断監査まで完了。数値・具体効果は未確定。**

設計軸: **いどむ**。ひとの「盤面を見て考え、選んでから動く」に対し、いぬは **まず動く→その行動から次の展開が生まれる**。ちょうせんだけの属性にはせず、あそび・能動行動・即効性と、後半の信頼／絆まで一生としてつなぐ。

仮数値曲線: `①2/1 → ②3/2 → ③5/3 → ④7/4 → ⑤9/5 → ⑥7/6 → ⑦5/7 → ⑧3/7`。

| 段階 | 人生テーマ | 仮値 | 能力方向（未確定） |
|---|---|---:|---|
| ① | 生まれたて／ついていく | 2/1 | 誰かがいることで最初の一歩を踏み出しやすくなる。後半の絆能力ほど強くしない。 |
| ② | 子犬／あそびまわる | 3/2 | あそびを使うこと自体が次の能動行動につながる。ひと②の「どちらを伸ばすか選ぶ」と操作感を分ける。時回復による連打は避ける。 |
| ③ | 成長期／やってみる | 5/3 | 自分からちょうせんして負けても、完全な失敗にせず次へつながる小さな利益。公開値で負けが見えていても挑む意味を作る。 |
| ④ | 若犬／まず飛び込む | 7/4 | **ターン前半型**を重点候補。早い段階で自分からちょうせん／行動することに意味を持たせ、「まず挑む」プレイを作る。 |
| ⑤ | 成犬／駆けまわって走り切る | 9/5 | 活動性ピーク。**ターン後半型**を重点候補。そのターンに既に行ったあそび・能動行動等が最後の成果につながる。ちょうせん回数上限は破らない。 |
| ⑥ | 成熟犬／一緒に動く・寄り添う | 7/6 | 自分が行動することで、一緒にいる誰かにも利益が生まれる方向。単なる「誰かがいるだけで+○」にはしない。 |
| ⑦ | シニア犬／見守る | 5/7 | 自分が前へ出続けるのでなく、周囲の行動を支える。③の「自分が失敗しても経験」と対比させる。 |
| ⑧ | 老犬／そばにいる | 3/7 | 次へ残す人間⑧とは分け、長く一緒に過ごした関係・現在盤面にいること自体を成果へつなげる方向。 |

連作: `①ついていく → ②あそびまわる → ③やってみる → ④まず飛び込む → ⑤駆けまわって走り切る → ⑥一緒に動く → ⑦見守る → ⑧そばにいる`。

#### いぬ横断監査
- **③敗北利益:** 「負けるたびそだち+5」等、わざと負ける方が得になる設計は禁止。通常勝利報酬より明確に弱い「次につながる利益」にする。手札調整等が候補で、そだち直接獲得は避ける方向。
- **②〜⑤の類似回避:** ④と⑤を特に分離。④=ターン前半にまず飛び込む、⑤=複数の行動を経てターン後半に走り切る。すべてを「あそび→ちょうせん+補正」の同型にしない。
- **ちょうせん上限:** メインは自分ターン1回まで、という確定ルールを破らない。⑤等で2回目のちょうせんを発生させない。
- **⑥〜⑧の絆:** 「誰かがいるだけで強い」という受動シナジーに寄せすぎない。前半から自分が能動的に関わった結果として、後半に関係が価値になる設計を優先する。
- **⑦→⑧:** 5/7→3/7で数値だけなら⑧が下位。これは許容可能だが、⑧固有能力に進む価値が必要。単なる強カード化ではなく「そばにいる」役割で価値を作る。
- **ひととの差:** ひと=何をするかを選ぶ楽しさ。けもの=動くことで展開を作る楽しさ。
