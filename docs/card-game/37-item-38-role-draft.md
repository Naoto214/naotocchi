## 目的

本編のアイテム効果をそのままカードゲームへコピーすると、カードゲームに存在しない「おなか・げんき・病気確率・コイン」等を新ルールとして持ち込むことになる。

そこで、**本編でその道具が何を助けるものか**を残しながら、既存カードゲームの

- 時
- そだち
- ちょうせん
- 手札／山札／捨て札
- 準備枠
- 交際／結婚
- セカイ
- たんじょう／ときとばし／へんしん
- プレイ方法

へ翻訳する。

現行source分類は28を維持する。

- SHOP_ITEMS 15
- NAOTO_ITEMS 4
- CONSUMABLE_ITEMS 11
- FUN_ITEMS 7
- RECOVERY_ITEMS 1 HOLD

## A. SHOP_ITEMS 15 — 主に「みにつける」候補

### I-flower — おはな
- 本編核: きゅうあいが少し成功しやすい
- カードテーマ: **関係を進めるきっかけ**
- 担当: 恋愛連携
- 既存第2稿の66整理: `メインまたはこいびとにみにつける。1ラウンドに1回。このカードをみにつけている間に、自分の交際段階が進んだ時、発動する。自分のそだち+5。その後、このカードを捨て札に置く。`
- 0→1を含む進行時の強制発動を明記し、08へ同期。0での交際開始と3→結婚は含まない。これはカード正本の接続修正であり、本編アイテム変更の先取りではない。時1・みにつける・+5・使用後捨て札の役割は維持する。
- 維持: こいびと本体の能力とは別に、道具で関係を後押しする基準。

### I-bowtie — ちょうネクタイ

### I-poop1 — トイレットペーパー
- 本編核: うんちがたまりにくい
- カードテーマ: **困る前に用意しておく**
- 担当: しかける／置換・予防
- 67本文（時1・しかける）: `相手がメインを除去する効果を発動した時、自分のメイン1枚を対象として発動できる。その発動が無効になっていない場合、その相手の発動の処理が終わるまで、対象のメインがその効果による除去で捨て札に置かれるなら、1回だけ、代わりにそのメインを場に残す。`
- 旧Aの「捨て札になるなら発動」は解決中に割り込めないため、相手の除去発動に反応して置換を事前適用する方式へ個別改稿した。効果の処理後にこの札自身は通常どおり捨て札。旧文・局面・低発動率の残件は[67](67-legacy-test-card-function-and-tracking.md)。本編アイテム変更の先取りではない。

## G. 重複監査ポイント

1. `ribbon / crown / hedgehog / scarf / sickshield` を全部同じ防止効果にしない。
2. `flower / partner1 / court small / court big / break half / break full` は恋愛の**進行・維持・終了**を分ける。
3. `hat / growth drink / lucky coin / star badge` は「成果を増やす」対象をそれぞれ分ける。
4. `travel1 / c_travel / naoto_lantern` は旅の**準備・一時保険・発見**を分ける。
5. `c_mgsmall / c_mgbig` と `court small / court big`、`break half / break full` は単純上下位互換になりやすいため、正式本文前に統合可能性を必ず見る。
6. `I-crown` と `I-naoto_crown` は名前が近いが、通常かんむり＝防御、なおとのかんむり＝あそびの特別化として別物にする。
