# 51 ひと属性 — おんなのひと／れんくん 能力本文 第1稿

最終更新: 2026-09-14

状態: **具体カード本文 第1稿。未確定・模擬前。** おとこのひとは15第2稿を比較基準として維持する。

62で公開情報・少数枚処理・発動した能力の参照を明記。「表向きでプレイ」は、すぐつかう／みにつけるでのプレイを指す。しかけるや後日の発動は数えない。変更による成立範囲と局面は[62](62-public-information-and-activation-text-fixes.md)。

## 共通

属性テーマ: **えらぶ**。

- おとこのひと: その場で1つを選ぶ。
- おんなのひと: 異なる人生要素を組み合わせる。
- れんくん: 好きなことを続け、同じ「あそび」の意味を人生で変える。

性別やシークレットで数値・能力の上下関係を作らない。れんくんについて、現行マスターにない本人の性格・経歴を能力理由として創作しない。

**カード側構築区分（71・第1稿）:** おとこのひと／おんなのひと／れんくんは各段階とも通常・同名3枚。れんくん8枚への割当は今回明記した個別設計。sourceのシークレットは本編の入手区分として残すが、追加の構築制限には使わない。同名は各段階のカード名ごとで、種族8段階全体を3枚に制限しない。あそびの反復を複数枚で試し、強度は後続で検証する。[27](27-card-master-foundation.md)・[71](71-main-248-card-text-cross-audit.md)参照。

# A. おんなのひと①〜⑧

仮数値曲線:
`1/1 → 2/3 → 3/4 → 5/5 → 7/5 → 7/6 → 6/7 → 5/8`

## M-woman-01 ① 1/1「ちがうものをみつける」

`このメインがたんじょうした時、発動できる。山札上2枚を公開する。公開したカードが2枚あり、そのカード種類が異なる場合、その中から1枚を選んで手札に加え、残りを山札の一番下に置く。それ以外の場合、公開したカードを好きな順で山札の一番下に置く。`

- おとこのひと①は上3枚からメイン以外1枚を選ぶ安定型。
- おんなのひと①は「違う2種類が並んだ時」に1枚を選ぶ多様性型。
- 純増は最大1枚。外れれば山札下整理だけになる。

## M-woman-02 ② 2/3「ちがうやりかた」

`1ターンに1回。自分がアクションカードを表向きでプレイした時、このターン、自分がそれより前に「あそび」「あいてむ」「できごと」のうち別の種類のアクションカードを表向きでプレイしていた場合、発動できる。このターン、このメインのちからかちえを1つ選び+1する。`

- 同じアクション種類を連打するより、別種類を組み合わせる価値。
- おとこのひと②の「あそび→能力値を選ぶ」と区別。

## M-woman-03 ③ 3/4「ふたつのとくい」

`1ターンに1回。自分の手札からカード種類が異なる2枚を公開して発動できる。このターン、このメインのちから・ちえ+1。`

- カードは捨てず、情報公開を条件にする。
- おとこのひと③の「片方+2／もう一方-1」と逆に、異なる2枚を持っている時だけ両方を小さく伸ばす。

## M-woman-04 ④ 5/5「いっしょにいどむ」

`1ターンに1回。このメインが自分からちょうせんする時、自分になかままたはこいびとがある場合、発動できる。このちょうせんの間、このメインの使用する能力値+1。自分になかまとこいびとの両方がある場合、代わりに+2する。`

- 一人で選ぶおとこのひと④と分け、人との組合せをちょうせんへ使う。
- なかま3枚等の人数比例にはしない。

## M-woman-05 ⑤ 7/5「だれと、どこで、つぎへ」

`1ターンに1回。自分のターンに、自分になかま・こいびと・セカイのうち2種類以上がある場合、発動できる。このターン、自分が次にプレイするアクションカードの時を1少なくする。`

- おとこのひと⑤は人生要素の中から1種類を選び、能力値へつなぐ。
- おんなのひと⑤は2種類以上が共存する盤面を、次の行動余地へ変える。
- 時は既存ルールどおり0まで下がる。

## M-woman-06 ⑥ 7/6「りょうりつする」

`1ターンに1回。自分がアクションカードを表向きでプレイした時、このターン、自分がそれより前に「あそび」「あいてむ」「できごと」のうち別の種類のアクションカードを表向きでプレイしていた場合、発動できる。1枚引き、その後手札1枚を山札の一番下に置く。`

- ②と同じ「異なるアクション種類」の成長後表現だが、数値補助から手札循環へ役割が変わる。
- 1枚純増にはしない。

## M-woman-07 ⑦ 6/7「けいけんをつなぐ」

`1ターンに1回。自分の捨て札から、カード種類が異なるメイン以外のカード2枚を好きな順で山札の一番下に置いて発動できる。このターン、このメインのちから・ちえ+1。`

- 発動時に2枚を戻すことをコストとする。
- おとこのひと⑦が「過去1枚を選んで+1／人生要素なら+2」なのに対し、こちらは異なる過去2種類を組み合わせて両能力+1。
- 2枚回収ではないため手札アドバンテージを増やさない。

## M-woman-08 ⑧ 5/8「つぎのみちをのこす」

`1ターンに1回。このメインがときとばしまたはへんしんでメイン枠から捨て札に置かれた時、発動できる。山札上3枚を見る。好きな順で山札の一番上に戻し、その後1枚引く。`

- おとこのひと⑧は過去1枚を山札下へ戻して1枚引く。
- おんなのひと⑧は次に続く3枚の順序を選び、今の1枚とその後の道を整える。
- 直接⑧たんじょう後にへんしんしても機能するが、時8＋へんしん時を払うため無料利益ではない。

# B. れんくん①〜⑧

仮数値曲線:
`1/1 → 3/2 → 5/3 → 7/4 → 7/5 → 6/7 → 4/8 → 3/9`

## M-ren-01 ① 1/1「すきなことをみつける」

`このメインがたんじょうした時、発動できる。山札上3枚を見る。その中から「あそび」カード1枚を選んで公開し、手札に加える。残りを好きな順で山札の一番下に置く。`

- 好きなことへ出会う入口。
- おとこのひと①より探索対象を狭くし、れんくんの「あそびを続ける」軸を明示する。

## M-ren-02 ② 3/2「もういっかい」

`1ターンに1回。自分が「あそび」カードを表向きでプレイした時、発動できる。このターン、自分が次に「あそび」カードを表向きでプレイするための時を1少なくする。`

- 同じターンにもう一度遊ぶ選択肢。
- 回数制限があるため、時0あそびの無限連打にはならない。

## M-ren-03 ③ 5/3「くりかえしておぼえる」

`1ターンに1回。自分が「あそび」カードを表向きでプレイした時、このターン、自分がそれより前に「あそび」カードを表向きでプレイしていた場合、発動できる。1枚引き、その後手札1枚を山札の一番下に置く。`

- 同じ行動を続けることで、手札を良くする。
- 子ども期のサッカー好きは主にフレーバーへ使い、カード本文をサッカー専用にはしない。

## M-ren-04 ④ 7/4「つづけたぶんだけ」

`1ターンに1回。このメインが自分からちょうせんする時、自分の捨て札に「あそび」カードが2枚以上ある場合、発動できる。このちょうせんの間、このメインの使用する能力値+1。`

- 過去に遊んだ経験が、挑戦時の小さな実力になる。
- カワウソの「あそび後の次の勝利で追加そだち+5」や、いぬ②の即時補助とは時間軸を分ける。

## M-ren-05 ⑤ 7/5「すきなことも、じんせいも」

`1ターンに1回。自分が「あそび」カードを表向きでプレイした時、発動できる。このターン、自分が次に「あそび」以外のアクションカードを表向きでプレイするための時を1少なくする。`

- ②は「あそび→あそび」。⑤は「あそび→別の人生行動」。
- 好きなことだけに閉じず、生活の他要素へつなぐ。

## M-ren-06 ⑥ 6/7「けいけんにする」

`1ターンに1回。自分の捨て札の「あそび」カード1枚を山札の一番下に置いて発動できる。山札上2枚を見て、1枚を山札の一番上、残りを山札の一番下に置く。`

- 過去のあそびを直接手札へ戻さず、次の判断材料へ変える。
- おとこのひと⑦の過去活用と違い、あそび経験に限定する。

## M-ren-07 ⑦ 4/8「みまもる」

`1ターンに1回。自分の捨て札に「あそび」カードがある場合、自分のなかままたはこいびとが発動した能力の効果が解決時に適用された時、発動できる。山札上1枚を見て、山札の一番上か一番下に置く。`

- 自分が前へ出るより、周囲の行動を見ながら次を整える老成。
- いぬ⑦の「周囲を支える」方向とは、過去のあそび経験を条件にすることで区別する。

## M-ren-08 ⑧ 3/9「すきだったことがのこる」

`1ターンに1回。自分の捨て札の「あそび」カード1枚を山札の一番下に置いて発動できる。このターン、自分が次にプレイするアクションカードの時を1少なくする。`

- ②では次のあそび、⑤ではあそび後の別アクション、⑧では過去のあそび経験が今のどんなアクションにもつながる。
- シークレットだから強いのではなく、8段階を通じて同じテーマが人生の別の意味へ変わることを個性にする。

# C. ひと3種 横断監査

## おとこのひと

- ①未来から選ぶ
- ②あそび後にどちらを伸ばすか選ぶ
- ③片方を得意にする
- ④挑戦時の手札交換
- ⑤誰と／どこで生きるか選ぶ
- ⑥低い方を補う
- ⑦過去1枚を選ぶ
- ⑧過去を次へたくす

→ **その場で何を選ぶか**が中心。

## おんなのひと

- 異なるカード種類
- なかま＋こいびと
- 2種類以上の人生要素
- 異なる過去2枚

→ **違うものを一緒に使う**ことが中心。

## れんくん

- あそびを探す
- もう一度あそぶ
- 繰り返した経験を手札へ変える
- 過去のあそびを挑戦へ
- あそびから他の人生行動へ
- あそびを経験へ
- 周囲を見守る
- 過去のあそびがどんな行動にも残る

→ **続けたものの意味が変わる**ことが中心。

## 重複リスク

### 時軽減
- おんなのひと⑤: 盤面2種類以上 → 次アクション-1
- れん②: あそび → 次あそび-1
- れん⑤: あそび → 次の非あそびアクション-1
- れん⑧: 捨て札あそびを戻すコスト → 次アクション-1

条件・人生段階は分かれているが、れんくん内で時軽減が3段階にある。模擬でプレイ感が単調なら、②または⑤を数値以外の継続報酬へ変更候補とする。

### 山札整理
ひと属性全体に山札整理が多い。

これは「えらぶ」と相性が良い一方、他属性でも山札操作を多用するため、全248能力本文完成後に総数を監査する。

## 第1稿判定

- 3種の戦術軸は分離できている。
- 新カウンター・基本ルール変更なし。
- おんなのひと④の+2、⑤の時軽減、れん②⑤⑧の時軽減密度は模擬重点項目。
- 正式確定ではなく、全属性本文作成後に再比較する。
