## 2. 共通の読み方

- すぐつかう18・しかける2。みにつけるは今回0。全20にメイン属性・ちから／ちえ・段階を付けない。
- 時はプレイ時に支払い、しかける発動時の追加時はない。通常の機会・反応・一部実行不能・対象固定・領域移動は01／06／07を使う。
- 複数カードを山札の上／下へ置く時は、本文の指定した順で一群を置く。「残り」の複数枚はその効果の使用者が好きな順で山札下へ置く。追加シャッフルはしない。
- 「カードに書かれた時コスト」は印刷値を使い、クモ等で実際に払った時と混同しない。裏向きの内容は本文が明示しない限り見ない。
- 対象個体への適用済み予約は発動元が捨て札になっても期限まで残る。対象が離れて再登場した場合は新しい個体。装備先の変更と領域移動を区別する。
- 「次の自分のターン開始時」は64の通常ドロー・たまご交換後の予約処理。R10終了後に次ターンを作らない。
- 本編の点数・失敗率・残り秒数を、そのままそだち・時へ換算しない。26アイテムの新効果、性別等を使わない交際、ちょうせん通常勝利+5も維持する。

## 4. 本文以外のsource訂正と比較

- 39のケーキ「自由に飾る」は本編実装とずれていた。3種の指定先へ順に置く実装に合わせ、装備の適正先と配分を軸に具体化した。おべんとうは見本が2200msで消え、覚えた場所へ戻すので「見本を覚えて配置」へ訂正した。2種とも同じ装備つけ替えにはしない。
- stack-themedはつみき／パンケーキ／ケーキの可変テーマ、road-themedも道路／空／海の可変テーマ。カード仮名を本編唯一の固定タイトルと呼ばない。
- p3-space／p3-driveはcategory上perspective3dのままだが、現行の本体はmakeRoadGameを共有する。39の差別化方向はカード側の選択であり、別の本編操作エンジンがあるという主張ではない。
