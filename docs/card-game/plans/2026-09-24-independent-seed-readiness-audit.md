# 独立新seedの通常プロキシ対戦・balance検証への移行監査

監査基準: PR #259 の保存HEAD `3adcfe98f544a795b34b089cb3fde84c3f86a9e1`、tree `aa9a7fa8a8d39e221b3726a2b237e4db36e5c31e`。134までの旧4経路は再実行していない。コード・正本・保護済みJSONの変更はない。

## 判定

**新しい独立seedをそのまま投入して、通常対戦の完走と独立balance標本の算入まで一意に実施する準備は未完了。** 固定4経路の完走は、その初期順と経由stateで必要になった契約の成立を示す。未知の初期順・盤面・反応窓全般の網羅性を証明しない。新seedの対戦結果や勝率を作らず、この監査地点で停止する。

## 次の境界

1. 新seed投入前に、107の同じA/B各40枚を対象とするseed一覧・全40枚manifest・先後鏡像・独立性を事前固定し、成功したseedだけを採用しない。旧4経路の停止証拠や112未実施fixtureは変更しない。
2. 少数の新seedを**基盤耐性の探索**として実行すること自体は、R1のseed抽選と真正停止を認めるなら別設計で可能。ただし116により独立balance標本は0であり、勝率・先後差・カード強度の根拠にはできない。既存runnerの固定入口とresponse未到達処理を接続する実装・検証が要る。
3. 独立balance標本を得たい場合は、たまご交換などの比較不能な選択を抽選する現行116契約、または標本算入条件について新しい判断が要る。候補間の優劣を根拠なく追加したり、既知seedで都合のよい完走だけを採用したりしない。現時点で複数の設計方向があるため、これを勝手に裁定しない。

新規seedの対戦fixture・decision・event・snapshot・winner・balance標本はすべて0。カード本文・数値・登録区分の変更0。PR #259はDraft・open・未マージのまま。117旧テストの件数期待値差1件は134検証の既知問題として分離する。
