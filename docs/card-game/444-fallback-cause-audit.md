## 結論

新方式182/241のfallbackは、**旧方式の時優先による確定128件、安全な無料配置による確定46件、旧方式から未解決の8件**に集約できる。増加分は174件。72件の旧方式適用限界はこの母数に混ぜていない。

414は時の単独先行順位を外したが、現在の比較証拠生成は通常pairの手札・盤面・予約を一律`incomparable`とする。したがって、上位3項目と116の限定的な安全配置証明を通過した候補の大部分に優越辺が付かず、広いfrontierがseedへ渡る。これは**順位変更と証拠生成の粗さが組み合わさった結果**であり、SHA抽選の不具合でも、182件の個別実行不足でもない。

ただし、粗い証拠を細分化すれば戦略的優越まで証明できるとは限らない。手札・予約を仮に全てequalへ緩めた診断でも182件全てでfallbackが残り、frontier変更0。盤面の将来価値の未知が残る。**既存正本だけでfallbackを減らせる比較証明は今回の監査では確立できなかった。** 任意点数・誕生優遇・時優先復帰・新方式採用は行っていない。

## 4. 実装不足と仕様限界の切り分け

### 証拠生成責務

`proxy_resource_value_shadow._inputs`の通常pair88組と`proxy_continuation_candidates.problem`の通常pair1,369組が、frontier内の全1,457組を構成する。両経路ともhand/board/reservationsは3成分すべてincomparable。時だけは750組で左worse、415組で左better、292組でequal（左右はID順であり政策優劣ではない）。**明示されたbetter/worseの資源間tradeoffを解決できなかった記録ではなく、資源価値を順位付けする証拠自体が未確定の記録**である。

上位比較、全pair coverage、frontier計算、seed証跡は再計算で一致した。構造エラーを抽選で隠している証拠はない。本文に効果・コストが書かれていることと、その効果の将来価値が他候補以上であることは別の命題である。

### 既存正本から導けるもの

- 414§5/7の「完全同値なら既存tie-break」は既に実装されている。未知をequalへ変える権限ではない。
- 116の安全な無料人物配置対passは既に適用されている。手札から場への移動を保持と扱う限定裁定を、有料誕生・セカイ・準備・装着へ広げない（414§6）。
- 同一の公開結果・残存義務・対象意味を立証できるなら成分の同値証明を作れる。しかし、対象が異なるだけで同値とはならず、現在状態で効果が発生しないだけで将来の義務を0扱いできない。
- 手札・予約の非変化をより細かく証明する余地はあるが、今回の感度検査ではその2成分だけを最大限緩めてもfrontier不変。削減効果が立証されないまま比較器接続を変更しなかった。

## 5. 利点と独立balanceへの境界

443で観測した盤面形成・成長増加は保存したまま。ただし増加174件の多くが、114では時で除外された行動をfrontierへ残した結果であり、fallbackを一律に縮めればその行動機会も変わり得る。**利点を維持したままseed依存を減らせた、という実測結果はまだない。** 採用・旧方式復帰とも未決定。

この8軌跡は固定初期2組×先後鏡像の4paired組で、旧AI対新AIの直接対戦ではない。独立balance標本0。116§4ではseeded / strategic unresolvedを含む対戦はbalance根拠へ加算できない。NORMALのfallbackだけを改善してもmandatory/responseの未解決は別に残るため、通常判断改善だけで独立balanceへ移行できたとは判定できない。

72件は441/443の47件（challenge/pass）・21件（安全配置/challenge）・4件（partner arrival）の適用限界をID付きで維持。選択強制・実停止・敗北への変換0。
