# 20 正式第0弾 — カードプール規模案

最終更新: 2026-09-14

状態: **収録総数・種類別比率の比較案。未確定。**

## 前提
- デッキ40枚固定。
- 通常同名3枚、レア同名1枚。
- 種類別固定枚数なし。
- Aは10/6/4/4/5/5/6、Bは16/5/3/3/4/4/5で機能した。
- A/Bはテストデッキであり、正式プール比率そのものではない。
- 正式第0弾では最低でも「メイン厚め人生型」「サポート厚め型」「ちょうせん型」「恋愛・盤面型」等、複数構築が可能であることを優先する。

# 総種類数の比較

## 56種案
40枚デッキに対して1.4倍。覚えやすく制作負担は軽いが、通常カード3積みをすると選択肢が急速に狭くなる。7種類すべてを使いながら複数アーキタイプを作るにはやや窮屈。

## 72種案
40枚の1.8倍。初弾として扱いやすく、各種類に複数の役割を持たせられる。カード本文・イラスト・バランス検証の制作量もまだ現実的。

## 80種案
40枚の2倍。構築自由度は高いが、初弾から80能力を整えると重複効果や把握負荷が増えやすい。なおとっちはメイン1キャラが8段階を持つため、メイン枠だけで種類数を大きく消費する点にも注意。

## 96種以上
初弾としては過剰。拡張余地を残す意味でも現時点では不要。

# 推奨: 72種

## 種類別
- メイン **24**
- なかま **10**
- こいびと **8**
- セカイ **6**
- あそび **8**
- あいてむ **8**
- できごと **8**
- 合計 **72**

# 24メインの考え方
メインは段階カード1枚ごとを1種類として数える。

24枚なら、単純には「8段階フルセット×3キャラ」。ただし正式第0弾を本編解禁連動にする場合、3キャラだけでは8属性の広がりが弱い。

したがって24は**最低推奨枠**であり、実際の第0弾で本編キャラを広く見せたいならメイン32（8段階×4キャラ）へ増やして総80種にする案も有力。

ただし、各キャラ8段階をすべて同時収録する必要があるかは別論点。ゲーム本編で出会った・育てた段階だけカード解禁する思想なら、初期プールに全段階を均等収録しなくてもよい。

# 72種案の利点
1. 40枚に対して十分な選択肢があり、同じA/B型だけになりにくい。
2. なかま10で3枠の組み合わせが生まれる。
3. こいびと8で人物の個性や能力方向に最低限の幅が出る。**66追記:** 旧「恋愛タイプ」の幅は収録基準に使わない。カード側に性別・恋愛対象を割り当てない方針を反映した表現修正で、72／80種の旧案・枚数を変更するものではない。
4. セカイ6なら「常に同じ最強セカイ」を避けつつ覚えやすい。
5. アクション24枚（8/8/8）で、すぐつかう／みにつける／しかけるの役割を分散できる。
6. 第1弾以降へ明確な拡張余地を残せる。

# 80種案に上げる条件
メインを24ではなく32必要と判断した場合、総80種を推奨する。

その場合:
- メイン32
- なかま10
- こいびと8
- セカイ6
- あそび8
- あいてむ8
- できごと8
=80

つまり、72 vs 80の本当の論点は**第0弾でメインを24にするか32にするか**であり、サポート48枚は共通案とする。

# 56種を推さない理由
メインを24確保すると残り32しかない。6種類へ平均5枚程度となり、40枚構築で毎回似たサポートが入りやすい。A/B模擬でサポート側の違いが段階選択を大きく変えたため、正式プールではサポート48程度ほしい。

# 現時点の推奨
**第0弾72〜80種。サポート48種を基準に、メイン24か32で最終決定。**

総数を先に72へ固定するより、次に「第0弾で何キャラ／何段階のメインを見せるべきか」を決め、その結果24なら72、32なら80とする。
