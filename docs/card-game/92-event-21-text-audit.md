## 4. 残る監査

40局面は合法性・個体追跡・予約・期限・不足の机上確認。全種類の意味上の重複、手札とそだちの効率、対戦結果の検証は別途必要。

- 交際0でデートを繰り返す時1ドロー＋5、だいおういかの敗北後反復、R5のお祝い複数枚、花の予約積み重ねは、コスト・同名制限の個別調整候補として実測する。名前だけで試合1回にはしない。
- とりいの上7／二世界、未来の自分の段階探索、アルバム／なおと／終盤の山札整理は既存あそび・アイテムと密度を比較する。完全同文なしは意味の重複なしを意味しない。
- すれちがいは手札戻しによる関係終了を供給する。こいびとを捨て札へ置く供給とは別。相手メインの捨て札除去／手札戻し、なかま除去は依然未充足で、びょうきを別効果へ変えて埋めない。
- 73 V01、75 V02、84 A83-01は大量プロキシ前に整理する。HOLD13、新12／旧24、legacy4、quick等を含む母集団の整理を飛ばして「477枚全て完成」と呼ばない。
