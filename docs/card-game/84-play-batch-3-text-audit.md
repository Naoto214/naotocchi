## 4. 監査中に明確化した点と残る問題

- サブマリンは「追加で実際に払った時」を探索数に使う初案を見直し、発動時に選んだ増加数を参照する本文へ修正。63の増減合算・最後に0下限を適用し、軽減だけを先に丸めない。X11が修正後の確認。
- 五目ならべで、相手効果によるそだち減少を具体化。うちゅうフライト・ハリネズミ・改良後いのちのくすりへ実在する本文の経路を接続した。メイン除去・関係終了等の別の供給問題まで解決した意味ではない。
- どうぶつしょうぎの捨て札は手札コスト等から用意できる。なかま満員交代の退出先73 V01を勝手に補わない。75 V02も引き続き残る。
- **A83-01：既存2048の短文の境界。** 08と13は同種2枚の交換を示すが、08本文には「発動コスト」「そうしたなら」の明記がない。今回のP06は同種2枚が揃う通常処理だけを確認した。追加コストか解決時の処理か、同種2枚が不足した発動／解決時の扱いを、63の支払いと01の部分処理に照らして全体監査で明文化する。新バブルの明記を2048へ自動適用せず、保存済み本文を「すべての境界が確定済み」と扱わない。新しい基本ルールの承認待ちではなく、既存カードの本文・裁定の追従事項。
- 五目の複数使用による維持妨害、相手の減少防止との密度、スキージャンプの事前準備に対する+3、テニスの終了ドロー、回収・山札掘り・同種3枚のドロー効率は実測課題。追加得点を全体+10で切らない。
- 探索の公開範囲・停止判断が物理カードで分かりやすいか、同種参照がメイン偏重構築を過度に有利にしないかもプロキシで評価する。ダーツ・カタパルト等の除去密度は全100の本文後に横断監査する。
