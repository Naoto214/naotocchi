# 最重要: 幼虫①〜③をカードでどう差別化するか

ここが16枚で最も危険。

現実にカブト・クワガタとも幼虫は白〜クリーム色の甲虫幼虫で、成虫ほど一目で差を出しやすくない。したがって**生物本体だけを真正面・無背景でカード中央へ置くと、カード一覧で混同しやすい**。

カード版では、キャラクター自体を別生物へ改造するのではなく、**生態の場面を構図に含める**。

### カブト幼虫
- 腐植質・柔らかい土の中を感じる丸い空間。
- 体の丸み・太さ・蓄える印象。
- ③では特に「まるまる」の量感を強調。

### クワガタ幼虫
- 朽ち木・木の繊維のトンネル感。
- カブトより長く低い輪郭。
- 顎・硬い頭部・木を削って進む印象を強調。

**背景は種を区別するラベルではなく、その生物がどう生きているかを見せる舞台として使う。**

# 成虫⑤〜⑧のカード構図差

## カブト
カード全体の視線を**前・上方向**へ向ける。
- ⑤: 羽化直後、角はあるがまだ柔らかい。
- ⑥: 前へ歩く、勢い。
- ⑦: 角を最も堂々と見せる。全盛期。
- ⑧: 脚を畳み、角は残るが静かな存在感。

キーワード: **押す / 持ち上げる / 進む / 変わる / 全盛期**。

## クワガタ
カード全体の視線を**前・左右へ挟み込む方向**へ向ける。
- ⑤: 羽化直後、大あごの存在が初めて強く出る。
- ⑥: 低い姿勢で相手を見る。
- ⑦: 大あごを大きく開き、左右から挟む構図。
- ⑧: 大あごを閉じ気味にし、低く落ち着く。

キーワード: **挟む / 構える / 捉える / 待つ / 競り合う**。

# 能力テーマの分離

## カブトムシ: 「かわる／いつ進むか」【維持】
Bテストで成立済み。

- ③に留まる。
- ④の弱いさなぎを通る。
- ④を飛ばして⑤へ急ぐ。
- ⑦全盛期10/4に留まる。
- ⑧6/6へ進んで柔軟性を取る。

カードを出す順番そのものが人生戦略になる。

## クワガタムシ: 「かまえる／はさむ」【新規候補】
カブトと同じ「高ちから＋進化効率」にはしない。

基本体験候補:
**相手を見る → 構える → 相手が動く → 捉える／押し返す**。

カードゲーム上は以下を中心にする。
- 相手のちょうせんや対象指定へ反応する。
- 自分から毎回殴るより、相手の行動を読んで利益を取る。
- 「挟む」は完全ロックではなく、対象を一時的に固定する／選択肢を狭める／反応時に数値を変える等で表現。
- 専用カウンターや長期ロックは増やさない。
- カブトの「いつ段階を進むか」と操作感を明確に分ける。

### 仮の人生連作
①潜る → ②探す → ③待つ → ④構える準備 → ⑤大あごを得る → ⑥相手を見る → ⑦挟んで競る → ⑧無理に動かず受ける

これは能力本文ではなく、8枚を作るための生態・ゲーム軸。

# 数値設計

## カブト
Bテストで使った曲線を引き続き比較基準とする。
- ③ 5/3
- ④ 1/4
- ⑤ 5/3
- ⑦ 10/4
- ⑧ 6/6
等、さなぎで落ち、全盛期でちからが突出し、⑧で均衡へ戻る。

## クワガタ
**まだ正式な8段階数値を作らない。**
カブトの数字を横滑りさせず、「かまえる／はさむ」という反応型能力を先に作り、その能力価値を見て数値曲線を逆算する。

候補傾向:
- カブト⑦より単純ちからピークは低くしてもよい。
- 代わりに相手ターン・反応時の実効値や選択制御で強みを出す。
- ⑥〜⑧は大あごの派手さだけで直線的に強くしない。

# 合格基準
16枚を並べて以下を満たすこと。

1. 同じ種の①〜⑧を名前なしで概ね順番に並べられる。
2. 同段階のカブト／クワガタを名前なしでも区別できる。
3. ⑥／⑦／⑧が色違いではなく姿勢・体格で違う。
4. 幼虫①〜③が単なるサイズ違いではない。
5. ④→⑤の劇的変化がカード上でも「人生の節目」に見える。
6. ⑦がコレクション上の見せ場になる。
7. ⑧が弱々しいだけでなく「長く生きた個体」として魅力がある。
8. 能力を隠してもカブトは「進む・変わる」、クワガタは「構える・挟む」の雰囲気が絵からある程度伝わる。
9. 能力を読めば「なぜこの生物か」を説明できる。
10. 16枚のどれも「同じカードの数値違い」に見えない。
