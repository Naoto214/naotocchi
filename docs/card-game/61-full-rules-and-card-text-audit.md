- **トイレットペーパー:** 08の「メインが捨て札になるなら発動」は、相手効果の解決中にその出来事が来る場合、06の解決中割込み不可にぶつかる。元効果の発動時に準備するのか、すでに有効な置換なのかを明確にする必要がある。即時置換と発動するしかけを混ぜない。
- **サクラ⑥・たぬき:** 準備枠→発動領域という移動の後に「そのカードの発動／効果適用」を追う。07の領域移動後の新しい個体扱いに対し、この移動を追う例外の範囲をカード本文で明示する必要がある。
- **サル:** 共通コピー裁定は復元できたが、「自分メインが発動した能力をコピー」の発動時点・コピーする対象・コピー後に改めて発動条件を満たす必要を正式本文にする必要がある。コピーしただけでたんじょう・ちょうせんを再発生させない。
- **とかい（63追記）:** 08の「そのターン2枚目のカードを使った時」は、アクションのプレイ、通常の人物・セカイ・メイン配置、能力の発動のどこまでを数えるか不明。63では他カードの「プレイ」を整理したが、とかいを黙ってアクション2枚限定にせず、セカイ本文の正式化に残す。

## 4. 不具合と断定せず、実戦で確認する強度・運用

### カブト④の同ターン通過

16は④経由を「弱い1ターンを受け入れる」と評価した。しかし、移動回数制限はなく時0まで軽減できるので、④を必ず相手ターンまで維持する設計ではない。

意図されているコスト処理では、③→④の時1、④→⑤の差分1−軽減1=時0で、③→⑤直行の時2より1少ない。同ターン通過は④カード1枚を余分に使い、その後のときとばし制限を受ける。**④滞在／同ターン通過／飛ばし**を別ルートとして試す。63で軽減を任意のコスト修正へ改稿した。③の留まる能力を使っていないことが前提であり、③の禁止を無視しない。カブト④へ新たな「1ターン待機必須」は追加していない。確定した共通手順に従い、各段階へ移動するたびに反応を処理してから次の通常行動へ進む。

### 同名・別個体・コピー・予約の重なり

- 1ターン1回はカード個体ごと。同名全体制限とは別。出し直し・別段階・コピー・回収を含めた全体のループ不在はまだ証明していない。
- カワウソを複数並べて各能力を適用する等、基本+5と追加報酬が複数重なり得る。「条件付き合計+10可」を、全カード共通の最大+10上限と読み替えない。
- れんの軽減3段階、海の手札交換密度、猫の一戦補助密度は完全同文ではなくても、操作が同じになるか要試験。
- レアの基礎値平均は通常より高い。能力を使わない高基礎値だけで有利すぎるか、低段階・直接たんじょう・各種経路を比較する。読解だけで数値を下げない。
- おばけの複数予約、世界樹等の複合条件は紙での追跡負荷が残る。専用カウンターを増やさないことだけでは処理が軽い証明にならない。
- U01の伏せ情報、U02〜U05の境界裁定が未解決のまま勝率を大量生成しても、選んだ実装上の仮定の勝率にしかならない。
