# 初回観察結果

## 1. 人生開始
16/40がメインで①が2枚、②も2枚あるため、Aより明確に早く人生を始めやすい。たまごで高段階を山札下へ戻しながら低段階を探す行動も意味を持つ。

Bでは「メインが来ない」より、**手札に複数段階がある時どれを今出すか**が問題になる。これは狙いどおり。

## 2. ときおくりの差分コストは強い
低段階から開始すると、後で同種族の高段階を引いた際に差分時だけで進めるため、直接高段階を待つより行動可能ターンを確保しやすい。

ただし毎回1段階ずつ刻むのが最適にはならない。例えば③から⑤を持っている時、④を通るためだけに④カードと時を使う意味がなければ③→⑤が自然。このため**中間段階の固有能力が経由価値を決める**という設計思想が実戦上かなり重要。

## 3. カブトムシ③／④／⑤
数値だけなら③=5/3、④=1/4、⑤=5/3。したがって④へ入ることは明確な短期損失。

現段階では④の保存済み方向「通った後の経路価値」が具体本文になっていないため、③→⑤で④を飛ばす方が自然になりやすい。これはルールの問題ではなく、**④能力本文がBの最重要設計点**だと確認できた。

ただし④経由を恒常的な大幅強化にすると逆に「必ず④を通る」が正解になる。必要なのは、
- ④を通る = 後で安定／柔軟性
- ④を飛ばす = 今すぐ⑤以上へ到達
という時間軸の交換。

## 4. カブトムシ⑦→⑧
⑦10/4は数値ピーク、⑧6/6はバランス型。ちから勝負を続けたい盤面では⑦に留まる理由が非常に明確。

一方、相手がちえ型へ寄った時や、⑧の過去利用能力を使いたい時には⑧へ進む余地がある。**⑧能力が「ちから4を失ってでも欲しい」程度には必要だが、常に進むほど強くしてはいけない。** 曲線自体は良好。

## 5. 人⑥→⑦→⑧
人⑥7/7は万能、⑦5/8、⑧3/9と徐々にちからを失う。数値だけなら⑥に留まる魅力がかなり強い。

ここも⑦=過去の経験を活かす、⑧=次へ残す、という能力方向が具体的な選択価値を持つ必要がある。逆に言えば、数値曲線は「進めるのに進まない」を自然に作れている。

## 6. へんしん
同種族ときおくりは差分時、別種族へんしんは変身先段階の通常時を払うため、素の状態では同種族継続がかなり効率的。

シルクハット／うんめいのへんしんがある時だけ、別種族へ移る選択が現実的になる。この構造は良い。ただし両方が同時に重なると軽減が大きいため、時コスト最低値の未確定論点が実際にBで重要になり得る。

現時点では新ルールを作らず、両方が重なる具体場面が発生した時だけ裁定する。

## 7. 留まるカード
とかい、もり、恋愛、おはな、キャッチボール等により「今すぐ段階を上げず、そのターンの時を盤面や成果へ使う」選択が成立する。

これは非常に重要で、基本ルールに留まるボーナスを追加しなくてもカードプール側で留まる価値を作れることを確認。

# 初回Bで判明した設計優先順位

Bをさらに回す前に、16枚のメイン能力を具体本文にする必要がある。能力方向だけのままでは「通る／飛ばす」の本当の比率を測れない。

優先順位:
1. **カブトムシ④** — B全体の核心。③→④→⑤と③→⑤を両方正解にする。
2. **カブトムシ⑤・⑥** — ④経由の価値を受ける側。ただし④参照だらけにしない。
3. **人⑦・⑧** — ⑥7/7に留まる選択との比較。
4. **カブト⑧** — ⑦10/4に留まる選択との比較。
5. その他①〜⑥ — 人生を刻む理由を作るが、全段階を必須経路にしない。
