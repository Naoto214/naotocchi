# 02 メインカード・ちょうせん・8属性

## たまご／たんじょう
開始時メイン枠はデッキ外の「たまご」。発見済みかつ手札にある好きな段階のメインを通常時コストで「たんじょう」でき、①経由不要。

**通常時コスト【確定】:** メインの通常時コストは段階番号と同じ。`①=時1 / ②=時2 / ③=時3 / ④=時4 / ⑤=時5 / ⑥=時6 / ⑦=時7 / ⑧=時8`。したがって高段階を直接たんじょうするには、その段階番号ぶんの時を支払う。

たまご固有能力: ターン開始時、通常ドロー後もたまごならさらに1枚引き、手札1枚を山札一番下へ戻す。非公開、シャッフルなし、手札枚数は増えない。

## ときとばし【ルール確定／名称暫定】
同種族の**後段階**へ段階差ぶんの時で進む。例: サクラ③→⑥=時3。同種族の過去段階へ直接戻れない（④→②不可）。必要な時がある限り共通回数制限なし。名称「ときとばし」は第一候補だが最終未確定。

飛ばした中間段階は「経由した」扱いにしない。中間段階のカードは場にも捨て札にも置かれず、その段階固有能力も発動しない。実際にその段階へ進んだ場合だけ経由として扱う。

## へんしん【確定】
別種族へ変更する行為そのもの。変身先段階の通常時コスト、すなわち**変身先の段階番号ぶんの時**を支払う。専用へんしんカード不要。必要な時がある限り共通回数制限なし。へんしんしても恋人関係・交際経過・結婚状態は原則維持。

## メイン除去
メイン→捨て札、メイン枠→たまご、メイン装備→捨て札。なかま・こいびと・セカイ・メイン以外への装備・しかけは残る。再登場は通常たんじょう。メイン1体制なので除去は高コスト／厳条件等で重くする。

## ちから／ちえ【確定】
**ちから＝人生を切りひらく力。** 身体能力だけでなく、行動する・挑戦する・耐える・踏み出す・やり遂げる・世界へ働きかける力。

**ちえ＝人生を選びとる力。** IQだけでなく、考える・気づく・覚える・判断する・工夫する・経験を活かす・相手や状況を読む力。

- 印刷基礎値: **1〜10**。基礎0は作らない。
- 対戦中: 効果で増減。最低0、上限なし。
- 10は象徴的な最高クラスとして安売りしない。
- 補正目安: ±1小、±2大きめ、±3以上は強力／条件付き。
- ①〜⑧で自由に上下。高段階ほど両方高いとは限らない。
- 種族ごとに独自の人生曲線。合計値固定なし。
- 隣接段階では原則どちらかを変えるが絶対ルールではない。
- 低数値＝弱カードではない。時、能力、経由価値、シナジー等で価値を作る。

## ちょうせん【確定】
相手を傷つける攻撃ではなく、同じ100年を生きるライバルと競う人生経験。

1. メインは**自分ターン1回まで**ちょうせん可能。任意。
2. 挑む側が「ちから」か「ちえ」を選ぶ。
3. 相手は拒否できない。
4. 選んだ同じパラメータ同士を比較。
5. 勝敗確定前に、しかけ・条件付き能力等で反応／連鎖可能。
6. 逆順解決後の最終値を比較。
7. **高い側が勝ち、そのプレイヤーのそだち+5。** 挑戦側／受け側を問わない。
8. 同値は引き分け。双方そだち変化なし。
9. 数値差による基本追加報酬なし。僅差・大差等は個別カード能力へ譲る。

数値差は逆転のしやすさとして自然に機能する。通常ちょうせん自体に時コストは現状なし。ちょうせんだけでは10ラウンド最大+50なので、初期20→100には他の人生成果も必要。

**未確定:** たまごがちょうせん可能か／対象になるか／ちから・ちえを持つか。

## 8段階／固有能力【確定方針】
- メイン①〜⑧は別カード。
- 原則各カード固有能力1つ。高段階・レアだから文章量を増やして強くしない。
- **8枚の別カードであり、同時に8枚の連作。** 並べた時にその種族の一生が能力として見えるよう設計。
- 特定段階を経由した時だけ追加価値を得る能力を作ってよい。高段階直接たんじょうと、低段階から人生を積む双方に価値を作る。
- 全8段階を順番に通ることを唯一の正解にしない。
- 状況により「今の姿を維持／先へときとばし／別種族へへんしん／周囲のカードで補う」を選ばせる。

## 8属性【確定】
属性数・所属は確定。「みずべ」のみ、より良い名称が見つかれば名称だけ変更可。

| 属性 | 所属種族 |
|---|---|
| **ひと** | おとこのひと、おんなのひと、れんくん |
| **けもの** | いぬ、ねこ |
| **みずべ** | ペンギン、かめ、かえる、さけ |
| **うみ** | カクレクマノミ、ヤドカリ、クラゲ、ヒトデ、サンゴ |
| **むし** | ちょう、カブトムシ、クワガタムシ、セミ、アリジゴク |
| **くさ** | タンポポ、サクラ、ハエトリグサ、キノコ、世界樹 |
| **げんそう** | りゅう、フェニックス、かみさま、おばけ |
| **ふしぎ** | ほし、ぬいぐるみ、？？？ |

属性と種族は別軸。同属性の別種族へ移る場合も「へんしん」。

### 固定属性相性なし【確定】
「くさはうみに強い」等の基本有利不利表は作らない。属性は、①分類、②複数種族を横断するシナジー、③得意戦術、④個別能力の参照情報、として使う。属性メタは必要なら個別カードで作る。

### 属性は能力を独占しない【確定】
得意分野は作るが、その属性だけが基本行動を使えるようにはしない。例: むしはときとばし活用が得意でも、全属性が通常ときとばし可能。

### 戦術アイデンティティ【代表テスト第一周済み／横断監査後に最終確定】
- **ひと＝えらぶ:** 選択、ちから／ちえ使い分け、なかま、こいびと、柔軟性。
- **けもの＝いどむ:** ちょうせん、あそび、能動行動、即効性。
- **みずべ＝わたる:** セカイ変更、複数環境、旅、適応。
- **うみ＝ながれる:** へんしん、手札循環、入替、対象変更、自身の柔軟な変化。
- **むし＝かわる:** ときとばし、段階参照、変態、どこで留まるか。
- **くさ＝そだてる:** 準備、継続、盤面形成、予告された後の成果。
- **げんそう＝こえる:** 再生、終盤、高い時、重条件で通常の限界を越える。
- **ふしぎ＝くつがえす:** ちから／ちえの扱い、引き分け、低数値、たまご等、ルールの見方を変える。

この一語テーマはプレイヤーに覚えさせる正式用語ではなく内部設計指針。

## げんそう／ふしぎの差
げんそう=物語・伝承・超自然の人格的存在。「普通の人生の限界を条件付きで越える」。ふしぎ=普通の生命分類や人生観では捉えにくい存在。「普通のルールの見方を変える」。統合しない。

## みずべ／うみの差
みずべ=世界・環境を**わたる**。うみ=自分自身が**ながれる／変わる**。代表テストでは別戦術として成立。8属性横断監査で最終確認する。
