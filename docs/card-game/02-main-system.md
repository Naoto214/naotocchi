# 02 メインカード・ちょうせん・8属性

最終更新: 2026-09-14

## たまご／たんじょう
開始時メイン枠はデッキ外の「たまご」。発見済みかつ手札にある好きな段階のメインを通常時コストで「たんじょう」でき、①経由不要。

**通常時コスト【確定】:** メインの通常時コストは段階番号と同じ。`①=時1 / ②=時2 / ③=時3 / ④=時4 / ⑤=時5 / ⑥=時6 / ⑦=時7 / ⑧=時8`。したがって高段階を直接たんじょうするには、その段階番号ぶんの時を支払う。

**たんじょう時のカード移動【確定】:** たまごはデッキ外カード。たんじょう時、たまごをメイン枠からデッキ外の**たまご置き場**へ戻し、手札の新メインをメイン枠へ置く。たまごは捨て札に行かない。

たまご固有能力: ターン開始時、通常ドロー後もたまごならさらに1枚引き、手札1枚を山札一番下へ戻す。非公開、シャッフルなし、手札枚数は増えない。

**64開始手順との接続:** 自分の通常ドロー直後に確認し、開始時の予約ドローやその他の発動より先に、この追加ドローと山札下への移動を続けて行う。途中に通常たんじょうや別発動を挟まない。山札不足でも01の一部実行不能裁定に従い、引ける分だけ引き、手札があれば1枚を下へ戻す。「引けた場合だけ戻す」という条件はない。通常ドローと追加ドローの双方が不発でも、手札の返却だけは行い得る。局面は[64 S02・S03](64-turn-boundaries-and-victory-timing.md)。

**たまごとちょうせん【確定】:** たまごはまだ人生が始まっていない待機状態として扱い、**ちから／ちえを持たない**。たまごからちょうせんを行うことはできず、相手からちょうせんの対象にもされない。たまご状態を維持すると手札調整能力を使える一方、自分もその間ちょうせんによるそだち獲得機会とメイン固有能力を使えない。たまご籠もりの強さは模擬対戦で検証し、問題が出た場合はまずカード／能力側の調整を優先する。

### たまご状態と周辺カード【確定】
- **こいびと:** カード自体と交際／結婚状態は盤面上保持するが、たまご中はこいびとの能力を無効にし、交際①→②→③等の進行も停止する。メインがたんじょうしたら、保存していた交際／結婚状態から再開する。結婚済みから復帰しても再結婚ではないため、結婚成立時のそだち+10や「結婚した時」能力を再取得・再発動しない。
- **なかま:** たまご中も能力は原則有効。ただしメインを対象・参照する部分は、メインが存在しないため機能しない。
- **セカイ:** たまご中も能力は原則有効。ただしメインを対象・参照する部分や、メインを必要とする条件は成立しない。
- **「しかける」で準備枠に置かれたアクションカード:** たまご中も盤面に残り、条件を満たせば原則発動可能。ただし「あなたのメインがちょうせんされた時」等、メインを必要とする条件は成立しない。
- メイン以外に「みにつける」で置かれたカード等も、既存の対象が残っている限り原則そのまま残る。

たまごを「死亡した別個体への転生」とは基本ルール上定義しない。メインとして活動できない待機状態として扱い、周辺の人生世界は上記ルールに従って継続する。

**たまご自体はカード効果で除去・移動・奪取できない【確定】。** たまごはデッキ外の基礎ゲーム状態として扱う。たまご状態のプレイヤーに対する限定的な干渉（例: たんじょうコストへの一時的な修正等）は個別カード効果として作成できるが、複数ターンにわたりたんじょうを封じる等の「たんじょうロック」は危険設計として厳しく監査する。

## ときとばし【確定】
同種族の**後段階**へ段階差ぶんの時で進む。例: サクラ③→⑥=時3。同種族の過去段階へ直接戻れない（④→②不可）。必要な時がある限り共通回数制限なし。正式名称は**「ときとばし」**。

**ときとばし時のカード移動【確定】:** 実際に進む直前の現在メインを捨て札へ置き、手札の後段階メインをメイン枠へ置く。

飛ばした中間段階は「経由した」扱いにしない。中間段階のカードは場にも捨て札にも置かれず、その段階固有能力も発動しない。実際にその段階へ進んだ場合だけ経由として扱う。

## へんしん【確定】
別種族へ変更する行為そのもの。変身先段階の通常時コスト、すなわち**変身先の段階番号ぶんの時**を支払う。専用へんしんカード不要。必要な時がある限り共通回数制限なし。へんしんしても恋人関係・交際経過・結婚状態は原則維持。

**へんしん時のカード移動【確定】:** 現在のメインを捨て札へ置き、手札の変身先メインをメイン枠へ置く。変身元は手札へ戻さない。

## 通常のメイン移動の実行時点【確定】

- 通常のたんじょう・ときとばし・へんしんは、[01](01-core-rules.md)の**自分の行動機会**に行う。相手ターン、連鎖の構築・解決中、ちょうせん中には通常行動として挿入できない。
- 現在メインと手札の行き先を示し、条件・時を確認する。宣言・計算・支払い・移動を途中に別発動を挟まず終え、離脱・到達で成立した能力を[06](06-action-chain-checkpoint.md)の順序で発動する。
- 各移動後の誘発・反応を終え、自分の行動機会へ戻ってから次の移動を選ぶ。ときとばし・へんしんの共通回数制限はなく、個別の禁止がなく時と手札があれば、同ターンに複数の移動を行える。
- 例: カブト③の留まる能力を使っていなければ、③→④へ時1で進み、反応を処理した後、④の任意軽減で⑤へ時0で進める。④を相手ターンまで維持する義務はない。今回の⑤への移動終了後に、④の本文どおり当ターン以後のときとばしを禁止する。
- カード効果が配置・移動を明確に指示する場合は、その効果の処理に従う。効果による移動と、反応機会に通常行動を追加することを区別する。

通常移動自体は発動した効果ではない。到達能力を無効にされても完了済みの移動は巻き戻らない。63の確定記録と共通の支払い手順を併せて使う。

## メイン移動のカード文語彙【確定】
- **「たんじょうした時」:** たまごから手札のメインをたんじょうした時だけ。
- **「この段階になった時」:** たんじょう／ときとばし／へんしん／その他の効果等で、その段階のカードが実際にメイン枠へ置かれた時。直接たんじょうなら「たんじょうした時」と同時に成立する。
- **「ときとばしで、この段階になった時」:** ときとばしによって実際にその段階へ入った時だけ。飛ばした中間段階では成立しない。
- **「へんしんで、この段階になった時」:** 別種族へのへんしんによってその段階へ入った時だけ。
- メインカードには原則として曖昧な**「場に出た時」**を使わず、上記の具体語彙を使う。
- **「経由」**は設計・説明用語としては使用するが、カード本文の共通キーワードにはしない。過去履歴をプレイヤーの記憶だけで追わせず、原則として移動した瞬間に処理する。

## メイン除去【確定方針】
メイン→捨て札、メイン枠→たまご、メイン装備→捨て札。なかま・こいびと・セカイ・メイン以外への装備・「しかける」で置かれたアクションカードは残る。再登場は通常たんじょう。

**メイン除去後のたまご処理【確定】:** デッキ外のたまご置き場からたまごをメイン枠へ戻す。

メイン1体制のため、相手メインの除去は通常の妨害ではなく**大技**として扱う。ただし、メイン除去そのものに共通の固定時コストは設けない。個別カードごとに、時・発動条件・代償・その他の制限を合わせて重さを調整し、無条件除去は特に重くする。

段階が低いことだけを理由に除去を共通で安くするルールは作らない。一方、個別カードの条件として「④以下」「⑦以上」等の段階を参照することは許可する。段階による共通の除去コスト補正・耐性は作らない。

段階だけでなく、**ちから・ちえ・盤面状態等も個別カードの除去条件として参照可能**。例として「ちから3以下」「ちえが自分のメインより低い」等を作成できる。ただし、ちから／ちえの低さ・高さ等を共通の除去弱点／耐性にはしない。

**自分のメインを任意に捨ててたまごへ戻す基本行動は作らない。** 自分のメインをたまごへ戻す効果自体は、必要なら個別カード能力として作成できる。

メイン除去そのものには「このターン再たんじょうできない」等の再たんじょう禁止を内蔵しない。再たんじょうを制限したい場合は個別カード効果として明記し、その制限もカード全体の強さ・コスト評価に含める。

通常の再たんじょうも自分の行動機会に行う。除去の連鎖へ通常たんじょうを挿入せず、連鎖・ちょうせん等を終えてから、必要な時・手札・個別制限を確認する。

メイン除去も通常のカード効果と同じく反応・連鎖の対象となる。除去専用の防御判定や、ちから／ちえによる共通の耐性判定は追加しない。防御・対象変更・除去耐性等を作る場合は個別カード効果で表現する。

**メイン除去そのものには共通のそだち増減を付けない。** 除去した側の+5、除去された側の-5等は自動では発生しない。必要なら個別カード能力として設定する。

**メイン除去に共通の試合中回数制限は設けない。** ただし、除去→たんじょう→再除去を容易に反復し、相手を継続的にゲームへ参加させない「除去ロック」は危険設計としてカード設計・模擬対戦で重点監査する。問題が出た場合はまず個別カードのコスト・条件・再利用性を調整する。

なお、除去されてたまごへ戻ることが常に不利益とは限らない。現在のメインがちから／ちえ両方で大きく不利な場合など、ちょうせん対象外となり手札を整えて別のメインで再出発できることが利益になる場合もある。このため、除去する側にも「今この相手をたまごへ戻すべきか」という判断が生じる設計を許容する。

### メインが捨て札へ行く原因の区別【確定】
カード文では必要に応じて以下を区別できる。
- **「このメインが除去された時」:** 除去によって捨て札へ行った場合だけ参照する。
- **「このメインがメイン枠から捨て札に置かれた時」:** 除去だけでなく、ときとばし・へんしん等でメイン枠から捨て札へ移った場合も含む広い条件。

「メインを離れた時」のような新しい包括語は作らず、必要な移動元・移動先を明記する。メインが除去された時に共通で能力が発生する基本ルールは作らず、これらは個別カード能力の発動条件として使用する。

## ちから／ちえ【確定】
**ちから＝人生を切りひらく力。** 身体能力だけでなく、行動する・挑戦する・耐える・踏み出す・やり遂げる・世界へ働きかける力。

**ちえ＝人生を選びとる力。** IQだけでなく、考える・気づく・覚える・判断する・工夫する・経験を活かす・相手や状況を読む力。

- 印刷基礎値: **1〜10**。基礎0は作らない。
- 対戦中: 効果で増減。最低0、上限なし。
- 10は象徴的な最高クラスとして安売りしない。
- 補正目安: ±1小、±2大きめ、±3以上は強力／条件付き。
- ①〜⑧で自由に上下。高段階ほど両方高いとは限らない。
- 種族ごとに独自の人生曲線。合計値固定なし。
- 隣接段階では原則どちらかを変えるが絶対ルールではない。
- 低数値＝弱カードではない。時、能力、経由価値、シナジー等で価値を作る。

## ちょうせん【確定】
相手を傷つける攻撃ではなく、同じ100年を生きるライバルと競う人生経験。

1. **自分の行動機会に、自分ターン1回まで**ちょうせん可能。任意。双方のメインがたまごではなく、自分のちょうせん回数が残っていることを確認する。
2. 参加する双方のメインを確認し、挑む側が宣言時に「ちから」か「ちえ」を選ぶ。時0。
3. 相手は拒否できない。条件を満たしたちょうせん時の能力を発動し、[06](06-action-chain-checkpoint.md)どおり反応を処理する。
4. 自分に発動機会が来たら、すぐつかう・条件を満たす能力・しかけた札の発動で対応できる。通常のへんしん・配置・交際進行等は挿入しない。
5. 双方連続パスで逆順解決し、その解決中に成立した後続の誘発・反応も終える。解決中や比較後に、元の勝負への新たな補助を割り込ませない。
6. 宣言時に選んだ同じパラメータ同士で、処理後の最終値を比較する。
7. **高い側が勝ち、そのプレイヤーのそだち+5。** 挑戦側／受け側を問わない。
8. 同値は引き分け。双方そだち変化なし。
9. 数値差による基本追加報酬なし。僅差・大差等は個別カード能力へ譲る。

自分からのちょうせん1回は**プレイヤーの制限**であり、メイン個体の「1ターンに1回」とは別に管理する。メインが別個体へ入れ替わっても、プレイヤーのちょうせん回数はリセットしない。

上記の比較手順は参加メインが維持された場合。カード効果で比較前に参加メインが離脱・入替・領域移動して戻る場合は、[65](65-challenge-participants-and-resolution.md)に「宣言した個体で固定し、離れた場合は勝敗・得点なし、宣言回数と支払いを戻さない」共通案を保存した。**確認待ちであり、ここへ確定ルールとしては追加していない。** 比較前後の予約・結果・終了処理も同書の提案と局面を参照する。

### ちょうせんのカード文表記

- 自分から挑む条件は「このメインが自分からちょうせんする時」、受ける条件は「このメインが相手からちょうせんを受ける時」と明記する。
- 両方向で使う新規・改稿本文は「このメインが自分からちょうせんする時、または相手からちょうせんを受ける時」と明記する。65でおとこのひと⑥・ヒトデ⑥・フェニックス⑤をこの個別本文へ改稿した。旧無指定表記すべてに、暗黙の両方向許可を追加しない。
- 「自分がちょうせんした／していない」は自分からの宣言履歴。「自分がちょうせんに勝った」「このメインがちょうせんに勝った／負けた」は、自分からに限定する文がなければ、受けた勝負の結果も含む。勝敗と宣言した履歴を区別する。
- 「ちょうせんする時／受ける時」の発動機会は宣言後・比較前。「勝った時／負けた時」は比較で結果が出た後。能力値の選択は宣言時に終えており、その能力の解決時に選び直さない。06・07の既存の条件確認・領域移動・コピー規則を使い、後から現れた個体やコピーに宣言を再発生させない。

### 得点と挑む判断

数値差は逆転のしやすさとして自然に機能する。通常ちょうせん自体に時コストは現状なし。**自分から行う**ちょうせんは10ラウンドで最大10回、その通常勝利報酬は最大+50。ただし、相手から受けたちょうせんに勝った場合も+5を得るため、これは通常勝利報酬全体の上限ではない。通常勝利だけで初期20→100へ届く局面もあり得る。相手はちょうせんを見送れるので、受け側の報酬を毎ターン保証される収入としても扱わない。旧評価の訂正と再現例は[61](61-full-rules-and-card-text-audit.md)を参照。

## 8段階／固有能力【確定方針】
- メイン①〜⑧は別カード。
- 原則各カード固有能力1つ。高段階・レアだから文章量を増やして強くしない。
- **8枚の別カードであり、同時に8枚の連作。** 並べた時にその種族の一生が能力として見えるよう設計。
- 特定段階を経由した時だけ追加価値を得る能力を作ってよい。高段階直接たんじょうと、低段階から人生を積む双方に価値を作る。
- 全8段階を順番に通ることを唯一の正解にしない。
- 状況により「今の姿を維持／先へときとばし／別種族へへんしん／周囲のカードで補う」を選ばせる。

## 8属性【確定】
属性数・所属・名称を確定する。**「みずべ」も正式名称として確定**。

| 属性 | 所属種族 |
|---|---|
| **ひと** | おとこのひと、おんなのひと、れんくん |
| **けもの** | いぬ、ねこ |
| **みずべ** | ペンギン、かめ、かえる、さけ |
| **うみ** | カクレクマノミ、ヤドカリ、クラゲ、ヒトデ、サンゴ |
| **むし** | ちょう、カブトムシ、クワガタムシ、セミ、アリジゴク |
| **くさ** | タンポポ、サクラ、ハエトリグサ、キノコ、世界樹 |
| **げんそう** | りゅう、フェニックス、かみさま、おばけ |
| **ふしぎ** | ほし、ぬいぐるみ、？？？ |

属性と種族は別軸。同属性の別種族へ移る場合も「へんしん」。

### 固定属性相性なし【確定】
「くさはうみに強い」等の基本有利不利表は作らない。属性は、①分類、②複数種族を横断するシナジー、③得意戦術、④個別能力の参照情報、として使う。属性メタは必要なら個別カードで作る。

### 属性は能力を独占しない【確定】
得意分野は作るが、その属性だけが基本行動を使えるようにはしない。例: むしはときとばし活用が得意でも、全属性が通常ときとばし可能。

### 戦術アイデンティティ【正式確定】
- **ひと＝えらぶ:** 選択、ちから／ちえ使い分け、なかま、こいびと、柔軟性。主な問いは「何をする？」。
- **けもの＝いどむ:** ちょうせん、あそび、能動行動、即効性。主な問いは「まず動くか？」。
- **みずべ＝わたる:** セカイ変更、複数環境、旅、適応。主な問いは「どこへ行く？」。
- **うみ＝ながれる:** へんしん、手札循環、入替、対象変更、自身の柔軟な変化。主な問いは「今ある何を動かす？」。
- **むし＝かわる:** ときとばし、段階参照、変態、どこで留まるか。主な問いは「人生のどの段階を通る／飛ばす／留まる？」。
- **くさ＝そだてる:** 準備、継続、盤面形成、予告された後の成果。主な問いは「今何を仕込み、後でどう実らせる？」。
- **げんそう＝こえる:** 再生、終盤、高い時、重条件・代償で通常の限界を越える。主な問いは「何を払って限界を越える？」。
- **ふしぎ＝くつがえす:** ちから／ちえの扱い、引き分け、低数値、たまご等、普通なら不利・無価値な状態の意味や評価基準を変える。主な問いは「普通の価値をどうひっくり返す？」。

この一語テーマはプレイヤーに覚えさせる正式キーワードではなく、カード設計上の正式な戦術アイデンティティとして扱う。

## げんそう／ふしぎの差【確定】
げんそう=物語・伝承・超自然の人格的存在。「普通の人生の限界を条件付きで越える」。ふしぎ=普通の生命分類や人生観では捉えにくい存在。「普通のルールの見方を変える」。統合しない。

## みずべ／うみの差【確定】
みずべ=世界・環境を**わたる**。うみ=自分自身・手札・対象・状態が**ながれる／変わる**。別戦術として正式確定する。
