# 50 メイン248形態 数値横断監査 第1回

最終更新: 2026-09-14

状態: **31種族×8段階の仮数値曲線を横断集計した第1回監査。能力本文・バランス確定ではない。**

## 目的

42〜49までで31種族すべての人生テーマと仮数値曲線が揃ったため、個別に良く見えても全体で偏っていないかを数値だけ先に監査する。

確認項目:

- 属性ごとの平均ちから／ちえ
- 段階ごとの平均値
- 通常／レア／シークレットの基礎値差
- 象徴値10の頻度
- 完全に同じ8段階曲線の重複
- ⑦→⑧が単純上位互換になっていないか
- 極端に低い／高い総量の意味が種族テーマと一致しているか

ここでいう「総量」は8枚の `ちから+ちえ` を足した設計監査用の値で、対戦中の資源・勝利点ではない。

### 読み取り

- けものは現状もっともちから寄りの通常属性。
- くさ・うみはちえ寄り。
- むしは平均合計が低い。蛹・まゆ・待機等の明確な弱い段階を複数含むためで、**能力・経路価値で埋める前提**。数値だけを他属性平均へ引き上げると「かわる」の谷が消える。
- げんそうは全4種がレアで高基礎値。属性平均とレアリティが完全に重なっているため、「げんそうだから高い」と「レアだから高い」を分離して今後監査する。
- ふしぎも全3種レアだが、？？？の低総量やぬいぐるみの低ちから等があり、単純高性能にはなっていない。

### 読み取り

全体として、

`①〜⑥: 身体・行動力も含めて成長 → ⑦〜⑧: ちからを一部手放し、ちえ・経験へ移る`

という人生曲線が自然に出ている。

重要なのは、平均合計が⑥12.87で最大になり、⑦12.74、⑧12.52とわずかに下がること。**高段階ほど基礎合計値が必ず増える構造にはなっていない。**

⑧へ進む価値は、数値上昇ではなく各種族の老成能力・役割変化でも作る。

## 3. 通常／レア／シークレット 平均

| 区分 | 平均ちから | 平均ちえ | 平均合計 |
|---|---:|---:|---:|
| 通常 | 4.32 | 4.86 | 9.18 |
| レア | 4.97 | 6.05 | 11.02 |
| シークレット（れんくん） | 4.50 | 4.88 | 9.38 |

### 重点リスク

レア8種は通常22種より基礎値平均が高い。

これは、りゅう／フェニックス／かみさま／世界樹等の「大きな存在」を数値にも出しているため意図は説明できるが、**レア＝引いたら単純に得**へ傾く危険がある。

対策方針:

1. レアは同名1枚という既存構築制限を維持。
2. 高基礎値のレア能力は、無条件追加強化ではなく条件・代償・盤面構築を要求する。
3. 通常種は経路・安定・低コスト段階・周辺シナジーで別価値を持つ。
4. 正式プール模擬で「レアを入れられるだけ入れる」が最適になった場合、まず個別レアの数値／能力を調整する。新しいデッキ内レア総数制限は最後の手段。

### 良い反例

- ？？？: 8枚総量74で、多数の通常種より低い。
- ぬいぐるみ: 総量81だが、⑦1/8等の極端な弱点を含む。

したがって現時点で「レアは全て通常の上位曲線」ではない。

## 5. 完全同一曲線

初回機械監査で、

- かめ
- ヤドカリ

が8段階すべて同じ曲線になっていた。

これは近縁ではないにもかかわらずカード一覧上の成長数値が完全一致するため改善対象と判断し、45のヤドカリを

旧:
`2/2 → 3/3 → 4/4 → 5/4 → 6/5 → 6/6 → 5/7 → 4/8`

修正後:
`2/2 → 3/3 → 4/4 → 5/5 → 6/5 → 6/6 → 5/8 → 4/8`

へ変更した。

理由:
- かめ = 防御・耐久・同じ環境を長く使う。
- ヤドカリ = 殻を選び、引っ越し、使いこなす。

ヤドカリ④以降を少しちえ寄りにする方が役割とも一致する。

**修正後、31種族で完全に同じ8段階数値曲線は0組。**

## 6. ⑦→⑧の進む／留まる監査

31種について `ちから+ちえ` の合計を⑦→⑧で比較した。

- ⑧で合計が下がる: **14種**
- 同じ: **11種**
- 上がる: **6種**

つまり31種中25種は、⑧へ進んでも基礎合計が増えない。

これは「⑦に留まる／⑧へ進み能力・配分を変える」という現行方針と整合する。

代表例:

- カブト ⑦10/4=14 → ⑧6/6=12
- セミ ⑦9/4=13 → ⑧4/7=11
- ほし ⑦10/3=13 → ⑧2/10=12
- フェニックス ⑦4/9=13 → ⑧9/8=17（再生なので例外的に大きく戻る）
- ぬいぐるみ ⑦1/8=9 → ⑧2/10=12（宝物として評価が変わる）

⑧へ進む／留まる判断が、種族ごとの物語として数値にも出ている。

## 7. 8枚総量の低い／高い種族

### 低い側

- クワガタムシ: 65
- カブトムシ: 68
- ちょう: 68
- セミ: 68
- アリジゴク: 70

むしが下位を占める。

これは蛹・まゆ・待機等の「弱い時間」を人生戦術へ入れているため。むし能力は経路・相手との間合い・段階価値を生む必要があり、**数値の低さを能力で補う**というより、低い段階そのものを意思決定として成立させる。

クワガタ65は特に低いため、正式プールで⑥〜⑧の反応能力が十分価値を持つか重点監査する。

### 高い側

- りゅう: 97
- フェニックス: 96
- かみさま: 94
- 世界樹: 90
- ほし: 88

高い側はレアが占める。

高総量の存在自体は許容するが、低段階から高数値かつ能力も無条件強力、という二重上位互換は避ける。

## 8. 属性アイデンティティと数値の関係

数値だけで属性を決めすぎない。

- ひと: 中庸。選択・組合せ・継続で差を作る。
- けもの: ちから寄り。能動性。
- みずべ: 中庸〜ちえ寄り。場所との関係。
- うみ: ちえ寄り。状態・関係の流動。
- むし: 平均低め・谷が大きい。段階そのものを戦術化。
- くさ: ちえ寄り。後半・準備。
- げんそう: 高総量。ただし条件・代償。
- ふしぎ: 極端な配分。評価軸を変える。

「属性だから全員ちから+○」という固定表にはしない。

## 9. 現時点で変更しないもの

今回の数値監査だけを理由に以下は変更しない。

- カブト／クワガタ31移植本文

- 第0弾80寄りの候補規模

レア基礎値差は重要なリスクとして残し、能力本文・正式プール・模擬まで見て調整する。

## 10. 第1回判定

仮数値曲線は、ヤドカリ重複を修正した後は**能力方向設計へ進める土台として保持**する。

ただし凍結ではない。以下で再開する。

- 同属性8段階能力を具体化した時に数値と能力が二重強化になった場合
- 第0弾／全プール模擬でレア偏重が明確になった場合
- 10のカードが今後追加されすぎた場合
- 低総量むしが実戦で明確に不利だった場合
