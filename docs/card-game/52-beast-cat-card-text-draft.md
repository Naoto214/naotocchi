# 52 けもの属性 — ねこ①〜⑧ 能力本文 第1稿

最終更新: 2026-09-14

状態: **具体カード本文 第1稿。未確定・模擬前。** いぬは04代表テストとAのいぬ②を比較基準として維持する。

## 設計軸

けもの = **いどむ**。

- いぬ: まず動く。
- ねこ: **まず見る／待つ → 狙いを決めた一度だけ動く。**

仮数値曲線:
`1/2 → 2/3 → 4/4 → 6/5 → 8/5 → 7/6 → 5/7 → 3/8`

# M-cat-01 ① 1/2「まずみる」

`このメインがたんじょうした時、発動できる。山札上2枚を見る。その2枚を好きな順で山札の一番上に戻す。`

- カードを増やさず、最初に少し先を見る。
- ひと①の「1枚を選んで手札へ」と違い、観察だけ。

# M-cat-02 ② 2/3「まつ」

`1ターンに1回。自分のターン終了時、このターンこのメインが自分からちょうせんしていない場合、発動できる。山札上1枚を見て、山札の一番上か一番下に置く。`

- 今すぐ挑まなかったターンを完全な損にしない。
- カブト②は「ときおくりしなかった」、ねこ②は「自分からちょうせんしなかった」で別の待ち方。

# M-cat-03 ③ 4/4 — 能力なし

- 子ねこの時期は4/4のバランス自体を基準にする。
- すべての段階へ無理に能力を付けず、④以降の「狙って飛びつく」能力との差を見やすくする。
- けもの属性でバニラが成立するかを見る比較枠。

# M-cat-04 ④ 6/5「とびつく」

`1ターンに1回。このメインが自分からちょうせんする時、このターン自分がアクションカードを1枚以上プレイしている場合、発動できる。このちょうせんの間、このメインの使用する能力値+1。`

- いぬ④が「早く動く」方向なのに対し、ねこは先に何かしてから飛びつく。

# M-cat-05 ⑤ 8/5「ねらいをさだめる」

`1ターンに1回。このメインが自分からちょうせんする時、このターン自分がプレイしたアクションカードがちょうど1枚の場合、発動できる。このちょうせんの間、このメインの使用する能力値+2。`

- 何枚も連打するより、1枚だけ準備して一度を狙う。
- ④は「1枚以上で+1」、⑤は「ちょうど1枚で+2」と精密さが上がる。
- アクション0枚では発動しない。

# M-cat-06 ⑥ 7/6「かわす」

`1ラウンドに1回。相手の効果でこのメインのちからまたはちえが下がる場合、そのうち1つの減少値を1少なくする。`

- 正面から大きく防ぐのではなく、数値妨害を少しだけかわす。
- そだち減少を守るハリネズミや、対象を引き受けるクワガタ⑥と別役割。
- -1なら0まで軽減できるが、追加の+値は得ない。

# M-cat-07 ⑦ 5/7「みてからかえる」

`1ターンに1回。相手がアクションカードをプレイした時、発動できる。このターン、自分が次に、相手がそのカードをプレイした方法とは異なるプレイ方法でアクションカードをプレイする場合、そのカードをプレイするための時を1少なくする。`

- 相手の「すぐつかう／みにつける／しかける」を見て、別のやり方を選ぶ。
- クワガタ⑧は相手の同じプレイ方法を重くする。ねこ⑦は**自分が違う方法へ切り替える**ので、干渉ではなく適応。
- 適用後にこのメインが離れても、既存の期限付き効果ルールどおりそのターン残る。

# M-cat-08 ⑧ 3/8「必要な時だけ」

`1ターンに1回。このメインが自分からちょうせんする時、このターン自分がアクションカードをプレイしていない場合、発動できる。このちょうせんの間、このメインの使用する能力値+2。`

- 若い⑤は「1枚だけ使ってから狙う」。老成⑧は「何も使わず、本当に必要な一度だけ動く」。
- ちから3なので+2しても身体的全盛期へ戻らない。高いちえ8を必要な一戦へ使いやすくする。

# いぬとの直接比較

| 段階帯 | いぬ | ねこ |
|---|---|---|
| 前半 | 遊ぶ→次へ動く | 見る→待つ |
| 中盤 | 早く挑む／走り切る | 1枚準備して一度を狙う |
| 後半 | 周囲と動く／見守る | 妨害をかわす／相手を見て方法を変える |
| 老成 | そばにいる関係 | 少ない行動を正確に使う |

## 重複監査

- ②はカブト②と似た山札上／下だが、発動条件が「ちょうせんしない」と「ときおくりしない」で戦術が違う。全体山札操作数が多すぎる場合は後で再検討。
- ④⑤⑧がすべてちょうせん補助だが、条件が `1枚以上 / ちょうど1枚 / 0枚` で人生段階ごとの行動密度を変える。模擬で単調なら1枚を別処理へ差し替える。
- ⑥は置換／防止ルールとの正式文言監査が必要。
- ⑦はクワガタ⑧と同じプレイ方法参照だが、相手妨害と自己適応で効果方向が逆。
