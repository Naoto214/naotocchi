# メイン16枚 正本回収

## おとこのひと①〜⑧ — ひと / 設計軸「えらぶ」
仮数値曲線: `1/1 → 2/2 → 4/3 → 6/4 → 8/5 → 7/7 → 5/8 → 3/9`

1. ① 1/1 — 赤ちゃん／可能性。未来からメイン以外の人生カードを選ぶ。
2. ② 2/2 — 幼児／あそぶ。あそび後にちから／ちえどちらを伸ばすか選ぶ方向。
3. ③ 4/3 — 子ども／得意を見つける。片方を一時的に得意にする方向。
4. ④ 6/4 — 青年／挑戦。ちょうせんでどちらを選ぶかに別の意味。
5. ⑤ 8/5 — 成人・壮年／人生を広げる。なかま／こいびと／セカイなど誰と・どこで生きるか。
6. ⑥ 7/7 — 中年・成熟／使い分ける。数値自体が選択性を持つため能力は盛りすぎない。
7. ⑦ 5/8 — 高齢期／経験を活かす。捨て札＝過去の人生から経験を選ぶ。
8. ⑧ 3/9 — 老年期／残す。過去から何かを選び次へ残す。

連作: `何と出会うか → どう遊ぶか → 何を得意にするか → どう挑むか → 誰と・どこで生きるか → 使い分ける → 経験を活かす → 次へ残す`

## カブトムシ①〜⑧ — むし / 設計軸「かわる」
仮数値曲線: `2/2 → 3/2 → 5/3 → 1/4 → 5/3 → 8/4 → 10/4 → 6/6`

1. ① 2/2 — 幼虫初期／ためこむ。今すぐ成果より後段階へ価値をつなぐ。
2. ② 3/2 — 幼虫成長／育つ。ときおくりを意識し始めるが単純高速化にはしない。
3. ③ 5/3 — 成熟幼虫／留まるか変わるか。④へ進むか留まるかが本当の判断。
4. ④ 1/4 — 蛹／止まって変わる。一時的に大幅弱体化。通る意味を作るが必須経路にはしない。
5. ⑤ 5/3 — 羽化直後／生まれ変わる。③と同値でも役割を別物にする。
6. ⑥ 8/4 — 成虫／飛び立つ。活動開始。経路を多少活かす。
7. ⑦ 10/4 — 全盛期／最強のとき。ちから10自体が個性。追加数値強化は控えめ。
8. ⑧ 6/6 — 老成／強さを手放す。⑦の圧倒的ちからを失いバランス型へ。

連作: `ためこむ → 育つ → 留まるか変わるか → 止まって変わる → 生まれ変わる → 飛び立つ → 最強のとき → 強さを手放す`

# Bで重点比較する問い

## 1. 低段階開始 vs 直接高段階
- ①〜③から早く人生を始める価値は十分か。
- ⑤〜⑧を直接たんじょうするために数ラウンド待つ価値は強すぎないか。
- 低段階開始側が、差分時コストで後段階へ進める利点を実感できるか。

## 2. ときおくりの刻み方
- ①→②→③…と1段階ずつ進む。
- ①→④、③→⑥等、中間を飛ばす。
- 現段階に留まり、別行動へ時を使う。
この3択が毎回意味を持つか。

## 3. カブトムシ④問題
- ③5/3から④1/4へわざわざ入るルート。
- ④を飛ばして⑤／⑥へ進むルート。
- ③に留まるルート。
の3つが「正解1択」にならないことを重点確認。

## 4. 高段階の非上位互換
- 人⑥7/7→⑦5/8→⑧3/9。
- カブト⑦10/4→⑧6/6。
で「進めるのに進まない」判断が実際に起きるか。

## 5. へんしんとの比較
人→カブト、カブト→人の別種族移動は通常時コストを払う。ときおくりとの差分時コストと比べ、へんしんが単なる損／得にならないか確認する。

# 残り24枚の役割案

- なかま 5〜6: 低段階支援、段階移動後支援、捨て札の過去利用、あそび連携。
- こいびと 3〜4: 段階を急がない選択に価値を作る。

- あいてむ 3〜4: ときおくり／へんしん支援は過剰にしない。

メイン16枚を優先するため、Aと同じ `10/6/4/4/5/5/6` 配分には拘らない。

# 横並び監査
- 人は「各段階で何を選ぶか」。
- カブトムシは「どの段階を通るか」。
この2種族は人生接続の意味が異なるため、Bで並べる価値が高い。
- 人①とカブト①の両方が序盤カードなので、AよりR1〜R2開始率が大幅に高くなる見込み。
- 一方、16/40がメインなので手札がメイン過多になる危険もある。Bでは「メインを引けるか」より「どの段階を今使うか」という手札選択を試す。
- 高段階メインが早期に手札で腐ること自体はテスト対象。たまご手札調整で山札下へ戻す価値も測る。
