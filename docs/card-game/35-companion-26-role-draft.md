# 35 なかま26体 役割第1稿

最終更新: 2026-09-14

状態: **能力本文を書く前の横断役割設計。既存A/B試作6体は本文を維持し、残り20体は役割案のみ。**

## 目的

なかま26体を名前順に能力化すると、山札整理・+1・時軽減など使いやすい効果を先に配った個体だけが強くなりやすい。

そのため先に、

**本編の名前／behavior → カード上の一言テーマ → ゲーム上の担当領域**

を26体すべて横並びにする。

なかまの既定ルールは維持する。

- 時0
- 最大3体
- こいびとと合わせて自分ターン1人まで場へ出せる
- 8属性・ちから／ちえ・①〜⑧は持たない
- 盤面に複数並ぶため、能力はメインより短くする
- 専用のきずなメーター等はカードゲームへ追加しない

## A. 既存A/B試作6体 — 基準を維持

### C-otter — あそびずきカワウソ
- 本編behavior: 物を転がす・滑らせる
- カードテーマ: **いっしょにあそぶ → 次の勝負を大事にする**
- 担当: あそび連携／条件付き追加そだち
- 既存第2稿: `1ターンに1回。自分が「あそび」カードをプレイした時、発動できる。このターン、自分が次にちょうせんで勝った時、自分のそだち+5。`
- 維持理由: いぬ②の能力値補助と役割分離できており、通常勝利+5に対して重要な一戦だけ追加+5を作る比較基準。

### C-monkey — まねっこサル
- 本編behavior: 主人公の動きを真似する
- カードテーマ: **メインのまね**
- 担当: メイン能力コピー
- 既存試作: `1ターン1回、自分メインが発動した能力をこのターンコピー。コピー共通ルールに従う。`
- 本文の正式化は後で行うが、コピー担当そのものは奪わない。

### C-owl — ものしりふくろう
- 本編behavior: 時々豆知識を言う
- カードテーマ: **よくみる**
- 担当: 山札上の情報整理
- 既存試作: `1ターン1回、自分ターンに山札上3枚を見て1枚上・残り下。`
- 大量ドロー役には広げない。

### C-hedgehog — びっくりハリネズミ
- 本編behavior: 驚くと丸くなる
- カードテーマ: **まるくなる**
- 担当: 相手効果からそだちを守る
- 既存試作: `1ラウンド1回、自分メインのそだちが相手効果で減るなら5防ぐ。`
- なかま側の防止基準として維持。

### C-snail — せっかちなカタツムリ
- 本編behavior: 気持ちは先へ急ぐが、からだはゆっくり。雨と葉っぱが好きで、思いついた遊びにすぐ誘う
- カードテーマ: **あとからいく**
- 担当: 後攻／遅さを小さな情報利益へ変える
- 既存試作: `後攻なら自分ターン最初に1回、山札上1枚を上／下。`
- 以前の「時軽減」案へ理由なく戻さない。

### C-tanuki — いたずらたぬき
- 本編behavior: 他の仲間にちょっかいを出す
- カードテーマ: **ばけてまつ**
- 担当: しかける／ブラフ連携
- 既存試作: `1ターン1回、しかけるでカードをプレイしたターンにそのカードが発動したら1枚引き、手札1枚を山札下。`
- しかける担当の基準として維持。

## B. 通常なかま 残り12体 — 役割案

ここでは能力本文・数値を確定しない。

### C-cat_friend — きまぐれなねこ
- 本編behavior: 自由に寝る・箱に入る
- 一言テーマ: **きまぐれに居場所を変える**
- 担当候補: なかま交代／自分から場を離れることを利用する柔軟枠
- 差別化: アザラシは「戻ってまた使う」、ねこは「その時の居場所を選ぶ」方向。基本ルールへ自由廃棄は追加しない。

### C-rabbit_friend — すばしっこいうさぎ
- 本編behavior: 急に横切る・跳ねる
- 一言テーマ: **最初に飛び出す**
- 担当候補: 自分ターン最初の行動／最初のちょうせん等への小さなテンポ支援
- 差別化: ニワトリはターン開始、うさぎは「最初に実際に動く行動」に寄せる。

### C-squirrel — おっちょこちょいリス
- 本編behavior: 木の実を運んで落とす
- 一言テーマ: **運んで、うっかり落とす**
- 担当候補: 手札1枚を別領域へ動かすことで次の選択を作るカード移動
- 差別化: ふくろうの山札上確認とは別。単純ドローではなく「運ぶ／落とす」を移動で表す。

### C-hamster — ほおぶくろハムスター

- 一言テーマ: **ためこんでおく**
- 担当候補: 手札を多めに保持していること／今使わず残したカードを利益にする
- 差別化: クワガタ③は「時を残す」、ハムスターは「手札を残す」。専用の貯蔵カウンターは作らない。

### C-panda — ぐうたらパンダ

- 担当候補: ターン中に行動を詰め込まなかった時の小さな立て直し／休息
- 差別化: カタツムリの後攻、クワガタ③の時温存と同じ時軽減へ寄せず、「何もしない／少なく動く」価値を担当。

### C-parrot — おしゃべりオウム

- 一言テーマ: **言ったことをくり返す**

- 差別化: サルは自分メイン能力そのもののコピー。オウムは能力コピーをせず、公開された「行動の種類」をまねる。

### C-sheep — ふわふわヒツジ

- 一言テーマ: **みんなのよりどころ**

### C-seal — ごろごろアザラシ

- 一言テーマ: **ごろごろ戻ってくる**
- 担当候補: 自分自身を手札へ戻す／出し直しに関する再配置
- 差別化: ねこは交代の柔軟性、アザラシは自分が転がって戻り再利用する方向。無限出し入れは防ぐ。

### C-bat — よふかしコウモリ

- 差別化: 「よる」世界カードが未確定でも機能できる役割にする。夜専用ロックへはしない。

- 差別化: うさぎは最初の行動に反応、ニワトリはターン開始そのものに反応。

## C. レアなかま8体 — 第1役割案

`clock` 以外は現行マスターにbehavior本文がない。したがって、**名前・現在のキャラクター性から能力を確定したことにはしない**。ここでは能力空間を予約するだけで、必要なら本編側のキャラ設定を先に補強してから本文を書く。

### C-punyu — とけかけのぷにゅ
- source behavior: 現行マスターに個別behaviorなし
- 一言テーマ案: **とける前に使う**
- 担当候補: 自分から場を離れる代わりに一度だけ成果を残す短期なかま
- 注意: 時0のなかまを単純な無料使い切りカードにしない。

### C-sekizou — むひょうじょうのせきぞう
- source behavior: 現行マスターに個別behaviorなし
- 一言テーマ案: **動かない**
- 担当候補: 相手による移動・入替等に強い安定盤面
- 注意: 完全耐性ではなく限定的にする。ハリネズミのそだち防止とは別。

### C-chameleon — サングラスのカメレオン
- source behavior: 現行マスターに個別behaviorなし
- 一言テーマ案: **その場に合わせる**
- 担当候補: 現在のセカイ／相手の直前行動等に応じて小さく役割を変える適応
- 注意: なかまに8属性を与えない。カクレクマノミ等のへんしん能力とも分ける。

### C-clock — じかんにルーズなとけい
- 本編behavior: 時刻は大まか。小さな出来事の音を覚えていて、誰かを待つ時間は気にしない
- 一言テーマ: **時間どおりじゃなくてもいい**
- 担当候補: 遅延効果／次のターンまで待つことを利益にする
- 差別化: 時そのものを大量に増やすカードにはせず、「待つ」方向を担当する。

### C-unicorn — まよいこんだユニコーン
- source behavior: 現行マスターに個別behaviorなし
- 一言テーマ案: **思わぬ場所に迷いこむ**
- 担当候補: セカイ変更・旅の後に現れる偶発的な盤面支援
- 注意: レアだから無条件に山札から直接出る等の上位能力にはしない。

### C-many_tail_fox — しっぽのおおいきつね
- source behavior: 現行マスターに個別behaviorなし
- 一言テーマ案: **いくつものやり方を持つ**
- 担当候補: 2〜3個の小さなモードから1つ選ぶ柔軟支援
- 注意: 1枚で何でもできる万能カードにしない。各モードを小さくする。

### C-watcher — みているなにか
- source behavior: 現行マスターに個別behaviorなし
- 一言テーマ案: **ずっと見ている**
- 担当候補: 相手の公開情報・準備状況を参照する観察
- 注意: 裏向きのしかけカード内容を恒常的に覗く能力は情報ルールへの影響が大きいため、現段階では採用しない。

### C-box — ただのはこ
- source behavior: 現行マスターに個別behaviorなし
- 一言テーマ案: **本当にただのはこ**
- 担当候補: 能力なし、または極端に短い能力のレアなかま候補
- 意義: 「レア＝長文・単純上位互換」を避け、なかま枚数・盤面条件そのものを活かす余白を作る。
- 正式にバニラ採用するかは全なかま本文監査後に決める。

## D. 26体の役割重複監査

### 山札・手札
- ふくろう：山札上を見る
- リス：カードを運んで別領域へ動かす
- ハムスター：手札を保持することを価値にする
- カタツムリ：後攻時の上／下整理

→ 全員を「山札上を見て下へ」にしない。

### タイミング
- うさぎ：最初の行動
- ニワトリ：ターン開始
- コウモリ：相手ターン／後半
- とけい：待って次へ
- カタツムリ：後攻

→ 同じ時-1を5体へ配らない。

### 盤面移動
- ねこ：交代・居場所選び
- アザラシ：自分が戻る／再配置
- ペンギン：セカイ移動
- ユニコーン：旅先への偶発接続

→ 「手札に戻す」の対象・意味を分ける。

### 模倣・観察
- サル：自分メイン能力コピー
- オウム：直前の行動種類をまねる
- ウォッチャー：相手公開情報を観察
- カメレオン：環境へ適応

→ コピー処理をサルの専売基準にし、残りはコピー以外で表現する。

### 防御・安定
- ハリネズミ：そだち減少防止
- 石像：移動・入替への安定
- しばいぬ：メインとの同行支援
- ヒツジ：仲間複数の盤面支援

→ 全員を「相手効果を無効」にしない。

### あそび・成果
- カワウソ：あそび→次の勝利追加+5
- たぬき：しかける
- パンダ：少なく動く／休む
- ぷにゅ：短期で場を離れる

→ 能動と非能動の両方をなかま枠に残す。

## E. 第1稿の結論

26体は現時点で役割を分離できる見込みがある。

ただし、以下は能力本文前に追加監査が必要。

1. レア7体（clock以外）は本編behaviorが未定義なので、名前だけから細かい能力を確定しない。
2. ねこ／アザラシの自己移動が、なかまの「満員時だけ交代可」という基本ルールを抜け道化しないこと。
3. うさぎ／ニワトリ／コウモリ／時計のタイミング系が、物理版で毎ターン監視負荷になりすぎないこと。
4. ペンギン／ユニコーンは33のセカイ4軸方式が未確定でも機能する本文にすること。
5. サルのコピーは既存コピー共通ルールを必ず再読して正式本文にすること。
