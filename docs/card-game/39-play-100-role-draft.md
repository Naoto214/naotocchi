## 目的

本編100ミニゲームをすべてカード候補として保持しつつ、

- 同じgeneratorだから同じ効果
- スポーツだからちから+1
- パズルだから1枚引く

のような機械的量産を避ける。

各候補について、元ゲームの**何をカードゲームへ翻訳するか**だけを先に1つ決める。

これは最終能力ではない。全候補を横に並べた時の役割衝突を検出するための地図。

## C. 重複監査で見えた主要グループ

### 山札探索が多すぎる危険
crane / dungeon / roguelike / fishing / voxel / clover等が探索へ寄りやすい。

→ 深さ・選択数・代償・対象種類を分ける。全部「上3枚から1枚手札」にはしない。

### 対象変更が多すぎる危険
tiltMaze / airHockey / pingPong / road回避等が「かわす」に寄りやすい。

→ 対象変更は少数にし、他は防止・手札戻し・条件回避・セカイ移動等へ分散する。

### 準備破壊が多すぎる危険
breakout / catapult / tank / bomber等。

→ 無条件除去を増やさず、段階的・遅延・種類条件・一時無効等へ分ける。

### 組合せ成果が多すぎる危険
fallingBlock / chain / bubble / match3 / connectFour / gomoku / sudoku等。

→ 「同じ種類を揃える」「異なる種類を揃える」「順番」「連続プレイ」を分ける。

## D. プレイ方法の仮分布方針

まだ個別確定しないが、100枚すべてを `すぐつかう` にしない。

- **すぐつかう中心**: スポーツ、物理、探索、即時パズル
- **しかける候補**: bomber、towerDefense、hauntedHouse、minesweeper、domino等、先に置く意味がゲーム性にあるもの
- **みにつける**: あそびでは例外的。ゲーム自体を装備にする必然がある場合だけ

準備枠はあいてむ・くさ・しかけると競合するため、あそびのしかける比率を増やしすぎない。
