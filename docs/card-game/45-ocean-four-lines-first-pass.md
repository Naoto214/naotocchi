## 属性テーマ

うみ = **ながれる**。

- カクレクマノミ: 役割・関係が流れる
- ヤドカリ: 身につける物／住処が流れる
- クラゲ: 外から来る流れに身を任せる
- ヒトデ: 失った後、価値が再び流れ込む
- サンゴ: 個体同士がつながり、周囲の居場所を作る

## 5種横断

| 種族 | 何が流れる／変わる？ | 主操作 |
|---|---|---|
| カクレクマノミ | 役割・関係 | 対象／関係／みにつけるの組替え |
| ヤドカリ | 殻・持ち物 | みにつけるの選択・つけ替え |
| クラゲ | 自分の位置・外からの流れ | 他効果の移動に乗る |
| ヒトデ | 失った後の価値 | 損失後の立て直し |
| サンゴ | 個体同士のつながり | 多種類盤面の共存 |

## 重点監査

- うみ5種をすべて手札交換／対象変更にしない。
- ヒトデの再生とフェニックスの再生を分離。ヒトデ=部分損失から立て直す、フェニックス=大きな代償の先で限界を越える。
- サンゴの盤面形成とくさ属性を分離。サンゴ=つながる生き物・居場所、くさ=時間差で育てて成果。
- ヤドカリは準備枠を使うため、あいてむカード全体の役割地図と横断監査する。
