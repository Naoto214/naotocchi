# 26 全カードプール棚卸し 1 — 最新main由来

## この文書の役割

`25-full-card-pool-development-plan.md` に従い、カード専用イラストを作る前に、本編に存在するカード化可能要素を全体プールとして棚卸しする。

この文書はカード効果の大量確定ではなく「何を設計対象として持つか」の入口。既存01〜24のカード案を上書きしない。

## 1. メイン

最新 `character-world-master.v1.js` を正として、通常22種＋レア8種＋シークレット1種が8段階を持つ。

- 通常：22 × 8 = 176枚候補
- レア：8 × 8 = 64枚候補
- シークレット `ren`：1 × 8 = 8枚候補
- 合計：248形態

作者 `naoto` は playable=false のため、メイン8段階には含めない。ただし別種類カードの候補から除外はしない。

### 通常22種

man / woman / dog / cat / penguin / turtle / frog / salmon / clownfish / butterfly / beetle / stagbeetle / cicada / antlion / hermit_crab / jellyfish / starfish / coral / dandelion / sakura / venus_flytrap / mushroom

### レア8種

dragon / phoenix / god / world_tree / ghost / star / plush / unknown

### シークレット

ren

### 既設計の移植

カブトムシ①〜⑧とクワガタムシ①〜⑧は新規に作り直さず、15・22・23・24等の現行案をカードマスターへ移植する。全プール横断で問題が見つかった場合のみ理由付きで再調整する。

## 2. なかま

最新WORLD_MASTERの companions をカード候補とする。

通常・レアを含め、各stable idを1候補として扱う。仲間はメインではないため8段階・属性・ちから／ちえを持たせない既存方針を維持する。

本編側で名称・ID・仲間構成が変わった場合はstable idを基準に差分追従する。

## 3. こいびと

最新WORLD_MASTERの partners をカード候補とする。

各こいびとは firstRegion と hook を持つため、カード能力を作る際は単なる汎用支援ではなく、初遭遇地域・性格・行動フックを能力理由の第一候補にする。

こいびとはメインではないため8段階・属性・ちから／ちえを持たない。

## 4. セカイ

WORLD_MASTERの地域をカード候補の核とする。

- home / おうち
- 通常地域
- 特殊地域

さらに本編では地域と独立して季節・時間帯・天気が存在する。これらを「セカイカードそのもの」「セカイへ条件を与える別カード」「できごと」等のどこへ置くかは、カード種類間の役割監査後に決める。現時点で新しいカード種類は増やさない。

## 5. あそび

本編 `games.js` は100本のミニゲーム本体を持つ。

原則として100本すべてをカード化候補として棚卸しする。ただし本編内には、同じ操作・勝敗構造でテーマだけ異なるものを1ゲームへ統合した経緯がある。そのためカード側でも「見た目違いだけの重複カード」を機械的に増やさず、stableなゲーム単位とゲーム性を確認してからCARD / HOLDを判定する。

重要：

- 「100本あるから100枚すべてを第0弾へ入れる」ではない
- 全体マスタープールには原則候補として保持する
- 同型ゲームをカード能力まで同型にしない
- あそびカードの能力は、元ゲームの操作・勝利条件・テーマのどれを翻訳したか説明できるようにする

## 6. あいてむ

本編ではアイテム体系が過去に大きく再設計されている。旧消耗品カタログをそのままカード化しない。

最新mainに現在存在する以下の実体を改めて抽出してから候補化する。

- 現行の身につけるもの
- 現行の遊び／お楽しみ系アイテム
- なおと系・伝説系など現行特殊アイテム
- その他、現行UI・状態に実在するアイテム

過去に削除された旧CONSUMABLE_ITEMS等は、最新mainに存在しない限り自動復活させない。

## 7. できごと

本編のイベント、地域イベント、人生上の出来事、天候・季節・時間に関係する出来事、ランダムイベント等を候補化する。

ただし「本編のログ文1行＝1カード」にはしない。ゲーム上の独立した出来事として意味がある単位を抽出する。

## 8. 現時点の規模感

メインだけで248候補あり、あそびは最大100候補。これに、なかま・こいびと・セカイ・あいてむ・できごとが加わる。

したがって全体マスタープールは第0弾80種を大きく超えることが確実である。

これは問題ではない。第0弾は全体プールから選抜する。

## 9. 棚卸しで守ること

- 01〜24の試行錯誤を消さない
- 既存の確定裁定を再質問しない
- 最新mainにない旧要素を記憶だけで復活させない
- stable id / source pathを残す
- 本編要素をカード化するだけの機械的な同能力量産をしない
- CARD / HOLD / NO-CARD の理由を残す
- イラストは全候補PROXYのまま進める
