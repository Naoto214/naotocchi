## 3. V02 たまごと能力無効の確認時点

採用した接続は、**発動前と解決に入る時点でたまごの無効を適用し、適用済みの予約は残す**。02へ全文を保存し、06から接続した。

発動時さえ非たまごなら常に通す方式では、02の「たまご中は能力を無効」と未解決能力の関係が曖昧なままになる。一方、たまごを一度挟んだら全て永久取消しにする方式は、状態履歴の追跡と新しい取消しルールを要する。解決に入る時点の状態を用い、現在状態と適用済み効果を分ける。

- たまご中は新規発動・継続効果・発動しない修正を止める。本文で許可された捨て札発動も対象。
- 出来事発生時にたまごなら発動待ちを作らず、非たまごで発生しても最初の発動機会がたまごなら持ち越さない。
- 適法な発動後でも解決に入る時点がたまごなら、その発動の効果全体を適用しない。コストと回数は戻さない。
- 解決に入る時点で非たまごなら、一時的なたまご履歴だけでは無効にしない。通常たんじょうを連鎖中へ挿入する許可ではない。
- 適用済みの期限付き・遅延効果は維持し、対象や追加条件は個別本文どおり。予約の実行を新しい能力発動としない。

この範囲は、こいびとカード自身の能力に対する02の無効。こいびとを参照するできごと、メイン／なかまの能力まで一括で無効にしない。発動元が離れたことだけを新しい無効条件にもせず、対象個体の適正とは分ける。

## 4. A83-01 2048の個別本文改稿

旧08／83原文を履歴として保存する。

> 手札の同じカード種2枚を公開して山札下へ。2枚引く。

時1・すぐつかう・通常同名3枚と、同じ種類2枚の手札交換という役割を維持する。現行本文を08・83へ同期した。

**現行2048本文:**

> このカード以外に、同じカードの種類のカードが手札に2枚以上ある場合に発動できる。解決時に手札に同じカードの種類のカードが2枚以上ある場合、そのうち2枚を選んで公開し、好きな順で山札の一番下に置く。2枚とも置いたなら、2枚引く。

発動時はペア所持を条件として確認するが、ペアを対象として固定・公開・先払いしない。選択・公開・山札下への移動は解決時の効果。同種の意味は7種類であり、種族・段階・名前が同じという意味ではない。発動する2048自身を手札ペアに含めない。

前払いコスト方式も可能だったが、旧文にその明記はなく、同種2枚の交換という意図は効果方式で保てる。2枚揃わない時に無条件2ドローだけ残る読みも防ぐ。無効時に2枚を失わない点などは今回具体化した挙動であり、旧模擬結果を新本文の検証済み結果へ置き換えない。

## 6. 残る横断監査と検査の範囲

3件の境界は具体化したが、次を残す。

1. 相手メインの捨て札除去／手札戻し、なかま除去、こいびとを捨て札へ送る実在する供給と防御の組合せ。今回V01は自分の通常交代であり、相手除去の供給ではない。すれちがいの手札戻しとゆきだるまの捨て札条件も別。
