## 4. 13枚の監査範囲と残る問題

今回の13枚は既存1枠を使う場所だけ。前3軸の盤面方式、カード総数、最終収録を決定しない。セカイのレア指定をsourceの特殊区分から自動導入せず、全13を通常・各同名3枚の第1稿とした。

- **供給:** うみで自分の装備つけ替えは追加できた。相手のメイン／なかま除去、関係終了の起点まで新設したわけではない。次のできごとは38のCARD21／HOLD13を保ち、その接続と旧A/Bの省略本文を確認する。
