# 477 — ぴょんぴょんジャンプの本文改訂（そだち+5の条件）

最終更新: 2026-10-27

状態: **本人限定試遊版で確認中。** 正式公開（mainマージ）は本人の最終QAと承認後。

## 改訂内容

| | 本文 |
|---|---|
| 旧 | このターン、自分が次にときおくりを行った時に1枚引き、その次にときおくりを行った時に自分のそだち+5。 |
| 新 | このターン、自分が次にときおくりを行った時、1枚引く。そのときおくりで段階が1つだけ上がった場合、さらに自分のそだち+5。 |

- 変えたのは、そだち+5の条件だけです。時1・ドロー1枚・+5・有効期間「このターン」・すぐつかう・通常（同名3枚）・イラストは変えません。
- 設計正本：[85](85-play-batch-4-card-text-draft.md) の G-doodle-jump と §5（改訂記録）。

## 裁定（接続）

- このターンの次の1回のときおくりで、1度だけ解決します。予約はそこで終わります（2回目のときおくりでは何も起きない）。
- 段階差は、ときおくり直前のメインと、移った後のメインに書かれた段階で比べます。例：②→③は1枚＋そだち+5、②→④は1枚だけ。
- たんじょう・へんしんはときおくりではないので数えず、予約は残ります。
- 山札が空で引けなくても、段階の条件を満たせば+5は適用します。
- ときおくりしなければ、ターン終了時に何もせず失効します。

- [PR #448](https://github.com/Naoto214/naotocchi/pull/448)（`prototypes/card-game/early-birth-value-20261027/REPORT.md`）：旧本文の+5（1ターンに2回目のときおくり）は、ときおくりをしたターンの1.8%でしか成立しない。
- [PR #451](https://github.com/Naoto214/naotocchi/pull/451)（`prototypes/card-game/doodle-jump-test-20261027/REPORT.md`）：1,280戦の比較。使用機会を揃えた比較で+5の成立は使用あたり0.04→0.48、得点率差 +0.018 [+0.009, +0.029]、事前基準の「強すぎる」に当たらない。
