# 36 こいびと18体 役割第1稿

最終更新: 2026-09-14

状態: **能力本文を書く前の横断役割設計。既存A/B試作4体は役割を維持し、残り14体は役割案のみ。**

## 目的

こいびと18体は、全員を「交際段階が進んだ時そだち+5」にすると人物差が消える。

本編の `firstRegion / hook` を使い、

**出会い → 交際開始 → 関係を深める → 結婚 → 結婚後 → すれちがい／別れ → 再出発**

のどこを得意とするかを先に分配する。

既定ルールは維持する。

- なかまと合わせ自分ターン1人まで、時0
- 各メイン・こいびとに性別・恋愛対象・恋愛タイプを割り当てず、交際成立条件に使わない。必要な組み合わせ条件だけ個別のカード能力に明記する（66のユーザー確定方針）
- 交際0→1→2→3→結婚
- 66で開始・進行の定義を接続。0で新しい交際を始め、0→1・1→2・2→3で進行時の能力、3→結婚で結婚時の能力を参照する。たまご復帰は再開始・進行・再結婚ではない。
- 交際進行は1ターン1回、時1
- 結婚で基本そだち+10
- 離婚／別れで基本そだち-10
- メインが盤面を離れても関係は維持
- こいびと自身に8属性・ちから／ちえ・8段階を持たせない

## C. 関係局面の横断監査

### 出会い・開始
- ねこ社長：交際開始時の手札循環
- E-new-encounter：出会いそのものの探索

→ こいびと本人と「出会い」できごとを二重にしない。

### 交際を進める
- クモ：進行時に準備へ利益
- ロボット：現在の交際段階で性質が変わる
- シカ：序盤弱く後で大きい
- サソリ：関係ボタンではなく実際の行動を通じて価値

→ 全員を「進行時そだち+5」にしない。

### 留まる・長く一緒にいる
- うし：同じ段階で過ごす
- ワシ：高段階／長期
- ゆきのせいれい：人生終盤
- ひまわり：メインが変わっても今の相手を向く

→ 「進めない方が得」と「進めた後に得」を区別する。

### 世界との関係
- ヤギ：セカイ変更中の関係
- にんぎょ：結婚時に過去のセカイを回収
- チョウチンアンコウ：環境で振る舞いが変わる

→ みずべ属性・世界カードと役割を食い合わない。

### 守る・支える
- クマ：関係／メイン防御
- タコ：複数人生要素の世話
- ゴリラ：条件付きちから支援
- ワニ：受け身／一歩引く

→ 全員を能力値+1の常時バフにしない。

### 終わり・その後
- ゆきだるま：関係終了後の次の選択
- E-reconciliation：すれちがいからの立て直し候補
- E-wedding-anniversary：結婚後の節目

→ こいびとの個性と人生イベントの個性を分ける。

## D. firstRegionの扱い

firstRegionは本編での初遭遇地域であり、カードゲームでそのセカイがないとこいびとを出せないという共通ルールにはしない。

地域との関係が強い人物（ヤギ、チョウチンアンコウ等）は個別能力条件としてセカイを参照してよいが、18体すべてを地域ロックするとデッキ構築が硬直するため避ける。

## E. 複雑さ予算

こいびとは1枚しか盤面に置かれず、なかまより少し複雑な能力を許容できる。ただし、交際段階そのものが既に状態を持つため、追加専用カウンターは作らない。

- 既存交際段階を参照する
- 結婚済みかを参照する
- セカイ・メイン・準備等の公開盤面を参照する

範囲を基本とする。

## F. 集計

本編の恋愛情報は `script.js` の `PARTNER_RUNTIME_PROFILE` と候補生成・保存処理にあり、[66](66-relationship-start-and-romance-profile.md)第4節へ実装資料として記録した。**ユーザー確定方針により、カードゲーム側ではこれらを割り当てず、交際成立条件に使わない。** WORLD_MASTERの名前・firstRegion・hookは人物表現・能力理由の資料に使うが、性別・恋愛対象・相性を補完しない。18体のプロフィール割当作業は不要となり、固定情報案・対戦用プロフィール案・登場時抽選案はいずれも採用しない。

- こいびと18候補：変更なし（18 CARD候補）
- 全体477候補：変更なし
- 今回は役割配分のみ。新カード追加なし。
