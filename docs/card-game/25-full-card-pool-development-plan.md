# 25 全カードプール開発方針 — イラスト制作前の正本

## 目的

なおとっちカードゲームは、第0弾72〜80種だけを先に完成させて閉じるのではなく、本編に存在するカード化可能な要素を可能な限り全て棚卸しし、将来カード化できる全体プールを先に設計する。

そのうえで第0弾は、全体プールからゲームとして最も良い72〜80種（現時点では80種寄り）を選抜する。

## 最重要方針：イラストは最後

カード専用の最終イラスト制作は、カードの名前・種類・数値・コスト・能力・役割・裁定・収録方針を十分にテストし、イラスト以外の設計が凍結できる段階まで原則行わない。

テスト中は本編の現行PNG、簡易記号、文字だけのプロキシを使用してよい。

理由：

- 効果変更による描き直しを避ける
- 絵に引っ張られてゲーム上必要な修正をためらわない
- 最終的な能力・役割・生態に最も合う構図を選べる
- 全カード横断でアートの重複を避けられる

カードアート制作時には `21-main-card-art-and-biology-principles.md`、`22-beetle-stagbeetle-16-stage-audit.md`、本編の `CHARACTER_ASSET_SPEC_V1.md` を再参照する。

## 既存01〜24を捨てない

本方針は設計のリセットではない。

01〜24で確定・検証したルール、テストデッキA/B、模擬対戦、第0弾規模、カブトムシ／クワガタムシの能力・生態・アート監査を全カード設計の基準として引き継ぐ。

特に以下は比較基準として保持する。

- デッキ40枚固定
- 7種類：メイン／なかま／こいびと／セカイ／あそび／あいてむ／できごと
- 8属性・ちから／ちえ・①〜⑧はメインのみ
- 通常ちょうせん勝利はそだち+5
- 条件付き能力による重要な勝負の追加+5、合計+10は可
- 時コスト軽減は0まで可
- 「1ターンに1回」はカード個体ごと。同名全体制限は本文で明記
- 適用済みの期限付き／遅延効果は発動元が離れても期限まで残る
- カブトムシ＝「かわる／いつ進むか」
- クワガタムシ＝「かまえる／はさむ」
- カブト⑦＝10/4・能力なしの純粋な全盛期
- クワガタ⑦＝9/5・相手が先にちょうせんしたラウンドの迎撃と追加そだち

既存案を変更する場合は、全体プールでの役割衝突、模擬対戦上の問題、生態との不整合、裁定上の問題など理由を記録する。

## 全カード化候補

本編に存在する以下を原則として棚卸し対象にする。

1. メインキャラクター：図鑑対象の全種・全8段階
2. なかま
3. こいびと
4. あいてむ
5. あそび
6. セカイ
7. できごと

本編の追加・削除・名称変更・生態変更・画像変更があった場合に差分追従できる構造とする。

「本編に存在する＝必ず同じセットで発売する」ではない。カード化可能なマスタープールと、各商品・セットへの収録を分離する。

## 棚卸し時の状態

各候補に最低限、次の状態を持たせる。

- CARD：カード化する
- HOLD：候補だが役割・裁定・重複等の理由で保留
- NO-CARD：カード化しない。理由を記録

単に作業がまだのものを NO-CARD にしない。

## カードマスターで管理する項目

全候補に一意な仮IDを付け、少なくとも以下を管理する。

- 仮ID
- 本編source ID / source path
- 表示名
- カード種類
- メインの場合：種・段階・属性・ちから・ちえ
- コスト
- 発動／使用条件
- 効果本文
- ゲーム上の役割
- 生態・本編設定との対応理由
- 同系統カードとの差別化
- 裁定メモ
- テスト状況
- カード化状態 CARD / HOLD / NO-CARD
- 第0弾候補か
- 将来セット候補
- イラスト状態（当面は PROXY）

## 設計順序

### Phase A — 本編全要素の棚卸し

最新mainを正として、メイン、なかま、こいびと、あいてむ、あそび、セカイ、できごとを機械的に列挙する。

### Phase B — 全体の役割地図

種類ごと・属性ごと・段階ごとに、既存能力と新規能力の役割を整理する。

能力を先着順で配らず、「この生物／このアイテム／この出来事だからこの能力」と説明できることを優先する。

### Phase C — カード本文の第1稿

全候補についてイラスト以外のカード案を作る。大量作成時も既存ルール語彙と裁定を使用し、新しいルール概念を安易に増やさない。

### Phase D — 横断監査

- 同一メイン①〜⑧
- 近縁キャラ
- 同属性
- 全メイン
- なかま／こいびと間
- あいてむ／あそび／できごと間
- セカイ
- 全種類横断

の順で、役割・効果・数値・文章・生態の重複を確認する。

### Phase E — 第0弾選抜

全体プールから第0弾72〜80種を選抜する。現時点では80種寄り、メイン32＋その他48が有力だが、これは最終確定ではない。

### Phase F — プロキシテスト

本編PNGまたは文字プロキシで複数デッキを作り、模擬対戦を重ねる。

確認項目：

- 先攻／後攻差
- 属性間勝率
- デッキタイプ間勝率
- 各カードの採用率・使用率
- 死に札率
- 役割重複
- コンボの上限／下限
- そだち速度
- へんしん経路
- 時の供給と消費
- 強制／任意／連鎖の裁定負荷
- 初見プレイヤーの理解負荷

### Phase G — 非アート凍結

テストで問題が十分に減った時点で、カードごとに「イラスト以外凍結」状態を設定する。

### Phase H — 最終イラスト

ここで初めてカード専用イラストを本制作する。

絵は能力の説明図ではなく、キャラクター／対象そのものの魅力、生態、段階、ゲーム上の役割を同時に伝えるものとする。

## 第0弾と全体プールの関係

第0弾は全体プールの部分集合である。

全体プールを先に見ることで、強い能力や特徴的な能力を第0弾の少数キャラへ集中させすぎることを防ぐ。また、将来の本編キャラを追加したときにも能力空間を残す。

第0弾のカード総数は、本ファイルでは確定しない。

## 次の作業

1. 最新mainからカード化可能な本編要素を種類別に全棚卸しする
2. 全候補へ仮IDを付与する
3. 既存01〜24のカード案をカードマスターへ移植する
4. 未設計候補を種類別に設計する
5. 横断監査後、第0弾候補を再選抜する
6. プロキシによる大量模擬対戦へ進む
7. イラスト以外が十分に固まってから最終アート制作へ戻る
