# 118 「ときおくり」暫定名称への用語移行

日付: 2026-09-19  
状態: 正本反映済み。名称だけ暫定、効果・処理は既存確定ルールを維持。

## 1. 目的

カードゲーム正本で段階移動を表す旧称「ときとばし」を、現時点の暫定名称「ときおくり」へ統一する。読み手が旧称と現行語を混在させないため、現行仕様として参照されるカード本文、ルール、裁定、用語定義、例示、対戦記録、fixture説明、生成データ、検査器周辺の記述を同時に移行する。

この変更は名称だけを対象とする。同種族の後段階へ段階差ぶんの時で進むこと、現在メインを捨て札へ置いて手札の後段階メインをメイン枠へ置くこと、中間段階を経由扱いにしないこと、共通回数制限を設けないことなど、既存の効果・処理・条件は変更しない。

## 2. 用語対応

| 区分 | 表記 | 扱い |
|---|---|---|
| 旧称 | ときとばし | この移行履歴だけに残す。現行仕様本文では使用しない |
| 現在の呼称 | ときおくり | 暫定名称。効果・処理の確定状態とは分けて扱う |
| 対になる候補 | ときもどし | 暫定候補だけ。今回、新しい効果やルールを追加しない |

ID、schema、英語の機械識別子は変更しない。event種別も維持する。既存の `two_time_skips_in_same_turn`、`count_one_multi_stage_move_as_two_time_skips` などは、保存済みschemaとの互換性を維持するためそのままとする。

## 3. 変更範囲

変更前監査では、`docs/card-game/` の81ファイルに旧称266件と表記ゆれ2件、合計268件があった。

- Markdown 77ファイル: 基本ルール、メインシステム、設計原則、横断監査、カード本文、裁定、例示、過去の模擬対戦・監査、代表資料、README、実装計画。
- JSON 3ファイル: 110の盤面併用plan／evaluation、111の構造的入力不足disposition。
- Python 1ファイル: 111 disposition生成器。

過去の対戦結果や監査文書も、同じゲーム行動を現行語で参照できるよう用語だけを更新した。勝敗、そだち、時、カードID、card copy ID、instance ID、event、snapshot、予約、判断結果は変更していない。Git履歴、過去commit、過去PR本文は書き換えない。

一般文としての「飛ばす」「飛ばした中間段階」「一気に飛ぶ」などは、正式なゲーム用語そのものではないため変更していない。

## 4. 自然文の調整

単純置換で意味が不自然になる箇所は次のように整えた。

- 02・05の見出しは、効果・処理が確定済みで名称だけ暫定であることを明記した。
- 「ときおくり時」は「ときおくりの際」、「経由時」は「ときおくりで到達した時」など、文脈に応じた表現へ直した。
- 03の旧「最終名称」記述は、現在の暫定名称と最終名称未確定を矛盾なく示す形へ更新した。
- 「先へ進む」「捨て札に置かれた条件」など、処理内容を変えず助詞と語順を整えた。

## 5. 検査方針

`check-design-data.py` は、旧称と表記ゆれがこの文書の明示的な移行履歴以外に残った場合をエラーにする。118内の旧称は、移行理由と対応表の2件だけを許可する。

生成データは、110 planの用語を更新した後に110 evaluationを再生成し、111生成器の文言更新後に111 dispositionを再生成する。保存JSONと生成結果の一致を既存テストで維持する。

既存proxyが参照するカタログfingerprintは、名称だけの変更で過去記録の同一性を壊さないよう、hash計算時に暫定名称を旧称と同一視する互換正規化を行う。正本として表示・出力するカード本文は「ときおくり」のままとし、ID・schema・保存済みreplay識別子は変更しない。

## 6. 変更しないもの

- カード効果、処理順、時コスト、そだち、発動条件、対象、期限、回数制限。
- 現行452件、登録477候補（CARD463＋HOLD14）、HOLD14、旧24、legacy4の母集団区分。
- 112の未実施fixture 6件、117のstopped 4経路、completed記録、独立balance標本数。
- ID、schema、英語の機械識別子。
- 新しい「ときもどし」効果。

## 7. 次の再開地点

ゲーム進行上の再開地点は117から変えない。次は117で不足したresponse-windowの候補、phase、stable ID contractを評価し、4経路を再開可能にする。112の6 fixtureへ先に進まず、名称が暫定であることを理由に効果・処理を再設計しない。
