# 43 けもの属性 — ねこ①〜⑧ 第1稿

最終更新: 2026-09-14

状態: **人生テーマ＋仮数値曲線。具体能力本文は未確定。**

## 属性内比較

けもの正式テーマ: **いどむ**。

- いぬ: **まず動く → その行動から次が生まれる**
- ねこ: **待って見る → 自分のタイミングで一気に動く**

どちらもちょうせん・能動行動を使うが、操作順を逆にする。

## 仮数値曲線

`①1/2 → ②2/3 → ③4/4 → ④6/5 → ⑤8/5 → ⑥7/6 → ⑦5/7 → ⑧3/8`

合計: ちから36 / ちえ40 = 76。

いぬ `41/35 = 76` と総量を揃えつつ、ねこは相手・盤面を見るためちえ寄り。

## ①〜⑧

### ① 1/2 — あかちゃんねこ「まずみる」
- 人生テーマ: 周りを眺めて安全を確かめる。
- 能力方向: 自分から即行動する利益ではなく、相手盤面／山札上等の公開に近い情報を小さく見る。
- 注意: ふくろうの上3枚整理の下位／上位コピーにしない。

### ② 2/3 — よちよちこねこ「まつ」
- 人生テーマ: 気になるものが動くまでじっと待つ。
- 能力方向: 自分ターンの最初にすぐちょうせんしなかった場合など、「待ったこと」を後の小利益へ。
- 差別化: クワガタ③は時2以上を残し次ターンへ。ねこ②は同ターン内の待ち方。

### ③ 4/4 — こねこ「おいかける」
- 人生テーマ: 動いたものへ反応して追う。
- 能力方向: 相手／自分のカードが移動した後、次の自分行動を少し有利にする。
- 注意: 対象変更そのものを主役にしない。

### ④ 6/5 — おてんばねこ「とびつく」
- 人生テーマ: 狙いが決まった瞬間に一気に飛び込む。
- 能力方向: 条件を待った後の自分からのちょうせんに短い補助。
- 差別化: いぬ④はターン前半にすぐ飛び込む。ねこ④は何かを見てから飛びつく。

### ⑤ 8/5 — 若いねこ「ねらいをさだめる」
- 人生テーマ: 身体能力ピークに近づき、無駄に動かない。
- 能力方向: そのターンに使うカード／ちょうせんを絞った場合、その1回を強くする。
- 注意: 何もしないだけで毎ターン+2等の恒常強化にはしない。

### ⑥ 7/6 — 大人のねこ「かわす」
- 人生テーマ: 正面から受けず、身軽に避ける。
- 能力方向: 相手の対象効果・ちょうせん補助に対して、一時防御／条件回避を選べる方向。
- 差別化: クワガタ⑥の対象引受けとは逆に「受けない」。うみの対象変更とも重ねすぎない。

### ⑦ 5/7 — 落ちついたねこ「みている」
- 人生テーマ: 自分が走り回らず、場全体を見る。
- 能力方向: 相手の選んだ行動種類を見て、自分の次の選択を少し整える。
- 差別化: いぬ⑦は周囲を支える。ねこ⑦は観察して自分の次行動を決める。

### ⑧ 3/8 — おとしよりのねこ「必要な時だけ」
- 人生テーマ: 普段は休み、本当に必要な一度だけ動く。
- 能力方向: 1ラウンド／ターンのうち使える回数を絞った、条件付きの精密支援。
- 差別化: いぬ⑧は「そばにいる関係」そのもの、ねこ⑧は「少なく動くことの質」。

## 連作

`①まずみる → ②まつ → ③動いたものを追う → ④とびつく → ⑤一度を狙う → ⑥かわす → ⑦場を見る → ⑧必要な時だけ動く`

## いぬ vs ねこ

| 観点 | いぬ | ねこ |
|---|---|---|
| 一語 | いどむ | ねらう |
| 行動順 | まず動く | まず見る／待つ |
| ちから寄り | 強い | 中程度 |
| ちえ寄り | 後半へ増える | 早めから高い |
| ちょうせん | 能動的に数を作る | 条件を整え一度を狙う |
| 後半 | 周囲を支える | 観察して少なく正確に動く |

両方が「けもの＝いどむ」に属しながら、毎ターンの操作順を変えられる。
