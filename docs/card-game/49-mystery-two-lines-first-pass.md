## 属性テーマ

ふしぎ = **くつがえす**。

普通なら不利・不要・終わったと見る状態や、当たり前だと思っている評価軸に、別の使い道・見方を作る。

- ほし: **ものさしを変える**
- ぬいぐるみ: **弱さ・古さ・失われたものに別価値を作る**
- ？？？: **分類・前提そのものを限定的に疑う**

「何でもルールを書き換える属性」にはしない。

# 1. ほし — ものさしを変える

仮数値曲線:

`①1/4 → ②2/5 → ③4/5 → ④6/6 → ⑤9/6 → ⑥7/8 → ⑦10/3 → ⑧2/10`

合計: ちから41 / ちえ47 = 88。

曲線自体を大きく非対称にして、通常の「高段階ほどバランスよく強い」という見方を崩す。

| 段階 | 現行名 | 人生テーマ | 仮値 | 能力方向 |
|---|---|---|---:|---|
| ① | 星のもとの雲 | まだ星ではない | 1/4 | 未完成・メインとして低い数値でも、次の選択を整える価値。 |
| ② | 集まる星の雲 | 集まるほど形が見える | 2/5 | 複数の小さい人生要素が集まることを価値化するが、単純枚数バフにはしない。 |
| ③ | うまれかけの星 | 途中だからこそ変われる | 4/5 | 完成前の段階を、へんしん／ときおくり等の柔軟さへつなぐ。 |
| ④ | 若い星 | 安定して輝き始める | 6/6 | バランス型の基準点。ここでは能力を盛りすぎず、前後の極端さを際立たせる。 |
| ⑤ | 輝く星 | 明るさがピークへ | 9/6 | 高いちからを持つが、「高い数値そのもの」以外の評価軸を次段階へ準備する。 |
| ⑥ | ふくらんだ星 | 大きくなるが、終わりにも近づく | 7/8 | 数値の総量・大きさと、今後の不安定さを両方価値にする。単純強化ではない。 |
| ⑦ | はじける星 | 終わりが最大の出来事になる | 10/3 | ちから10・ちえ3という極端な一瞬。場を離れる／次へ進むことまで含めて大きな意味を持たせる候補。無条件メイン除去は作らない。 |
| ⑧ | 星のなごり | 終わった後の残りにも価値 | 2/10 | 普通なら「ピーク後で弱い」状態を、最高級ちえと過去参照で別の強さへ変える。 |

連作:
`まだ星でない → 集まる → 生まれかける → 安定する → 輝く → ふくらむ → はじける → なごりになる`

## 能力設計上の問い

ほしは段階ごとに、

- 未完成は弱いのか
- 大きい方が強いのか
- 終わることは損なのか
- 最高ちからと最高ちえ、どちらが「完成」なのか

という評価のものさしを揺らす。

⑦10/3と⑧2/10は両方が象徴的なピークであり、⑦に留まる／⑧へ進む選択を明確に作る。

# 3. ？？？ — きまりを疑う

仮数値曲線:

`①2/2 → ②4/2 → ③3/6 → ④2/8 → ⑤7/4 → ⑥10/3 → ⑦1/10 → ⑧5/5`

合計: ちから34 / ちえ40 = 74。

意図的に普通の成長曲線を作らない。段階名自体が `点 → ぷる → 足？ → 目？ → 羽？ → でっかい？ → ちっちゃい？ → 点……？` なので、「どの器官が増えれば強くなるか」「大きい方が上か」という分類を毎段階少しずつ疑わせる。

ただし、カード本文でカード種類・属性・段階を恒常的に自由変更するような万能能力は作らない。**各段階につき1つの前提だけを限定的に揺らす**。

| 段階 | 現行名 | 人生テーマ | 仮値 | 能力方向 |
|---|---|---|---:|---|
| ① | 点 | 何なのか分からない | 2/2 | 何も揃っていない／分類しにくい盤面でも小さく動ける。 |
| ② | ぷる | 形らしきものが出る | 4/2 | ちから優位だが、普通の身体能力として説明しない。「低いちえ＝ただ弱い」を限定的に崩す方向。 |
| ③ | 足？ | 動けそうで、何か違う | 3/6 | 「移動した＝セカイ変更」等の通常分類を直接書き換えず、カード移動の別の使い道を作る。 |
| ④ | 目？ | 見えているのかもしれない | 2/8 | 相手の公開情報を通常と違う角度から利用。裏向きカードを恒常的に覗かない。 |
| ⑤ | 羽？ | 飛べるのかもしれない | 7/4 | 高いちからへ急に振れるが、通常の能動行動と同じ使い方にしない。 |
| ⑥ | でっかい？ | 大きい＝強い？ | 10/3 | 象徴的ちから10。ただし「でっかいから最強」と結論づけず、次の⑦で真逆へ振れる。能力は控えめ候補。 |
| ⑦ | ちっちゃい？ | 小さい＝弱い？ | 1/10 | 最低級ちから・最高級ちえ。低い数値を使うふしぎテーマを強く示すが、ぬいぐるみ⑦と同じ能力にはしない。 |
| ⑧ | 点……？ | 最初へ戻ったようで違う | 5/5 | ①の点と同じに見えてバランス値。過去の極端な段階を「どれが本当だった？」と次の選択へつなぐ。 |

連作:
`何か分からない → 形が出る → 動ける？ → 見える？ → 飛べる？ → 大きい？ → 小さい？ → また点に見える？`

## ？？？で許可する「くつがえし」の範囲

能力具体化時は、各段階1つまで以下のような限定テーマを候補にする。

- 高い／低い能力値の評価
- 同じ／異なるカード種類の評価
- 最初／最後の行動の評価
- 盤面にある／ないことの評価
- 引き分けの意味

一方、以下は避ける。

- 好きなカード種類として扱う
- 好きな属性へ変える
- 好きな段階になる
- 基本ルールを毎ターン自由に選んで無視する
- 相手に裁定不能な隠れ状態を作る

## げんそうとの差

- げんそう: 今の評価軸のまま、条件・代償で「もっと先」へ行く。
- ふしぎ: そもそも、その評価軸だけで見てよいのかを変える。

ほし⑦や？？？⑥にちから10があっても、それをさらに11・12へ伸ばすのがふしぎの主役ではない。
