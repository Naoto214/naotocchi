## 8属性の暫定戦術
- ひと = **えらぶ** — 状況を見て選択する。
- けもの = **いどむ** — まず動き、行動から展開を作る。
- みずべ = **わたる** — 場所・環境を移って適応する。
- うみ = **ながれる** — 手札・状態・関係を流動させる。
- むし = **かわる** — 段階・経路・留まる／飛ばすを戦術にする。
- くさ = **そだてる** — 今仕込み、時間差で実らせる。
- げんそう = **こえる** — 条件・代償付きで通常の限界を突破する。
- ふしぎ = **くつがえす** — 普通なら不利な状態の意味・評価基準を変える。

現時点では8つともプレイヤーが主に考える問いが異なり、統合の必要は見つかっていない。最終確定は横断監査完了後。

## 横断監査済み: カード種の独占
属性は得意分野を持つが、基本カード種・基本行動を独占しない。
- ちょうせん: けものが得意だが全属性が使用。
- あそび: けものが得意。ひと・くさ等も別の使い方をする。
- セカイ: みずべが得意。くさは根づく、ひとは人生の場所として利用。
- 準備／しかけ: くさが得意。げんそうは代償、ふしぎは使用後の価値等に使える。
- 手札操作: うみが得意。ひとは選択、げんそうは代償等として扱える。
- ときとばし: むしが特に活用するが全属性の基本行動。
- へんしん: 全属性の基本行動。うみは流動性の一部として扱いやすい程度。
- 捨て札: ふしぎ寄りだが、人間=経験、くさ=循環、むし=経路確認、げんそう=再生候補等に使う。

方針: **属性専用カード種を基本ルールとして作らない。** 同じカードを属性ごとに違う思想で使えるよう、主にメイン側の能力で差を作る。

## 横断監査済み: 複雑さ
属性ごとの習熟難度差は許容するが、難易度とカードパワーを比例させない。
目安: けもの=直感的、ひと・みずべ・くさ=中程度、むし・うみ・げんそう・ふしぎ=判断がやや深い。
上級属性でもカード文・物理処理は簡潔にし、難しさは処理量ではなく意思決定から生ませる。

## 確定仕様の再確認: メイン移動
### たんじょう【確定】
好きな段階から開始できる。通常時コストは段階番号と同じ。
`①=時1 / ②=時2 / ③=時3 / ④=時4 / ⑤=時5 / ⑥=時6 / ⑦=時7 / ⑧=時8`
高段階直接たんじょうは禁止しない。

### ときとばし【確定／名称のみ暫定】
同種族の後段階へ段階差ぶんの時で進む。例: ③→④=時1、③→⑥=時3、⑦→⑧=時1。
必要な時がある限り共通回数制限なし。飛ばした中間段階は経由扱いにせず、中間カードの能力も発動しない。
実際に進む場合、旧段階メインは捨て札、新段階メインをメイン枠へ置く。

### へんしん【確定】
別種族へ変更。変身先の段階番号ぶんの時を支払う。例: どの段階からでも別種族⑥へなら時6。
必要な時がある限り共通回数制限なし。専用へんしんカード不要。恋人関係・交際経過・結婚状態は原則維持。
変身元メインは捨て札、手札の変身先メインをメイン枠へ置く。

### たまご／物理版
開始時のたまごはデッキ外カード。たんじょう時はたまごをデッキ外の専用待機領域へ戻す。メイン除去等でメイン枠がたまごへ戻る場合は、そのたまごをメイン枠へ戻す。
物理版では **たまご置き場が必要**。ただし、その具体的な位置・形・サイズは物理カード／プレイマット設計フェーズまで保留する。

## メイン移動5項目の横断監査結果
### 1. 高段階直接たんじょう vs 低段階から積む
8属性すべてで両ルートは成立可能。
- 直接高段階 = 遅いラウンドに大きな時を払い、その段階の即時価値を使う。
- 低段階から積む = 早く人生を始め、後半は差分コストで進めるため残り時を他行動へ使いやすい。経由能力を持つ一部カードでは追加価値もあり得る。
- **直接高段階カードを能力なしにしない。** 単体でも固有能力が成立し、経由は一部カードの追加の使い方に留める。

### 2. むしによるときとばし独占
問題なし。全属性が同じ基本ときとばしを使う。
むしの個性は恒常コスト軽減や回数優遇ではなく、**どこに留まる／どこを通る／どこを飛ばすかに意味を与えること**。
「むしだけ常時時-1」「むしだけ回数無制限」等、基本行動自体をむしだけ優遇する設計は避ける。

### 3. うみ vs むし
境界は維持可能。
- うみ = **今ある手札・状態・関係・対象をどう流動させるか**。
- むし = **人生のどの段階を通る／飛ばす／留まるか**。
- うみを「へんしんコスト恒常軽減属性」にはしない。へんしんは全属性の基本行動。
- カクレクマノミの同種族内性転換等はルール上ときとばし側の段階変化だが、属性テーマとしては自身の状態が流動する「ながれる」を表現できる。

判定目安: 「どの段階を通った？」ならむし寄り。「今あるカード・対象・状態をどこへ動かす？」ならうみ寄り。

### 4. 連続ときとばし／連続へんしん
**現時点では共通回数制限を追加しない。**

ときとばしは1段階ずつ刻んでも一気に飛んでも基本合計時が同じ。刻む場合は途中段階カードを実際に手札から使う必要があり、途中能力を使う価値と手札消費の交換になる。

へんしんは変身先段階ぶんの時に加え、変身先メインを手札から消費し、変身元が捨て札へ行く。時＋手札消費が自然なブレーキになる。

危険効果として厳しく扱う:
- 段階移動／へんしんで時を大量回復する。
- へんしんコストを簡単に0へする。
- 変身元メインを即座に手札へ戻して再利用する。

これらが複合してループを作らないようカード設計時に監査する。模擬対戦で長い1ターン・反復コンボが実測された場合のみ、カード調整→それでも不可なら最小限の基本回数制限、の順で検討する。

### 5. 経由能力／履歴管理
**プレイヤーの記憶だけを証拠にする履歴能力は原則作らない。**

原則:
1. その場で処理できる経由効果は、その瞬間に処理する。例: 「カブトムシ④から⑤へときとばした時」。
2. 後から参照するなら、捨て札など公開領域を見れば確認できる条件を使う。
3. 専用の経路カウンター・人生履歴トラック等は基本作らない。

注意: 「捨て札にカブトムシ④がある」ことは、必ずしも「④を実際に経由した」証拠ではない。手札から捨てた可能性もある。そのため、本当に経由そのものが重要なら移動した瞬間に処理するのを優先する。

経由参照はむしでも使いすぎず、代表テスト目安では1種族8枚中1〜2枚程度。その他属性ではさらに限定的にする。履歴管理ゲームにしない。

## 発動条件語彙 — 次フェーズで共通整理
連続移動との関係から、少なくとも以下を区別する必要がある。
- **「たんじょうした時」**: 手札からたんじょうした時だけ。
- **「この段階になった時」**: たんじょう／ときとばし等で実際にその段階へ入った時。

具体的な共通語彙・へんしん時の表現は後でカード文テンプレートとして整理する。強い段階到達能力を大量に置き、1ターンで連鎖発動する設計は避ける。
