## 8属性の暫定戦術
- ひと = **えらぶ** — 状況を見て選択する。
- けもの = **いどむ** — まず動き、行動から展開を作る。
- みずべ = **わたる** — 場所・環境を移って適応する。
- うみ = **ながれる** — 手札・状態・関係を流動させる。
- むし = **かわる** — 段階・経路・留まる／飛ばすを戦術にする。
- くさ = **そだてる** — 今仕込み、時間差で実らせる。
- げんそう = **こえる** — 条件・代償付きで通常の限界を突破する。
- ふしぎ = **くつがえす** — 普通なら不利な状態の意味・評価基準を変える。

現時点では8つともプレイヤーが主に考える問いが異なり、統合の必要は見つかっていない。最終確定は横断監査完了後。

## 横断監査済み: カード種の独占
属性は得意分野を持つが、基本カード種・基本行動を独占しない。

例:
- ちょうせん: けものが得意だが全属性が使用。
- あそび: けものが得意。ひと・くさ等も別の使い方をする。
- セカイ: みずべが得意。くさは根づく、ひとは人生の場所として利用。
- 準備／しかけ: くさが得意。げんそうは代償、ふしぎは使用後の価値等に使える。
- 手札操作: うみが得意。ひとは選択、げんそうは代償等として扱える。
- ときとばし: むしが特に活用するが全属性の基本行動。
- へんしん: 全属性の基本行動。うみは流動性の一部として扱いやすい程度。
- 捨て札: ふしぎ寄りだが、人間=経験、くさ=循環、むし=経路確認、げんそう=再生候補等に使う。

方針: **属性専用カード種を基本ルールとして作らない。** 同じカードを属性ごとに違う思想で使えるよう、主にメイン側の能力で差を作る。

## 横断監査済み: 複雑さ
属性ごとの習熟難度差は許容するが、難易度とカードパワーを比例させない。

目安:
- けもの: 直感的
- ひと・みずべ・くさ: 中程度
- むし・うみ・げんそう・ふしぎ: 判断がやや深い

ただし上級属性でもカード文・物理処理は簡潔にする。難しさは処理量ではなく意思決定から生ませる。

避ける例: 複数種類の履歴・回数・直前状態を同時に要求する長条件。

## 確定仕様の再確認: メイン移動コスト
今回の監査で、過去の正本に「通常時コスト」の対応表が明文化されていないことが判明したため、`02-main-system.md` に明記済み。

### たんじょう【確定】
好きな段階から開始できる。通常時コストは **段階番号と同じ**。

`①=時1 / ②=時2 / ③=時3 / ④=時4 / ⑤=時5 / ⑥=時6 / ⑦=時7 / ⑧=時8`

高段階直接たんじょうは禁止しない。

### ときとばし【確定／名称のみ暫定】
同種族の後段階へ **段階差ぶんの時** で進む。

例: ③→④=時1、③→⑥=時3、⑦→⑧=時1。

必要な時がある限り共通回数制限なし。飛ばした中間段階は経由扱いにせず、中間カードの能力も発動しない。

### へんしん【確定】
別種族へ変更。**変身先の段階番号ぶんの時**を支払う。

例: どの段階からでも別種族⑥へへんしんなら時6。

専用へんしんカード不要。恋人関係・交際経過・結婚状態は原則維持。

### 共通設計意図
- 高段階直接たんじょう = 遅いラウンドに大きな時を払って、その段階から直接人生を始める。
- 低段階からときとばし = 早く人生を始め、現在位置から差分コストで進める。
- 特定段階を実際に経由した価値は一部カードで作ってよいが、全カードを履歴参照にしない。

**撤回済み案:** `①②=時1 / ③④=時2 / ⑤⑥=時3 / ⑦⑧=時4` の段階帯コスト案は採用しない。正本へは採用仕様として残さない。

## 現時点で大きな基本ルール矛盾は未検出
今回確認した範囲では、以下は互いに両立している。
- 10ラウンドの時 `R1=1 ... R10=10`
- 通常時コスト `①=1 ... ⑧=8`
- ときとばし=段階差コスト
- へんしん=変身先通常時コスト
- 高段階直接たんじょう可能
- 高段階を完全上位互換にしない設計原則
- ちょうせんは自分ターン1回まで
- 属性は基本行動を独占しない
- 物理版で処理可能なことを優先する

ただし、これは**ゲームバランスが確定したという意味ではない**。実際の時1の価値、直接高段階たんじょうの強さ、各能力の効果量等は後の模擬対戦で検証する。

## 次に再開する場所
**たんじょう／ときとばし／へんしんの8属性横断監査を、確定した通常時コスト `①=時1〜⑧=時8` を前提に続ける。**

重点:
1. 高段階直接たんじょうと低段階から積むルートが、8属性それぞれで両方成立するか。
2. ときとばしを得意とするむしが基本ルールを独占・破壊していないか。
3. へんしんを活用するうみと、段階を扱うむしの境界が保たれるか。
4. 連続ときとばし・連続へんしんが、時コストだけで十分制御できるか。
5. 経由能力が多すぎて履歴管理ゲームにならないか。
