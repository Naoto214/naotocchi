# 34 全カードプール役割地図 第1稿

最終更新: 2026-09-14

状態: **個別カード大量設計前の役割配分。基本ルール変更なし。**

## 目的

477候補＋未展開の世界source componentsを、先着順で能力化しないための全体地図を作る。

この文書では、

- どのカード種類が何を主役にするか
- 同じ処理でも種類ごとにどう意味を変えるか
- すでにA/B・カブト／クワガタで試した処理をどこへ残すか
- 100あそび、38あいてむ、34できごと等へ能力を配る前に何を空けておくか

を整理する。

## 1. 7種類の主役

### メイン — 「どう生きるか」

- 人生の中心。
- 8段階・属性・ちから／ちえを持つ唯一の種類。
- 能力はその種族・その段階の生態／人生を翻訳する。
- 高段階を単純上位互換にしない。
- たんじょう／ときおくり／へんしん／ちょうせんとの接続が主。
- 他種類の仕事を万能に奪わない。

### なかま — 「誰と日常を作るか」

- 時0、最大3の盤面支援。
- 基本は継続・小さな誘発・他カードとの連携。
- 本編behaviorを能力理由にする。
- 単体で大技を出すより、日常の積み重ね・補助・反応を担当。
- 盤面に複数並ぶため、文章密度と常時監視負荷を特に抑える。

### こいびと — 「関係をどう育てるか」

- 交際0→1→2→3→結婚という既存基本行動に接続。
- 66で0開始と誘発を整理済み。0での交際開始、0→1・1→2・2→3の進行、3→結婚を分ける。[66](66-relationship-start-and-romance-profile.md)のユーザー確定方針により、各メイン・こいびとへ性別・恋愛対象・恋愛タイプを割り当てず、交際成立条件に使わない。
- firstRegionとhookを人格・能力理由にする。
- 交際開始、進行、結婚、関係終了、再出発のどこを担当するかを分ける。
- 結婚時基本そだち+10を各カードが重複して上乗せしすぎない。
- 本編の性別・恋愛タイプの仕組みとは切り離す。必要な組み合わせ条件がある場合のみ個別のカード能力に明記し、名前・絵柄・本編プロフィールから隠れた条件を補わない。

### セカイ — 「いつ・どんな環境で・どこで生きるか」

本編概念順：**じかん → てんき → きせつ → ばしょ**。

- ばしょ13は既にCARD候補。
- じかん4・てんき4・きせつ4はsource componentとして保持し、カード化方式は未確定。
- 基本は盤面全体・行動条件・カード種類横断の環境を作る。
- メインの固有能力のように「自分1体だけ強化」する効果ばかりにしない。
- みずべ属性の「わたる」を助けるが、みずべだけが世界を触れる設計にはしない。

### あそび — 「今、何をするか」

- 本編の100ゲームを行動へ翻訳。
- 即時性・能動性を主役にする。
- 同じgeneratorの色違い能力を量産しない。
- 元ゲームの操作、勝利条件、リスク、読み、積み上げのうち何を翻訳したか説明できるようにする。
- `すぐつかう` が中心候補だが、かくれんぼ旧試作のようにゲーム性が合う場合は `しかける` も許容。
- 「あそび＝能力値+1」だけにしない。

### あいてむ — 「何を持つ・備えるか」

- 現行本編38候補。
- SHOP系は `みにつける` と親和性が高い。
- CONSUMABLE系は `すぐつかう`／条件付き一回効果と親和性が高い。
- 本編の分類をそのまま新しいカード種類へ増やさない。
- 準備3枠を使う意味を作る中心種類。
- 同じ「+1」装備を対象違いで増殖させず、道具の機能から役割を出す。

### できごと — 「人生に何が起きたか」

- 一時的な大きな転機・外部変化・経験。
- キャラクターや物そのものを代理しない。
- 新しい専用メーター／状態を作らず、既存盤面・時・そだち・カード移動等へ翻訳する。
- 既存試作6枚、伝説、なおと、人生イベント等を核にする。
- ログ文違いを大量カード化しない。

## 2. 主要処理の「第一担当」

第一担当は独占ではない。同じ処理を他種類でも使えるが、理由・条件・強度を変える。

| 処理・ゲーム体験 | 第一担当 | 第二候補 | 注意 |
|---|---|---|---|
| 段階を進む／留まる判断 | メイン | あいてむ、できごと | カブト等の種族テーマを汎用サポートが消さない |
| 別種族へのへんしん | メイン基本行動 | あいてむ、できごと | 専用カード必須にはしない |
| ちょうせんの数値操作 | メイン、あそび | あいてむ | 恒常+ばかりにしない |
| 重要な勝負の追加そだち+5 | 条件付きメイン／なかま／あそび | こいびと | 通常勝利+5は維持 |
| 手札交換・山札上下 | メイン、なかま、パズル系あそび | できごと | 山札確認過多に注意 |
| ドロー | なかま、条件付き能力 | できごと | 無条件低コスト大量ドローを避ける |
| 時軽減 | 条件付きメイン、あいてむ | なかま、セカイ | 0まで可。恒常軽減の積み過ぎに注意 |
| 対象変更 | うみ系メイン、反応系カード | あそび、あいてむ | クワガタ⑥等との役割衝突監査 |
| 防止・軽減 | あいてむ、なかま | できごと | 防止だらけでゲームを停滞させない |
| 準備枠を育てる | くさ系メイン、あいてむ | なかま、セカイ | 準備3枠の圧迫をゲーム性にする |
| しかける／ブラフ | あそび、できごと | なかま | たぬき、旧かくれんぼを基準にする |
| 捨て札再利用 | 老成メイン、記憶系セカイ | できごと | 無限循環を避ける |
| なかま探索／加入支援 | できごと、セカイ | なかま | E-new-encounterを基準 |
| こいびと探索／交際支援 | こいびと、できごと | あいてむ | おはな等と重複監査 |
| 結婚後の価値 | こいびと | できごと | 記念日候補を別軸にする |
| セカイ変更 | セカイ、みずべ系メイン | できごと、あいてむ | 「とつぜんのたび」と通常変更を区別 |
| 相手の行動を読む | クワガタ等メイン、ボード系あそび | しかけるカード | 記憶依存を減らす |
| 大きな人生転機 | できごと | 高段階メイン | 小さなログを大技化しない |

## 3. あそび100候補の大分類と翻訳方向

32のsource categoryを能力設計へ落とす前の方向。

### 反射・タイミング
例：archery / bowling / darts / baseball / freeKick / rhythmHighway / takoyaki

翻訳候補：
- 条件を満たす「今」の一手
- 数値を見て使うタイミング
- 成功時だけ追加成果
- 一度きりの精密な補助

同じ「ちから+1」へ統一しない。

### 移動・回避
例：road / race / ringFlight / submarine / frogger / skyShooter / jumpQuest

翻訳候補：
- 対象を避ける／変更する
- セカイを移る
- 妨害をかわす
- 盤面カードを一時的に守る

対象変更を全てここへ集めず、移動・回避・世界変更を分ける。

### 物理・ねらい
例：miniGolf / billiards / basketball / curling / catapult / pinball

翻訳候補：
- 対象を1つ選ぶ
- 小さい成功と大きい成功を分ける
- 条件付きで+5成果
- 「狙った対象」に関する効果

### 盤面パズル
例：2048 / matchThree / picross / sudoku / lightsOut / slidePuzzle / pushPuzzle / pipeConnect

翻訳候補：
- 手札・山札・捨て札の並べ替え
- 2枚を組み合わせる
- 段階的な準備
- 少ない選択肢から正解を作る

2048旧試作の手札整理を基準の1つにする。

### 対人読み合い／ボード
例：reversi / connectFour / gomoku / checkers / mancala / blackjack / yachtDice / animalShogi / hitBlow

翻訳候補：
- 相手の選択を見る
- 公開情報に応じて効果が変わる
- 二択／三択
- リスクを取るか止めるか

旧「うそつきしょうぶ」の読み合い役割をここに保持する。

### 構築・積み上げ
例：stack / jenga / domino / towerDefense

翻訳候補：
- 準備枠
- 次ターンへの遅延成果
- 複数カードが揃った時の成果
- 崩す／崩れるリスク

くさ属性と似るため、「あそびは短期の構築」「くさメインは人生をまたぐ準備」を意識する。

### 探索・冒険
例：roguelike / dungeon / hauntedHouse / voxelMine / fishing

翻訳候補：
- 山札上から探す
- 複数候補から1枚選ぶ
- リスク付き探索
- セカイとの連携

### 戦闘・防衛
例：streetFight / tankBattle / bomber / missileCommand / asteroids

翻訳候補：
- ちょうせん
- 妨害への反応
- 相手カードへの一時的干渉
- 防御との選択

メイン除去を安売りしない。

### 創作・配置
例：cake / bento / lineTrace

翻訳候補：
- みにつけるカードの付け替え
- 準備枠の順序・選択
- なかま／こいびとを含む盤面配置の活用

単なる回復7種類にしない。会話、公開情報、手札、関係、相手との交流等へ役割を分ける。

## 6. 既存試作を基準点として残す

- なかま：カワウソ、サル、ふくろう、ハリネズミ、カタツムリ、たぬき

## 7. 役割衝突を見つけた時の優先順位

同じ効果を複数候補が欲しがる場合：

1. 本編・生態・ゲーム性との結びつきが最も強い候補へ主要版を置く。
2. 既に模擬済みカードなら、理由なく奪わない。
3. 他候補は条件・対象・タイミング・代償を変えて別の意思決定にする。
4. 名前だけ違う同効果になるなら、片方をHOLDにすることも許容。
5. 新しい共通ルールを足して解決するのは最後。

## 8. 複雑さ予算

数百候補あるため、全カードを個性的にしようとして全カードを長文化しない。

- バニラ／短文カードを残す。
- メイン原則1能力。
- なかまは盤面に3枚並ぶため特に短く。
- こいびとは関係進行の基本ルールを本文で再説明しない。
- あそび／あいてむ／できごとは既存正式語彙を使う。
- 専用カウンター／マーカーは増やさない。
- 期限付き効果は既存ルールで追える範囲にする。

## 9. 次に個別設計へ進む順番

大量に477枚を一度で書かず、役割地図を保ちながら次の順でブロック設計する。

1. **なかま26** — behaviorが明確で、全体サポート役の骨格を作りやすい。
2. **こいびと18** — 関係進行の役割を先に分配する。
3. **あいてむ38** — 準備枠・すぐつかう・しかけるを整理する。
4. **できごと34** — 他種類の役割を見て重複を削る。
5. **あそび100** — 大分類ごとに能力を設計し、同型量産を防ぐ。
6. **セカイ** — ばしょ13の本文と4軸方式を監査する。4軸方式に基本ルール変更が必要ならその地点で重要判断として止める。
7. **メイン残り232形態** — 先に周辺カードの役割空間を見たうえで、生態・8段階・属性を横断しながら設計する。

この順序でも、メインがゲームの中心であることは変わらない。周辺カードの能力空間を先に決めることで、メイン固有能力を汎用サポートで食い潰すのを防ぐ。
