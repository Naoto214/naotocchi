# なかま5
Aから流用し、人生接続観察を邪魔しにくいものを選ぶ。

1. **カワウソ** — あそび→ちょうせん勝利時そだち+5。低段階のまま行動する価値を作る。
2. **サル** — メイン能力コピー。各段階能力の差を比較しやすくする。
3. **ふくろう** — 山札上3枚整理。16枚あるメインのうち「今使いたい段階」を選びやすくする。
4. **カタツムリ** — 後攻時の小さな山札整理。先攻後攻差を大きく変えず、手札段階選択を助ける。
5. **たぬき** — しかける連携。段階移動以外へ時を使う選択肢を残す。

**61全体監査追記:** 下記Bは、しかけるの「かくれんぼ」「トイレットペーパー」を両方外しているため、しかける0枚。たぬきの能力を自デッキだけで成立させられず、この役割を検証できる構成にはなっていない。B40枚は比較履歴として維持し、差し替え案と再試験を[61 U07](61-full-rules-and-card-text-audit.md)の課題にする。

ハリネズミはBでは外す。防止テストはAですでに担当しており、人生接続観察への寄与が小さい。

# こいびと3
「今すぐ次段階へ行かず、同じ段階に留まって関係を進める」価値を観察する。

1. **ビルのねこ社長** — 交際開始時の手札交換。
2. **あみものがすきなクモさん** — 交際進行時、準備カードの時軽減。
3. **とけないゆきだるま** — 関係終了後に次の選択肢を得る。

うみのにんぎょはBでは外す。結婚時セカイ回収より、「留まる／進む」の観察を優先する。

# セカイ3
1. **とかい** — そのターン2枚目のカード使用に小利益。高段階へ時を使い切るか、低段階に留まり複数行動するかを比較。
2. **もり** — なかま2枚以上でちえ+1。盤面を育てながら同じ段階に留まる価値。
3. **きおくのみずうみ** — 捨て札の過去を山札へ戻す。実際に通った過去段階・人生カードを資源として意識させる。

しんかいは手札枚数依存で段階接続テストとの直接関係が薄いため外す。

# あそび4
1. **スノーボード** — 即時の能力値補助。低段階からでも勝負する選択肢。
2. **2048** — 手札の同種2枚を交換。高段階メインが早期に手札で腐った時の整理を試す。
3. **キャッチボール** — なかまがいれば能力値補助。盤面を作って留まる価値。
4. **うそつきしょうぶ** — 段階移動と無関係な読み合いを最低限残す。

かくれんぼはBでは外す。対象変更テストはAで担当済み。

# あいてむ4
1. **サングラス** — 低段階でも自分からちょうせんする価値を補助。
2. **シルクハット** — へんしん時-1。ときとばしと別種族へんしんのコスト差を比較する重要カード。
3. **おはな** — 交際進行時そだち+5。段階を急がず関係を進める選択肢を作る。
4. **ハグ** — そだち回復。段階選択以外の守りを最低限残す。

トイレットペーパーはBでは外す。置換テストはAで担当済み。

# できごと5
1. **うんめいのへんしん** — 次のへんしん時-2。Bで最重要の比較カード。ときとばしとの競合を観察。
2. **あたらしいであい** — なかま／こいびとを探す。留まって盤面を作るルートを補助。
3. **とつぜんのたび** — セカイを手札へ戻す。盤面固定を崩し、人生ルートの再判断を促す。
4. **さいごのじかん** — ⑧またはR10で手札整理。⑧へ進む意味を補助するが、直接⑧だけが得しすぎないか監査する。
5. **おおきなびょうき** — 相手メインのちから・ちえ-2。現在段階に留まる／次へ進む判断を相手から揺さぶる干渉。

すれちがいはBでは外す。恋愛関係破壊より人生接続観察を優先。

# 横断監査
- 16/40がメインなので「メインを引けない」はAより大幅に減る代わり、早期に高段階メインを抱える確率が高くなる。これはBの意図したテスト対象。
- ときとばし支援カードを大量投入していないため、「ときとばしが簡単すぎて刻む／飛ばす判断が消える」ことを避ける。
- へんしん支援はシルクハット＋うんめいのへんしんの2枚に限定。これで同種族継続と別種族へんしんを比較できる。
- 留まる価値は恋愛・なかま・あそび・セカイから作り、基本ルールへ「留まるボーナス」は追加しない。
- Aで検証済みの置換・防止・対象変更はBでは薄くしてよい。

# 初回B模擬で測る項目
1. R1〜R3でどの段階をたんじょうするか。
2. 1試合あたりのときとばし回数。
3. 1段階刻み／2段階以上飛ばしの比率。
4. 現段階に1ラウンド以上留まった回数。
5. 人→カブト／カブト→人のへんしん回数。
6. カブト③→④、③→⑤以上、③留まりの選択率。
7. カブト⑦→⑧へ進んだ率と、⑦に留まった理由。
8. 人⑥→⑦→⑧で、数値低下を受け入れて能力目的で進む場面があるか。
9. 高段階メインの手札死に札率。
10. 直接⑤〜⑧たんじょうが低段階開始より強すぎないか。
