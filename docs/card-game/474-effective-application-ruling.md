## 裁定

「発動した」「解決した」「効果が適用された」は別の事実である。処理順が来て指示を確認・処理したことだけでは、効果の実効的な適用を証明しない。

そだちは01の0〜100に収める。増加指示を処理しても上限により実増加が0で、他に実際に適用された効果部分もなければ、効果適用なし。じんとりに限らず、実効的な適用が何も発生しなかったと完全な処理証拠で確認できる場合に適用する。アリジゴク⑥の誘発・⑦の当ターン適用履歴の根拠に数えない。発動・解決と指示量／実増加／上限による不増加の記録は残す。

複数部分のうち一部でも実際に適用されれば、効果全体の適用事実はあり。例：そだち増加0でも実際に1枚引いた場合。適用済み予約を作ることも67どおり適用であり、後で使わなかったことを理由に遡及取消ししない。

未知・証拠欠落を不適用にしない。全stateの不変だけで不適用と決めない（情報を見る等は別途実行証拠が必要）。カードの発動領域から捨て札への通常移動、支払い、解決済みという記録自体を、本文効果の適用部分に数えない。条件不成立、対象不適正、無効化と上限による0は理由を区別する。

各処理は発動参照、解決event、本文source、指示内容、実際の操作結果、適用／不適用／未証明と理由を保持し、前後state/hashと再実行に結ぶ。完全性を立証できない部分が残り、適用された部分も証明できなければ未証明。機械契約への適合だけを真正な発動／解決履歴の証明にしない。
