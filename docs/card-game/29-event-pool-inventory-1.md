本編のログ文1行を機械的に1カードへ変換しない。「プレイヤーがカード名を見て独立した出来事として理解できるか」「カードゲーム上の役割を持たせられるか」を基準に、source eventを束ねる。

## B. せかいの小さな出来事 — ENV_MOMENTS

本編には天気・時間帯ごとに小さな出来事がある。個々のメッセージを全て別カードにすると、セカイカードとの役割重複と水増しが起こりやすい。

そのため第1稿では「個別メッセージ」ではなく、以下のsource familyをHOLD候補として保持する。

### 時間帯4系統

## E. 現段階でカード化しないもの

以下は「本編に存在する」という理由だけでは独立カードにしない。

- 毎年の年齢トースト
- 単なるUI通知
- セーブ／復帰通知
- 同じ意味のログ文違い
- 数値が増減しただけのログ

必要なら、より大きな出来事カードのフレーバー／効果根拠として使用する。
