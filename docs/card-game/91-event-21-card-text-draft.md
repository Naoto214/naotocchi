## 2. 共通の読み方

全21枚は今回の個別割当として**通常・同名3枚、すぐつかう**。伝説・作者という本編区分から自動でレアにしない。なおと／さいごのじかんの「この名前」は各プレイヤーの同名全体発動制限で、無効でも発動回数を戻さない。他のカードへ一律の同名制限を追加しない。

通常の反応・無効・対象再確認・可能な部分の解決に従う。対象以外の発動条件は発動時に確認し、本文が解決時条件を別記した部分は解決時に再確認する。対象移動は特記しない限り効果であり追加の先払いコストではない。山札を見る枚数・引く枚数が不足したら可能な枚数を扱い、手札へ加えられる適格札がない探索でも残りを指定どおり下へ置く。山札下へ複数置く時は好きな順。適用済み予約は発動元が離れても残り、過ぎた開始へ遡らない。R10の最終比較を延長しない。

性別・恋愛対象・相性条件は割り当てない。交際0開始、0→1→2→3→結婚の通常行動を維持する。探索で得た人物や世界は通常配置を別途必要とし、なかま／こいびとの共有1人、自分の行動機会、通常時を省略しない。主語ができごとの効果と、たまごで無効になるこいびと自身の能力は区別する。
