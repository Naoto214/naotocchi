# 種族テーマ

## カブトムシとの差
- カブトムシ: **かわる／いつ進むか**。自分の人生段階の進行判断が主役。
- クワガタムシ: **かまえる／はさむ**。相手の行動を見て反応し、捕らえる・押し返す・選択を狭めることが主役。

クワガタを「カブトよりちからが少し違う」だけにはしない。

## 生態からの翻訳
- 大あご → 相手への反応、対象を捉える、選択を拘束する。
- 縄張り・樹液場での競争 → 相手の能動行動へ構えて待つ。
- 長い幼虫期 → 序盤は急いで段階を上げるより準備を蓄える。
- 成虫の大あごによる争い → ⑥⑦でちょうせん・相手行動への反応がピーク。
- 老成 → ⑧は力押しより、長く構えた経験・読みを価値にする。

# 仮数値曲線
`1/1 → 2/2 → 4/2 → 2/4 → 5/4 → 7/5 → 9/5 → 5/7`

狙い:
- カブトの既存テスト曲線と完全一致させない。
- ⑦を強い成虫ピークにするが、単純な10/4カブト⑦の横コピーにしない。
- ⑧はちからを落としてちえを上げ、老成＝読みへ移す。
- ④さなぎはちからを落とし、直接戦う段階ではない。

# 8段階 第一稿

## ① うまれたての幼虫 — 「もぐる」
仮値: **1/1**

能力方向:
**このカードをたんじょうさせた時、自分の山札の上から2枚を見る。そのうち1枚を山札の上、もう1枚を山札の下へ置く。**

意味:
朽ち木の中へ潜り、先を探る。ドローそのものではなく未来の並びを整える。カブト①の人生開始価値と同型にしない。

## ② 育ちざかりの幼虫 — 「くいすすむ」
仮値: **2/2**

能力方向:
**1ターンに1回、自分がカードを1枚みにつけた時、次にこのターン自分が支払うメイン以外の時を1少なくする。**

意味:
朽ち木を食べ進み、準備から次の行動へつなぐ。軽減は0まで可という既決定ルールを使用。

監査点:
準備カードがないと働かないため、カードプール拡大時の依存度を要確認。

## ③ 大きな幼虫 — 「ためこむ」
仮値: **4/2**

能力方向:
**自分ターン終了時、このターンに時を2以上残していたなら、次の自分ターンに最初にプレイするアクションカードの時を1少なくする。**

意味:
幼虫期に急いで使い切らず、蓄えたものが次へつながる。「留まる／待つ」感を序盤から作る。

監査点:
時の持越しそのものではない。期限付き効果として次ターンまで残る処理が既決定ルールで可能。

## ④ さなぎ — 「じっとかまえる」
仮値: **2/4**

能力方向:
**相手ターンに相手が最初にアクションカードをプレイした時、1ターンに1回、自分はカードを1枚引き、その後手札を1枚山札の下へ置ける。**

意味:
動けない時期を「弱い」だけにせず、相手を観察する段階へする。直接妨害ではなく情報・手札整形。

## ⑤ 出たてのクワガタ — 「ひらく」
仮値: **5/4**

能力方向:
**このカードが⑤として段階変化で出た時、このターン相手が次に自分のカードを対象にする効果を発動した場合、その対象を自分の別の適正なカードへ1回だけ変更できる。**

意味:
羽化して大あごを開く最初の防御。対象変更ルールを使う。

監査点:
直接⑤たんじょうでは発動せず、④を通る価値を作る。ただし段階経由要求を増やしすぎない。

## ⑥ 若いクワガタ — 「つかまえる」
仮値: **7/5**

能力方向:
**1ターンに1回、相手が自分のカード1枚を対象にする効果を発動した時、時1を払って発動できる。その発動の対象を、このカードが適正な対象ならこのカードへ変更する。そうしたなら、このターンこのカードのちから+2。**

意味:
大あごで相手の動きを自分へ引きつけて受け止める。対象変更＋一時的な強さ。

## ⑦ りっぱなクワガタ — 「はさみうち」
仮値: **9/5**

能力方向:
**相手がちょうせんを行ったターン、自分がそのターン次に行うちょうせんでは、宣言後に相手がちから／ちえを変更する効果を使えない。さらにそのちょうせんに勝った時、条件付きでそだち+5。**

意味:
相手が動いた後に構えて捉える全盛期。通常勝利+5に追加+5が乗る「重要な一戦」を作る。

監査点:
「能力値選択を変更するカード」がまだ少ない場合、前半が死文になり得る。より汎用的な反応能力への改訂候補。

## ⑧ 長生きクワガタ — 「みきる」
仮値: **5/7**

能力方向:
**1ターンに1回、相手がアクションカードを発動した時、そのカードが「すぐつかう／みにつける／しかける」のどのプレイ方法で出されたカードかを参照する。このターン中、次に相手が同じプレイ方法のアクションカードをプレイするなら、その時コスト+1。**

意味:
老成して力で挟むのではなく、相手の癖を読む。相手の選択を完全禁止せず、同じ動きを繰り返すほど重くする。

監査点:
しかけるはプレイ時に裏向きで種類・本文非公開のため、プレイ方法自体が公開情報であることとの整合を正本で再確認する。

# 8枚のゲーム上の連作
`①先を見る → ②準備しながら進む → ③蓄える → ④相手を観察する → ⑤初めて受け流す → ⑥自分で受け止める → ⑦勝負で捕らえる → ⑧相手の癖を読む`

カブトの「人生段階をどう進むか」に対し、クワガタは成長するほど **相手を見る割合が増える**。

# カードイラスト→本編への逆輸入ルール
カード版で、段階差・生態・シルエット・表情が本編より明確になった場合、その改善を本編へ戻してよい。

逆輸入するもの:
- キャラ本体の姿勢
- 体格比率
- 顔・象徴器官
- 年齢／成長表現
- 生態的に自然な特徴

原則として逆輸入しないもの:
- カード専用背景
- 枠外エフェクト
- 能力を説明するためだけの小道具
- カード構図にしか必要ない演出

逆輸入後は本編128×128で、他キャラ・世界背景・仲間配置と並べて再検証する。
