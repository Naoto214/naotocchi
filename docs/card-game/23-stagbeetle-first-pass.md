# 種族テーマ

## カブトムシとの差【第2稿で固定する軸】
- カブトムシ: **かわる／いつ進むか**。自分の人生段階と自分の時計を見る。
- クワガタムシ: **かまえる／はさむ**。相手が先に何をしたかを見て、自分の次の行動を強くする。

短く言えば:
**カブト＝自分の時計を見る甲虫。クワガタ＝相手の動きを見る甲虫。**

クワガタを「カブトよりちからが少し違う」だけにはしない。

## 生態からの翻訳
- 大あご → 相手への反応、対象を捉える、受け止める。
- 縄張り・樹液場での競争 → 相手が動いた後の勝負に強い。
- 長い幼虫期 → 序盤は急いで進むより、相手より先に準備する／蓄える。
- 成虫の大あごによる争い → ⑥⑦で反応・ちょうせんがピーク。
- 老成 → ⑧は力押しより相手の繰り返しを読む。

# 8段階 第2稿

## ① うまれたての幼虫 — 「もぐる」
仮値: **1/1**

`このメインがたんじょうした時、発動できる。山札上2枚を見る。そのうち1枚を山札の一番上、残りを山札の一番下に置く。`

役割:
朽ち木の中へ潜り、先を探る。カブト①は手札1枚を戻して1枚引くため、同じ初期整形でも操作を分ける。

## ② 育ちざかりの幼虫 — 「さきにくいすすむ」【第2稿変更】
仮値: **2/2**

`1ターンに1回。自分のターンに、相手がこのターンまだアクションカードをプレイしていない場合、自分が最初にプレイするアクションカードの時を1少なくする。`

役割:
相手より先に朽ち木を食い進む。「みにつける」依存を廃止し、相手がまだ動いていない状況を見る最初のクワガタらしい能力に変更。

裁定メモ:
自分ターン開始時点では通常相手はそのターン行動していないが、相手がしかけ等を反応発動すれば条件状態が変わる。最初の自分アクションへの軽減なので処理は比較的単純。

## ③ 大きな幼虫 — 「ためこむ」
仮値: **4/2**

`自分ターン終了時、このターンに時を2以上残していたなら発動できる。次の自分ターン、自分が最初にプレイするアクションカードの時を1少なくする。`

役割:
今使い切らず、次へ蓄える。時そのものは持ち越さない。

②との違い:
②は「今、先に動く」。③は「今は動かず、次へ備える」。

## ④ さなぎ — 「じっとみる」
仮値: **2/4**

`1ターンに1回。相手ターンに、相手がそのターン最初のアクションカードをプレイした時、発動できる。1枚引き、その後手札1枚を山札の一番下に置く。`

役割:
直接動けない代わりに、相手の最初の一手を観察して手札を整える。

カブト④との差:
カブト④は「次へ進む時を軽くする」。クワガタ④は「相手を見る」。同じ蛹でもカード上の意味を完全に分ける。

## ⑤ 出たてのクワガタ — 「はじめてかまえる」【第2稿変更】
仮値: **5/4**

`このメインがたんじょうした時、またはこの段階になった時、発動できる。このターン、相手が次に自分のカード1枚を対象にする効果を発動した場合、その発動の対象を変更する効果を自分が発動するために支払う時を1少なくする。`

役割:
羽化直後、大あごを開いて初めて構える。④経由必須を廃止し、直接⑤たんじょうでもカードとして機能する。

重要:
⑤自身だけで対象を自由変更するのではなく、対象変更カード／能力との組合せを軽くする。⑥の自前の「受け止める」能力へ成長する前段階。

監査点:
第0弾に対象変更手段が十分存在しない場合は依存度が高い。模擬時に要確認し、必要なら「次に相手が対象を取った時に1枚見る」等へ簡略化する。

## ⑥ 若いクワガタ — 「つかまえる」
仮値: **7/5**

`1ターンに1回。相手が自分のカード1枚を対象にする効果を発動した時、時1を払って発動できる。このメインがその効果の適正な対象なら、その対象をこのメインへ変更する。そうしたなら、このターンこのメインのちから+2。`

役割:
大あごで相手の動きを自分へ引きつけ、受け止める。⑤の「構える」から⑥の「自分で捕まえる」へ進む。

## ⑦ りっぱなクワガタ — 「あとからはさむ」【第2稿変更】
仮値: **9/5**

`1ターンに1回。自分からちょうせんする時、このラウンド中に相手が先にちょうせんしていた場合、発動できる。このちょうせんの間、このメインのちから+1。このちょうせんに勝ったなら、さらにそだち+5。`

役割:
相手が先に勝負へ出たのを見てから、大あごで挟み返す全盛期。

結果:
- 通常は9/5。
- 条件成立時のちからちょうせんは10になり、純粋なカブト⑦10と並べる。
- 勝てば基本+5に能力+5が加わり、その重要な一戦だけ合計+10。
- 相手が先にちょうせんしていなければ追加能力なし。カブト⑦の常時10とは役割が異なる。

「能力値変更を封じる」旧稿を廃止し、現カードプールでも必ず意味のある条件へ変更。

## ⑧ 長生きクワガタ — 「みきる」
仮値: **5/7**

`1ターンに1回。相手がアクションカードをプレイした時、そのプレイ方法（すぐつかう／みにつける／しかける）を記録する。このターン、相手が次に同じプレイ方法でアクションカードをプレイする場合、そのカードの時+1。`

役割:
力で挟むのではなく、相手の癖を読む。同じ動きを禁止せず、繰り返しだけ重くする。

裁定監査:
「しかける」はプレイ時点でプレイ方法自体は明らかであり、カード本文・条件等の非公開情報を参照しない形にする。正式本文化時に公開情報正本と再照合する。

# 16枚横断監査

| 段階 | カブトムシ | クワガタムシ | 差別化 |
|---|---|---|---|
| ① | 手札を入替える | 山札上を並べる | 自分の手札 vs 未来を見る |
| ② | ときとばしせず未来を見る | 相手より先にアクション | 自分の進行 vs 相手の行動状況 |
| ③ | 留まるとちから+1 | 時を残して次へ蓄える | 段階に留まる vs 資源を温存 |
| ④ | 蛹を通ると次が軽い | 相手の最初の一手を観察 | 進行補助 vs 観察 |
| ⑤ | ときとばし羽化で未来を見る | 初めて対象へ構える | 経由報酬 vs 反応準備 |
| ⑥ | そのターン羽化して挑むと強い | 相手の対象を自分へ引きつける | 自分の勢い vs 相手を受ける |
| ⑦ | 常時10/4・能力なし | 9/5、相手が先に挑めば10＋勝利追加 | 純粋ピーク vs 後手反撃ピーク |
| ⑧ | 過去のカブトを使い6/6 | 相手の繰り返しを読み5/7 | 自分の過去 vs 相手の現在 |

結論:
**16枚のゲーム上の役割は十分に分離できる。**
特に⑦は同じ強い成虫でも、カブトは「何もしなくても最大ちから」、クワガタは「相手が先に動いた時だけ最大級」という違いが明確。

# イラストとの接続
能力差をカード絵にも反映する。

- カブト: 前へ進む／羽化する／飛び出す／堂々と立つ。**自分の変化が画面の中心。**
- クワガタ: 潜む／待つ／相手方向へ大あごを構える／挟む。**画面外の相手を意識した構図。**

同じ段階を並べた時、色だけでなく視線・体軸・大あご／角・余白の使い方まで変える。

カード版で本編より良いキャラ本体デザインが生まれた場合は、姿勢・体格・顔・象徴器官・成長表現を本編128pxへ逆輸入してよい。カード専用背景・枠外エフェクト・能力説明用小道具は原則逆輸入しない。
