# 23 クワガタムシ①〜⑧ 第3稿

最終更新: 2026-09-14

状態: **カード用第3稿。第1回模擬の問題を反映。凍結前の最終短期テスト用。**

## 種族テーマ
- カブトムシ: **かわる／いつ進むか** — 自分の時計を見る。
- クワガタムシ: **かまえる／はさむ** — 相手の動きを見る。

仮数値曲線は維持:
`1/1 → 2/2 → 4/2 → 2/4 → 5/4 → 7/5 → 9/5 → 5/7`

カブト:
`2/2 → 3/2 → 5/3 → 1/4 → 5/3 → 8/4 → 10/4 → 6/6`

# 8段階 第3稿

## ① 1/1「もぐる」
`このメインがたんじょうした時、発動できる。山札上2枚を見る。そのうち1枚を山札の一番上、残りを山札の一番下に置く。`

## ② 2/2「すきをみつける」【第3稿変更】
`1ターンに1回。自分がこのターン最初のアクションカードをプレイする時、相手の準備枠にカードがない場合、そのカードをプレイするための時を1少なくする。`

- 旧稿の「相手がこのターンまだアクションをプレイしていない」はほぼ常時成立したため廃止。
- 相手の3×3盤面を見れば条件が分かる公開情報型。
- 相手がまだ構えていない隙を見て先に食い進む。
- 相手が準備枠を1枚でも使えば軽減を止められるため恒常時-1ではない。

## ③ 4/2「ためこむ」
`自分ターン終了時、このターンに時を2以上残していたなら発動できる。次の自分ターン、自分が最初にプレイするアクションカードの時を1少なくする。`

## ④ 2/4「じっとみる」
`1ターンに1回。相手ターンに、相手がそのターン最初のアクションカードをプレイした時、発動できる。1枚引き、その後手札1枚を山札の一番下に置く。`

## ⑤ 5/4「はじめてかまえる」【第3稿変更】
`1ターンに1回。相手が自分のカード1枚を対象にする効果を発動した時、その対象がこのメイン以外なら発動できる。このターン、このメインのちえ+1。`

- 対象変更カード依存を廃止。
- 相手が別の自分カードを狙ったことを見て構える。
- 直接⑤たんじょうでも機能。
- ⑥では実際に対象を自分へ引き受けるため、⑤→⑥で「見る→捕まえる」と成長する。

## ⑥ 7/5「つかまえる」
`1ターンに1回。相手が自分のカード1枚を対象にする効果を発動した時、時1を払って発動できる。このメインがその効果の適正な対象なら、その対象をこのメインへ変更する。そうしたなら、このターンこのメインのちから+2。`

## ⑦ 9/5「あとからはさむ」
`1ターンに1回。自分からちょうせんする時、このラウンド中に相手が先にちょうせんしていた場合、発動できる。このちょうせんの間、このメインのちから+1。このちょうせんに勝ったなら、さらにそだち+5。`

- 条件成立時のみちから10。
- カブト⑦の常時10/4を侵食しない。
- 通常勝利+5と合わせ、重要な一戦だけ合計+10になり得る。

## ⑧ 5/7「みきる」【第3稿本文整理】
`1ターンに1回。相手がアクションカードをプレイした時、発動できる。このターン、相手が次に同じプレイ方法（すぐつかう／みにつける／しかける）でアクションカードをプレイする場合、そのカードをプレイするための時は1多くなる。`

- 「記録する」という独自処理語を廃止。
- 適用済み期限付き効果として既存ルールで処理。
- 相手は別のプレイ方法を選べば回避可能。完全ロックではない。

# 第3稿 短期模擬

## ②
相手準備0なら最初のアクション時-1。相手が前ターンまでにみにつける／しかけるを1枚置いていれば不成立。

評価:
- 盤面だけで確認可能。
- 相手側にも「準備を置いて牽制する」選択が生まれる。
- ただし準備カードが環境に極端に多い／少ないと発生率が偏るため、正式プール完成後に再計測。
- 第0弾試作としては許容。

## ⑤
相手がなかま等を対象に取れば5/5へ。自分自身を狙われた場合は発動しない。

評価:
- 何も対象を取らない相手にはバニラだが、これは「相手を見る」カードとして許容できる条件依存。
- コンボ部品を要求しない。
- ⑥との成長差が明確。

## ⑥
対象を引き受け、時1を払い7→9。

評価:
- 既存対象変更ルール内で処理可能。
- 強いが相手発動＋適正対象＋時1が必要。
- 維持。

## ⑦
相手が先にちょうせんしたラウンドだけ9→10。勝利にはさらに1点等の支援が必要になりやすい。相手は先に挑まないことで能力を抑制できる。

評価:
- 相手の行動順を変える「構え」の圧力が良い。
- 追加そだち+5は高報酬だが条件が複数ある。
- 維持。正式プールで発生率再計測。

## ⑧
相手がすぐつかう→⑧適用→次のすぐつかうだけ時+1。みにつける／しかけるへ切り替えれば回避。

評価:
- 3択のうち直前と同じ方式だけを見るため理解可能。
- 専用マーカー不要。ただし物理版では「このターンだけ」を忘れないようカード横向き等の既存ターン使用済み表現を検討してもよい。専用カウンターは増やさない。
- 維持。

# 凍結判定

**クワガタムシ第3稿を、正式カード候補ではなく「むし属性・近縁差別化テストの基準8枚」として一旦凍結する。**

理由:
1. ①〜⑧の役割が重複していない。
2. カブト8枚と操作軸が分離している。
3. 直接高段階たんじょうでも⑤〜⑧が機能する。
4. ①〜④から刻む場合は山札整形・時温存・観察という別価値がある。
5. 数値曲線はカブトと総量を近づけつつ、ちえ寄りで差がある。
6. ⑥⑦は大あご／縄張りの生態イメージとゲーム操作が一致する。

凍結解除条件:
- 正式第0弾の準備カード比率確定後に②発生率が極端だった場合。
- 対象を取るカードが少なすぎて⑤⑥が死んだ場合。
- ⑦追加+5が実戦で頻発しすぎた場合。
- ⑧の物理版記憶負荷が高かった場合。
- カードイラスト制作で生態・段階の再解釈が必要になった場合。

# カブト vs クワガタ 最終差分

| 段階 | カブト | クワガタ |
|---|---|---|
| ① | 手札を循環 | 未来を覗く |
| ② | 進まず未来を整える | 相手の準備がない隙を突く |
| ③ | 今の段階に留まる | 今の時を残して次へ備える |
| ④ | 蛹を通って次へ進みやすく | 蛹で相手の最初の一手を見る |
| ⑤ | 経由羽化のご褒美 | 他カードを狙う相手を見て構える |
| ⑥ | 羽化の勢いで自分から挑む | 相手の対象を自分へ引き受ける |
| ⑦ | 常時最大ちから | 相手が先に挑んだ時だけ挟み返す |
| ⑧ | 自分の過去のカブトを活かす | 相手の現在の癖を読む |

**カブト＝自分の人生の進み方。クワガタ＝相手との間合い。**
