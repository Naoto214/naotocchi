## ひと代表: おとこのひと

設計軸: **えらぶ**。男性だからちから型ではなく、ひと属性の標準的人生として、人生の各時期で何を選ぶかを表す。

仮数値曲線: `1/1 → 2/2 → 4/3 → 6/4 → 8/5 → 7/7 → 5/8 → 3/9`

| 段階 | 人生テーマ | 仮値 | 能力方向（未確定） |
|---|---|---:|---|
| ① | 赤ちゃん／可能性 | 1/1 | デッキ＝未来から、メイン以外の人生に関わるカードを選ぶ。①から始める価値を作る。 |
| ② | 幼児／あそぶ | 2/2 | あそびを使った時などに、ちから／ちえのどちらを伸ばすか選ぶ。永久累積は避ける。 |
| ③ | 子ども／得意を見つける | 4/3 | ちから／ちえのどちらを得意にするか選ぶ。第一案はそのターン片方+2。 |
| ④ | 青年／挑戦 | 6/4 | ちょうせんでどちらを選ぶかに別の意味を持たせる。単純数値強化だけにしない。 |
| ⑤ | 成人・壮年／人生を広げる | 8/5 | なかま／こいびと／セカイなど「誰と・どこで生きるか」に関わる。 |
| ⑥ | 中年・成熟／使い分ける | 7/7 | 7/7自体が相手を見て選ぶ性格。能力を盛りすぎない。 |
| ⑦ | 高齢期／経験を活かす | 5/8 | 捨て札＝過去の人生から経験を選んで活かす。枚数比例の自動巨大化は避ける。 |
| ⑧ | 老年期／残す | 3/9 | 過去から何かを選び次へ残す。自発的へんしんとの組合せを重点候補。 |

連作: `①何と出会うか → ②どう遊ぶか → ③何を得意にするか → ④どう挑むか → ⑤誰と・どこで生きるか → ⑥状況に応じて使い分ける → ⑦どの経験を活かすか → ⑧何を次へ残すか`

### 横断監査
- 高段階が完全上位互換ではなく「進む／留まる」を選べる曲線を維持。
- ちょうせん基本ルールは曲げない。「ちから」を選べばちから同士、「ちえ」を選べばちえ同士。
- 公開値なので補正前勝敗は予測しやすい。「高い方を選ぶだけ」にせず、しかけ・条件付き能力・別目的で読み合いを作る。
- ①未来／⑦過去の対称性は残すが、両方を同じカード選択操作にしない。
- 高段階直接たんじょうが可能なので、⑧を「直接⑧→即へんしん」が常に最適になる能力にしない。必要なら過去の別段階を参照するが、全段階経由は要求しない。
- ひとは「人生で何を選んできたか」。むしは後で「どの段階を通る／飛ばす／留まるか」を中心にして分ける。

## けもの代表: いぬ

設計軸: **いどむ**。ひとの「考え、選んでから動く」に対し、いぬは **まず動く→その行動から次の展開が生まれる**。ちょうせんだけの属性にはせず、あそび・能動行動・即効性と、後半の信頼／絆まで一生としてつなぐ。

仮数値曲線: `2/1 → 3/2 → 5/3 → 7/4 → 9/5 → 7/6 → 5/7 → 3/7`

| 段階 | 人生テーマ | 仮値 | 能力方向（未確定） |
|---|---|---:|---|
| ① | 生まれたて／ついていく | 2/1 | 誰かがいることで最初の一歩を踏み出しやすくなる。後半の絆能力ほど強くしない。 |
| ② | 子犬／あそびまわる | 3/2 | あそびを使うこと自体が次の能動行動につながる。時回復による連打は避ける。 |
| ③ | 成長期／やってみる | 5/3 | 自分からちょうせんして負けても、完全な失敗にせず次へつながる小さな利益。 |
| ④ | 若犬／まず飛び込む | 7/4 | ターン前半型。早い段階で自分からちょうせん／行動することに意味を持たせる。 |
| ⑤ | 成犬／駆けまわって走り切る | 9/5 | 活動性ピーク。ターン後半型。そのターンに既に行った能動行動が最後の成果につながる。 |
| ⑥ | 成熟犬／一緒に動く | 7/6 | 自分が行動することで、一緒にいる誰かにも利益が生まれる方向。 |
| ⑦ | シニア犬／見守る | 5/7 | 自分が前へ出続けるのでなく、周囲の行動を支える。 |
| ⑧ | 老犬／そばにいる | 3/7 | 人間⑧の「次へ残す」と分け、長く一緒に過ごした関係・現在盤面にいることを価値にする。 |

連作: `①ついていく → ②あそびまわる → ③やってみる → ④まず飛び込む → ⑤駆けまわって走り切る → ⑥一緒に動く → ⑦見守る → ⑧そばにいる`

### 横断監査
- ③の敗北利益は通常勝利報酬より明確に弱くし、わざと負ける方が得にならない。そだち直接獲得は避ける方向。
- ②〜⑤を同型にしない。特に④=ターン前半、⑤=ターン後半で操作感を分ける。
- メインのちょうせんは自分ターン1回まで、という確定ルールを破らない。
- ⑥〜⑧は「誰かがいるだけで+○」にせず、前半から能動的に関わった結果として関係が価値になる設計を優先。
- ⑦5/7→⑧3/7は数値だけなら下がるため、⑧固有能力に進む意味を必ず作る。
- ひと=何をするか選ぶ楽しさ。けもの=動くことで展開を作る楽しさ。

## みずべ代表: かえる

設計軸: **わたる**。実際の生態では身体が大きく変態するが、ゲーム上の主役は「自分自身の変化」ではなく **水・陸など複数の環境を渡り、状況変化へ適応すること**。同じかえるの①〜⑧の変態はゲーム用語上の「へんしん」ではなく段階変化（ときとばし側）。

仮数値曲線: `1/2 → 2/3 → 3/4 → 5/4 → 6/5 → 7/6 → 5/7 → 4/8`

| 段階 | 人生テーマ | 仮値 | 能力方向（未確定） |
|---|---|---:|---|
| ① | 卵／環境に支えられる | 1/2 | 現在の環境を受け入れる。セカイカード必須にしすぎない。 |
| ② | オタマジャクシ／適応する | 2/3 | 今いる環境に馴染み、その環境で動けるようになる。セカイ変更そのものはまだ主役にしない。 |
| ③ | 足が生える／旅立つ準備 | 3/4 | 次の環境へ移る準備。次のセカイ変更等を少し有利にする方向。 |
| ④ | 子ガエル／外へ出る | 5/4 | 新しい環境へ渡った時、移った先ですぐ適応・小さな利益を得る方向。 |
| ⑤ | 若いカエル／行き来する | 6/5 | **セカイが変更されたターン**など「今の移動」に価値を持たせる。過去セカイ参照は⑦へ譲る。 |
| ⑥ | 成体／どこでもやっていく | 7/6 | 移動し続けなくても、現在の環境を活用できる適応力ピーク。複雑なセカイ能力コピーは避ける。 |
| ⑦ | 成熟／経験した場所を活かす | 5/7 | 捨て札のセカイ＝過去にいた場所を参照して経験を活かす。枚数比例の自動強化は避ける。 |
| ⑧ | 老成／一つの場所に縛られない | 4/8 | 現在の環境に過度に依存せず、複数環境を経験していれば追加価値。直接⑧たんじょうだけで旅の成果を得ない。 |

連作: `①環境を受け入れる → ②適応する → ③旅立つ準備 → ④新しい環境へ渡る → ⑤移動の勢いを活かす → ⑥どこでもやっていく → ⑦過去の場所を活かす → ⑧一つの場所に縛られない`

### 横断監査
- 「わたる」は成立。ただし全8段階をセカイカード依存にしない。セカイを引けないだけでほぼバニラになる設計は禁止。
- 三部構成の目安: ①②=適応、③④⑤=移動、⑥⑦⑧=経験した環境を活かす。
- ⑤と⑦を分離。⑤は現在の移動・変更ターン、⑦だけが捨て札の過去セカイを参照する方向。
- ①②はセカイを直接要求しすぎず、「環境／状況への適応」を広く表現する。
- **うみとの差:** かえるは **自分の外側が変わる**。セカイ・環境・居場所を渡って適応する。カクレクマノミは **自分の内側が変わる** 方向で設計し、セカイ変更を主戦術にしない。

## 次に再開する場所

### うみ代表: カクレクマノミ
次はカクレクマノミ①〜⑧を仮設計する。

うみの有力戦術は **ながれる**: へんしん、手札循環、入替、対象変更、自身の柔軟な変化。

重点条件:
- かえるとの差を守る。**かえる=外側の環境が変わる／カクレクマノミ=自分自身の状態・役割が変わる**。
- カクレクマノミの実際の生態に沿う「成長に伴う性転換」を人生曲線へ反映する方向を検討する。
- 性転換を扱う場合、現在の性別と恋愛対象を分け、性別が変わっただけで恋愛対象まで自動変更しない。本編側で検討中の整合性を壊さない。
- 同種族の①〜⑧で起きる性転換は、別種族へのゲーム用語「へんしん」と混同しない。
- うみ属性を「カクレクマノミだけの性転換属性」にはしない。代表個体の生態を活かしつつ、他のうみ種族にも展開できる「自身の流動性」という共通戦術を検証する。

カクレクマノミ第一周後、**かえる vs カクレクマノミ直接比較**を行い、みずべ=わたる／うみ=ながれるがゲーム上でも十分違うか監査する。
