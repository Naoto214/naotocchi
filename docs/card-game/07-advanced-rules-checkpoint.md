変更内容:
- `フェニックス⑥ → フェニックス⑤`
- `サクラ⑤ → サクラ⑥`

理由:
- フェニックス⑤は10/5の極限ピークで「げんそう＝こえる」を第0弾で最も明確に検証できる。
- サクラ⑥は9/5の開花ピークで「くさ＝今仕込んで後で得る」を、直接⑥たんじょうとの比較も含めて検証できる。
- 結果として段階構成は `①②③④④⑤⑥⑦⑧⑧` となり、①〜⑧をすべて含む。
- カブトムシ④1/4と⑧6/6、おとこのひと①1/1と⑧3/9は両端・経路比較に価値があるため維持。
- ぬいぐるみ⑦1/8は「低数値＝弱カードではない」を直接テストできるため維持。

基本思想: 1〜2種族固定を基本にせず、複数種族をへんしんで渡り歩く「1つの人生」をデッキ構築の核として試す。8属性を最低1枚ずつ入れて横断テストする。数値・能力方向は各 `representatives` 正本を優先し、理由なく再設計しない。
