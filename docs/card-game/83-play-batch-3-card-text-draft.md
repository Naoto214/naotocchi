## 2. 共通の読み方

- カード種は7種類。属性や段階はメインだけにあり、同種・同名・同属性を混同しない。
- 印刷時と実際の支払額を区別し、軽減は0まで。追加コストは発動時に決めて払い、無効でも戻らない。本文の効果としての廃棄と区別する。
- 対象とモードは発動時に指定し、連鎖は逆順。通常登場・交際開始・セカイ配置等は反応の途中で自由に挿入しない。
- 予約は発動元が離れても残り、対象個体の領域移動を追わない。66の性別・恋愛対象を使用しない方針、64の期限と65の終了／完了を維持する。
- 上から順に公開する探索は、1枚の効果の中で処理する。途中に新しいカードの発動を挟まず、山札不足なら存在する分だけ。公開中のカードを別の恒久領域へ移すルールは追加しない。
- 同名全体の回数制限は今回の新19には付けていない。複数枚の予約・回収・そだち減少が重なる強度は後の実測へ残す。
