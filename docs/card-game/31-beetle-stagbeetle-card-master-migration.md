# 16枚横断で維持する差

| 段階 | カブトムシ | クワガタムシ |
|---|---|---|
| ① | 手札を循環 | 未来を覗く |
| ② | 進まず未来を整える | 相手の準備がない隙を突く |
| ③ | 今の段階に留まる | 今の時を残して次へ備える |
| ④ | 蛹を通って次へ進みやすく | 蛹で相手の最初の一手を見る |
| ⑤ | 経由羽化のご褒美 | 他カードを狙う相手を見て構える |
| ⑥ | 羽化の勢いで自分から挑む | 相手の対象を自分へ引き受ける |
| ⑦ | 常時最大ちから | 相手が先に挑んだ時だけ挟み返す |
| ⑧ | 自分の過去を活かす | 相手の現在の癖を読む |

**カブト＝自分の人生の進み方。クワガタ＝相手との間合い。**

## 再調整を許す条件

移植しただけでは正式確定しない。以下が全体プール・模擬対戦で確認された場合のみ、理由を記録して再調整する。

- クワガタ②：正式プールの準備カード比率により発生率が極端

- カブト⑦：他メインへちから10が増え、純粋ピークとしての差が薄れる
