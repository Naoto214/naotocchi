## 共通の扱い

- カード種類はあいてむ。属性・ちから／ちえ・段階を新たに持たせない。40枚・準備3枠・既存3方式を維持する。
- 個別の構築区分案は、なおとシリーズ4枚をレア・各同名1枚、残り22枚を通常・各同名3枚とする。本編の価格／入手難度そのものではなく今回のカード設計上の割当。未登録12の正式採否は別途。
- みにつける本文は指定された自分のキャラクターに限る。装備先が離れれば捨て札。メインが移動しても自動的に新メインへ引き継がない。
- 装備の能力は準備枠で適正な装備先にみにつけられている間に使用・適用する。継続効果と適用済みの期限付き効果は06どおり区別する。
- 使用時の時は全額先払い。相手の反応後の不適正・無効・探索不発でも返金しない。本編の不発時に在庫を消費しない挙動を共通ルールへ移植しない。
- すぐつかうは相手ターンや連鎖中でも、発動条件・対象・時・発動機会を満たせば使える。「自分のターン」とある装備能力は相手ターンに使えない。
- 1ターン／1ラウンドは個体ごと。いのちのくすりには、同名全体の制限を個別に明記した。
- 新しいHP・コイン・満腹・気分・病気状態・図鑑／実績台帳は作らない。sourceの数字とカードの数値を同じものとは扱わない。
