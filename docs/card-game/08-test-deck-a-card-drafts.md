### 65の個別改稿と残る共通裁定

- フェニックス⑤は両方向の勝負で使う本文とし、手札1枚を発動コスト、+2をその勝負の間、終了後のちから-2を当ターン中と明記。効果を無効にされれば+2も消耗予約も適用されないが、手札の支払いは返さない。基礎10/5・時5・代償付きのピークを維持する。旧省略文の未指定部分を設計しているため、単なる誤字訂正や強度確定とは扱わない。
- ぬいぐるみ⑦は受ける時だけ。選ばれた勝負がちえでも、本人のちからが発動時に1以下なら使える。解決済みの終了後予約は、本人が後から離れても残る。山札が1枚ならその1枚を上へ戻し、0枚なら操作なし。
- 比較前の参加メイン離脱による途中終了は[65](65-challenge-participants-and-resolution.md)のユーザー確定文により01・02・06へ反映済み。勝負は宣言時に開始しており、途中終了でも適用済みの終了後操作・消耗は条件どおり処理する。比較・勝敗を必要とする効果や、途中終了後に作って過ぎた終了へ遡る予約は処理しない。今回の確定反映でカード能力本文・数値は変更しない。

# 第2稿変更理由
1. なかま時0へ訂正: 01確定仕様との不一致修正。
2. 正式語彙「すぐつかう」へ統一。
3. カワウソ: 山札確認過多を1つ削り、あそび→勝利成果へ。いぬ②は能力値補助、カワウソは勝利後そだちで役割分離。
4. おはな: 曖昧な「つけたカードに関係する能力」を廃止し、交際進行との明確な連携へ。
5. ハグ: 相手効果限定を外し「実際にこのターンそだちが減った」ことを条件にして死に札率を下げる。
6. トイレットペーパー／かくれんぼは高度ルール試験用として低頻度を許容し変更しない。
