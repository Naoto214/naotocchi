2. いぬ② — 3/2・時2。「もっとあそぼ！」: 1ターン1回、あそび使用後、次に自分から行うちょうせんの使用能力値+1。
3. かえる③ — 3/4・時3。「つぎのばしょへ」: 1ターン1回、自分のセカイ変更時コスト-1。
4. カクレクマノミ④ — 5/5・時4。「やくわりこうたい」: 1ターン1回、メインについている、別カードにも適正につけられる「みにつける」1枚をそのカードへつけ替える。
5. カブトムシ④ — 1/4・時4。「さなぎのじかん」: このメインからときとばしする時コスト-1。その後このターンもうときとばしできない。
6. フェニックス⑤ — 10/5・時5。「もえつきるほど」: 1ターン1回、ちょうせん時に手札1枚を捨て、ちからかちえ+2。そのちょうせん後ちから-2（ターン終了まで）。
7. サクラ⑥ — 9/5・時6。「まんかい」: この段階になった時、準備枠1枚を選ぶ。このターンそのカードが条件を満たして発動・解決した時、そだち+5。1回まで。
8. ぬいぐるみ⑦ — 1/8・時7。「よわいままで」: 1ターン1回、ちから1以下でちょうせんされた時、その終了後山札上2枚を見て1枚上・1枚下。
9. おとこのひと⑧ — 3/9・時8。「つぎへたくす」: 1ターン1回、このメインがときとばし／へんしんで捨て札へ行った時、捨て札のメイン以外1枚を山札下、その後1枚引く。
10. カブトムシ⑧ — 6/6・時8。「つよさのあと」: 1ターン1回、捨て札の前段階カブトムシ1枚を山札下。このターンちからかちえ+1。

# B. なかま6枚

- ハリネズミ「まるくなる」: 1ラウンド1回、自分メインのそだちが相手効果で減るなら5防ぐ。
- カタツムリ「あとからいく」: 後攻なら自分ターン最初に1回、山札上1枚を上／下。
- たぬき「ばけてまつ」: 1ターン1回、しかけるを準備したターンにそのカードが発動したら1枚引き、手札1枚を山札下。旧稿の「名前を隠す」は公開情報ルール未確定のため第1稿から外し、ブラフ性はしかける自体に任せる。

- サングラス — 時1・みにつける: メインにつける。1ターン1回、そのメインが自分からちょうせんする時、その間ちから+1。

- シルクハット — 時2・みにつける: メインにつける。1ターン1回、そのメインからへんしんする時、そのへんしん時コスト-1。
- トイレットペーパー — 時1・しかける: 自分メインが相手効果で捨て札になるなら発動可。代わりにこのカードを捨て札にし、そのメインは捨て札にならない。

# 40枚横断監査 第1回

## 構成
メイン10 / なかま6 / こいびと4 / セカイ4 / あそび5 / あいてむ5 / できごと6 = 40。

## アクション3方式
- つかう: あそび4＋ハグ＋できごと6 = 11。
- みにつける: 3。
- しかける: 2。
3方式すべてを試せる。しかけるは第0弾Aでは意図的に少なめ。

## 高度ルールのカバレッジ
- コピー: サル。
- 対象変更: かくれんぼ。
- 防止: ハリネズミ。
- 置換: トイレットペーパー。
- 領域移動: すれちがい／とつぜんのたび。
- ときとばし／へんしん／セカイ／交際・結婚／捨て札利用を含む。
- 発動無効・効果無効は第1稿では意図的に入れず、基礎連鎖を先に検証する。

## 時コスト
非メインは時1中心。セカイや強い干渉・軽減は時2〜3。時軽減が複数重なった場合の最低支払値は01〜07に既決定があるか模擬前に再確認し、未決定なら必要時だけ裁定する。

## そだち
基本ちょうせん勝利+5、結婚+10を維持。追加そだち獲得はサクラ⑥、おはな、ハグ等に限定。+5単位を基本とする。

## 手札・山札
山札上を見る能力は20枚前半から多め。残り20枚では意図的に抑えた。2048等は交換で純増を抑制。模擬で情報処理が煩雑なら既存「見る」能力の一部を変更する。

## 盤面
自由廃棄ルールは追加しない。なかま枠を自力で空けるカードは現状なし。模擬で実際に詰まった場合だけ個別カードで解消する。

## 先攻後攻
カタツムリのみ後攻を小さく利用。基本ルールの後攻補正は追加しない。模擬で差を測る。

## 模擬前に再確認する既存仕様
1. 時軽減の最低支払値。
2. しかけるカードの公開情報範囲。ただし本40枚は非公開化なしでも動く。
3. 交際／結婚カードが領域移動した場合の状態消失は07の「新しいカード」原則で処理可能か最終確認。
4. サクラ⑥の選択した準備カード追跡が物理版で無理なく可能か。
