## 設計上の前提
- メインの印刷基礎値は保存済み代表テスト値を使用する。
- 高段階を低段階の完全上位互換にしない。
- 直接高段階たんじょうでも固有能力は成立させる。
- 過去履歴をプレイヤーの記憶だけで追わせない。後から参照するなら捨て札等の公開領域を使うか、移動時に即処理する。
- 新ゲージ・専用カウンターを基本的に増やさない。
- 「対象にする」は発動時、「選ぶ」は解決時。
- 回数制限は06の正式語彙を使う。

# A. メイン10枚 第1稿

## 1. おとこのひと① — ひと
- ちから1 / ちえ1 / 通常時1
- 人生テーマ: 赤ちゃん／可能性
- 能力案 **「これからのじんせい」**
  - `このメインがたんじょうした時、発動できる。自分の山札の上から3枚を見る。その中からメイン以外のカード1枚を選んで手札に加え、残りを好きな順で山札の一番下に置く。`
- 狙い: ①から始める価値。未来から何と出会うかを選ぶ。メインを直接探さないので人生ルートの万能サーチにしない。

## 2. いぬ② — けもの
- ちから3 / ちえ2 / 通常時2
- 人生テーマ: 子犬／あそびまわる
- 能力案 **「もっとあそぼ！」**
  - `1ターンに1回。自分が「あそび」カードを使った時、発動できる。このターン、自分のメインが次に自分からちょうせんする時、そのちょうせんで使うちからまたはちえを+1する。`
- 狙い: あそぶ→次に動く。時回復やちょうせん回数追加はしない。

## 3. かえる③ — みずべ
- ちから3 / ちえ4 / 通常時3
- 人生テーマ: 足が生える／旅立つ準備
- 能力案 **「つぎのばしょへ」**
  - `1ターンに1回。自分が自分のセカイを変更する時、発動できる。その変更で支払う時を1少なくする。`
- 狙い: ③は移動そのものの成果ではなく旅立つ準備。恒常的なセカイ無料化を避け、1ターン1回・-1に限定。

## 4. カクレクマノミ④ — うみ
- ちから5 / ちえ5 / 通常時4
- 人生テーマ: 成長個体／役割をもつ
- 能力案 **「やくわりこうたい」**
  - `1ターンに1回。自分のメインについている「みにつける」カード1枚を選び、そのカードをつけられる自分の別のカード1枚につけ替えることができる。`
- 狙い: 新マーカーを作らず、既存の装備対象関係を流動させる。セカイ移動のかえる、段階移動のカブトムシと分離。
- 監査事項: 「みにつける」の対象範囲が01〜06の既存仕様で十分か、具体カード群完成時に再確認。

## 5. カブトムシ④ — むし
- ちから1 / ちえ4 / 通常時4
- 人生テーマ: 蛹／止まって変わる
- 能力案 **「さなぎのじかん」**
  - `このメインからときとばしする時、発動できる。そのときとばしで支払う時を1少なくする。その後、このターン、自分はもうときとばしできない。`
- 狙い: ④を実際に通った瞬間に価値を処理し、履歴マーカー不要。④を通る=次へ少し進みやすい代わりにそのターンは刻んで連続進行できない。④を飛ばすルートにも即時性を残す。

## 6. フェニックス⑤ — げんそう
- ちから10 / ちえ5 / 通常時5
- 人生テーマ: 絶頂／燃え尽きるほど輝く
- 能力案 **「もえつきるほど」**
  - `1ターンに1回。自分のメインがちょうせんする時、手札1枚を捨てて発動できる。このちょうせんの間、このメインのちからまたはちえを+2する。このちょうせんの後、このメインのちからをターン終了時まで-2する。`
- 狙い: 高基礎値の上からさらに限界へ届くが、手札と後から来る衰弱を伴う。11/12を印刷値として作らない。

## 7. サクラ⑥ — くさ
- ちから9 / ちえ5 / 通常時6
- 人生テーマ: 咲く
- 能力案 **「まんかい」**
  - `この段階になった時、発動できる。自分の準備枠にカードがあるなら、その中から1枚を選ぶ。そのカードがこのターン発動条件を満たして発動した場合、その解決後、自分のそだち+5。この能力でそだちを増やせるのは1回まで。`
- 狙い: 直接⑥でも9/5。準備して⑥なら公開された仕込みが開花成果になる。⑤経由そのものは要求しない。
- 監査事項: しかける以外の準備枠カードとの整合を40枚完成時に確認。

## 8. ぬいぐるみ⑦ — ふしぎ
- ちから1 / ちえ8 / 通常時7
- 人生テーマ: 忘れられる／弱いからこそ
- 能力案 **「よわいままで」**
  - `1ターンに1回。自分のメインのちからが1以下の時に自分がちょうせんされた場合、発動できる。このちょうせんが終わった後、自分の山札の上から2枚を見る。そのうち1枚を山札の一番上、残りを一番下に置く。`
- 狙い: 低いちからを勝利へ反転せず、相手が挑みやすい状態を情報価値へ変える。相手がちからを上げることで能力を止める逆転的干渉も成立。

## 9. おとこのひと⑧ — ひと
- ちから3 / ちえ9 / 通常時8
- 人生テーマ: 老年期／残す
- 能力案 **「つぎへたくす」**
  - `1ターンに1回。このメインがときとばしまたはへんしんによってメイン枠から捨て札に置かれた時、発動できる。自分の捨て札のメイン以外のカード1枚を選び、山札の一番下に置く。その後、1枚引く。`
- 狙い: 過去を丸ごと回収せず、次の人生へ1つ残す。直接⑧→移動でも成立するが、捨て札に経験がなければ価値が小さい。

## 10. カブトムシ⑧ — むし
- ちから6 / ちえ6 / 通常時8
- 人生テーマ: 老成／強さを手放す
- 能力案 **「つよさのあと」**
  - `1ターンに1回。自分の捨て札にこのカードより前の段階の「カブトムシ」がある場合、発動できる。その中から1枚を選び、山札の一番下に置く。このターン、このメインのちからまたはちえを+1する。`
- 狙い: 公開領域だけで過去段階を確認。⑦10/4の単純延長ではなく、過去の段階を手放して今の6/6を補う。

# B. なかま6枚 第1稿

※なかまはメイン固有の段階・属性・ちから／ちえを持たない。第1稿では役割を検証し、時コストは40枚横断調整時に確定する。

## カワウソ — 「いっしょにあそぼ」
`1ターンに1回。自分が「あそび」カードを使った時、発動できる。自分の山札の上から1枚を見る。そのカードを山札の一番上または一番下に置く。`

## サル — 「まねっこ」
`1ターンに1回。自分のメインの能力が発動した後、発動できる。このターン、このなかまはその能力をコピーする。コピーした能力の発動条件を満たした場合、その能力を発動できる。`
- 06〜07のコピー共通ルールを実戦テストする。コピーしただけでは過去履歴は成立しない。

## ふくろう — 「よくみる」
`1ターンに1回。自分のターンに発動できる。自分の山札の上から3枚を見る。そのうち1枚を山札の一番上に置き、残りを好きな順で山札の一番下に置く。`
- 山札情報・手札事故緩和を担当。直接ドローまで付けるかは模擬対戦で判断。

## ハリネズミ — 「まるくなる」
`1ラウンドに1回。自分のメインのそだちが相手の効果で減るなら、その減少を5防ぐ。`
- 発動する反応ではなく、すでに有効な防止として処理する方向。置換・防止と連鎖の実戦テスト。

## カタツムリ — 「あとからいく」
`自分がそのラウンドの後攻プレイヤーなら、自分のターンの最初に1回、山札の上から1枚を見る。そのカードを山札の一番上または一番下に置く。`
- 遅いことを小さな情報利益へ。後攻補正を基本ルール化せず、このカード固有に留める。

## たぬき — 「ばけてまつ」
`1ターンに1回。自分が「しかける」でカードを準備枠に置いた時、発動できる。そのターン、そのカードが発動するまで、相手はそのカードの名前を確認できない。`
- 伏せ・ブラフを強める候補。ただし物理版の公開／非公開ルールとの整合が必要なため、最終確定前に準備カードの情報公開範囲を再監査する。

# C. こいびと4枚 第1稿

こいびとはなかまの上位互換にせず、交際の時間軸を能力にする。既存の交際①→②→③→結婚と結婚時そだち+10を変更しない。

## ビルのねこ社長 — 交際開始型
`このこいびととの交際が始まった時、発動できる。自分の手札1枚を山札の一番下に置き、その後1枚引く。`
- 新しい関係が始まる時に予定を整理するイメージ。純粋な+1ドローにしない。

## あみものがすきなクモさん — 交際継続型
`1ラウンドに1回。このこいびとの交際段階が進んだ時、発動できる。自分の準備枠のカード1枚を選ぶ。このラウンド、そのカードの発動コストとして支払う時を1少なくする。`
- 関係を積み重ねるほど「編んでいたもの」が使いやすくなる。準備枠との接続はサクラと重なるため横断監査対象。

## うみのにんぎょ — 結婚型
`このこいびとと結婚した時、発動できる。自分の捨て札の「セカイ」カード1枚を選び、手札に加える。`
- 基本の結婚そだち+10に追加される固有能力。結婚を繰り返して乱用できない既存ルールと整合。

## とけないゆきだるま — 別れ・再出発型
`このこいびととの交際または結婚が終わり、このカードがこいびと枠から捨て札に置かれた時、発動できる。自分の山札の上から2枚を見る。そのうち1枚を手札に加え、残りを山札の一番下に置く。`
- 別れを直接そだち獲得へ変えず、次の人生の選択肢を残す。
