## 3. 6群の同名経路

1. **P97-01 はじめてのデート2枚**: AはR1にこいびとを交際0で配置し、R1とR2に別現物を1枚ずつ使用した。各1枚ドロー・そだち+5で、交際段階は0のまま。A 30／B 20。

3. **P97-03 ヒット&ブロー2枚**: AはR1・R2に別現物を使用し、公開前の種類宣言、公開、手札取得、各そだち+5を分けて記録した。A 30／B 20。
4. **P97-04 とかいラン2枚**: Aはメイン・とかいを配置し、R5に装備とバスケ3Dを表向きでプレイした後、別現物2枚を連続使用した。各回の公開4枚、異なる種類2枚までの取得、残りの山札下順を記録した。A 20／B 20。
5. **P97-05 どうぶつしょうぎ2枚**: Aはなかま3枠を埋め、満員交代で捨て札へ置いた別々のなかまを、別現物のどうぶつしょうぎで1枚ずつ回収した。通常再配置時に`A-011#1→#2`、`A-012#1→#2`の2 transitionを発行した。A 20／B 20。
6. **P97-06 ブロックくずし2枚**: Aは同じB準備カードを対象に別現物2枚から予約を作った。次のAターン開始時、先の予約が対象を手札へ戻して消費され、後の予約は対象不在で失効した。A 20／B 20。

同名2枚を一つの回数制限や一つの個体としてまとめていない。カード個体ごとの「1ターンに1回」、予約元、対象、消費・失効、再登場世代を分ける。
