# 46 むし属性 — ちょう／セミ／アリジゴク 第1稿

最終更新: 2026-09-14

状態: **未設計3種の人生テーマ＋仮数値曲線。カブト／クワガタは31の現行本文を維持。**

## 属性テーマ

むし = **かわる**。

- ちょう: **蓄えたものを羽化で解放する**
- カブトムシ: **自分の時計／どの段階を通るか**
- クワガタムシ: **相手との間合い／かまえる**
- セミ: **長く待って、短い全盛期へ出る**
- アリジゴク: **待ち伏せ幼虫から飛ぶ成虫へ役割反転**

# 1. ちょう — ほどいて、はばたく

仮数値曲線:
`①2/2 → ②3/2 → ③5/3 → ④4/4 → ⑤1/5 → ⑥7/5 → ⑦6/7 → ⑧4/8`

合計: ちから32 / ちえ36 =68。カブトの総量68と同じだが曲線・役割は別。

| 段階 | 現行名 | 人生テーマ | 仮値 | 能力方向 |
|---|---|---|---:|---|
| ① | うまれたてのいもむし | 食べ始める | 2/2 | 手札／盤面の小さな要素を後で使うため残す。新しい栄養カウンターは作らない。 |
| ② | 育ちざかりのいもむし | 蓄える | 3/2 | 今すぐ使わないカードを山札下／準備等へつなぐ。 |
| ③ | 大きないもむし | 十分に育つ | 5/3 | 現段階に留まって能動的に動くか、蛹へ入るかの判断。カブト③とは成果の種類を分ける。 |
| ④ | さなぎの準備中 | 自分をほどく準備 | 4/4 | ⑤へ進む前に、今まで蓄えたものを何に変えるか選ぶ予告段階。 |
| ⑤ | さなぎ | 動かず作り変える | 1/5 | 大幅弱体化。準備／手札等を別用途へ変換する時間。カブト④の時軽減とは別。 |
| ⑥ | 羽を広げたちょう | 固定を解いて飛ぶ | 7/5 | 羽化したターンに、蓄え／準備を移動・解放して能動行動へ。 |
| ⑦ | 花めぐりのちょう | 場所から場所へ価値を運ぶ | 6/7 | セカイ／なかま等の間をつなぐ。タンポポ等との花・種シナジーは後で個別監査。 |
| ⑧ | 年を重ねたちょう | 最後に次へ運ぶ | 4/8 | 手元の価値を次のカード／山札へ流し、止まらず終盤をつなぐ。 |

連作:
`食べる → 蓄える → 育ち切る → 蛹へ備える → 作り変える → 解放して飛ぶ → 運ぶ → 次へ渡す`

# 4. セミ — まって、いっきに鳴く

仮数値曲線:
`①1/3 → ②2/4 → ③3/5 → ④4/4 → ⑤2/5 → ⑥7/4 → ⑦9/4 → ⑧4/7`

合計: ちから32 / ちえ36 =68。

セミは幼虫期を地下で過ごし、地上へ出て脱皮して成虫になる。周期ゼミの極端な年数を全セミへ一般化せず、「地下で待つ時間が長く、地上の成虫期は相対的に短い」という方向だけ使う。

| 段階 | 現行名 | 人生テーマ | 仮値 | 能力方向 |
|---|---|---|---:|---|
| ① | 小さな幼虫 | 地下へ入る | 1/3 | 盤面で目立って成果を出すより、後へつなぐ小準備。 |
| ② | 土ぐらしの幼虫 | 地下で育つ | 2/4 | 同じ段階／同じセカイに留まることを小利益へ。 |
| ③ | 旅立ち前の幼虫 | 出る時を待つ | 3/5 | 次段階へ進むタイミングを予告／選択する。単純時軽減にはしない。 |
| ④ | 地上に出たセミ | 地上へ出る | 4/4 | ときとばし等でこの段階になった時、次の脱皮へつなぐ短期準備。 |
| ⑤ | ぬけがらをぬぐセミ | 脱皮する | 2/5 | 一時的に弱いが、今までの待機を⑥へ変える転換点。 |
| ⑥ | 若いセミ | 鳴き始める | 7/4 | 地上で一気に能動化。ちょうせん／あそびの短期成果。 |
| ⑦ | よく鳴くセミ | 全盛期に鳴く | 9/4 | 短いピーク。今ターンの行動を大きくするが、カブト⑦10/4を数値で越えない。 |
| ⑧ | 年を重ねたセミ | 鳴き終えた経験 | 4/7 | ⑥⑦の能動ピークを手放し、過去の行動を次へ残す。 |

連作:
`地下へ → 地下で育つ → 出る時を待つ → 地上へ → 脱皮 → 鳴き始める → 全力で鳴く → 静かに経験を残す`

# 5. アリジゴク — しかけて、飛び立つ

仮数値曲線:
`①2/3 → ②3/4 → ③5/4 → ④1/5 → ⑤2/5 → ⑥6/5 → ⑦7/6 → ⑧4/8`

合計: ちから30 / ちえ40 =70。

| 段階 | 現行名 | 人生テーマ | 仮値 | 能力方向 |
|---|---|---|---:|---|
| ① | ちびアリジゴク | 待ち伏せを覚える | 2/3 | 小さなしかける連携の入口。 |
| ② | 巣作りアリジゴク | 罠を作る | 3/4 | 準備枠／しかけるを使うが、準備枠追加はしない。 |
| ③ | 大きなアリジゴク | 相手が来るまで待つ | 5/4 | 相手の特定行動を待ち、条件成立時に短く利益。ハエトリグサとの後日比較が必要。 |
| ④ | 砂のまゆ | 罠をやめて閉じる | 1/5 | これまでのしかけ役を一度止め、後半へ切り替える。 |
| ⑤ | まゆの中のさなぎ | 飛ぶ体へ変わる | 2/5 | 準備していたものを整理し、能動型へ移行する中継。 |
| ⑥ | 出たてのウスバカゲロウ | 飛び立つ | 6/5 | 前半の待ち型から、自分ターンの移動／あそび型へ明確に反転。 |
| ⑦ | 飛び回るウスバカゲロウ | 自分から動く | 7/6 | セカイ・行動をまたいで能動的に動くピーク。 |
| ⑧ | 羽休めのウスバカゲロウ | 飛んだ後に休む | 4/8 | 前半の罠／後半の飛翔の両経験を次の選択へ使う。 |

連作:
`待ち伏せを覚える → 罠を作る → 待つ → 罠を閉じる → 体を変える → 飛び立つ → 飛び回る → 羽を休める`

## 5種横断

| 種族 | 段階変化の主役 | 前半 | 後半 |
|---|---|---|---|
| ちょう | 蓄積→解放 | 食べて蓄える | 羽化して運ぶ |
| カブト | 自分の時計 | 留まる／蛹を通る | 全盛期→老成 |
| クワガタ | 相手との間合い | 隙を見る／時を残す | 捕まえる／挟み返す |
| セミ | 待機→短期ピーク | 地下で待つ | 鳴く短い全盛期 |
| アリジゴク | プレイ様式の反転 | しかける | 飛んで能動化 |

## 重複監査

- 蛹／まゆがある3種以上を「弱い④→時-1」に統一しない。
- カブト④=ときとばし経路、ちょう⑤=蓄積の用途変換、セミ⑤=長い待機を短期ピークへ、アリジゴク④⑤=罠型から能動型へ役割転換。
- アリジゴクとハエトリグサは両方しかける方向なので、くさ設計時に「動物の待ち伏せ→別成体」と「植物として一生待ち捕らえる」を明確に分ける。
