## 属性テーマ

みずべ = **わたる**。

同じ「環境を渡る」を4種で分ける。

- ペンギン: **むれでわたる**
- かめ: **たえてすすむ**
- かえる: **環境を渡り適応する**
- さけ: **遠くへ行って戻る**

# 1. ペンギン — むれでわたる

仮数値曲線:

`①1/2 → ②2/3 → ③3/4 → ④2/5 → ⑤6/5 → ⑥7/6 → ⑦6/7 → ⑧5/8`

合計: ちから32 / ちえ40 =72。かえるの総量72と揃える。

④の羽の衣替えを一時的な身体弱体として明確にする。

| 段階 | 現行名 | 人生テーマ | 仮値 | 能力方向 |
|---|---|---|---:|---|
| ① | 小さなひな | 群れに守られる | 1/2 | なかま等がいる時だけ小さく安全になる。単独では大利益を出さない。 |
| ② | ふわふわのひな | 群れをついていく | 2/3 | 他のキャラクターの行動後に小さくついていく。いぬ①との差は環境／群れ。 |
| ③ | 大きなひな | 海へ出る準備 | 3/4 | 次のセカイ変更や⑤以降へ備える。直接時軽減だけにはしない。 |
| ④ | 羽の衣替え中 | 一時的に止まる | 2/5 | 自分から大きく動かない代わりに、群れ／盤面を整える時間へ変える。カブト④ほど極端な経路カードにはしない。 |

# 2. かめ — たえてすすむ

仮数値曲線:

`①2/2 → ②3/3 → ③4/4 → ④5/4 → ⑤6/5 → ⑥6/6 → ⑦5/7 → ⑧4/8`

合計: ちから35 / ちえ39 =74。

数値だけを防御値に見立てず、能力で「急がない／守る」を作る。

| 段階 | 現行名 | 人生テーマ | 仮値 | 能力方向 |
|---|---|---|---:|---|
| ① | うまれたてのかめ | 小さな体を守る | 2/2 | 最初の相手干渉に対する小さな防御。完全耐性にはしない。 |

# 4. さけ — もどる

仮数値曲線:

`①1/2 → ②2/3 → ③3/4 → ④4/5 → ⑤6/5 → ⑥7/6 → ⑦8/6 → ⑧5/8`

実際の回遊生活に合わせ、中盤で海へ出て体格・活動性が増し、後半で川へ戻る流れをゲームへ翻訳する。

`川で生まれる → 川で育つ → 海へ備える → 環境を変える → 遠くで育つ → 帰る時を決める → 川をのぼる → 戻った場所で次へつなぐ`

## 4種横断

| 種族 | 一語 | 世界との関係 | 主操作 |
|---|---|---|---|
| ペンギン | むれる | 群れと環境を渡る | キャラ＋セカイ |
| かめ | たえる | 同じ環境を長く使う | 防御＋維持 |
| かえる | わたる | 次の環境へ適応 | セカイ変更 |
| さけ | もどる | 遠くへ出て過去の場所へ帰る | セカイ履歴／往復 |

## 重点監査

- 4種すべてに「セカイ変更時+1」を配らない。
- かめは移動しないことにも価値、かえるは移動そのもの、さけは往復、ペンギンは仲間との移動。
- セカイを引かないと4種全部がバニラになる設計を避ける。各前半・後半にセカイ以外の盤面要素も持たせる。
- 33のじかん／てんき／きせつ方式が未決定でも、場所セカイ13だけで最低限機能する能力にする。
