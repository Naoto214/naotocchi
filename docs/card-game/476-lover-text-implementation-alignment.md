## 3. 保存互換性

保存は seed・デッキ・操作列を再生する方式のため、修正前の対戦をそのまま新しい処理で再生すると、クモの結婚時誘発やサソリの伏せ札での誘発を選んだ操作が「今は選べない行動」になり、復帰できない。

- 新しい対戦は `hotseat-3`。
- 修正前の保存 `hotseat-2` は、その版のまま修正前の動作で再生する（クモの結婚時誘発・サソリの旧判定は `hotseat-2` だけに残す）。再保存しても `hotseat-2` のまま。
- `hotseat-1` は従来どおり `legacy-engine.mjs`。
- 修正前のエンジンで作った実際の保存2件（`prototypes/card-game/tests/lover-fix-hotseat2-saves.json`）で、最終状態が一致することを確かめる。
