# 上限で増加量0となる効果の適用 — 未承認裁定

条件が成立し、無効化もされていない「じんとり」G-area-claimを、そだち100で解決する場合。本文の処理はそだち増加のみで、上限により実際の増加は0。この処理を「効果が適用された」と数えるかは未確定。

01の「効果が実際に働く」、実行可能部分の処理、そだち0〜100は確定済み。06の空撃ちを独立禁止しない規則は発動可能性を決めるが、適用判定までは決めない。55アリジゴク⑥⑦／56 A6・A7、67・71の一部適用と全処理不適用の区別にも、この上限事例の明示はない。67 Q06の時0でも軽減予約を消費する規則はコスト変更の専用規則で、そだちへ転用しない。85のじんとり本文と86 P17にも上限時の適用裁定はない。独立レビューでも一意には導けないと確認。

選択肢：

- A：増加指示を正当に処理したことを適用と数える。実増加0でもアリジゴク⑥の誘発機会、⑦の当ターン適用履歴の根拠になる。他の条件・コスト・対象は別途必要。
- B：この効果は実増加も他の適用部分もないため、適用と数えない。この解決は⑥の誘発機会・⑦の履歴根拠にならない。

どちらも発動／解決した事実は残る。任意能力を必ず発動する意味ではない。状態が変わらない効果を全て不適用とする一般化はしない（見る等の実行がある場合は別）。カード価値・戦略点数・policy乱数では決めない。現行の100境界guardは解除せず、実装・採用はユーザー裁定後。過去記録へ遡及しない。

これはゲーム裁定の確認であり、seed生成・入力固定・400戦実行の確認ではない。今回の裁定が決まっても、challenge機会、終了／勝利、初期入力真正性、全体replay等の残工程を実装検証した後に、改めて最終実行確認が必要。
