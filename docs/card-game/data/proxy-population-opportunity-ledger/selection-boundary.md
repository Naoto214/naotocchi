# 06初期誘発群の選択単位：未採用の比較

これはゲームの合法性を変更する提案ではない。06の強制／通常任意4区分、同区分内の積む順の選択、見送った同じ出来事への後出し禁止を維持する。選択単位を定める前に、合法候補を証明し、107/114による比較が成立する範囲を適用する。未知を0や同値として比較しない。

## 既存契約を適用した後の境界

- 06は合法な区分順、発動条件判定、発動／見送りを規定するが、比較不能な群に対する抽選の分解を規定しない。
- 114は通常候補の優先順位であり、同区分の部分集合・順序の価値や同値性を証明しない。
- 116は完全合法集合・継続可能性・情報境界・stable IDが確認できた比較不能判断を継続する手段を提供する。mandatory_choiceのcontextにchoice_kindを置けることだけでは、どの判断を一回と数えるかは確定しない。
- 119のresponse-passと反応機会indexは通常反応の契約。06の初期誘発群を、すぐつかう／しかけるを含む通常反応へ混ぜない。
- 463〜465の意図的ランダムpolicyの指定5種／source allowlistへ、誘発の発動・順序を追加しない。
- 旧pilotの単一任意ドローを常に発動する記録は、群全体の一般選択方針の根拠ではない。保存済み旧結果も書き換えない。

## 比較案（いずれも未採用）

|案|比較不能時の候補単位|利点|差・限界|

2つの異なる任意発動X/Yがともに合法、各1回、指定なし、互いの発動コストが合法性を変えず、比較不能と証明された条件付き例では、合法な列は空・X・Y・XY・YX。理想化した均等抽選なら、Aの列確率は1/3・1/6・1/6・1/6・1/6、Bは各1/5。これは抽選単位の差を説明する算術であり、116のSHA moduloの厳密な有限分布や戦略的優劣を主張するものではない。実seedは生成しない。

Aを選ぶ場合も116のstrategic_unresolved_seeded_fallback・除外を維持する。今回のpolicy適格へ読み替えない。どちらを選んでも全400戦の適格性を保証せず、除外／未証明が残れば予定集合全体の結論を保留する。
