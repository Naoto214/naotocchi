# 21 メインカード — 生態・イラスト・能力の品質基準

最終更新: 2026-09-14

状態: **正式カード制作前の品質基準。**

## 世界観の基本
なおとっちの「たまご」は生物学的な卵そのものではなく、まだ何になるか分からない命の入口として扱う。植物・菌類・人間・サンゴ等も、なおとっち世界ではたまごから人生を始めてよい。

たんじょう後は、各キャラの現実の生態・成長・特徴を土台にする。ただし図鑑教材の写実再現を目的にせず、なおとっちの世界観に合わせて大胆にデフォルメ・誇張してよい。

基本式:
**現実の生態 → なおとっちらしい解釈 → 見栄えのための誇張 → カード能力への翻訳**

## 誇張の許容範囲
### 積極的に行ってよい
- その生物の象徴的パーツを現実より大きく／印象的にする。
- 成熟、老成、開花、羽化等をポーズ・表情・エフェクト・背景で強調する。
- 透明感、発光、花びら、胞子、水流、風等を幻想的に演出する。
- 実際の生態から連想できる性格や動きをキャラクター性として強調する。
- カードで小さく表示しても段階が識別できるようシルエットを意図的に変える。

### 通常成長では避ける
- 生態と無関係な武器・機械・翼等を理由なく追加する。
- 元生物が判別不能になるほど別モンスター化する。
- 見栄えだけのために、その生物の核となる特徴を別種の特徴へ置換する。

ただし「へんしん」「特殊セカイ」「特殊カード」の明示的な結果なら、通常成長より自由な改造を許容する。

# メイン8段階の5軸監査
各キャラ①〜⑧は、隣接段階ごとに最低でも以下の複数軸で差が分かること。

1. **絵** — ポーズ、表情、背景・生活場面。
2. **シルエット** — 体格、器官、姿勢、輪郭。
3. **数値** — ちから／ちえ。高段階を単純上位互換にしない。
4. **能力** — 同じ+値能力の段階違いを避ける。
5. **ゲーム上の役割** — 留まる、飛ばす、準備する、挑む、経験を使う等。

合格条件は「名前と段階数字を隠して8枚を並べても、おおよその成長順と各段階の違いを説明できる」こと。

# 横方向の差別化
縦の①〜⑧だけでなく、似たキャラ間も監査する。

監査階層:
1. 同一キャラ①〜⑧。
2. 近縁・見た目が似るキャラ同士（例: カブトムシ vs クワガタムシ）。
3. 同属性内。
4. 全メイン横断。

「単独では良いが一覧にすると似る」を不合格とする。

# カブトムシ vs クワガタムシの方向性
具体能力は別途正本確認・設計するが、少なくとも同じ「甲虫・高ちから」の色違いにはしない。

## カブトムシ
核候補: 角、押す／突進、蛹による大変化、羽化、短い成虫全盛期。
カードゲーム軸は既存Bで試した **「かわる／いつ進むか」** を基準にする。

## クワガタムシ
核候補: 大顎、挟む／構える、幼虫期、樹液・縄張り、生存戦略等。
カブトの「進む時期」と別のゲーム軸を生態から抽出する。数値だけの差（カブト+1等）では区別しない。

# 能力設計の基準
能力を読んで「なぜこのキャラなのか」が説明できること。

良い例:
- 蛹 → 一時的に弱いが、その後の変化を助ける。
- カクレクマノミ → 性転換という生態を性別システムへ翻訳。
- ハエトリグサ → 待ち伏せ・捕獲。
- アリジゴク → 罠を作り待つ。
- サクラ → 開花・散る・循環。

避ける例:
- 「昆虫だからちから+1」のような汎用効果だけで個性を作る。
- 8段階すべてが+1/+2/+3の量違い。

# カードとしての見栄え
本編用キャラ画像をそのまま縮小して置くだけで完成とはしない。

カード化時には:
- 小サイズでも顔・象徴パーツが読めるか。
- カード枠内でシルエットが映えるか。
- 能力欄とイラストの情報量が競合しないか。
- ①〜⑧を並べた時にコレクションとして気持ちよいか。
- ⑦／⑧等の象徴段階に「引いて嬉しい」画面力があるか。
を確認する。

必要なら本編イラスト自体を修正し、その後カードへ再反映してよい。

# 本編との同期
最終的には図鑑キャラ、各8段階、なかま、こいびと、アイテム、あそび、セカイ等を原則カード化対象にする。

本編を正として、名前・画像・生態・設定変更があればカード側を差分監査する。カード側のちから／ちえ／能力はゲーム固有情報として分離管理する。

変更時は影響度を3段階で判断:
- 画像のみ変更 → カード画像監査。
- 生態／段階意味変更 → イラスト＋能力再監査。
- キャラ構造／段階構造変更 → 8枚セット全体再監査。

# 正式カード化フロー
1. 本編正本の8段階画像・設定を確認。
2. 現実生物なら生態上の根拠を確認。
3. 8段階を横並びにして縦監査。
4. 近縁キャラと並べて横監査。
5. ちから／ちえ曲線を監査。
6. 各能力を生態・人生テーマへ接続。
7. 実カード枠に仮配置して視認性・画面力を確認。
8. 類似・弱い段階があれば本編イラストまたは能力へ戻って修正。
9. 模擬対戦。
10. 合格後に正式カード候補へ。
