## 2. 公開情報で確認できる本文にする

### プレイの種類を数えるカード

今回の本文でいう **「表向きでプレイ」** は、アクションを **すぐつかう／みにつける** の方法でプレイすることを指す。しかけるの中身を調べる能力は加えない。

| 出来事 | 今回の「表向きでプレイ」に数えるか |
|---|---|
| すぐつかうであそびをプレイ | 数える。後に発動・効果が無効でも、正当に成立したプレイ履歴は巻き戻さない |
| みにつけるであいてむをプレイ | 数える。カードの発動は起きなくてもプレイは成立する |
| しかけるで裏向きに置く | 数えない。以前にその実物を公開していても同じ |
| しかけたカードを後から発動する | 新しいプレイではないので数えない |
| 手札を公開するだけ／既存装備のつけ替え | 新しいプレイではないので数えない |
| 同じ種類を別の表向きの方法でプレイ | 同種類。方法が違うことを「別種類」にしない |

種類を数える正の条件は範囲が狭まる。一方、セミ⑦の「まだ表向きでプレイしていない」という否定条件は、先にしかけることを許すようになる。**単なる誤字訂正ではなく、公開情報で裁定できるようにするカード側の調整**である。

全伏せ札の種類公開や、非公開の履歴を申告して報酬を得る方式は採らない。01の「アクションをプレイ」は引き続き3方法すべてを含む。ちょう②・アリジゴク・ハエトリグサ等、種類を調べず方法そのものを参照する本文には、この限定を広げない。

れん②⑤の軽減も表向きのプレイに限定した。すぐつかう／みにつけるで支払うカードを相手も確認し、種類・軽減・支払時を照合できる。間にしかけるを行っても、そのカードには適用せず予約を消費しない。予約は元の本文どおり当ターン限り。時0下限、適用後の発動元離脱でも残る裁定は維持する。すべての通常行動の宣言・反応順はU02として別途整理する。

### 盤面の種類と山札からの探索

- クラゲ②・サンゴ③・ヒトデ⑧は**盤面の表向きカード**だけの種類を参照する。発動領域は3×3盤面ではなく、伏せ札の名前・種類も含めない。
- 指定種類／使用方法のカードを非公開の山札から取る本文は、**取るカードを公開してから手札へ加える**。手札全体や山札の残りを公開する必要はない。
- おんなのひと①は「見た2枚の種類が異なる」こと自体が報酬条件なので、上2枚を公開する。山札1枚なら、その1枚を下へ置くだけ。0枚なら移動なし。2枚同種類も全部下。2枚異種類なら1枚を手札へ取る。
- 条件に合うカードが見つからなければ取得部分を行わず、残りの山札下処理を行う。一般的な空撃ち禁止ルールは追加しない。
- 一度公開したカードを後で手札・山札・伏せた準備へ移した場合に、恒久的な公開カードとして扱わない。

## 3. 発動した能力の効果を参照する

れん⑦・ペンギン⑥・ヤドカリ⑦・サンゴ④⑥・世界樹⑥は、**発動した能力の効果が、その解決時に適用されたこと**を条件にする。

| 状態・処理 | この条件を満たすか |
|---|---|
| 指定された種類のカードが発動した能力の効果が解決時に働く | 満たす。回数・他の条件も必要 |
| 能力を発動したが、その発動または効果が無効 | 満たさない |
| すべての処理が実行不能で効果が働かなかった | 満たさない。解決したことだけでは足りない |
| 効果の一部だけでも実際に適用された | 満たす。全処理の成功を要求していない |
| 常時の数値補正を持つカードが存在する／その補正の値が変わる | 満たさない |
| すでに有効な置換・防止が連鎖を作らずに働く | 満たさない |
| 発動した能力の解決で、期限付きの予約が作られる | 満たす。実際に予約を適用したことを数える |
| その予約が後のターン等に自動で働く | 新しい能力の解決ではないため再び数えない |

01が避けている、効果無効でも成立する「解決した時」だけの条件にはしない。現在の連鎖の解決中に成立した誘発は、06どおり連鎖終了後に処理する。

サンゴ⑥の異種類は **なかま／こいびと／セカイというカード種類**。別名のなかま2人、同じなかまの別能力2つでは成立しない。今の効果が適用されるより前に、同ターンの別種類の発動能力の効果も適用されている必要がある。参照順は発動宣言順ではなく、実際の効果適用順。

装備カードそのもののプレイと、装備が持つ能力の発動も別。ヤドカリ⑦は、みにつけたカードが常時補正を持つだけでは働かない。対応する発動能力を持つ装備の密度と処理の重さは、あいてむ本文設計・プロキシで確認する。

## 4. 発動時の対象と解決時の選択

### おとこのひと⑦・カブト⑧・ヒトデ⑧

「選んで発動」を「**対象として発動**」へ直し、発動時に捨て札の1枚を固定する。カードを山札下へ戻す部分は効果のままで、発動コストには変えていない。

- 対象が不適正になっても別のカードを選び直さない。
- おとこのひと⑦の+1／+2判定とヒトデ⑧の盤面種類との照合は、**発動時に公開して指定した対象の種類**を使う。本文にその時点を明記した。この3枚の明示を、全カードに無記載の過去情報参照を認める一般則へ広げない。
- 01では「その後」も無接続の後続処理も、前の処理失敗だけでは止まらない。そのため**「そうしたなら」は追加しない**。
- おとこのひと⑦は対象を戻せなくても本人が残っていれば数値補助を行う。発動時の対象がなかま等なら+2。カブト⑧も戻す処理と+1は独立。
- ヒトデ⑧は解決時に表向きの同種類が盤面にあれば、対象を戻せなくても引く→手札1枚を下へ行う。同種類が盤面になければ条件内の処理をすべて行わない。
- 本人が離れた場合、その本人への数値補助を後継メインへ引き継がない。保護や予約の存続と、受益者の個体の存続は別である。

08のカブト⑧にあった「前段階」の省略も、15第2稿の「捨て札のカブトムシメイン1枚」に同期した。⑧の別個体が捨て札にあれば対象にできるのは、今回追加した性能ではなく15の既存本文どおり。

### ペンギン⑦

「セカイ変更時、なかまがある場合、**発動できる**」とし、通常任意の最初の機会に使用を決める。なかま1枚は本文どおり**解決時に選ぶ**。選択後へ割り込む新しい連鎖は作らない。

相手は発動を見て反応できる。解決時に残るなかまから選び、なかまが0枚なら保護を作らない。適用済み保護は発動元離脱でも指定期限まで残り、選ばれた個体への相手効果による離脱を1回防ぐ。
