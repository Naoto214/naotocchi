# 475 人物・装備の同時退場順（現行版追補）

2026-10-10 ユーザー承認A。01/06/64/93/449への現行版追補。旧正本と過去保存結果は変更しない。

カード本文の個別指定が優先する。人物1枚の退場に付随する装備移動では、各所有者の既存捨て札prefixを保持する。人物の行き先が捨て札なら人物を先に置く。その後、装備を退場直前の所有者の準備枠配列順でその所有者の捨て札へ置く。人物が山札・手札へ移る場合は人物を捨て札へ加えない。人物の移動を記録した後、装備の領域移動を同じ順で記録する。準備枠順を変更する選択権、所有者の順序選択、追加policyは設けない。

この内部列は1件の原子的退場の記録であり、領域移動ごとの独立した発動・応答窓を作らない。既存の誘発条件は退場直前と処理後を既存規則どおり参照し、一続きの処理が終わった後に既存の窓で扱う。満員なかま交代は旧人物の退場群を終えて新人物を配置する。C-cat_friendの本人支払は本人を山札下、装備を捨て札へ移した後で発動を続ける。

replayでは退場イベントに順序付きmovementsと所有者別discard_additions、参照正本とSHA256を保存する。人物の移動を先頭、装備を準備枠順とし、原子イベント内ordinalを0から付ける。単一人物へ異なる所有者の装備が付く将来拡張は現在の合法性証明に含めない。現在の実装はその状態を拒否する。複数人物の同時退場相互順は本追補で新設しない。

stateの配列順と上記receiptをhash対象に含め、辞書登録順やIDの辞書順に依存させない。旧membership用sorted IDを残す場合も、それを移動順とは呼ばない。順序未証明だった449の境界は、本追補が適用される現行版の退場だけで解消する。全合法性・情報利用・選択根拠・全機会・標本適格性は別に検証する。
