## 裁定（変更なし）

- ルナランダー：残り時は、支払いと反応を経た**解決時**に見る。発動条件ではないので、ちょうど2でなくても発動できるが効果は得られない。時0軽減時も印刷時から逆算しない（85 §3、[86](86-play-batch-4-text-audit.md) P16・X18）。
- サブマリン3D：選んだ数0／1／2に対して見る枚数は3／5／7枚。時2＋選んだ増加分と他の増減を合算し、最後に0を下限にする。実際の支払額から枚数を逆算しない。山札が足りなければある分だけ見る（83 §3、[84](84-play-batch-3-text-audit.md) P07・X11）。

## 意味が同じである根拠

| 観点 | ルナランダー | サブマリン3D |

| 実装 | `iff('time2',[draw(),growth(5)])` は解決時の `p.time===2` を評価（rules.mjs・effects.mjs、不変更） | `n:'submarine'` は `3+Number(variant)*2`、`variants:[0,1,2]`、`extraTime:'variant'`（rules.mjs・effects.mjs、不変更） |
| 旧本文の読み | 時点の記載なし（裁定で解決時） | 3＋2×選んだ数 |
| 新本文の読み | 解決時（裁定と同じ） | 0→3、1→5、2→7（3＋2×0／1／2 と同じ） |
| テスト | `tests/lunar-submarine-text.test.mjs`（解決時2で成立、反応で1に減ると不成立、使う前2でも支払い後1なら不成立） | 同（0／1／2 → 時2／3／4・3／5／7枚、1枚まで、残りは指定順で一番下、山札不足） |
