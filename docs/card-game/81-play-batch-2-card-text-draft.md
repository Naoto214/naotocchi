## 2. 共通の読み方

- 時は印刷値。しかけるは前払い、発動時に二重払いしない。すぐつかうは発動条件と反応機会を満たせば相手ターンにも使用できる。
- アクションカードはあそび・あいてむ・できごと。プレイと、しかけ済みカードの発動を区別する。2回のときとばし・二つの完了した勝負は、実際に行った履歴だけを数える。
- 対象は発動時に指定し、解決時に適正を確認する。対象となる装備の行き先も適正である必要がある。本文の独立した処理と「したなら」の条件付き処理を区別する。
- 山札が不足すれば存在する枚数だけを扱う。公開したカードから選ぶ時は選択を双方に示す。見たカードを手札に取るだけの探索では、本文にない公開義務を追加しない。
- 予約は発動元が離れても期限まで残り、対象が別領域へ離れて戻れば別個体。65の途中終了を勝利・引き分け・完了へ読み替えない。終了後に作った終了時予約は遡及しない。
- 交際へ性別・恋愛対象を持ち込まない。通常勝利+5を維持し、追加分との合計+10を上限にしない。
