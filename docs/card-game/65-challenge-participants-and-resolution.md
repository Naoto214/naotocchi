## 2. 個別本文の修正

現行の完全本文で「このメインがちょうせんする時」とだけ書かれていたのはおとこのひと⑥・ヒトデ⑥。08のフェニックス⑤には「ちょうせん時」という省略が残っていた。自分から・受ける時・勝った時を全件同じ文字列に置き換えず、役割に沿って次のように明記した。

| カード・正本 | 個別改稿 | 役割と再試験点 |
|---|---|---|
| おとこのひと⑥ 7/7・15 | 自分から／受ける時の両方。低い方+1、同値なら1つ選ぶ処理は維持 | 成熟期の使い分け。低い方は解決時に確認する。受けでも使える7/7の滞在価値を再試験 |
| ヒトデ⑥ 6/6・54 | 自分から／受ける時の両方。捨て札の非メイン3種類条件と使用能力値+1は維持 | 傷・経験の多様さで適応する。種類条件は最初の発動機会だけ。おとこのひとの無条件の低い方補正とは別 |
| フェニックス⑤ 10/5・08 | 両方向で発動可。手札1枚を発動コストにし、選ぶ能力値+2はこの勝負の間。勝負終了後のちから-2は当ターン中 | 代償付きの極限ピーク。旧省略文の+2の期限と支払いを明記。防御でも使える強さ、手札消費と終了後の消耗を再試験 |
| ぬいぐるみ⑦ 1/8・08 | 相手から受ける時、本人のちから1以下なら任意発動。終了後に上2枚から1枚上・残り下 | 低いちから自体の価値。ちえ勝負でも条件成立。弱さを確認するのは発動時で、終了後の山札操作は予約 |

これらは**個別カードの改稿案**。未指定の範囲を設計しているので、旧試走の結果をそのまま両方向での検証結果へ読み替えない。数値・通常時・1ターン1回は変えていない。本文案あり190枚・未展開58枚も変わらない。既存代表のA採用6枚のうち2枚を正式語彙へ進めたが、残る4枚の省略やU07を解消した扱いにはしない。

旧フェニックス⑤の本文は「1ターン1回、ちょうせん時に手札1枚を捨て、ちからかちえ+2。そのちょうせん後ちから-2（ターン終了まで）。」、旧ぬいぐるみ⑦は「1ターン1回、ちから1以下でちょうせんされた時、その終了後山札上2枚を見て1枚上・1枚下。」として履歴を残す。新しい完全本文は08を正とし、本書へ重複して管理しない。

### 表記の使い分け

| 表記 | 指すもの |
|---|---|
| このメインが自分からちょうせんする時 | そのメインで自分から宣言する一戦。受け側では使わない |
| このメインが相手からちょうせんを受ける時 | 相手の宣言を受ける一戦。自分からは使わない |
| 上記2条件を「または」で明記 | どちらの一戦でも使える。ただし発動機会は宣言後・比較前の所定の機会 |
| 自分がちょうせんした／していない | 自分からの宣言履歴。受けることを自分から挑んだ履歴へ足さない |
| このメイン／自分がちょうせんに勝った・負けた | 自分からに限定する本文がなければ両方向の実際の結果。引き分けは勝ちでも負けでもない |
| このちょうせんに勝ったなら／勝った時 | 指定された一戦の勝利。別の勝負の勝利へ持ち越す条件ではない |
| このターン、次にちょうせんで勝った時 | 予約適用後の次の実際の勝利。宣言時点で消費する予約と区別 |

プレイヤーの自分からの1回と、カード個体の能力1回は別。たとえば、同じおとこのひと⑥を維持しても、自分ターンと相手ターンには能力をそれぞれ使える。新しい個体が来ても、プレイヤーの宣言回数は戻らない。無指定の旧省略本文を使う時は、勝手な共通解釈で埋めず該当する改稿を参照する。

## 3. 比較前の参加メイン離脱による途中終了【確定】

ユーザーが提示した確定文は[02「勝負中に参加メインが場を離れた場合」](02-main-system.md)へ原文を保持して反映した。以下は既存裁定への接続。初回案の「不成立」という表現は、開始していなかったという誤読を防ぐため「途中終了」へ改めた。

**有効な宣言時に勝負は開始し、宣言時の2体を参加個体として固定する。比較前にどちらかが場を離れた時点で途中終了する。比較・勝敗決定を行わず、勝者・敗者・引き分けを作らない。宣言回数、カード・能力へ支払済みのコスト、既に起きた出来事は戻さない。宣言自体は時0のまま。**

| 終了時・終了後に参照する条件 | 比較前の途中終了 | 通常の終了・完了 |
|---|---|---|
| この勝負の終了時／終了後 | 適用済みで他の条件も満たせば処理 | 同様に処理 |
| 比較後／勝敗決定後／比較まで完了した場合 | 比較がないので処理しない | 実際に比較・結果決定を行っていれば処理 |
| 勝った時／負けた時 | 勝者・敗者がないので処理しない | 実際の勝者／敗者だけ。引き分けでは処理しない |
| 終了後、ただしその勝負に勝っていた場合 | 終了しても勝利条件がないので処理しない | 勝っていれば処理 |

「終了時／終了後」だけを理由に他の条件を省略しない。通常の途中終了は基本ルールが処理するため、除去・移動カードすべてへ「勝負を終了する」と追記しない。異なる処理を意図したカードだけ例外を明記する。

- 片方だけ、双方、除去、手札へ戻る、別個体へ入れ替わる場合を同じ基準にする。同じ物理カードが同じ効果内で戻っても、07どおり別個体なので再開しない。
- 離れた時点で勝負は途中終了するが、進行中の効果・連鎖を一律に打ち切らない。残りの効果を可能な範囲で解決し、終了時・終了後の適用済み予約、離脱等の誘発・反応を06どおり処理する。比較前へ戻ったり、開始していなかったことにしたりしない。
- 除去が無効・防止され、参加個体が実際には離れなかった場合は続ける。かめ⑧の置換でセカイだけを失う場合も同じ。ただし盤面変化後の実際の値で比較する。
- 比較前の途中終了には、通常勝利+5、クワガタ⑦等のその一戦の勝利追加、かみさま②の敗北時能力は生じない。引き分け条件も成立しない。
- 宣言時・離脱時等に別の条件で実際に得たそだちや、独立した効果の処理は取り消さない。途中終了は、その勝負の勝利・敗北・引き分けの報酬を作らないという意味で、期間中の全そだち変動を禁止するものではない。
- 有効な宣言だったので、自分から挑んだ1回と履歴は残る。「次にちょうせんする／受ける時」の適用済み予約も使用済み。宣言前からたまごだった等、そもそも始められなかった場合とは別。
- 「終了後」は途中終了でも迎える。既に解決済みのぬいぐるみ⑦の山札操作は実行する。フェニックス⑤本人が残る場合は消耗する。本人が離れていれば、元個体への消耗を新メインへ付け直さない。
- 数値比較で結果を確定した後にメインが離れても、確定した勝敗・通常報酬を遡って消さない。後続の個別効果は対象・参照先等の適否を通常どおり確認する。

### 比較した選択肢（初回案の検討履歴）

| 方式 | 結果と影響 | 今回の判断 |
|---|---|---|
| 宣言個体を固定し、比較前の離脱で途中終了 | 除去が、その一戦の得点を止める場合もある。後継メインは次の行動から使う | 途中終了として採用。別個体とたまごの既存ルールへ接続 |
| 離れた側を不戦敗、残った側に+5 | 相手メインの除去をそのまま勝利条件にできる。両方離れた場合等の追加規定も必要 | 不採用。除去と得点の関係を新たに大きく強める |
| 比較時のメイン枠の新個体へ引き継ぐ | 途中の入替で勝負の値・能力を差し替えられる。たまごになった場合の扱いは別途必要 | 不採用。宣言・対象・一戦限定補正の引継ぎが複雑になる |

この途中終了は「自分を逃がして負けを防ぐ」「相手を除去すると得点を失う」という判断を作る。現行02が許容する、たまごへの退避が利益になる場合と両立するが、除去・自分のメイン移動効果の強度は実カードで再試験する。自分のメインを自由に捨てる基本行動や、無制限の無料退避は追加しない。

## 4. 宣言から終了まで【確定】

ユーザーの確定文に沿って、参加個体・予約・結果・終了を02・06へ接続した。連鎖中の途中終了を記録する時点と、終了に伴う処理を行う時点を区別する。

| 順 | 処理 | 注意点 |
|---|---|---|
| 1 | 宣言できることを確認。双方の参加個体とちから／ちえを示し、宣言時に勝負を開始して自分からの1回を記録 | 宣言自体は時0。途中に発動を挟まない。宣言は通常行動であり、カード効果の対象指定ではない |
| 2 | 宣言時刻の来た適用済み予約を実行し、ちょうせん時の誘発・反応へ | ちょう⑤・セミ⑧・おばけ⑤等の予約。既に適用済みの自動処理は新しい発動として積み直さない |
| 3 | 連鎖と後続誘発・反応を終える。比較前の離脱があれば、その時点で途中終了を記録 | 勝負が続いていれば、解決後もターン側から反応機会を渡す。連鎖・未処理誘発がない状態で双方連続パスなら比較へ。途中終了なら現在の効果・連鎖を終え、比較へ戻らず6へ進む |
| 4 | 参加個体の継続を確認。両者が維持されていれば最終値を比較し、勝敗と通常+5を続けて処理 | 比較・結果確定・通常報酬の途中に発動を挟まない。途中終了なら比較も通常報酬も行わず6へ |
| 5 | 実際の勝敗に対応する適用済み予約を実行し、勝敗等の誘発・反応を終える | カワウソ・クワガタ⑦・りゅう⑤の解決済み予約はここ。かみさま②・サンゴ⑧等は通常の発動。元の勝敗は補助や離脱で変え直さない |
| 6 | 終了時の適用済み処理、一戦限定の補正の終了、終了後の適用済み処理と誘発・反応を終える | フェニックス⑤の+2が終了してからちから-2。ぬいぐるみ⑦も、終了前に適用済みなら途中終了でも処理。比較や勝敗を要する未成立条件は処理しない |

### 予約・条件・期限

- 同時刻の適用済み自動予約は、64と同様にターン側→非ターン側、同じプレイヤー分は本人が順を選ぶ。一群の途中に新規発動を挟まず、そこから生じる誘発は一群の後へ送る。置換・防止は必要な出来事の直前に適用する。
- 勝負の宣言自体は1回だけ。宣言時に有効な能力について、最初の発動機会で状態条件・支払いを確認する。その後に登場・コピー・条件充足しただけで同じ宣言へ遡らない。解決時確認と書かれた条件は本文どおり。
- 「次に宣言する／受ける時」の予約は、その予約の適用後に来る宣言で使用する。既に始まった勝負の途中に新しく作っても、過ぎた宣言には適用しない。一方、「次に勝った時」は比較前に予約が適用されれば、その勝負の実際の勝利へ使える。
- 宣言時の予約は使用後に特定の一戦・参加個体へ結び付く。ちょう⑤から別メインへ移った**後の宣言**には+2を渡せるが、宣言後に入れ替わった新個体へ同じ+2を渡し直さない。
- 途中終了や引き分けでは「次に勝った時」の予約は未使用。ただし自身の期限は延長しない。カワウソならそのターンまでで、自分からの1回を使った後に通常の再挑戦を許す効果にもならない。
- クワガタ⑦・りゅう⑤の「このちょうせん」の勝利予約は、負け・引き分け・途中終了なら追加そだちなしで終わる。別の勝負へ持ち越さない。手札・準備等の支払いも返さない。
- 「このちょうせんの間」は終了処理で終了し、終了後の予約より前に終える。通常は勝敗に対応した処理を経るが、途中終了では比較・勝敗の手順を行わない。「このターン」は64の期限まで残る。終了後の処理を終えるまで通常のへんしん等は挟まない。
- 終了の出来事は一戦に1回だけ。終了前に適用されていた効果を処理し、途中終了後の解決で作った予約を過ぎた終了へ遡らせない。比較して引き分けになった勝負は完了するが、途中終了は比較を経た完了ではない。
- 「このちょうせんに勝った」等の結果は比較時の記録。勝敗後の反応で数値が下がる、敗者が離れる等で結果を再計算しない。結果を受ける能力の対象不適正等は06・07どおり個別に処理する。
- そだち100への到達は各実変化で記録し、勝負中に即勝利にしない。確定済み64の、到達後に開始する最初の相手ターン終了までの維持とR10最終比較を使う。
