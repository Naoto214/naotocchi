## 3. 禁止する近道

- カード本文・数値・登録区分や現行452の定義を、fixture成立のために変更しない。
- 未実施や到達不能を発動率0、カード強度不足、採用不可として数えない。
- ①から③への一度の移動を、ときとばし2回として数えない。
- 同じ物理カードを盤面と捨て札へ重複させない。
- サクラ⑤、りゅう⑧、ペンギン⑦、かみさま⑧を通常配置や例外処理で直接メイン枠へ置かない。
- 112のfixtureをcompleted対戦、勝敗、発動率、強度測定へ数えない。

## 4. 通常意思決定の初回反復

対象fixtureを作る112より後に、107の判断プロトコルで通常意思決定4戦を1バッチだけ実施する。

- 独立した初期順を2組用意する。
- 各初期順を先後鏡像にし、合計4戦とする。
- 各通常行動機会で合法候補とpass、判断前状態、選択、次点、理由、支払い、対象、連鎖、公開情報を保存する。
- 4戦終了時に停止し、判断不能、候補数、未使用時、カード種類別使用数、予約、再登場、そだち推移を再確認する。
- 4戦だけで勝率、先後差、発動率、カード強度の結論を出さない。

「独立した初期順」は110までの焦点カードを成立させる固定順のコピーを意味しない。一方、完全な無作為大量対戦や対戦エンジン化も、この初回バッチの範囲外とする。

## 5. 停止条件

以下のいずれかが起きた記録はfixtureまたはcompleted対戦として確定せず、その地点で設計監査へ戻す。

1. 高段階メインの直接配置など、既存ルールにない近道が必要になる。
2. 必須前提カード、領域、支払い、対象、期限を用意できない。
3. 相手の非公開手札・山札を判断へ使用する。
4. 既存正本だけでは一意に裁定できない。
5. validator、保存JSON、再生成結果が一致しない。

停止はカードの不採用や弱さの判定ではない。必要ならfixture構成または裁定正本を別チェックポイントで見直す。
