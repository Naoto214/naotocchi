# 09 第0弾テストデッキA 初回模擬対戦

最終更新: 2026-09-13

状態: **初回ペーパーテスト。第2稿調整前。**

**61全体監査追記（2026-09-14）:** この模擬は過去の試走記録。下記の得点評価は受け側の勝利回数を数えておらず、通常報酬の上限を示さない。現在の訂正は[61 F01](61-full-rules-and-card-text-audit.md)。完全な対戦ログがないため、今回この試合を再現済みとは扱わない。

## 模擬前に正本から再確認したこと
- 40枚固定、初手5、マリガンなし、毎ターン開始時1ドロー、先攻R1もドロー。
- R1=時1〜R10=時10。毎ターン最大値まで回復、持越しなし。
- そだち初期20、5刻み、最大100。
- メイン通常時は段階番号。
- たまご中は通常ドロー後にさらに1枚引き、手札1枚を山札下へ戻す。したがって、たまごに留まること自体に手札調整価値がある。
- たまごはちょうせん不可・ちょうせん対象にもならない。
- **なかまは時0。** 08第1稿に書いた「なかま時1」は01正本との不一致なので、模擬では正本の時0を使用する。08の次回更新時に修正する。
- アクションの正式プレイ方式は01正本の `すぐつかう / みにつける / しかける` を優先する。08の略記「つかう」はカード案のメモ表記であり、正式本文化時に `すぐつかう` へ統一する。

## 初回シャッフル
再現用シード:

## R1〜R4: たんじょうまで
Aは初手に③かえるを持つがR1〜R2では払えない。たまご手札調整を使い、R3で②いぬを確保してたんじょう可能になった。

Bは初手に④カクレクマノミと⑤フェニックスを持つが、低段階メインを引けず、④カクレクマノミをR4で直接たんじょうするのが最初の自然な開始になった。

結果:
- A: R3から人生開始。
- B: R4から人生開始。
- たまご能力があるため完全な「何もできない」ではないが、序盤2〜3ラウンドはメイン同士の読み合いが発生しない。

## R4〜R7: 最初の実戦区間
Bの④カクレクマノミ5/5に対し、Aの②いぬ3/2は数値上かなり不利。Aは④カブトムシ1/4へへんしんしても正面性能は改善しにくく、手札にある補助カードを使う理由が生まれた。この点は「高段階へ進めば自動的に強い」ゲームになっておらず良い。

一方で、Bは直接④たんじょうによって早期の数値優位を得る。Aは低段階から始めたことで早くメインを持てるが、差分時コストの利点を活かせる後段階同種族カードが手札に来なければ、その長所を十分使えない。

ここで **低段階開始 vs 高段階直接たんじょうの基本思想自体は成立しているが、40枚中メイン10枚かつ各種族の段階が飛び飛びなので、「低段階から人生をつなぐ」体験がドロー依存になりやすい** と判定。

## R8〜R10: 終盤構造の確認
R8以降は⑧メインを直接出せるため、おとこのひと⑧・カブトムシ⑧が手札にあれば一気に終盤能力へアクセスできる。これは確定ルールどおりで問題なし。

ただし、R3〜R4までたまごだった試合では、ちょうせん可能なターン数が最大でも7〜8回程度。ちょうせん勝利+5だけでは初期20から100へ届かない。結婚+10、サクラ⑥等の人生成果を絡める必要があるというゲーム意図は確認できた。

監査訂正: 7〜8回は自分からの機会だけ。受け勝利も+5なので、両メインがR4にそろう本試走の機会はR4の出生順により最大13〜14戦、通常報酬は+65〜70となる。本試走で100に届かない点は維持するが、R1出生等の全試合へ一般化しない。61には通常報酬16勝で100に届く反例を保存した。

一方、現40枚は直接そだちを増やすカードが少なく、交際→結婚にも時間が必要なため、**初回試走では100到達よりR10判定へ行く試合が基本になりそう**。これは即問題とはしないが、早期100勝利が実際に起こり得るかは複数試合で要測定。

# 初回模擬で見つかった重要点

## 1. 08のなかま時1は誤り【修正必須】
01正本ではなかま時0。模擬は時0で実施。第2稿で08を修正する。

## 2. メイン10枚の段階分布は「属性テスト」には良いが「序盤開始率」は低め
現分布: `①②③④④⑤⑥⑦⑧⑧`。

初手5＋通常ドローだけなら低段階を引けない率は高いが、実際にはたまごの追加ドロー→1枚戻しがあるため緩和される。それでも今回BはR4開始だった。

**現時点では入れ替えを即確定しない。** たまご手札調整が設計上意図された救済なので、まず複数シャッフルでR1〜R4の開始ラウンド分布を測る。平均開始が遅すぎる場合に、追加枠の⑧1枚を①〜③へ変更する。

## 3. 低段階から積むメリットを測るには同種族の複数段階が必要
現Aでは、おとこのひと①/⑧、カブトムシ④/⑧だけが同種族2枚。いぬ②、かえる③等は同種族後段階がないため、ときおくりの差分コストを実戦で十分検証できない。

第0弾Aが「8属性代表テスト」と「人生接続テスト」を同時に担うには不足がある。40枚Aを変えるより、**次のテストデッキBを1〜2種族の複数段階中心にして比較する**案が有力。

## 4. 山札を見る処理はやはり多い
たまご自体にも手札調整があるため、カード側の「上を見る」が重なるとゲームテンポを落とす可能性が高い。特にふくろう、カワウソ、カタツムリ、ぬいぐるみ等が同時に並ぶ試合は物理版で確認回数が多くなる。

第2稿では少なくとも1〜2枚を、山札確認ではない簡潔な利益へ変更する候補。

## 5. なかま時0は盤面形成をかなり助ける
時をメイン／アクションへ残したままなかまを出せるため、R1〜R3のたまご中でも人生世界を少しずつ作れる。なかま3枠の詰まりは、時コストより「自分ターンにこいびとと合わせ1人まで」の制限が自然なブレーキになる。

# 第1回結論
- 基本ルールを変更する必要はまだない。
- 40枚構成も1試合だけで即変更しない。
- まず08の正本不一致（なかま時0、正式語彙）を直す。
- 次に複数シャッフルの統計テストを行い、平均たんじょうR、R4までたまご率、メイン死に札率を測る。
- その後、2〜3試合の詳細プレイでそだち速度、先攻後攻、盤面詰まり、山札確認頻度を測る。
