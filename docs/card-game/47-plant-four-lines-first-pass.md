# 47 くさ属性 — タンポポ／ハエトリグサ／キノコ／世界樹 第1稿

最終更新: 2026-09-14

状態: **未設計4種の人生テーマ＋仮数値曲線。サクラは既存代表を維持。具体能力本文未確定。**

## 属性テーマ

くさ = **そだてる**。

- タンポポ: **根づいて、最後に散らす**
- サクラ: **仕込んで、咲かせ、実らせる**
- ハエトリグサ: **待って、条件が来たら捕らえる**
- キノコ: **見えないところで広がり、表へ出る**
- 世界樹: **長い成長で世界全体をつなぐ**

# 1. タンポポ — 根づいて、ちらす

仮数値曲線:
`①1/3 → ②2/3 → ③3/4 → ④5/4 → ⑤6/5 → ⑥7/5 → ⑦4/7 → ⑧3/9`

合計: ちから31 / ちえ40 =71。

後半は自分の強さより、育てたものを遠くへ渡す能力へ価値を移す。

既存曲線:

# 3. ハエトリグサ — まって、とらえる

仮数値曲線:
`①1/3 → ②3/3 → ③4/4 → ④6/4 → ⑤7/5 → ⑥9/5 → ⑦7/6 → ⑧5/8`

合計: ちから42 / ちえ38 =80。

捕食植物としてくさ内ではちから寄り。ただし強さは**相手が条件を踏んだ時**に活かす。

現実のハエトリグサは感覚毛への刺激を検知し、短時間に複数回の刺激があると罠を閉じる。これを「相手の行動を数回待つ」カード文へ直接コピーするのではなく、公開情報で分かる反復条件へ翻訳する。

# 4. キノコ — みえないところでひろがる

# 5. 世界樹 — 世界までそだてる

仮数値曲線:

## 重複監査

- ハエトリグサとアリジゴク: 両方待ち伏せだが、アリジゴクは成虫でプレイ様式反転、ハエトリグサは一生「待って反応」。
- タンポポとちょう: 両方移動・花に関わるが、タンポポは育てた種を散布、ちょうは蓄えから羽化して価値を運ぶ。
- キノコとおばけ／ぬいぐるみ: 捨て札を使っても、キノコは「見えない網を広げる」、おばけは「離れた後も残る」、ぬいぐるみは「失ったものの評価を変える」。
- 世界樹は高数値レアだが、サクラの開花成果を単に倍にしない。
