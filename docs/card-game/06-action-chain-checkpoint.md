## 条件／コスト／効果【確定】
- **発動条件**は、そのカード・能力を発動できる状況かを判定するもの。原則として発動時だけ確認する。
- 一度正当に発動した後で発動条件を満たさなくなっても、そのことだけでは発動・効果を無効にしない。
- ただし、効果本文そのものが解決時の状態を参照する場合は、解決時にその状態を確認する。
- **発動コスト**は発動するために発動時に支払うもの。一度正当に支払ったコストは、その後に発動または効果を無効にされても返還しない。支払った「時」も戻らない。
- 「手札1枚を捨てて発動する」の捨て札はコスト。「手札1枚を捨てる。その後〜」の捨て札は効果。効果を無効にされた場合、効果としての捨て札は行わない。
- 「そうしたなら」は、指定された前処理を実際に行えた場合だけ後続処理を行う。

## コスト／効果で起きた出来事の参照【確定】
- カード文が単に「〜した時」と書く場合、コストか効果かを問わず、その出来事が実際に起きれば参照できる。
- 区別したい場合は「効果で〜した時」「コストとして〜した時」と明記する。
- 発動手順の途中には別の発動を割り込ませない。例: コストとして手札を捨てる→元カードの発動成立→その後、「手札を捨てた時」に発動できるカードを同じ連鎖へ追加できる。

## 反応機会・パス【確定】
- カード／能力を発動したプレイヤーがまず追加発動するか選べる。パスしたら相手へ反応機会が移り、以後交互に反応機会を持つ。
- 一度パスしても、相手が新しい発動を追加した場合は再び反応機会が来る。
- **双方が連続してパスした瞬間に連鎖構築を終了し、逆順解決へ入る。** その後「やっぱり発動する」は不可。
- 解決開始後はその連鎖へ新しい発動を割り込ませない。

## 強制発動／通常任意発動／しかける【確定】
- **強制発動:** 「〜した時、発動する」。条件成立時の最初の発動機会で必ず発動する。
- **通常任意発動:** 「〜した時、発動できる」。条件成立後の最初の発動機会で使うか決める。見送った場合、同じ出来事を理由に後から発動できない。
- **しかけるの任意発動:** 例外として、条件成立時にすぐ発動せず温存できる。その出来事を含む連鎖の構築中で、自分に反応機会がある間なら、相手の反応を見た後でも発動できる。
- しかけるも双方連続パスで解決開始したら、その出来事を理由に発動する権利を失う。
- この性格は遊戯王のセットされた罠カードに近い役割だが、なおとっちでは上記を独立した正式ルールとして扱う。

## 同じタイミングで複数条件成立した場合【確定】
同じタイミングで複数の発動条件が成立した場合、まず以下の順で連鎖へ積む。
1. ターンプレイヤーの強制発動すべて
2. 非ターンプレイヤーの強制発動すべて
3. ターンプレイヤーの通常任意発動
4. 非ターンプレイヤーの通常任意発動
5. しかける等を含む通常の反応を交互に追加
6. 双方連続パスで連鎖確定、逆順解決

- 同じ区分に複数ある場合、そのプレイヤーが積む順番を選ぶ。
- 強制発動は双方とも先にすべて積む。通常任意はその所定の機会で発動するか決め、見送れば同じ出来事では後出し不可。
- しかけるだけは上記の温存特例を持つ。

## 解決中に新しい発動条件が成立した場合【確定】
- 連鎖の解決中に新しい発動条件が成立しても、その場では割り込まない。
- 現在の連鎖を最後まで解決した後、解決中に成立して待っていた効果を確認し、新しい連鎖として処理する。
- 新しい連鎖でも、`ターンプレイヤー強制 → 非ターンプレイヤー強制 → ターンプレイヤー通常任意 → 非ターンプレイヤー通常任意 → しかける等の通常反応` の順序を使う。
- 解決中の別々の時点でA、Bが条件成立して待機していても、元の連鎖終了後にA、Bが**同じ発動区分かつ同じプレイヤーのもの**なら、条件成立の早い／遅いでは固定せず、そのプレイヤーが積む順番を選べる。
- 専用の待機カウンター／履歴トラックは現時点では作らない。

## 同じ能力が解決中に複数回条件成立した場合【確定】
- **同じカードの同じ能力でも、1つの連鎖の解決中に条件を複数回満たしたなら、条件を満たした回数だけ発動できる。** 原則1回にはまとめない。
- 例: 「手札を捨てた時、1枚引く」能力があり、元の連鎖の解決中に別々の処理で2回「手札を捨てた」が起きたなら、元の連鎖終了後にその能力は2回分待機しており、2回発動できる。
- 同じ能力の複数回分も、それぞれ独立した発動として新しい連鎖へ積む。
- 回数を制限したい能力は、カード側に「1連鎖に1回」等の回数制限を明記して例外化する。
- したがって解決中は、待機している能力だけでなく**各能力が何回条件を満たしたか**も保持する。専用の物理カウンター／履歴トラックを基本ルールとして必須にはしない。

## 回数制限の共通語彙【確定】
- **「1ターンに1回」**は、そのカード1枚のその能力について1ターンに1回。場に同名カードが複数あれば、それぞれ1回ずつ使える。
- **「1ラウンドに1回」**は、そのカード1枚のその能力について1ラウンドに1回。自分ターンと相手ターンを通して1回だけ使える。
- **「この名前の能力は1ターンに1回」**は、同名カードが複数あっても、そのプレイヤー全体でその名前の能力をそのターン合計1回だけ使える。
- **「この名前の能力は1ラウンドに1回」**も同様に、同名カード全体でそのラウンド合計1回だけ使える。
- **「1連鎖に1回」**は、そのカード1枚のその能力について、同じ連鎖を原因として発動できるのは1回まで。連鎖解決中に同じ条件を複数回満たしても、その連鎖終了後に発動できるのは1回だけ。
- **「この名前の能力は1連鎖に1回」**は、同名カード全体を通して、その連鎖を原因とする発動を合計1回に制限する。
- 回数制限は原則として**能力単位**に掛かる。同じカードに別々の能力がある場合、一方の「1ターンに1回」を使っても、別能力まで使用済みにはしない。カード全体を制限したい場合はカード文で明示する。

## 01-core-rules.md に保存済みの直前確定事項
- 対象は発動時に選んで固定。不在・不適正になっても自動で選び直さない。
- 対象変更は明示された効果だけ。原則として元効果の適正対象内で変更し、変更カードが変更先を明示する場合はその指示を優先。
- 一部実行不能でも可能な部分を適用。複数対象の一部だけ不適正なら残りへ適用。全対象不適正でも対象外の残りの効果は可能なら処理。
- 「その後」は前処理ができなくても後続を可能なら行う。「そうしたなら」は前処理が実際に行えた場合だけ後続を行う。
- 効果無効=`発動○ / 解決○ / 効果適用×`。発動無効=`発動× / 解決× / 効果適用×`。
- 発動無効でも時間を巻き戻さない。すでに成立した他の連鎖、ドロー、そだち増減、カード移動等は取り消さない。カードを元の場所へ巻き戻さない。
