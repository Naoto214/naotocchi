# 詳細模擬A-2
## 序盤
双方R2〜R3で低〜中段階メインへ。なかま時0により、たまご中でも盤面形成は可能。R1の時1をアクションへ回せるため「たまご=完全待機」にはならない。

## 中盤
時4〜6になると、メイン移動＋時1アクションの組み合わせが自然に可能になる。一方、高段階へ直接たんじょう／へんしんすると、そのターンは他の有料行動をほぼ行えない。このトレードオフは良好。

ちょうせんは毎ターン必須行動ではなく、数値補助や相手状態を見て仕掛ける形になった。いぬ②、サングラス、キャッチボール、フェニックス⑤がある時に明確に攻め時が生まれる。

## 終盤
そだちはR10判定へ向かう。ちょうせん勝利だけで100へ行くことは難しく、交際→結婚やサクラ等の人生成果を絡める必要があるという基本思想は成立。

監査注: この試走の見通しとして保存する。通常勝利だけでの100到達不可能を意味せず、頻度は勝敗別の得点を残した再試験で測る。

# 詳細模擬A-3
## 山札操作密度
たまご、ふくろう、カワウソ、カタツムリ、ぬいぐるみ等が重なると「上を見る→戻す」が1ターンに複数回起こり得る。ゲーム上は処理可能だが、物理カードではテンポを明確に落とす。

特にカワウソとカタツムリは、役割を維持しながら山札確認以外へ変更可能。

## 盤面
なかまは最大3だが、新なかまを出す時に既存1人と交代できる01正本があるため、以前懸念した「なかま枠を自力で空けられない」は問題ではなかった。自由廃棄ルール追加は不要。

準備3枠は、みにつけるが長く残ると圧迫する。しかける2枚しかないAでは完全ロックまでは起きにくいが、装備3枚を並べると新しいみにつける／しかけるの選択が狭くなる。これは意図した盤面管理として現状維持。

# 詳細模擬A-4
## 条件付き死に札
- ハグ: 相手効果でそだちが減らない試合では完全に使えない。
- トイレットペーパー: 現Aに「相手メインを捨て札にする」カードがほぼないため、A対Aでは発動機会が極端に少ない。
- かくれんぼ: 対象変更先として適正ななかまが必要で、対象を取る相手カードも限定的。高度ルール試験用としては意味があるが通常性能は低い。
- おはな: 現本文の「つけたカードを発動元とする能力でそだち増加」が該当しづらく、期待した恋愛連携を十分起こせない。

この4枚は第2稿で優先修正対象。

# 先攻／後攻
現段階では、先攻R1も1枚引くため先攻の手札差はない。先攻は先に盤面を作れる一方、後攻は相手の盤面を見て行動できる。カタツムリの後攻小利益もある。詳細数試合では基本ルールを変更するほどの明確な先攻有利は確認できず、現状維持。

# 第2稿で行うカード調整
基本ルールは変えず、カード側だけ最小修正する。

## 1. 正本不一致修正【必須】
- なかま6枚の時コスト表記を時1→**時0**。
- アクションの「つかう」略記を正式語彙 **「すぐつかう」** へ統一。

## 2. 山札確認を2枚削減
### カワウソ
旧: あそび使用時、山札上1枚を上／下。
第2稿候補: `1ターンに1回。自分が「あそび」をプレイした時、発動できる。このターン、自分が次にちょうせんで勝った場合、そだち+5。`
- あそび連携を強め、山札確認を削る。
- いぬ②と似るため、いぬ=能力値補助、カワウソ=勝利後成果で分離。

### カタツムリ
旧: 後攻ならターン最初に山札上1枚を見る。
第2稿候補: `自分がそのラウンドの後攻プレイヤーなら、自分のターン中、自分が最初にプレイするアクションカードの時を1少なくする。`
- 「遅いから少し得」を維持。
- 0コスト化問題が未確定なので、採用前に最低支払値裁定が必要。よって第2稿では一旦旧能力維持、時軽減裁定後に変更判断する。

結論: 山札確認削減はまずカワウソ1枚だけ確定候補。2枚目は時軽減裁定を増やさず、別案を次回検討。

## 3. ハグ
旧: 相手効果でそだちが減ったターンのみ+5。
第2稿候補: `自分のそだちがこのターン減っている場合に発動できる。自分のそだち+5。`
- 相手効果限定を外し、自分の代償等にも将来対応。
- それでも空撃ち不可で条件は明確。

## 4. トイレットペーパー
置換テストという役割は重要なのでカード自体は維持。ただしA対Aで発動機会を作るため、できごと側にメイン捨て札効果を安易に足すのは設計原則に反する。Aでは低頻度の高度ルール試験カードとして許容し、通常性能評価はB以降へ回す。

## 5. かくれんぼ
対象変更テストのため維持。第0弾Aで通常カードとして弱くても、テスト目的を優先する。将来正式カード化時に再設計。

## 6. おはな
旧本文は発動機会が狭すぎる。
第2稿候補: `メインまたはこいびとにつける。このカードをみにつけている間、自分の交際段階が進んだ時、1ラウンドに1回、自分のそだち+5。その後、このカードを捨て札にする。`
- 恋愛連携が明確。
- 結婚+10とは別に、交際を進める小成果+5。
- 1回使い切りなので過剰加速しにくい。

# そだち速度の判定
現Aでは早期100はレアで、R10判定が主流になる見込み。ただし「100到達がほぼ不可能」とまではまだ言えない。カワウソ・おはなを+5成果へ寄せる第2稿は、早期100ルートを少し増やす方向でもあり、次の模擬で再測定する。
