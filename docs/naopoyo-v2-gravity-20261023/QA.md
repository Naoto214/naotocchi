# なおぽよ。v2 検証報告

## 実装結果
同種族の段階違いも足し算。合計9〜15は進入先8／進入前に余剰、8+8は変化なしとして拒否。全64組を検証。本体IDを保持してドラッグを続ける。異種族は足場・障害物。
分裂は k=min(n−1,t,s)。通常・2連・3連を実装、能力4以上にも対応。空き不足は部分分裂、0体でもトゲを通行する。探索は通常空きマスだけの8方向BFS最大2歩、同距離は進入方位に対する後／左／右／左後／右後／左前／右前／前。2歩目もこの順、最初の発見を採用して完全に決定的。
合体→トゲ新規進入→分裂配置→重力安定→次入力。種族別段階合計（救出済みを含む）、1〜8、重複なしを維持。通常描画やpointerupでは重力を再実行しない。

## 境界裁定（本人の試遊で評価）
- トゲはその上の本体を支える通行可能な足場。自由ジャンプは追加しない。
- 同一重力連鎖では同じトゲは1回だけ発動。新しい合法移動で再発動可能。単なる段階変化では発動しない。
- 分裂本体と兄弟は直後の重力中だけ相互合体を抑止。別キャラと合体した当事者だけ保護解除。次の合法移動では全体を通常へ戻す。
- 下が8の無変化重力接触は足場。IDだけ交換する無限反復を防ぐ。
- 比較用の初期配置と保存復帰では重力を自動実行せず、最初の合法移動から実行する。

有限性は「各トゲ最大1回」と「その間は質量の落下位置が下がる／救出で残留質量が減る」による。循環検出の巻き戻しに頼らない。旧ステージ23そのものは変更せず、同種のトゲ足場問題をV24と専用テストで再現して確認。

## 操作テンポの比較
実v1/v2エンジンに同じ方向列を渡したtempo.jsonを同梱。V01は旧0成功/3拒否、v2は3成功/0拒否。V10は旧0/5、v2は5/0で、1→3→6→7→5→6を1ドラッグで完了。V11も旧拒否、v2は合体と分裂を続けられる。
これはルールの異なる同じ入力の比較であり、「旧版の最小ドラッグ数が5、v2が1」等とは推論しない。旧ルールではその足し算自体が成立しない。段階1トゲ通過V09は両方3成功。通常トゲV16と2連V17では同じ2移動でも分裂計算・個体数が異なる。
合体・分裂・余剰・重力を理由に指を離す必要はない。救出された本体は操作終了し、別の仲間を救出する際は改めて触れる。8+8、異種族、壁・閉門は意図した通行拒否。予期しない停止のユーザー頻度・楽しさ・指による隠れ方は自動計測で確定しない。
