## 1. 現行メインテーマの 分析

| 項目 | 内容 |
|---|---|
| 調・拍子・テンポ | ハ長調 · 4/4 · ♩=96（swing 0.08） |
| 長さ | 8小節 = 20秒で 1周（ゲームでは ループし、2周目ごとに アルペジオが 加わる） |
| 和声 | C – Am – F – G │ C – Em – F – G7。すべて 全音階の 和音、借用和音・二次ドミナントなし |
| 音域 | F4 – C6（19半音、広め） |
| 旋律の 型 | 1〜4小節: 8分音符の 分散和音で 上下（ド ミ ソ ミ ド…）。5〜8小節: 付点8分の 3+3+2 リズム（ソ..ミ..ド）で 句を 変え、7小節で 高い ド（C6）に とどいて 8小節で ドに もどる |

**良いところ**
- 全部の 音が 和音に よりそうので、明るく にごりが ない。三角波の チップ音色でも 崩れない。
- 後半の 3+3+2 リズムが 前半との 対比を つくり、ここが 曲の 顔に なっている。
- 8小節めの ソ ファ レ シ レ ド が 次の 周の ドへ なめらかに つながり、ループの 継ぎ目が 目立たない。
- 和音音中心なので、別の 楽器・テンポ・調に うつしても 形が 保ちやすい。

**弱いところ（客観的に）**
- 前半 4小節は 分散和音そのもので、「この曲だけの 形」が うすい。C–Am–F–G の 上の 分散和音は 多くの 曲と 似た 手ざわりに なりやすい。
- 和声が 全音階だけで、切なさ・懐かしさを 出す 和音（借用・二次ドミナント）が ない。
- 20秒で 1周するため、長時間 流すと 同じ 句が 早く もどってくる。
- 起承転結の「転」に あたる 部分が 短い（5〜6小節の 変化だけ）。

5案とも 16小節（A 4 + A′ 4 + B 4 + A″ 4 の 起承転結）。現行曲の 2倍の 長さで、ループの 継ぎ目は 16小節め → 1小節めで 自然に つながる ように 書いた（A・B は 16小節に 弱起を 置き、C は 属七で おわって 主和音へ 戻り、D・E は 主和音で 閉じる）。

### 各案の 設計メモ

**A案 ひだまりの みち** — 下降ベース（F – C/E – Dm – B♭）の 上で 短い 動機を 2回、B部（9〜12小節）は 8分休符から 始まる シンコペーションで 色を かえ、13小節で 動機が 4度 上に 戻る。14小節の A7（ソ#）が 唯一の 切なさ。もっとも 王道で、現行曲と おなじ 方向の 発展形。

**B案 ゆうやけの おもいで** — 4度・7度の 音を 控えた 五音音階より の 旋律と、IV – V – iii – vi（Fmaj7 – G – Em7 – Am）の 進行。B部は 高い ド（C6）から 1音ずつ 下がる 句、12小節の sus4 → 3度の 解決が 山場。14小節に A7（ド#）。

**C案 あしたの かぜ** — 8分休符からの 弱起で 駆けだし、2小節目で 一段 高い ラ（B5）まで 上がって「前へ 出る」 感じを 出した。12小節で ♭VII（C♮ の 和音）を 一瞬 はさみ、16小節は 属七で おわって 次の 周へ 背中を おす。

**D案 ほしふる みずうみ** — 3拍子。IV（Cmaj7）始まりで 主和音を 遅らせ、浮遊感を 出す。2小節ずつ 3度 下に 写す 句が「星が ふる」動き。14小節の ♭VI（E♭maj7）が 最も 不思議な 光。

**E案 なおとっちの うた** — 題名「な・お・と・っ・ち」の 5拍の リズム（8分×3、8分休符＝促音、のばす音）を そのまま 動機に した。1・3・5・13小節に 動機が あらわれ、13小節で 曲中 最高音（D6）に とどく。6小節 B7（ソ#）と 8小節 Cm（ラ♭、同主短調からの 借用）で 切なさを 2か所 だけ のぞかせ、9〜11小節は 同じ 形を 1音ずつ 上げる 成長の 句。動機が 2小節で 完結するので、効果音・ジングル・地域変奏に 切り出しやすい。

Claude は 音を 聴けないため、旋律の 形・反復・音域・和声の 分析から つけた 予想点です。現行曲が「すでに 耳に なじんでいる」 利点は 点に ふくめていません。

- **B**: 切なさは いちばん。ゆっくりで 長時間 流しても 疲れない。速い 編曲（ミニゲーム・CARD GAME）には 一工夫 いる。

### 見立て

机上では **E案** が いちばん 現行曲を こえる 見込みが あり、次点は **A案**（王道の 改良）と **B案**（切なさ重視）。C・D案は 主題としては 現行曲を こえにくく、変奏（C → ミニゲーム、D → 夜・地域）の 素材として 価値が ある。差は 大きくないので、最終判断は 実際に 聴いた 印象を 優先する。おすすめの 聴き方は、E案と 現行曲を「ピアノ」で 聴きくらべ、つぎに「くりかえし」を 入れて 数分 流すこと。現行曲の ほうが よければ、現行曲の 採用が 正解。

## 4. 試聴版の しくみと 制約

- 実際の 録音音源は 作っていない。ブラウザの Web Audio で その場で 合成する（`engine.js`）。サンプルの ピアノでは ないので、本物の ピアノより 素朴に 聴こえる。
- 音色は 3種: **メロディのみ** / **ピアノ**（メロディ ＋ 左手の ベースと 和音） / **軽い伴奏**（ピアノの 分散和音・ベース・パッド・ごく 軽い キックと シェイカー）。6曲 すべて 同じ 音色・同じ 音量・同じ 伴奏型。
- 音量: OfflineAudioContext で 6曲を 描いて 測った RMS の 差は 各モード内で 0.8 dB 以内（メロディのみ −20.6〜−21.4 dB、ピアノ −18.9〜−19.7 dB、軽い伴奏 −16.2〜−16.7 dB）。
- 長さ: 現行 60秒（8小節×3）、A 77秒、B 87秒、C 66秒、D 65秒、E 77秒（16小節×2）。
- 「すべて 96」で 6曲の テンポを そろえて 聴ける。「くりかえし」で 長時間 再生を 試せる。
- 現行曲だけ「ゲームの 音で」が あり、`audio.js` の 鳴らしかた（三角波 リード・パッド・ベース・ドラム・2周目の アルペジオ）を なぞる 参考再生。
- 比較の 公平さの ため、現行曲も 他と 同じ ピアノ音色で 鳴らす。音の 長さは 次の 音まで（`audio.js` では 一律 16分 × 2.2）。

## 7. 権利関係

- A〜E案の 旋律・和声づけ・試聴用 伴奏型は、2026-11-08 に Claude（Anthropic の AI）が この リポジトリの ために 新しく 作成した もの。依頼者 Naoto214 の 指示のもとで 制作した。
- 既存の 著作権保護楽曲の 旋律を 参照・引用・模倣していない。下降ベース、IV–V–iii–vi、♭VI・♭VII の 借用、sus4 の 解決などは 一般的な 和声の 技法で、特定の 曲に 依拠していない。
- 主要動機の 由来: A・B・C・D は 各案の 方向（温かさ・懐かしさ・期待・幻想）から 作った もの、E は 題名「なおとっち」の ことばの リズムから 作った もの。
- 音源は 合成で、外部の 音素材・サンプル・ライブラリを 使っていない（フォントは Google Fonts を 表示に だけ 使う）。
- 現行メインテーマは 以前 Claude が この プロジェクトの ために 作曲した 曲で、今回は 読むだけ（変更なし）。
- AI が 作った 楽曲の 著作権の 扱いは 国・地域で 異なる。商用利用や 登録の 前に 必要なら 専門家に 確認する こと。
