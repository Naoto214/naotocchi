2026-09-10、ユーザーの「デザインと実装お願いします」「卵は顔ない方がいいですよね」に基づく新規素材。孵化前の共通卵であり、種族の248形態には追加しない。

| 状態 | パス | 見た目 |
| --- | --- | --- |
| 0–39% | `assets/characters/egg/intact.png` | クリーム色、青銀色の模様3つ、顔なし |
| 40–79% | `assets/characters/egg/cracking.png` | 細い短いひび |
| 80%–孵化前 | `assets/characters/egg/ready.png` | 殻を横切るひび |

全PNGを個別に目視した。128×128の元画像をそのままゲームの既存rendererへ渡す。新規素材のメタデータは [検証JSON](../qa/faceless-egg-assets-2026-09-10.json)。承認済み301画像はバイト単位で保持。

## 制作方法と採用プロンプト

組み込みの `imagegen` を使用。各段階を1枚ずつ制作し、スプライトシートからの切り出しはしていない。背景が不透明だった生成候補は採用せず、背景抽出を再依頼して実alphaを確認した。通常→小ひび→大ひびで同じ卵を編集する。

通常卵の生成：

```text
Create ONE production game sprite for the Japanese virtual-pet game Naotocchi. Use case: stylized-concept. Asset: an UNHATCHED EGG, standalone, no face. Exactly one intact egg centered in a square TRUE TRANSPARENT RGBA PNG. Target logical pixel-art canvas 128x128, all art inside x=16..111 and y=16..119 with at least 8 pixels transparent padding on all sides, baseline y=119. If output must be larger, use exact hard square pixel blocks corresponding to a 128x128 grid. Cute high-quality 16-bit game pixel art matching small softly shaded chibi animal sprites: clear 1-2 logical pixel dark warm-brown contour, rounded egg silhouette with narrower rounded top and wider bottom, gentle front-left highlight, 5-8 restrained flat colors, no antialiasing, no gradients or grain. Shell is warm ivory and cream, with only THREE small irregular pale silver-blue patches, asymmetrically placed so they cannot resemble eyes or a face. Subtle warm tan shading at bottom. Simple, endearing, mysterious, readable at 42px. Egg is vertical, entirely intact, no cracks. No eyes, mouth, eyebrows, cheeks, arms, legs, wings, crown, nest, straw, platform, cast shadow, sparkles, words, labels, frames, panels, borders, background color or painted checkerboard. This is a faceless egg containing an unknown future animal or plant. Keep the complete shell inside the image. Output only the single transparent sprite.
```

## 規格への変換

採用した生成原本の識別子：通常 `exec-1ab70b7c-6497-431f-879d-943a31723792`、小ひび `exec-ae6d1dca-13ce-4e36-9695-ed2bfac135ef`、大ひび `exec-2dae59b3-a1f9-4d65-ab5c-46e243971709`。原本は保持し、各1枚の全体へImageMagickで機械的なサイズ・色数変換を適用した。既存素材の加工はなし。

```sh
convert "$egg_source" -channel A -threshold 50% +channel -trim +repage \
  -filter point -resize x104 -dither None -colors 32 -background none \
  -gravity south -extent 128x120 -gravity north -extent 128x128 \
  -depth 8 "PNG32:$egg_output"
python tools/generate-cast-bounds.py
```

実測の不透明色数は24／27／26、alphaは全ピクセル0または255。接地点は全てy=119。生成モデルが返した絵の色数を無検証で「8色」とは数えない。
