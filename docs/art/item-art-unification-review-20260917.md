## 共通仕様とアンカー

- 最上位基準はメインキャラ・こいびと・なかま。猫 `cat/06`、ロボットのこいびと、フクロウ等と隣接比較する。
- アイテムのアンカーはリュック、らぶれたー、肉球バッジ、まくら、リング。線・紙・布・金属の良い表現を複数参照する。
- 暖色寄りの暗い輪郭、細かなピクセル感、上左からの控えめな光、浅い陰影を基本とする。全面発光・大きな外影・写真風の光沢を使わない。
- 材質の個性は残す。金属・布・紙を同じ塗りに潰すのではなく、輪郭の強さ・細部の密度・実寸での読みやすさを揃える。
- 透過128×128px、見える部分の長辺104〜112pxを目安に中央配置。現在のマスターは108px。ショップは40px枠、ホームは本来の装備枠で評価する。
- モチーフを優先し、箱の角度は穏やかな上面＋正面、カード・バッジはほぼ正面。視点を機械的に同じにしない。
- 名前・効果・価格・セーブ形式は変えない。破損画像の代替表示も維持する。

### Quickコイン target 境界の修正

Runtime CIで `coins (Lv4) could not be solved from its target hint` を再現した。コイン本体の当たり判定は、悪い落下物とバスケット中心の縦距離が18px未満の間を衝突範囲としていたが、QA用 `target()` は `basket.y + 10` を越えた時点で回避を止めていた。再現seedでは悪い落下物が `y=264`、バスケット中心が `y=252` のとき、まだ衝突範囲内なのに良いコインへ移動して失敗していた。

`target()` の回避終了境界だけを実当たり判定と同じ `basket.y + 18` に合わせた。ゲームの出現率・速度・制限時間・得点・実入力処理は変更していない。修正前はseed 21のLv4で確実に失敗。修正後はLv1〜5各500seed（計2,500ケース）、従来失敗テスト30回、Quickテスト15件がすべて通過した。
