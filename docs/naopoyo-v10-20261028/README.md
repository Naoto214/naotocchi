## 正準仕様（今後のステージも利用可）

プレイヤー説明：**同じ仲間は、落ちて触れたら合体する。各トゲは1手につき1回だけ分裂させる。**

共通 `prototypes/naopoyo-v2/engine.mjs` の `splitRules: 'recombine-once-v1'` を選択する。第2章11〜20だけが採用し、revision は6。未指定の第1章・旧v2・既存ワールドは従来規則を保持する。重力・接触・地形は `supported-v1` / `contact-v1` / `magic-gate-v2` を組み合わせる。

1手は `move(state,id,dx,dy)` が受理する隣接1マスの入力から、その重力・接触の安定化まで。長いドラッグの各マスは別の呼出しとなる。Undo は従来どおり一筆書き単位。移動拒否は状態を変更しない。

- `resolvedStep` ごとに新しいローカル `context.fired: Set` を生成。トゲ座標をキーにし、実際の分裂数kが1以上の場合だけ記録する。同じcontext中は再分裂しない。段階1・空き不足による0分裂は記録しない。複数トゲは独立。
- context は盤面オブジェクトへ追加しない。永続保存・Undoに発動履歴は入らず、次の入力・予告仮実行は独立contextを使用する。WorldSessionの既存 `fired` は波・光用の時刻情報であり、このトゲ集合とは無関係。
- 同種族の重力接触は親子でも通常合体。family は合体拒否にも新ルールの循環署名にも使用しない。段階上限8、8超過の余剰分離、異種族非合体、下が8の場合の飽和支持、段階合計と種族別合計を維持する。
- 配置の `splitCandidates` は変更しない。進入方向基準の8方向BFS、合法な空きマスを経由した最大2歩。特殊マス・占有マス・角抜けを除外。本体はトゲへの進入地点、生成体は1。後続重力で本体・生成体・余剰体を安定化する。
- 岩・全段階共通のゲート上面が支持。トゲ・出口は非支持。遠隔生成体は岩・ゲート・通常キャラ支持がある場合に残れる。支持がなければ落ちる。同種接触は通常合体し、異種族と下段8は支持する。
- 循環検知を残す。新ルールの署名は盤面の位置・数字・種族と**ソート済み発動済みトゲ集合**。同じ並びに戻っても新たにトゲを消費した有限連鎖は拒否しない。例外時は元盤面へ復元。通常進行はこのロールバックに依存しない。
- `externalMove` / `externalSplit` の各イベント入口も独立contextを持つ。第2章には時間イベントがなく、1マス入力境界と混在しない。
