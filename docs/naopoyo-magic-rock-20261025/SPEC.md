# 数字付き魔法岩 — 正準仕様 / version 6

`movementRules: contact-v1`, `gravityRules: supported-v1`に`terrainRules: magic-rock-v1`を追加。第2章のrevisionは4。内部の`gates`配列と`exact`は互換のため維持する。

|地形|通行|地形からの支持|効果|
|---|---|---|---|
|通常岩|不可|あり|障壁|
|魔法岩|数字一致のみ|数字不一致のみ|選択的な障壁|
|トゲ|合法な進入が可能|なし|分裂|
|星型出口|誰でも通れる|なし|条件一致で救出|

`terrainBlocks(s,a,x,y) = wall(...) || !gateAllows(...)`が障壁と地形支持の共通定義。キャラによる支持は別に加算する。一致魔法岩上に別のキャラがいれば、そのキャラから支持を受ける場合はある。
上昇は出発直下・到着直下の両方に支持が必要。移動者自身を支持から除外。魔法岩専用ジャンプや落下だけの例外はない。
斜め移動は側面2セルが両方とも移動者にとって障壁の場合に拒否。交換相手も逆方向で独立に同じ判定。合体可能なら合体優先で、不正な合体を交換へフォールバックしない。
合体後の数字・余剰の戻り先・外部分裂後の親をそれぞれ検査。分裂子の配置経路では子の数字1で角を検査。既存の分裂子は通常の空きマスだけへ配置する規則を維持。
