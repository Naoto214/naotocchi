# 全表示文言の読みやすさ修正計画

## Goal

ゲーム、ムービー、イベント、会話、図鑑、操作画面を含む全表示文言を点検し、なおとっちらしい読みやすい文章に整える。

## Architecture / Tech Stack

既存の静的HTML・CSS・JavaScriptの文言定義を直接修正する。DOM/Canvasの表示と既存Nodeテストを利用する。文言のための保存移行や新しい翻訳基盤は導入しない。

## Spec

ユーザー承認済みの全文監査（2026-09-10、main `9969a44ec14ef0339294281f857232067a33846d`）と「ゲーム、ムービー、イベントなども含めて全ての言葉をみて、直して」。基準は短い操作名にはひらがな、長い説明にはやさしい漢字、難語は意味から言い換える。問題のない文やキャラクターの口調は維持する。

## Global Constraints

- Stable ID、種族31系統×8段階、仲間26種・恋人18種、質問150問、ゲーム100種とルール・数値・入力・タイミングを維持する。
- 保存済みの名前・思い出・質問・旧キャラを移行・上書きしない。表示エスケープと旧新テキストによる思い出判定を維持する。
- 既存の画像・音・レイアウト・コメントのイラスト化を保持する。
- 「そだち／せいちょう」「げんき／けんこう／いのち」「きずな／なかよし度」は別の値として維持する。数値効果の幸福度名は「ごきげん」。
- 日本語文中を空白で分かち書きしない。数値の独立した効果は「／」などで区切る。操作キー・英単語・コードの空白は維持する。
- テストは既存の意味ある検証と、操作説明の欠落や動的値のような実際の不具合に絞る。文言の全文スナップショットを追加しない。
- 最新mainを再確認してPRを作成する。マージ・公開はこの作業には含めない。

## Task 1: 全100ゲームの説明・表示を整える

Files: `games.js` 全表示文言、`script.js` の `MINIGAME_INFO`・`MINIGAME_CONTROLS`・ゲーム一覧・初回説明・ゲーム結果、必要な `tests/*` と `package.json`。

1. 全100種の名前、紹介、初回説明、本体の案内、HUD、Canvas、結果を読む。長いかな文をやさしい漢字と句読点で整える。短い呼び名やゲーム固有の用語は自然さで判断する。
2. 初回説明5件の欠落を表示結果で再現するテストを先に追加して失敗を確認する。たまころがし迷路はゴールへの案内、卓球は5点、ナンプレは難易度で4×4/6×6、じんとりは75%、ビーチバレーは7点を正確に伝える。実ゲームの条件を変更しない。
3. 初回とゲーム本体の説明を両方修正する。ナンプレは両サイズを説明してもよいが、固定4だけにはしない。
4. 「みプレイ」を「まだあそんでない」へ、残り時間・得点表記を読みやすく揃える。説明の空白を除き、効果は読める区切りを使う。
5. 対象テストと全テストを実行し、ゲームID・ルールを変えていないことを自己レビューする。

## Task 2: 全成長名と図鑑説明を整える

Files: `character-world-master.v1.js` の表示名、`script.js` の `SPECIES`・`SPECIES_STAGE_DESCS` および該当テスト。

1. 全31系統×8段階の現行名と説明を読み、マスターの専門分類を短い表示名へ言い換える。隣接段階の違いとイラストの内容を維持する。原基→小さなキノコの芽、蛹→さなぎ、孵化仔→うまれたてのかめ等。
2. 技術的なカタカナ（プラヌラなど）も意味から簡単にする。世界樹などの自然な固有名・詩的な名前は残してよい。
3. 長いひらがなの図鑑文を漢字と句読点で読みやすくする。旧セーブ用種族の説明も確認し、同じ表示の表記を揃える。
4. ラベル変更を使う成長通知・図鑑・プロフィールの表示を確認する。比較に使われる文言やテストを調べ、互換性を維持して必要な期待値だけ更新する。
5. 関連テストを実行し、段階数・ID・数値・画像参照が保持されていることを確認する。

## Task 3: 会話・ムービー・イベント・全UIを整える

Files: `script.js` のTask 1/2以外の全表示文言、`index.html`、`care-status.js`、`world-environment.js`、CSSの `content`、その他実行JSの表示文字列、`docs/TEXT_STYLE.md`、必要な既存テスト。

1. 会話20イベント、仲間・恋人固有反応、地域、デート、記念日、伝説、5ゴール、作者、人生カード、思い出、ムービー全経路、通信150問、実績87、所持品、設定・保存・復旧・削除・読み上げラベルを読む。
2. 長いかな説明や不自然な漢字混在・難語を自然に直す。キャラの口調・方言・ロボットの話し方・恋愛と大切に思う気持ちの区別を保つ。
3. デート案内先を実際の「データ」のこいびと欄へ直す。アイテム／デザインを画面間で統一する。数値の「きげん」を「ごきげん」へ。実績、世界効果、ゲーム一覧、保存画面等の日本語空白と数値効果のつながりを修正する。
4. 状態・通信エラーの原因や保存確認の意味を弱めずに読みやすくする。CSSやaria-label等も対象とする。
5. 文章ルールを文書化し、全テストを実行する。ムービー・イベントは実際の生成結果と既存の経路テストを確認する。

## Task 4: 全体再点検・レビュー・PR

1. JS文字列/テンプレート、HTML本文/属性、CSS contentを再抽出。全残存候補を読み、追加修正が必要なら該当タスクへ戻す。
2. テスト・構文検査・差分検査、保存互換と既存素材の保持を確認する。可能ならブラウザーで狭い画面・ムービー・ゲーム説明を確認する。未実施の実機検証を実施済みと書かない。
3. 各タスクレビューと全体レビューの指摘を処理し、QA・引継ぎに対象範囲・変更数・検証・制約を記録する。
4. mainとopen PRを再確認し、必要なら最新変更を取り込む。隔離ブランチのPRを作成し、正確なHEADのCIを確認する。
