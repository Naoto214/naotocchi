# 天候・周囲の小物への既存素材展開

基準main `37ee430060626dee74a16ed33619bde208f8b62a`（#226統合済み）。
ユーザーの継続依頼に従い、先に公開と未完了の画面確認を再試行した。
Runtime #298・Pages #224成功、配信5ファイル一致。公式ブラウザーはタブ一覧20秒タイムアウト。

1. 既存36種atlasから雲・雪・月・太陽・花・クローバー・リボン・マフラーを、
   同じ意味の天候／周囲の小物へ再利用する。地域や季節の選定、保存中の絵文字は変えない。
2. 雲・雪・月は既存の動きの外枠の中へ入れる。雨粒・太陽光・星のCSS描画は保持。
   個数・サイズ・速度・乱数呼出回数・通知領域・キャラ配置を維持する。
3. 冬の季節選択／世界情報にも同じ雪を使う。未制作の季節素材は既存記号を保つ。
4. 動きを減らす設定で周囲の小物の揺れを止め、形と文字を残す。
   画像失敗は既存の代替表示へ接続する。
5. 実ランタイムで表示・低負荷時の個数・設定切替・保存不変を検証し、
   開発用QAに天候／季節と動きの状態を記録する。独立レビューを行う。
6. 全画像のバイト保持と最終テストを確認し、GitHubへPR・CI・引継ぎ記録を保存。

画面を取得できない制約は継続。NodeをiPhone描画・タッチ・音・FPSの証拠にはしない。
