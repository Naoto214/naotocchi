# 承認済みUI・キャスト同期の統合

> **For agentic workers:** Use `superpowers:executing-plans` to implement this plan inline.

**Goal:** 承認されたスマホ用UIを最新mainに統合し、全キャストを同じ周期で左右に揺らす。
**Base:** `1c389070e0f5b81ed248b6df8afaecd793639e42`。PR #183（画像）、#203（100ゲーム）、#205（入力・保存復旧）、#206（文章）を含む。
**Architecture:** 既存script.jsのゲーム処理を維持し、index.htmlを再配置。ui.css、cast-layout.js、world-environment.jsに表示・配置計算・外部環境取得を分離する。PNGとWORLD_MASTER、セーブの安定IDを変更しない。

## 承認内容

- ホームはごはん／あそぶ／そうじ、ねる／くすり／じゃれる、たび／きゅうあい／メニューの同寸9ボタン。きゅうあい連打、健康時のくすり消費と反応、あそぶの即ランダム開始を保持。
- お世話4ゲージと、せいちょう・おとろえ・いのち・へんしん・100さいまでを表示。なかよし度はデータ内。
- 上に名前・恋人名・獲得済みバッジ。内容に合う吹き出しを維持。恋人は左上、装備は右上で見える身体を重ねず近接。名前のハートは文字と同じ大きさ。
- 仲間26体は13体ずつ左右の弧に配置。全身表示、仲間同士4px以上の間隔、狭幅でも最大限大きく。旧セーブの追加キャラを削除しない。
- 全員を共通の親で左右に移動し、相対間隔を固定。揺れの余白を確保。reduced-motion時は静止。再描画で周期をリセットしない。
- データ／通信は上。通信のきゅうあい説明とバトル説明を保持。デートは恋人データ内。世界から旅・デートの重複を除く。
- メニューに世界・アイテム・ゲームを選ぶ・図鑑・実績・デザイン。デザインは画面を先に、40色／40柄と解放条件を保持。字体と文字サイズを選択可能に。
- 世界：じかん auto/morning/day/evening/night、きせつ auto/spring/summer/autumn/winter、てんき auto/sunny/cloudy/rain/snow。表示は「げんざい／あさ／ひる／ゆう／よる」等。時刻・季節は端末時計から。
- 旅の先頭に現在地。位置を取得して市区町村のみ（読み仮名を優先）表示。住所や座標は画面・セーブに残さない。現在の天気を取得し、失敗や拒否から再試行できる。手動設定を非同期応答で上書きしない。ゲームの地域ID・地域実績と実在の住所は別に扱う。
