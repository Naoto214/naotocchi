# なおぽよ。100面 Implementation Plan

**Goal:** 本番と独立した100面試作と絵本を本人限定で提供。
**Architecture:** 正式D物理の試作adapter、データ駆動盤面、共通描画、探索証拠、専用保存。
**Tech Stack:** browser ES modules, Canvas, Node test, Python packaging.
**Spec:** docs/superpowers/specs/2026-11-09-naopoyo-100-design.md

## Global Constraints
- 既存ファイルは無変更。mainマージ・本番公開禁止。
- 時の針 D: maxSteps=7, resetHeading=false, passGenerated=false。
- 主観難易度と面白さは自動探索で保証しない。

## Review Focus
- 不正・破損保存から復旧し、旧保存キーを変更しない。
- 強制移動のループ・接触・落下で質量や通行条件を破らない。
- 地形描画と当たり判定が一致する。
- 100面の解法が同じランタイムで実行可能。
- iPhone横画面で盤面と操作ボタンに触れられる。
