# いのちのおまもり V2 — 確定仕様（2026-09-16）

> PR #274 のアイテム再設計V2における、使い切りアイテム「いのちのおまもり」の確定仕様メモ。ゲームコードはまだ変更しない。

## 確定仕様

- 死亡が確定する瞬間に自動発動する。
- その死亡を1回無効化する。
- 発動時に **いのちを全回復** する。
- 発動時に1個消費する。
- 一生あたりの使用回数制限は設けない。在庫がある限り複数回発動しうる。
- **病気・空腹・げんき不足など、死にかけた原因そのものは治さない。**
- そのため、発動後も原因を放置すれば再び危険になる。
- 100歳到達による通常のお別れは対象外とする。

## いのちのくすりとの役割分担

- **いのちのくすり**：好きなタイミングで自分で使い、いのちだけを全回復する能動回復。
- **いのちのおまもり**：死亡確定時に自動で発動する最後の救済。

両者は「回復」と「保険」で役割を分ける。病気・空腹・げんきなどの原因状態は、どちらを使っても自動治療しない。
