# クイックモード V2 — 経済・育成分離ルール（2026-09-16）

> PR #274 のアイテム・経済再設計におけるクイックモードの最新確定仕様。ゲームコードはまだ変更しない。

## 確定仕様

- クイックモードは、通常育成とは切り離した独立の腕試しモードとして扱う。
- げんき消費は **0**。
- せいちょう・ごきげん・おとろえ・いのち・空腹・病気・恋人・なかま等、育成パラメータには一切影響しない。
- 途中終了ではコイン報酬を出さない。
- 20/20完走した場合だけ、通常ミニゲームより明確に大きい専用コイン報酬を与える。
- 完走コイン額は未決定。通常ミニゲーム報酬とアイテム価格の基準を決めた後で最終決定する。
- クイックモードの記録・自己ベスト・クイック専用実績は維持する。
- クイックを通常ミニゲームの30/70点閾値に通して育成報酬や通常コインを与える現行仕様は、V2では採用しない。

## 役割分担

- 通常ミニゲーム：育成 + 安定したコイン獲得。
- クイックモード：育成には影響せず、20/20完走時だけ大きなコイン獲得。
- うそつきしょうぶ：リスクを取ってコインが増減する。
- ラッキーコイン：運による単発のコイン獲得。
