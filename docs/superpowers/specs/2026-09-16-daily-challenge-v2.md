# 今日のチャレンジ V2（2026-09-16）

> PR #274 のアイテム再設計V2に伴う「今日のチャレンジ」見直しの確定メモ。ゲームコードはまだ変更しない。

## 確定仕様

- 今日のチャレンジは削除せず、**かなり簡略化して残す**。
- 毎日、日付から1本の指定ミニゲームを決める現在の基本構造は維持する。
- その日の指定ミニゲームを**実際に遊んで成功した時だけ**達成とする。
- 達成は1日1回。
- 達成報酬は **ラッキーコイン1枚だけ** にする。
- 現行の連続日数ボーナスは撤去する。
- 現行の追加コイン報酬は撤去する。
- 現行の「せいちょう2倍（10分）」報酬は撤去する。
- ミニゲーム省略装具による「省略成功」は、実際にゲームを遊んでいないため今日のチャレンジ達成には使えない。
- 自己ベストや高得点を要求するデイリーにはしない。指定ゲームで通常成功以上なら達成できる、軽い毎日の目的として扱う。

## ラッキーコインとの役割分担

- ラッキーコインはショップで普通に購入できる使い切りアイテムにする。
- 今日のチャレンジは、1日1枚だけラッキーコインを無料で得られる経路として残す。
- ラッキーコインの販売価格は全アイテム・収入の横断監査後に決める。

## 実装前に確認すること

- 現行の `dailyStreak` / `dailyLastDate` / 連続日数表示・ボーナスの移行や削除。
- 既存セーブの今日の達成済み状態を壊さないこと。
- 省略成功から日次達成処理へ入らないこと。
- 1日1回の二重取得防止。
