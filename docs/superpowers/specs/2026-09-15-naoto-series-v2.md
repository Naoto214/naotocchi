# ナオトシリーズ V2（2026-09-15）

この文書は次フェーズの設計であり、現在の実装完了を示さない。お楽しみ7品の廃止は独立して確定している。

## 位置づけ

「なおとのおまもり／ランタン／リング／かんむり」は、通常の装備1枠とは別の、達成バッジ兼永久パッシブとする。獲得後は左上の達成バッジ表示に対応させ、以後の人生でも常時有効。通常アイテムや使い切りアイテムと効果を重複させず、次の大目標を少し達成しやすくする役割を持たせる。

表向きの説明は数値を出しすぎず、「なんとなく心強い」程度のふわっとした文言にする。一方、内部仕様はテスト可能な形で明確に定義する。

## 取得順と役割

1. 100歳到達 → なおとのおまもり
2. 100歳＋そだち70以上 → なおとのランタン
3. 100歳＋そだち100 → なおとのリング
4. 図鑑完成 → なおとのかんむり
5. 図鑑完成＋全実績 → ♾️の世界

この順番を「生き抜く → 育てきる → 出会い尽くす → やり尽くす → ♾️」の導線として扱う。

## なおとのおまもり

表示文候補：

> 長い一生の、心細いころをそっと守ってくれる。

内部効果：

- 年齢による死亡リスクのU字型部分をやわらげる。
- 高齢期だけでなく、死亡リスクが高い幼少期も対象にする。
- 成人期など元々リスクが低い時期を過剰に無敵化しない。
- 死亡そのものを無効化しない。
- 使い切りの「いのちのおまもり（死亡1回無効＋いのち全回復）」とは役割を分ける。
- 通常のお世話不足、病気、100歳のお別れ等の基本ルールは残す。

目的：最初の100歳達成後、次の人生で再び100歳まで生き抜く安定感を少し上げる。

## なおとのランタン

表示文候補：

> 育っていく道を、少し明るく照らしてくれる。

内部効果：

- せいちょうを通常より得やすくし、そだちが上がりやすくなる永久補助。
- 「そだち70を達成した次はそだち100」という導線を助ける。
- 旧「あかり探し」専用UI、地域ボタン、10分クールダウン、あかり記録は新仕様では必須としない。新効果採用時に整理・転用・削除を監査する。
- 成長2倍など極端な加速ではなく、ゲームバランスを壊さない範囲の恒久補助とする。具体倍率は経済・育成バランス監査で確定する。

## なおとのリング

表示文候補：

> まだ知らない出会いへ、そっと導いてくれる。

内部効果：

- 未経験のメイン種族が変身候補に出やすくなる。
- 未遭遇の通常なかま、未遭遇のレアなかま、未遭遇の恋人候補が通常プレイ中に優先されやすくなる。
- 出会いやすくするだけで、図鑑を自動登録しない。
- なかま加入や恋人成立そのものは自動化しない。
- れんくん等のシークレット条件は飛ばさない。
- 使い切りのおともだちチケット、レア遭遇チケット、おみあいチケット、ずかんチケットより弱く、常時じわっと効く補助にする。
- 旧「合言葉」専用処理は新仕様と重複しないよう整理・転用・削除を監査する。

目的：そだち100達成後、図鑑完成へ向かう探索を助ける。

## なおとのかんむり

表示文候補：

> まだやり残したことへ、そっと背中を押してくれる。

内部効果：

- 図鑑完成後に残った未達成実績へ進みやすくする永久補助。
- 未達成実績に関係するイベント、条件、行動機会を可能な範囲で優先しやすくする。
- 実績そのものを自動達成しない。
- 条件を無視して隠し要素やれんくんを開放しない。
- 実績の意味を壊すほど強制的に発生させず、ヒント・発生率・候補優先などで支援する。
- 旧「お楽しみ7品の追加リアクション」は7品の廃止とともに削除する。この新効果の実装を待って維持しない。

目的：図鑑完成後、全実績→♾️の世界へ進む最後の後押しにする。

## 共通ルール

- 4品は通常の身につける1枠を消費しない。
- 一度獲得したら以後の人生でも常時有効。
- 左上の達成バッジを「取得したなおとのアイテム」表示へ対応させる。
- 効果の重複で通常アイテムの価値を消さない。
- 表示文は具体的な倍率や内部確率を原則書かず、効果の雰囲気だけ伝える。
- 内部倍率・優先率は、通常装備・使い切り・コイン経済を横断した最終バランス監査で確定する。
