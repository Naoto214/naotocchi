# なおとっち：画面全体で暮らす世界

## 目的と監査

ユーザーの11項目の依頼を実装する。まず海を高品質な代表地域として完成させ、検証結果を基準に他地域へ広げる。
基準mainは `d2a350aa4f83fb7aac36c19accb7e8179fc4e393`（#238）。open PRは旧#92のみ。#234の文章、#235の地域監査、#236の旧キャラ移行、#237のシール・保存v5・メニュー排他、#238のiOS操作を保持する。#235/#237のコメントは0件。mainのRuntime/Pagesチェックは成功。ローカル基準262件も成功。

現行 `device > screen-frame > screen > screen-normal` は本体と液晶の色・柄を持つ。地域の飾りは本体の外周にランダム配置、天候は画面全体とキャラ領域、季節は独立した前後景に分散している。`world-environment.js` と `currentEnvironment()` が天候・時刻の正、`getEffectiveSeason()` が季節の正。深海と星空は地上の天候から分離済み。

`cast-layout.js` は全身の外接領域と左右の弧、`cast-motion.js` は会話反応と全体の跳ねを分離済み。これを使い、環境移動は一段外側の `castSway` に限定する。上下16pxの反応余白・左右6pxの揺れ・常設20pxのうんち領域を維持する。`care-status.js` は健康0など命ゲージに表れない危険も検出するので、新警告でも必ず使う。

## 構造

- `world-scene.js`: 表示専用の地域登録表、環境モデル、DOM描画。ゲーム状態を変更しない。
- 世界背景 → 奥の環境素材 → 光/空気 → 手前の環境素材。すべて非操作・読み上げ対象外。
- キャラ・会話・HUDは実際の既存DOMを使う。画面/本体のIDは互換アンカーとして保持し、枠・背景・大きな塗り・疑似要素をホームでは廃止する。
- `world-scene.css`: 全画面景色、すりガラスのHUD、下部操作、表示専用の環境動作。ゲームと物語の描画ロジックは変更しない。
- 時間/季節/天候/地域が同じ間は環境DOMを再生成しない。非表示・メニュー・ゲーム・物語では環境動作を停止する。reduced-motionでは静止、軽量段階で粒子とぼかしを削減する。

## 見た目と環境の整合性

海は水面・遠い岩礁・砂地・海藻/サンゴを別の奥行きで示す。背景はオリジナルの絵を使用。海中の雨/雪は水面の光量低下と寒色の水で表現し、地上の降水粒子を出さない。朝昼夕夜は水面の光、季節は水色/海藻/水の透明感。深海はさらに暗い生物発光、星空は恒常的な夜。

地上では地域の気候に合う表現を登録表で選ぶ。水辺は岸と水面を分ける。森は葉の季節差、雪国は残雪、ジャングル・砂漠は雪を描かない。保存された天気の選択とゲーム効果は変えず、その場所での見え方だけ解釈する。

## UI・保存互換

名前・場所・環境は上部、キャラは中央、9つの既存メーターと9ボタンは下部。通常のiPhoneでは全体を収める。狭い/低い画面・文字拡大では切り捨てずスクロールを許容。操作は最低44px、主なラベル14px。色以外に数値・ラベル・ゲージ・警告を保持。

旧がめん色/柄はメーターの面、旧ほんたい色/柄はボタンの面へ弱く反映する。選択・解禁条件・保存IDは保持。世界の時刻や天気に勝手に置き換えない。デザイン画面の名称を表示面の用途へ更新する。

命は通常→軽い注意→警告→危険。既存care判定を優先し、健康低下や命ゲージの中間段階を補う。危険時は可愛いお世話マーク、明確な文、穏やかな輪の脈動、推奨操作。無敵・卵・死亡後に偽の死亡警告を出さない。恋人のなかよし度も名前付近で読めるようにする。
