# ふしぎなたまご V2 — 確定仕様（2026-09-16）

> PR #274 のアイテム再設計V2で確定した、使い切りアイテム「ふしぎなたまご」の仕様メモ。ゲームコードはまだ変更しない。

## 確定仕様

- ふしぎなたまごは使い切りアイテム。
- **未経験の通常種族が残っているときだけ使用できる。**
- 使用すると、**次の人生の種族を、未経験の通常種族の中からランダムで1種に予約する。**
- 使用したその場で現在のキャラクターの種族が変わるわけではない。
- 未経験の通常種族が残っていない場合は使用できない。
- レア種族は対象外。レア種族は別アイテム「レアなたまご」で扱う。
- 価格・入手頻度は、全アイテムと収入の横断監査後に決定する。
