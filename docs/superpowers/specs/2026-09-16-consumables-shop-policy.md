# 使い切りアイテム V2 — ショップ販売方針（2026-09-16）

> PR #274 の使い切りアイテム再設計における販売方針。ゲームコードはまだ変更しない。

## 確定方針

- 現時点の使い切りアイテム13種は **すべてショップで通常購入できる**。
- 「特別入手専用」「非売品」の使い切りアイテムは作らない。
- ラッキーコインもショップで通常購入できる。
- 今日のチャレンジ等で無料入手できるアイテムがあっても、ショップ購入不可にはしない。
- 入手経路の希少性ではなく、**価格と効果の強さ・用途の違い**で価値を分ける。
- 購入回数制限や日次購入上限は、現時点では追加しない。
- 各商品の具体的な価格は、全アイテム・収入・ミニゲーム報酬・スターバッジ・ラッキーコイン期待値を横断して後で決める。
