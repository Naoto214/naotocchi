## 確定ルール

以下の4商品は、旧アイテムのイラストを名称だけ変えて流用しない。
それぞれ専用の新イラストを用意する。

- おべんとうばこ
- おもちゃばこ
- きゅうきゅうばこ
- ゲームパス

## 旧アイテムとの対応

| V2商品 | 旧ID/旧表示 | 旧絵の扱い |
|---|---|---|
| おべんとうばこ | `bowtie` / ちょうネクタイ | 流用しない |
| おもちゃばこ | `ribbon` / リボン | 流用しない |
| きゅうきゅうばこ | `scarf` / マフラー | 流用しない |
| ゲームパス | 新規商品。旧 `glasses` / サングラスは廃止返金 | サングラス絵を流用しない |

## 理由

V2では商品名と役割が明確な生活用品へ整理されているため、旧アクセサリーの絵を残すと、ショップで見たときに名前・役割・見た目が食い違う。

特に、おべんとうばこ・おもちゃばこ・きゅうきゅうばこは、見ただけで何の自動ケアか分かることを優先する。ゲームパスも、旧サングラスの能力とは別物なので新しい視覚表現にする。

## 実装時の条件

- 新4商品のショップ表示と装備表示は、それぞれ専用イラストへ差し替える。
- 旧 `bowtie` / `ribbon` / `scarf` の内部IDを保存互換のため維持しても、見た目は新商品名に対応した絵を使う。
- 旧 `glasses` はV2ショップに残さず、ゲームパスには別の新規表示キー／アセットを与える。
- 旧イラストは他用途まで自動削除しない。参照がなくなったことを確認してから整理する。
- 新イラスト追加時はショップ、ホーム装備表示、代替表示、テストの参照を揃える。
