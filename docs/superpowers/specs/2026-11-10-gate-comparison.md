# 数値条件付き通路の比較
本人の追加依頼に従い、旧正式アーチ A と図鑑V2角形案 B を原描画の直接呼出しで比較する。PR #535 V2本体は既にAへ復元されているため、その事実を画面で明記する。
通常／条件一致／不一致、36/48 CSS px、同一の実在8×8盤面を用意。条件は =2, ≥4, ≤3, =8。旧Aの数字のみ表記を初期値とし、記号付き表示は比較用の明示的な表示拡張とする。判定は正式matchesConditionを再利用し、移動やステージを変更しない。
選択は専用localStorageに版・日時・履歴付きで記録し、JSONの保存と読込で端末移行できる。未選択は未選択のまま、実効素材はA。選択は採用判断の記録のみで、自動適用しない。保存不可は明示する。
