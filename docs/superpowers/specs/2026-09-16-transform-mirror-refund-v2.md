# へんしんのこかがみ 返金移行確定（2026-09-16）

> PR #274 / アイテム再設計V2の使い切り旧在庫移行に関する確定事項。
> 設計の保存のみ。ゲームコードはまだ変更しない。PR #274はDraftのまま、mainへはマージしない。

## 確定ルール

- 旧 `new_transform_mirror`「へんしんのこかがみ」は、新V2の「へんしんチケット」へ1:1変換しない。
- 旧在庫は **1個につき80コイン** を一度だけ返金する。
- 返金後、旧「へんしんのこかがみ」は通常商品として表示・販売・使用しない。
- 新「へんしんチケット」は6,000コインの新商品として通常購入する。

## 理由

旧「へんしんのこかがみ」は、変身候補が出たときに候補1つだけを引き直す80コインの商品だった。一方、新「へんしんチケット」は、通常変身条件を守った上で3候補を提示し、その中から好きな1体を選べる6,000コインの商品で、効果と価値が大きく異なる。

そのため旧在庫を新「へんしんチケット」へ無料変換せず、旧購入価格相当を返金する。

## 実装時の安全条件

- 旧在庫数を安全な整数として検証し、`在庫数 × 80` コインを一度だけ返金する。
- 旧予約・候補引き直し途中状態が残っている場合も、新「へんしんチケット」の予約・在庫へ変換しない。
- 再読込、次人生、無限モード復帰で二重返金しない。
- 返金済みフラグを持ち、旧IDを互換読み込みで認識してもV2ショップには再表示しない。
