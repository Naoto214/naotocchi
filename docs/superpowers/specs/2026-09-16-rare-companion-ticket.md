# レアなかまチケット — 決定メモ（2026-09-16）

> PR #274 の使い切りアイテムV2設計における確定事項。ゲームコードはまだ変更しない。

## 確定仕様

- 表示名は **「レアなかまチケット」**。
- 対象はレアなかま。
- **未遭遇のレアなかま**だけでなく、**一度遭遇済みでも、まだ加入していないレアなかま**も対象に含める。
- 対象候補から好きな1人を指定して呼べる。
- 呼んだだけでは加入しない。
- 通常の加入条件・加入ゲームはそのまま必要。
- すでに加入済みのレアなかまは対象外。
- 通常なかまは「おともだちチケット」が担当するため、このチケットでは対象外。
- 価格は全アイテム・収入の横断監査後に決める。

## 位置づけ

- 「おともだちチケット」＝未加入の通常なかまを呼ぶ。
- 「レアなかまチケット」＝未加入のレアなかまを呼ぶ。

どちらも「呼ぶ＝加入」ではなく、出会いの機会だけを作り、加入そのものは通常ルールで成立させる。
