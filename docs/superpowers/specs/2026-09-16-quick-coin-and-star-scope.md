# クイック完走報酬とスターバッジ適用範囲（2026-09-16）

> PR #274 のアイテム再設計V2における確定事項。ゲームコードはまだ変更しない。

## 確定仕様

- クイックモードは 20/20 完走した場合のみ **100コイン** を獲得する。
- 途中終了は **0コイン**。
- クイックモードは育成パラメータに影響しない。
  - げんき消費 0
  - せいちょう変化 0
  - ごきげん変化 0
  - おとろえ変化 0
  - いのち・空腹・病気・関係値などにも影響しない
- 記録・実績は従来どおり残す。

## スターバッジ

- スターバッジは **通常ミニゲームのコイン報酬だけ** に適用する。
- 通常ミニゲームの確定報酬は以下。
  - 通常成功: 30コイン
  - 大成功: 60コイン
  - 失敗: 0コイン
- スターバッジ装備中は通常ミニゲーム報酬を **3倍** にする。
  - 通常成功: 90コイン
  - 大成功: 180コイン
  - 失敗: 0コイン
- クイック完走100コインにはスターバッジ倍率を掛けない。
- うそつきしょうぶ、ラッキーコインにもスターバッジ倍率を掛けない。

## 位置づけ

- 通常ミニゲーム = 育成しながら安定してコインを稼ぐ。
- スターバッジ = 通常ミニゲームの金策を強化する。
- クイック = 育成に触れない腕試し。20/20完走時だけ固定100コイン。
- うそつきしょうぶ = リスクありのコイン増減。
- ラッキーコイン = 運による一発狙い。
