# ゲームパス — なかま勧誘判定の扱い（2026-09-16）

PR #274 / アイテム再設計V2の追加確定事項。

## 確定

ゲームパスで「あそぶ」を押し、実際のミニゲームを遊ばず通常成功扱いにした場合、**そのミニゲーム固有のなかま勧誘判定は発生させない。**

理由:
- ゲームパスは実プレイを省略して通常成功相当の通常結果を得る装具であり、実際に遊んだことを前提とする出会い・加入判定は発生させない。
- 既に確定している「点数条件の加入」「今日のチャレンジ」「実プレイ回数系実績」「自己ベスト・高得点実績」「大成功・レア報酬」等と同じく、実プレイ依存の判定から除外する。

## 既存の確定事項との関係

ゲームパス使用時は:
- 通常成功のコイン・せいちょう・ごきげん等は受け取る。
- 通常ミニゲームと同じげんき消費は発生する。
- 使用後5秒だけ「あそぶ」を再使用できない。
- なかま勧誘判定は発生しない。
