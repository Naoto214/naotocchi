# 通常装具 V2 — 旧データ移行確定（2026-09-16）

> ゲームコードはまだ変更しない。PR #274はDraftのまま、mainへはマージしない。
> 現在のアイテム正本 `2026-09-16-items-v2-decision-log.md` と併せて実装時の根拠とする。

## 基本原則

- 新V2でも役割が継続する装具は、既存所有をそのまま引き継ぐ。
- 名称が変わっても役割が同じものは、既存内部IDを活かして所有継続してよい。
- 新価格が旧価格より高くなっても、既存所有者へ差額の追加徴収はしない。
- 廃止される装具、または新商品と意味が大きく異なる旧装具は、新しい高額商品へ無料変換せず、旧販売価格を1回だけ返金する。
- 返金は保存データの再読込、次人生、無限モード復帰で二重実行しない。

### サングラスの扱い

- 旧サングラスは「ゲーム判定+10」で、新V2のゲームパスとは意味が大きく異なる。
- そのため `glasses` 所有を8,000コインのゲームパス所有へ自動変換しない。
- 旧所有者には360コインを一度だけ返金する。
- ゲームパスはV2の新商品として通常購入する。

## 新規商品

- ゲームパス（8,000コイン）は旧装具からの所有引き継ぎなし。

## 実装時の安全条件

- 移行済みフラグを持ち、返金は1回だけ行う。
- `ownedShopItems` と `equippedItemId` の双方を確認する。返金対象を装備中だった場合は、安全に装備解除する。
- 旧IDを保存互換の読み込みに必要な範囲で認識しても、V2ショップへ再表示・再販売しない。
- 所有継続9種は購入実績・所有実績を失わせない。
- 返金対象5種を、V2の「装具全部」達成条件に残さない。
- 移行のテストでは、通常ロード、再ロード、新人生、無限モード復帰の全てで二重返金が起きないことを確認する。
