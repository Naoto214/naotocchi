# 旧「ゆめ」在庫 → V2たまご 移行確定（2026-09-16）

> PR #274 / アイテム再設計V2の使い切り旧在庫移行に関する確定事項。
> 設計の保存のみ。ゲームコードはまだ変更しない。PR #274はDraftのまま、mainへはマージしない。

## 確定ルール

- 旧 `dreamEggs.normal`「たまごのゆめ」は、新V2の「ふしぎなたまご」へ **1個につき1個** で引き継ぐ。
- 旧 `dreamEggs.rare`「でんせつのゆめ」は、新V2の「レアなたまご」へ **1個につき1個** で引き継ぐ。
- 新価格との差額の追加徴収はしない。
- 旧在庫数を減らして新在庫へ同数移し、二重に残さない。

## すでに予約済みの次の種族

- 旧仕様で `nextEggLine` / `nextEggKind` に「次はこの種族」と予約済みの場合、その予約だけは孵化までそのまま尊重する。
- 予約済みの旧指定を、移行時に未経験ランダムへ勝手に置き換えない。
- 旧予約が正常に孵化した時点で、その旧予約分の在庫消費を1回だけ完了させる。
- 旧予約がない在庫、および移行後に新しく使う在庫からV2仕様へ切り替える。

## V2で新しく使う時の仕様

### ふしぎなたまご

- 未経験の通常種族が残っている時だけ使える。
- 次の人生の種族を、未経験通常種族の中からランダムで1種予約する。
- 現在のキャラクターはその場では変化しない。

### レアなたまご

- 未経験のレア種族が残っている時だけ使える。
- 次の人生の種族を、未経験レア種族の中からランダムで1種予約する。
- れんくんは対象外。

## 実装時の安全条件

- 通常在庫・レア在庫をそれぞれ整数として検証してから移行する。
- 再読込、次人生、無限モード復帰で1:1変換を二重実行しない。
- 旧予約と新V2予約を同時に二重保持しない。
- 旧予約の対象種族が現在も合法なら尊重し、壊れた古い予約から不正な種族を生成しない。
- 旧「ゆめ」の表示・選択UIはV2移行後に通常導線から撤去する。
