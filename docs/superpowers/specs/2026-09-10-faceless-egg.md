# 顔のない卵 — 承認仕様

ユーザー依頼：専用の卵をデザイン・実装する。「卵は顔ない方がいいですよね」。この会話で提案した「あたためる→ひび割れ→孵化」を続行する。実画面で確認できない項目は実装後の確認へ残す。

- クリーム色の殻、青銀色の控えめな模様、顔・手足なし。孵化して初めて子の顔が見える。
- 通常、小さなひび、孵化直前の3枚。1枚ずつ生成し、新規素材だけを128×128 RGBA、二値alpha、最大63不透明色、最低8px余白・接地点y=119へ整える。
- 既存の `growth` と `HATCH_GROWTH=20` を使用。1回4、通常5回のあたためで孵化。40%から小さなひび、80%から大きなひび。
- あたため時は殻を短く揺らす。孵化時は殻が開き、決定済みの乳児が現れる。表示演出の完了を保存・操作の条件にしない。
- 31種族／248形態、次の卵の指定、安定ID、旧セーブ、旧キャラクター、承認済み301画像を保持する。卵は248形態に含めない。
- 演出は保存しない。再読込で孵化や報酬を再実行しない。動きを減らす設定では即時表示。画像エラーは既存の絵文字表示を利用する。
