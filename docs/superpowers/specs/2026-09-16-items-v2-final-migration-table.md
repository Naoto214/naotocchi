## 1. 共通原則

- V2でも役割が継続する通常装具は、既存所有をそのまま引き継ぐ。
- 名称が変わっても役割が同じ装具は、既存内部IDを活かして所有継続してよい。
- 新価格が旧価格より高くなっても、既存所有者へ差額の追加徴収はしない。
- 廃止される商品、または新商品と意味・価値が大きく異なる旧商品は、新しい高額商品へ無料変換しない。
- 返金は旧販売価格を基準に、現存する所有・在庫について1回だけ行う。
- 移行返金は通常のコイン発生源ではなく、旧商品廃止に伴う補償として扱う。
- 再読込、次人生、無限モード復帰で二重変換・二重返金しない。

## 6. 旧「ゆめ」在庫 → V2たまご

- 旧 `dreamEggs.normal`「たまごのゆめ」→ 新「ふしぎなたまご」へ1:1。
- 旧 `dreamEggs.rare`「でんせつのゆめ」→ 新「レアなたまご」へ1:1。
- 新価格との差額徴収なし。
- 旧在庫と新在庫を二重に残さない。

### 予約済み種族の扱い

- 旧仕様で `nextEggLine` / `nextEggKind` に種族を予約済みなら、その予約だけは孵化まで尊重する。
- 移行時に未経験ランダムへ勝手に置き換えない。
- 旧予約が正常に孵化した時点で、その予約分の在庫消費を1回だけ完了する。
- 予約がない在庫、および移行後に新しく使う在庫からV2仕様へ切り替える。

### V2での新規使用

- ふしぎなたまご: 未経験通常種族の中から次人生をランダム予約。
- レアなたまご: 未経験レア種族の中から次人生をランダム予約。れんくん対象外。

## 9. 実装時の安全条件

- 通常装具移行、使い切り移行、ゆめ移行をそれぞれ移行済みフラグで一度だけ実行する。
- 返金対象通常装具を装備中だった場合は、安全に装備解除する。
- 旧IDは保存互換に必要な範囲で認識しても、V2ショップ・ふくろへ再表示しない。
- 所有継続9種は購入履歴・所有実績を失わせない。
- 返金対象5種をV2「装具全部」達成条件へ残さない。
- 予約中の旧使い切り効果を、新V2効果として誤発動させない。
- 旧在庫数は安全な整数として検証してから変換・返金する。
- 通常ロード、再ロード、新人生、無限モード復帰で二重移行しないことを自動テストする。
