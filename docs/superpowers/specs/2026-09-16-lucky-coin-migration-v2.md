# ラッキーコイン V2 — 旧在庫移行確定（2026-09-16）

> PR #274 / アイテム再設計V2の使い切り旧在庫移行に関する確定事項。
> 設計の保存のみ。ゲームコードはまだ変更しない。PR #274はDraftのまま、mainへはマージしない。

## 確定ルール

- 旧 `c_coin2`「ラッキーコイン」は、新V2の「ラッキーコイン」へ **1個につき1個** で在庫を引き継ぐ。
- 旧仕様の「次のミニゲーム大成功でもらうコインを2倍」に発動予約されている分がある場合、その予約は解除する。
- 予約解除した分は失わせず、**ラッキーコイン1個として在庫へ戻す**。
- 新V2の販売価格300コインとの差額徴収はしない。
- 旧仕様の2倍効果そのものはV2へ持ち越さない。

## 新V2での役割

新ラッキーコインは、使用するとその場でルーレットを回し、止まった額のコインを即時に受け取る。

当選額・確率は正本どおり以下を使用する。

- 10コイン: 15%
- 20コイン: 20%
- 50コイン: 25%
- 100コイン: 20%
- 500コイン: 12%
- 1,000コイン: 7%
- 10,000コイン: 1%

0コインは出さない。

## 実装時の安全条件

- 旧在庫数を検証し、その個数を新ラッキーコイン在庫へ引き継ぐ。
- 旧 `doubleCoins` 等の発動待ち状態を解除する際、予約済み1個を在庫へ1個だけ戻す。
- 在庫と予約中状態を二重に数えて増殖させない。
- 再読込、次人生、無限モード復帰で二重変換・二重返却しない。
- V2移行後は旧「次の大成功2倍」効果を発動させない。
- 今日のチャレンジで受け取るラッキーコインと、旧在庫から移行したラッキーコインは同じ在庫として扱う。
