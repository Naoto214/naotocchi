# ラッキーコイン V2 — ルーレット方針（2026-09-16）

> PR #274 のアイテム再設計V2で、ラッキーコインの仕様を会話しながら詰めるための小さな決定メモ。ゲームコードはまだ変更しない。

## 現時点で確定・優先する方向

- ラッキーコインは、使用するとその場でルーレットを回し、止まった額のコインを即時獲得する使い切りアイテムとする。
- スターバッジの「ゲームを遊んで安定して稼ぐ」と差別化し、ラッキーコインは「単発で大きな当たりを狙える」役割にする。
- ルーレットには **10,000コインの超大当たり** を含める方向で進める。ユーザーが「10000コインとかも入れたい」と希望。
- 10,000コインは日常的に出る額ではなく、非常に低確率のジャックポットとして扱う。
- **0コインのハズレは入れない。使用すれば必ず1以上のコインを獲得する。** 「ラッキーコイン」なのに何も得られない結果は作らない。
- 具体的な当選額の段階、各確率、期待値は未確定。
- 以前の「次の大成功のコイン2倍」という旧ラッキーコイン効果へは戻さない。

## 比較用の未確定案

候補例：10 / 20 / 50 / 100 / 500 / 1,000 / 10,000 コイン。

10,000コインを0.1%程度に置く案は比較候補。これは未承認であり、経済全体（通常装具、使い切り、シール商品、日次収入、ミニゲーム基本報酬、スターバッジ10倍）と合わせて最終決定する。
