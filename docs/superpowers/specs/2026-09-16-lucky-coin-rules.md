# ラッキーコイン V2 — ルーレット方針（2026-09-16）

> PR #274 のアイテム再設計V2で、ラッキーコインの仕様を会話しながら詰めるための小さな決定メモ。ゲームコードはまだ変更しない。

## 現時点で確定した仕様

- ラッキーコインは、使用するとその場でルーレットを回し、止まった額のコインを即時獲得する使い切りアイテムとする。
- スターバッジの「ゲームを遊んで安定して稼ぐ」と差別化し、ラッキーコインは「単発で大きな当たりを狙える」役割にする。
- ルーレットの当選額は **10 / 20 / 50 / 100 / 500 / 1,000 / 10,000コイン** の7段階で確定。
- **0コインのハズレは入れない。使用すれば必ずコインを獲得する。**
- **10,000コインは超大当たり** とし、当選確率は **1%** で確定。
- 残りの当選確率も、ユーザーの「価格は後から変えられるからもっと楽しみを増やしたい」という方針に合わせ、期待値を抑えるよりルーレットの楽しさを優先して確定する。
- 最終確率は **10コイン15% / 20コイン20% / 50コイン25% / 100コイン20% / 500コイン12% / 1,000コイン7% / 10,000コイン1%**。
- 500コイン以上は20%、1,000コイン以上は8%、10,000コインは1%。小当たりだけに偏らず、ときどき大きく当たる体験を狙う。
- 毎日1枚使う場合、10,000コインは平均すると100枚に1回、約3.3か月に1回の頻度になる。ただし実際の当選間隔はランダムで、3.3か月ごとに必ず当たる意味ではない。
- 1枚あたりの期待値は **268コイン**。
- 以前の「次の大成功のコイン2倍」という旧ラッキーコイン効果へは戻さない。
- 価格や入手頻度は、この期待値だけで固定せず、通常装具・使い切り・シール商品・日次収入・ミニゲーム基本報酬・スターバッジ10倍を含む経済全体で後から調整する。
