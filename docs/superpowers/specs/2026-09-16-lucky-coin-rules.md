# ラッキーコイン V2 — ルーレット方針（2026-09-16）

> PR #274 のアイテム再設計V2で、ラッキーコインの仕様を会話しながら詰めるための小さな決定メモ。ゲームコードはまだ変更しない。

## 確定した仕様

- ラッキーコインは、使用するとその場でルーレットを回し、止まった額のコインを即時獲得する使い切りアイテムとする。
- スターバッジの「ゲームを遊んで安定して稼ぐ」と差別化し、ラッキーコインは「単発で大きな当たりを狙える」役割にする。
- **ショップで普通に購入できる使い切りアイテムにする。** 「今日のチャレンジ」限定入手にはしない。
- 今日のチャレンジを実際に遊んで成功した場合は、1日1回だけラッキーコイン1枚を無料で受け取れる。
- ルーレットの当選額は **10 / 20 / 50 / 100 / 500 / 1,000 / 10,000コイン** の7段階。
- **0コインのハズレは入れない。使用すれば必ずコインを獲得する。**
- 最終確率は **10コイン15% / 20コイン20% / 50コイン25% / 100コイン20% / 500コイン12% / 1,000コイン7% / 10,000コイン1%**。
- 500コイン以上は20%、1,000コイン以上は8%、10,000コインは1%。
- 1枚あたりの期待値は **268コイン**。
- 毎日1枚使う場合、10,000コインは平均すると100枚に1回、約3.3か月に1回。ただし実際の当選間隔はランダム。
- 以前の「次の大成功のコイン2倍」という旧ラッキーコイン効果へは戻さない。
- **販売価格は未確定。** 全アイテム・収入・購入ペースを横断監査した最後に決める。期待値268コインだけで機械的に価格を決めない。

## 今日のチャレンジとの関係

- 今日のチャレンジは、日付ごとに指定された1本のミニゲームを実際に遊んで成功した時だけ達成。
- 達成報酬はラッキーコイン1枚だけに簡略化する。
- 旧仕様の連続日数ボーナス、追加コイン、せいちょう2倍は撤去する方向で確定。
- ミニゲーム省略装具による「省略成功」は、今日のチャレンジ達成には使えない。
