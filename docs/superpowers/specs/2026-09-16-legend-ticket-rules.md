# でんせつチケット — 確定仕様（2026-09-16）

> PR #274 のアイテム再設計V2で確定した、でんせつチケットの設計メモ。ゲームコードはまだ変更しない。

## 確定仕様

- 未体験の5伝説から好きな1つを指定する。
- 指定した伝説イベントを体験できる機会を作る。
- 伝説は図鑑登録対象ではない。
- 未体験の伝説が残っていない場合は使用不可。
- チケット使用だけで伝説を「体験済み」にせず、実際にその伝説イベントを体験した時点で通常どおり記録する。

## 位置づけ

- 図鑑救済ではなく、未体験イベントへアクセスするための使い切りアイテム。
- 価格は、通常装具・他の使い切り・なおとシリーズ・シール商品・全収入を横断して最後に決める。
