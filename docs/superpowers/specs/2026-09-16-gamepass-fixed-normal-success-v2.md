# ゲームパス V2 — 成功結果の固定ルール（2026-09-16）

PR #274 / `chatgpt/items-v2-home-strip-20260915` の通常装具V2設計判断。

## 確定

ゲームパス使用時は、大成功しやすさに関わる環境補正・幸運系効果・その他の成功率補正を参照せず、**必ず通常成功固定**とする。

- 大成功にはならない。
- 失敗にもならない。
- 通常成功としての育成結果を受け取る。
- げんき消費は通常ミニゲームの通常成功と同じく発生する。
- せいちょう、ごきげん、通常成功コイン、へんしんメーターは通常成功相当として進む。
- 実際に遊んだことが必要なものは発生させない。
  - 今日のチャレンジ
  - 実プレイ回数系実績
  - 自己ベスト／高得点実績
  - 点数条件の加入
  - なかま勧誘判定
  - 人生記録・年表等のミニゲーム実プレイ履歴
- 大成功・レア報酬は発生しない。
- 使用後5秒だけ「あそぶ」を再使用できない。

## 意図

ゲームパスの役割は「実際のミニゲーム操作を省略して、安定して通常成功相当の育成結果を受け取る」こと。結果を環境や運で揺らさず、実プレイ由来の達成・記録・出会いとは明確に分離する。

この文書は設計確定の保存であり、コード実装そのものではない。PR #274はDraftのまま維持し、mainへはマージしない。
