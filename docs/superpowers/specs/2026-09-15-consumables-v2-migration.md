# 使い切りアイテム V2 移行案（2026-09-15）

この文書は次フェーズの移行案であり、12種の実装完了を示さない。専用ごほうびの廃止、お楽しみ7品の廃止は別の確定決定として優先する。

## 共通原則

- 使い切りアイテムは全種、複数ストック可。
- 使用時に1個消費し、未使用在庫は次の人生へ持ち越す。
- 予約型は同時予約1個まで。予約解除時は未消費のまま戻す。
- この移行案の旧在庫は無言で削除しない。既に廃止済みの専用ごほうび関連の旧キーは、確定済みの破棄方針を維持する。
- 旧効果と新効果が同じ意味のものだけ1:1変換する。
- 旧効果と新効果の価値・意味が大きく違う場合は、旧購入価格で一度だけ自動返金し、旧IDは互換用に残す。
- 新しい高額・強力アイテムへ旧安価在庫を自動変換しない。

## 新しい使い切り体系

1. ラッキーコイン
   - 使用するとその場でルーレット。
   - 止まった数字ぶんのコインを即時獲得。
   - ルーレット数字・確率は経済監査で決める。

2. へんしんチケット
   - 通常変身と同じ3候補。
   - 可能な限り未経験種族だけから候補を出す。
   - 未経験が3種未満なら残りを経験済みから補完。
   - 条件を満たしていればレア種族も混ざりうる。

3. ときのチケット・まえ
   - 今の種族の1段階前の姿に5分間なる。
   - 未登録なら即図鑑登録。
   - 通常変身または年齢による段階変更が起きたら即終了。
   - 1段階目では使用不可。

4. ときのチケット・あと
   - 今の種族の1段階後の姿に5分間なる。
   - 未登録なら即図鑑登録。
   - 通常変身または年齢による段階変更が起きたら即終了。
   - 8段階目では使用不可。

5. ずかんチケット
   - 通常種族＋レア8種の全姿から、未発見を含め好きな1姿を指定。
   - その姿に5分間なる。未登録なら即図鑑登録。
   - れんくん・伝説は対象外。
   - 通常変身または年齢による段階変更が起きたら即終了。

6. おともだちチケット
   - 未遭遇・未加入の通常なかまから好きな1人を指定して呼ぶ。
   - 呼んだだけでは加入せず、通常の加入ゲーム条件を維持。
   - 対象が残っていなければ使用不可。

7. レア遭遇チケット
   - 未遭遇のレアなかま8種から好きな1人を指定して遭遇機会を作る。
   - 加入条件は通常ルールを維持。
   - 対象が残っていなければ使用不可。

8. おみあいチケット
   - 未遭遇の恋人候補のうち、相互に恋愛対象が合う相手から好きな1人を指定して呼ぶ。
   - 初遭遇地域設定は世界設定として保持するが、チケット使用時のみ現在地へ来る。
   - 出会っただけで交際せず、通常の求愛ルールを維持。
   - 対象が残っていなければ使用不可。

9. いのちのおまもり
   - 死亡確定の瞬間に自動発動。
   - その死亡を無効にし、いのちゲージを全回復。
   - 1個消費。
   - 一生あたりの使用回数制限は設けない。
   - 強力なため価格を高くし、経済上の主要コインシンクにする。

10. ふしぎなたまご
   - 未経験の通常種族が残っている時だけ使用可。
   - 次の人生の種族を、その未経験通常種族の中からランダムで1種に予約。
   - 未経験通常種族が残っていなければ使用不可。

11. レアなたまご
   - 未経験のレア種族が残っている時だけ使用可。
   - 次の人生の種族を、その未経験レア種族の中からランダムで1種に予約。
   - れんくんは対象外。
   - 未経験レア種族が残っていなければ使用不可。

12. でんせつチケット
   - 未体験の5伝説から好きな1つを指定し、その伝説イベントを体験できる機会を作る。
   - 伝説は図鑑登録対象ではない。
   - 未体験伝説が残っていなければ使用不可。

## 旧→新 移行対応

### そのまま引き継ぐ

- `c_coin2` ラッキーコイン → 新ラッキーコイン
  - 名称が同じで、非売品・日次由来の位置づけも近いため1:1で在庫維持。
  - 予約中の「次の大成功2倍」は、新仕様導入時に予約を解除して在庫1個へ戻す。

### 名称・役割を置き換えて1:1変換してよいもの

- `new_transform_mirror` へんしんのこかがみ → へんしんチケット
  - どちらも変身候補へ介入する系統なので、既存在庫を1:1変換。
  - ただし旧「候補1つ引き直し」の予約中状態は解除し、在庫へ戻してから変換。

- `new_life_patch` いのちのばんそうこう → いのちのおまもり
  - 生存救済という目的が近いため1:1変換候補。
  - ただし新効果は大幅に強いので、経済監査で新価格が旧価格160から大きく上がる場合は、既存在庫だけは1:1維持して既得権扱いとする。旧購入履歴から追加付与はしない。

- 既存の通常ゆめ在庫 → ふしぎなたまご
  - 表示名を「ゆめ」から「たまご」へ変更。
  - 旧仕様の「好きな通常種族を指定」より新仕様は「未経験通常種族からランダム」なので、予約済みの旧指定がある場合はその予約だけ尊重して孵化まで維持し、新規使用から新仕様へ切替。

- 既存のレアゆめ在庫 → レアなたまご
  - 旧予約済みのレア種族指定は孵化まで尊重。
  - 新規使用から「未経験レア種族からランダム」に切替。

### 返金して販売終了

以下は旧効果と新体系の意味が大きく異なるため、新しい強力チケットへ自動変換しない。

- `c_safety` スコアほけん → 旧価格20/個を一度だけ返金。
- `c_mgsmall` やる気のおまもり → 旧価格40/個を一度だけ返金。
- `c_mgbig` 大成功のおまもり → 旧価格120/個を一度だけ返金。
- `c_sickshield` びょうきよけのおふだ → 旧価格60/個を一度だけ返金。
- `c_growth` せいちょうドリンク → 旧価格90/個を一度だけ返金。
- `c_courtsmall` こいのおまもり → 旧価格50/個を一度だけ返金。おみあいチケットへは変換しない。
- `c_breakhalf` なかなおりのおまもり → 旧価格60/個を一度だけ返金。
- `c_breakfull` きずなのおまもり → 旧価格100/個を一度だけ返金。
- `c_travel` たびのおまもり → 新体系では独立した旅チケットを採用しないため、旧価格70/個を一度だけ返金。

### 独立システムとして残す

- `new_themed_pack` テーマシールパック
  - 使い切り12種の「育成・図鑑救済チケット体系」とは別に、シール収集システムの商品として残す。
  - シール経済の価格監査対象には含める。

### 廃止が確定した別系統

- `reward` 専用ごほうびは廃止済み。旧キーは破棄し、新在庫への変換や再付与はしない。通常のデート・旅は維持する。
- お楽しみ7品は全廃し、[専用の返金仕様](2026-09-15-fun-items-retirement.md) に従う。新使い切り12種へ変換しない。

## 移行安全性

- 返金は `consumablesV2MigrationDone` のような一度だけのフラグで二重実行を防ぐ。
- 返金前に在庫数を整数として検証する。
- 旧予約状態を解除して在庫へ戻す処理と返金処理の順序を固定する。
- 新仕様導入後も旧IDはロード時の互換マッピング用に保持する。
- セーブ再読込、人生リセット、無限モード復帰で返金・変換が二重実行されないテストを必須とする。
