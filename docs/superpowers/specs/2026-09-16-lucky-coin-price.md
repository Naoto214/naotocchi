# ラッキーコイン — 販売価格の確定（2026-09-16）

## 確定価格

- ラッキーコインのショップ販売価格は **300コイン** とする。
- ラッキーコインは使うと即ルーレットを回し、当選額を受け取る使い切りアイテム。
- 当選額と確率は既存のラッキーコイン決定メモを正本とする。

## 経済上の意味

- 1枚あたりの期待値は **268コイン**。
- 300コインで販売すると、1回あたりの期待差は **-32コイン**。
- 期待還元率は約 **89.3%**。
- そのため、ショップで何度でも購入できても、平均的には「買って回すだけでコインが増え続ける」正の期待値ループにはならない。
- 10,000コインの大当たりを狙う楽しさは残しつつ、経済全体では小さなコインシンクとして機能する。
- 今日のチャレンジで1日1枚無料入手できる方針とは両立する。
