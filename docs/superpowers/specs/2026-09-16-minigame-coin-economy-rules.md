# ミニゲーム・コイン経済 V2 — 確定メモ（2026-09-16）

> PR #274 のアイテム再設計V2で決めた、通常ミニゲーム報酬とスターバッジ倍率の最新仕様。ゲームコードはまだ変更しない。

## 通常ミニゲームのコイン報酬

- 失敗：**0コイン**
- 通常成功：**30コイン**
- 大成功：**60コイン**

ラッキーコインの販売価格300コインを基準にすると、通常成功10回または大成功5回でラッキーコイン1枚ぶんになる。

## スターバッジ

- 旧案の10倍は撤回する。
- 最新仕様では、スターバッジ装備中は通常ミニゲームのコイン報酬を **3倍** にする。
- したがって、通常成功は **90コイン**、大成功は **180コイン**。
- 失敗は0コインのまま。
- 点数・せいちょう・その他の育成パラメータは倍率対象外。
- ミニゲーム省略装具とは通常装具1枠を共有するため同時装備できない。

## 位置づけ

- 通常ミニゲーム＝育成しながら安定してコインを稼ぐ。
- スターバッジ＝通常ミニゲーム金策を強化する装具。
- クイックモード＝育成パラメータに影響せず、20/20完走時だけ大きな専用コイン報酬。
- うそつきしょうぶ＝リスク付きのコイン増減。
- ラッキーコイン＝300コインで購入できる運要素。期待値268コイン。

## 実装状態

- 今回は設計保存のみ。
- 現行コードの通常成功2コイン・大成功5〜11コイン・旧スターバッジ挙動はまだ変更していない。
