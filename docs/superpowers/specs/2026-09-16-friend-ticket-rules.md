# おともだちチケット V2 — 決定メモ（2026-09-16）

> PR #274 の使い切りアイテム再設計で、おともだちチケットの最新確定事項を記録する。既存の使い切り移行案と矛盾する場合、この文書の最新決定を優先する。ゲームコードはまだ変更しない。

## 確定仕様

- 名称は **「おともだちチケット」** とする。
- 対象は **まだ加入していない通常なかま**。
- 未遭遇の通常なかまだけでなく、**一度会ったことがあるが、まだ加入していない通常なかまも対象**に含める。
- 対象の中から好きな1人を指定して呼ぶ。
- 呼んだだけでは加入しない。
- 通常の加入ゲームや加入条件はそのまま必要とする。
- すでに加入済みのなかまは対象外。
- 対象となる通常なかまが残っていない場合は使用不可。
- レアなかまは別の「レア遭遇チケット」が担当する。
- 通常装具の「おともだちバッジ」は、現在のなかまとのきずな維持を担当する別アイテム。名称が似ていても役割は分ける。
