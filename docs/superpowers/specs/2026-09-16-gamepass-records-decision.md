# ゲームパス記録扱いの決定（2026-09-16）

PR #274 / アイテム再設計V2。

## 確定

- ゲームパス使用時は、実際にはミニゲームを遊んでいないため、「ミニゲームを1回遊んだ」ことを示す人生記録・年表・実プレイ履歴には残さない。
- これは既存の「実プレイ回数系実績に数えない」「今日のチャレンジを達成しない」「自己ベスト・高得点実績・点数条件のなかま勧誘を発生させない」という方針と同じ線引き。
- 一方で、通常成功相当の育成結果として、コイン・せいちょう・ごきげん・げんき消費・へんしんメーター進行は発生する。
- ゲームパス固有の使用記録を新設するかどうかは、今回の決定には含めない。
