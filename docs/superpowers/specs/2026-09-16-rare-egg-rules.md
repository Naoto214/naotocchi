# レアなたまご — 確定仕様（2026-09-16）

> PR #274 のアイテム再設計V2で確定した使い切りアイテム仕様。設計保存のみで、ゲームコード実装完了を示さない。

## 確定仕様

- 名前は **レアなたまご**。
- 未経験のレア種族が残っている時だけ使用できる。
- 使用すると、**次の人生の種族を未経験レア種族の中からランダムで1種に予約**する。
- その場で現在のキャラが変身する効果ではない。
- **れんくんは対象外**。
- 未経験レア種族が残っていなければ使用不可。
- 価格・販売方法は、通常装具・他の使い切り・なおとシリーズ・シール商品・収入全体の監査後に決める。
