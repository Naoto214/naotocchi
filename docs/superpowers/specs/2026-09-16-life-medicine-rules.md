# いのちのくすり — 使い切りアイテム追加決定（2026-09-16）

> PR #274 のアイテム再設計V2で追加する使い切りアイテムの決定メモ。ゲームコードはまだ変更しない。

## 確定仕様

- 使い切りアイテムに **「いのちのくすり」** を追加する。
- プレイヤーが好きなタイミングで能動的に使用できる。
- 使用すると **いのちゲージだけを全回復** する。
- 病気、空腹、げんき、その他の原因側パラメータは治さない。
- そのため、死にかけた原因を放置すると再びいのちが減りうる。
- 「いのちのおまもり」とは役割を分ける。
  - いのちのくすり = 危険になる前に自分で使う回復手段。
  - いのちのおまもり = 死亡確定時に自動発動する最後の保険。
- 12種固定にはせず、必要な役割がある場合は使い切りアイテム数を増やしてよい。本追加により候補は少なくとも13種になる。
- 名前は **「いのちのくすり」** で確定。
- 価格は全アイテム・収入の横断監査後に決める。
