# ミニゲーム省略装具 — 記録・報酬ルール（2026-09-16）

> PR #274 のアイテム再設計V2における、ミニゲーム省略装具の確定ルール。決定ログと併読する。

## 確定仕様

- 装備中に「あそぶ」を押すと、実際のミニゲームを遊ばず通常成功と同じ育成結果を受け取る。
- 通常成功ぶんの通常コイン、せいちょう、ごきげん等は受け取る。
- 省略成功のあと、5秒だけ「あそぶ」を再使用できない。これは遊びを省略した反動を表す短い待ち時間。
- 追加のげんき減少、回数制限、長いクールダウンは付けない。

## 実際にゲームを遊んだ記録には数えない

省略成功は「育成上の通常成功」であって、「実際にミニゲームをプレイした記録」ではない。したがって、以下には加算・反映しない。

- 今日のチャレンジ／日次チャレンジの達成
- ミニゲームのプレイ回数系実績
- 自己ベスト
- 高得点・スコア系実績
- 実点条件が必要ななかま加入
- 大成功
- レア報酬

今後、ゲームを実際に遊んだこと自体を条件とする実績・記録・報酬を追加する場合も、省略成功は原則として対象外とする。

## 役割の整理

- ミニゲーム省略装具：ゲームを遊ぶ手間を省き、育成上の通常成功を得る時短装具。
- スターバッジ：実際にミニゲームを遊んで通常成功・大成功を出した時のゲームコインを10倍にする金策装具。
- 両者は通常装具1枠を共有するため同時装備しない。

この文書は設計の保存のみであり、ゲームコードへの実装完了を意味しない。
