# おみあいチケット V2（2026-09-16）

> PR #274 のアイテム再設計V2における、おみあいチケットの確定メモ。ゲームコードはまだ変更しない。

## 確定仕様

- 対象は、現在交際していない恋人候補。
- 未遭遇の候補だけでなく、**一度会ったことはあるが、まだ交際していない候補も対象**に含める。
- 候補の中から、好きな1人を指定して呼べる。
- 選べるのは、現在の性別・恋愛対象の組み合わせで**相互に恋愛対象が合う相手だけ**。
- 候補が通常は別地域にいる設定でも、チケット使用時だけ現在地へ来る。
- 元の初遭遇地域などの世界設定自体は書き換えない。
- 呼んだだけでは交際成立しない。
- その後の求愛は通常ルールどおり行う。
- 対象となる未交際候補が残っていなければ使用不可。
- 使用時に1個消費する使い切りアイテムとし、未使用在庫は次の人生へ持ち越せる共通ルールに従う。

## 役割

通常プレイでは地域・遭遇運に左右される恋人候補との出会いを、1回だけ狙って作れるチケット。
交際そのものを保証するアイテムではなく、「会いたい相手に会う」ためのアイテムとして扱う。
