# ゲームパス — へんしんメーター進行（2026-09-16）

> PR #274 / `chatgpt/items-v2-home-strip-20260915`
> 通常装具V2「ゲームパス」の追加確定事項。
> 設計確定とゲームコードへの実装は別。PRはDraftのまま維持し、mainへはマージしない。

## 確定

ゲームパスで実際のミニゲームを省略して「通常成功」として処理した場合でも、**へんしんメーターは通常成功時と同じだけ進める**。

理由・位置づけ:

- ゲームパスは「実プレイ条件だけを満たさない通常成功」として扱う。
- 通常成功の育成結果である、コイン・せいちょう・ごきげん・げんき消費・へんしんメーター進行は発生する。
- 一方で、実際に遊ぶことや実スコアが必要な処理は発生させない。

## 既に確定している非発生項目

ゲームパス使用時は以下を発生させない。

- 今日のチャレンジ達成
- 実プレイ回数系実績
- 自己ベスト／ハイスコア更新
- 点数実績
- 大成功
- レア報酬
- ミニゲーム固有のなかま勧誘判定
- 点数条件のなかま加入

## 既に確定している発生項目

- 通常成功のコイン
- 通常成功のせいちょう
- 通常成功のごきげん等の通常育成結果
- 通常ミニゲームと同じげんき消費
- 通常成功時と同じへんしんメーター進行
- 使用後5秒の「あそぶ」再使用待ち

スターバッジとは同じ通常装具1枠のため同時装備できない。
