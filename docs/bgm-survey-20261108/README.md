## 1. 既存 BGM の 全調査（audio.js）

すべての BGM は `audio.js` の `TRACKS`（8曲）。WebAudio で その場で 合成し、どれも 8小節で ループ する。場面の 選び方は `currentScene()`（上から 順に 判定）:

1. **farewell**: 死亡・旅立ち（STAGE.DEAD / FAREWELL）または 一生カードの 表示中
2. ミニゲーム中（`gameActive`）: ジャンルで 選ぶ — 3D・のりもの → **race**、パズル・ボード → **puzzle**、スポーツ → **sports**、それ以外（アクション・ストラテジー・ジャンル不明）→ **game**
3. **movie**: デートを 選ぶ 画面・デートの 映画
4. **night**: ペットが 眠っている 間
5. **home**: それ以外 すべて（ホーム・めぐる・たまご・お店・図鑑・設定・旅行・対戦・誕生日や 結婚の お知らせ など）

場面は 100ms ごとに 確認し、約 0.6〜0.8秒で 切りかわる。BGM の 設定は オン/オフ だけ（`state.lifetime.soundBgm`）。最初の タップまでは 鳴らない。

| home | ハ長調 · 96（swing 0.08） | 三角波 + コーラス、ドラム軽め | 20.0秒 | 2.60 | 83% | ふだんの 画面すべて | このまま（昼「いつものにわ」として アレンジA 採用済み） |

**既存曲の 評価（音楽理論上。聴感では ない）**

- 8曲とも 旋律の 82〜100% が その場の 和音の 音で、ほぼ 分散和音 そのもの。にごらず 場面の 役目は 果たしているが、「この 曲だけの 形（動機）」は 弱い。
- 眠り・デート・パズル・お別れの 4曲は、場面の 長さと 雰囲気に 合っていて、作り直す 理由が 弱い。残す。
- **game** は もっとも 多くの 場面（34本＋クイック）で 流れる のに、1周 14秒と もっとも 短い 部類。1回の ゲームで 同じ 所が 何度も もどる。いちばん 改善の 効果が 大きい。
- **race** は 3D・のりもの 16本 すべてで 流れるが、おばけやしき・ダンジョン・迷路・マイニング・フライト・サブマリン・着陸のように「レースでは ない」 ゲームにも 152 BPM の 疾走曲が かかる。レース 4本（ハイウェイ・カーレース・グランプリ・リズムハイウェイ）には 合うので 残し、それ以外に 新曲候補を 作った。
- **sports** は 旋律が G6（約 1568Hz）まで 上がり、長く 聴くと 耳に 刺さる おそれ。作り直さず、将来の 編曲で 1オクターブ 下げる 等で 直せる 点として 記録。

## 6. 試聴ページ

- 24曲: 正式ホーム4曲（原曲の 旋律）・既存BGM 8曲・新曲 12曲。用途の タブで しぼれる。
- 音色: メロディのみ / ピアノ / 軽い伴奏（全曲 同じ 合成音・伴奏型）。既存 8曲は「ゲームの 音で」も 聴ける（`audio.js` の 鳴らし方を 曲ごとの 音色・ドラム・ワルツ・アルペジオ・スウィングまで なぞった もの。V2 の エンジンは home の 鳴らし方しか なぞって いなかった ので、`engine-bgm.js` に 広げた）。
- 連続再生（表示中の 曲を 上から 順に）、ループ、音量、前／次、再生中の 曲名と 何曲目か、譜面（ピアノロール・コード・階名）。
- **公平さ**: 既存曲は 8小節・新曲は 16小節なので、1回の 再生が どれも 45〜90秒に なる よう 周回数を 合わせた。ホーム4曲は 原曲の 旋律で、採用済みの アレンジA（生楽器サンプル）は #530 の 試聴ページで 聴ける。
- **音量**: OfflineAudioContext で 全曲 1周の RMS を 測ると、補正前の 差は メロディのみ 2.3 dB・ピアノ 2.1 dB・軽い伴奏 1.5 dB・ゲームの 音 4.4 dB。「曲間の 音量を そろえる」（初期 オン）で、各モードの 平均に そろえる 補正（−1.3〜+3.1 dB）を 再生時の 音量だけに かける。値は `loudness.js`（`tools/measure-loudness.cjs` で 再生成）。
- **iPhone Safari**: これまでの 試聴室と 同じ 対策（タップで 再生開始、`navigator.audioSession` と 無音 `<audio>` で 消音スイッチ対策、画面復帰で 再開）。iPhone 13 を 再現した Chromium で 390px 幅・横スクロールなし・タップ再生を 確認。**本物の iOS Safari では 未確認**。
- 確認: Playwright で 24曲の 再生と 既存 8曲の「ゲームの 音で」（計 32通り）が 始まり 進む こと、全曲・全モードの オフライン描画が 無音や 数値異常で ない こと、評価・メモ・タブが 再読みこみ後も 残る こと、連続再生と 次の 曲。
