## 3. 分類の 方法

- **A 確定**: 採用曲が 決まっていて 追加作曲 不要（ホーム4曲・ふたりのきねんび、および ホーム曲を そのまま 続ける 場面）
- **B 既存曲で 対応可能**: いまの 曲を 残す 候補。今回は 該当なし（game・race・farewell は 未確定なので D に 入れた）
- **C 採用済み曲の 流用で 対応可能**: 採用済みの 曲を 編曲・流用すれば 足りる（睡眠＝ほしぞらのやくそく、デート＝ふたりのきねんび）
- **D 未確定**: 既存曲と 候補を 比べて 決める。うち「曲名確認待ち」は 採用が 決まっていて、どの 曲かを 確かめれば A に なる もの
- **E 不足**: 使える 曲が なく 追加作曲が 必要（スポーツ）
- **無音**: 意図して 音楽なし（ものがたり・起動直後・BGM オフ設定）
