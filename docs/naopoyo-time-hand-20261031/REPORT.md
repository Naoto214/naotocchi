## 1–10. D「時の針」の正確な仕様

1. 最初の方向は進入ベクトル `(dx,dy)` の反対 `(-dx,-dy)`。8方向対応。
2. 最後に生成した1の位置から隣接1マスへ進む。空いていれば直進を優先。
3. 不適格な場合だけ画面座標で `(-vy,vx)` へ90度時計回り。上→右→下→左、左下→左上→右上→右下。
4. 曲がった後の方向を維持。各起点で最大4方向。4方向不可ならその場で終了。巻き戻して別の枝を探索しない。
5. 岩・仲間・本体・生成済み1・ゲート・出口・トゲへ生成しない。正式 `cornerBlocked` と `canEnter` の条件を利用。正式の角抜け条件は「直交する両経路が塞がった場合」であり、片側だけの壁を勝手に禁止しない。第1章のバージョン別物理フラグも変更しない。
6. 実際の個数は `min(元段階−1, トゲの強さ, 経路上の合法候補数)`。最大7体。3マス通路では8→5+1+1+1。
7. 生成先は重複なし。本体へ戻らない。既存の1を飛び越えない。標準では成功最大7歩×4候補、最大28判定。比較用通過案も歩数消費・既訪問状態検知・ハード上限で停止。
8. 候補は仮想占有状態で計算し、全生成完了後に正式エンジンのsettleを実行。重力、支持、親子再合体、8上限の余剰分離、異種族交換、ゲート、救出、トゲ1手1回に例外を加えない。
9. 同種族の合体に回収方向の制限はない。時計回りは生成だけの法則。
10. 960条件（15配置×8方向×平面/重力×4方式）、1,440派生条件、乱数固定障害物試験、20面再生で段階合計保存を検証。公式Sessionを独立engineへ接続した保存・復元・Undo・Retry試験も成功。本番ストレージを読み書きするページコードはない。

### 斜めに固有の重要な結果

本体D4（0始まり3,3）の障害物なし盤面で、右下進入はC3→B2→A1の3体で停止、左上進入はE5→F6→G7→H8の4体で停止する。角で戻る先が自分の生成済み1となり、残り3方向は盤面外になるため。空きマスが残っていても到達できなければ生成しない。残り6方向は同条件で7体。これは「7体必ず生成」という仕様ではない。
