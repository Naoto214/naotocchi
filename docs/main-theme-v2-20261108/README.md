## 1. お気に入り 2曲の 分析

楽譜データから 数えた 値（`songs.js` から 算出）:

| | 現行メインテーマ | ほしふるみずうみ |
|---|---|---|
| 調・拍子・テンポ | ハ長調 · 4/4 · ♩=96 | ト長調 · 3/4 · ♩=88 |
| 1周 | 8小節・20秒 | 16小節・33秒 |
| 1秒あたりの 音数 | 2.6 | 1.2 |
| 和音の 音の 割合（メロディの 音が その場の 和音に ふくまれる） | 83% | 90% |
| 音の 動き（2度 / 3度 / それより 広い） | 18 / 29 / 4 | 14 / 16 / 8 |
| 和声 | 全音階だけ（C–Am–F–G…） | maj7 中心、IV から 始まる、♭VI（E♭maj7）の 借用 |
| 旋律の 型 | 和音を 8分で のぼりおり、後半 3+3+2 の リズム | 4分音符 3つの 動機（2度 + 4度 上）を 2小節ずつ 3度 下へ 写す |

**2曲に 共通する 魅力（理論上の 見立て）**

1. **メロディが 和音に よりそう**（83〜90%）。にごりが なく、すなおで 安心感が ある。
2. **音の 動きは 2度と 3度が 中心**で、大きな 跳躍は 少ない。口ずさみやすい。
3. **形の 反復と 移し**（同じ 形を 高さを 変えて くりかえす）。現行曲は 1〜3小節、ほしふるは 1〜6小節。少ない 材料で 覚えられる。
4. **後半で 高い 音へ とどき、主音へ 帰る** 弓なりの 形（現行 C6・ほしふる D6）。ループの 継ぎ目が なめらか。
5. **長調で、テンポは 88〜96**。走らず、眠くも ならない 速さ。

**ちがい**（＝あなたが 両方を 好む 理由の 仮説）

- 現行曲は「明るさ・にぎやかさ（音数 多め・全音階）」、ほしふるは「透明感・余白（音数 少なめ・長7度・借用和音）」。
- 新曲は この 2つの あいだ（1秒 0.9〜2.2音）に 散らして 置き、どの あたりが 好みかを 聴いて 決められる ように した。

### 各曲の 設計

**新A ひだまりと かぜ** — 「ソー.ミ ド ミ｜ファ ソ ラ ドー.ラ」。現行曲は 和音を 下から のぼるが、こちらは 上から なでおろして 次の 小節で のぼり返す。9〜11小節は「ラー ソ ミ」を 1音ずつ 下げる 句（ほしふるの「写し」の 考え方を 4拍子で）。12小節 E♭m（同主短調の iv、ラ♭）で 日だまりに かげが さし、14小節 Ebmaj7 の 上で 最高音 D6 へ。

**新B ほしぞらの やくそく** — 1〜3小節は ベースが 主音 A に とどまる 保続音で、和音（Amaj7 ↔ D/A）だけが 動く。「ソー レ ミ」（4度 下りて 1歩 上がる）は ほしふるの 動機（1歩 上がって 4度 上がる）とは 向きも 拍子も 逆。10小節 C#7（ソ#、vi への 二次ドミナント）と 12小節 Dm6（ラ♭、iv の 短和音）。最後は 3度の ミで とまり、答えを 言わずに 1小節めへ 戻る。

**新C きせつの きおく** — 唯一の 短調（ホ短調）。「ミ ラ シ ドー シ ラ」の 動機を 2小節ごとに 1音 下へ 写す（季節が 1つずつ 過ぎる）。9小節から 平行長調側（Cmaj7 → D7 → Bm7）へ ひらき、「ソ ミー ソ シー」と はずむ 思い出の 句。8・15小節の B7（ソ#）で 短調へ 帰る。

**新D ちいさな ぼうけん** — 「ソソ ドー シ ド ミー」— 8分 2つで 足ぶみして 跳ぶ 動機。2小節めは 1音 上で 同じ 形。9〜11小節は「ドー.ファ ファー」を 1音ずつ 上げて 3回（4度の 跳躍で 行進）。13〜14小節で 動機が 高い 音域に 戻る。いちばん 音数が 多く、ホームより ゲームや 場面曲 向きの 可能性が ある。

**新E ゆうなぎ** — 2曲の あいだを ねらった 曲。動機「ミ ソ ド シー.ソ」は 主和音を のぼる（現行曲の 明るさ）と、長7度 C#6 に 着地する（ほしふるの 透明感）を 1小節に まとめた もの。7小節 G → Gm6（ラ → ラ♭）で 夕方の 光が かわる。9〜11小節は 2分音符で 1音ずつ 下りる 凪の 句。13小節 Gmaj7 上の C#6（#11）は ほしふるが もつ リディアの 色を 一瞬 だけ 借りた もの。14小節 F#7（ソ#、vi への 二次ドミナント）が 山場。和音の 音の 割合 95% は 7曲中 最大。

### 既存曲との 似かた（点検）

`tools/check-v2.cjs` は「音程 + 長さ」の 並びで、各新曲と 既存曲（V1 の 6曲: 現行・A〜E）・他の 新曲との 最長一致を 数える（移調しても 同じ 形なら 一致と みなす）。結果は 全曲 **最大 5音**（どこにでも ある 音階の 断片の 長さ）で、8音 以上の 一致は ない。現行曲と ほしふるの 旋律は 流用していない。

### 強拍に のる 和音外の 音（意図した もの）

- `webkitAudioContext` / `webkitOfflineAudioContext` への フォールバック、`roundRect` が ない ときの 代替描画。

## 7. 権利関係

- 新A〜E の 旋律・和声づけは、2026-11-08 に Claude（Anthropic の AI）が この リポジトリの ために 新しく 作成した もの。依頼者 Naoto214 の 指示のもとで 制作した。
- 現行メインテーマと「ほしふるみずうみ」は 特徴の 分析（音数・音の 動き・和声の 型）に だけ 使い、旋律は 流用していない（似かたの 点検結果は 2章）。
- 既存の 著作権保護楽曲の 旋律を 参照・引用・模倣していない。保続音・二次ドミナント・同主短調からの 借用（iv）・maj7 などは 一般的な 和声の 技法。
- 音源は 合成で、外部の 音素材・サンプルは 使っていない（フォントは Google Fonts を 表示に だけ 使う）。
- AI が 作った 楽曲の 著作権の 扱いは 国・地域で 異なる。商用利用や 登録の 前に、必要なら 専門家に 確認する こと。
