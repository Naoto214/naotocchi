## 画像の出典・保護

- 6種族: `assets/characters/{dog,clownfish,penguin,frog,butterfly,dandelion}/01.png` 〜 `08.png`（48枚）
- 精霊案A: `assets/characters/god/03.png`（正式名「小さな精霊」）
- ふくろう案B: `assets/characters/companions/owl.png`（正式名「ものしりふくろう」）
- 全50枚のGit blob SHA-1、SHA-256、寸法、可視領域は [source-manifest.json](source-manifest.json)。ダウンロード後にGitHubの各ディレクトリ情報のblob SHAと照合済み。
- 原本PNGを再描画・上書き・再減色しない。比較SVGには元PNGのバイトを埋め込む。
- キャラの表示時にだけalpha bounding box＋2px余白をviewBoxに利用。透明余白だけを除いてフィットさせ、耳・羽・枝・周囲の魚・散った種はすべて残す。均一な体積拡大で成長を捏造しない。
- `CHARACTER_ASSET_SPEC_V1.md` のドット絵方針を尊重し、別の丸いキャラへ描き直さない。42pxでは整数倍表示はできないため、実機でpixelatedと通常補間の最終比較を行う。

## 01〜08の表示方針

8段階の順序・正式名・画像を維持。表示枠へのフィットで乳児が小さすぎる問題を防ぐ。元画像のサイズ比をそのまま身体の大きさとして再現することより、パズル上の識別を優先する案。顔・姿勢・器官の変化と常設の2桁番号を併用する。

番号札はセル右下、幅41%・高さ26%、数字25%（42pxセルで10.5px）。キャラ本体はセルの上74%以内。門に重なる場合は段階札を右上に移す。通行中は番人とキャラが重なりうるため、採用後は進入方向に応じた短い退避などを検討するが、門や番人を隣セルへはみ出させない。

2.5D案は影と薄い透明リムを添える表示比較であり、3Dモデル化や新規原画ではない。推奨は接地影だけ。合体・分裂の案: 180〜240ms程度、最大約8%の縦横伸縮、番号札は変形させず、reduced-motionでは静止。今回は静止フレーム比較であり動作実装はしていない。

## 条件札

下部一列（A）を推奨。種族アイコン→比較記号→2桁数字の順。`=02` は02のみ、`≥02` は02以上、`≤02` は02以下。種族のみの場合は `ALL`、種族指定なしなら種族アイコンを省略。共通の06画像を種族アイコンに使い、条件段階の画像と取り違えさせない。

上部一列（B）は番人・星を圧迫。分割（C）は視線移動が増え、種族アイコンと番人を混同しやすい。これらは比較用の非推奨案。42pxでの条件数字は10.5px相当、下地を不透明にしてコントラストを確保。色だけに条件を依存させない。
