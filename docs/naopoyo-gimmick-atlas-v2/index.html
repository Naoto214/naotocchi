04 / SHARED DATA

図鑑と制作で、同じ素材を。

表示と作用を分ける

波の絵は1マス、前線は複数マス。足場は1部品、移動経路は別データ。床・壁・装飾・仕掛けをレイヤーで区別します。

灯りも2つの意味

背景の灯りは表示だけ。合図の灯りは信号を受ける入力専用装置。見た目が近くても動作が異なるため別IDにします。

見つけた記憶を守る

通常プレイで見えた時に発見。初めての面を記録し、Undoで知識を消しません。旧セーブに項目がない場合は空集合から。今回は保存処理を本編へ追加しません。
