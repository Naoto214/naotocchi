# iPhone Safari確認用メモ

iPhone実機とSafariエンジンは未確認。下記はChromeの実ブラウザを375×667・844×390・320×568のiframe表示領域で操作した結果であり、Safari合格の代わりにはしない。

|確認|結果|
|---|---|
|375×667縦|盤面314px。横はみ出しなし。戻す・やり直しを下端に固定|
|844×390横|盤面256pxを左、操作を右。スクロールで全操作へ到達|
|320×568小画面|盤面259px。横はみ出しなし|
|方向入力・分裂・Undo|方向入力で分裂、Undoで1入力前へ復元|
|解法の見本|100面目の28入力をUIで再生し全員救出。通常クリアには記録しない|
|途中保存|1面で1手→再読込→1手を復元|
|次の面|1面クリア→2面へ→再読込で2面を維持|
|評価・メモ・再確認|保存して再読込後も保持。あとでもう一度フィルターに表示|
|図鑑|遭遇済み11/29素材を表示。未遭遇素材は未発見表示|
|設計資料|ブラウザで100面と29素材の行数を確認|

## 実機で試してほしい順番

1. 「はじめの絵本」を開き、指でキャラクターを選んで隣をタップ／ドラッグ。斜め、分裂後の別個体選択も確認。
2. 縦から横へ回し、盤面が切れないか、戻す・やり直しと方向操作に触れられるか確認。Safariのアドレスバー開閉時も確認。
3. 1〜10面を順に解き、難度の逆転・説明不足を「感想」で記録。
4. 37・43・64・89面で、水流・箱・氷・風の意図が観察で理解できるか確認。89面は風を使う11手解と、使わない13手解がある。
5. 97・99・100面は最短性未確定。99から100への難しさの差、ふくろうの条件、周期表示を重点確認。
6. 再読込・タブ復帰で続きを再開し、記録JSONの書き出し／読み込みがiOSのファイル選択でも動くか確認。

全100面の目標難易度は仮配置。実際の気づき・操作負担・面白さは試遊で調整する。途中の詰みはUndo/Retryで戻せるが、すべての到達状態から解けるという保証ではない。
