# 主仕掛けの経路監査

最初の比較では、主素材を取り除いても最短手数が変わらない面が8つあった。削除により新しい道ができる場合と、元の盤面でも仕掛けを使わずに解ける場合を区別した。

実際の試作盤面を変更せず、同じエンジンで主仕掛けを使う遷移だけを除いて幅優先探索した。箱は押した手、氷・風・水流は各効果が発生した手、片開きと周期扉はそのマスに入った手、保持板は指定の板が作動した手を除外した。探索上限は12,000状態。下表の「解なし」は、上限に達する前に探索を終えた結果を示す。手数は成功した入力の数。

|現行番号|面名|監査結果|
|---:|---|---|
|17|箱の横顔|5手。元の盤面は箱を2回押してから曲がる。箱を押さないと解なし。箱を消した比較では、箱がいた上の道を通れるため同じ5手。|
|19|片方だけの横断|5手。矢印に沿う東向きの進入が必要。片開きを消すと、閉じていた斜め経路を同じ5手で通れる。|
|37|流されて出会う|改修前は下を回って5手で合体できた。枝道を絞り、1を流れの停止点の下に置いた。現行は4手。水流を起こさないと解なし。水流を消した比較では5手。|
|43|板に残る重さ|改修前は犬が板から直接扉へ斜めに入り、箱を置いたまま5手で救出できた。扉を右へ1マス移した。現行も5手で、箱を押さないと解なし。|
|64|氷の片道券|改修前も滑走は必須だったが、下の片開きの手前で合体できた。中央の抜け道を閉じ、右岸で出会うようにした。現行は9手で、氷を消した比較では11手。|
|70|針が二拍進めない|10手。周期扉を避けると解なし。扉を消した比較も10手だが、本体を先に救出できる。現行では本体と子の手順を交互に入れ替えて周期を合わせる。|
|78|先に床を消すか|7手。保持板を作動させないと解なし。板を消した比較は同じ7手だが、閉じた扉が足場になり、扉に入らず上へ進める。|
|89|小さい仲間の裏口|改修前は風を使わずに12手で留め具と出口に届いた。下段に1専用の東風を追加し、横道の一部を閉じた。現行は風をつないで11手。現行盤面で風を起こさず進む最短は13手。風を消した比較では12手。|
