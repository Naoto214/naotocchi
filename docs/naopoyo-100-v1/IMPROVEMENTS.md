# 改善候補と検証の範囲

## 確認できたこと

- 100面すべてで、試作の操作と同じランタイムに手順を入力し、全員の救出を再現した。図鑑ID交換形式へ出力し、読み戻した盤面でも同じ手順を再生した。
- 幅優先探索で最短を確定したのは 97 面。上限後に優先探索で見つけた解は 2 面、手書きの確認解は 1 面。上限を超えた面では記録した手数は上限値として扱う。
- 幅優先の上限は一面 12000 展開・90 手。優先探索は 30000 展開・120 手。状態は個体の座標・種族・段階、押された板、記憶、順序、箱、崩壊、周期の相で区別する。
- 主素材を外す比較を 75 面に実施した。素材を外すと解がないことまで確認できた面は 02、12、22、24、26、28、30、34、38、41、42、43、45、47、57、59、60、63、72、73、74、76、79、80、81、85、86、91、92、95。比較上限は 2500 展開。

## 試遊で確認する点

- 主素材を外しても最短手数が同じ面は 17、19、70、78。同手数でも経路や役は変わり得る。見かけだけで通れる場合は進入側、受け口、保持条件を見直す。
- 外すと最短手数が短くなる面は 04、21、23、44、52、53、65、67、71。向き・位相・停止点を読む負荷が意図どおりかを確認する。
- 外すと最短手数が長くなる面は 10、11、14、15、16、18、20、25、29、37、40、46、48、49、51、54、64、68、69、75、77、83、87、88、89、93。自動で運ばれる結果が想像できるかを確認する。
- 素材を外した比較が上限に達した面は 94、96、97、98、99、100。解の有無は未確定。素材除去は局所的な比較なので、同手数で解ける場合も経路と担当の変更が起こり得る。
- 盤面での初出、担当の引き継ぎ、時間の合わせ方を中心に並べた。連続する面の体感の差、先に知っておきたいルール、気持ちよく発見できるヒントの長さを本人の試遊で見直す。
- 絵本で見せるのは正式Dの基本。試作の風、水、地中の入口、連動、協力は対応する番号面の説明と図鑑で確認する。
