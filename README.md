### 年齢とそだち

年齢はゲームを開いて育成している時間で進みます。基本画面(なにも開いていないとき)では3秒ごとの更新20回で1さい、100さいで人生の締めくくりを迎えます。おせわができない画面を開いているあいだは育成時間が止まります: メニュー(ずかん・じっせき・でざいん・プロフィール・つうしん・あいてむ・せかい・たび・シール)、うそつきしょうぶ、デートのムービー、なかまのさそい、ゴールのおいわい、「めぐる」で地域を歩いているあいだ、ミニゲーム・クイックモードの最中、へんしんの すがたを選んでいるあいだ、のすべてで年齢もおなか・ごきげん・げんきも動きません(閉じればまた進みます)。ページを閉じていた時間は加算されません。

孵化後の姿は年齢で決まる8段階です。卵はこの8段階に含みません。

| --- | --- |
| 0さい | あかちゃん |
| 3さい | よちよち |
| 7さい | こども |
| 12さい | しょうねん・しょうじょ |
| 16さい | せいしゅん |
| 22さい | わかもの |
| 40さい | おとな |
| 70さい | ろうねん |

「そだち」は20から始まり、0〜100で変わる育ち具合です。お世話などでためた「せいちょう」が必要量に達すると上がり、「おとろえ」がたまると下がります。そだちの上下で年齢や姿の段階が巻き戻ることはありません。到達した最高そだちに応じて特典も開きます。

別の種族になる「へんしん」は抽選ではなく、へんしんメーターが満タンになったその場でチャンスが開きます。メーターはミニゲームを1回あそぶと+25(4回で満タン。シルクハットで早まります)。回数の上限はありません。候補を選ぶほか、今の姿で育て続けることもできます。

### カクレクマノミの成長と恋愛

カクレクマノミは⑥「卵を守るオス」、⑦「メスへ変わる途中」、⑧「群れのリーダーのメス」と育ち、⑧で性転換が完了します。[現実では群れの順位などが性転換に関係します](https://pubmed.ncbi.nlm.nih.gov/18533742/)が、ゲームでは既存の成長物語として簡略化しています。40さい・70さいという区切りはゲーム共通の時間で、実際の魚の年齢ではありません。

性転換しても好きになる相手の性別は変わりません。男の子を好きなオスは「ゲイ」から「ストレート」へ、女の子を好きなオスは「ストレート」から「レズビアン」へ表示が変わります。バイ・パン・アロ・クエスチョニングの種類と対象範囲は維持します（クエスチョニングの求愛による変化は従来どおり）。NBの個体はNBのまま、プロフィールに体の変化を添えます。

今の恋人や夫婦はその場で解消しません。双方の対象が合わなくなれば、従来の「すれちがい」と話し合って仲直りする仕組みへ進みます。対象や相手の恋愛タイプは書き換えません。性転換は年表にも残り、ゲームやムービー中のお知らせはホームへ戻ってから表示します。旧セーブですでにメスの個体をオスへ戻すことはありません。

### あそぶ

ミニゲームは100種類あります。地域・季節向けのゲームもすべて候補に入り、現在の地域や季節に合うもの、まだあまり遊んでいないものは出やすくなります。同じジャンルの連続を減らす選び方も入っています。

「あそぶ」でランダムにすぐ始まります。「メニュー」→「ゲームを選ぶ」で、遊んだゲームの記録を確認して選べます。100種類という数字は登録数であり、すべての端末で操作感・描画まで確認済みという意味ではありません。

ミニゲームの操作はスマホ向けに作り直してあります。上下左右の方向ボタンは原則なくし、ゲーム画面の下に薄い「タッチパッド」を置きました。パッドは MacBook のトラックパッドと同じ「指を置いてからの移動量」で動きます。指がパッドの端に着いたら、離して好きな場所に置き直し、また同じ方向になぞれば進み続けます(置き直しただけでは動きません)。パッドの種類はゲームごとに選んでいます: 1マスずつ動くゲーム(スネーク・2048・フロッガー・倉庫番・ローグライク・ドットイーター)は「なぞった向きが決まった瞬間に1マス(指を離すのを待たない)。短いフリックでも1マス、右→上と続けてなぞれば離さずに2回入力、同じ向きに1回のフリックで2マス進むことはない」、飛行・シューティング系(リングフライト・潜水艦・ハンググライダー・スカイシューター・いんせきガンナー)は「なぞった分だけ動く」(パッドの端に指を当てたまま押し続けると、ゆっくり加速しながら動き続け、少し戻すか離すと止まる)、押しっぱなし系(ボクセルマイニング・ボンバー・戦車・陣取り・かたむき迷路・ジャンプクエスト・かくとう)は「なぞった向きに、指を離すまで動き続ける」(向きは指を動かした分から決まり、指を止める時のぶれでは変わりません。ボクセル・ボンバー・戦車・陣取りは上下左右のどれかにそろえます)、ハンドル系(3Dレース・グランプリ・ダウンヒル・野球・テニス・ボウリング・月面着陸・着陸)は「なぞっている間だけその向き」です。3Dダンジョン・お化け屋敷は横で向きを変え、上で進みます。ブロックパズル・連鎖パズルは横になぞって移動、下で速く落とし、タップで回転。レーン系(ロード・宇宙・ハイウェイ)はパッドを左右にフリック(画面の左・中・右タップも可)。対象をタップ・スワイプするゲーム(魚釣り・アーチェリー・釣り・ゴルフ・ビリヤード・パズル各種など)は直接タッチのままです。残したボタンは アクセル・ジャンプ・スイング・うつ・ばくだん・回転・一気に落とす・パンチ/キック/ガード など、そのゲームに必要なものだけです。方向ボタンがなくなった分、ゲーム画面は縦に最大1.5〜1.9倍まで広がります(空いた高さに合わせて自動)。パッド操作中はページがスクロールしません。

難易度は「ちょっと頑張れば成功できる」を中心に合わせています(2026-09-17の総点検)。狙いを定めるゲームでは、**入力のうち成功する範囲がレンジの中央に来るように**パラメータを組み直しました。たとえばバスケ3Dは「はらう強さ＝飛ぶ距離」にして落下点の輪を出し(成功範囲 約5%→40%)、カーリングは強さを指の速さではなくスワイプの長さにして止まる位置を●で表示、ひこうき着陸は緑のガイドが加点ゾーンの中央を指し降下角も機速から逆算するので「線のとおりに飛べば正解」になりました。ロードラン系はアイテムの間隔を広げて反射ゲームから判断ゲームにし、1回ぶつかっても挽回できる配点に変えています。アーチェリーの照準とたこやきの焼き加減ゲージは、表示と実際の判定が食い違っていたのを一致させました。くわしい点検結果は `docs/qa/minigame-difficulty-audit-2026-09-17.md` にあります。

1プレイは「サクッと」を基準に、アクション系 20〜28秒、パズル系 45〜75秒、対戦ボード系は上限 60秒にそろえています(例: 3Dレース 26秒、スネーク・テニス・ボクセルマイニング 28秒、リングフライト 25秒、2048 45秒、リバーシ・どうぶつしょうぎ・四目ならべ 60秒、ソリティア・ナンプレ 90秒)。回数制のゲームも短くしました(ダーツ 6投、野球 6球、フリーキック 4本、ブラックジャック 4ハンド、ヨット 5ターン、月面着陸・着陸 2回、グランプリ 2周、カーリング 3投、ローグライク 2階、タワーディフェンス 4ウェーブ)。開始前の待ち時間は 0.6秒、終了から結果までの待ちは 0.65秒です。「みじかめ」設定は20秒以上のゲームを7割の長さにします。

そのゲームを3回遊ぶまでは、動き出す前に絵文字・名前・ジャンル・説明・そうさを1枚のカードで見せ、「▶ はじめる」で始まります(4回目からはすぐ始まります)。ゲーム中はいちばん下の「？そうさ」で、いつでも説明と指の動きのデモを見られます(ゲームは止まりません)。アクセルやジャンプなどのメインボタンは右に大きく、◀▶は左にまとめてあり、片方の指で押しながらもう片方で操作できます。カードの「そうさ」には、そのゲームの指の動き(タップ / スワイプ / ドラッグ / おしっぱなし / ◀▶ボタン)を小さなアニメで見せます。

### せかい(じかん・てんき・きせつ・ばしょ)

世界の4要素は「じかん → てんき → きせつ → ばしょ」の順で表示します。短い周期・小さな環境変化から、より長い周期・大きな世界へ広がる、という意味で、今後のカードゲームのカード裏面も同じ順序・概念に揃えます。場所を選ぶ操作は、背景世界を変える独立した「たび」のままです。

「メニュー」→「せかい」で、時間・天気・季節を自動か手動で選べます。自動の天気は、おうちでは取得できた現在地の天気、旅先では地域の気候と季節から3時間ごとに予想した天気を使います（「はれ(よそう)」など）。ジャングルや砂漠は、冬でも雪の予想にはなりません。

じかん・てんき・きせつ・ばしょにはそれぞれ固有の効果があり、「せかい」画面の「いまの せかい」カードで確認できます。たとえば はれ は きげんが下がりにくく、あめ は きげんが下がりやすく なかまとの出会いが減り、よる は ねると回復が早い、もり は なかまに出会いやすい、など（自然減・ねむりの回復・あそぶ疲れ・出会いやすさに影響します。ゲームのコイン額は変わりません）。ミニゲームの出やすさも変わり、あめ の日は パズル・ボード、はれ は スポーツ・3D、よる は パズル、うみ は スポーツ、さばく は のりもの が出やすくなります(「いまの せかい」に ↑↓ で表示)。

ホーム画面には あめ・ゆき・くも・ひざし・よるの星と月 の演出と、あさ・ゆう・よる の色合いがかかります(ゲーム中とメニュー中は消えます)。ときどき てんきや じかんにちなんだ小さな できごと(にじを見つけた、ゆきだるまを作った、ながれぼしに おねがい…)が起こり、きげん・げんきが少し動きます。てんき・じかんにまつわる じっせき も6つ増えました。

「かわ・みずうみ」の表示名は「みずべ」になりました。訪問歴や過去の思い出は引き継ぎます。山では岩を選んでタイミングよくつかむ「岩場のぼり」、雪国ではスキーやスノーボードを楽しめます。全100ゲームは、どの地域でも遊べます。

大画面の景色は場所ごとに構図を分けています。とかいは高層ビルと交差点、夜はネオン街。おうちはソファやラグのある室内で、雨や雪は部屋の中に降りません。いなかは田畑、ジャングルは大きな熱帯植物と滝、みずべは湖と桟橋です。

「たび」→「📍げんざいち」で、位置情報を許可すると市区町村に応じた街のイメージを表示します。函館市は港町、飯田市は山あい、大阪市（各区を含む）と東京都の23区は都会、それ以外は一般的なまちなかです。実在の街並みをそのまま再現するものではありません。選んだ景色は再読み込み後も残り、「せかい」から現在地を調べ直せます。「おうち」を選ぶと室内に戻ります。

雪国は睡眠で回復しやすく遊ぶ疲れも少なめ、ジャングルは仲間との出会いが多めです。それぞれ少しおなかがすきやすく、詳しい効果は旅先カードで確認できます。

深海は泡や光るくらげの世界、星空の停留所はいつも星空です。この2か所には地上の天気や暑さ・寒さの効果を当てはめません。選んだ天気と季節は、地上へ戻ると反映されます。そだち70で開く星空の停留所では星のかけらを拾うことがあり、記憶の湖では実際に記録された思い出が水面にうつります。伝説は未遭遇を優先しながら、ゆかりのある地域で少し出会いやすくなります。

### おかねのつかいみち

「あいてむ」で買った使い切りの品は、まずふくろに入ります。「つかう」で発動し、未使用の在庫は次の一生にも残ります。候補を選ぶチケットは確定したときに1個使い、取り消しや対象がいないときは減りません。次の人生のたまごは同時に1件だけ予約でき、孵化したときに1個使います。いのちのおまもりは死亡を防ぐときに自動で1個使い、通常の100歳のお別れには使いません。

### シールちょう

メニューの「シールちょう」で、これまでの絵をシールにして集め、4つのページ(おうち・たび・なかま・きねん)に貼って遊べます。シールは、ずかんに初めて載ったすがた・なかまになったとき・こいびとになったとき・通常ゲームのSランク(30%、その日のチャレンジ達成回を除く)でもらえるほか、💰30の「シールパック」(3枚)で買えます。しゅぞくのすがた(全ライン×8段階)、なかま、こいびと、身につけるあいてむ、けしき(木・山・海・天気など)があり、レアなしゅぞく・レアななかまは「レア」です。かぶったシールは「かけら」になり(ふつう1・めずらしい3・レア8)、12個で未所持優先の3候補から1枚を選べます。取り消しは無料で、全種類を持っている場合は重複になります。60コインのテーマパックは分類を選んで3枚。かぶった分はもう1枚貼れます。シールは飾りで、本編の図鑑発見や仲間加入にはなりません。「みため」の色41種・柄40種も無料の鑑賞コレクションで、からだの着せ替えではありません。

ページに貼ったシールは指で動かせ、タップで「まわす・大きさ・いちばん上・はがす」を選べます(1ページ24枚まで)。ページごとの「おだい」(例: おうちにしゅぞくのシールを3枚)を達成すると かけら がもらえ、じっせき「シールあつめ」(10種類)・「シールちょうのたつじん」(おだい5つ)・「シールコレクター」(100種類)もあります。「このページを がぞうにする」で、ページを1枚のPNGにして長押し保存できます。集めたシールと貼った配置は「はじめから」しても残ります。

### そだちのバランス

そだちを1あげるのに必要な「せいちょう」は 8→10→14→20→26→32→40 と上がり、そだち20→70で680、20→100で1,660です(100分の一生で高得点を重ねれば届く量)。通常ミニゲームでSランクを取ると2分のあいだ、せいちょうが2倍になります（画面上に ✨2ばい の印、最大10分まで重なります。その日のチャレンジ達成回とクイックは対象外）。ふかふかまくらを装備して「ねる」を押すと、すぐげんきが100になり、通常の睡眠状態は続きます。「ねる」の回復は 0→100 で約5秒です(病気のときは約8秒)。90さい台は お世話が行き届いていても老いのリスクがわずかに上回ることがあり、そだちが高いほど守られます。たべすぎは おとろえ+4・15%で病気(以前の半分)です。

お世話のペースは「ほのぼの見ていられる」速さにしてあります。満腹・きげんは 0.35/3秒(100→30 で約10分)、うんちは約1.5分に1こ。病気になりうるのは うんち3こ以上・けんこう40未満・満腹かきげん20未満のときだけで、その間も 3%/3秒(以前は うんち2こ・30未満で 9%)。3さいまでは うんちがいっぱいのとき以外は病気になりません。けんこうは 満腹・きげんが50以上なら +1/3秒(70以上なら +2)で戻り、下がるときも以前の半分ほどです。幼少期の いのちの自然リスクはなくしました(老いの分は70さいから)。いのちは、病気でなく おなか・きげん・けんこうが40以上ならふだんの暮らしで 0.9/3秒ずつ戻り、4つとも60以上なら 1.8/3秒で戻ります(100→0 まで約5分半)。病気になったときの いのちの減りは 6→4 です。ミニゲームは 30点未満だけが「しっぱい」(おとろえ+8・いのち+2。以前は 40点未満で +16・+5)で、年齢による むずかしさの上がり方も ふつう 0.55・やさしい 0.3 に下げました(以前 0.7・0.4)。

### むずかしさとおと

「メニュー」→「せかい」の「ゲームの むずかしさ」で、やさしい・ふつう・むずかしいを選べます。年齢で上がる難しさの伸びを やさしい0.4倍・ふつう0.7倍・むずかしい1倍に抑え、制限時間は やさしいだけ+20% 長くなります(ふつう・むずかしいはそのまま)。「ゲームの ながさ」を みじかめ にすると、90秒以上の長いゲーム(タワーディフェンス、ローグライクなど)が6割の長さで終わります。かくとうバトルは連打対策として、続けざまの攻撃は威力が落ちて隙が大きくなり、3連続ヒット以降はスタンしなくなり、相手はガード後に反撃してきます。たこやきの焼き加減の幅、ルナランダーの着陸判定、ドットイーターのライフも やさしいで ゆるくなります。はじめの設定は「ふつう」です。

効果音とBGMは音のファイルを使わず、WebAudioでその場で作ります。効果音はボタンのタップ、ミニゲームのゲット/ミス/クリア(ヒント文の変わり目から自動判定)に加えて、100本すべてに投げる・跳ぶ・置く・当たる・取るなどの動作音、結果のランクに応じたファンファーレ、実績やイベントの知らせ、そだち・孵化・おわかれ・ねる/おきる など。BGMは場面ごとに8曲(ふつうの画面 / よる / ミニゲーム / 3D・のりもの / パズル・ボード / スポーツ / デート・ムービー / おわかれ)を、それぞれ8小節のコード進行にベース・メロディ・パッド・ドラムを重ねてループし、2周目ごとにアルペジオやハイハットが加わって表情が変わります。場面が変わるとクロスフェードします。ブラウザの決まりで最初のタップまでは鳴らず、タブを離れると止まります。「せかい」の「おと」で効果音とBGMをそれぞれON/OFFできます。

### デート

ムービーの発言には、小さなキャラの絵と名前が付きます。一つの字幕では一人が話し、情景の説明には話者を付けません。デートの小話は通常40本・深海20本、恋人18体の固有の掛け合いは各3本、伝説の出会いは各4本。同じ小話は、ゲームを開いている間は一巡するまで繰り返さず選びます。通常デートは約25秒（指輪の合言葉が加わると約32秒）で、途中でスキップできます。

デート・結婚記念日・伝説の出会いのムービーは、ブラウザの表示領域いっぱいに流れます。背景がゆっくり近づき、星・雨・光・泡と、字幕に合わせたキャラクターの動きが入ります。深海では水中の景色になります。字幕と「スキップ」「おもいでにしまう」は画面内に固定し、再生中は育成時間が止まります。端末の「動きを減らす」設定では、静止画と場面の切り替えで同じ物語を見られます。

「としをとったじぶん」は、森の水たまりに同じ種族の老年期の姿が映る場面です。水面に波紋が広がり、未来の顔が消える物語と、今の顔に戻る物語があります。この演出で、育てている子の年齢・姿・性別・恋愛関係が変わることはありません。

上の「データ」にあるこいびとの欄からデートに誘い、行き先を選びます。専用のごほうび在庫は使いません。深海にも地域に合うデートが用意されています。

### めぐる(いまいる地域を歩いて、みんなに会いにいく)

たびの画面のいちばん上に「○○をめぐる」(げんざいちのときは「げんざいち(まちなど)をめぐる」)の入口があり、いまいる地域の中を自由に歩ける「めぐる」画面に切り替わります(ホームの 3×3 ボタンは増えません)。探索画面が主役で、ヘッダー・ヒント・パッド以外の高さはすべて探索エリアに使い、iPhone の縦画面でも見切れません。下のパッドをなぞると歩き、奥行きのある見た目(ミニゲームと同じ canvas の擬似 3D。地平線は画面の上から 3 割で、地面・こみち・スポットが 7 割)で、遠景(地域ごとのシルエット: 森の木立、都会のビル、山なみ、海の水平線、砂丘、星空の停留所…)・中景(木や建物などの大きな物とスポットの目印)・手前(こみちのわきの小物と地面の草・小石・きらめき)の 3 層で地域らしさを出しています。ほしぞらのていりゅうじょは、星雲と流れ星のある空、光るこみち、提灯とベンチ、宇宙に浮かぶ足場、遠くの停留所の灯りで「停留所」と分かる場所になっています。じかん・てんき・きせつは本編と同じものが反映され、夜は暗く、雨や雪は降ります。

地域ごとに景色・色・光・地面・建造物・植物・密度・見通しが大きく変わり、切りかえた瞬間にどこへ来たのか分かるようにしています(とかいはネオンの繁華街、もりは木もれびと苔の深い森、ジャングルは葉が迫る密林と遺跡、さばくは巨大な岩山と砂紋、しんかいは光るサンゴと海溝、ゆきぐには夜のオーロラ、うみは歩くすぐ横が波打ちぎわ、かわは川が流れ、ほしぞらは浮島、きおくのみずうみは霧のヴェール)。地面は「世界のマス目」から見えている分だけ作るので、どこに立っても草・落ち葉・砂紋・舗装の目地などで埋まり、大きな空白になりません。

大事にしているのは小物の数ではなく「何の上を、何に囲まれて歩いているか」です。地面そのものが地域で変わり(田んぼの水面、車道と歩道と横断歩道、雪原と凍った湖、濡れ砂と砂丘、海底の亀裂、下草と根、がれ場、浮いた石畳…)、道の両側は自分よりずっと大きなもの(ビルの壁、岩壁、巨大な幹、雪の土手、砂丘、サンゴの壁、生垣、木の柵)が囲み、手前を枝・巨大な葉・葦・稲穂・雲などが横切ります。これらは canvas で描く造形物なので、住民の絵とは混ざりません。

地域の中は一本道ではなく、いくつかの「地区(zone)」に分かれた広い地図です(通常地域で 14〜23 スポット、おうちは 10 でコンパクト、きおくのみずうみは狭くて深い)。地区ごとに明るさ・霧・地面の色・木立の密度が変わり、歩く位置でなめらかに混ざるので、森なら「明るい森 → 似たような木立 → キノコの森 → 深い森 → 大木のまわり」と奥へ行くほど景色が変わります。地域ごとに構造も違います: もりは迷路型(二股・三股・ループ・似た木立・複数の橋・木の隙間の隠し道)、とかいは街区型(十字路・商店街・路地裏・公園・高台)、いなかは広い平面型(畑と草原、遠くの風車が目印)、やまは折り返しの登山道型(温泉・キャンプ・尾根・山小屋・山頂)、ゆきぐには雪原型(ロッジ・足跡の道・凍った湖・かまくら・ゲレンデ)、うみは海岸線型(潮だまり・桟橋・岩場・岬・灯台)、しんかいは暗い迷宮型(昆布の森・沈没船・光る深場・海溝)、かわ・みずうみは水辺追従型(川沿い・複数の橋・湖で開ける)、ジャングルは密集型(蔓の道・滝・遺跡・吊り橋・深いジャングル)、さばくは広大型(砂山・オアシス・キャラバン・遺跡・蜃気楼の丘)、ほしぞらのていりゅうじょは浮島ネットワーク型(複数の停留所を雲の道でつなぐ)、きおくのみずうみは静かな一本道+隠し分岐型です。分岐は道の縁の踏み跡や石、三叉路の標識、道幅の違いで景色から分かります。隠し道の入口には花・足跡・小さな光などの「誘い」があり、遮蔽物に隠れても自分の足元に輪が出て見失いません。道はスポット同士を結ぶ帯として描かれ、道を外れると草むらや砂の上で少し遅くなります。道の両わきには木・建物・岩・雲などの遮蔽物が並び、曲がった先や木の向こうは行ってみるまで見えません。カメラは歩く向きと道の向きにゆっくり合わせて首を振るので、左の道へ入ると左を向いた景色になります(パッドの上は「いま見ている方向へ進む」、左右は「曲がる」)。広場では少し引き、狭い道では寄り、見晴らし台では遠くまで見えるようにカメラが変わります。各地域には遠くからでも見える大きなランドマーク(森の大木、都会の時計塔、海の灯台、深海の巨大サンゴ、雪国のロッジと雪山、砂漠のオアシスと遺跡、星の停留所の大きな標識、田舎の風車…)があり、初めて入ったスポットには「○○を みつけた」と出ます(発見済みスポットは地域ごとにセーブされ、隠し場所は見つけるまで地図データに載りません。地図の画面は今後の予定です)。

ずかんに登録済みのキャラは全員がこの世界のどこかに住んでいます(住むのは現在の正式なずかんにある種だけで、古いセーブに残った旧種族は住民になりません。同じ住民は世界に必ず 1 体です)。景色の絵文字(木・きのこ・看板など)は住民の画像には変換されず、話しかけることも名前が出ることもありません。景色としてランダムに何度も置かれる小物(道ばた・壁・誘い・地区ごとの小物)には鳥・魚・哺乳類・爬虫類・虫の絵文字を入れない方針で、画面上で「生きている生き物」に見えるものは住民台帳(ずかんのキャラ・なかま・レアなかま・こいびと・ナオト)由来だけです(草木・花・きのこ・サンゴ・貝がらは景色として使います。「ねこのばしょ」「ぼくじょう」「ラクダのみずば」のような場所の目印は 🐾 や 🪧 の看板で表します)。なかま・レアなかま・こいびとと同じ絵文字も同様にランダム景色には使いません(雪国の ⛄ は こいびと「とけないゆきだるま」なので景色から外し、「ゆきだるまのおか」には 🧣 のマフラーだけが残っています。植物・天気の 🌻 🌵 ❄️ と、ジャングルの遺跡に 1 つだけ立つ石像 🗿 は景色として許容)。しゅぞくの 8 つの すがた は 1 つずつ別の住民として数え、生態に合う地域(ペンギンは雪・海、カブトムシは森・ジャングル、アリジゴクは砂漠…)に定住しています(サケのように育つと住みかが変わる種は段階ごとに地域が変わります)。なかま・レアなかまは「旅人」で、日替わりでどこかの通常地域へ遊びに行きます(好む地域があればそこへ出やすく、同じ日のうちは何度入っても同じ地域)。こいびと候補は初めて出会った地域に住みます。ランダムに何体かだけ出るのではなく、探せば全員に会えます。住民は均等には散らばらず、広場や店前・水辺に集まり、静かな小道には 0〜1 体、隠し場所には 1 体だけがいます。いまの子は自分自身として歩き、いま連れているなかま・こいびとは同じ個体として少し後ろ・横をついてきます(二重には出ず、自分を隠しません)。入った瞬間に入口のひろばに 2〜4 体がいて、近くの住民には名前が出ます。同時に描く数に上限はありますが、自分・同行中のなかま・こいびと・話しかけられる距離の住民は背景の小物より優先して必ず描かれます。住民は歩く・座る・ながめる・寝る・釣る・遊ぶ・おしゃべり・数体で集まる・追いかけっこ・店を見るなどをしていて(広場では集まりやすく、水辺では釣り、ベンチでは座り、見晴らし台では景色を見ています)、夜や雨で行動が変わります。キャラは向き(heading)を持ち、左右へ歩くと反転して少し傾き、奥へ歩くと揺れが小さく、座る・寝る・話すで姿勢が変わります(将来、横向き・後ろ向きの画像を足せる構造です)。遠くの住民は小さなシルエットで描かれ、賑やかな場所では一画面に数体〜十体ほどの気配が見えます。ヘッダーには「この地域に住んでいる数(○○たい)」と「今回近くで会った数(であった ○)」が出ます。近づくと「はなす」が押せて、そのキャラらしいひとことが吹き出しで出ます(会った人数は「であった n／m」に出ます)。

画面内の「たび」からそのまま地域を変えられ、通常のたびと同じ処理(げんき消費・たびづかれ・はじめての地域の記録)を通って、その地域の世界に切り替わります。「もどる」(キーボードなら Esc)でホームへ戻ります。めぐっているあいだは本編の時間が止まり(年齢・おなか・ごきげん・げんきが動かず、しぬこともありません)、なかまのさそい・でんせつとの出会い・ひとりごと・おせわの通知もホームに戻るまで出ません。

つくりは「世界(ワールド座標・住民・移動・当たり判定・行動・会話)」と「描画(canvas の擬似 3D)」の 2 層に分かれていて、キャラや小物の位置は画面の px ではなく仮想世界の座標で管理しています。描画は世界の状態を読むだけなので、将来 Three.js などの本物の 3D に置き換えるときも、同じワールドデータとゲームロジックをそのまま使えます。

ナオトは特別な住民で、通常の住民には混ざりません。ずかんコンプリート/パーフェクトのゴール(ホーム画面でナオトが現れる条件と同じ)を達成しているときだけ、きおくのみずうみの奥の隠し場所「みずうみのおく」(霧の小道か積み石の先の細い道でたどり着く)にいつもいて、話しかけると達成状況に応じた専用のことばを言います。未解禁なら世界のどこにも出ません。

| `assets/` | 画像などの素材 |
