# なおとっち

ブラウザで遊べる育成ゲームです。ごはんやそうじ、ミニゲームでお世話をしながら、出会いと成長を楽しめます。

[ゲームを遊ぶ](https://naoto214.github.io/naotocchi/)

地域・天気・山の遊びの説明は、PR #234を含むmainから進めた地域改善に合わせています。開発は継続中です。再開時は [公開後チェックポイント](POST_RELEASE_CHECKPOINT_2026-09-10.md) とGitHubの最新状態を確認してください。

## 遊び方

「満腹」「機嫌」「元気」「体力」を見ながら、ごはん・そうじ・ねる・くすり・あそぶでお世話します。進行は使っているブラウザの保存領域に自動保存されます。公開ゲームと別のURL・ブラウザでは、同じセーブが自動で共有されるわけではありません。

### 年齢とそだち

年齢はゲームを開いて育成している時間で進みます。基本画面とミニゲーム中は3秒ごとの更新20回で1さい、100さいで人生の締めくくりを迎えます。図鑑などのメニューやデートのムービー中は育成時間が止まり、ページを閉じていた時間は加算されません。

孵化後の姿は年齢で決まる8段階です。卵はこの8段階に含みません。

| 始まる年齢 | 姿の段階 |
| --- | --- |
| 0さい | あかちゃん |
| 3さい | よちよち |
| 7さい | こども |
| 12さい | しょうねん・しょうじょ |
| 16さい | せいしゅん |
| 22さい | わかもの |
| 40さい | おとな |
| 70さい | ろうねん |

「そだち」は20から始まり、0〜100で変わる育ち具合です。お世話などでためた「せいちょう」が必要量に達すると上がり、「おとろえ」がたまると下がります。そだちの上下で年齢や姿の段階が巻き戻ることはありません。到達した最高そだちに応じて特典も開きます。

別の種族になる「へんしん」のチャンスは、姿の段階が変わる節目(へんしんメーターの分だけの確率)と、メーターが満タンで迎えた誕生日(55%、そだちが高いほど上がる)に抽選されます。メーターはミニゲームを1回あそぶと+20(5回で満タン)。回数の上限はありません。候補を選ぶほか、今の姿で育て続けることもできます。

通常の卵からは通常22種族のいずれかが生まれます。「たまごのゆめ」などで次の種族を選んでいた場合は、その指定が使われます。レア・隠し種族には別の入手条件があります。

ホームの「たび」で行き先を選びます。「メニュー」→「せかい」では、じかん・きせつ・てんきを「げんざい」か手動で選べます。じかんときせつはスマホの時計にあわせ、現在のてんきは位置情報から取得します。現在地の表示は市区町村までで、座標や番地はセーブに残しません。「げんざいち」を旅先に選んだ場合は、市区町村名と景色の種類を保存します。取得できないときは再試行や手動設定ができます。旧セーブに残っている引退済みキャラクターも互換性の対象です。上の数字は現在の構成で、古いキャラクターを似た新キャラクターへ置き換える意味ではありません。

### あそぶ

ミニゲームは100種類あります。地域・季節向けのゲームもすべて候補に入り、現在の地域や季節に合うもの、まだあまり遊んでいないものは出やすくなります。同じジャンルの連続を減らす選び方も入っています。

「あそぶ」でランダムにすぐ始まります。「メニュー」→「ゲームを選ぶ」で、遊んだゲームの記録を確認して選べます。100種類という数字は登録数であり、すべての端末で操作感・描画まで確認済みという意味ではありません。

そのゲームを3回遊ぶまでは、動き出す前に絵文字・名前・ジャンル・説明・そうさを1枚のカードで見せ、「▶ はじめる」で始まります(4回目からはすぐ始まります)。ゲーム中はいちばん下の「？そうさ」で、いつでも説明と指の動きのデモを見られます(ゲームは止まりません)。アクセルやジャンプなどのメインボタンは右に大きく、◀▶は左にまとめてあり、片方の指で押しながらもう片方で操作できます。カードの「そうさ」には、そのゲームの指の動き(タップ / スワイプ / ドラッグ / おしっぱなし / ◀▶ボタン)を小さなアニメで見せます。

ミニゲームのボタンは画面の下(親指の届く位置)にまとめ、説明文もその上に置いています。おしっぱなしのボタンは指が少し動いても切れません(touch-action: none)。ゲームが終わると点数のトーストに「🔁 もういちど」が出て、同じゲームをすぐやりなおせます(6秒で消えます。げんきが足りないときは いつもどおり ことわられます)。スワイプで動かすゲーム(ブロックパズル・スネーク・2048・スライドパズルなど)は、指の動き 16px からスワイプと判定する共通のしきい値に そろえてあります。おしっぱなしボタンの反応間隔も共通(1マスずつ 240ms→140ms、速い操作 80ms→45ms)です。

「じっせき」タブも「じっせきの まとめ」(かいほう数のバー・9段階ごとの数・さいきん かいほう・つぎの もくひょう)と段階ごとのセクション、24時間いないに かいほうした NEW の しるしで見やすくなりました。「ゲームを選ぶ」の一覧は、いちばん上の「きろくのまとめ」で あそんだ本数のバー・S〜Dランクの内訳バー・平均ベスト・コンプリートまでの残り本数がわかり、ジャンルごとに きろく数とSランク数が見えます。ジャンル / みプレイ / ランクひくい順 / ベスト高い順 で並び替えられます。いちばん上の「きょうのチャレンジ」は日付で決まる1本に1日1回だけ挑戦でき、クリアすると 💰+10 と連続日数が記録されます。

「データ」画面の「セーブのバックアップ」で、セーブをコード(`NTS1.` から始まる文字列)にして控えたり、別の端末で読み込んで置きかえたりできます。同じ画面の「じどうバックアップ」には、20分以上あいだのあいたセーブが自動で3つまで残り、「この時点にもどす」を2回押すとそのセーブに戻せます(戻す前のセーブも一番上に残るので、戻すのをやめることもできます)。端末が重いときは自動で描画を軽くします(3段階: 平均フレーム 22ms 超で解像度1.5倍・飾り65%、34ms 超で解像度1倍・飾り40%。速いフレームが3回続けば1段もどります)。

### せかい(じかん・きせつ・てんき・地域)

「メニュー」→「せかい」で、時間・季節・天気を自動か手動で選べます。自動の天気は、おうちでは取得できた現在地の天気、旅先では地域の気候と季節から3時間ごとに予想した天気を使います（「はれ(よそう)」など）。ジャングルや砂漠は、冬でも雪の予想にはなりません。

じかん・きせつ・てんき・地域にはそれぞれ固有の効果があり、「せかい」画面の「いまの せかい」カードで確認できます。たとえば はれ は きげんが下がりにくく ゲームのおかね+10%、あめ は きげんが下がりやすく なかまとの出会いが減る代わりに おかね+15%、よる は ねると回復が早い、もり は なかまに出会いやすい、など(自然減・ねむりの回復・あそぶ疲れ・おかね・出会いやすさの5つの倍率を掛け合わせ、0.7〜1.5倍に収めます)。ミニゲームの出やすさも変わり、あめ の日は パズル・ボード、はれ は スポーツ・3D、よる は パズル、うみ は スポーツ、さばく は のりもの が出やすくなります(「いまの せかい」に ↑↓ で表示)。

ホーム画面には あめ・ゆき・くも・ひざし・よるの星と月 の演出と、あさ・ゆう・よる の色合いがかかります(ゲーム中とメニュー中は消えます)。ときどき てんきや じかんにちなんだ小さな できごと(にじを見つけた、ゆきだるまを作った、ながれぼしに おねがい…)が起こり、きげん・げんき・おかねが少し動きます。てんき・じかんにまつわる じっせき も6つ増えました。

「かわ・みずうみ」の表示名は「みずべ」になりました。訪問歴や過去の思い出は引き継ぎます。山では岩を選んでタイミングよくつかむ「岩場のぼり」、雪国ではスキーやスノーボードを楽しめます。全100ゲームは、どの地域でも遊べます。

大画面の景色は場所ごとに構図を分けています。とかいは高層ビルと交差点、夜はネオン街。おうちはソファやラグのある室内で、雨や雪は部屋の中に降りません。いなかは田畑、ジャングルは大きな熱帯植物と滝、みずべは湖と桟橋です。

「たび」→「📍げんざいち」で、位置情報を許可すると市区町村に応じた街のイメージを表示します。函館市は港町、飯田市は山あい、大阪市（各区を含む）と東京都の23区は都会、それ以外は一般的なまちなかです。実在の街並みをそのまま再現するものではありません。選んだ景色は再読み込み後も残り、「せかい」から現在地を調べ直せます。「おうち」を選ぶと室内に戻ります。

雪国は睡眠で回復しやすく遊ぶ疲れも少なめ、ジャングルは仲間との出会いが多め、砂漠はゲームのおかねが多めです。それぞれ少しおなかがすきやすく、詳しい効果は旅先カードで確認できます。

深海は泡や光るくらげの世界、星空の停留所はいつも星空です。この2か所には地上の天気や暑さ・寒さの効果を当てはめません。選んだ天気と季節は、地上へ戻ると反映されます。そだち70で開く星空の停留所では星のかけらを拾うことがあり、記憶の湖では実際に記録された思い出が水面にうつります。伝説は未遭遇を優先しながら、ゆかりのある地域で少し出会いやすくなります。

### おかねのつかいみち

「あいてむ」の「つかいきり」で、つぎの1回だけきく おまもりを買えます: ラッキーコイン(ゲームのおかね2倍)、スコアほけん(しっぱいのばつなし)、やる気/大成功のおまもり(とくてん+25/かならず大成功)、びょうきよけのおふだ(3回)、せいちょうドリンク(5分2倍)、こいのおまもり(小/大)、なかなおり/きずなのおまもり(わかれの軽減/無効)、たびのおまもり。同じこうかは1つずつしか持てず、画面上部に「いまもっているこうか」が出ます。きょうのチャレンジのごほうびは 10コイン+連続日数×5(最大60)、3・7・14・30日の節目で +30/+100/+200/+500 です。

### シールちょう

メニューの「シールちょう」で、これまでの絵をシールにして集め、4つのページ(おうち・たび・なかま・きねん)に貼って遊べます。シールは、ずかんに初めて載ったすがた・なかまになったとき・こいびとになったとき・きょうのチャレンジのクリア・Sランク(30%)でもらえるほか、💰30の「シールパック」(3枚)で買えます。しゅぞくのすがた(全ライン×8段階)、なかま、こいびと、身につけるあいてむ、けしき(木・山・海・天気など)の300種類以上で、レアなしゅぞく・レアななかまは「レア」です。かぶったシールは「かけら」になり(ふつう1・めずらしい3・レア8)、12個で持っていないシール1枚と交換できます。かぶった分はもう1枚貼れます。

ページに貼ったシールは指で動かせ、タップで「まわす・大きさ・いちばん上・はがす」を選べます(1ページ24枚まで)。ページごとの「おだい」(例: おうちにしゅぞくのシールを3枚)を達成すると おかね と かけら がもらえ、じっせき「シールあつめ」(10種類)・「シールちょうのたつじん」(おだい5つ)・「シールコレクター」(100種類)もあります。「このページを がぞうにする」で、ページを1枚のPNGにして長押し保存できます。集めたシールと貼った配置は「はじめから」しても残ります。

### いっしょうの ねんぴょう と いっしょうカード

「データ」画面の「いっしょうの ねんぴょう」で、この子に起きた できごとを ねんれい順に見られます(いちばん とくいなゲームも)。おわかれの画面は できごとを全部ならべ、「いっしょうカードのコード」(`NTL1.` から始まる文字列)を作ってコピーできます。コードは「データ」画面の「いっしょうカードを 見る」に貼るとカードとして表示され(セーブは変わりません)、おわかれした子は「これまでの子」に ねんぴょう つきで残ります。同じ画面の「エラーのきろく」には最近のエラーが並び、セーブコードと一緒にコピーして相談に使えます。

### るすのあいだ

ページを閉じているあいだも年はとりませんが、2分以上あいだが空くと、おなか・きげん がゆっくり下がります(1回の るすで最大30、20より下にはならず、死ぬことはありません)。げんきは るすのあいだ休んでいる扱いで下がらず、ねかせておけば回復します。もどると「おかえり」のおしらせに るすのあいだの変化と、5分ごとに1コイン(最大12)、30分以上なら ときどき おたのしみ のおみやげが出ます。

### ずかん・たびの画面

ずかんは「ずかんの まとめ」(ふつう/レアの うまりぐあい、いまの子の つぎの すがたは何さいか)と、しゅぞくごとの見出し(名前・進捗バー・n/8)で見やすくなりました。まだ見ていない しゅぞくは「？？？」のままです。たびの画面は地域カードになり、その地域の こうか・出やすいゲーム・ごとうちゲーム数・こいびと候補の人数・おとずれた しるし(✓)・いまいる場所 がわかります。たまごのあいだは おなか・きげん・げんき・けんこう のバーを出しません。

### いっしょうの できごと

ごはん・じゃれる・おきる・たび・きゅうあいのあとにも、ときどき短い できごとの一言が出ます。44・50・56・62・66さいには「ちゅうねんの できごと」(しゅみ、おいわい、アルバム、にわの花、たびの計画)が1回ずつ起こり、きげん・せいちょう・おかねが少し動いてライフログに残ります(こいびとがいると ふたりの版になります)。でんせつのであいは そだち70(たびだち)から起こるようになりました。

### そだちのバランス

そだちを1あげるのに必要な「せいちょう」は 8→10→14→20→26→32→40 と上がり、そだち20→70で680、20→100で1,660です(100分の一生で高得点を重ねれば届く量)。ミニゲームで Sランクを取ると2分、きょうのチャレンジをクリアすると10分のあいだ せいちょうが2倍になります(画面上に ✨2ばい の印、最大10分まで重なります)。「ねる」の回復は 0→100 で約5秒です(病気のときは約8秒、まくらを付けると約4秒)。90さい台は お世話が行き届いていても老いのリスクがわずかに上回ることがあり、そだちが高いほど守られます。たべすぎは おとろえ+4・15%で病気(以前の半分)です。

お世話のペースは「ほのぼの見ていられる」速さにしてあります。満腹・きげんは 0.35/3秒(100→30 で約10分)、うんちは約1.5分に1こ。病気になりうるのは うんち3こ以上・けんこう40未満・満腹かきげん20未満のときだけで、その間も 3%/3秒(以前は うんち2こ・30未満で 9%)。3さいまでは うんちがいっぱいのとき以外は病気になりません。けんこうは 満腹・きげんが50以上なら +1/3秒(70以上なら +2)で戻り、下がるときも以前の半分ほどです。幼少期の いのちの自然リスクはなくしました(老いの分は70さいから)。いのちは、病気でなく おなか・きげん・けんこうが40以上ならふだんの暮らしで 0.9/3秒ずつ戻り、4つとも60以上なら 1.8/3秒で戻ります(100→0 まで約5分半)。病気になったときの いのちの減りは 6→4 です。ミニゲームは 30点未満だけが「しっぱい」(おとろえ+8・いのち+2。以前は 40点未満で +16・+5)で、年齢による むずかしさの上がり方も ふつう 0.55・やさしい 0.3 に下げました(以前 0.7・0.4)。

### むずかしさとおと

「メニュー」→「せかい」の「ゲームの むずかしさ」で、やさしい・ふつう・むずかしいを選べます。年齢で上がる難しさの伸びを やさしい0.4倍・ふつう0.7倍・むずかしい1倍に抑え、制限時間も やさしい+35%・ふつう+17% 長くなります(100本すべての制限時間が対象)。「ゲームの ながさ」を みじかめ にすると、90秒以上の長いゲーム(タワーディフェンス、ローグライクなど)が6割の長さで終わります。かくとうバトルは連打対策として、続けざまの攻撃は威力が落ちて隙が大きくなり、3連続ヒット以降はスタンしなくなり、相手はガード後に反撃してきます。たこやきの焼き加減の幅、ルナランダーの着陸判定、ドットイーターのライフも やさしいで ゆるくなります。はじめの設定は「ふつう」です。

効果音とBGMは音のファイルを使わず、WebAudioでその場で作ります。効果音はボタンのタップ、ミニゲームのゲット/ミス/クリア(ヒント文の変わり目から自動判定)に加えて、100本すべてに投げる・跳ぶ・置く・当たる・取るなどの動作音、結果のランクに応じたファンファーレ、実績やイベントの知らせ、そだち・孵化・おわかれ・ねる/おきる など。BGMは場面ごとに8曲(ふつうの画面 / よる / ミニゲーム / 3D・のりもの / パズル・ボード / スポーツ / デート・ムービー / おわかれ)を、それぞれ8小節のコード進行にベース・メロディ・パッド・ドラムを重ねてループし、2周目ごとにアルペジオやハイハットが加わって表情が変わります。場面が変わるとクロスフェードします。ブラウザの決まりで最初のタップまでは鳴らず、タブを離れると止まります。「せかい」の「おと」で効果音とBGMをそれぞれON/OFFできます。

### デートとごほうび

上の「データ」にあるこいびとの欄からデートに誘い、行き先を選びます。ごほうびを持っていると、ゲーム内に「ごほうびを1こ使う」「使わずにデートする」「行き先にもどる」が表示されます。

ごほうびは「ごほうびを1こ使う」を選んで特別デートを始めると1個消費します。行き先選択に戻っただけでは消費しません。深海にも地域に合うデートが用意されています。

## 画面とデザイン

お世話はホームの9ボタンにまとまっています。きゅうあいは続けて押せます。元気なときにくすりを使った反応も残っています。おとろえを含む育成ゲージは通常のホームで確認できます。

病気になると、状態名と病気のマーク、主人公の周りの汗で知らせます。いのちが40以下になると回復に必要なお世話を案内し、20以下やけんこうが限界のときは画面の縁の赤い光がゆっくり脈打ちます。必要なお世話ボタンも光り、治療・回復に合わせて切り替わります。動きを減らす設定や軽量モードでも、静止した色・マーク・文章で確認できます。

名前・恋人の名前・クリアのバッジは上に、セリフは吹き出しに表示します。仲間が増えると左右の弧に並び、メイン・恋人・仲間・装備は一緒に左右に揺れます。端末の「視差効果を減らす」など、動きを減らす設定では静止します。

「メニュー」→「デザイン」は、がめん／ほんたいを選んで色や柄を変更します。40色・40柄と従来の解放条件を保ち、文字のテイストと大きさも選べます。「データ」「つうしん」は上のボタンから開けます。

## ローカルで動かす

通常のゲームはビルド不要です。リポジトリのルートで次を実行し、ブラウザで `http://localhost:8000` を開いてください。

```sh
python3 -m http.server 8000
```

開発用のシーン確認はViteで起動します。

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

起動時に表示されるURLの `/__qa` を開くと、デート・記念日・伝説などの確認用セーブを選べます。選んだセーブで同じオリジンの保存領域を上書きするので、普段のゲームとは別のオリジンで使ってください。`/__qa` は開発用ルートで、GitHub Pagesにはありません。

```sh
npm test
```

`npm test` は CI と同じ内容で、そだちのバランス・つかいきりアイテム・るすのあいだ・採点とランク・ショップ・じっせき解放・画面(ずかん/たび/たまご)・アセットの参照・旧セーブ(schemaVersion 2〜4)の移行と形のそろえなおし・オーバーレイの排他・軽量モードの段階も検証します。`node tools/perf-measure.js --throttle 4` は Playwright で全ミニゲームのフレーム時間(平均/p95/最大)を測り、重い順に並べます(`--ms` で1本あたりの秒数、`--json` で保存。playwright は `NODE_PATH=$(npm root -g)` で解決)。`npm run bump` で index.html の `?v=` キャッシュ版数をファイルのハッシュから付けなおせます(変わったファイルだけ更新)。`npm test` は起動・ミニゲーム登録と開始・会話・QAセーブに加え、終了や画面切り替え時の入力解除と、保存失敗・バックアップ復旧・旧セーブ移行を検証します。ブラウザでの見た目、実機の速度や操作感は別に確認します。
