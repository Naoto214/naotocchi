# tamagotchi-modoki

ブラウザで遊べる、たまごっちもどきの育成ゲームです。ビルド不要、HTML/CSS/JSだけで動きます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ローカルで確認する場合は、リポジトリのルートで以下のように簡易サーバーを立てても構いません。

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。

## ゲームの内容

- 卵からかえって、あかちゃん→こども→はんせいじん→おとな、と成長します。
- おとなになるとき、育て方によって「いぬ・ねこ・とり・おとこのひと・おんなのひと・カブトムシ・クワガタムシ」のいずれかに変身します。どのボタン(ごはん・あそぶ・そうじ・ねる・くすり)を一番よく使ったかに加えて、マンガ風の質問でどんな方向性の返答を選んできたか(やさしい/自由/おだやか/勇敢/ロマンチック)も影響します。お世話の質が全体的にとても高いと、まれに「かみさま」になることも。ミニゲームの成績がずっと良い、またはロマンチックな返答を選び続けていると、さらにまれに「れんくん」という男の子が仲間になります。
- おとなのままさらに長く育てると、同じ姿で歳を重ねた「エルダー」の見た目に変化します(例:いぬ→としをとった いぬ)。
- 「満腹」「機嫌」「元気」「体力」の4つのステータスを管理します。
- 「あそぶ」を押すと、8種類のミニゲーム(おやつキャッチ・もぐらたたき風タップ・タイミングタップ・マンガ風の質問・きおくチャレンジ・けいさんチャレンジ・はんしゃしんけいチャレンジ・いろとことば(ストループ)チャレンジ)から、直前と同じものを避けてランダムで1つが始まります。結果に応じて機嫌が上がります。
- あとから追加した4種(きおく・けいさん・はんしゃしんけい・いろとことば)は大人でも歯ごたえのある脳トレ系で、なおとっちの日齢が上がるほど難易度も上がります(記憶する個数が増える、時間制限が短くなる、判定がシビアになる、など)。既存の4種も同様に、育つほどタイミングがシビアになったり展開が速くなったりします。
- おやつキャッチには うんち・ゴキブリ・刃物・銃 などの「わるいもの」も混ざっていて、キャッチすると減点されます。
- マンガ風の質問は40種類・160択(ふつう・シリアス・大人っぽい・馬鹿らしい・ラブロマンス的・感動)を用意していて、全部出きるまで同じ質問は繰り返しません。「感動」は新しく追加した、涙腺にくる系の質問カテゴリです。選択肢を選ぶと、その方向性にあわせた一瞬の演出(ハート・きらめきなど)が入ってから結果が反映されます。
- お世話をさぼる(うんちが溜まる・おなかがすいている・きげんが悪い・体力が低い)と、びょうきになりやすくなります。びょうきには10種類の症状名があり、そのたびに画面とペットの見た目も病気っぽく変化します。くすりで治療できます。
- 放っておくと うんち が溜まったり、びょうきになったりします。びょうきを何度も繰り返していると、そのぶん弱っていき、天国に旅立つまでの時間も短くなります(リセットでやり直せます)。
- 「進化」「退化」「死亡」の3つのメーターがあります。ごはん・そうじ・ねる・くすり・ミニゲームがうまくいくと「進化」メーターが上がり、たまると必ず1段階変身(成長)します。逆に手入れをさぼったり、ミニゲームに失敗したり、くすりを無駄遣いしたりすると「退化」メーターが上がり、たまると必ず1段階もどってしまいます(おとな未満まで退化すると種族もリセットされて、次におとなになるときにあらためて種族が選びなおされます)。年齢の下限は0です。びょうきになったり、体力が0の状態が続いたり、ミニゲームに失敗し続けたりすると「死亡」メーターが上がり、たまると死亡します。成長のスピード自体もかなり速くしてあるので、数分プレイするだけでも進化・退化・死亡がどんどん起こります。
- 見た目の成長段階とは別に、進化するたびに+1・退化するたびに-1される「せいちょうレベル」を裏で記録していて、これが+100に達すると見た目の成長段階に関係なくゲームクリアです。ド派手な演出とともに「GAME CLEAR / go to heaven!!」の画面になり、「はじめから」で新しいたまごから再スタートできます。
- ごはんは、おなかがすでに満腹に近い(満腹80以上)ときに与えると「食べすぎ」扱いになり、進化メーターは増えません。それどころか機嫌が下がり、退化メーターが上がり、一定確率でびょうきになってしまいます。ごはんを連打するだけでは簡単に進化できないようになっています。
- 育てていく中で、成長のふしめ(何度も変身をくり返す・びょうきをたくさん乗り越える・ミニゲームをたくさんこなす、など)で一度きりの特別な演出(「ライバルが あらわれた!」など)が画面いっぱいに出ることがあります。一度見た演出は同じセーブデータでは二度と出ません。
- 進行状況(成長段階・各ステータスなど)はブラウザの localStorage に自動保存され、アプリを閉じても続きから再開できます。ただし時間はゲーム画面を実際に開いている間だけ進み、閉じている間は進みません。

## ファイル構成

- `index.html` — 画面構成
- `style.css` — たまごっち風デバイスの見た目
- `script.js` — ゲームロジック(状態管理・成長・保存)
