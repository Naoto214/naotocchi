# tamagotchi-modoki

ブラウザで遊べる、たまごっちもどきの育成ゲームです。ビルド不要、HTML/CSS/JSだけで動きます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ローカルで確認する場合は、リポジトリのルートで以下のように簡易サーバーを立てても構いません。

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。

## ゲームの内容

- 卵からかえって、あかちゃん→こども→はんせいじん→おとな、と成長します。
- お世話の良し悪しによって、おとなの見た目(なかよし/やんちゃ)が変わります。
- 「満腹」「機嫌」「元気」「体力」の4つのステータスを管理します。
- 「あそぶ」を押すと、4種類のミニゲーム(おやつキャッチ・もぐらたたき風タップ・タイミングタップ(3ラウンド)・マンガ風の質問)から、直前と同じものを避けてランダムで1つが始まります。結果に応じて機嫌が上がります。
- マンガ風の質問は30種類(ふつう・シリアス・大人っぽい・馬鹿らしい・ラブロマンス的)を用意していて、全部出きるまで同じ質問は繰り返しません。
- 放っておくと うんち が溜まったり、びょうきになったりします。ひどく放置すると天国に旅立ってしまいます(リセットでやり直せます)。
- タブを閉じている間の時間も加味して、次に開いたときにステータスが進みます(進みすぎないように上限があります)。
- 進行状況はブラウザの localStorage に自動保存されます。

## ファイル構成

- `index.html` — 画面構成
- `style.css` — たまごっち風デバイスの見た目
- `script.js` — ゲームロジック(状態管理・成長・保存)
