# tamagotchi-modoki

ブラウザで遊べる、たまごっちもどきの育成ゲームです。ビルド不要、HTML/CSS/JSだけで動きます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ローカルで確認する場合は、リポジトリのルートで以下のように簡易サーバーを立てても構いません。

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。

## ゲームの内容

- 卵からかえって、あかちゃん→こども→はんせいじん→おとな、と成長します。
- おとなになるとき、育て方によって「いぬ・ねこ・とり・おとこのひと・おんなのひと・カブトムシ・クワガタムシ」のいずれかに変身します。どのボタン(ごはん・あそぶ・そうじ・ねる・くすり)を一番よく使ったかで決まります。お世話の質が全体的にとても高いと、まれに「かみさま」になることも。ミニゲームの成績がずっと良いと、さらにまれに「れんくん」という男の子が仲間になります。
- おとなのままさらに長く育てると、同じ姿で歳を重ねた「エルダー」の見た目に変化します(例:いぬ→としをとった いぬ)。
- 「満腹」「機嫌」「元気」「体力」の4つのステータスを管理します。
- 「あそぶ」を押すと、8種類のミニゲーム(おやつキャッチ・もぐらたたき風タップ・タイミングタップ・マンガ風の質問・きおくチャレンジ・けいさんチャレンジ・はんしゃしんけいチャレンジ・いろとことば(ストループ)チャレンジ)から、直前と同じものを避けてランダムで1つが始まります。結果に応じて機嫌が上がります。
- あとから追加した4種(きおく・けいさん・はんしゃしんけい・いろとことば)は大人でも歯ごたえのある脳トレ系で、なおとっちの日齢が上がるほど難易度も上がります(記憶する個数が増える、時間制限が短くなる、判定がシビアになる、など)。既存の4種も同様に、育つほどタイミングがシビアになったり展開が速くなったりします。
- おやつキャッチには うんち・ゴキブリ・刃物・銃 などの「わるいもの」も混ざっていて、キャッチすると減点されます。
- マンガ風の質問は30種類(ふつう・シリアス・大人っぽい・馬鹿らしい・ラブロマンス的)を用意していて、全部出きるまで同じ質問は繰り返しません。
- お世話をさぼる(うんちが溜まる・おなかがすいている・きげんが悪い・体力が低い)と、びょうきになりやすくなります。びょうきには10種類の症状名があり、そのたびに画面とペットの見た目も病気っぽく変化します。くすりで治療できます。
- 放っておくと うんち が溜まったり、びょうきになったりします。びょうきを何度も繰り返していると、そのぶん弱っていき、天国に旅立つまでの時間も短くなります(リセットでやり直せます)。
- 進行状況(成長段階・各ステータスなど)はブラウザの localStorage に自動保存され、アプリを閉じても続きから再開できます。ただし時間はゲーム画面を実際に開いている間だけ進み、閉じている間は進みません。

## ファイル構成

- `index.html` — 画面構成
- `style.css` — たまごっち風デバイスの見た目
- `script.js` — ゲームロジック(状態管理・成長・保存)
