### 年齢とそだち

年齢はゲームを開いて育成している時間で進みます。基本画面(なにも開いていないとき)では3秒ごとの更新20回で1さい、100さいで人生の締めくくりを迎えます。おせわができない画面を開いているあいだは育成時間が止まります: メニュー(ずかん・じっせき・でざいん・プロフィール・つうしん・あいてむ・せかい・たび・シール)、うそつきしょうぶ、デートのムービー、なかまのさそい、ゴールのおいわい、「めぐる」で地域を歩いているあいだ、ミニゲーム・クイックモードの最中、へんしんの すがたを選んでいるあいだ、のすべてで年齢もおなか・ごきげん・げんきも動きません(閉じればまた進みます)。ページを閉じていた時間は加算されません。

孵化後の姿は年齢で決まる8段階です。卵はこの8段階に含みません。

| 始まる年齢 | 姿の段階 |
| --- | --- |
| 0さい | あかちゃん |
| 3さい | よちよち |
| 7さい | こども |
| 12さい | しょうねん・しょうじょ |
| 16さい | せいしゅん |
| 22さい | わかもの |
| 40さい | おとな |
| 70さい | ろうねん |

「そだち」は20から始まり、0〜100で変わる育ち具合です。お世話などでためた「せいちょう」が必要量に達すると上がり、「おとろえ」がたまると下がります。そだちの上下で年齢や姿の段階が巻き戻ることはありません。到達した最高そだちに応じて特典も開きます。

別の種族になる「へんしん」は抽選ではなく、へんしんメーターが満タンになったその場でチャンスが開きます。メーターはミニゲームを1回あそぶと+25(4回で満タン。シルクハットで早まります)。回数の上限はありません。候補を選ぶほか、今の姿で育て続けることもできます。

### カクレクマノミの成長と恋愛

カクレクマノミは⑥「卵を守るオス」、⑦「メスへ変わる途中」、⑧「群れのリーダーのメス」と育ち、⑧で性転換が完了します。[現実では群れの順位などが性転換に関係します](https://pubmed.ncbi.nlm.nih.gov/18533742/)が、ゲームでは既存の成長物語として簡略化しています。40さい・70さいという区切りはゲーム共通の時間で、実際の魚の年齢ではありません。

性転換しても好きになる相手の性別は変わりません。男の子を好きなオスは「ゲイ」から「ストレート」へ、女の子を好きなオスは「ストレート」から「レズビアン」へ表示が変わります。バイ・パン・アロ・クエスチョニングの種類と対象範囲は維持します（クエスチョニングの求愛による変化は従来どおり）。NBの個体はNBのまま、プロフィールに体の変化を添えます。

今の恋人や夫婦はその場で解消しません。双方の対象が合わなくなれば、従来の「すれちがい」と話し合って仲直りする仕組みへ進みます。対象や相手の恋愛タイプは書き換えません。性転換は年表にも残り、ゲームやムービー中のお知らせはホームへ戻ってから表示します。旧セーブですでにメスの個体をオスへ戻すことはありません。

### あそぶ

ミニゲームは100種類あります。地域・季節向けのゲームもすべて候補に入り、現在の地域や季節に合うもの、まだあまり遊んでいないものは出やすくなります。同じジャンルの連続を減らす選び方も入っています。

「あそぶ」でランダムにすぐ始まります。「メニュー」→「ゲームを選ぶ」で、遊んだゲームの記録を確認して選べます。100種類という数字は登録数であり、すべての端末で操作感・描画まで確認済みという意味ではありません。

ミニゲームの操作はスマホ向けに作り直してあります。上下左右の方向ボタンは原則なくし、ゲーム画面の下に薄い「タッチパッド」を置きました。パッドは MacBook のトラックパッドと同じ「指を置いてからの移動量」で動きます。指がパッドの端に着いたら、離して好きな場所に置き直し、また同じ方向になぞれば進み続けます(置き直しただけでは動きません)。パッドの種類はゲームごとに選んでいます: 1マスずつ動くゲーム(スネーク・2048・フロッガー・倉庫番・ローグライク・ドットイーター)は「なぞった向きが決まった瞬間に1マス(指を離すのを待たない)。短いフリックでも1マス、右→上と続けてなぞれば離さずに2回入力、同じ向きに1回のフリックで2マス進むことはない」、飛行・シューティング系(リングフライト・潜水艦・ハンググライダー・スカイシューター・いんせきガンナー)は「なぞった分だけ動く」(パッドの端に指を当てたまま押し続けると、ゆっくり加速しながら動き続け、少し戻すか離すと止まる)、押しっぱなし系(ボクセルマイニング・ボンバー・戦車・陣取り・かたむき迷路・ジャンプクエスト・かくとう)は「なぞった向きに、指を離すまで動き続ける」(向きは指を動かした分から決まり、指を止める時のぶれでは変わりません。ボクセル・ボンバー・戦車・陣取りは上下左右のどれかにそろえます)、ハンドル系(3Dレース・グランプリ・ダウンヒル・野球・テニス・ボウリング・月面着陸・着陸)は「なぞっている間だけその向き」です。3Dダンジョン・お化け屋敷は横で向きを変え、上で進みます。ブロックパズル・連鎖パズルは横になぞって移動、下で速く落とし、タップで回転。レーン系(ロード・宇宙・ハイウェイ)はパッドを左右にフリック(画面の左・中・右タップも可)。対象をタップ・スワイプするゲーム(魚釣り・アーチェリー・釣り・ゴルフ・ビリヤード・パズル各種など)は直接タッチのままです。残したボタンは アクセル・ジャンプ・スイング・うつ・ばくだん・回転・一気に落とす・パンチ/キック/ガード など、そのゲームに必要なものだけです。方向ボタンがなくなった分、ゲーム画面は縦に最大1.5〜1.9倍まで広がります(空いた高さに合わせて自動)。パッド操作中はページがスクロールしません。

難易度は「ちょっと頑張れば成功できる」を中心に合わせています(2026-09-17の総点検)。狙いを定めるゲームでは、**入力のうち成功する範囲がレンジの中央に来るように**パラメータを組み直しました。たとえばバスケ3Dは「はらう強さ＝飛ぶ距離」にして落下点の輪を出し(成功範囲 約5%→33%、しかも“ふつうの払い”がちょうどリングの強さになるように合わせました)、カーリングは強さを指の速さではなくスワイプの長さにして止まる位置を●で表示、ひこうき着陸は緑のガイドが加点ゾーンの中央を指し降下角も機速から逆算するので「線のとおりに飛べば正解」になりました。ロードラン系はアイテムの間隔を広げて反射ゲームから判断ゲームにし、1回ぶつかっても挽回できる配点に変えています。アーチェリーの照準とたこやきの焼き加減ゲージは、表示と実際の判定が食い違っていたのを一致させました。くわしい点検結果は `docs/qa/minigame-difficulty-audit-2026-09-17.md` にあります。

そのうえで「難しさ」ではなく「遊んで楽しいか」でもう一度見なおしました(`docs/qa/minigame-fun-audit-2026-09-17.md`)。ひこうき着陸は、①何もしなくても緑の線のとおりに▲へ着陸できる ②風で流されるぶんを直すと「ライン」点が伸びる ③接地の直前に機首を上げるとふわっと浮いて◎まで届き「ふわっと」点が跳ねる、という3段階にして、着陸時に内訳（ちゅうしん／ふわっと／ライン）を表示するようにしました(でたらめ操作68点→27点、無操作45〜52点、ちゃんと操縦すると90点)。カーリングのガイドは石のカーブまでそのまま描くようにして、見た場所と実際の止まる位置が1px未満で一致します。ぴょんぴょんジャンプは1回踏み外しただけで2秒で終わっていたので、1回だけ助けるようにしました。

「メニュー」→「クイック」(または「ゲームをえらぶ」の上のカード)で、通常のミニゲームとは別系統の「クイックモード」が遊べます。「たべろ!」「よけろ!」「つかまえろ!」などの短い指示が文字と声で出て、その瞬間からゲームが始まり、1つ3〜5秒で○か✕が決まって、すぐ次の別のゲームに移ります。1ランは20ゲームで、3回しっぱいすると終わり。4ゲームごとにレベルが上がり、制限時間が7%ずつ短く、動きが14%ずつ速く、対象が増え、レベル3からはフェイント(「ぎゃくへ!」「みどりでおせ!」の黄色い点滅、おとりのうんちなど)が入ります。操作はタップ・連打・スワイプ・ドラッグ・押して離す・短い移動・「さわらない」だけで、説明を読まなくても分かる設計です。題材はごはん・うんち・なかま・こいびと・くすり・へんしん・季節・ずかん・おせわ・じゃれる・だっこ・たんじょうび・おべんとう・おばけ屋敷・もぐらたたきと、既存ミニゲームのモチーフ(たこやき・ジャンプクエスト・スキージャンプ・しゅうかく・ダウンヒル・バスケ・フルーツ・ミサイル)で、全50本。1つできるごとに5点(20こで100点)です。げんきを使わず、おせわ・せいちょう・関係などの育成パラメータを変えない独立モードで、混合ランの20/20完走だけ100コインをもらえます。未完走・途中終了・1本ずつのモードは0コイン。スターバッジは掛かりません。自己ベスト・ランク・実績は残ります。カードの「1本ずつえらぶ」を開くと50本の一覧が出て、好きな1本だけを10回くりかえす遊びかた(2回ごとにレベルが上がり、1つ10点)もでき、1本ごとの最高記録が残ります。声は「せかい」→「おと」の「クイックモードの こえ」で、よみあげ(ブラウザの読み上げ、初期値。「たべろっ!」のように語尾を切った掛け声にし、短い言葉は1.22倍・長い言葉は1.36倍の話速で1秒以内に言い切ります。読み上げ中はBGMと効果音を下げて言葉を聞き取りやすくします)・ぴこぴこ(音のつぶで話す、ことばなし)・こえなし から選べます。じっせきには「クイックのたつじん(10こ)」「クイックパーフェクト(20こ)」があります。

そのゲームを3回遊ぶまでは、動き出す前に絵文字・名前・ジャンル・説明・そうさを1枚のカードで見せ、「▶ はじめる」で始まります(4回目からはすぐ始まります)。ゲーム中はいちばん下の「？そうさ」で、いつでも説明と指の動きのデモを見られます(ゲームは止まりません)。アクセルやジャンプなどのメインボタンは右に大きく、◀▶は左にまとめてあり、片方の指で押しながらもう片方で操作できます。カードの「そうさ」には、そのゲームの指の動き(タップ / スワイプ / ドラッグ / おしっぱなし / ◀▶ボタン)を小さなアニメで見せます。

### せかい(じかん・てんき・きせつ・ばしょ)

世界の4要素は「じかん → てんき → きせつ → ばしょ」の順で表示します。短い周期・小さな環境変化から、より長い周期・大きな世界へ広がる、という意味で、今後のカードゲームのカード裏面も同じ順序・概念に揃えます。場所を選ぶ操作は、背景世界を変える独立した「たび」のままです。

「メニュー」→「せかい」で、時間・天気・季節を自動か手動で選べます。自動の天気は、おうちでは取得できた現在地の天気、旅先では地域の気候と季節から3時間ごとに予想した天気を使います（「はれ(よそう)」など）。ジャングルや砂漠は、冬でも雪の予想にはなりません。

じかん・てんき・きせつ・ばしょにはそれぞれ固有の効果があり、「せかい」画面の「いまの せかい」カードで確認できます。たとえば はれ は きげんが下がりにくく、あめ は きげんが下がりやすく なかまとの出会いが減り、よる は ねると回復が早い、もり は なかまに出会いやすい、など（自然減・ねむりの回復・あそぶ疲れ・出会いやすさに影響します。ゲームのコイン額は変わりません）。ミニゲームの出やすさも変わり、あめ の日は パズル・ボード、はれ は スポーツ・3D、よる は パズル、うみ は スポーツ、さばく は のりもの が出やすくなります(「いまの せかい」に ↑↓ で表示)。

ホーム画面には あめ・ゆき・くも・ひざし・よるの星と月 の演出と、あさ・ゆう・よる の色合いがかかります(ゲーム中とメニュー中は消えます)。ときどき てんきや じかんにちなんだ小さな できごと(にじを見つけた、ゆきだるまを作った、ながれぼしに おねがい…)が起こり、きげん・げんきが少し動きます。てんき・じかんにまつわる じっせき も6つ増えました。

「かわ・みずうみ」の表示名は「みずべ」になりました。訪問歴や過去の思い出は引き継ぎます。山では岩を選んでタイミングよくつかむ「岩場のぼり」、雪国ではスキーやスノーボードを楽しめます。全100ゲームは、どの地域でも遊べます。

大画面の景色は場所ごとに構図を分けています。とかいは高層ビルと交差点、夜はネオン街。おうちはソファやラグのある室内で、雨や雪は部屋の中に降りません。いなかは田畑、ジャングルは大きな熱帯植物と滝、みずべは湖と桟橋です。

「たび」→「📍げんざいち」で、位置情報を許可すると市区町村に応じた街のイメージを表示します。函館市は港町、飯田市は山あい、大阪市（各区を含む）と東京都の23区は都会、それ以外は一般的なまちなかです。実在の街並みをそのまま再現するものではありません。選んだ景色は再読み込み後も残り、「せかい」から現在地を調べ直せます。「おうち」を選ぶと室内に戻ります。

雪国は睡眠で回復しやすく遊ぶ疲れも少なめ、ジャングルは仲間との出会いが多めです。それぞれ少しおなかがすきやすく、詳しい効果は旅先カードで確認できます。

そだちを1あげるのに必要な「せいちょう」は 8→10→14→20→26→32→40 と上がり、そだち20→70で680、20→100で1,660です(100分の一生で高得点を重ねれば届く量)。通常ミニゲームでSランクを取ると2分のあいだ、せいちょうが2倍になります（画面上に ✨2ばい の印、最大10分まで重なります。その日のチャレンジ達成回とクイックは対象外）。ふかふかまくらを装備して「ねる」を押すと、すぐげんきが100になり、通常の睡眠状態は続きます。「ねる」の回復は 0→100 で約5秒です(病気のときは約8秒)。90さい台は お世話が行き届いていても老いのリスクがわずかに上回ることがあり、そだちが高いほど守られます。たべすぎは おとろえ+4・15%で病気(以前の半分)です。

### むずかしさとおと

「メニュー」→「せかい」の「ゲームの むずかしさ」で、やさしい・ふつう・むずかしいを選べます。年齢で上がる難しさの伸びを やさしい0.4倍・ふつう0.7倍・むずかしい1倍に抑え、制限時間は やさしいだけ+20% 長くなります(ふつう・むずかしいはそのまま)。「ゲームの ながさ」を みじかめ にすると、90秒以上の長いゲーム(タワーディフェンス、ローグライクなど)が6割の長さで終わります。かくとうバトルは連打対策として、続けざまの攻撃は威力が落ちて隙が大きくなり、3連続ヒット以降はスタンしなくなり、相手はガード後に反撃してきます。たこやきの焼き加減の幅、ルナランダーの着陸判定、ドットイーターのライフも やさしいで ゆるくなります。はじめの設定は「ふつう」です。

### デート

ムービーの発言には、小さなキャラの絵と名前が付きます。一つの字幕では一人が話し、情景の説明には話者を付けません。デートの小話は通常40本・深海20本、恋人18体の固有の掛け合いは各3本、伝説の出会いは各4本。同じ小話は、ゲームを開いている間は一巡するまで繰り返さず選びます。通常デートは約25秒で、途中でスキップできます。

デート・結婚記念日・伝説の出会いのムービーは、ブラウザの表示領域いっぱいに流れます。背景がゆっくり近づき、星・雨・光・泡と、字幕に合わせたキャラクターの動きが入ります。深海では水中の景色になります。字幕と「スキップ」「おもいでにしまう」は画面内に固定し、再生中は育成時間が止まります。端末の「動きを減らす」設定では、静止画と場面の切り替えで同じ物語を見られます。

「としをとったじぶん」は、森の水たまりに同じ種族の老年期の姿が映る場面です。水面に波紋が広がり、未来の顔が消える物語と、今の顔に戻る物語があります。この演出で、育てている子の年齢・姿・性別・恋愛関係が変わることはありません。

### めぐる(いまいる地域を歩いて、みんなに会いにいく)

たびの画面のいちばん上に「○○をめぐる」(げんざいちのときは「げんざいち(まちなど)をめぐる」)の入口があり、いまいる地域の中を自由に歩ける「めぐる」画面に切り替わります(ホームの 3×3 ボタンは増えません)。探索画面が主役で、ヘッダー・ヒント・パッド以外の高さはすべて探索エリアに使い、iPhone の縦画面でも見切れません。下のパッドをなぞると歩き、奥行きのある見た目(ミニゲームと同じ canvas の擬似 3D。地平線は画面の上から 3 割で、地面・こみち・スポットが 7 割)で、遠景(地域ごとのシルエット: 森の木立、都会のビル、山なみ、海の水平線、砂丘、星空の停留所…)・中景(木や建物などの大きな物とスポットの目印)・手前(こみちのわきの小物と地面の草・小石・きらめき)の 3 層で地域らしさを出しています。ほしぞらのていりゅうじょは、星雲と流れ星のある空、光るこみち、提灯とベンチ、宇宙に浮かぶ足場、遠くの停留所の灯りで「停留所」と分かる場所になっています。じかん・てんき・きせつは本編と同じものが反映され、夜は暗く、雨や雪は降ります。

地域ごとに景色・色・光・地面・建造物・植物・密度・見通しが大きく変わり、切りかえた瞬間にどこへ来たのか分かるようにしています(とかいはネオンの繁華街、もりは木もれびと苔の深い森、ジャングルは葉が迫る密林と遺跡、さばくは巨大な岩山と砂紋、しんかいは光るサンゴと海溝、ゆきぐには夜のオーロラ、うみは歩くすぐ横が波打ちぎわ、かわは川が流れ、ほしぞらは浮島、きおくのみずうみは霧のヴェール)。地面は「世界のマス目」から見えている分だけ作るので、どこに立っても草・落ち葉・砂紋・舗装の目地などで埋まり、大きな空白になりません。

地域と地区には「そこで何が動くか」があります。地域ごとに風のつよさとはやさが決まっていて、地区ごとに落ち葉・雪・砂の筋・もやの層・水面のきらめき・のぼる光の粒・ネオンのまたたきのどれかが流れます(落ち葉の色はきせつで変わります)。草木は足もとを止めたまま上だけが風になびき、木のいちでずれるので「風が渡っていく」ように見えます。あかりはゆっくり明滅します。つぶの数は端末の重さに合わせて減りますが、いちばん軽い設定でも止まりません。生きもの(とり・さかな・むし)は景色としては出しません。

空・遠景のシルエット・手前のかぶさりは、はっきり違う量で流れます(横に歩くと手前ほど大きく動き、空はほとんど動きません)。ワールドの物はこれまでどおり正しい位置に描かれるので、場所のつじつまは崩れません。カメラは歩くとごく小さく上下し、速く歩くとすこし引き、広い地区では引いて狭い地区では寄り、近くのランドマークへ視線がすこしだけ向きます。どれも数%までで、大きな揺れ・急なズーム・自動回転はしません(「動きをへらす」設定のときはこの演出だけ止まります)。カメラと自分のあいだに入って**自分を隠している**ものだけがすこし透け、隣のものは巻きこまれません。近づいただけでは透けず、透けても濃さは残ります。

大事にしているのは小物の数ではなく「何の上を、何に囲まれて歩いているか」です。地面そのものが地域で変わり(田んぼの水面、車道と歩道と横断歩道、雪原と凍った湖、濡れ砂と砂丘、海底の亀裂、下草と根、がれ場、浮いた石畳…)、道の両側は自分よりずっと大きなもの(ビルの壁、岩壁、巨大な幹、雪の土手、砂丘、サンゴの壁、生垣、木の柵)が囲み、手前を枝・巨大な葉・葦・稲穂・雲などが横切ります。これらは canvas で描く造形物なので、住民の絵とは混ざりません。

造形は「細部より形」で作っています(2026-09-17 の 13 地域横断監査)。大木は板根と曲がる幹と枝、ビルは本体と入口と窓の帯とひさし、崖はふぞろいな輪郭と層、砂丘はゆるい曲線の重なりと風下の陰、雪の丘は青い影、深海のサンゴの壁は明るい岩と光る縁、というように、単純な長方形や三角形をそのまま完成形にしません。遠くの造形物は半透明にせず、色を霧の色へ寄せる空気遠近で描くので、重なった地形がガラスの板に見えることがなくなりました。地面は草や落ち葉の記号を撒くのではなく、苔のまとまり・落ち葉のたまり・湿った面と、海岸線に沿う濡れ砂の帯で「地形」として読めるようにし、🌊 や ⭐ のような素材のイラストを大きな目印には使いません(氷柱・クリスタル・畑・門などの canvas 造形に置きかえ、海そのものが主役の場所には置きません)。同じ地域の中でも地区ごとに囲うもの・生えているもの・主役(キノコの森の光るキノコの群れ、オアシスの水、深海の光の庭、星空のクリスタルの庭など)が変わります。世界のデータは `worldLayers(world)` で terrain / water / road / building / vegetation / landmark / obstacle / light に分けて読めるので、将来 Three.js で描くときも同じ世界設計をそのまま使えます。監査の全表と「疑似3Dで直すもの／3D化まで待つもの」の分類は `docs/qa/meguru-visual-audit-2026-09-17.md` にあります。

通れるもの・通れないものは、絵の四角ではなく「地面についているところ」で決めています(2026-09-19 のあたりはんてい横断監査)。木は幹だけ(絵の幅の 1〜2 割)、家やビルや遺跡の壁は建物本体、柵は道に沿った細い線、岩やサンゴは接地面、大きな目印は根もとだけ、というように形ごとに円か向きつきの箱を持たせています。だから葉っぱに触れただけで止まることはなく、灯台や大木にはすぐ足もとまで近づいて見上げられます。草・花・落ち葉・小さなきのこ・地面の模様・砂のうねり・浮かぶ雲・光の演出はすべてすり抜けられ、橋と桟橋も当然わたれます(以前は雲や草にも当たり判定があり、逆に大木やビルは半径 44 の小さな丸しかなくてすり抜けて見えていました)。斜めにぶつかったときは壁に沿ってすべるので、スマホのパッドでも角に引っかかりません。形は canvas のピクセルではなくワールド座標で持っているので、住民の歩きも同じ判定を通りますし、将来 Three.js で描くときもそのまま使えます(`worldLayers(world).obstacle` が shape / hw / hd / ang / role を返します)。role は solid(かたい)・water(景色の水たまり)・boundary(崖や砂丘など世界のふち)の 3 つです。

道をふさがないことはデータの側で保証しています。当たり判定を作るときに、道の通行帯(道幅 + 26)とスポットの中心に食いこむ分は自動で縮め、縮めても小さすぎるものは置きません。13 地域 652 本すべての道の中心線と 469 スポットの中心に当たり判定がないことと、実際に歩いて 469 スポット(うち隠し 50)すべてに行けることをテストで確認しています。水については、海(海岸線の外)だけが入れない水で、これは以前から横幅の制限で止めています。川・湖・滝つぼ・潮だまり・海底・海溝は道が渡っている設計なので、これまでどおり歩けます(景色の温泉・オアシス・岩の水たまりだけは role=water の当たり判定で よけて歩きます)。計算は 360 のマス目に分けて周りのマスだけを見るので、景色が 8805 個あっても 1 フレームの計算はマス 1 つ分(平均 2〜5 個)で済み、世界を広げても重くなりません。

地域の中は一本道ではなく、いくつかの「地区(zone)」に分かれた広い地図です(通常地域で 34〜50 スポット・9〜11 地区、おうちは 14 スポットでコンパクト、きおくのみずうみは狭くて深い)。13 地域あわせて 118 地区・469 スポット・652 本の道があり、ひとつの地域を一通り歩くのに 2〜4 分ほどかかります(おうちだけは 40 秒)。地区ごとに明るさ・霧・地面の色・木立の密度が変わり、歩く位置でなめらかに混ざるので、森なら「明るい森 → 似たような木立 → キノコの森 → 深い森 → 大木のまわり」と奥へ行くほど景色が変わります。地域ごとに「広さの種類」そのものが違います: もりは迷路型(明るい森・小川・似た木立・しだのくぼ地・キノコの森・深い森・石の森・大木・滝の谷・古い森・森の奥の奥の 11 地区)、とかいは街区ネットワーク型(駅前・商店街・市場通り・公園・路地裏・川沿い・オフィス街・住宅街・高台・時計塔)、いなかは広い平面型(村・畑・果樹園・草原・川沿い・棚田・となりの集落・丘・鎮守の森・村のはずれ)、やまはふもとから山頂までの長い登山型(ふもと・山の集落・山道・谷あい・キャンプ・滝道・尾根・山の湖・岩塊の道・頂上)、ゆきぐには広大な雪原型(雪原・ロッジ・松林・凍った湖・雪の温泉・ゲレンデ・吹雪の原・雪山)、うみは長い海岸線型(砂浜・潮だまり・桟橋・入り江・岩場・港・砂丘・岬・海食洞窟・はての浜)、しんかいは深くなるほど暗くなる迷宮型(浅瀬の棚・サンゴの町・昆布の森・沈没船・光る深場・海底の遺跡・熱水孔・海溝・深い闇)、かわ・みずうみは川をさかのぼる型(川岸・橋・葦原・湿地・川の狭いところ・川の滝・上流・湖・中の島)、ジャングルは複数ルート型(入口から蔓の道／木の上／遺跡の 3 方向へ分かれ、川・滝・沼・洞窟・花の谷を経て奥の奥へ)、さばくは 13 地域でいちばん広大(砂山・岩の谷・オアシス・キャラバン・メサ・遺跡・塩の平地・砂の海・骨の谷間・さばくのはて)、ほしぞらのていりゅうじょは浮島ネットワーク型(停留所から西・東・雲の回廊へ分かれ、星の畑・古い浮島・月の島を経て空のはてへ)、きおくのみずうみは面積ではなく奥行き型(ほとり・葦原・霧のなか・ともしびの道・湖の奥・湖の底で、最後の 3 つはすべて隠し道)、おうちは生活圏として少しだけ広げています(となりの小道と裏の畑が増えただけ)。分岐は道の縁の踏み跡や石、三叉路の標識、道幅の違いで景色から分かります。隠し道の入口には花・足跡・小さな光などの「誘い」があり、遮蔽物に隠れても自分の足元に輪が出て見失いません。道はスポット同士を結ぶ帯として描かれ、道を外れると草むらや砂の上で少し遅くなります。道の両わきには木・建物・岩・雲などの遮蔽物が並び、曲がった先や木の向こうは行ってみるまで見えません。カメラは歩く向きと道の向きにゆっくり合わせて首を振るので、左の道へ入ると左を向いた景色になります(パッドの上は「いま見ている方向へ進む」、左右は「曲がる」)。広場では少し引き、狭い道では寄り、見晴らし台では遠くまで見えるようにカメラが変わります。めじるしは大・中・小の 3 階層です。大は遠くからでも見えて地域の方角が分かるもの(森の大木と滝、都会の時計塔、海の灯台、深海の巨大サンゴ、雪国のロッジと雪山、砂漠のオアシスとピラミッド、星の停留所の大きな標識、田舎の風車と大木…)、中は地区ごとに 1 つだけ置く「場所を覚える手掛かり」(森なら小さな泉・木の橋・積み石・倒木・光るキノコの群れ・古い道しるべ・石積み・滝・切り株・苔のくぼ地、都会なら駅のネオン・商店の軒先・赤ちょうちん・公園の銅像・路地の自販機・川の桟橋・ビルの噴水・大きな一軒家・望遠鏡)、小は分かれ道や隠し道の目印です。名前表示を読まなくても「前に来た場所だ」と景色で分かるように、同じ造形は 1 つの地域に 1 か所しか置いていません。各地域には初めて入ったスポットには「○○を みつけた」と出ます(発見済みスポットは地域ごとにセーブされ、隠し場所は見つけるまで地図データに載りません。地図の画面は今後の予定です)。

探索画面の右下に小さな「🗺 ちず」があり、押すと**歩いた結果として少しずつ完成していく地図**が全画面で開きます(常時ミニマップは出しません)。地図は攻略情報ではなく「自分が歩いた世界の記録」なので、初めて入った地域では紙の余白と地域の枠しかありません。地区に入るとその地区が紙に描かれ、実際に歩いた道が線になり、立ち寄ったスポットに名前が載り、見つけた目印が残ります。まだ行っていない地区は、ふつうの道でつながっているものだけがぼんやりした影で出て(秘密の道でしかつながっていない地区は出ません)、道もスポットも名前も分かりません。**見つけていない秘密の場所は、位置も名前も道も「？」マークも一切出しません**。見つけた瞬間にひし形の印で地図へ加わります。目印は大・中・小の3階層で、大(森の大木、海の灯台、都会の時計塔…)は遠くから見えた時点で星として載り方角の手がかりになります。中(地区の主役)はその地区に入ってから、小(分岐や隠し道の印)はそのスポットを見つけてから出ます。地面の色・海岸線・川の流れは世界データから作るので、森は緑の迷路、都会は街区、海は海岸線、しんかいは暗い海底、ほしぞらは浮島、と地図を見ただけで地域の構造が分かります(地図専用の手書きデータはありません)。いまいる場所は小さな矢印で向きつきで出ます。地図はドラッグで動かし、＋／−で3.2倍まで拡大できます(拡大すると細かいスポット名も出ます。タップしても名前が出ます)。上には「たんさく ○○% ・ ○／○ ちく」が出ますが、この計算に未発見の秘密は入らないので、残りの秘密の数は逆算できません。地図を開いているあいだ探索は止まり、「もどる」で同じ場所から続きます。地図は開いたときだけ作って閉じると捨てるので、歩いているあいだの fps には何も足しません。歩いた記録は zone / path / spot / landmark の id だけを保存し、歩いた座標は残しません。地図を足す前のセーブは、すでに見つけたスポットから安全に組みなおすので「全部未発見に戻る」ことはありません。

**その地域地図の下のボタン列に「🌍 せかい」があり、押すと「なおとっちのせかい」の世界地図に切り替わります**(**なおとっち世界 地理正本 v1** ＋ 世界地図 Phase 1)。13 地域は独立したステージではなく、**一つの世界の各地方**です。世界の中心は**二つの大きな山地に挟まれた細長い谷**で、その谷に**おうち**があります(谷底ではなく、川を見下ろす段丘の上です)。**おうちのすぐ東を大きな川が北から南へ流れ**、そのさらに東には**歩けない巨大な山地**がそびえています。おうちから**西〜南西へ進むと森がだんだん濃くなって もり**になり、**その先に いなか**(田畑・果樹園・棚田・鎮守の森のある山里)があって、**その山の上から ほしぞらのていりゅうじょ**へ入れます(もりを通らなくても いなかへは行けます)。ほしぞらへの道はふつうの徒歩の道ではありません。いなかの奥の**ちんじゅのもり**から**ふるいとりい**をくぐり(ここから先は山の領域です)、**森の山道**をすこし登って、開けた**山麓の乗り場**から**ゴンドラ**で上空へ上がります(鳥居は実在の施設ではなく、日常の世界と特別な世界の境界を表すなおとっち独自のものです。山道・乗り場・ゴンドラの実装は次の段階です)。谷には**大きな川**が流れていて、**かわ・みずうみ**がその水辺です。この川は南へ下って太平洋へ向かい、**都会や湾へは流れません**。いなかの奥の**峠(分水界)を越えると水の流れる方向が変わり**、**その向こう側から別の川がはじまって**、その流域に**とかい**があります(いなかから流れ出すのではありません)。とかいの川は**港から湾**へ出て、湾の外は**外洋**、そのさらに**下に しんかい**があります。きおくのみずうみだけは世界地図のどこにもありません(地上の座標を持たない「記憶」の層です)。世界の山は 3 つで、**西は歩ける山地**(その代表が やま、その南の尾根ぞいに広がる大森林が もり)、**東はもっと大きな歩けない山地**(地域ではなく地形なので、谷に立つと見えます)、そして**やまよりさらに北の高地が ゆきぐに**です(北へ行くほど高く雪深くなります)。谷の大河のいちばん上流には**大きな源の湖**があり、いなかの奥の峠には**分水界**があって、ここを境に水の流れる向きが変わります。世界の**北西は風と砂の世界(さばく)、南西は南国の森(ジャングル)**です。

**世界地図も最初から完成していません。**はじめは おうちの周りだけで、あとは紙の余白です(黒塗りにはしません)。地域へ初めて到達するとその地形と名前が描き足され、**山地・川・海岸線も見つけた地域のぶんだけ延びます**。地域と地域をつなぐ道は**両側の入口となる場所を両方とも見つけたときだけ**線になります。「その地域へ行ったことがある」だけでは道は 1 本も開きません。見つけた大きな目印(tier 1)は小さな星として残ります。**未発見の地域は正確な輪郭も名前も出さず、未発見の特殊層は存在すら出しません**。世界地図には 469 のスポットも道も住民も出さず、細かい記録は地域地図の役目のままです。世界地図から発見済みの地域をタップするとその地域地図を読めますが、そこへワープはしません(地域の移動はこれまでどおり「たび」です)。上には「せかい ○○% ・ ○／11 ちほう」が出ます。この計算は「地域・主要な道・大きな目印・地区」の 4 つだけで、秘密の場所と秘密の道は分母に入っていないので、**秘密を 1 つも見つけなくても、ほしぞらや きおくのみずうみへ行かなくても 100% にできます**。世界地図の保存は地域と道の id の集合 2 つだけで、座標は残しません。世界地図を足す前のセーブは、訪れたことのある地域から安全に移行します。地域の中の世界(座標・スポット・道・当たり判定・住民の生活)は今回 1 つも変えていません。

ずかんに登録済みのキャラは全員がこの世界のどこかに住んでいます(住むのは現在の正式なずかんにある種だけで、古いセーブに残った旧種族は住民になりません。同じ住民は世界に必ず 1 体です)。住民の数はセーブの進み具合で変わるので、ひとつの数字では言えません。正確には **ずかんの姿の上限 248(31 系統 × 8 段階)− いまの子 1 = 247 体**が台帳の基本で、そこへ**なかま 18・レアなかま 8・こいびと 18** が記録した分だけ加わり、**ナオト**が解禁されるともう 1 体増えます(ずかん全解放・なかま/こいびとなしなら台帳 247 + ナオト 1 = **世界に 248 体**、全部そろうと最大 **292 体**)。いま連れているなかま・こいびとはその数から外れて、同行者として一緒に歩きます。景色の絵文字(木・きのこ・看板など)は住民の画像には変換されず、話しかけることも名前が出ることもありません。景色としてランダムに何度も置かれる小物(道ばた・壁・誘い・地区ごとの小物)には鳥・魚・哺乳類・爬虫類・虫の絵文字を入れない方針で、画面上で「生きている生き物」に見えるものは住民台帳(ずかんのキャラ・なかま・レアなかま・こいびと・ナオト)由来だけです(草木・花・きのこ・サンゴ・貝がらは景色として使います。「ねこのばしょ」「ぼくじょう」「ラクダのみずば」のような場所の目印は 🐾 や 🪧 の看板で表します)。なかま・レアなかま・こいびとと同じ絵文字も同様にランダム景色には使いません(雪国の ⛄ は こいびと「とけないゆきだるま」なので景色から外し、「ゆきだるまのおか」には 🧣 のマフラーだけが残っています。植物・天気の 🌻 🌵 ❄️ と、ジャングルの遺跡に 1 つだけ立つ石像 🗿 は景色として許容)。しゅぞくの 8 つの すがた は 1 つずつ別の住民として数え、生態に合う地域(ペンギンは雪・海、カブトムシは森・ジャングル、アリジゴクは砂漠…)に定住しています(サケのように育つと住みかが変わる種は段階ごとに地域が変わります)。なかま・レアなかまは「旅人」で、日替わりでどこかの通常地域へ遊びに行きます(好む地域があればそこへ出やすく、同じ日のうちは何度入っても同じ地域)。こいびと候補は初めて出会った地域に住みます。ランダムに何体かだけ出るのではなく、探せば全員に会えます。住民は地域が広くなっても増やしません(ずかんの数のまま)。かわりに「にぎやかな地区」へ寄せていて、広場や店前・水辺は以前と同じ密度のまま、奥の地区はほとんど無人になります(地区ごとの にぎやかさ と スポットごとの crowd の差を強調して配っています)。静かな小道には 0〜1 体、隠し場所には 1 体だけがいます。いまの子は自分自身として歩き、いま連れているなかま・こいびとは同じ個体として少し後ろ・横をついてきます(二重には出ず、自分を隠しません)。入った瞬間に入口のひろばに 2〜4 体がいて、近くの住民には名前が出ます。同時に描く数に上限はありますが、自分・同行中のなかま・こいびと・話しかけられる距離の住民は背景の小物より優先して必ず描かれます。住民は歩く・座る・ながめる・寝る・釣る・遊ぶ・おしゃべり・数体で集まる・追いかけっこ・店を見るなどをしていて(広場では集まりやすく、水辺では釣り、ベンチでは座り、見晴らし台では景色を見ています)、夜や雨で行動が変わります。キャラは向き(heading)を持ち、左右へ歩くと反転して少し傾き、奥へ歩くと揺れが小さく、座る・寝る・話すで姿勢が変わります(将来、横向き・後ろ向きの画像を足せる構造です)。遠くの住民は小さなシルエットで描かれ、賑やかな場所では一画面に数体〜十体ほどの気配が見えます。ヘッダーには「この地域に住んでいる数(○○たい)」と「今回近くで会った数(であった ○)」が出ます。近づくと「はなす」が押せて、そのキャラらしいひとことが吹き出しで出ます(会った人数は「であった n／m」に出ます)。

住民は「置かれている」のではなく「そこで暮らして」います(2026-09-19 のめぐる住民生活 v1)。住民は **behavior**(いま なにを しているか: あるく・たたずむ・ながめる・やすむ・すわる・ねむる・はなす・あつまる・あそぶ・つりをする・店を見る)と **emotion**(どう感じているか)を別々に持ち、どちらも絵ではなくシミュレーションの状態です。行動は「やりたいことを決める → それができる近くのスポットを選ぶ → 道をつたって歩く → しばらくそれをする → 次」という流れで生まれるので、左へ行って右へ行くだけの動きにはなりません。

**どこで何ができるか(activity)はスポットが持っています**。469 スポットすべてに手で書いたのではなく、スポットの種類(ひろば・休憩・屋根の下・水辺・見晴らし・木立・お店・こみち)と目印から決めています。ひろばは集まる・話す・遊ぶ、ベンチや休憩場所は座る・休む、水辺は眺める・休む・釣る、見晴らし台は眺める、お店は見る・集まる、森の奥は歩く・眺める・ひとりで休む。**座れる場所がないのに座ったり、道の真ん中で寝たりはしません**(座れるのは 221 スポット、眠れるのは 175 スポット、屋根があるのは 54 スポット)。隠し場所では集まりも立ち話も起きません。この「ここで何ができるか」はスポット側のデータなので、将来おみせ・住民の家・釣り場などを足すときも、住民 AI とプレイヤーの遊びの両方が同じものを読みます。

**13 地域は同じ AI パラメータではありません**。地域ごとに「人といる／ひとりで過ごす／歩く／眺める」の重みが違い、そこに地区ごとの にぎやかさ(crowd)がかかります。とかいは立ち話と集まりが多く、いなかは少人数でのんびり、もりは歩いて一人で眺めて たまに誰かと会い、うみは眺める・遊ぶ・小さな集まり、しんかいとさばくの奥とほしぞらは静かに眺める、**きおくのみずうみはほとんど一人で過ごします**(10 分見ていて立ち話が 1 組、集まりは 0 組)。奥地は生活 AI を入れても賑やかになりません。時間帯でも変わり、朝は歩きだす人が多く、昼は話す・集まる・遊ぶ、夕方は眺める・休む、夜は休む・眠る(夜の睡眠は昼の 10 倍以上)。雨・雪では屋根のある場所へ寄りますが(屋根の下が 2 割 → 4 割)、全員が消えることはなく、雨を眺めている住民も残ります。季節も軽くかかります。**行動を始める時刻・行動の長さ・歩く距離・集まりやすさ・好きな過ごし方は住民ごとにずれている**ので、全員が同じ瞬間に立ち止まったり歩きだしたりはしません。

**出会いは「離れたところで急に会話状態になる」のではなく、近づいて向き合ってから始まります**。話しかけたい住民は近くの相手を探して予約し(1 人に 2 人以上が同時に申し込むことはありません)、互いに歩みより、適切な距離で止まり、向き合って話し、しばらくして自然に解散します。集まりも同じで、同じ場所へそれぞれ歩いてきて、重ならないよう少し離れて立ち、輪の中心を見ます。**集まりは 2〜3 体が中心で、ひろばでも最大 4〜5 体まで**です。住民全員が常に誰かといる必要はなく、たたずむ・歩く・眺める・休むが大半で、たまに出会いが起きるくらいにしてあります。

**遠くの住民は毎フレーム動かしません**。近く(1600)は最大 48 体まで毎フレーム、その外(4200)は 6 フレームに 1 回、それより遠い住民は「次に動く時刻」だけを持ち、毎フレーム 12 体ずつ順番に次の行動へ進めます。**探索距離が伸びても 1 フレームの計算は増えません**。生活 AI を足したことで増えた 1 フレームの計算は、13 地域平均で 0.015ms(16.7ms の予算に対して 0.09%)です。離れているあいだも世界は少しずつ進むので、戻ってくると別のスポットにいたり、休んでいたり、誰かと話していたりします(秒単位の完全な計算はしません)。戻ってきたときは自然な位置に立ち直すので、見ている前でワープすることはありません。

住民も **#294 のワールド座標の当たり判定**を通るので、大木・建物・壁・柵・岩をすり抜けず、歩けない海にも入りません。住民どうしは固い壁ではなく軽いパーソナルスペースだけなので、群衆が詰まることはありません。**同行中のなかま・こいびとは通常の住民生活から外れ**、これまでどおり同じ個体としてついてきます。解禁済みのナオトは特別な居場所のまま動きません。同じ住民が 2 か所に同時にいることもありません。地図には住民のリアルタイム位置を出しませんし、住民が歩いても地図の未踏の地区・道・秘密の場所が開くことはありません。「はなす」はこれまでどおりで、歩いていても休んでいても話していても、近づけば話しかけられ、話が終わると自然に生活へ戻ります。

**emotion は論理状態だけで、今回は画面に出していません**。名前は制作中の表情の正本に合わせて `normal / happy / tired / sleeping / unhappy / wantsPlay / strained` の 7 つで、お世話の状態(`hungry / sick / weak / critical`)は住民の生活からは出しません。behavior と emotion は独立していて、「はなしているから happy」とは決めていません(同じ talk でも normal・happy・unhappy があります)。表情の絵がそろったら `emotion → 表情カタログ → 住民スプライト` をつなぐだけで見た目が変わり、生活 AI は直さずに済みます。レンダラーは `view().lifeOf(resident)` から behavior / emotion / activity / 目的スポット / 相手 / 層 / げんき を読めます。開発時だけ `sim.lifeDebug = true` で住民の上に behavior と emotion を出せますが、通常の画面には出しません。

画面内の「たび」からそのまま地域を変えられ、通常のたびと同じ処理(げんき消費・たびづかれ・はじめての地域の記録)を通って、その地域の世界に切り替わります。「もどる」(キーボードなら Esc)でホームへ戻ります。めぐっているあいだは本編の時間が止まり(年齢・おなか・ごきげん・げんきが動かず、しぬこともありません)、なかまのさそい・でんせつとの出会い・ひとりごと・おせわの通知もホームに戻るまで出ません。

つくりは「世界(ワールド座標・住民・移動・当たり判定・行動・会話)」と「描画(canvas の擬似 3D)」の 2 層に分かれていて、キャラや小物の位置は画面の px ではなく仮想世界の座標で管理しています。描画は世界の状態を読むだけなので、将来 Three.js などの本物の 3D に置き換えるときも、同じワールドデータとゲームロジックをそのまま使えます。

ナオトは特別な住民で、通常の住民には混ざりません。ずかんコンプリート/パーフェクトのゴール(ホーム画面でナオトが現れる条件と同じ)を達成しているときだけ、きおくのみずうみの奥の隠し場所「みずうみのおく」(霧の小道か積み石の先の細い道でたどり着く)にいつもいて、話しかけると達成状況に応じた専用のことばを言います。未解禁なら世界のどこにも出ません。
