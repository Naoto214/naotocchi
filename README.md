# なおとっち

ブラウザで遊べる、なおとっちの育成ゲームです。ビルド不要、HTML/CSS/JSだけで動きます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ローカルで確認する場合は、リポジトリのルートで以下のように簡易サーバーを立てても構いません。

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。

## ゲームの内容

- 卵がかえるとき、「いぬ・ねこ・とり・おとこのひと・おんなのひと・カブトムシ・クワガタムシ・うさぎ・さかな・りゅう・パンダ・きつね・ふくろう・はな・ロボット・きょうりゅう」の16種族のどれになるかがランダムに決まります。動物だけでなく、はな(植物)やロボットのような種族もいます。あかちゃんの見た目もそのときから種族ごとに違います(たとえば犬なら子犬、女の子なら赤ちゃんの女の子、というように)。
- そこから先の成長(あかちゃん→こども→思春期→若者→おとな→エルダーの8段階)は放っておくだけでは進みません。「進化」メーターが満タンになったときだけ、そのタイミングで確実に1段階変身します。種族ごとに全段階ちがう見た目・せりふが用意されています(例:いぬなら 子犬→よちよちあるく こいぬ→こいぬ→わんぱくいぬ→そとあそび だいすきな いぬ→わかいいぬ→いぬ→としをとった いぬ)。
- 「満腹」「機嫌」「元気」「体力」の4つのステータスを管理します。「満腹」「機嫌」「元気」は なにも しなくても 時間経過で すこしずつ さがっていきますが、なにも 操作しないで 基本がめんを しばらく ながめているだけでも あわてなくて いいよう、余裕を もたせた 下がりかたに 調整してあります。
- 「ねる」ボタンを押すとすいみん状態になり、押した瞬間その場で元気がすこし回復したうえで、そこから毎ティックすばやく回復していきます(待たされる感じをほぼなくしてあります)。びょうき中は回復が少しひかえめです。もういちど「ねる」を押すと起きて、通常どおり時間経過で元気が減っていく状態にもどります。
- 「あそぶ」を押すと、95種類のミニゲームから、全部出きるまで同じものを繰り返さないようにランダムで1つが始まります。結果に応じて機嫌が上がります。内訳は以下のとおりです。

  - RPGふうバトル(3種):スライム・ドラゴン・ゴースト。たたかう/まほう(MP消費)/ぼうぎょ/にげる の4コマンドから じっくり えらぶ、ターン制の HP・MPを もった バトルゲーム。かくとうゲームとは ちがい 時間せいげんが なく、せんりゃくを ねって たたかえる
- 上記のうち「なつかしめいさく風」の9種(コイン&キノコキャッチ・ダンジョンのたからさがし・はてなブロックたたき・ライバルファイターたたき・スマッシュこうげき・ダンジョンのわかれみち・ハートだけタップ・ころがってくる こうらをよける・オールスターたいかい)は、配管工アクション・けんと まの 冒険アクション・にぎやかな かくとうアクションなど、だれもが しっている 名作ジャンルの あそびごこちを モチーフにした オリジナルの オマージュ・ミニゲームです(商標キャラクターの 名まえや 見た目そのものは つかっていません)。
- 反射神経・記憶・計算・注意力系のゲームは大人でも歯ごたえのある脳トレ系で、なおとっちの年齢が上がるほど難易度も上がります(記憶する個数が増える、時間制限が短くなる、判定がシビアになる、など)。ほかのゲームも同様に、育つほどタイミングがシビアになったり展開が速くなったりします。
- おやつキャッチには うんち・ゴキブリ・刃物・銃 などの「わるいもの」も混ざっていて、キャッチすると減点されます。
- マンガ風の質問は40種類・160択(ふつう・シリアス・大人っぽい・馬鹿らしい・ラブロマンス的・感動)を用意していて、全部出きるまで同じ質問は繰り返しません。「感動」は新しく追加した、涙腺にくる系の質問カテゴリです。選択肢を選ぶと、その方向性にあわせた一瞬の演出(ハート・きらめきなど)が入ってから結果が反映されます。
- お世話をさぼる(うんちが溜まる・おなかがすいている・きげんが悪い・体力が低い)と、びょうきになりやすくなります。びょうきには10種類の症状名があり、そのたびに画面とペットの見た目も病気っぽく変化します。くすりで治療できます。
- 放っておくと うんち が溜まったり、びょうきになったりします。びょうきを何度も繰り返していると、そのぶん弱っていき、天国に旅立つまでの時間も短くなります(リセットでやり直せます)。
- 「進化」「退化」「死亡」「変身」の4つのメーターがあります。ごはん・そうじ・ねる・くすり・ミニゲームがうまくいくと「進化」メーターが上がり、たまると必ず1段階変身(成長)します。逆に手入れをさぼったり、ミニゲームに失敗したり、くすりを無駄遣いしたりすると「退化」メーターが上がり、たまると必ず1段階もどってしまいます(種族ラインは変わりません)。年齢の下限は0です。びょうきになったり、体力が0の状態が続いたり、ミニゲームに失敗し続けたりすると「死亡」メーターが上がり、たまると死亡します。成長のスピード自体もかなり速くしてあるので、数分プレイするだけでも進化・退化・死亡がどんどん起こります。逆に、びょうきでなく満腹・機嫌・元気・体力の4つが すべて そこそこ高い(60いじょう)状態を たもてていると、「死亡」メーターが すこしずつ ひとりでに 回復していきます。回復アイテムの うんに たよらなくても、ちゃんと お世話を つづければ じぶんの ちからで 下げられます(ひとつでも 60を きると その瞬間は 回復しません)。これに くわえて、「死亡」メーターは 年齢が 上がるほど なにも なくても わずかに 自然に 上昇していきます(放っておいても メーターが まったく うごかない、という ぬるさを なくす ための しくみです)。この自然じょうしょうぶんは 60いじょうを たもつ回復ぶんより ひかえめな 大きさに おさえてあるので、育ちきった あとでも きちんと お世話を つづければ「死亡」メーターは じぶんの ちからで しっかり さげられます。びょうき・体力ぎれ・ミニゲーム大失敗・食べすぎ など「なにか やらかした とき」の ダメージも あわせて ひかえめに 調整してあり、油断すると あがりますが、ふつうに お世話していれば おそれすぎる 必要は ありません。
- ミニゲームで遊ぶと(結果のよしあしに関わらず)「変身」メーターも上がっていきます。これがたまると、今の年齢の姿のまま別の種族ラインに変われるチャンスが訪れ、2つの候補(いまとは違う種族ラインの、同じ成長段階の姿)から選べます。「このままでいい」を選べば今の姿のまま育て続けることもできます。お世話の平均が高かったり、ミニゲームの腕前がよかったり、ラブロマンス系の選択を重ねていたりすると、候補にレアな「かみさま」「れんくん」「にんぎょ」「ユニコーン」「フェニックス」ラインが混ざることがあります(にんぎょは やさしい方向の選択、ユニコーンは ゆうかんな方向の選択を重ねていると出やすく、フェニックスは びょうきを何度も乗り越えていると出やすくなります)。この変身でも、「ずかん」からの ワンタップ変身と おなじく せいべつ・れんあいタイプ・せいかく傾向が まるごと 新しく ロールしなおされ、その けっか いまの こいびと/夫婦と おたがいの れんあい対象で なくなった ばあいは 自然に わかれます(こちらは 年齢・せいちょう段階は そのままで、しゅぞくラインだけが かわります)。
- ごはん・そうじ・ねる(起きる)・くすり(治療)がきちんと成功すると、「退化」メーターも少し下がります。お世話をしっかりすれば、たまってしまった退化メーターを打ち消すこともできます。
- 年齢(画面上部に出ている「年齢: ◯」の数字)が100になると、そのままゲームクリアです。「はじめから」で新しいたまごから再スタートできます。進化すると年齢がその段階の年齢まで進み、退化すると年齢がその段階の年齢まで戻るので、進化・退化がそのままゴールへの近道/遠回りになります。
- クリア演出は、クリア時点で「ずかん」「じっせき」がどれだけ揃っているかで4段階に豪華さが変わり、それぞれ見た目も丸ごと違う演出になっています。①ふつうにクリア(夕焼けいろの グラデーションに、風船と紙吹雪が ふわふわ 舞いおちる)→ ②ずかんもコンプリートして クリア(📖バッジつき、しぜんを イメージした 緑いろの グラデーションに、はっぱと本が ゆらゆら 舞いおちる)→ ③じっせきもコンプリートして クリア(🏅バッジつき、ずかん以外の46個の実績が対象。ひょうしょうしきを イメージした 金いろの グラデーションに スポットライトが 横切り、メダルと花火が まわりに はじける)→ ④ずかんも じっせきも すべてコンプリートして クリア(「PERFECT CLEAR」の特別な金色+虹色の回転リングつきエフェクトで、王冠・きらめき・花火が いちばん たくさん・はやく はじけとぶ)。ずかんが16+5種族×8段階(合計168種類)に増えたため、①②の道のりも②③④よりずっと長くなっています。
- この4段階のクリアパターンは、一度でも たどりついたら そのあかしとして 🎉(ふつうクリア)📖(ずかんコンプリート)🏅(じっせきコンプリート)👑(PERFECT CLEAR)のバッジが キャラの 左上に つくようになり、「はじめから」しても消えません。ずかんコンプリートとじっせきコンプリートは それぞれ独立に判定されるので、両方そろった状態でクリアすると(PERFECT CLEARと同時に)4つのバッジが いっきに そろうこともあります。4つ ぜんぶの バッジが そろうと、その しゅんかんに 育成がめんの色が「レインボー」に自動で切りかわります。これも「はじめから」しても消えない永続のごほうびで、そのあとは「でざいん」ボタンから レインボーと ほかの色を いつでも自由に切りかえられます。
- クリア画面の 説明文には、①②③(ふつう/ずかんコンプリート/じっせきコンプリート)の ときだけ「つぎは ずかん・じっせきを コンプリートして、もっと すごい ゴールを めざしてね!!」のような、そのクリアで まだ 足りていない 条件を ぐたいてきに 示す 一言が 添えられます。④PERFECT CLEAR(ずかん・じっせき りょうほう コンプリート)の ときだけは、めざす さきが もう ない ぶん この 一言の かわりに「これからは じゆうに あそんでね」という メッセージと「じゆうに あそぶ」ボタンが 表示されます。押すと ゲームオーバー状態が 解除され、年齢・ゴールメーターは そのままに 通常プレイ(ごはん・そうじ・きゅうあい・たび など すべての ボタン)を ずっと 続けられます。
- PERFECT CLEARで「じゆうに あそぶ」を 選んだ あとは、「ずかん」で であった ことの ある すがた(❓で 伏せられていない セル)を タップすると、その ばで すぐ その すがたに 変身できます(なかま・こいびとの セクションは 対象外)。変身メーターを ためて 2択から えらぶ 通常の「変身」とは べつの、コレクションを 自由に 見せびらかせる ごほうび機能です。この変身では しゅぞく・せいちょう段階に くわえて、せいべつ・れんあいタイプ・せいかく傾向も、たまごが かえる ときと おなじ ロジックで まるごと 新しく ロールしなおされます(重みつきランダムで、man/womanラインなら せいべつは こていのまま)。その けっか、れんあいタイプが 変わって いまの こいびと/夫婦と おたがいの れんあい対象で なくなって しまう ことも あり、その ばあいは なかよし度が0に なった ときと おなじ あつかいで 自然に わかれます(夫婦なら りこん、こいびとなら はなれる あつかいで、それぞれ「死亡」メーターに ダメージも 入ります)。
- この年齢の進み具合は「ゴール」メーターとして画面にも表示され、現在の値が「◯◯ / 100」の数字と虹色のバーで確認できます。
- ミニゲームでいい成績(スコア70以上)を出すと、「死亡」メーターを回復できるごほうびアイテムを1つもらえます。キス・ハグ・かたたたき・なべ・カレー・うどん・ドッグフード・キャットフード・あめ の9種類があり、回復力はキスが一番高く、ハグが2番目に高いです(レアなアイテムほど回復力が高く、出現率は低くなっています)。もらったアイテムはメッセージの下にボタンとして並び、タップすると1つ消費して「死亡」メーターを減らせます。
- ミニゲームでいい成績(スコア70以上)を出すと、上のごほうびアイテムに加えて「おかね」(💰5〜10くらい)ももらえます。画面上部の「年齢」の よこに 現在の しょじきんが つねに表示され、「あいてむ」ボタンから開ける ショップで つかえます。おかねは「はじめから」しても 消えない永続の しょじきんです。
