# なおとっち

ブラウザで遊べる、なおとっちの育成ゲームです。ビルド不要、HTML/CSS/JSだけで動きます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ローカルで確認する場合は、リポジトリのルートで以下のように簡易サーバーを立てても構いません。

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。

- そこから先の成長(あかちゃん→こども→思春期→若者→おとな→エルダーの8段階)は放っておくだけでは進みません。「進化」メーターが満タンになったときだけ、そのタイミングで確実に1段階変身します。種族ごとに全段階ちがう見た目・せりふが用意されています(例:いぬなら 子犬→よちよちあるく こいぬ→こいぬ→わんぱくいぬ→そとあそび だいすきな いぬ→わかいいぬ→いぬ→としをとった いぬ)。
- 「満腹」「機嫌」「元気」「体力」の4つのステータスを管理します。

- 反射神経・記憶・計算・注意力系のゲームは大人でも歯ごたえのある脳トレ系で、なおとっちの年齢が上がるほど難易度も上がります(記憶する個数が増える、時間制限が短くなる、判定がシビアになる、など)。ほかのゲームも同様に、育つほどタイミングがシビアになったり展開が速くなったりします。
- おやつキャッチには うんち・ゴキブリ・刃物・銃 などの「わるいもの」も混ざっていて、キャッチすると減点されます。
- マンガ風の質問は40種類・160択(ふつう・シリアス・大人っぽい・馬鹿らしい・ラブロマンス的・感動)を用意していて、全部出きるまで同じ質問は繰り返しません。「感動」は新しく追加した、涙腺にくる系の質問カテゴリです。選択肢を選ぶと、その方向性にあわせた一瞬の演出(ハート・きらめきなど)が入ってから結果が反映されます。
- お世話をさぼる(うんちが溜まる・おなかがすいている・きげんが悪い・体力が低い)と、びょうきになりやすくなります。びょうきには10種類の症状名があり、そのたびに画面とペットの見た目も病気っぽく変化します。くすりで治療できます。
- 放っておくと うんち が溜まったり、びょうきになったりします。びょうきを何度も繰り返していると、そのぶん弱っていき、天国に旅立つまでの時間も短くなります(リセットでやり直せます)。
- 「進化」「退化」「死亡」「変身」の4つのメーターがあります。ごはん・そうじ・ねる・くすり・ミニゲームがうまくいくと「進化」メーターが上がり、たまると必ず1段階変身(成長)します。逆に手入れをさぼったり、ミニゲームに失敗したり、くすりを無駄遣いしたりすると「退化」メーターが上がり、たまると必ず1段階もどってしまいます(種族ラインは変わりません)。年齢の下限は0です。びょうきになったり、体力が0の状態が続いたり、ミニゲームに失敗し続けたりすると「死亡」メーターが上がり、たまると死亡します。成長のスピード自体もかなり速くしてあるので、数分プレイするだけでも進化・退化・死亡がどんどん起こります。逆に、びょうきでなく満腹・機嫌・元気・体力の4つが すべて そこそこ高い(60いじょう)状態を たもてていると、「死亡」メーターが すこしずつ ひとりでに 回復していきます。回復アイテムの うんに たよらなくても、ちゃんと お世話を つづければ じぶんの ちからで 下げられます(ひとつでも 60を きると その瞬間は 回復しません)。これに くわえて、「死亡」メーターは 年齢が 上がるほど なにも なくても わずかに 自然に 上昇していきます(放っておいても メーターが まったく うごかない、という ぬるさを なくす ための しくみです)。育ちきった あとは この自然じょうしょうぶんが 60いじょうを たもつ回復ぶんを うわまわるので、どんなに かんぺきに お世話しても すこしずつは あがっていき、ときどき 回復アイテムを つかって 打ち消す ひつようが あります(急激な 上昇では ないので、こまめに アイテムを つかえば じゅうぶん おさえられます)。
- ミニゲームで遊ぶと(結果のよしあしに関わらず)「変身」メーターも上がっていきます。これがたまると、今の年齢の姿のまま別の種族ラインに変われるチャンスが訪れ、2つの候補(いまとは違う種族ラインの、同じ成長段階の姿)から選べます。「このままでいい」を選べば今の姿のまま育て続けることもできます。お世話の平均が高かったり、ミニゲームの腕前がよかったり、ラブロマンス系の選択を重ねていたりすると、候補にレアな「かみさま」「れんくん」「にんぎょ」「ユニコーン」「フェニックス」ラインが混ざることがあります(にんぎょは やさしい方向の選択、ユニコーンは ゆうかんな方向の選択を重ねていると出やすく、フェニックスは びょうきを何度も乗り越えていると出やすくなります)。
- ごはん・そうじ・ねる(起きる)・くすり(治療)がきちんと成功すると、「退化」メーターも少し下がります。お世話をしっかりすれば、たまってしまった退化メーターを打ち消すこともできます。
- 年齢(画面上部に出ている「年齢: ◯」の数字)が100になると、そのままゲームクリアです。「はじめから」で新しいたまごから再スタートできます。進化すると年齢がその段階の年齢まで進み、退化すると年齢がその段階の年齢まで戻るので、進化・退化がそのままゴールへの近道/遠回りになります。
- クリア演出は、クリア時点で「ずかん」「じっせき」がどれだけ揃っているかで4段階に豪華さが変わり、それぞれ見た目も丸ごと違う演出になっています。①ふつうにクリア(夕焼けいろの グラデーションに、風船と紙吹雪が ふわふわ 舞いおちる)→ ②ずかんもコンプリートして クリア(📖バッジつき、しぜんを イメージした 緑いろの グラデーションに、はっぱと本が ゆらゆら 舞いおちる)→ ③じっせきもコンプリートして クリア(🏅バッジつき、ずかん以外の46個の実績が対象。ひょうしょうしきを イメージした 金いろの グラデーションに スポットライトが 横切り、メダルと花火が まわりに はじける)→ ④ずかんも じっせきも すべてコンプリートして クリア(「PERFECT CLEAR」の特別な金色+虹色の回転リングつきエフェクトで、王冠・きらめき・花火が いちばん たくさん・はやく はじけとぶ)。ずかんが16+5種族×8段階(合計168種類)に増えたため、①②の道のりも②③④よりずっと長くなっています。
- この4段階のクリアパターンは、一度でも たどりついたら そのあかしとして 🎉(ふつうクリア)📖(ずかんコンプリート)🏅(じっせきコンプリート)👑(PERFECT CLEAR)のバッジが キャラの 左上に つくようになり、「はじめから」しても消えません。ずかんコンプリートとじっせきコンプリートは それぞれ独立に判定されるので、両方そろった状態でクリアすると(PERFECT CLEARと同時に)4つのバッジが いっきに そろうこともあります。4つ ぜんぶの バッジが そろうと、その しゅんかんに 育成がめんの色が「レインボー」に自動で切りかわります。これも「はじめから」しても消えない永続のごほうびで、そのあとは「でざいん」ボタンから レインボーと ほかの色を いつでも自由に切りかえられます。
- クリア画面の 説明文には、①②③(ふつう/ずかんコンプリート/じっせきコンプリート)の ときだけ「つぎは ずかん・じっせきを コンプリートして、もっと すごい ゴールを めざしてね!!」のような、そのクリアで まだ 足りていない 条件を ぐたいてきに 示す 一言が 添えられます。④PERFECT CLEAR(ずかん・じっせき りょうほう コンプリート)の ときだけは、めざす さきが もう ない ぶん この 一言の かわりに「これからは じゆうに あそんでね」という メッセージと「じゆうに あそぶ」ボタンが 表示されます。押すと ゲームオーバー状態が 解除され、年齢・ゴールメーターは そのままに 通常プレイ(ごはん・そうじ・きゅうあい・たび など すべての ボタン)を ずっと 続けられます。
- PERFECT CLEARで「じゆうに あそぶ」を 選んだ あとは、「ずかん」で であった ことの ある すがた(❓で 伏せられていない セル)を タップすると、その ばで すぐ その すがたに 変身できます(なかま・こいびとの セクションは 対象外)。変身メーターを ためて 2択から えらぶ 通常の「変身」とは べつの、コレクションを 自由に 見せびらかせる ごほうび機能です。
- この年齢の進み具合は「ゴール」メーターとして画面にも表示され、現在の値が「◯◯ / 100」の数字と虹色のバーで確認できます。
- ミニゲームでいい成績(スコア70以上)を出すと、「死亡」メーターを回復できるごほうびアイテムを1つもらえます。キス・ハグ・かたたたき・なべ・カレー・うどん・ドッグフード・キャットフード・あめ の9種類があり、回復力はキスが一番高く、ハグが2番目に高いです(レアなアイテムほど回復力が高く、出現率は低くなっています)。もらったアイテムはメッセージの下にボタンとして並び、タップすると1つ消費して「死亡」メーターを減らせます。
- ミニゲームでいい成績(スコア70以上)を出すと、上のごほうびアイテムに加えて「おかね」(💰5〜10くらい)ももらえます。画面上部の「年齢」の よこに 現在の しょじきんが つねに表示され、「あいてむ」ボタンから開ける ショップで つかえます。おかねは「はじめから」しても 消えない永続の しょじきんです。
- 「あいてむ」ボタンを押すと、おかねで こうにゅうできる「みにつける もの」(8種類、それぞれ ねだんが ちがいます)の一覧が開きます。タップすると、みこうにゅうなら おかねを はらって こうにゅうし、そのまま そうびします。すでに もっている ものは タップの たびに そうび/かいじょが きりかわり(いちどに そうびできるのは 1つだけ)、そうびちゅうの アイテムは なおとっちの みぎうえに ずっと 表示されつづけます。こうにゅうずみの アイテムと いま そうびしている アイテムは「でざいん」の せっていと おなじく「はじめから」しても消えない永続の コレクションです。
- みにつける ものは、それぞれ そうびちゅうだけ はっきする とくべつな こうかを もっています(ショップがめんにも 表示されます)。

- 「たび」ボタンを押すと、うみ・ゆきやま・とかい・いなか・もり・さばく・なんごく の7つの地域(+はじめの「おうち」)から、いまいる地域とは ちがう場所にランダムに移動します。地域ごとに ゲーム機のまわりの背景色が変わるだけでなく、その地域らしい絵柄(うみなら🌊🐚🐠⛵、ゆきやまなら❄️⛄🏔️、とかいなら🏙️🌃🚕、など各地域8種類)が まわりに やわらかく ふわふわ ただよって、豪華な景色になります。この絵柄は地域を移動するたびに あたらしく ちりばめなおされ、画面上部の小さならんに いまの地域が表示されつづけます。地域ごとに2〜3種類の到着セリフが用意されていて、着くたびにランダムな反応を見せます。上記のとおり、地域ごとに出会える「きゅうあい」のあいても変わります。「あそぶ」のミニゲームも地域によってふんいきが変わり、地域ごとに専用のミニゲームが4種類ずつ用意されています(うみなら「さかなつり」「カニたたき」「さんごしょうの めいろ」「うみの いきものペアさがし」、ゆきやまなら「ゆきだるまを よけて すべる」「ゆきだるまづくり」「ペンギンたたき」「ゆきの けっしょうキャッチ」、さばくなら「オアシスの みずキャッチ」「サボテンよけジャンプ」「サソリたたき」「さばくロードレース」など)。はじめの「おうち」も れっきとした ひとつの地域として あつかい、おなじく専用の4種類(「おそうじ れんだタップ」「せんたくもの キャッチ」「おもちゃばこの ペアさがし」「おかたづけめいろ」)を もっています。地域専用のミニゲームを 優先的に出すような 特別あつかいは せず、いま いる地域に いるあいだだけ その4種類が いつもの共通ミニゲームの プールに そのまま くわわる かたちにしています。さらに、地域専用がある「しゅるい」(もぐらたたき系・キャッチ系・しょうがいぶつジャンプ・ロードげーむ など)は、ふつうの バリエーションを いっさい出さず、地域仕様だけに まるごと おきかわります(たとえば さばくに いるあいだは、もぐらたたき系は「サソリたたき」しか出ず、ほし・もぐら・むし・おばけ・ひよこ・はてなブロック・ライバルファイターは 出ません)。地域専用の ない しゅるい(タイミングタップ系・けいさんチャレンジ系 など)は これまでどおり ふつうの プールから えらばれるので、プールぜんたいの けんすうは 地域によって かわります(たとえば さばくでは 95−(もぐらたたき7+キャッチ8+ジャンプ3+ロード3)+地域専用4=78種類)。それでも「あそぶ」は 全部出きるまで 同じものを 繰り返さない しくみなので、旅先に とうちゃくした あいだは その地域らしい あそびに かならず めぐりあえます(地域を はなれると すぐ その地域の プールに きりかわります)。なお、もぐらたたき系だけは「おうち」もふくめた 全8つの地域すべてに 地域限定版が あるため、ほし・もぐら・むし・おばけ・ひよこ・はてなブロック・ライバルファイターの ふつうの7種類は「おうち」でしか 出会えません(「おうち」自身は もぐらたたき系の 地域限定版を もたないよう あえて はずしてあるので、この7種類が どこにも 出せなくなることは ありません)。旅をしても年齢・種族・成長段階・ステータス・ずかん・じっせき・「でざいん」の設定などは変わらず、こいびとと同じく現在地だけが「はじめから」でリセットされます。たびは からだを つかう ので、おす たびに「元気」を6ポイント、「満腹」を4ポイント けずります。「機嫌」は 1回ごとに+5される ボーナスが ありますが、ほかの おせわを はさまずに 4連続いじょう おしつづける(「たびづかれ」)と、この ボーナスが きえて 逆に「機嫌」が3ポイント へってしまいます。ほかの ボタンを ひとつでも おせば「たびづかれ」の カウントは リセットされるので、たびの あいまに ふつうに おせわを していれば ふせげます。
- ふだんの育成中、ごくたまに「なかまイベント」が とつぜん おきます。まず であった あいて(しばいぬ・たぬき・ペンギン・ふくろう・うさぎ・はりねずみ・コアラ・カワウソ・ハムスター・リスの10種類から ランダムで1たい)が ひとこと しょうかいされ、そのあと じどうで ミニゲームが はじまります。クリアできれば その あいてが「なかま」になり、なれなくても また こんど おなじ あいてに であえます。いちど でも であって なかまに なった ことの ある きろくは「ずかん」の したのほうにも「なかま」セクションとして追加され(何/10 で進捗表示)、種族の ずかんと おなじく「はじめから」しても消えない永続のコレクションです。
- ただし「いま そばに いる なかま」は それとは べつに、その プレイ中だけの きずな度(bond)で かんりされています。なかまに なった しゅんかんは きずな度100で 本体キャラの りょうサイド(こうごに ひだり・みぎ)に くっついて 表示され、本体キャラが ゆらゆら ゆれる うごきにも いっしょに ついてきますが、「じゃれる」を おさぼると じわじわ きずな度が さがっていき、0に なると さびしがって はなれて いってしまいます(いちど であった きろくは きえないので、また あとで「なかまイベント」で であいなおせます)。「じゃれる」を おすたびに、そばに いる なかま ぜんいんの きずな度が まとめて かいふくするので、なかまが いる あいだは「じゃれる」を わすれずに おすのが たいせつです。なかまが そばに いるあいだ、じゃれるの メッセージには「なかまたちも まざって いっしょに あまえてきた!」のような、なかまが いる ときだけの すこし ちがった 文言も まざって 表示されます。そばに いる なかまが ふえるほど「元気」の 時間経過による げんしょうが おだやかになり(1たいごとに5%ずつ やわらぎ、10たい そろうと げんしょうスピードが半分に)、にぎやかな なかまとの くらしが つかれを やわらげてくれます。「元気」の 基本の げんしょうスピード じたいも、なかまが 0たいの ときでも いぜんより ゆっくりに 調整しました。
- 「ずかん」の いちばん したには「こいびと」セクションもあり、「きゅうあいする」で いままでに こいびとに なった ことが ある 地域ごとの あいて(全8地域×2種類=16種類)が きねんに 記録されます(何/16 で進捗表示)。けっこんまで いたった あいては 💍 マークつきで表示され、なかま・種族の ずかんと おなじく「はじめから」しても消えない永続のコレクションです(「あいてコード」の おきゃくさんは、こちらではなく 種族の ずかんに 記録されます)。
- キャラのひょうじ(pet-area)の右下に人物アイコン(👤)のボタンがあり、押すと「プロフィール」が開きます。しゅぞく・せいちょう段階・せいべつ・れんあいタイプに加えて、これまでのお世話や選択でどう傾いているかを示す「せいかく傾向」(やさしい・やんちゃ・おだやか・ゆうかん・ロマンチックの5本バー)が確認できます。クエスチョニングのあいだは、あと何回の経験で自分のタイプがはっきりするかの進捗もここに表示されます。こいびとがいる場合は、そのせいべつ・れんあいタイプに加えて、相性ボーナスの元になっている「すきなところ」(affinityTrait)も、こいびとが成立したあとだけここで確認できます(こくはく前の相手には表示されません)。「なかま」の欄には、いま そばに いる なかま ぜんいんが アイコン・なまえ・きずな度バーつきで いちらん表示され、じゃれるを おさぼると このバーが へっていく ようすが ひとめで わかります(だれも いないときは その むねの あんないが 出ます)。
- この「プロフィール」画面の「あいてコード」から、ほかの端末をつかっている ともだち と なおとっちを出会わせることができます。サーバーや通信は使わず、なおとっちの しゅぞく・せいちょう段階・せいべつ・れんあいタイプ・せいかく傾向を短い文字コードに変換するだけの、完全無料のしくみです。「コードを つくる」で発行した自分のコードを ともだち に送り(LINEなど、好きな方法で)、もらった ともだち のコードを「よみこむ」に貼り付けると、その ともだち の なおとっちが「おきゃくさん」として登場します。「きゅうあいする」を押すと、いま いる地域の キャラに加えて、この おきゃくさん にも こくはく できるようになり(れんあいタイプの相性判定はふつうの こくはく と同じ)、成立すれば正式な こいびと になります。おきゃくさんは じっさいの ともだちの なおとっちなので、地域の2キャラと おなじ かくりつで うもれてしまわないよう、いる ときは 6わり多めの かくりつで 優先的に こうほに えらばれます。おきゃくさんは、そのプレイのあいだ(「はじめから」するまで)ずっと 画面に とどまり、こいびとが成立すると その しゅぞく・すがたが「ずかん」にも記念に記録されます。すでに べつの あいてと こいびと/夫婦の じょうたいで おきゃくさんを よみこんだ ばあいは、「きゅうあいする」は いまの あいてと いちゃつく だけに なり おきゃくさんは こうほに はいらないので、プロフィール画面に その りゆうを つたえる せつめいが 表示されます(この おきゃくさんと こくはくするには、いまの あいてと わかれる ひつようが あります)。
