# なおとっち

ブラウザで遊べる育成ゲームです。ごはんやそうじ、ミニゲームでお世話をしながら、出会いと成長を楽しめます。

[ゲームを遊ぶ](https://naoto214.github.io/naotocchi/)

このガイドはPR #206までのmainと、今回のUI統合に合わせています。開発は継続中です。再開時は [公開後チェックポイント](POST_RELEASE_CHECKPOINT_2026-09-10.md) とGitHubの最新状態を確認してください。

## 遊び方

「満腹」「機嫌」「元気」「体力」を見ながら、ごはん・そうじ・ねる・くすり・あそぶでお世話します。進行は使っているブラウザの保存領域に自動保存されます。公開ゲームと別のURL・ブラウザでは、同じセーブが自動で共有されるわけではありません。

### 年齢とそだち

年齢はゲームを開いて育成している時間で進みます。基本画面とミニゲーム中は3秒ごとの更新20回で1さい、100さいで人生の締めくくりを迎えます。図鑑などのメニューやデートのムービー中は育成時間が止まり、ページを閉じていた時間は加算されません。

孵化後の姿は年齢で決まる8段階です。卵はこの8段階に含みません。

| 始まる年齢 | 姿の段階 |
| --- | --- |
| 0さい | あかちゃん |
| 3さい | よちよち |
| 7さい | こども |
| 12さい | しょうねん・しょうじょ |
| 16さい | せいしゅん |
| 22さい | わかもの |
| 40さい | おとな |
| 70さい | ろうねん |

「そだち」は20から始まり、0〜100で変わる育ち具合です。お世話などでためた「せいちょう」が必要量に達すると上がり、「おとろえ」がたまると下がります。そだちの上下で年齢や姿の段階が巻き戻ることはありません。到達した最高そだちに応じて特典も開きます。

別の種族になる「へんしん」のチャンスは、姿の段階が変わる節目に抽選されます。候補を選ぶほか、今の姿で育て続けることもできます。

### キャラクターと世界

| 内容 | 現行の構成 |
| --- | --- |
| 主人公 | 通常22種族・レア8種族・隠し1種族。各8段階、計248形態 |
| なかま | 通常18体・レア8体 |
| こいびと | 18体 |
| たびさき | 通常10地域・特別2地域 |
| でんせつ | 5体 |
| きせつ | げんじつにあわせる・はる・なつ・あき・ふゆ |

通常の卵からは通常22種族のいずれかが生まれます。「たまごのゆめ」などで次の種族を選んでいた場合は、その指定が使われます。レア・隠し種族には別の入手条件があります。

ホームの「たび」で行き先を選びます。「メニュー」→「せかい」では、じかん・きせつ・てんきを「げんざい」か手動で選べます。じかんときせつはスマホの時計にあわせ、現在のてんきは位置情報から取得します。現在地の表示は市区町村までで、座標や住所はセーブに残しません。取得できないときは再試行や手動設定ができます。旧セーブに残っている引退済みキャラクターも互換性の対象です。上の数字は現在の構成で、古いキャラクターを似た新キャラクターへ置き換える意味ではありません。

### あそぶ

ミニゲームは100種類あります。地域・季節向けのゲームもすべて候補に入り、現在の地域や季節に合うもの、まだあまり遊んでいないものは出やすくなります。同じジャンルの連続を減らす選び方も入っています。

「あそぶ」でランダムにすぐ始まります。「メニュー」→「ゲームを選ぶ」で、遊んだゲームの記録を確認して選べます。100種類という数字は登録数であり、すべての端末で操作感・描画まで確認済みという意味ではありません。

### むずかしさとおと

「メニュー」→「せかい」の「ゲームの むずかしさ」で、やさしい・ふつう・むずかしいを選べます。年齢で上がる難しさの伸びを やさしい0.4倍・ふつう0.7倍・むずかしい1倍に抑え、制限時間も やさしい+35%・ふつう+17% 長くなります(100本すべての制限時間が対象)。たこやきの焼き加減の幅、ルナランダーの着陸判定、ドットイーターのライフも やさしいで ゆるくなります。はじめの設定は「ふつう」です。

効果音とBGMは音のファイルを使わず、WebAudioでその場で作ります。効果音はボタンのタップ、ミニゲームのゲット/ミス/クリア(ヒント文の変わり目から自動判定)、結果のランクに応じたファンファーレ、実績やイベントの知らせ、そだち・孵化・おわかれ・ねる/おきる など。BGMは場面ごとに5曲(ふつうの画面 / よる / ミニゲーム / デート・ムービー / おわかれ)をループし、場面が変わるとクロスフェードします。ブラウザの決まりで最初のタップまでは鳴らず、タブを離れると止まります。「せかい」の「おと」で効果音とBGMをそれぞれON/OFFできます。

### デートとごほうび

上の「データ」にあるこいびとの欄からデートに誘い、行き先を選びます。ごほうびを持っていると、ゲーム内に「ごほうびを1こ使う」「使わずにデートする」「行き先にもどる」が表示されます。

ごほうびは「ごほうびを1こ使う」を選んで特別デートを始めると1個消費します。行き先選択に戻っただけでは消費しません。深海にも地域に合うデートが用意されています。

### 5つのゴール

| ゴール | 新しく達成する条件 |
| --- | --- |
| ① てんじゅをまっとうした | 100さいまで生きる |
| ② いっしょうクリア | 100さいまで生き、その人生の最高そだちが70以上 |
| ③ さいこうのいっしょう | 100さいまで生き、その人生の最高そだちが100 |
| ④ ずかんクリア | 現行の主人公248形態を見つける |
| ⑤ PERFECT CLEAR | 図鑑コンプリートを含む全実績を達成する |

①〜③は100さいでの人生評価、④〜⑤は積み重ねたコレクションの目標です。図鑑や獲得済み実績、クリア記録などは次の人生にも引き継がれます。旧版で獲得済みの報酬は保持する互換処理があります。

## 画面とデザイン

お世話はホームの9ボタンにまとまっています。きゅうあいは続けて押せます。元気なときにくすりを使った反応も残っています。おとろえを含む育成ゲージは通常のホームで確認できます。

名前・恋人の名前・クリアのバッジは上に、セリフは吹き出しに表示します。仲間が増えると左右の弧に並び、メイン・恋人・仲間・装備は一緒に左右に揺れます。端末の「視差効果を減らす」など、動きを減らす設定では静止します。

「メニュー」→「デザイン」は、がめん／ほんたいを選んで色や柄を変更します。40色・40柄と従来の解放条件を保ち、文字のテイストと大きさも選べます。「データ」「つうしん」は上のボタンから開けます。

## ローカルで動かす

通常のゲームはビルド不要です。リポジトリのルートで次を実行し、ブラウザで `http://localhost:8000` を開いてください。

```sh
python3 -m http.server 8000
```

開発用のシーン確認はViteで起動します。

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

起動時に表示されるURLの `/__qa` を開くと、デート・記念日・伝説などの確認用セーブを選べます。選んだセーブで同じオリジンの保存領域を上書きするので、普段のゲームとは別のオリジンで使ってください。`/__qa` は開発用ルートで、GitHub Pagesにはありません。

```sh
npm test
```

`npm test` は起動・ミニゲーム登録と開始・会話・QAセーブに加え、終了や画面切り替え時の入力解除と、保存失敗・バックアップ復旧・旧セーブ移行を検証します。ブラウザでの見た目、実機の速度や操作感は別に確認します。
