# なおとっち

ブラウザで遊べる、なおとっちの育成ゲームです。ビルド不要、HTML/CSS/JSだけで動きます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ローカルで確認する場合は、リポジトリのルートで以下のように簡易サーバーを立てても構いません。

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。

## ゲームの内容

- 卵がかえるとき、「いぬ・ねこ・とり・おとこのひと・おんなのひと・カブトムシ・クワガタムシ・うさぎ・さかな・りゅう・パンダ・きつね・ふくろう・はな・ロボット・きょうりゅう」の16種族のどれになるかがランダムに決まります。動物だけでなく、はな(植物)やロボットのような種族もいます。あかちゃんの見た目もそのときから種族ごとに違います(たとえば犬なら子犬、女の子なら赤ちゃんの女の子、というように)。
- そこから先の成長(あかちゃん→こども→思春期→若者→おとな→エルダーの8段階)は放っておくだけでは進みません。「進化」メーターが満タンになったときだけ、そのタイミングで確実に1段階変身します。種族ごとに全段階ちがう見た目・せりふが用意されています(例:いぬなら 子犬→よちよちあるく こいぬ→こいぬ→わんぱくいぬ→そとあそび だいすきな いぬ→わかいいぬ→いぬ→としをとった いぬ)。
- 「満腹」「機嫌」「元気」「体力」の4つのステータスを管理します。
- 「あそぶ」を押すと、69種類のミニゲームから、全部出きるまで同じものを繰り返さないようにランダムで1つが始まります。結果に応じて機嫌が上がります。内訳は以下のとおりです。

  - もぐらたたき系(5種):ほし・もぐら・むし・おばけ・ひよこ
  - タイミングタップ系(3種)
  - マンガ風の質問(7種):テーマ別(ふつう・シリアス・大人っぽい・馬鹿らしい・ラブロマンス的・感動)+ぜんぶミックス
  - きおくチャレンジ系(4種):いろ・どうぶつ・たべもの・きせつ
  - けいさんチャレンジ系(5種):ミックス・たしざん・ひきざん・かけざん・わりざん

  - 神経衰弱(ペアさがし、3種):くだもの・どうぶつ・たべもの

  - バランスゲーム(1種)
  - まちがいさがし(2種):いろ・どうぶつ
  - すうじならべ(1種)

  - けつだんめいろ(2種):もりのめいろ・ほらあなのめいろ(わかれみちで正しい方をえらぶ)
  - いろわけ・しわけ(2種):くだものだけ・あおいものだけを グリッドから タップでさがす
  - ハイ&ロー(1種):つぎの数字が たかいか ひくいかを あてる

- 反射神経・記憶・計算・注意力系のゲームは大人でも歯ごたえのある脳トレ系で、なおとっちの年齢が上がるほど難易度も上がります(記憶する個数が増える、時間制限が短くなる、判定がシビアになる、など)。ほかのゲームも同様に、育つほどタイミングがシビアになったり展開が速くなったりします。
- おやつキャッチには うんち・ゴキブリ・刃物・銃 などの「わるいもの」も混ざっていて、キャッチすると減点されます。
- マンガ風の質問は40種類・160択(ふつう・シリアス・大人っぽい・馬鹿らしい・ラブロマンス的・感動)を用意していて、全部出きるまで同じ質問は繰り返しません。「感動」は新しく追加した、涙腺にくる系の質問カテゴリです。選択肢を選ぶと、その方向性にあわせた一瞬の演出(ハート・きらめきなど)が入ってから結果が反映されます。
- お世話をさぼる(うんちが溜まる・おなかがすいている・きげんが悪い・体力が低い)と、びょうきになりやすくなります。びょうきには10種類の症状名があり、そのたびに画面とペットの見た目も病気っぽく変化します。くすりで治療できます。
- 放っておくと うんち が溜まったり、びょうきになったりします。びょうきを何度も繰り返していると、そのぶん弱っていき、天国に旅立つまでの時間も短くなります(リセットでやり直せます)。
- 「進化」「退化」「死亡」「変身」の4つのメーターがあります。ごはん・そうじ・ねる・くすり・ミニゲームがうまくいくと「進化」メーターが上がり、たまると必ず1段階変身(成長)します。逆に手入れをさぼったり、ミニゲームに失敗したり、くすりを無駄遣いしたりすると「退化」メーターが上がり、たまると必ず1段階もどってしまいます(種族ラインは変わりません)。年齢の下限は0です。びょうきになったり、体力が0の状態が続いたり、ミニゲームに失敗し続けたりすると「死亡」メーターが上がり、たまると死亡します。成長のスピード自体もかなり速くしてあるので、数分プレイするだけでも進化・退化・死亡がどんどん起こります。
- ミニゲームで遊ぶと(結果のよしあしに関わらず)「変身」メーターも上がっていきます。これがたまると、今の年齢の姿のまま別の種族ラインに変われるチャンスが訪れ、2つの候補(いまとは違う種族ラインの、同じ成長段階の姿)から選べます。「このままでいい」を選べば今の姿のまま育て続けることもできます。お世話の平均が高かったり、ミニゲームの腕前がよかったり、ラブロマンス系の選択を重ねていたりすると、候補にレアな「かみさま」「れんくん」「にんぎょ」「ユニコーン」「フェニックス」ラインが混ざることがあります(にんぎょは やさしい方向の選択、ユニコーンは ゆうかんな方向の選択を重ねていると出やすく、フェニックスは びょうきを何度も乗り越えていると出やすくなります)。
- ごはん・そうじ・ねる(起きる)・くすり(治療)がきちんと成功すると、「退化」メーターも少し下がります。お世話をしっかりすれば、たまってしまった退化メーターを打ち消すこともできます。
- 年齢(画面上部に出ている「年齢: ◯」の数字)が100になると、そのままゲームクリアです。「はじめから」で新しいたまごから再スタートできます。進化すると年齢がその段階の年齢まで進み、退化すると年齢がその段階の年齢まで戻るので、進化・退化がそのままゴールへの近道/遠回りになります。
- クリア演出は、クリア時点で「ずかん」「じっせき」がどれだけ揃っているかで4段階に豪華さが変わり、それぞれ見た目も丸ごと違う演出になっています。①ふつうにクリア(夕焼けいろの グラデーションに、風船と紙吹雪が ふわふわ 舞いおちる)→ ②ずかんもコンプリートして クリア(📖バッジつき、しぜんを イメージした 緑いろの グラデーションに、はっぱと本が ゆらゆら 舞いおちる)→ ③じっせきもコンプリートして クリア(🏅バッジつき、ずかん以外の46個の実績が対象。ひょうしょうしきを イメージした 金いろの グラデーションに スポットライトが 横切り、メダルと花火が まわりに はじける)→ ④ずかんも じっせきも すべてコンプリートして クリア(「PERFECT CLEAR」の特別な金色+虹色の回転リングつきエフェクトで、王冠・きらめき・花火が いちばん たくさん・はやく はじけとぶ)。ずかんが16+5種族×8段階(合計168種類)に増えたため、①②の道のりも②③④よりずっと長くなっています。
- この4段階のクリアパターンは、一度でも たどりついたら そのあかしとして 🎉(ふつうクリア)📖(ずかんコンプリート)🏅(じっせきコンプリート)👑(PERFECT CLEAR)のバッジが キャラの 左上に つくようになり、「はじめから」しても消えません。4つ ぜんぶの バッジを 集めると、ふだんの育成がめんの 画面いろが 虹色に ゆっくり 変化しつづける「レインボーモード」になります(こちらも「はじめから」しても消えない、永続の ごほうびです)。
- この年齢の進み具合は「ゴール」メーターとして画面にも表示され、現在の値が「◯◯ / 100」の数字と虹色のバーで確認できます。
- ミニゲームでいい成績(スコア70以上)を出すと、「死亡」メーターを回復できるごほうびアイテムを1つもらえます。キス・ハグ・かたたたき・なべ・カレー・うどん・ドッグフード・キャットフード・あめ の9種類があり、回復力はキスが一番高く、ハグが2番目に高いです(レアなアイテムほど回復力が高く、出現率は低くなっています)。もらったアイテムはメッセージの下にボタンとして並び、タップすると1つ消費して「死亡」メーターを減らせます。
- ごはんは、おなかがすでに満腹に近い(満腹80以上)ときに与えると「食べすぎ」扱いになり、進化メーターは増えません。それどころか機嫌が下がり、退化メーターが上がり、一定確率でびょうきになってしまいます。ごはんを連打するだけでは簡単に進化できないようになっています。
- 進化・退化・変身・ミニゲームの好成績/大失敗・びょうきの治療・食べすぎ・そうじ、8つの場面それぞれで、その出来事に合わせた ちょっとユーモラスな コメント演出が画面上部に出ることがあります(例:進化なら「からだが ムズムズする…これが せいちょうつうか!?」、ミニゲーム大失敗なら「いまのは わすれて ほしい…れんしゅうだったし!」など)。場面ごとに4〜5種類の せりふを ランダムに抽選するので同じ場面でも毎回ちがう反応が見られ、出現確率は約45%です(でるかどうかも 毎回のお楽しみ)。この演出(および じっせき解放のお祝い演出)は画面いっぱいをふさぐのではなく上部の小さなバナーとして表示され、表示中もキャラやステータスは見えたままで、ごはん・あそぶなどの操作も止まらず続けられます。
- 進行状況(成長段階・各ステータスなど)はブラウザの localStorage に自動保存され、アプリを閉じても続きから再開できます。ただし時間はゲーム画面を実際に開いている間だけ進み、閉じている間は進みません。
- 「ずかん」ボタンを押すと、いぬ・ねこ・とり・おとこのひと・おんなのひと・カブトムシ・クワガタムシ・うさぎ・さかな・りゅう・パンダ・きつね・ふくろう・はな・ロボット・きょうりゅうの16種族+レアな「かみさま」「れんくん」「にんぎょ」「ユニコーン」「フェニックス」を合わせた21ライン×8段階、合計168種類の登場キャラクター一覧を確認できます。実際に育てて出会った姿だけが公開され、まだ見ていない段階は❓のまま伏せられます。この記録は「はじめから」でリセットしても消えず、何度も遊んでコンプリートを目指せます。
- 「じっせき」ボタンを押すと、はじめての進化・変身・ゲームクリア、進化を10回/50回/100回など、育てる中でのふしめとなる行動を記録した47種類の実績バッジ一覧を確認できます。進化・退化・変身・ゲームクリア・しぼう・ミニゲーム回数・びょうきの治療・年齢到達・ずかんの進み具合(25/50/100/150種類)・レアな種族との出会い・ふつうの16種族すべてとの出会い・エルダー(さいごの段階)10種類以上との出会い・ごはん/あそぶ/そうじ/なでる/はなしかける/くすりを1回の育成でたくさん行った・やさしい/ゆうかん/ロマンチックな選択肢を重ねた・「はじめから」を何度もした、など幅ひろいジャンルから目指せます。ずかんとちがい、未達成の実績もラベルと達成条件は常に見えるので、なにを目指せばいいかは最初からわかります。達成ずみかどうかは、内容を隠すのではなくカードの色(達成=金色のトロフィーカード、未達成=グレーの🔒カード)で判別します。こちらも「ずかん」と同様に「はじめから」でリセットしても記録は消えず、遊ぶたびに積み重なっていきます。実績を新しく達成すると、その場でお祝いの演出が出ます。
- 「なでる」「はなしかける」という2つの触れ合いボタンがあります。「なでる」はすこしだけ機嫌が上がり進化メーターもわずかに動きます。「はなしかける」は機嫌が上がるのに加えて退化メーターも少しだけ下がります。どちらもごはん・あそぶほどの効果はなく、合間に様子を見るための軽いアクションです。タップするたびに12種類のリアクションからランダムに1つが表示されます。
- ただし「なでる」「はなしかける」を、ほかのお世話(ごはん・そうじ・ねる・くすり・あそぶ)をはさまずに4回以上れんぞくで押すと、効果が逆転して機嫌が下がり退化メーターが上がるようになり、いやがるリアクションに変わります。連打で無限に機嫌をかせぐことはできず、ちゃんとほかのお世話も混ぜる必要があります。
- ふだんの画面でもキャラは完全に静止せず、ゆらゆらと左右に大きく ゆらめきながら 揺れ続け、数秒〜十数秒おきに ふと首をかしげたり ぴょこっと跳ねたりします(ねている間は もっと ゆったりした揺れに変わります)。お世話の結果ごとに モーションも変化し、うれしいとき(ごはん成功・おそうじ・くすり・なでる/はなしかけるの通常反応・進化・へんしん・ごほうびアイテム使用 など)はハートやきらめきが舞い上がりながら跳ね、たのしい大成功(ミニゲーム好成績)はくるっと回転し、かなしいとき(退化・ミニゲーム大失敗)はしゅんと うなだれて涙が浮かび、おこったとき(食べすぎ・びょうきじゃないのにくすり・なでる/はなしかけるの連打しすぎ)はぷるぷる震えて怒りマークが飛びます。
- なにもせず放っておくと、はやければ3びょうほど、平均でも3〜12びょうに1回くらいの頻度で キャラのほうから ひとこと話しかけてきます。「おい!」「やあ!」のような ふつうの声かけから、関西弁・博多弁・広島弁・名古屋弁・東北弁・北海道弁・土佐弁・うちなーぐち(沖縄)などの方言、Hello!・Bonjour!・你好!・안녕!・Привет! といった世界各国のあいさつ、ちょっとした ネタせりふまで、93種類のセリフをランダムに抽選します。ミニゲーム中・すいみん中・変身選択中や、ほかのメッセージが表示されている間は話しかけてきません。

- `index.html` — 画面構成
- `style.css` — たまごっち風デバイスの見た目
- `script.js` — ゲームロジック(状態管理・成長・保存)
