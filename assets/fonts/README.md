# Rounded Japanese UI font

`mplus-rounded-1c-regular.woff2` is the complete M PLUS Rounded 1c Regular
font, converted losslessly from TTF to WOFF2. No glyph subset or outline edits.

- Source: [Google Fonts — MPLUSRounded1c-Regular.ttf](https://github.com/google/fonts/blob/main/ofl/mplusrounded1c/MPLUSRounded1c-Regular.ttf)
- Source Git blob: `a66978b6a6f55de71105a37f8de702ab3f31d27d`
- Source version: `1.059.20150529`
- Copyright: 2016 The Rounded M+ Project Authors.
- License: SIL Open Font License 1.1; see [OFL.txt](OFL.txt).
- WOFF2: 1,017,540 bytes; SHA-256 `56e81fbbd16e8bf08d64c9d1d609a2748b908ae12887b6b944b25c29a291614e`.

Conversion used FontTools `TTFont`, setting `flavor = 'woff2'` before saving.
The decoded character map, glyph outlines, horizontal metrics and name/license
tables were checked against the source. The generic OFL 1.1 text is copied from
[Google Fonts' OFL distribution](https://github.com/google/fonts/blob/main/ofl/mplus1/OFL.txt),
with the copyright notice taken from this font's own name table.

The CSS family alias is `Naotocchi Rounded`. It loads from this game's own
assets with `font-display: swap` and a preload; gameplay does not wait for it.
Rounded system fonts and ordinary Japanese sans-serif provide fallback.
The existing standard/retro design choices remain available.
